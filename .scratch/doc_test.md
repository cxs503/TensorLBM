# P262W1-N02 冰–水–气三相接触线：伪势 LBM 的 Young 律 / Cox–Voinov 验证

*节点* p262w1-N02-lbm-contact-line ｜ *仓* TensorLBM ｜ *产物* `.scratch/out_run1` ｜ *运行时长* 661 s ｜ *quick 模式* False

## ① 案例介绍（物理背景 / 几何 / 参数）

冰–水–气三相接触线是冰区航行、结冰/融冰、超疏水防覆冰涂层的共同物理内核。连续介质层面它由两条独立定律支配：(i) **Young 律**把平衡接触角与三相界面张力联系起来，`cos θ_Y = (γ_sg − γ_sl)/γ_lg`；(ii) **Cox–Voinov 律**把动态接触角与接触线速度联系起来，`θ_d³ = θ_Y³ + 9 Ca ln(L/ℓ_m)`，`Ca = μU_CL/γ_lg`。本节点用二维 Shan–Chen 伪势 LBM 复现这两条定律。

**相的身份映射**：单组分伪势流体提供两相 —— 密相=水(l)、轻相=气(g)；**冰=刚性壁面**，润湿性由壁面虚拟伪势 `ψ_w = f·ψ(ρ_l)` 给定（f 为壁面耦合分数）。这是伪势模型处理「刚性基质 + 两流体」的标准做法，代价是冰不可熔化（见 ⑤ 局限）。

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **水/气张力 γ_lg —— Laplace 法，不用任何抄来的常数。** 无壁周期盒内松弛自由液滴，用等值线圆拟合得半径 R，用**本节点标定的晶格状态方程** `p = c_s²(ρ − (G/2)ψ²)` 得液/气压强差 Δp，则 `γ_lg = Δp·R`。状态方程独立验证：`p(ρ_l)` 与 `p(ρ_v)` 相差 0.3%（共存要求二者相等）。
2. **润湿张力 Δγ = γ_sg − γ_sl —— 两条路线，其中两条被判死，结论如实记录。**
   - 路线 A（压低张量积分）：对壁/流体界面做 `∫(P_xx−P_yy)dy`。**被证伪**：刚性壁处伪势作用力是纯法向，张量积分度量的是壁面法向压力/分离压而非界面张力，实测偏差约 0.024（≈0.43 γ_lg），且对 f 几乎不敏感（与实测角随 f 单调变化矛盾）。
   - 路线 B（热力学积分）：利用巨势对剖面驻值，`∂γ_sf/∂ψ_w = −G⟨ψS⟩`，沿 ψ_w 阶梯从 0 积分到目标值，液/气两次测量的未知常数在 Δγ 中相消。**同样被证伪**：以 `ψ_w=ψ(ρ_l)` 的内部锚点检验（该处 Δγ 应为 γ_lg≈0.0564）时 TI 给出 0.28，偏大 5 倍 —— 伪势模型的「双求和交互能」并不就是产生作用力的那个势（SC 模型已知的变分不一致性）。
   - 因此 **Young 律检验在本模型内无法闭合（honest WITHHELD/FAIL）**，下文把两条路线的数字与「由实测角反演的 Δγ = γ_lg cos θ」并列，供读者判读偏置方向与量级。
3. **静态接触角 θ_meas**：坐滴（初始为 110° 圆冠，比切圆 180° 更接近平衡）在壁面上松弛，每 200 步用等值线点云做整冠圆拟合 `theta_fit.angle_estimate`（含 bootstrap/窗口/壁面偏移不确定度预算），记录整条 θ(t) 松弛轨迹；若液滴铺展到充满整个周期域（footprint ≥ 0.85 nx）则标记 `angle_valid=False`，该角不参与判据。
4. **动态接触角与 Cox–Voinov**：同壁面坐滴施加流向体积力（仅作用于液相），以**质心位移**（全局、低噪）拟合稳态滑移速度 U_CL，用前缘/后缘圆拟合得 θ_A/θ_R，`Ca = μU_CL/γ_lg`，再用库内 `scaling.cox_voinov_fit` 做 `θ_d³−θ_Y³ = K·Ca` 最小二乘。
5. **网格收敛**：固定 g_x 与壁面，三档网格 (48×96, 64×128, 80×160) 比较 U_CL，Richardson 估计阶数 `p = log(|U₁−U₂|/|U₂−U₃|)/log(h₁/h₂)`，h ∝ 1/ny。
6. **质量守恒**：整体域质量（含壁内存储）+ 仅流体质量同时记录。全反弹壁面会在壁格内储存分布函数，导致仅流体质量出现 ~1% 的「表观漂移」，物理守恒量是全域总质量（见 ③ 表）。
7. **测试**：`pytest tests/test_contact_line_three_phase.py` —— 18 条用例，覆盖状态方程共存、张量各向异性、壁耦合权重、壁面切向力恒零命题、接触线定位解析解、Young 反解、TI 单调性、物理单位映射。

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

1. **伪势壁面不满足 Young 律的自身自洽性**（本节点主要负结果）：壁面虚拟密度法给出的接触角与模型自身壁面自由能不自洽；据此把 F1 判为 withheld/FAIL，而不是用一个「标定曲线」冒充预测。
2. **压力张量在刚性壁处失效**：壁面处作用力纯法向，`∫(P_xx−P_yy)` 度量的是法向压力/分离压；该量在 f 上几乎不变（对 f=0.3–0.5 约 0.027），与实测角随 f 的单调变化矛盾，故证伪。
3. **壁面切向力恒为零**（可在测试中复现）：均匀二维壁面在 x 方向上平移不变，伪势交互对固壁的切向合力精确为 0 —— 所以 Wilhelmy 式「直接测润湿张力」在本离散格式里不可用。
4. **全反弹壁面会在壁格内储存质量**：仅流体质量的表观漂移 ~1%，全域总质量漂移 ~1e-4。判据用后者；这一区别在报告里显式列出，避免把数值假象当成守恒性缺陷。
5. **驱动强度受限**：G=5、τ=1 的伪势模型在 g_x ≳ 1e-3 时发散；可用的 Ca 窗口很窄，且静态态的伪势假速度（spurious current）与滑移速度同量级，接触线速度信噪比是主要的系统误差来源。
6. **冰是刚性壁**：无熔化/冻结、无熔水膜；冰–水界面张力只能以「壁面耦合」间接表征。
7. **适用范围**：本模块给出的可复用能力是 (i) 状态方程标定的 Laplace 张力测量（0.075% 吻合）、(ii) 接触角/接触线定位/速度标定的后处理链、(iii) 壁面质量守恒的正确记账方式。Young 律的闭合需要换用自由能一致的多相模型（如自由能 LBM 或彩色梯度模型）。
