## ① 案例介绍（物理背景 / 几何 / 参数）

单组分 Shan–Chen 伪势模型（SCMP），D2Q9、ψ(ρ)=1−e^(−ρ)、G_lib=+5（= 教科书 G_eff=−5，吸引）、
τ=1.0。首轮的结论是：周期盒内液滴满足 Young–Laplace 律 Δp=σ/R，四半径（R=12…24）标定
σ=0.05550 vs "库锁定值" 0.0561 → 偏差 1.07%，并报告了一个**未解释的 56.8% 力格式敏感性**
（velocity-shift vs Guo）与一条**未做的 τ 依赖腿**。

本轮不改模型、不改协议，只做两件事：
**(a)** 用完全不同的探针（**平面界面**，Δp≡0）独立复核该标定的物理自洽性；
**(b)** 把 56.8% 与 τ 依赖这两笔"欠账"定量查清。
平面界面是本轮的关键工具：它不涉及曲率、不涉及 Laplace 拟合，却直接给出**该离散格式自己的共存态**，
从而把"数值 bug"与"格点 EOS 位移"分开。

| 参数 | 值 |
|---|---|
| 模型 / 伪势 | SCMP，D2Q9，ψ=1−e^(−ρ)，ρ0=1 |
| 耦合 / 松弛 | G_lib=+5.0（G_eff=−5.0），τ=1.0（τ 扫描腿：0.7/1.0/1.5） |
| 平面界面算例 | 256×8，液膜半宽 40，界面宽 w=4，周期，收敛判据 Δρ<2e−6/500 步（实测 20000–22000 步收敛） |
| 液滴算例 | R=16/20，L=4R（沿用首轮协议），采样至 dp 变化 <2e−5 |
| 长时程腿 | R=16, L=64，20000 步（首轮只到 4000） |
| 解析基准 | SC EOS 的 Maxwell 等面积构造：ρ_v=0.152895、ρ_l=1.928866、p_c=0.034214 |

## ② 怎么做的（方法 / 流程）

1. **V1 平面界面腿**（新探针）：三种力格式各跑一个平面液膜到收敛，测两侧体相平台密度与
   EOS 压力 p=ρc_s²+(G_eff c_s²/2)ψ²。平面界面在力学平衡下必须 **p_l=p_v**（Δp=σ/R，R→∞）。
   平台密度即该格式的共存态，与解析 Maxwell 共存对照。
2. **V2 液滴腿**（独立重跑首轮协议）：R=16/20 × 三种力格式，Δp 由内带（r≤0.5R_eq）/外带（r≥1.5R_eq）
   平均压力差给出，σ=Δp·R_eq。
3. **V3 τ 腿**（首轮"未做"）：R=20，τ∈{0.7,1.0,1.5}，其余同 V2。
4. **长时程腿**：R=16 velocity-shift 跑到 20000 步，检验首轮 4000 步停止点是否过早、
   以及远场蒸汽压是否仍在漂移。
5. **报告缺陷修复**：首轮 `make_report.py` 的逐半径残差列读错了键（`rows` 里没有
   `dev_pct_through_origin`，该量在 `per_radius` 里），发布表里印成 `+nan%`。
   修复为按 R_eq 从 `per_radius` 查表，并重生成 `REPORT.md`。

工具链：TensorLBM（torch，CPU）+ 独立 numpy 参考实现 `ref_sc.py`（首轮）+ matplotlib；
所有数字写入 `verify_r1/artifacts/verify_r1.json`、`long_run_check.json`，下文表格为程序化摘录。

| velocity_shift | 1.93152 | 0.15550 | 0.034550 | 0.034550 | **0.000%** | +0.14% | +1.70% | +0.98% |
| edm | 1.93152 | 0.15550 | 0.034550 | 0.034550 | **0.000%** | +0.14% | +1.70% | +0.98% |

三条：① 平面界面的力学平衡 p_l=p_v 在**所有**格式下精确成立（0.000%），
说明 EOS 压力公式对各格式都是自洽的机械压力，**Guo 路径不是"压力测量坏了"**；
② velocity-shift 与 edm 完全等价（首轮"τ=1 时二者代数等价"的说法成立）；
③ **Guo 格式的共存态整体位移**：ρ_v 低 22%、p_coex 低 14.6%（ρ_l 仅 −2.1%）。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **"1.07% 一致"是自指基准**。首轮拿 σ 与"库锁定值 0.0561"比，而该锁定值由同一模型、同一协议
   产生 ⇒ 这条比较只能证明**可复现性**，不能证明物理正确性。本单把判据换成两条真正独立的腿：
   平面共存密度 vs 解析 Maxwell（+0.14% / +1.70%）、Laplace 线性性。
2. **σ 的适用域极窄**：σ=0.0555 只对应 (τ=1.0, velocity-shift/EDM)。换 τ 到 1.5 → +83%，
   换 Guo → −38%，都远超 15% 标准。SC 伪势模型的共存曲线与界面张力**随力格式与 τ 位移**
   （首轮记为"事实"，本轮给出定量范围与机理：平面界面自洽证明是离散共存态位移，不是实现 bug）。
3. **我自己的一个假设被否证（honest-FAIL 记录）**：V2 发现外带蒸汽压比平面共存压高 1.83%，
   占 Δp 的 18.6%，我最初判为"初始条件过填蒸汽 → 协议对 σ 有 −18% 偏置"。
   长时程腿否证了它：该偏移在 16000 步内不衰减（不是未收敛），且**符号与量级符合 Kelvin 曲率效应**
   （估计 2σ/(R_eq ρ_l c_s²)≈1.1%，实测 1.83%）。因此用平面共存压当参考会**重复计入曲率**，
   σ=Δp·R 仍是正确估计量；首轮的 σ 未被推翻。
4. **spurious current 未消**：u_max≈0.139（与力格式无关，Guo 0.151），τ=1.5 时降到 0.119。
   它不影响 Δp（体相带平均），但任何依赖界面内速度的算例需注意。
5. **2D 圆柱**（Δp=σ/R），3D 球形（2σ/R）本轮未做。

## ⑥ 误差判定（逐项，显式回答 <3%）

| 量 | 基准 | 误差 | <3%? | <15%? |
|---|---|---|---|---|
| σ（τ=1，velocity-shift，R=16/20 均值 0.05554） | 首轮/库锁定 0.0561（同协议 → 仅可复现性） | −1.0% | ✓ | ✓ |
| σ（同上） | 首轮四半径标定 0.05550 | +0.07% | ✓ | ✓ |
| ρ_l 平面共存（velocity-shift） | 解析 Maxwell 1.928866 | +0.14% | ✓ | ✓ |
| ρ_v 平面共存（velocity-shift） | 解析 Maxwell 0.152895 | +1.70% | ✓ | ✓ |
| p_coex 平面共存（velocity-shift） | 解析 Maxwell 0.034214 | +0.98% | ✓ | ✓ |
| 平面力学平衡 (p_l−p_v)/p | 0 | 0.000% | ✓ | ✓ |
| ρ_v 平面共存（**Guo**） | 解析 Maxwell 0.152895 | **−21.94%** | ✗ | ✗ |
| σ（**τ=1.5**） | 库锁定 0.0561 | **+83.3%** | ✗ | ✗ |
| σ（**τ=0.7**） | 库锁定 0.0561 | **−33.3%** | ✗ | ✗ |

结论：**锚点的 <15%（并同时 <3%）主张在 (τ=1.0, velocity-shift/EDM) 上成立且可复现**；
Guo 力格式与 τ≠1 不在其适用域内，此前的报告未把这一点量化为数字，本轮补上。
σ 无第一性原理解析值（SC 伪势模型界面张力依赖离散化），故以 Maxwell 共存 + Laplace 线性性
+ 跨实现一致三条独立腿构成判据。

## ⑦ 复核结论（adversarial-review 交付）

- **复核对象身份**：`xval/XVAL-LBM-SHAN-CHEN-LAPLACE-PRESSURE-CALIBRATION`（m20921，merged PR #2416），
  产物 `artifacts/result.json`、`REPORT.md`；本轮产物 `verify_r1/`（commit 见 finish）。
- **独立性限制**：本轮复用首轮的 `TorchSolver` 包装与 `ref_sc` 参考实现（同仓、同作者谱系），
  独立之处在于**探针**（平面界面）、**基准**（Maxwell 解析）、**参数域**（τ 扫描、长时程）与执行者席位；
  未做与首轮完全无共享代码的第三方实现。
- **发现（按严重度）**：
  - **F1（中，已修）** 发布表逐半径残差列因取键错误印成 `+nan%`，使"逐点符合"不可核验。
    修复后真值为 −0.52% / −0.38% / +0.70% / +1.81%（过原点拟合残差）。
  - **F2（中，结论需重新表述）** "vs 锁定 0.0561 的 1.07%"是**自指基准**，不能作为精度证据；
    应以 Maxwell 共存（+0.14%/+1.70%）与 Laplace 线性性承担该主张。
  - **F3（中，新增事实）** σ 的适用域：(τ=1, velocity-shift/EDM) 之外误差 −38%~+83%，
    锁定值必须连同 (τ, 力格式) 一起引用，否则不可比。
  - **F4（低，非缺陷，机理已定）** 56.8% 力格式差异 = 离散共存态位移（Guo 的 ρ_v −22%、p_coex −14.6%），
    平面界面 p_l−p_v=0.000% 证明实现无误；首轮"σ 必须与力格式绑定"的判断成立。
  - **H2（假设被否证）** "外带蒸汽压偏高 ⇒ σ 有 −18% 协议偏置"不成立：长时程平稳 + Kelvin 效应。
- **未做的检查（unknown / not_run）**：3D 球形液滴；τ 细扫与分辨率（w、c_s 收敛性）联合扫描；
  与文献绝对 σ 值的对比（SC 伪势无闭式解，需第三方独立代码）；界面宽度对 σ 的敏感度。
- **处置（disposition）**：**approve with notes** —— 首轮数值结论可复现且物理自洽，
  但报告的精度主张需按 F2/F3 重新表述；F1 已在本轮修复并重生成 `REPORT.md`。
