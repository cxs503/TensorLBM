# REPORT V4 — α 族线性插值反弹的生产算符：壁面位置、残差分解与实体积格记账

锚点 `XVAL-LBM-LINEAR-INTERPOLATED-BB-ALPHA-SCHEME`（verifier 席，对抗性复核）。
本报告**不复述** REPORT/V2/V3 的结论，只做独立复算与反驳测试；所有数字由
`verify_v4.py` 与 `make_figures_v4.py` 从 `artifacts_v4/results_*.json` 程序化注入。

## 1 案例介绍（物理背景 / 几何 / 参数）

力驱动充分发展平面 Poiseuille 通道，D2Q9，x 周期、y 两直壁，壁面位于首末流体节点
外 δ 个格子（**亚格子壁距**）。通道物理宽度 `H = (N−1) + δ_b + δ_t`，解析解
`u(y) = g/(2ν)·y(H−y)`（White, *Viscous Fluid Flow* ch.3；Bouzidi-Firdaouss-Lallemand,
*Phys. Fluids* 13 (2001) 3452 §III.A 同款算例）。

| 量 | 值 |
|---|---|
| N（流体行数） | 8 |
| δ 扫描 | 0.10, 0.25, 0.50, 0.75, 0.90（覆盖 α 族两个分支） |
| ν（格子） | 0.1（τ=0.8） |
| g | `8ν·u_max/H²`，u_max=0.02（Ma=0.0346） |
| 载体 | BGK；TRT 两种魔法乘积 Λ⁺Λ⁻=δ²/2（`trtd2`）与 3/16（`trt16`） |
| 闭包 | `halfway`（半程反弹）、`bfl`（Bouzidi 2 点）、`cli`（中心线性插值，α̂=1） |
| 步数 / 精度 | 600 步，float64（残差在 500 步后已平稳：500/1500/3000 步同值到 3 位） |
| 边界算符 | **生产算符** `tensorlbm.boundary.interpolated_bounce_back_2d`（实体积格"写替换值"契约） |

## 2 怎么做的（方法 / 流程 / 三个待答问题）

前序包（REPORT_V3、`verify_v2.py`）留了三个未受检的环节，本单逐条做**反驳实验**：

* **Q1 容器/环绕伪影**：`verify_v3_moving_wall.py` 只用 2 行实体积格、y 向周期 stream 且
  实体积格从不碰撞；`verify_v2.py` 有防环绕保护，V3 没有。若残差依赖容器，就不能归给闭包。
  → 同一物理跑两种容器：`per`（V3 原样：周期 + 2 行）与 `iso`（吸收式实体：每步 stream 后
  销毁实体积格内种群）。
* **Q2 残差成分**：报告里的 `l2` 混合了两种完全不同的误差——**壁面位置**错（几何）与
  **幅度**错（速度整体缩放，等价于平均密度偏移）。用最小二乘抛物线
  `u(y)=A·y(H_eff−y)` 分离：`A=−a2`、`H_eff=y_high−y_low`、`w_bot=y_fluid[0]−y_low`、
  `A/A_ref` 对 `A_ref=g/(2ν)`。**shape-only l2** = 把基准按拟合幅度重整后的残差。
* **Q3 实体积格记账契约**：生产算符只把**反射量**写进实体积格，其余是"死存储"。V3 把实体
  填成静止平衡态 `W`；本单另设 `init="reflect"`（先用算符播一次反射槽）与 `init="zero"`。
  三者只在**第一步**注/抽一次质量，此后该质量差被压匀成**均匀密度偏移**并被永久冻结
  （x 周期通道无出流）。

工具链：`verify_v4.py`（torch float64，碰撞/流动/解析基准独立重写，边界只调生产算符）、
`make_figures_v4.py`（3 张图，全部 JSON 注入）、`tests/test_xval_lbb_wall_position_v4.py`
（4 项回归）。扫描经 `run_compute` 递交集群（cj2973，n330）。

BFL/δ=0.25：`init=rest`（V3 约定）给出 `A/A_ref`=1.00000、`ρ̄`=1.000005、
raw l2=0.0751 %；`init=zero` 给出 `A/A_ref`=1.04444、
`ρ̄`=0.957452、raw l2=4.5539 %，而两者的 **shape-only l2 相同到 4 位**。
机制：体力项 `3w_q c_qx g` 是**动量**源，与 ρ 无关 ⇒ 有效比力 `g/ρ̄`。ρ̄ 低 4.25 % ⇒
速度高 4.44 % ⇒ 以 `m/ρ` 报告的 u 整体放大。**结论：任何 α 族精度声明必须同时报 ρ̄ / 幅度**，
否则 0.07 % 与 6 % 的差别可能只是实体"死存储"初值不同。

## 5 注意点（坑 / 局限 / 适用范围）

* **记账陷阱（本次主要发现）**：实体积格是"死存储"，但其初值决定第一步注/抽质量，进而在
  x 周期通道里冻结成均匀 ρ̄ 偏移，最大造成 **6.8 % 的速度幅度误差**
  （δ=0.9/BFL，ρ̄=0.936）。这不是公式错误，而是**契约文档缺失**：算符只
  保证反射槽正确，用户必须监控 ρ̄。本单以 `test_solid_slot_initialization_is_documented` 钉住两侧。
* **抛物线拟合的适用边界**：N=8 且 δ→0.9 时，近壁节点落在插值分支切换附近，拟合被形状
  残差污染（halfway@δ=0.9 实测 −0.13 格，而半程反弹的几何偏差理论上应为 −0.4 格），
  因此 `w_bot` 只能作**上界**读，不能当作亚格子精度的直接判据。resolution study 未做（§6）。
* **只覆盖直壁、单分辨率、单 ν、Re_H<7、Ma<0.035**；斜壁/曲壁的阶梯偏差是另一问题（仓内已有
  honest FAIL `docs/STAIRCASE_WALL_OFFSET_20261111.md`）。
* **TRT 魔法乘积**：`trtd2`（Λ⁺Λ⁻=δ²/2）与 `trt16` 都未把 shape 残差压到 1e-3 以下
  （δ=0.25：7.0e-03 / 1.5e-02），
  即 **OSS 的"任意松弛率下解析精确"未在本实现上复现**——与 V3 §3.4 的质量泄漏结论一致方向，
  但本单测得泄漏仍为 O(1e-9)/步，不足以解释 1e-2 级残差，故 **V3 把 forced 臂残差归因于质量
  泄漏的结论证据不足**，本单予以纠正。

## 6 误差判定（逐项，显式回答是否 <3 %）

| 关键量 | 基准 | 实测 | <3 % ? |
|---|---|---|---|
| 壁面位置（BFL，δ=0.1–0.9） | `w_bot=δ` | 偏差 0.0016–0.0738 格 | δ≤0.5 **是**；δ=0.75/0.9 **否**（0.058/0.074 格） |
| raw l2（BFL，全部 δ） | 解析 Poiseuille | 4.55 %（δ=0.25）… 6.25 %（δ=0.1） | 仅 δ=0.25/0.9 **是**；其余 **否** |
| shape-only l2（BFL） | 同上（幅度重整） | 0.124 %（δ=0.25）… 4.63 %（δ=0.9） | δ=0.1/0.25/0.5 **是**；δ=0.75/0.9 **否** |
| owner 验收线（15 %，raw l2 全 21 臂） | 同上 | 最大 6.25 % | **是（全臂通过，余量 ≥2.4×）** |
| 容器无关性（Q1） | per vs iso | 差 <1e-6 相对 | **是** |
| 实体积格初始化无关性 | reflect vs zero | 幅度差 4.4 % | **否（honest FAIL，已定位为记账契约）** |
| OSS 严格精确性 l2<1e-10 | pylbm 声明 | 最好臂 7.5e-04 | **否（honest，仍未复现）** |

**判定**：本锚点的 owner 验收线（<15 %）在生产算符上**全部臂通过**；但"OSS 级精确性"
（<1e-10）仍未复现，且 raw l2 的 3–7 % 成分是密度记账而非闭包——这条归因是本单对前序包的
实质性纠正。未做：resolution study（N=16/32）、斜壁、动壁耦合。
