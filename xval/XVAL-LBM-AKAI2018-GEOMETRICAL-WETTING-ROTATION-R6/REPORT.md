# XVAL-LBM-AKAI2018-GEOMETRICAL-WETTING — Round 6: measurement gate and the rotational wetting path

**Anchor**: `XVAL-LBM-AKAI2018-GEOMETRICAL-WETTING`（lanl/MF-LBM 的 akai2018-geometrical-wetting 做法）
**Repo**: TensorLBM · **Round**: R6（承接 m17366 实现 / m17444 审计意见）
**Acceptance**: 端到端接触角误差 < 15%（owner 精度标准）；本次另报 < 3% 达成情况。

## ① 案例介绍

物理背景：二维坐滴（sessile drop）在平板上的静态接触角。几何：`ny × nx` 格点，
上下各一排 solid（底部壁面施加接触角 BC，顶部壁面保持中性 90°），x 方向周期。
求解器：`tensorlbm.color_gradient2d.color_gradient_two_tau_step`（Rothman–Keller /
Latva-Kokko–Rothman 色梯度模型，fp64，`tau_r = tau_b = 1.0`，`A = 0.04`，`beta = 0.7`），
半程反弹实现无滑移壁面。初值 = 满足规定角的 `tanh` 圆冠（`xi = 2`）。

| 参数 | 值 |
|---|---|
| 网格（标准臂） | 96 × 128，R = 18，xi = 2 |
| 网格（θ=30° 臂） | 128 × 192，R = 30（浅冠需要更大域） |
| 相密度 | rho_r = rho_b = 1（等密度） |
| 弛豫时间 | τ = 1.0（ν = 1/6） |
| 表面张力振幅 | A = 0.04 |
| 再着色系数 | β = 0.70 |
| 迭代上限 | 120 000 步，收敛判据见 ② |

两条润湿实现（本单的核心对照）：
* **ghost 值形式**（`cg_wetting2d.geometrical_wetting_ghost`，R4 用过）：
  `phi_solid = phi_fluid + cot(theta) |dphi/dt|`，把固体格子的相值改成与旋转后法向一致，
  相当于**额外注入**一个壁法向梯度；
* **梯度旋转形式**（`cg_wetting_geometric.rotate_wall_color_gradient`，= Akai et al.
  (PRE 98, 043302, 2018) 经 `lanl/MF-LBM` `Phase_gradient.F90:209-265` 继承的写法）：
  在壁面邻近流体点把色梯度**旋转**到规定角，**保持梯度模长不变**，不向密度场注入壁相。

## ② 怎么做的

1. **先做量测门（measurement gate），再做物理判定。** R4 的决策量是 Kasa 圆拟合
   （`wetting.metrics.contact_angle_circle_fit`），其唯一的"解析验证"是把解析 tanh 界面
   喂给润湿核、再用**同一构造的逆算子**把角读回来——这是代数恒等式，m17444 审计已判明
   它没有验证力。本单改为在**不含任何边界条件**的解析圆冠上验证**量测算子本身**：
   `benchmarks/xval_akai2018_wetting_rotation/estimator_validation.py`，
   9 个 θ × 3 个 R × 3 个 xi = **81 例**。
2. **新判定量**：`spherical_cap_inversion`（帽面积 + 接触宽度反演），并用
   `theta_vol`（**精确守恒液量** + 实测接触宽度）做独立交叉校核。
3. **卫星液滴检测**：对 `phi > 0` 掩膜做 4-邻接洪水填充，数液体团簇；R4 的
   "伪流把液帽推离圆帽"现象由此被显式检出，而不是被形状拟合悄悄吸收。
4. **收敛判据**：每 250 步采样，要求 `max|Δphi| < 1e-9`（连续 3 个窗口）**且**
   最近 4 个窗口的 `θ_cap` 极差 < 0.05°，且团簇数为 1；否则跑到 120 000 步上限并
   标记 `converged = false`。
5. **重测 R4 存档场**：`remeasure_round4.py` 用新判定量重测 R4 已存在的
   `_last_phi_<arm>.npy`（同一批文件，同一初值），把"实现的物理对不对"与
   "量测对不对"分开判。
6. 工具链：`torch` (CPU, fp64) + numpy + matplotlib；单元测试
   `tests/test_xval_akai2018_wetting_rotation.py`（9 passed）。

## ③ 计算结果

### 3.1 量测门：解析圆冠（无边界条件，81 例）

数据：`benchmarks/xval_akai2018_wetting_rotation/estimator_validation.json`（程序化写出，零手抄）。

| 估计量 | 中位绝对误差 | p95 | 最大 | 说明 |
|---|---|---|---|---|
| `theta_cap`（帽面积+宽度反演，**判定量**） | **0.45°** | 1.69° | 5.14°（θ=30°, R=12，最浅冠） | R ≥ 18 时最大 1.75° |
| `theta_vol`（精确液量+宽度） | 0.39° | 5.36° | 18.1°（θ=30°, R=12, xi=3） | 浅冠/厚界面时界面体积偏差放大，仅作交叉校核 |
| `theta_circle_sym`（圆拟合，R4 判定量） | **63.9°** | 127.4° | 131.3° | **结构性失效**，见下 |

逐角（`theta_cap` 均值）：30°→27.6°，45°→44.5°，60°→59.7°，75°→74.8°，90°→89.7°，
105°→104.2°，120°→119.1°，135°→134.7°，150°→150.0°。

**关键结论（负面结果，可复用）**：对完美解析圆冠，圆拟合在 θ = 30° 时给出 **141–146°**，
在 θ = 120° 时给出 **57.6° ≈ 180 − 120**。原因：θ < 90° 时 `phi = 0` 弧在竖直方向只跨
2–3 个格点，圆拟合病态；θ > 90° 时按列取最上交点取到的是弧的**上支**，得到的是补角。
**因此 R4 以圆拟合为决策量给出的 41%–108% 误差中，大部分是量测伪像，不是物理误差。**
（回归测试 `test_circle_fit_is_ill_conditioned_for_shallow_caps` 固定这一结论，
防止它被改回决策量。）

### 3.3 ghost 形式的失效机理（R4 存档场证据）

`gk60` 的最终相位场里有两个液体团簇：主帽贴底壁，**另一个 ~66 格的液滴贴在顶壁**
（`_last_phi_gk60.npy`，`phi` 行扫描：第 57–62 行有 5–15 个 `phi > 0` 格点）。
ghost 形式满足 `phi_solid = phi_f + cotθ|∂φ/∂t|`，壁法向导数被 **放大**
（θ≠90° 时 |∇φ| 被人为抬高），而表面张力扰动 ∝ `(A/2)|∇φ|(c_i·n)²`，
于是在壁面附近产生额外的法向体力 → 伪流（R4 记录 |u|max ≈ 5e-3…1.8e-2）→ 液滴被顶离、
分裂。旋转形式保持 |∇φ| 不变，正是不产生这一项的写法。

### 3.4 旋转形式的初步运行（**未收敛，仅 smoke**）

## ⑤ 注意点 / 局限

* **未完成的正面结论**：旋转润湿形式的**收敛**角度扫描已递交集群
  `cj4251`（8 shard：rot_30/60/90/120/150 + ghost_60 + neutral + rot_60_R12，
  每臂上限 120 000 步、收敛即停），递交后排队 > 26 min 仍在 queued，本单结束前未取得节点，
  **无可引用的收敛数据**。因此本单不宣称端到端 <15% 已达成。
* R4 存档场是 6000 步的未收敛场（`converged_dphi ≈ 2e-2`），3.2 节的 PASS/FAIL
  只用于验证"量测换对之后，中性壁与 90° 臂本来就基本正确"，不构成端到端验收。
* `theta_vol` 在浅冠（θ ≤ 30°、R = 12）会因界面体积偏差偏离最多 18°，本单只把它当交叉校核；
  判定量一律用 `theta_cap`，其误差上限（≤ 5.14°）已由 3.1 节显式量化。
* 60×64 这种小域中，θ=30° 的帽只有 ~3 格高——浅冠需要在保证体积的同时放大 R，
  这是 `rot_30` 用 128 × 192 / R=30 的原因，也意味着各个 θ 臂的分辨率不同，
  跨臂比较时须同时看 `theta_cap` 的估计器偏差（3.1 节按 (θ, R, xi) 给出）。
* 本单未触碰 `tensor_benchmark_cases` 登记（m17444 意见①）：属于平台侧动作，
  不在本仓白名单内。

## ⑥ 误差判定（显式回答"是否 < 3%"）

| 关键量 | 基准 | 实测 | 误差 | < 3%？ | < 15%？ |
|---|---|---|---|---|---|
| `theta_cap` 量测算子，解析圆冠 θ=60°, R≥18 | 解析 60° | 59.7–59.8° | < 0.5° (≈0.7%) | **是** | 是 |
| `theta_cap` 量测算子，解析圆冠 θ=30°, R=12（最坏） | 解析 30° | 24.9° | 5.14° (≈17%) | 否 | 否（最浅冠病态，已在选臂时规避） |

| ghost BC θ=90° 端到端，R4 场重测 | 90° | 86.48° | −3.9% | 否（临界） | **是** |
| ghost BC θ=30° 端到端，R4 场重测 | 30° | 35.10° | +17.0% | 否 | 否（且场未收敛） |
