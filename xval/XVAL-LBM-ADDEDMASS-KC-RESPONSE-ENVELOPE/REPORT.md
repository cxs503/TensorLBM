# XVAL-LBM-ADDEDMASS-KC-RESPONSE-ENVELOPE — 附加质量（质量类比量）测量臂的有效性包络

接棒 `XVAL-LBM-NO-MASS-ANALOGUE-IN-OSS-INVENTORY`（m18997，报告 17584）与其 board audit（m19108，报告 17643，裁定 L2）。审计遗留的唯一未结项是 LBM 实体臂的 honest-FAIL：`oscillatory_cylinder_inertia` 在 KC≈0.49/0.94 给出 C_I = 1.55 / 1.83（+55 % / +83 %）。本单回答：那个数是**物理**、**spin-up 欠账**，还是**估计器偏置**。

## ① 案例介绍

二维圆柱（题设外径 D 格）置于**双周期盒**中固定不动，流体受均匀简谐体积力 a(t)=a₀cos(ωt) 驱动（Guo 二阶源）。取 E1（Ladd 动量交换）与 E2（压力+粘性牵引）两个独立力估计器做一阶谐波分解：C_I 为与加速度同相项（附加质量），C_Q 为正交项（粘性）。两相似数 KC=U₀T/D、β=D²/(νT)。

本单确认性扫描的几何（**便宜点**）：D=8, box=L/D=4, u₀=0.02, Ma=0.0346；盒内固体分数 0.0508。
仓内出厂默认点（D=24, box=12, β=100）**按本单判据不可行**：需要 365 个周期 spin-up （≈328281 步/臂），而模块只丢弃 1.5 个周期——比值 121.6×。

## ② 怎么做的

- 直接调用仓内真实模块 `tensorlbm.oscillatory_cylinder_inertia.run_arm`（不改被测代码），只改 `ArmCase` 的 transient/measure/beta/kc/box/D。
- **判据先声明后跑**：`predeclared.json` 固定 H1–H4 与判决规则；4 个探索性探针（相位/β/窗口/自旋）先于声明执行，在 predeclared.json 中逐条列明。
- 参照系（`reference.py`，全部与被测模块无关）：
  - **R1** 无界圆柱势流 C_a = m_a/(ρπR²) = 1；
  - **R2** 同心圆形容器闭式 (R_o²+R²)/(R_o²−R²)（Lamb 1932 §71），并用**独立径向有限差分 + 能量积分**（不同公式路径）复核该闭式；正方形周期盒用内切圆 R_o=L/2 与等面积圆 R_o=L/√π 两个半径夹逼（夹逼不是定理，已在正文标明）；
  - **R3** 仓内同 mask 势流解 `fsi_added_mass.potential_added_mass`：**不作为真值**，只用来量它自身的离散偏置——它正是被审计指认为“自参考”的那个量。
- 判据量：每周期一阶谐波相位漂移（deg/period）、谐波拟合残差、逐窗口 C_I 散布、E1/E2 估计器散布、以及 ωL/c_s 与 δ/R 两个无量纲诊断。

## ⑤ 注意点

- **探针 A/B/C 的关键否定**：把相位错认成“非线性历史极限”会得出错误结论。β=50…1600 时 C_I/C_Q 几乎不变（探针 B），说明 90° 相位污染与粘性无关；逐周期相位每周期漂 +20°（探针 C）才是本质——周期解根本没到。
- **R3 有系统性离散偏置**：同 mask 势流解在小盒（box=4）只比 R1 高 ~0.5 %，在大盒（box=12）反而高 ~7 %，与“堵塞越大附加质量越大”的物理趋势相反（见 3.4），因此它不能当真值使用；本单只用它做“被消费的参考量本身有多准”的度量。
- **D=8 的便宜点**带来的阶梯几何误差不可忽略（δ/R 见 3.2），所以本单只主张**趋势与判据**，不主张 3 % 级精度；3 % 级需要在 D≥16 且自旋到位的点位重跑。
- **未做/无法判定**：粘性（Bessel / 振荡 Stokes）精确解未实现，故低 β 的 C_Q 只作“与 β 反向”的趋势记录，标 WITHHELD，不宣称验证。
- 计算纪律：集群作业 cj2600（16 核，`--all` 全臂）在报出时仍在跑（16 min+），本报告全部数字来自本地便宜点扫描 `runs/*.json`；cj2600 的用途是把 3.2/3.3 推到 D=12/16。
