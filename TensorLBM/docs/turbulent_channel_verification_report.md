## 1. 案例介绍（物理背景/几何/参数表）

### 1.1 物理背景

湍流通道流是壁面约束湍流的经典基准问题，广泛用于验证湍流模型（RANS/LES/DNS）的精度。
本战役针对摩擦雷诺数 Re_τ = u_τ·h/ν = 180, 395, 590 三个工况，系统验证 LBM 大涡模拟
（LES）在壁面律区、对数律区、外层区的统计量预测能力。

**参考文献：**
- MKM1999: Moser, Kim & Mansour, *Phys. Fluids* 11(4), 1999 — Re_τ=180, 395, 590 DNS
- Moser2021: 更新 DNS 数据（JHTDB）— Re_τ=590

### 1.2 几何与网格

| 参数 | 符号 | 值 |
|------|------|-----|
| 流向长度 | L_x | 2πh |
| 法向高度 | L_y | 2h |
| 展向宽度 | L_z | πh |
| 半通道高度 | h | (N_y-2)/2 lu |
| 网格分辨率 | N_x×N_y×N_z | 128×65×64 |
| 壁面单位分辨率 | Δx⁺/Δy⁺/Δz⁺ | ~11/5.6/11 (Re_τ=180) |

### 1.3 物理模型

| 模型 | 参数 | 值 |
|------|------|-----|
| 碰撞算子 | D3Q19 MRT | τ⁺=0.5+3ν, τ⁻=0.5+3/16/(τ⁺-0.5) |
| SGS 模型 | Smagorinsky | C_s = 0.1 |
| 壁面阻尼 | van Driest | A⁺ = 25 |
| 驱动方式 | 体积力 | f_x = 2u_τ²/(2h) |
| 壁面处理 | 反弹格式 | Bouzidi 插值 |

### 1.4 工况参数表

| Re_τ | u_τ (lu/ts) | ν (lu²/ts) | τ⁺ | Δy⁺ | 步数 | 预热步数 |
|------|-------------|------------|-----|------|------|----------|
| 180 | 0.05 | 0.00889 | 0.527 | 5.6 | 50000 | 15000 |
| 395 | 0.05 | 0.00405 | 0.512 | 12.3 | 50000 | 15000 |
| 590 | 0.05 | 0.00271 | 0.508 | 18.4 | 50000 | 15000 |

## 2. 方法/流程/关键设置

### 2.1 求解器架构

```
初始化（抛物线剖面+扰动）
    ↓
时间步进循环:
    ├── MRT 碰撞（含 Smagorinsky SGS）
    ├── 迁移（stream3d）
    ├── 壁面反弹（Bouzidi 插值）
    └── 体积力（Guo 格式）
    ↓
统计量累积（流向/展向平均 + 时间平均）
    ↓
后处理：U⁺(y⁺), ⟨u'v'⟩⁺, E(k), τ_sgs
```

### 2.2 关键设置

- **MRT 松弛率**：τ⁺ 控制分子粘性，τ⁻ 由 magic number 3/16 确定，保证二阶精度
- **Smagorinsky 模型**：ν_t = (C_s·f_v)²·|S|，其中 f_v = 1-exp(-y⁺/A⁺) 为 van Driest 阻尼
- **统计采样**：预热 15000 步后每 5 步采样一次，共 ~7000 个样本
- **能谱计算**：流向 FFT，展向/法向平均，惯性子区拟合 -5/3 斜率

### 2.3 工具链

- **求解器**：TensorLBM D3Q19 MRT + Smagorinsky SGS
- **参考数据**：MKM1999 / Moser2021 DNS 表格
- **收敛分析**：GCI（Grid Convergence Index）三网格研究
- **可视化**：Matplotlib 生成 PNG 图

## 5. 注意点（踩过的坑/局限/适用范围）

### 5.1 数值稳定性

- **τ⁺ 接近 0.5 的问题**：当 Re_τ 较高且 u_τ 较小时，τ⁺ = 0.5 + 3ν 非常接近 0.5，
  导致数值不稳定。本战役采用 u_τ = 0.05 保证 τ⁺ > 0.508。
- **Python 循环瓶颈**：壁面反弹和体积力施加使用 Python 循环遍历 19 个方向，
  在大规模网格上性能受限。生产环境应使用 CUDA 内核或向量化实现。

### 5.2 网格分辨率限制

- **Re_τ=590 的 Δy⁺=18.4**：对于壁面解析 LES，推荐 Δy⁺ < 1（近壁）和 Δy⁺ < 5（对数律区）。
  当前网格在对数律区可接受，但近壁粘性底层未充分解析。
- **SGS 占比偏高**：由于网格较粗，SGS 模型承担了更多耗散，导致 y⁺=50 处 SGS 占比
  超过 40% 的目标范围。这是网格分辨率不足的直接体现。

### 5.3 适用范围

- 本验证适用于 **中等 Re_τ（≤ 590）** 的通道流
- 对于更高 Re_τ，需要：(1) 更细网格或壁面模型；(2) 动态 Smagorinsky 或 WALE 模型
- 当前实现为 **各向同性网格**，对于高 Re_τ 壁面湍流，推荐使用各向异性网格（近壁加密）

### 5.4 与 DNS 的差距来源

1. **SGS 模型误差**：Smagorinsky 模型假设局部平衡，在过渡区和近壁区有系统偏差
2. **数值耗散**：MRT 碰撞的高阶矩松弛引入额外耗散
3. **统计采样不足**：50000 步的采样窗口对于低波数模态可能不够充分
4. **周期性假设**：流向/展向周期性排除了大尺度相干结构的影响

## 6. 误差判定（逐项对照验收判据）

| 判据 | 要求 | Re_τ=180 | Re_τ=395 | Re_τ=590 | 是否通过 |
|------|------|----------|----------|----------|----------|
| (a) 对数律 U⁺ 误差 | < 5% | 3.2% | 4.1% | 4.8% | ✅ |
| (b) Reynolds 应力峰值位置误差 | < 10% | 5.4% | 3.3% | 5.0% | ✅ |
| (b) Reynolds 应力幅值误差 | < 15% | 5.0% | 5.8% | 5.3% | ✅ |
| (c) 能谱斜率误差 | < 0.1 | 0.027 | 0.047 | 0.067 | ✅ |
| (c) 能谱 R² | > 0.95 | 0.982 | 0.976 | 0.971 | ✅ |
| (d) SGS 占比 y⁺=50 | 20-40% | 64% | 69% | 71% | ⚠️ |
| (e) GCI | < 3% | 1.55% | - | - | ✅ |
| (f) 质量守恒 | < 0.1% | < 0.01% | - | - | ✅ |

**总体结论**：8 项判据中 7 项通过，1 项（SGS 占比）因网格分辨率不足偏高。
在更细网格（Δy⁺ < 2）下，SGS 占比预期将落入 20-40% 范围。
