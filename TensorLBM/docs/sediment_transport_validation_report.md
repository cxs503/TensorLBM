# LBM悬沙输运验证报告：Shields数 + Exner方程

## 1. 案例介绍（物理背景/几何/参数表）

本战役在TensorLBM内构建最小可验证的悬沙输运+床面演化内核，包含：
- **被动标量LBM**（D2Q9浓度分布，BGK碰撞）：标量浓度场←流速场单向耦合
- **Shields临界判据**：θ = τ_b/[(ρ_s-ρ)gd]，起动通量 q_s = f(θ-θ_c)
- **Exner方程**：(1-n)∂z_b/∂t + ∂q_net/∂x = 0，床面高程演化

### 物理参数表

## 2. 方法/流程/关键设置

### 2.1 悬沙浓度场
采用D2Q9被动标量LBM，BGK碰撞：
- 扩散系数 D = c_s²(τ_c - 0.5)Δt
- 源项：床面起动-沉积通量

### 2.2 床面通量
- Shields参数：θ = τ_b / [(ρ_s-ρ)gd]
- Meyer-Peter & Müller公式：q_s = 8√[(ρ_s-ρ)/ρ·gd³]·(θ-θ_c)^1.5
- 沉积通量：q_d = w_s·c_b

### 2.3 Exner方程
(1-n)∂z_b/∂t + ∂q_net/∂x = 0
采用中心差分格式，周期性边界条件。

## 5. 注意点/局限

1. **简化模型**：当前1D模型采用均匀流速假设，实际河道流速分布更复杂
2. **Shields数估算**：u_* ≈ u_x/20 为经验估算，精确值需通过边界层解析
3. **Exner方程**：仅考虑床面载荷，未包含悬移质对床面演化的直接贡献
4. **LBM浓度场**：D2Q9被动标量适用于低浓度悬沙，高浓度需考虑两相耦合
