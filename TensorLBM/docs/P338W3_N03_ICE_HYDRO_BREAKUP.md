## ① 案例介绍

二维渠道 canonical 算例：水深 h = 30.0 m 的渠道顶盖为漂浮冰盖（厚度 h_i 取 5 档 [0.1, 0.25, 0.5, 1.0, 2.0] m），水流沿 x 方向均匀流入，冰盖在动水压力下弯曲、开裂。
物理参数：E = 5e+09 Pa，ν = 0.3，σ_f = 7e+05 Pa（冰弯曲强度），ρ_i = 917.0 kg/m³，ρ_w = 1025.0 kg/m³，g = 9.81 m/s²，渠道长 L = 200.0 m。

两条互相竞争的解析判据（本节点要求「互裁」）：

1. **任务书给定判据（k² 型）**：`D k^4 + ρ_w g = ρ_w U_cr² k^2`，等价于 `U_cr = (4 D g / ρ_w)^{1/4}`。该式在力学上正是**弹性地基梁受轴压屈曲**（Winkler 地基 + 轴向压力 N = ρ_w U²，N_cr = 2√(D ρ_w g)），即把流动动量通量当作膜压的工程模型。
2. **第一性原理判据（k 型）**：线性势流掠过微弯冰盖底面给出壁面压力扰动 `p̂ = ρ_w U² k coth(kh) ŵ`，与弯曲+浮力平衡得 `D k^4 + ρ_w g = ρ_w U² k coth(k h)`，即 `U_B(k) = c(k)`（挠曲重力波相速度），判据为 `U_cr = min_k c(k)`。两条推导在 `analytical.py` 中独立实现且恒等（有 pytest 守卫）。

## ② 怎么做的

* **LBM 流体**：`lbm_channel.py` 自研 D2Q9 BGK 求解器（numpy，可审计）：无滑移半程反弹（Poiseuille 验证）与自由滑移镜面反射（冰盖底面，外层无粘流区），体积力驱动 + 盖面波状形貌提供唯一形阻，稳态由 `u_history` 漂移量校核。
* **DEM 冰盖**：`bonded_cover.py` 键合颗粒（格点 DEM）冰盖：颗粒间转动弹簧 k_r = D/a （等价 Euler-Bernoulli 曲率关系，对简支梁解析挠度 5qL⁴/384D 做验证）、轴向弹簧传膜压、Winkler 浮力弹簧 ρ_w g、可断键（|M| > M_f = σ_f h_i²/6 即断，断后成铰并保留）。
* **耦合**：LBM→DEM 双向之一向（准静态）——LBM 实测盖面压力增益标定压力律，DEM 以谱算子 `p = gain·ρ_w U² L[w]`（每波数 k coth(kh)）受载；DEM 变形→LBM 几何在参数级闭合（同一波数）。
* **临界流速扫描**：DEM 刚度阵在 U 上单调，用特征值零点二分求 `U_cr`；再以 12 档 U/U_cr 做动力松弛断键扫描（记录开裂时刻/位置/序列）。

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

1. **判据归属**：k² 判据不是错，但它对应「动量通量当膜压」的载荷模型；均匀流掠冰盖的实际水力压力是 k¹·coth(kh) 型（势流推导 + LBM 实测一致）。两者相差 4.30 倍（h_i=1 m），混用会把临界流速高估约 4 倍。
2. **LBM 分辨率限制**：格点 Re_h = 20–305，粘性使盖面压力增益被低估约 2–4 倍（gain 0.24–0.51 而非 1）；因此 LBM 只能做**量级互裁**，不能作 5% 级定量验证。阶梯状壁面（specular 反射）的 O(dw/dx) 几何误差计入其中。
3. **DEM 断键处理**：断键用「曲率零释放（铰）」行替换，对称、可审计，但后裂结构偏刚；开裂时刻由动力松弛得到，受初始扰动幅值（5% M_f）与 t_end 限制——本算例的检出盲窗为 |U/U_cr−1| ≲ 1%（δ 增大时盲窗按 ln 关系收缩）。
4. **没做的部分（诚实申报）**：未实现真实 D3Q19 三维持久（2D canonical 案例不含 3D 信息，偏差已声明）；DEM 用格点梁-柱理想化而非球形颗粒接触模型（未算滚动/摩擦）；未做湍流/粗糙冰底（本判据属层流-势流稳定性范畴）。
5. **适用范围**：均匀流、薄冰盖（h_i ≪ λ_cr）、小挠度线性稳定性 + 脆性弯曲破坏；不适用于碎冰堆积、爬坡（ride-up）、以及 Froude 数接近 1 的浅水长波机制（kh ≪ 1 时 c(k) 判据退化为 Fr=1，可实现性另议）。
