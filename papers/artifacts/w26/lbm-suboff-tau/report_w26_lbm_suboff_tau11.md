# W26 · SUBOFF 裸艇摩擦阻力锚再核销 + 网格 GCI 重判（mission 17569）

## ① 案例介绍

**对象**：DARPA SUBOFF（DTRC Model 4740）裸艇体 AFF-1，艇长 L = 4.356 m，最大直径 D = 0.508 m，湿表面积 S = 5.998 m²（DTRC Table 1 逐字转录，grade PRIMARY_TABLE_SECOND_HAND）。

**外部定量锚**：DTRC 拖曳水池总阻力 R_T(V)，来源 Liu & Huang (1998) CRDKNSWC/HD-1298-11 Table 14 p.23（仓内二手逐字转录；原始报告（Groves, Huang & Chang 1989 DTRC/SHD-1298-01 与 CRDKNSWC/HD-1298-11）离线不可得，已在 `external_transcriptions.json › offline_disclosure` 声明）。

## ② 怎么做的

1. **锚登记（不跑算例）**：对仓内 5 个冻结转录源做 RFC-6901 指针定位 + 逐字段回读 + sha256 固定；34 条 verbatim quote 全部机器校验为归档文件的连续子串；17 行全精度锚行（17 行）逐行复算 ITTC-1957 C_F = 0.075/(log10 Re − 2)² 并记录残差；对『试验 C_F』做可用性判定。
2. **定 Re 三档网格阶梯**：固定 lattice Re = 1000，令 ν_lb = u_lb·N/Re ⇒ τ(N) = 0.5 + 3·u_lb·N/Re（N = 32/48/72 ⇒ τ = 0.5024/0.5036/0.5054）。三档各 8640 步（= 3.0/2.0/1.33 个对流时间 3N/u），力采样每 5 步，末窗 200 步均值 + 10 段块均值 + 末窗漂移一并记录。
3. **GCI（Celik et al. 2008 / ASME V&V20）**：R = (f₂−f₁)/(f₃−f₂)，p = |ln|R||/ln r（r = 1.5），Richardson 外推 f_ex，GCI_fine = 1.25·|(f₁−f₂)/f₁|/(r^p − 1)；对 C_T、C_F、C_P 各算一遍，并同时给出 p = 1、p = 2 的固定阶次对照值。
4. **负阻力边界扫描**：τ ∈ {0.5000, 0.5000, 0.5001, 0.5001, 0.5002, 0.5005, 0.5010, 0.5020, 0.5050, 0.5072} × N ∈ {32}，每格 1.5 个对流时间（90N 步），判据 = 末窗均值 C_T 的符号，并附末窗漂移；漂移超 2% 的格子标 *UNSTEADY*、场发散标 *DIVERGED*，不静默计入符号判定。
5. **工具链**：`run_case.py`（单算例，导入冻结驱动 `SuboffAppendageEngine`/`run_engine_routed`，不改冻结树）→ `run_batch.py`（有界并发批）→ `build_gci.py` → `build_artifact.py` → `make_figures.py` → `test_artifact.py`（pytest，从 npz 重算复核）。环境 python 3.11 / torch 2.7.1。

## ⑤ 注意点（踩坑与局限）

1. **锚里根本没有『试验 C_F』**：DTRC 表给的是 R_T 与 V；仓内所有 C_F 都是 ITTC-57 相关线值，而记录的 (1+k) 在数值上恒等于 C_T/CF_ITTC57（残差 1.50e-12），属定义式而非独立测量 ⇒ 只能用 C_T 作锚，C_F 试验值 WITHHELD。这就是前序 5 项 honest FAIL 的结构性根因。
2. **口径不可混用**：ITTC-57 在 Re = 1e3 处给出 C_F = 0.0750（湍流相关线，在 Re=100 处有极点），与案例层流参考 C_F 相差约 78.6%。拿它当 Re=1e3 LBM 案例的摩擦锚必然 FAIL——这不是实现问题。
3. **几何欠分辨**：R/L = 0.0583，N = 32/48/72 对应艇体半径只有 0.9–2.1 个格点，阶梯的『收敛阶』因此受阶梯式外形离散限制，不能当作光滑几何的渐近阶。
4. **稳态性门槛**：GCI 只在统计稳态上有意义；本单把每算例的末窗漂移一并入表，漂移超 2% 的格子不作为符号判定。稳态收敛仍是本案例最大的不确定源。
5. **算力边界**：集群队列本单开始时有 400+ 作业排队，实际算例在本机以有界线程预算（≤6 线程/算例、≤4 并发）完成，cell-update 总量与吞吐已入表 6， 因此没有做 N ≥ 96 或 Re ≥ 1e4 的档位。
6. **EVO-1 盲评期**：本单未读取任何 `evo1-*` 报告或工件。
