# p40w4_n04_nonnewtonian_rheology — non-Newtonian verification surface

Node `p40w4-n04-lbm-nonnewtonian` · module `src/tensorlbm/nonnewtonian_frontier/` ·
report `docs/P40W4_N04_NONNEWTONIAN_RHEOLOGY.md`.

What it verifies
----------------

| model | constitutive law | anchor |
|---|---|---|
| power law | `ν = K γ̇^(n−1)` | closed-form Ostwald–de Waele profile |
| Carreau–Yasuda | `ν = ν∞ + (ν0−ν∞)[1+(λγ̇)^a]^((n−1)/a)` | constitutive inversion + quadrature |
| Cross | `ν = ν∞ + (ν0−ν∞)/(1+(λγ̇)^m)` | same quadrature anchor |
| Herschel–Bulkley (ice slurry) | `ν = τ_y(1−e^{−mγ̇})/γ̇ + Kγ̇^(n−1)` | ideal plug half-width `τ_y/(ρa)` |

The lattice side is a D2Q9 variable-viscosity BGK channel with per-cell
relaxation time, Guo (2002) body forcing, pre-streaming half-way bounce-back
plates and a second-order shear-rate stencil.

Files
-----

* `run.py` — full study; writes `result.json`, `gates.json`, `RESULTS.md` and
