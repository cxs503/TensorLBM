# P46W3-N03 — 碎冰/冰晶悬浮液有效粘度闭合的 LBM 标定：预注册实验设计

> 本文件在**任何新算例开跑之前**写成（commit 时间早于 artifacts/raw_cases.json 的生成时间），
> 阈值与判定规则先于观测固定，避免"看着结果调阈值"。遵循 experimental-design 技能要求。

## 1. 决策（Decision）

D1：LBM 剪切元胞测得的相对粘度 η_r(φ)，其**稀薄极限斜率 [η]** 是否能在 5% 以内复现
Einstein 值 2.5？若不能，缺口是否由「φ 用格子掩膜体积定义」这一**体积口径**误差解释，
且改用同一离散球的**水动力体积**（Stokes 阻力反演半径 a_h）后能否通过？

## 2. 备择假设

- **H1（体积口径假设）**：掩膜体积高估颗粒水动力体积，故 dη_r/dφ_mask = [η]·(a_h/a_eff)³ < 2.5。
  改用 φ_h = φ_mask·(a_h/a_eff)³ 后斜率误差 ≤5%。
- **H0（非体积口径）**：斜率缺口与 a_h/a_eff 无关（分辨率阶梯不改进口径化后的斜率），
  则缺口来自测量链（壁面应力估计 / 颗粒运动学 / 统计量不足），如实记为 FAIL。

前置事实（前序战役 IN13-W4-N02 的 honest FAIL，本节点不再重复其已验证面）：
mask 口径斜率 [η]=1.9112（vs 2.5，偏 -23.6%）；intercept 1.0229；KD 单参数拟合 R²=0.722（φ≤0.166）；
单球阻力门 10.45% 误差。本节点新颖处 = 上述缺口能否由体积口径闭合，以及把 φ 覆盖推到 0.45。

## 3. 指标（Metrics，先定）

| 记号 | 定义 |
|---|---|
| η_r | (τ_susp/τ_pure)·(γ̇_pure/γ̇_susp)，壁面动量交换应力 + 实测剖面斜率，纯流体比值相消乘性偏置 |
| φ_mask | 离散掩膜节点数/盒节点数（含壁外固体排除） |
| a_eff | 掩膜体积等效半径 (3V/4π)^(1/3) |
| a_h | 同一离散球、同一格子、同一壁构型的 Stokes 阻力反演半径：a_h = F/(6πμU·K_HS) |
| φ_h | φ_mask·(a_h/a_eff)³ |
| [η] | η_r 对 φ 的加权线性回归（权重 1/SEM²，seed 聚合）斜率 |
| R² | 同一回归 / 全域 KD 拟合的判定系数 |
| R²_KD | ln η_r 对 ln(1-φ/φ_m) 单参数最小二乘（golden section 于 φ_m∈[0.50,0.80]）的 R² |

## 4. 基线 / 对照（Baseline & control）

- **解析基线**：Einstein η_r=1+2.5φ；Batchelor 1+2.5φ+6.2φ²；Krieger–Dougherty
  η_r=(1-φ/φ_m)^(-2.5φ_m)，φ_m 文献值 0.63（随机密堆单分散球 0.63~0.64）。
- **纯流体负控**：φ=0，要求 η_eff 回归输入 ν 且剖面 R²>0.999（测量链自检）。
- **φ→0 负控**：φ_mask≈0.002（单小颗粒）要求 η_r-1 与 2.5φ 同阶（±20% 内，统计窗口小）。

## 5. 预注册阈值（Predeclared thresholds，不改）

| 判据 | 阈值 | 来源 |
|---|---|---|
| (a) 稀薄斜率误差 \|slope/2.5-1\| | ≤ 5% | 战役表 metadata |
| (a') 线性回归截距 \|b-1\| | ≤ 0.01 | 前序战役口径（保持不变） |
| (b) KD 发散指数拟合值与理论 -[η]φ_m 的相对偏差 | ≤ 10% | 本节点预先设定 |
| (c) 全域 KD 拟合 R² | ≥ 0.95 | 战役表 metadata |
| (d) 负控①纯流体 φ=0：η_eff/ν−1 | ≤ 0.5% | 本节点预先设定 |
| (d) 负控②φ 最小点增量比 (η_r−1)/(2.5φ) 偏离 1 | ≤ 20% | 本节点预先设定（§4） |
| (测量门) 每个算例速度剖面 R² | > 0.99 | 前序战役口径 |

### 5b. 设计修订（AMENDMENT-1，2026-11-10 08:20，**任何算例产出之前**）

初版稀薄扫掠 φ∈{0.02,0.05} 的**弦斜率偏差**本身就有 O(φ) 曲率偏置：
KD(φ_m=0.63) 在 [0.02,0.05] 窗口的弦斜率 = (η_r(0.05)-η_r(0.02))/0.03 = 2.92，
即比 2.5 高 16.8% —— 即使 LBM 完美，判据 (a) 也会被"解析曲率"判死。
故在**看任何结果之前**修订扫掠表：稀薄 φ∈{0.005, 0.01, 0.02, 0.05}，
**主判据窗口 = φ≤0.01**（该窗口 KD 弦斜率 2.53，曲率偏置 1.2% < 5% 判据的 1/4），
φ≤0.05 的全稀薄窗口作为**次级**结果报告。判据阈值 (5%/0.01/10%/0.95) 一字未改。
修订理由属"分析口径"，非"看着结果调阈值"；两个窗口的数字都进报告。

## 6. 变量与混杂（Variables / confounders）

- **受控**：格子 (48×48×57)、ν=0.1、u_wall=0.02、步数 2600（warmup 1300）、采样间隔 25、
  颗粒形状（球）、壁带、格点离散（同一 sphere_mask）。
- **改变**：颗粒半径 r∈{3.5,5.0,6.5}（离散分辨率阶梯）、目标 φ（稀薄 {0.02,0.05}、
  稠密 {0.15,0.25,0.35,0.45}）、随机种子 seed∈{1,2}（微结构实现）。
- **混杂/风险**：①通道受限（β=a/R）会放大阻力 → 用 Haberman–Sayre 因子 K_HS 修正并同时报告未修正值；
  ②单颗粒/少颗粒微结构是**冻结**的，未做构型平均 → 用多 seed + SEM 量化，报告为局限；
  ③阶梯球曲率误差 → 用半径阶梯诊断其趋势（不自称网格收敛，GCI 只作诊断不作判据）；
  ④高 φ 放置受 wall_margin 限制，实际 φ_mask 与目标 φ 有差 → 一律用实测 φ_mask/φ_h。

## 7. 重复与统计（Repetition rationale）

每 φ 点 2 个独立微结构 seed（不同放置），报告均值±SEM；稀薄区 2 个 φ 层 × 3 个半径 = 6 组 →
回归 6 点（加权）。此规模由 2 个 seed 的组间散布预期（前序战役 SEM/η_r ≈ 1~3%）与
"要在 5% 内分辨斜率"所需标准误反推：斜率标准误 ≈ 2%·√(2/(Σφ²)) 量级，本设计 φ 跨 2.5 倍
（0.02→0.05），可支持 ~5% 的斜率分辨；不足处如实报告置信区间，不夸大。

## 8. 环境（Environment）

CPU 双节点 loong64 集群（run_cluster，`stage_dir`=本工作树），torch CPU、float32 元胞、
`OMP_WAIT_POLICY=PASSIVE`、每算例线程数=分配核数/jobs，版本：git 分支 `agent/m9151`。

## 9. 分析（Analysis，先定）

1. 每算例 η_r = (τ_susp/τ_pure)·(γ̇_pure/γ̇_susp)（τ 用 tau_corrected = 近壁行应力 − 颗粒体积力贡献）。
2. 稀薄区按 seed 聚合成 (φ, η_r±SEM)，加权最小二乘得 [η], 截距, R²。
3. 同一数据分别用 φ_mask 与 φ_h 回归 → 两次斜率对比即 H1 的直接检验量。
4. 全域（φ_h≤0.45）对 KD 单参数拟合 φ_m，报告 R²_KD、RMSE、max|Δ|。
5. 发散诊断：ln η_r vs ln(1-φ_h/φ_m) 斜率 vs -2.5φ_m。
6. 负控：φ=0 算例的 η_eff/ν；小 φ 算例的 η_r-1 vs 2.5φ_h。
7. 异常值处理：不剔除算例；仅报告 seed 间散布。缺失：失败算例编号列出（无则显式写 none）。

## 10. 安全与资源上限

总算例 24 个（3 drag + 21 shear），单算例 ≤ 30 min，总核时预算 ≤ 12 h；jobs=12，
超时 5400 s；失败重试 0 次（一次失败即记录）。

## 11. 解释限度（Interpretation limits）

- 结论只覆盖：单分散刚性球、冻结微结构、通道受限剪切、Re_p ≪ 1 的 Newton 载体。
- 真实碎冰/冰晶为多分散、非球形、有絮凝与屈服应力，粘性闭合只是其牛顿极限；不外推。
- 相关性≠因果：a_h 与掩膜体积同源于同一离散化，H1 被"支持"不等于"证明"其是唯一机制；
  H0 不能被完全排除，报告同时给出两条口径的数字。
### 5c. 实现口径澄清（AMENDMENT-2，2026-11-10 08:30，仍**在任何真实算例产出之前**）

判据 (d) 由两条机器检查组成（上表 d①/d②）：纯流体的 `η_eff/ν` 还原，以及**最小 φ 簇**的增量比
`(η_r-1)/([η]φ)→1`。不采用「\|η_r(φ_min)-1\|≤1%」这种写法——最小 φ 点上 η_r-1 本身就是 O(φ)
（φ=0.005 时预期 1.25%），用绝对值判据会把物理预测当成测量误差。此澄清只改**实现**，不改阈值精神；
`evaluate_acceptance()` 的输出同时带 diagnostics（纯流体偏差、最小 φ 簇的 φ/η_r/点数）供复核。

### 5d. 执行修订（AMENDMENT-3，2026-11-10 08:25，**仍无任何算例产出**）

**触发**：集群调度停摆——`run_cluster` 全队列 20+ 分钟无一作业进入 running（提交 cj186 为
1 核 `python -c` 亦排队 ≥15 min，队列里 07:29 提交的作业仍 queued，另有批量 killed），
控制面 load average 一度 >900（128 核）。重型算例无法上集群，只能在本地降规模执行。

**修订内容（只减规模，不改阈值/不改判据）**：
- 剪切元胞保持 **48×48×57**（预注册值，不降网格以免放大受限与离散误差）；
- 步数 2600 → **1400**（warmup 700、采样 25 → 28 个采样窗）；
- 半径阶梯 {3.5, 5.0, 6.5} → **{3.0, 4.0, 5.0}**（三档仍覆盖 1.67 倍分辨率跨度）；
- 稀薄扫掠 {0.005, 0.01, 0.02, 0.05} → **{0.005, 0.01}**（主判据窗口内两档，宽窗口结果作废并注明）；
- 稠密扫掠 {0.15, 0.25, 0.35, 0.45} → **{0.15, 0.25, 0.35}**（随机序贯放置在高 φ 会卡住，
  实际 φ 以实测为准；φ=0.45 在含壁边距的盒内已接近堆积极限，预期不可达）；
- 算例总数 36 → **22**（3 drag + 1 pure + 12 dilute + 6 dense）。

**代价（写进报告的局限）**：稀薄回归只有 2 个 φ 层（6 个聚合点）→ 斜率自由度小、
`R²` 对斜率几乎无信息；稠密区只到 φ≈0.3 → KD 的 `φ_m` 由外推主导、发散指数检验更弱。
因此本报告把 (a) 斜率、(b) 发散、(c) 全域 `R²` 三条判据的证据强度分别标注，
不因数据变少而放宽阈值。**判据阈值与判定规则一字未改。**

### 5e. 稀薄估计量修订（AMENDMENT-4，2026-11-10 09:12，第一位数据到达后、主数据集完成前）

**已有事实**：ABORTED-PILOT（08:36-08:39，同元胞同设置，φ∈{0.005,0.01}，22 个算例中先到的
8 个）显示单算例 `η_r` 的随机噪声约 **1~2%**，而 φ=0.005/0.01 处的物理增量只有
**1.25%/2.5%** —— 信噪比 <2，弦斜率估计在这一窗口不可用（实得点里出现 `η_r<1` 的非物理值）。
这是"测量噪声地板"事实，不是"结果方向"事实；据此修订**估计量与稀薄窗口**：

- 稀薄扫掠改为 φ ∈ **{0.02, 0.05, 0.10}** × 3 个半径 × **3 个种子**（27 算例），
  增量 5%~25%，信噪比 3~15；
- 判据 (a) 的估计量增设**曲率一致单参数估计** `fit_intrinsic_viscosity()`
  （`ln η_r = -[η]φ_m ln(1-φ/φ_m)` 对 `[η]` 线性 → 加权过原点回归，精确解+精确标准误），
  因为宽窗口上的**弦斜率本身有 +31% 曲率偏差**（[0.02,0.1] 窗口实测 3.28 vs 2.5）；
- 报告同时给出**弦斜率（原预注册估计量）**与**曲率一致估计量**两套判据结果，
  阈值（5%/0.01/10%/0.95）**一字未改**；两者结论不一致时以"哪一种估计量的偏差已被证明"为准并显式说明。

**理由分类**：这是"用无偏估计量测同一个量"，不是"看着结果放宽阈值"——两个数字都进报告，
且弦斜率的曲率偏差是可解析验证的（不依赖任何 LBM 结果）。

### 5f. 数据有效性与后验诊断（AMENDMENT-5，2026-11-10 09:20，主数据集已到齐）

1. **稠密区判为测量失效（不是物理结果）**：φ≳0.15 的算例出现**单个 seed 的 `η_r < 1`**
   （被动悬浮液不可能比载体更稀）以及**种子均值随 φ 非单调下降**。判定：近壁带应力估计在高 φ
   下失效（颗粒-壁相互作用 + 冻结微结构强涨落）。处理：**不删除数据**——全部测点照实列出；
   闭合的全域拟合按原样给出（因此 `φ_m` 撞到 0.80 上界、`R²` 为负，就是"数据不可用"的直接读数），
   另外给出**可信窗口 φ≤0.11** 的拟合与以文献 `φ_m`=0.63 的闭合检验，作为主证据。
2. **新增两个后验诊断（非预注册判据，只用于解释残差）**：
   - A 行分辨应力：`probe_core_stress.py` → 近壁带 vs 核心区；
   - B/C 时间收敛：`probe_time_convergence.py`（单点 4200 步）与 `raw_timeconverged.json`
     （r=4、φ∈{0.03,0.06,0.10}、4200 步；1400 步对照来自主数据集）。
   两者都只解释机制，**不用于把失败的判据改判为通过**。
3. **体积口径扩为三种**（mask / hydrodynamic-K_HS / core_fraction），全部列出；不挑选最有利者。
   其中 hydrodynamic 口径另给"未做壁面修正"的敏感性数字，因为阻力反演的壁模型在
   moving-belt 构型下不满足 Haberman-Sayre 的前提（壁随流体运动）。
