## 1. 连续问题与几何

Stokes（ν=1），2D 周期胞，体力 G·e_x（G=1）驱动，圆柱表面 u=0：

    -ν∇²u + ∇p = G·e_x ,  ∇·u = 0,  u|=0 (圆柱),  全方向周期。

输出唯一观测量 = 表观（superficial/Darcy）速度 U_s 与渗透率 K_s=ν·U_s/G。

几何（名义，与 W9-C prereg §1 名义定义一致）：
- **方阵**：胞 W×W，单圆柱居中，R = W·√(vf/π)。
- **六角**：三角格点，近邻距 W；名义 R = √(vf·W·(√3·W)/(2π))，即理想
  面积 W²√3 下 2 支圆柱/胞。W9-C LBM 档案用 H=round(√3·W) 的名义 R
  （含取整），与理想值的差 ≤0.13%（W=100 档），在再判定时按其 JSON 存储
  口径逐档镜像（见 §8）。

**有限 N 六角纵横比设计（本轨关键决策）**：周期胞必须整数网格
（N_x×N_y），N_y/N_x≠√3 的格点形变以 O(1/N) 量级把 ~0.1-0.4% 的"案例
漂移"注入阶梯、破坏 Richardson 的误差平滑性。处置：
1. 全阶梯锁定有理纵横比 **A = N_y/N_x = 97/56**（|A−√3| = 9.205e-5），
   N_x=56m、N_y=97m —— 所有 rung 解**同一个**连续问题（近三角格点、
   vf 名义、R=√(vf·A/(2π))·W），Richardson 干净。
2. 终端纵横比较正：再解 **A' = 26/15**（|A'−√3| = 1.282e-3）短阶梯
   （2-3 rung，中等 N），由 K(A) 与 K(A') 外推实测斜率 dlnK/dA，把
   97/56 外推值校正到理想 √3。解析预算校正量 ≈ −0.03%（vf 0.70）/−0.06%
   （vf 0.75）；实测斜率的不确定度进误差带。输出一律用理想 r_ideal²=
   vf·√3/(2π)·W² 归一。

## 2. 口径锁定（与 W9-C §2/§3 锁定逐字一致）

- Sangani–Acrivos 1982 精确 f 表（W4-A 双转录锁定，9 点）：
  {0.05:15.56, 0.10:24.83, 0.20:51.53, 0.30:102.90, 0.40:217.89,
  0.50:532.55, 0.60:1.763e3, 0.70:1.352e4, 0.75:1.263e5}。
- f 为**压力形阻力、表观速度口径**：f = G·L²/(μ·U_s)，U_s=全胞平均 ux
  （流体区平均×流体分数）。依据：(a) W4-A ctrl 实现以 f_press=1/U_s 直
  接对表收敛；(b) W9-C §2 换算 K/R²=π/(vf·f) 复核锁定表（0.30→
  1.017676e-1 ✓）；(c) W9-C §3 K_sim=(1−vf_actual)·ν·⟨u⟩_fluid/a_body
  = 表观形。任务指令括注"U_D=流体域平均"与此锁定不符，**以 W9-C 锁定
  为准**（被替换门控的同一口径）。
- K_s/R² = π/(vf·f)。本轨输出 hex：K_s/r_ideal²（表观形）；interstitial
  形 K_i/r²=K_s/((1−vf)·r²) 仅并列披露。
- Gebart 对照（锁定，W9-C §1）：K=C1·R²·(√(vf_max/vf)−1)^{5/2}，hex
  C1=16/(9π√6)=0.2310212744，vf_max=π/(2√3)；K/r²@0.70=1.641231e-3、
  @0.75=7.239255e-4（本轨独立复算式吻合，锁进 compare 环节）。

## 3. 方法

**M0（主变体）**：MAC staggered 有限差分（W4-A ctrl 血统离散结构、独立
重写+向量化）：u 胞面 (i·h,(j+½)h)、v 胞面 ((i+½)h,j·h)、p 胞心；5 点
Laplacian；圆内面速度=Dirichlet 行消元；全固面包围胞 p 钉 0；一个保证
流体胞的连续性行替换为 p 规范钉（周期 div 行总和恒为 0，替换保非奇异）；
solid-center 但非全固面的胞保留连续性行（ctrl 同构）；spsolve/splu
（MMD_AT_PLUS_A）稀疏直解。U_s = 全胞 (u_R+u_L)/2 平均（固面贡献 0，
楼梯自洽表观形）。离散结构与 ctrl 在方阵小 N 逐位交叉验证（本地，达
机器精度才算装配正确）。

**M1（预登记备变体，同 FD/MAC 族）**：面开度（open-fraction）cut-cell
MAC，α_face=解析圆-面相交开度，动量/连续按 FV 部分面权重。**触发条款**：
M0 在任一门控 vf（0.30–0.70）外推后 >0.5% 且定源性态可归因于楼梯几何时
自动启用，并**重跑全部方阵档**（非只补失败档）；hex 用通过门的变体出值。
两变体都失败 → 如实报败，不出 hex 值。变体切换记 NOTES.md（属 FD/MAC 族
内的边界处理升级，非换法；若控制器认定属换法，以控制器裁为准，hex 冻结
点相应后移）。

**解算器实现纪律**：装配全向量化（kron/切片，无 Python 逐点循环）；每档
记录 nnz、内存峰值、耗时、‖div u‖∞/h、楼梯 vf_actual。

## 6. 外推与误差带

- 模型：q_N = q_∞ + C·N^{−α}（+ 次阶 D·N^{−β} 备用）。α 由盲拟合（§4）。
- 误差带 = 以下各分量最大值：(i) 拟合窗口选择离散（最细 4/5/6 rung 三窗
  的 q_∞ 极差）；(ii) α 不确定度（拟合残差传播）；(iii)（hex）纵横比较
  正的不确定度（斜率实测拟合残差）；(iv) 保留次阶项的量级估计（首阶差
  的 10-30% 敏感带）。所有分量进 JSON。
- 方阵上同一机器的"带"必须覆盖真实误差（外推值−表值），否则说明带校准
  失败 → 如实披露（hex 带可信度随之下调）。
