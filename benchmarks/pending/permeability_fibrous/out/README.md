## Setup

- D2Q9 BGK, tau = 1 (nu = 1/6), fully periodic unit cell.
- sq: W x W, one centred cylinder (W4-A inheritance). hex: W x H supercell,
  H = round(sqrt(3) W), cylinders at folded corners + centre (triangular
  lattice, nn distance W).
- Body force on fluid nodes only, force scale 10; step order collide ->
  stream -> masked force -> bounce-back; kernels all from tensorlbm.
- Darcy convention: K_sim = (1-vf_actual)*nu*<u_x>_fluid/a_body.
- PRIMARY reference per tier: square -> Sangani-Acrivos 1982 exact
  f-table (k_ref = pi/(vf*f)*R^2; W4-A double transcription);
  hex -> Gebart closed form (exact hex table unobtainable, 8-channel
  hunt in prereg). Gebart is additionally reported for EVERY tier
  as a consistency channel; diagnostic channel B re-references to
  vf_actual (disclosed only).
- Locked Gebart constants: sq C1=16/(9 pi sqrt2), hex 16/(9 pi sqrt6);
  vf_max = pi/4 / pi/(2 sqrt3). Lock channels in result.json.
