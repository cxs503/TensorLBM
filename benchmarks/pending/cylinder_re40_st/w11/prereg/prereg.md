## 1. 物理问题

2D 圆柱定常绕流（亚脱落区）：Re 阶梯 {20, 40}（名义 Re，见 §4 R_eff 重锁）。
原 Re=30 档因无 OA 一手参考（Fornberg Re=30 仅在图 22；Sen/Rajani/D&C/Coutanceau 全部付费墙/机器人墙，
抓取尝试与证据见 ref/ref_lock.json blocked_sources）→ 以 {20, 40} 双锁档替代，Re=30 弃档（控制器决定项）。
判据物理量: 定常阻力系数 Cd = F_x/(0.5·rho·U^2·D_eff)。
附带诊断量（不入门）: 分离角 theta_s、尾涡长 Lw/D。

## 2. 求解器与步进（复用 verified/cylinder 家族，零新发明）

- D2Q9 + collide_mrt(tau, tau_field) + stream（src/tensorlbm/solver.py）
- 边界: boundaries.far_field_bc_2d —— 入口/两侧自由流 Dirichlet(feq)、出口零梯度、障碍 bounce-back（一次调用）
- 力: boundaries.compute_obstacle_forces —— Ladd 动量交换, post-stream pre-bounce-back（与 re100/re200/SUBOFF 同相位）
- tau = 0.5 + 3·nu_lb（MRT 家族口径, re100 同式）
- sponge: make_sponge_strength, 下游 W_sp=10D, power 2, tau_eff = tau·(1+10·sigma)（re100 口径）
- 初值: 全场自由流平衡态; 无播种（定常问题）

## 3. 域（家族口径 + Phase 0 CPU 诊断定标）

- LX = 40D（流向), UP = 10D（圆柱心距入口), H = 20D（半侧距, 域 40D×40D)
- 依据（机器档 pilot/*.json + diag 对照）:
  紧凑域 20D×16D@D20: Cd 1.7452 → 家族域 40D×40D@D20: Cd 1.6031（域 −8.2%）
  侧距扫描（紧凑域固定 D20): h5 1.8179 / h8 1.7452 / h12 1.7366 → h≥8D 后侧距贡献 ~0.5%
  紧凑域去 sponge 对照: 1.7418 vs 1.7452 → sponge 贡献 +0.34%
  → 域残差以"上游 5D→10D + 下游尾流空间"为主导，家族域为冻结选择（与 re100 完全一致）。

## 4. R_eff 口径（单一冻结定义）+ 逐档 Re 重锁

- 冻结口径: area-equivalent。mask 半径 r_mask 由二分搜索选到 R_area = sqrt(N_solid/pi) 最接近 D/2;
  R_eff := R_area（实测), D_eff := 2·R_area（实测)。
- 逐档重锁: nu_lb = u_lb·D_eff/Re（Re 恒为名义 {20,40}), Cd 分母 0.5·u_lb²·D_eff。
- 依据 diag/geom.json: area 口径几何残差 D40 +0.0144% / D80 −0.0154% / D160 −0.0627%（非单调、O(量化)）
  vs row 口径 +2.5%/+1.25%/+0.625%（系统性单调漂移）——CPU 试点三口径 Cd 差 <1.7%（D40),
  几何残差决定: area 冻结。
- 否决项: nominal 口径（用格数 D 而非实测几何) 保留为对照列不进门。

## 5. 网格与参数阶梯

- D ∈ {40, 80, 160}（三档，两档门 + 单调门用全部三档)
- u_lb = 0.05 全阶梯固定（Ma = 0.0866; Ma 敏感性 0.03→0.07 已测 −0.013/0.01 Ma⁻¹·D20, 外推 <1%）
- tau 阶梯随之: Re=40: {0.650, 0.800, 1.100}; Re=20: {0.575, 0.650, 0.800}

## 6. 定常判据 + Cd 估计器（冻结协议）

- t_c := D_eff/u_lb（对流时间, 格步数取整)
- 平台检测: 每 10 t_c 检查相邻两窗（各 10 t_c) 均值漂移 |Δm|/m < 0.15%
- 最小运行 60 t_c，检查从 60 t_c 起；上限 150 t_c（Phase 0 实测: 全部 CPU 档在 50 t_c 内已平到 0.01%,
  60 t_c 下限覆盖; W7-B 教训: 窗口协议显式化)
- Cd := 末 20 t_c 均值; 全迹线存档（npz) 备查
- 扰动检查: 无（低于 Re_c≈47）

## 7. 判据门（冻结）

- G1 直接观测量: |Cd(D) − Cd_ref|/Cd_ref ≤ 3% @ D∈{40,80,160} 全档（D160 为硬档)
- G2 单调收敛: Cd(D) 随 D 严格单调趋近 Cd_ref（|err| 逐档不增）
- G3 逐档 Re 重锁核验: 每档实测 R_area 记入 result.json, nu 由 D_eff 反算（机器链)
- 修正/还原变换: 一律不算直接模拟（owner 裁定)——本设计无任何修正项
- 参考锁: ref/ref_lock.json（Fornberg1980 主锁 + Gautier2013/Dennis 交叉）
  - Re=40: 1.4980±0.0005（Fornberg) 交叉 1.4931(Gautier 谱)/1.494(Dennis-in-Fornberg) 合差 <0.54%
  - Re=20: 2.0001±0.0002 交叉 1.998 合差 0.10%
  - 簇展宽披露: 17 行簇 9.15%（Calhoun 1.62 为离群高端) → 单一主锁条款（高精度数值簇 1.49-1.54 内一致性 <3%)
- 停损线: D160 任一 Re 档 GPU 时 > 6 h 或 NaN/发散 → 停, 报告, 不改门
