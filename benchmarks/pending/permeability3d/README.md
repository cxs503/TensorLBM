## 测量映射

单位胞 L=N（格点），体力加速度 a_body 仅注于流体节点（等效压梯度 G=ρ·a_body，
固内力惰性——与 2D 先例同一投影面积簿记；Basilisk spheres.c 的
`K = dp·L²/(6πμa·V·(1−Φ))`（V=间隙平均速度）与此恒等）。直接观测量为间隙
平均速度 ⟨u_x⟩_fluid；表观速度 U=(1−φ)·⟨u_x⟩_fluid：

    k_sim = ν·(1−φ)·⟨u_x⟩_fluid / a_body        （主通道用名义几何 φ、a_nom）
    k_ref = N³ / (6π·a_nom·K_table)
    signed err = k_sim/k_ref − 1（正 = 渗透率偏高 = 曳力偏低）

主通道名义几何（楼梯有效半径 O(1/R) 偏差属真实离散误差，实测 φ 逐档披露，
重标定通道不作判据）。

## 协议

- D3Q19 BGK，τ=1.0（ν=1/6 精确），fp32，全周期单胞；步序 collide_bgk3d →
  stream3d →（流体掩码）体力 → bounce_back_cells_3d。3D 单相体力库内无助手，
  driver 层 `_apply_body_force_2d` 的 D3Q19 逐字转写（一阶 Guo/Luo 形，
  每步恰注 ρ·a；与 2D 先例同款披露）。
- Re_p = U·2a/ν 目标 0.05；Ma=√3·max|u| ≤ 0.05 逐案核。阶梯 N=64/96/128/160。
- 稳态：drift<1e-5/2000 步 ×3 连过 + 8000 步，测量窗末 20 样本（4000 步）。
- fp32 注入地板预检（正式跑前）：φ=0.343/N=128 处 force_scale∈{1,10,100}
  K_sim 散布 6.65% > 0.5% → **地板激活，正式协议 fs=10**（2D 战役同款判据；
  fs=100 地板净但 Re_p≈5 带惯性 +2.6%，fs=10 为注册折中，Re_p≈0.5）。

## 数值注记

1. **稀释档失败的定量解剖**（披露，非判据）：(a) fp32 注入地板在细 N 稀释档
   侵入 fs=10 通道（a_body ~5e-7→1.3e-7 随 N⁻³fs⁻¹ 缩；地板映射
   (φ=0.125,N=128)：K(fs=1/3/10) = 4.310/3.804/4.230，注入量化在 a_body≲4e-8
   时扰乱通道——2D 战役同机制在 N 轴上晚一个十年）；(b) 正式 Re_p≈0.5 的负
   O(Re) 惯性修正偏稀释侧（fs1−fs10 偏移（K 形）@N64 无地板档：+4.35%(0.125)/
   +2.49%(0.216)/−1.13%(0.343)，方向与排序符合方阵惯性修正已知行为）。
   两者皆非 solver 共性路径缺陷。
2. fs=1 诊断链（Re_p=0.05 真斯托克斯，k-form 同号约定）：φ=0.125
   +7.40/+7.56/−0.41%、φ=0.216 +5.93/+4.84/−0.25%、φ=0.343
   +3.50/+1.15/−4.30%（N≥96 稀释档在地板扰乱域内，仅作地板披露）。
3. τ 探针（φ=0.216/N96 固定 Re_p=0.5）：K(τ=0.75/1.0/1.25) = 7.526/7.312/7.217
   → BB τ 耦合 ≈±1.6%/0.25τ（文献标准 ~2.5% 量级，τ=1 处小）。
4. 质量：全案 mass drift ≤2.5e-3 相对；φ_actual（N_solid/N³）逐档入 result.json
   （如 0.343@N128 = 0.343002，体积无偏掩码）。
5. 判据恒等式：k_sim/k_ref ≡ K_table/K_sim（互逆），err 取 |k_sim/k_ref −1|。
