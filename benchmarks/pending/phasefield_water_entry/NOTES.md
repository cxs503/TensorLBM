### 读法

1. **g = 1e-4 / 1e-3 时静水压梯度在 2% 内**（−1.021 / −1.016）；**g = 1e-5 时退化到 −1.22（22%）**，并且随时间继续恶化。→ 入水算例的格子重力不能取得太小（prereg §2.2 的 Fr–g_lat 耦合）。
2. **界面单向爬升 + φ 积分单向增长，符号一致、近似线性**（g=1e-4 时 ~2.5e-4/1e3 步）⇒ 是**系统性相质量源**，不是噪声。位置：墙—相场通量（bounce-back 作用在 g 上，壁面化学势梯度非零）。
3. **密度比 100 与 816 的探针结果逐位接近**（界面 0.606 vs 0.607、dp/dy −1.0213 vs −1.0213）⇒ 密度比本身不是当前误差主因，问题在壁面/界面厚度，不在对比度。
4. **对 benchmark 的直接后果**：S0 的 3 个门里，dp/dy 在 g=1e-4 恰好 PASS（2.1%），而"φ 漂移 ≤1e-4/1e3 步"与"界面漂移 ≤0.5 格/1e4 步"**FAIL**（实测 2.5e-4 与 1.0 格）。见 prereg §3 与阻塞项 B2。
5. **外推（量级）**：若跑 3e4 步（S3 的 1.4e4 步量级），φ 增长约 +0.8%，界面漂升约 3 格 —— 对"液面高度/湿宽"类观测量是一阶误差，**必须先修或改观测定义**。

### 读法

2. **伪流被接触线放大约 3.6–3.8 倍**（无体基线 2.79e-4 同日同参数）。这个量级**低于** S1 的 2e-3 门，但已接近 1e-3，说明**接触线是伪流主源**，S2 的 `max|u|/V ≤ 3`（V = 0.05 ⇒ 1.5e-1）仍有充足余量。

## B1 — CAC 运动固体 + 动量交换力（代码在，S2 端到端**仍 BLOCKED**）

新增 `src/tensorlbm/cac_moving_body.py`；`cac_lbm.py` 的 `step()` 拆成
`refresh_solid_ghosts / collide / stream / apply_boundaries`，并新增
`set_wall_mask()`、`refresh_solid_ghosts(mask)`。拆分后 `tests/test_cac_smoke.py`
仍是 10 passed（逐位兼容）。

本轮在自查中找出并修掉 **4 个真 bug**（每个都有复现，不是风格问题）：

1. **流体侧半步 bounce 会吃掉相质量。** 第一版在流体节点上做半步反弹，
   固体节点的 ghost 从不刷新，每一步都丢掉"流进固体"的那份分布：
   `(6,20,20)` 水箱里 4×4 柱状体、φ≡1、100 步后 Σφ 从 2400 掉到 656（−73%）。
   改为与 `bounce_back_cells_3d` 相同的**全步（solid-node）交换**后，
   `test_static_body_conserves_phase_mass` 120 步相对漂移 < 1e-6。
2. **壁面速度项加到了所有固体节点。** 内部节点每步净加 2wρ(c·u)/cs²，
   没有流体带走 → 体内自泵：ζ=8°、V=0.05 时第 26 步 NaN。
   现在只加在"上游邻居是流体"的**边界链**上（`surface = body & links_from(fluid)`）。
3. **`refresh_solid_ghosts()` 每步用静止态覆盖body ghost，`fill_new_solid()`
   又把刚变固体的节点重置为静止平衡态。** 两者都在接触线上注入质量/动量。
   现在 ghost 策略只作用于**静态壁**，新固体节点不再重置（全步交换自己会保留内容）。
4. **相场必须跟着壁面速度走。** `move_phase_field=False`（原默认）时
   ζ=8°、V=0.01 的入水在 250–300 步内 NaN；打开后 600 步稳定、φ∈[0,1.005]。
   默认已改为 `True`。

另外确认了两个**读数**层面的事实：

* `momentum_exchange_delta()`（用一步内固体节点分布的动量差）在 u_w = 0 时与
  Ladd 求和一致，但**u_w ≠ 0 时会把每个表面单元的两侧都算进去**，力随体积而非
  面积增长（600 步时读到 F = 59.5，Wagner 只预测 ~0.45）。因此力的读数回到
  `momentum_exchange()` + 平衡态扣除。delta 版本只保留给单元测试核对。
* 力的**量纲**在格子里是 ρ_l·(dx/dt)²；二维楔形的 Ladd 和在 4 层周期 z 上求和，
  必须除以 `nz` 才是"单位展长"。`run_s2_wedge.py` 已按 `nz` 归一。

## B2 — 墙/相场质量源归因（`probe/p1_mass_source.py`，10 臂）

基线：`(8,96,8)` 水箱、W = 4、ν = 0.1、g = 1e-4、界面 y₀ = 48、6000 步。

| 臂 | 改动 | Δφ/φ (6000 步) | 每 1k 步 | 界面位移 |
|---|---|---|---|---|
| A | 基线（六面壁，g=1e-4，freeze） | +1.524e-3 | 2.54e-4 | +0.606 格 |
| B | 同上但 **g = 0** | +1.919e-3 | 3.20e-4 | +0.815 格 |
| C | 侧壁关掉（x,y 周期，仅 z 壁） | +6.482e-4 | 1.08e-4 | **+0.040 格** |
| D | 水箱高度 ×2（8×192×8） | **+1.78e-6** | 2.97e-7 | −0.414 格 |
| E | 界面下移到 y₀=32 | +3.043e-3 | 5.07e-4 | +0.884 格 |
| F | 界面宽度 W = 6 | +2.132e-3 | 3.55e-4 | +1.070 格 |
| G | A + **Neumann ghost（`wall_phi_policy="neumann"`）** | +2.026e-2 | 3.38e-3 | +0.959 格 |
| H | B + Neumann ghost | +2.493e-2 | 4.15e-3 | +1.198 格 |

长跑（24000 步）用来区分"瞬态重分布"还是"稳态通量"：

| 臂 | 总 Δφ/φ | 最后 1k 步速率 | 前后半速率比 |
|---|---|---|---|
| `I_long_freeze`（A 跑 24000 步） | +3.742e-3 | 1.56e-4 | **1.87×**（在衰减） |
| `J_long_double_height`（D 跑 24000 步） | +1.038e-3 | 4.33e-5 | 1.50×（在衰减） |

结论（可直接写进报告）：

1. **重力不是驱动源。** 把 g 关掉，漂移反而**变大** 1.26×（B/A），界面爬得更多。
2. **侧壁是界面爬升的主因，但不是 φ 增长的主因。** 关掉 x、y 壁后界面位移从
   +0.606 掉到 +0.040 格（15×），但 φ 仍以 1.08e-4/1k 增长。
3. **φ 增长是"饱和型"的，不是稳态壁面通量。** 水箱加高一倍，漂移小
   856×（1.524e-3 → 1.78e-6，壁面积不变）；24000 步长跑的速率还在线性衰减
   （前半/后半 = 1.87）。→ 它是**扩散界面在被壁面夹住时的重分布**，量级 ∝ 1/H。
4. **Neumann ghost 策略（G/H）不是解**：它让漂移**变差 13×**（2.54e-4 → 3.38e-3/1k）。
   该策略已保留为可选项，但默认仍为 `freeze`，并在 `cac_lbm` docstring 里写明原因。
5. 因此 **B2 仍开**：S0 的 φ 门（≤1e-4/1k 步）在标准几何下没有一臂通过；
   最好的臂（D/J，加倍高度）到 2.97e-7/1k，说明这个门只能靠**足够高的水箱**
   或"从守恒量里扣掉界面重分布项"来满足，而不是靠换壁面边界条件。

## S2 楔形入水（`run_s2_wedge.py`）——机制跑通，判定仍 BLOCKED

* **V_lat = 0.05（Ma = 0.087）不可用**：ζ = 8°/4°/2°、D_w = 100 三臂全部在第
  50 步就出现 max|u| = 2.6 / 5.0 / 21.4，100 步内 NaN。CAC 在入水冲击这种
  强压缩下 Ma 上限远低于常规算例。
* **V_lat = 0.01（Ma = 0.017）可用**：ζ = 8°、D_w = 100、400 步预松弛 +
  1200 步测量，全程有限、φ∈[0,1.02]、max|u| ≈ 0.07–0.09。
* 已跑通的一臂：**ζ = 8°，D_w = 100，V = 0.01，400 步预松弛 + 1200 步测量**
  （`--arm zeta8_dw100`，157 s，`(4,62,230)` = 57 040 格）。

| 量 | 值 |
|---|---|
| 拟合斜率（per span） | 7.33e-4 |
| Wagner 斜率（per span） | 1.962e-4 |
| 相对误差 | **+273.7 %** |
| 拟合 R² | 0.613（门：≥ 0.98） |
| max\|u\|/V | **9.78**（门：≤ 3） |
| 拟合窗口 | step 101–1200（穿透 0–11 格） |
| φ 范围 | [−0.000, 1.014] |
| 预松弛 | max\|u\| = 2.16e-3，φ ≤ 1.0136 |

  逐段（每 150 步）的 F_y：0.84 → 1.96 → 1.91 → 2.42 → 3.24 → 3.56 → 3.51，
  而**接触前**（step 40–100，体全在空气中）读数已经是 0.755（step 1 时 0.366）。
  这两个数说明：
  ① 力读数在 u ≠ 0 时有一个**与状态无关的偏置**（空气段就存在），
  ② 斜率偏大约 4×，且 R² 只有 0.61（力有明显振荡）。

* **为什么这不是"再调调就好"**：`momentum_exchange()` 的 u_w 项用**壁面速度**
  做平衡态扣除，而标准的 Galilean 不变形式要用**当地流体速度**。体在空气中
  u_fluid = 0 但 u_w ≠ 0，于是 `2Σ c_q ρ_wall (c_q·u_w)/cs²` 不会自消，
  形成与雷诺数无关的常值偏置。**下一步的正确闸门**不是继续跑 S2，而是做
  **动量守恒闸门**：在封闭水箱里比较
  `F_body(读数)` 与 `dP_fluid/dt − F_gravity − F_walls(静态壁读数)`；
  两者相对偏差 ≤ 1 % 才算力读数在 u ≠ 0 时可用。

**BLOCKED 的准确表述**：B6 已关；B1 的"运动固体 + 力读数"已通过静态
Archimedes 闸门（两相 1.0251 / 均相 1.0027 / g=0 时 −1e-5），但
**u ≠ 0 时的力读数没有独立闸门**（这正是 4× 系统偏差的来源），S2 的
max|u|/V 与 R² 也都没进 prereg 门；B2 有归因、无解。
