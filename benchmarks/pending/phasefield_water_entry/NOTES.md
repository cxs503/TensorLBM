| 单臂机时 | 26.2 / 27.1 / 27.5 / 27.5 s | | | | | |

### 读法

1. **g = 1e-4 / 1e-3 时静水压梯度在 2% 内**（−1.021 / −1.016）；**g = 1e-5 时退化到 −1.22（22%）**，并且随时间继续恶化。→ 入水算例的格子重力不能取得太小（prereg §2.2 的 Fr–g_lat 耦合）。
2. **界面单向爬升 + φ 积分单向增长，符号一致、近似线性**（g=1e-4 时 ~2.5e-4/1e3 步）⇒ 是**系统性相质量源**，不是噪声。位置：墙—相场通量（bounce-back 作用在 g 上，壁面化学势梯度非零）。
3. **密度比 100 与 816 的探针结果逐位接近**（界面 0.606 vs 0.607、dp/dy −1.0213 vs −1.0213）⇒ 密度比本身不是当前误差主因，问题在壁面/界面厚度，不在对比度。
4. **对 benchmark 的直接后果**：S0 的 3 个门里，dp/dy 在 g=1e-4 恰好 PASS（2.1%），而"φ 漂移 ≤1e-4/1e3 步"与"界面漂移 ≤0.5 格/1e4 步"**FAIL**（实测 2.5e-4 与 1.0 格）。见 prereg §3 与阻塞项 B2。
5. **外推（量级）**：若跑 3e4 步（S3 的 1.4e4 步量级），φ 增长约 +0.8%，界面漂升约 3 格 —— 对"液面高度/湿宽"类观测量是一阶误差，**必须先修或改观测定义**。

## P0b 静态圆盘跨越界面（4000 步，`(8,96,64)`，g = 1e-4，盘心在液面）

| 臂 | max\|u\| | φ 范围（末） | φ 超调（步 500 → 4000） | 远/近场界面高差（末） | φ 积分漂移（末） | NaN | 机时 |
|---|---|---|---|---|---|---|---|
| 圆盘 R = 8 | 1.13e-3 → **1.00e-3** | [−6.2e-11, 1.0049] | 1.81% → 0.49% | 0.073 → **−0.029 格** | +6.37e-4 | 无 | 86.0 s |
| 圆盘 R = 16 | 1.23e-3 → **1.06e-3** | [−3.0e-10, 1.0077] | 1.71% → 0.77% | 0.221 → **+0.320 格** | +3.71e-4 | 无 | 89.5 s |

### 读法

1. **静态体跨越弥散界面本身是稳定的**：无 NaN，φ 越界 ≤ 0.8%，伪流 1.0–1.1e-3。
2. **伪流被接触线放大约 3.6–3.8 倍**（无体基线 2.79e-4 同日同参数）。这个量级**低于** S1 的 2e-3 门，但已接近 1e-3，说明**接触线是伪流主源**，S2 的 `max|u|/V ≤ 3`（V = 0.05 ⇒ 1.5e-1）仍有充足余量。
3. **大圆盘（R = 16）出现持续 0.3 格量级的"界面台阶"**（远场 47.81 / 近场 48.13），且不随时间收敛；小圆盘在 ±0.03 格内。这与"无湿润/无接触线毛细力"一致：相场在固体附近只能靠 bounce-back + 化学势自然满足 90° 角，曲率越大偏差越大。→ prereg 把 S1 门定在 0.5 格（R = 8 型），并把 R = 16 的 0.32 格记为**已知偏差**而非通过证据。
4. 两臂 φ 漂移（3.7–6.4e-4 / 4000 步）与 P0 同量级 ⇒ 再次指向墙/固体—相场通量。

## 尚未覆盖（必须写进报告边界）

- 没有运动固体、没有 MEM 力读数 ⇒ **本探针完全没有验证"入水冲击载荷"**。
- 没有接触角边界 ⇒ 喷溅/空腔/闭合的定量结论不可得。
- 没有网格收敛（每臂单网格）；S2 起才做 100/200 两网格跨度。
- 2D 题用 z 周期薄板（4 层）在 S2/S3 才引入；本探针用六面壁（`axes="www"`），两者壁面数不同，S1 复跑需换 `axes="pww"` 并重测基线。
