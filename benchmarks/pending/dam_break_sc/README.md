# 2D 溃坝 — Martin & Moyce (1952) 验证（SCMP / Shan–Chen 单组分伪势）

**状态：❌ 未达标（2026-09-29）** — 波前位置系统性偏快 ~+6–14%（T=1 检查点最顽固，+10–16%），
超过仓库 ≤3% 门槛，未入库 `benchmarks/verified/`。本目录保留真实数据与可复现材料。

## 物理问题

水柱 a×2a（宽 a、高 2a）位于左下角（x<a, y<2a），重力 -y，四周固壁（bounce-back 闭合盒），
其余为气相。域 6.4a × 3.2a。

- 前端 `X = x_toe / a`（初始 1.0）
- 双轴无量纲时间（run.py 同时给出）：
  - `T_raw = t·√(g/a)`            （字面定义，M&M 原始口径）
  - `T_eff = t·√(g_eff/a)`        （两相流体力等效，`g_eff = g·(1-ρ_v/ρ_l) = 0.9184 g`）
- 参考（Martin & Moyce 1952, Phil. Trans. R. Soc. A 244, 312）：T=1 → X≈1.5；T=2 → X≈2.7

## 共性模块（无手写 solver）

`tensorlbm.multiphase.collide_sc_single_component`（SC94 伪势 `psi_exp`，`G_lib=+5.0`
符号翻转工作点 → 物理 `G_eff=-5.0`，`tau=1.0`）+ `tensorlbm.solver.stream` +
`tensorlbm.boundaries.bounce_back_cells` + `tensorlbm.d2q9`。
离散共存（laplace_droplet 口径）：ρ_l=1.957、ρ_v=0.1596（密度比 ≈12.3）。
编译路由：`benchmarks/compile_route.py` → `tensorlbm.compile_utils`（本机无 CUDA，走 `--compile-mode eager`）。

## 本次运行前修复的两个缺陷（run.py，已就地修正）

1. **初始条件距离函数错误**（决定性）：原 `dist_out = min(xx-a, yy-2a)` 在右上象限
   （`xx>a` 且 `yy>2a`）取正值 → 把 ~10k 个气相格误置为液相，域平均密度 0.89
   （高于共存中点），整个盒相分离为液体、水柱不坍塌。改为到矩形边的真符号欧氏距离
   （`dist_out = -√(clamp(xx-a)²+clamp(yy-2a)²)`）。修复后初始液格恰为 a×2a 个、平均 0.339。
2. **波前测量采样到贴壁贫化层**：原 `X_toe` 采样第 1..n_toe 行（a=40 时 n_toe=2），
   而 no-slip 壁（`solid_mask` 将 ψ 置零，壁不吸引流体）紧贴壁面形成 ~2 格
   ρ 贫化层（ρ_max≈0.66 < ρ_mid=1.058），导致 `X_toe` 在 0 与真值间抖动（原样运行
   直接报 −100%）。改为采样底部 1/8 盒高、自第 3 行起（该带内各行波前一致到 ~1 格）。

## 结果（真实模拟，无外推；SCMP，a=40/80，g=2e-4）

run.py 默认口径（`X_toe`，底部带 rows[3:ny/8]）：

| a | T_eff=1 模拟 (误差) | T_eff=2 模拟 (误差) | T_raw=1 模拟 (误差) | T_raw=2 模拟 (误差) |
|---|--------------------|--------------------|--------------------|--------------------|
| 40 | 1.742 (**+16.1%**) | 2.933 (**+8.6%**) | 1.694 (**+13.0%**) | 2.836 (**+5.0%**) |
| 80 | 1.705 (**+13.7%**) | 2.972 (**+10.1%**) | 1.657 (**+10.5%**) | 2.867 (**+6.2%**) |

- 参考 X：T=1 → 1.5，T=2 → 2.7。**所有轴、所有网格误差均 >3%**。
- 质量漂移 ≤2e-5，max_u ≤0.26（稳定、守恒良好）。

**口径敏感性**（a=40，仅取最贴地有效带 rows[3:5] 即最有利定义）：

| 检查点 | 最有利带 rows[3:5] | 默认带 rows[3:ny/8] |
|--------|-------------------|---------------------|
| T_raw=1 | X=1.643 (**+9.5%**) | 1.694 (+13.0%) |
| T_raw=2 | X=2.786 (**+3.2%**) | 2.836 (+5.0%) |
| T_eff=1 | X=1.692 (+12.8%) | 1.742 (+16.1%) |
| T_eff=2 | X=2.875 (+6.5%) | 2.933 (+8.6%) |

即使取「最有利口径」（最贴地窄带 + T_raw 轴），T=1 仍 +9.5%、T=2 仍 +3.2% → **不达标**。

**两档网格收敛（a=40 vs a=80）**：T_eff 轴 T=1 **2.15%**、T=2 **1.31%**；
T_raw 轴 T=1 **2.27%**、T=2 **1.09%** — **≤3%，收敛判据满足**。

## 缺口定位（模块/参数/口径）

- **不是口径问题**：三条候选时间轴（T_raw、T_eff、仓库 `dam_break.py` 的
  `t·√(2g/a)`）分别给出 +10~13% / +14~16% / −9~−21%，无一 ≤3%；波前曲线斜率与 M&M
  相当（~1.2）但整体 **加一个 ~+0.15a 的系统前移**，属真实动力学偏差而非归一化错位。
- **不是离散分辨率问题**：a=40→a=80 仅变 1–2%，已收敛，误差不随网格减小。
- **不是重力尺度问题**：固定 a、扫 g（Re 从 ~11 增至 ~60）→ T_raw=1 的 X 单调
  收敛到 ≈1.60（仍 +7%）；高 Re 惯性极限不回到 1.5。
- **不是密度比参数问题（反直觉）**：自制 G 扫描（自洽取共存 ρ、ρ_mid）显示
  G=5→比 13 → +16.1%，G=6→比 24 → **更差 +23%**（G=7 数值不稳）。
  即提高密度比（更接近水/空气 ~800）不收敛误差、反而更糟。
- **判定**：残留 ~+10% 属 **SCMP（SC94 指数伪势）本构缺口** —— 低密度比 + 弥散界面
  + 贴壁贫化/伪势边界层共同使溃坝涌浪前端偏快。与仓库既有结论一致
  （`benchmarks/problems.md` B20、`gap_analysis.md`：溃坝「多相缺口阻塞」）。
