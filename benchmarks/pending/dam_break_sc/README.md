## 0. 决定性修正一：M&M 时间口径（T = t·√(2g/a)）

此前 `run.py` 的（以及仓库另外两个基准脚本 `bench_fs_2d.py`、`dam_break_3d_mm` 的）
无量纲时间用的是 `T = t·√(g/a)`，**少了一个 √2**。

M&M (1952, Phil. Trans. R. Soc. A **244**, 312, doi:10.1098/rsta.1952.0006) 的定义是

```
T = t · √(2 g / a) ,      X = x_front / a ,      X(0) = 1
```

（`a` 为初始水柱**宽度**；水柱为 a 宽 × 2a 高。√(2g/a) 来自浅水 Ritter 标度。）

- **逐字确证**：Lethe 官方后处理脚本
  `examples/multiphysics/dam-break/dam-break-2d.py`：
  `time_list = [x * ((2 * g / L1) ** 0.5) for x in time_list]`。
- **仓库内核本已正确**：`src/tensorlbm/dam_break.py:299`
  `sqrt_coeff = (2.0 * config.g / L)**0.5`；`dam_break_3d.py:500` 同。
- 只有 3 个基准脚本用错了 √(g/a)。本目录的 `run.py` 已改正，并把旧口径作为
  `T_code` 列保留（标注用途）。

**改正口径后**：`T_MM = √2 · T_code`。历史报告中「+50~82%」的误差是**双重错误**的
产物（口径缺 √2 **且**参考表错位），必须撤回。

## 0c. 决定性修正三：Guo 力方案落地 & 「源项质量不守恒」伪影（2026-09-29）

### 落地

Guo (2002) 力方案已落地到 `tensorlbm.multiphase.collide_sc_single_component`，
**opt-in**（新参数 `forcing="guo"`），**默认仍是旧的速度平移 `forcing="velocity_shift"`，
逐位复现历史产物**（a=80 默认重跑 = +2.49% / −9.72% / −19.09%，与 `case_a80.json` 完全一致）。

Guo 方案（F 作为源项 + 速度含半力修正）：

```
u_phys = u + F/(2ρ)                      # 半力修正速度
f_eq   = f_eq(ρ, u_phys)
S_i    = w_i (1 − 1/(2τ)) [ (c_i − u_phys)·F / cs² + (c_i·u_phys)(c_i·F) / cs⁴ ]
f_out  = f − (f − f_eq)/τ + S
```

基准脚本新增 `--forcing {velocity_shift,guo}`。

### 决定性发现：`/root/db_guo.py` 原型源项**质量不守恒**，其「杠杆」是伪影

`db_guo.py`（即此前「Guo 是真正杠杆」结论的来源）用的源项是

```
S_i = w_i (1 − 1/(2τ)) [ (c_i·F)/cs² + (c_i·u)(c_i·F)/cs⁴ ]
```

**漏掉了标准 Guo 源项里的 `−(u·F)/cs²` 项**。因此
`Σ_i S_i = (1 − 1/(2τ)) (u·F)/cs² ≠ 0` —— **每步凭空造/毁质量**。
实测（a=80, G=5, τ=0.8, noslip）：

| 源项 | Σ_i S_i 数值 | 质量漂移（1600 步） | T=1 / T=2 / T=2.96 误差 |
|------|-------------|--------------------|------------------------|
| 原型（`db_guo`，漏项） | −0.0123 ≠ 0 | **1.1e-1（11%）** | +4.38 / −5.10 / **−8.74** |
| 标准 Guo（守恒） | 2.7e-9 ≈ 0 | **1.7e-5** | +5.66 / −7.75 / **−17.04** |

**把源项改成标准（质量守恒）形式后，Guo 与速度平移几乎逐位相同**：

| config（a=80, g=2e-4） | T=1 | T=2 | T=2.96 | 质量漂移 |
|------------------------|-----|-----|--------|----------|
| `velocity_shift` G5.0 τ0.8 | +4.71% | −7.75% | −16.70% | 1.7e-5 |
| `guo`            G5.0 τ0.8 | +5.66% | −7.75% | −17.04% | 1.7e-5 |

→ **结论：此前「Guo 力把 T=2.96 从 −19% 拉到 −8.4%」的改善，几乎全部来自源项的
质量泄漏（11%），而非 Guo 力本身；物理上不可接受，该「决定性杠杆」予以撤回。**
（g 依赖亦被复核：g=1e-4→+8.05/−5.99/−16.14，g=3e-4→边界发散；误差形状不随 g 改善。）

**结构性障碍**：T=1 的误差与 T=2.96 的误差对 G 的单调依赖**方向相反**
（降 G：晚时波前变快 → T=2.96 修复，但 T=1 急剧变快超差）。二者无法同时归零，
故不存在能把三点都压进 ±3% 的 (G, τ)。

**稳定性（任务 3）**：Guo（守恒形式）稳定域 τ≳0.70（τ=0.60/0.65 在 20~1020 步发散），
G≤5.0；τ≤0.8 时 G≥5.2 自激发散（step 440 NaN），G≥5.5 立即发散。即
**短 τ 或大 G 的自激未被 Guo 消除**；降低 G 能扩稳但以 T=1 精度为代价。

**两档收敛**（对 a=40 vs a=80，取最接近达标的两个配置）：

## 4. 判定

- 精度 ≤3%（细网格 a=80，T=1/2/2.96）：**不满足**。最优稳定配置
  （guo G5.0 τ0.8）为 +5.7% / −7.2% / −17.0%；任务目标的三点全 ≤3% 无法达到。
- 两档收敛 ≤3%：**不满足**（T=1 约 4.9%）。
- **综合：未达标** → 不迁入 `benchmarks/verified/`。

### 缺口（gap）

- 波前在 T≥2 后**系统性偏慢**且偏差随 T 单调增大（基线 −9.7% → −19.1%）。
  模拟水柱**塌得过快**（残高 H≈0.16–0.21 vs M&M ~0.42–0.5）→ 势能转移动能不足 → 波前
  推进速度上不去。属**本构/两相密度比**缺口（本 SC94 密度比 ~13，M&M 水/气 ~800；
  气相 `ρ_v≈0.16` 带来显著气阻）。
- 早期（T≤1）反而略快（+2.5%），随后转负 → 时间标度本身不是唯一缺口。
- 已排除的杠杆：`psi=sqrt(rho)`（G_lib=+5 下不稳）、`wall_psi=0.4`（不能网格收敛）、
  **Guo 力（质量守恒版；与速度平移等价）**、G 扫描 4.6–5.2、τ 扫描 0.7–1.0、
  g 扫描 1e-4–3e-4。剩下未试：Ramshaw–Phathanapirom 压力张量形式、客主耦合力、
  更高密度比伪势（Carnahan–Starling / power-law，需重测共存密度）。
