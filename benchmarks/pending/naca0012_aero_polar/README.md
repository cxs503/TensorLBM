- `solver.collide_mrt` + `stream` + `d2q9`

## 关键发现

- **D2Q9 方向表顺序**：仓库 lattice 顺序与教科书写法不同，错用会让反弹把不同方向的分布函数对调，产生 $C_L\approx 72$ 的伪力（对称性测试才暴露）；
- **固体内清零会炸**：固体格点被清零后，仅部分方向有分布的格点非平衡量极大，碰撞变成数值源（无壁面条件也发散）；固体内部只需保证不向流体串流即可；
- **纯涡面板 + 均匀涡 Hess-Smith 退化**：闭合涡片对法向速度的贡献恒为 0，单涡未知量与 Neumann 方程解耦 -> 奇异性；改用逐面板涡强度 + 二阶差分正则化。
