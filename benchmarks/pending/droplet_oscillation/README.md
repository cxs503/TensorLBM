# B24: 液滴振荡 Rayleigh 频率基准（SCMP 单组分 Shan-Chen，m=2 模式）

**状态：❌ 未达标（pending，2026-08-19 实测）——观测振荡频率与 Rayleigh 公式偏差 6~8%（>3% 阈值），
但已定位根因：SC94 模型固有强阻尼（γ≈0.72/R²，比体黏性理论大 ~4.5 倍），
阻尼还原后的本征频率与理论一致（~1-2%）。**

## 物理问题

2D 周期域中心液滴（初始平均半径 R₀），气相包围，初始 m=2 形状扰动：

```
R(θ) = R₀·(1 + ε·cos(2θ))， ε = 0.05
```

液滴自由形状振荡。Rayleigh（1880）线性理论，2D 圆液滴 m 阶模式：

```
ω² = m(m²-1)·σ / (ρ·R³)      m=2 → ω² = 6σ/(ρR³)
```

- σ = σ_eff = **0.056112**（laplace_droplet 已验证 2D 实测值）
- ρ = ρ_l = 1.957（离散共存液相密度；严格 2D 推导分母为 ρ_l+ρ_v=2.1166，
  气相修正 −3.8%，本基准两种口径均报告，主判据按任务公式用 ρ_l）
- R = 实测平衡半径 R_eq（mid 界面，自适应阈值）

## 配置（与 laplace_droplet 完全一致，复用已验证参数）

- SC94，ψ(ρ)=1−e^(−ρ)，物理 G_eff=−5.0（库调用 G=+5.0，后向 gather 约定），τ=1.0，float32

  + `solver.stream`；grep 校验同 Laplace

## 测量与分析方法

- **主信号**：质量加权 quadrupole 矩 Q(t)=⟨x²−y²⟩_ρ（液核内积分）。m=2 纯形变下
  **等效半径 R_eq=√(A/π) 一阶不振荡**（面积守恒），必须测 Q 或界面半径差；
  界面位置沿中心线 mid 阈值**亚格子线性插值**（整格量化会污染频谱，见 gap 文件）
- **频率提取**：时域阻尼正弦最小二乘拟合 Q=A·e^(−γt)·cos(ωt+φ)+c
  （网格扫描 ω×γ + 线性系数求解）。FFT 口径在本参数下不可靠——
  强阻尼使谱峰严重展宽（峰比仅 1.1，R20 时 FFT 低估频率达 −23%）
- 拟合窗口取信号主导段（跳过 ~500 步声学/弛豫瞬态，取 ~4 个理论周期；
  强阻尼下后期信号衰减到噪声以下，窗口必须截断）

## 根因诊断：SC94 模型固有强阻尼

1. **阻尼率 γ ≈ 0.72/R² 常数**（R²γ：0.76 / 0.81 / 0.80），完美 R⁻² 标度，
   但数值为体黏性理论 γ~ν/R²（ν=1/6）的 **~4.3 倍**（m=2 因子 ~(m−1)(m+1)/... 仍差 2-4 倍）
2. **τ 无关**：τ=0.75 诊断运行 γ 几乎不变（6.5e-4 vs 8.5e-4，R=30）→ 阻尼主要来自
   SC 伪势相互作用的界面耗散，不是体黏性
3. **阻尼压低可观测频率**：ω_d=√(ω₀²−γ²)，偏移 ≈γ²/2ω₀²：R20 −8.9%、R30 −6.5%、
   R40 −4.8%，与实测观测误差（−6~−8%）定量吻合
4. **色散关系正确**：阻尼还原 ω₀=√(ω_d²+γ²) 后与 Rayleigh 理论一致
   （R20 +0.75%、R30 −1.1%、R40 −2.0%）→ 模型本征频率正确，耗散过大
5. 阻尼比 γ/ω：R20=0.42、R30=0.36、R40=0.31——任务指定档位（R=20/30）下
   振荡仅 1.5-3 个有效周期，属强阻尼/近临界区，频率测量不确定度大

## 结论

任务指定配置（tau=1.0、G_eff=−5.0、R=20/30）下，液滴振荡观测频率未达 3% 判据
（偏差 −6~−8%，由模型固有强阻尼所致，非数值 bug——质量守恒 2e-4、R_eq 稳定、
γ 标度自洽、本征频率还原后吻合）。**不保存至 verified/**，记录为 pending 并保留
全部数据（hist json/npz）供后续分析。
