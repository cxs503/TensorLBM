## 稳态性与诊断 (rule 5)

- 预期: Kurtulus 称 8° 以下 Cl 振幅为零 (稳态)。实测: α=5° 全部档位存在
  **周期性 Cl 振荡** (std≈0.06-0.07, 峰峰≈0.23), 主频在对流时间下网格无关:
  f=2.875/t_c (周期 0.348 t_c), 三档完全一致 → 流动尺度现象, 非格子伪影;
  但 St=2.875 远高于物理尾迹脱落 (St~0.15-0.2 → 周期 5-7 t_c)。
- **rule-5 诊断 (logs/diag_correct_mass.json, c60 双跑)**: correct_mass 全局
  重标定因子偏差仅 ~1e-7; 去掉 correct_mass 后振荡 std 完全相同 (0.0608 vs
  0.0608), Cl 均值差 0.1% (0.2449 vs 0.2446) → **排除质量校正致振**;
  振荡为该配置 (通道域+阶梯边界+MRT τ≈0.51) 的真实流动尺度现象,
  物理来源未定 (候选: 域声学相互作用模态 / 阶梯边界激发的分离泡不稳定性)。
  参考: Di Ilio HLBM (曲面边界) 在 α=4° 报告稳态 — 边界处理差异为可疑因子。
- 域高敏感性 (披露): c90 域 14c×12c → Cl=0.2572 (vs 8c 高的 0.2628, −2.1%)。
- Ma = u_in·√3 = 0.104, 可压缩误差 O(Ma²)~1-2% (披露)。
- 力方法: Ladd 动量交换, post-stream pre-bounce-back, wet-node; 阶梯边界
  (无曲面处理) — 与库约定一致, 未见系统性符号/量级问题 (Cd 收敛良好)。

## 披露清单

1. 参考提取方法: 图数字化 (无表值), 不确定度 ±0.015 (标记半径 ~5px)。
2. 两源差异: 0.132(图) vs 0.24-0.27(文字锚+Di Ilio) ≈ 85% → 参考受限。
3. 力方法: 动量交换 (见上)。
4. Ma=0.104 可压缩性 ~1-2%。
5. 域: 14c×8c 通道型 (上下无滑移壁), 堵塞 ~2.6%; 域高 8c→12c 影响 −2.1%。
6. α=5° 出现非预期周期振荡 (St=2.875 对流网格无关), 未见稳态平台;
   Cl 均值在 ≥23 个振荡周期上取平均, 非整周期残差 ≲0.8%。
7. 判据计算以锁定参考 0.132 为准; 0.26 列仅为披露。
