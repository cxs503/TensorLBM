# collision_kernels_3d_tg（pending）

**状态：❌ 未达标（判据类 + 实质核缺陷）——六高性能碰撞核 3D Taylor-Green 衰减：五核容差与指数性全过（每档 |err_E| ≤ 0.4713%，为 3% 门的 1/6）但单调收敛门 0/5（collide_bgk27 对照链同不单调 ⇒ D3Q27 + 固定 Re 的 τ 阶梯结构性，非核特异）；collide_kbc_d3q19 实质 FAIL——τ 不设定该核粘度（ν_eff≈1/6 恒定），三档 +8.5904/-16.1851/-36.5120%，该缺陷已由库 PR #312 修复，修复核同协议复跑 -0.6748->-0.3576->-0.1608% 严格单调。**

## 物理问题

对库碰撞核矩阵中此前零定量基准的 6 个高性能核（cumulant/cascaded/mrt/trt/rlbm/kbc）逐个建立 3D Taylor-Green 涡衰减定量基准，协议与已验证先例 `benchmarks/verified/taylor_green_3d/`（D3Q19 BGK）一致，仅替换碰撞核与对应格子；另附 collide_bgk27 参照对照（诊断用，非预注册核）。周期域 N³，k=2π/N，ν=U0·N/Re，τ=0.5+3ν；Re=24、U0=0.05、阶梯 N=64/96/128（τ=0.9/1.1/1.3）。初场 u=(U0·sin kx·cos ky·cos kz, −U0·cos kx·sin ky·cos kz, 0)、ρ=1、f0=f_eq；步序 collide(stream(f))；步数 auto（E/E0→e−10，record_every=50，下限 2000）。fp32（RTX 5090，TF32 matmul 关闭）。观测：γ_E_sim=−d(lnE)/dt（LSQ，t≥50 全采样）对解析 γ_E=6νk²——初场为波矢 (±k,±k,±k) 的 8 支平面波叠加，|κ|²=3k² ⇒ γ_vel=3νk²、γ_E=6νk²；D3Q27 与 D3Q19 的 cs² 同为 1/3，六核剪切模弛豫率均为 1/τ（源码核对），两格子解析式一致。3D TG 非 NS 精确解：涡拉伸使 γ_sim 略高于 6νk²（先例 BGK 量级），如实测量、无修正、无重标定。判定条款预注册于暂存 NOTES_sha256 链（judge() 语义与先例一致）。源钉定只读 worktree bm_w5（commit cf5709db3c）。库入口：六核碰撞函数 + d3q27.stream27_roll / solver3d.stream3d + equilibrium27/equilibrium3d + macroscopic，全程只调库函数。

## 根因/诊断

1. **单调条款在 D3Q27 + 固定 Re τ 阶梯下结构性不可满足**：五核 err 趋势（随 N 微升）在裸 bgk27 上同样出现（+0.3137->+0.3347->+0.3263）；预注册横波粘度审计已测各核格子离散项 ∝ k²·f(τ)，f(τ) 随 τ 增长快于 k² 随 N 缩小；固定 τ=0.9 单档对照（上表）再次确认误差随 (τ,Re) 组合整体移动。D3Q19 先例（BGK 单调通过）条款不可迁移。
2. **collide_kbc_d3q19 粘度不由 τ 设定（实质缺陷，旧核）**：本工作横波审计（fp64，L=32）测得 ν_eff 基本不随 τ 变——τ=0.9 时 ν_eff 0.16593839184000658 vs 目标 0.13333333333333333（24.4538%）、τ=1.1 时 0.16747834997382327 vs 0.20000000000000004（-16.2608%）、τ=1.3 时 0.1650998788197422 vs 0.26666666666666666（-38.0875%），均趋于 cs²/2=1/6；库自带 collision_viscosity_audit 独立复核同判（audit_extra.json，τ=0.8/0.9 两档 acceptance admitted=false；其嵌套键含点号不可寻址，数字以本表 audit_viscosity.json 为准）。机理：对 H(f_eq+γs+h*) 做无条件逐胞极小化，小非平衡极限下解得 γ≈0（剪切模全弛豫 ⇒ ν=cs²(1−1/2)=1/6），初值 γ0=1−1/τ 被丢弃；任何 τ 取值都无法改变 γ≈0，不做参数重调。
3. **collide_cumulant_d3q27 ≡ collide_cascaded_d3q27（层流弱压缩区数值恒等）**：γ_sim 6 位一致，与库文档 O(Kn²) 警示一致；两核基准互为旁证，区分两者须高 Ma/高 Re 工况。
4. **基础设施无缺口**：D3Q27 stream27_roll（周期）、equilibrium27、macroscopic27 及六核碰撞函数齐备。
