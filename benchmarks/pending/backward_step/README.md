## 物理问题

台阶后分离流，再附着长度基准：
- **Armaly et al. 1984（JFM 127:473）**：Re=100（基于台阶高 h 和最大入口速度）→ **X_r/h ≈ 3.0**
- Re=400 → 8.0；Re=800 → 14.0（二维）

## 共性模块

**backward_facing_step.run_backward_facing_step**（src/tensorlbm/backward_facing_step.py）：
- BackwardFacingStepConfig：nx=400, ny=80, 台阶高 39 格, 膨胀比 1.95
- 入口：充分发展抛物线（Zou-He），U_max=0.05
- 碰撞：MRT（τ=0.529，Re=200）

## 结果（子 agent 实测，真实模拟）

- **Re=200**（子 agent 误用）：X_r/h=5.65 vs 参考 3.0 → **88% 误差**
- **Re=100 重跑**：X_r/h=3.37 vs Armaly 3.0 → **12.2% 误差**（仍 >3%）

## 未达标原因分析

1. 再附着长度对入口条件（充分发展度、膨胀比）和网格分辨率敏感
2. 子 agent 首跑误用 Re=200（参考表是 Re=100）；Re=100 重跑 12.2%
3. 可能需：更大网格（ny≥100）、更长收敛、入口剖面精确匹配
