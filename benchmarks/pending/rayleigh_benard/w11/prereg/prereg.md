## 1. 物理与数值设计（冻结）

- 2D 双分布 BGK: 水力 D2Q9（tau=0.855, nu=0.118333…）+ 温度 D2Q5（tau_T=1.0,
  alpha=1/6 精确）→ Pr = 0.71 精确（0.355/0.5）。
- Boussinesq 浮力（Guo 力格式, collide_bgk_force）: F = (0, g_beta·theta),
  theta = T − T̄(y)（对导热基态零力，纯线性耦合）。
- 域: x 周期, nx = 2·ny; 上下无滑移等温。half 构造: 速度半程反弹壁位于半平面
  y=0.5/(ny−1.5)（P1 实测 d_v = ny−2），温度壁反对称镜像到同一半平面
  （P0.7 实测 d_T = ny−2 = d_v，重合层）。基态 T̄ = 1 − (j−0.5)/d。
- 格点阶梯: ny ∈ {64, 128, 256}（d = 62, 126, 254）; k = 2π/nx（a = k·d =
  3.0434/3.0925/3.1170, 邻近 a_c = 3.1163）。
- Ra 臂: {0.85, 0.95, 1.05, 1.15, 1.3} × Ra_c(a)（各层 own-solver 冻结值）;
  臂 1.0 仅报告（γ_ref = 0 无相对判据）。
- 格子单位映射（冻结, 已被算子+fp64 步进器双重经验证实）:
  g_beta = Ra·ν·α/d³, t* = d²/α, γ = slope_per_step · d²/α。
- 运行器 dtype = float64, 种子幅 amp = 1e-4（本征模特征种子, 见 §3）。
  fp32 判死（§6 证据）: 线性起稳可观测量在 fp32 下被群体量子化破坏。
- 每步 solver.correct_mass(f, m0)（库自带质量归一设施; 对 (u, θ) 动力学中性,
  证据见 §6; 消除 D2Q9 W fp32 求和伪影 7.45e-9 的线性积累）。

## 3. 观测量与拟合协议（冻结; 符号投影, 禁 |A| 整流）

- 种子: Θ 特征模 + 无散速度场（Φ, Φ′）, 幅 amp=1e-4, cos(kx) 相位。
- 观测量: 符号投影幅 A_T(t) = Σ_{x,j}(T−T̄)·Θ(j)·cos(kx) / Σ Θ²·(nx/2)
  （每采样步记录; 符号全程保留, 拟合用 log|A_T| 仅在 A_T 定号段）。
- 采样: sample_every = max(1, N//600)。
- 步数（冻结公式）: N = ceil(3.0 · steps_per_tstar / |γ_ref|), 下限 4000,
  上限 6·steps_per_tstar。
- 窗口协议: 三窗 ((0.15,0.90),(0.05,0.75),(0.30,1.00)) log|A_T| 线性 LSQ;
  γ_sim = 三窗斜率均值 · d²/α; 窗间散布 spread = (max−min)/|mean| ≤ 2% 为
  拟合合格门; 单次预注册延长: 若 spread 超限, N ×1.5 重跑一次, 仍超限则该臂
  诚实 FAIL（拟合质量条款, 不改判据值）。

## 4. 门禁（冻结; 判据数字全部机器对机器）

主门（直接可观测量）:

  → 主门 PASS。ny=64 为粗披露层（Phase-0 证据预测其 0.95/1.05 臂为最紧点,
  ~1.5–2.9%）。
- G2 单调门: E(ny) = sqrt(mean_arms rel_err²) 严格单调下降 64 → 128 → 256。
- G3 符号门: γ_sim < 0 @ 臂 0.85, 0.95 且 γ_sim > 0 @ 臂 1.05, 1.15, 1.3,
  每臂 |γ_sim| ≥ 2×该臂三窗散布; 臂 1.0 报告 γ_sim 符号（预期≈0, 不进门）。
- G4 健康门: |mass_drift|/m0 ≤ 1e-8（correct_mass 后）;
  u_max ≤ 1e-3; max|T−T̄| ≤ 0.01; 窗散布 ≤ 2%; a_last/a_first ≥ e^2.2。
- 判 FAIL 合法: 任一门不过即如实记录; 禁止事后调门。

## 5. 运行器规范（冻结）

- 输入: ref_table.json + eig_ny{ny}.npz（机器读取 Ra, γ_ref, 种子形状）。
- 步序（每步）: macroscopic → F=(0,gβθ) → 温度碰撞(τ_T, u) → 温度 stream →
  apply_rb_temp_bc("half") → collide_bgk_force(τ, F) → pre_streaming_bounce_back
  → stream → correct_mass(f, m0)。
- fp64 全程; 记录 A_T 序列 + 健康量到 results/ JSON（机器判据管线直接消费）。
- 判据计算: verify 脚本只读 JSON 与 ref_table.json, 输出判决行
  (arm, γ_sim, γ_ref, rel%, sign, spread, G1..G4 逐项)。
