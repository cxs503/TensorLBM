# 方柱绕流 Re=100（尖锐角验证，播种+sponge 工程链）— 未达标记录

**状态：🔶 未达标（相对 Okajima 口径参考：Cd -7.4%/-7.2%、St +5.9%/+5.7%，两档超 3% 容差；但网格收敛良好）**

## 物理问题

自由流方柱（正置）绕流 Re=100（尖锐前缘分离 + Kármán 涡街）：
- **任务口径参考（Okajima 1982）**：St≈0.14（方柱文献 0.13-0.15）、Cd≈1.6（自由流）
- 2D 数值文献：St≈0.145-0.15（Sohankar 1998、Sharma & Eswaran 2004 ≈0.149）、自由流 Cd≈1.5-1.65
- 注意：Sohankar 1997 的 Cd≈2.05 是**通道配置**（高阻塞加速），不适用自由流——B19 首版（-26.7%）即因误用该参考

## 工程链（完整复用 cylinder_re100，仅掩码换方块）

库 solver 路径（D2Q9），零手写 collide/stream/equilibrium：
- solver.collide_mrt（tau_field 逐格松弛 = sponge）+ stream + d2q9.equilibrium
- boundaries.far_field_bc_2d（入口/两侧自由流 Dirichlet + 出口零梯度 + obstacle BB）
- boundaries.make_sponge_strength（下游 10D 渐变吸收，α=10）
- boundaries.compute_obstacle_forces（Ladd 动量交换 Cd/Cl，post-stream/pre-BB）
- **square_mask**（run.py 本地定义，half-way BB → 有效边长精确 = D；接口同 cylinder_mask）
- 入口播种：2 个 St_seed=0.14 周期、10% 振幅正弦横向扰动后回归自由流
- ν = U·D/Re（U=0.05），τ = 3ν + 0.5；域 40D×40D（blockage 2.5%）

## 未达标原因分析（超 3% 容差，如实记录）

1. **St=0.148 vs 参考 0.14（+5.8%）**：0.148 在方柱文献范围 0.13-0.15 内，且与 2D 数值文献主流
   （Sohankar 1998 ≈0.148-0.15、Sharma & Eswaran 2004 ≈0.149）高度一致——参考口径是 Okajima 1982
   实验值 0.14，2D 模拟普遍略高于实验。
2. **Cd=1.48 vs 参考 1.6（-7.3%）**：位于自由流低阻塞 2D 数值文献范围（~1.5-1.65）下沿；
   40D 域（blockage 2.5%）→ Cd 偏低合理。
3. **判定**：两档 ≤3% 且收敛 → **不满足**（虽然收敛）。不达标是真实结果，未做任何外推/调参凑值。
