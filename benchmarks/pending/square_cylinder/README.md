# 方柱绕流 Re=100（square_cylinder）— 判定记录（W8-B 更新）

自由来流正置方柱涡脱落。D2Q9 MRT（τ 场含下游 10D sponge）+ far_field 侧边界
+ 入口两周期升力播种（St=0.14, 10% 振幅）+ 半程 BB 方块（有效边长精确 D）。
域 40D×40D（堵塞 2.5%），u_in=0.05，阶梯 D32/D48/D64 = 60k/90k/120k 步
（分析窗 = 后 50%）。基线 36224617f19。

## 参考（锁定于正式输出之前）

主参考 = **2D 低堵塞数值簇中位数**：Cd_ref = 1.4785、St_ref = 0.1456
（8/10 样本：Sohankar 1998 1.477/0.146、Sharma & Eswaran 2004 1.494/0.1488、
Berrone 2011 1.48/0.145、Zhao 2013 1.452/0.1447、Haque 2023 1.476/0.144、
Przulj 1998 D1 1.4614/0.1444、Sahu 1.488/0.1486、Rajpoot 2021 1.51/0.1512，
经 Haque 2023 AIP Adv. 13:085219 Table III 等多源逐字核对）。

本记录替换旧档（Okajima 实验口径 1.6/0.14，判双 FAIL）。替换依据：同簇成员
（2D、B 3.3–5.6%）自身对 Okajima 实验 Cd 也低 6–8%（簇 1.45–1.51 vs 实验
1.59），高堵塞家族（Franke 1990 1.61、Davis & Moore 1982 1.63）曾通胀
"Cd≈1.6" 预期；Przulj 1998 堵塞阶梯 B_f 8.33%→3.33%（Cd 1.5899→1.4430、
St 0.1539→0.1430）定量解释该家族偏高的来源。旧档数值本身由本轨逐位复现
（见复现门）。实验值降为敏感性旁列，不作判据。

## 测力口径三列 A/B 与动量预算闭包

同一步、同一采样相位（post-stream、pre-BB）三列并行：

| 列 | 定义 | D32 | D48 | D64 |
|----|------|-----|-----|-----|
| mem | 2·Σ_{全固体}Σ_q c_q f_q（旧档方法） | 1.4817 | 1.4845 | 1.4870 |
| pair | Σ_links c_q·[f_q(x_s)+f_opp(x_f)]（主列） | 1.4817 | 1.4845 | 1.4870 |
| wet | 2·Σ_links c_q·f_q(x_s)（库 3D wet-node 2D 同式） | 1.6576 | 1.6296 | 1.6139 |

- **闭包：pair−mem 窗口均值差 ≤0.001%**（D32/D64 0.000%、D48 +0.001%；
  窗口逐步 |Δ| ≤ 0.2%；warmup 段 mem 有 t=0 初始化尖峰 80D、pair 恒 0，
  不入分析窗）。pair 恒等于流体控制体离散动量预算（进入固体动量 E + 壁面
  链接回流 R 的代数恒等），mem/pair 为本引擎正确口径。
- **wet 单侧式在本 2D 链失效：+11.87/+9.77/+8.53%**。机理：collide_mrt
  作用于固体格，返回通量被碰撞弛豫衰减（R/E≈0.79@D32），"返回=入射原位
  反转"前提（库 3D 球问题 pair=wet 的前提）不成立。Cl 幅值 wet 0.443–0.487
  vs mem/pair 0.290–0.297（文献簇 0.24–0.27）同向印证。库 3D wet-node
  约定不可直接移植到本 2D 链。
- St 对测力口径不敏感（三列全同，差 0.0%）。
- 旧档 −7% Cd 偏差归因：测力口径 0%（旧方法预算闭合正确），100% 来自
  参考口径（实验值 + 高堵塞家族通胀预期）。
