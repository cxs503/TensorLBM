## 3. 根因分析

### 3.1 误差来源：壁面约束效应

Hadamard-Rybczynski 解析解假设**无限域**（unbounded domain），但实际模拟必须有壁面作为动量汇（momentum sink）。

**约束比**（confinement ratio）：
```
a/L = 12/96 = 0.125
```

根据 Faxén 修正理论，壁面约束会显著降低液滴终端速度。对于球形液滴在方形管道中，一阶修正为：
```
U_confined / U_unbounded ≈ 1 - 2.104 * (a/L) + ...
```

代入 a/L = 0.125：
```
U_confined / U_unbounded ≈ 1 - 2.104 * 0.125 ≈ 0.737
```

实际测量值：
```
U_sim / U_ref = 5.653e-05 / 9.998e-05 ≈ 0.565
```

偏差来源：
1. Faxén 修正是一阶近似，高阶项未计入
2. 方形管道 vs 圆形管道的几何差异
3. 全壁面（6 面）vs 单管道方向的约束

### 3.2 为什么无法通过网格细化解决

壁面约束效应是**物理问题**，不是数值误差：
- 细化网格（L=128, 192, 256）会保持 a/L 不变（如果同时增大 a）
- 如果保持 a=12 不变，增大 L 会减小约束比，但需要更大的计算域
- 这不是收敛性问题，而是边界条件问题

### 3.3 可能的解决路径（超出本任务预算）

1. **增大域尺寸**：L=256 或更大，使 a/L < 0.05
   - 预算估算：L=256 需要 ~10x 计算量（3D）
   - 预计误差：~10%（仍需 Faxén 修正）

2. **应用 Faxén 修正**：后处理修正壁面效应
   - 需要推导方形管道的高阶修正公式
   - 引入额外的理论不确定性

3. **改用其他基准**：选择对壁面不敏感的基准
   - 例如：Taylor-Green 涡（无边界）
   - 或：周期性两相流（无壁面）
