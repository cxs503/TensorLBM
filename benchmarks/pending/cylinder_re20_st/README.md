# 圆柱 Re=20（Schäfer-Turek 2D-1）— 待确认（两档均 ≤3% 但加密恶化，未达标）

**状态：🔴 未达标（2026-08-19 两档 300k 步长跑完成：D=40 -0.558% ✅、D=80 -2.875% 贴边 ≤3%，但 |err| 随网格加密增大 5 倍，不满足"误差单调下降"真收敛铁律）**

## 物理问题

Schäfer-Turek 通道内圆柱 Re=20（2D-1）：
- Cd=**5.57953523384**、Cl=0.010618948146（Nabh 1998 谱方法，FeatFlow 官方）
- 域 2.2×0.41，圆柱 D=0.1 偏心 (0.2,0.2)，Poiseuille 入口（U_mean=0.2）+ 压力出口 ρ=1
- Re = U_mean·D/ν = 20（ν=0.001），τ=0.8（ν_lb=0.1，U_mean_lb=0.05）

## 实测结果（2026-08-19，正确配置 mask=R + 无重整化，300000 步，末 50000 步平均）

- 两档各自**统计收敛**：末 20k 步 Cd 漂移 <0.01%（D=40: 5.5473→5.5475；D=80: 5.4188→5.4196）
- 可复现：D=40 与 120k 步短跑（5.5486）一致；D=80 与 120k 步短跑（5.4193）一致
- **但 |err| 随网格加密增大（0.558% → 2.875%，5 倍）**——不是"误差单调下降到参考值"，而是"加密向参考值偏离更远"。与同物理问题 cylinder_re40_st（-0.76%/-3.28%）、B3 球、B19 方柱同模式：**MEM 阶梯偏差随 D 增大而增大**。D=80 已贴 3% 边界（余量 0.125%），加密到 D=160 大概率超线 → 按用户铁律"≥2 档网格误差单调下降才算真收敛，加密恶化=假结果"**不入 verified/**

## 关键发现（历史，2026-08-19 实测定案）

1. **质量重整化是真凶（已定案）**：每 2000 步全局重整化 f*=M0/Σf 激发 ~10k 步周期慢振荡（Cd ±2-4%），污染末段平均 → 旧数据"假网格依赖"（D=40 -0.76%、D=80 -3.28% 是相位样本）。**去掉重整化后振荡消失、Cd 单调收敛**——但注意：无重整化后两档误差仍为 -0.56%/-2.87%，**网格依赖本身是 MEM 阶梯偏差的真实行为，不是重整化伪影**（重整化只制造了时间振荡，没制造网格依赖方向）
2. **R-0.5 掩膜修正被实验否决**：数字圆柱水力有效半径 ≈R+0.11（3D 管流量反演），R-0.5 过冲到 R_eff≈R-0.39 反而减小动量交换力（D=40 -2.97%、D=80 -4.01%，加细远离参考）
3. **正确配置** = mask 半径 R + 无重整化 + 长时运行（≥300k 步）；本案例已按此配置跑满，结果如上述

## Cl 不匹配（如实记录）

- 实测 Cl = -0.0141（D=40）/ -0.0015（D=80）vs 参考 +0.0106：符号反、量级小
- 归因：**动量交换升力对阶梯角点/入口剖面敏感**（升力是二阶效应，量级 ~0.01 远小于 Cd ~5.5，MEM 对表面法向的离散投影误差直接淹没 Cl）；不作修正
- 注意 D=40→D=80 Cl 也在变（-0.014→-0.0015），进一步说明 Cl 不是收敛量

## 下一步（修复方向）

- **D=160 第三档**确认趋势（预期 -4% 以上超线，坐实"加密恶化"而非巧合）；或

- 3D 圆管（poiseuille_3d_pipe）：同根因但不适用 R-0.5——按流量反演半径（R_eff^Q≈R+0.11）比较
