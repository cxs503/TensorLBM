## 判定：FAIL（参考受限定源）

- 档 A：最细 2.436%≤3% ✓，严格单调 ✗（2.920→2.281→2.436）→ FAIL
- 档 B：最细 2.177%≤3% ✓，严格单调 ✗（1.858→2.626→2.177）→ FAIL
- 档 C：最细 3.058%>3% ✗，严格单调 ✗（2.696→2.962→3.058）→ FAIL
- **总判 FAIL**。无后验放宽；独立复算（PCHIP / 锁定节点 / 独立 log-log 三插值
  互差 ≤2.6e-4，插值项远小于判据带）全数通过。

失败结构（定源）：

1. **偏移为主、离散为辅**：err_A 九点全部 1.86–3.06% 平坦系统性偏低，对 d 无
   收敛趋势；斯托克斯自检 err_SA 在 d≥104 全部 ≤1%（最细 0.21%）——我方
   复现 S&A 斯托克斯曳力无虞，偏差专门落在弱惯性增量上（R−1：sim
   0.148/0.261/0.397 vs A 0.182/0.284/0.435，惯性增量比 K&L97 小 5–8% 相对量）。
2. **参考侧带宽 ~1.0–1.6% 吸收偏移约半**：对 B 序列 err 0.71–1.79%（全部
   ≤3% 无一破带）；以 A/B 中点为参考 err ≈ 1.4–2.4%。其余为方法侧（τ=0.55
   BB 墙位残余、Ma² 可压缩性、Re 轴约定差各 ≤0.3–0.9%，方向一致无一单独主导）。
3. **单调条款无判别力**：各 d 档掩码实现（f 形 y0 摆动 217.1–219.8 = ±0.6%）
   构成 ~±0.5% 实现噪声地板，高于阶梯间误差变化（0.4–0.8%）——严格单调要求
   在该偏移+噪声水平下不具判别力（判据设计对该问题类的适用性发现）。
4. **档 C 反向漂移与 Ma² 定量一致**：Δerr 0.36pp ↔ ΔMa² 0.0068（等效
   +0.5%/Ma²），外推 Ma=0 档 C err ≈ −3.1%（对 A）——可压缩性偏高曳力随
   Ma→0 消失的方向一致。
