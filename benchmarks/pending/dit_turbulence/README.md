## 1. 物理问题与配置

- 周期域 [0,N)³（Δx=Δt=1），**随机无散（solenoidal）初始速度场**，目标能谱
  E(k) ∝ k⁴·exp(−2(k/m0)²)，m0=3（模式指数），u_rms=0.04 精确归一化。
- 分子 τ=0.501（ν=(τ−1/2)/3=3.33e-4 极小）⇒ 分子 Re_L≈65、Re_λ≈665（N=64）/1905（N=128）/5462（N=256）；
  亚格子耗散由 **Smagorinsky LES（C_s=0.12）** 提供（库 `turbulence.collide_smagorinsky_bgk3d`）。
- 能量级联在无外力下自由发展（DIT）。共性模块：`solver3d.stream3d` + `turbulence.collide_smagorinsky_bgk3d`
  + `d3q19.equilibrium3d/macroscopic3d`；3D FFT 球壳谱/无散初始场/偏度分析为 run.py 自实现（库缺口
  G-DIT-1/2，见 `/tmp/dit_gap.md`）。dtype=float32（mrt3d 变体存在已知 dtype bug，正式档用 bgk 路径）。

## 4. 根因分析（三次验证合并）

1. **N=64 欠分辨（第一次，决定性）**：LES 亚格子耗散相对级联过强 → 谱随时间快速变陡、无 −5/3 平台、
   n=1.610 超带、E 衰减 558×（N=128 仅 142×）。
2. **N=256 欠耗散（第二次，决定性）**：分辨率提高后数值耗散下降，Smagorinsky Cs=0.12 的亚格子耗散
   **相对不足** → 能量在惯性区堆积、谱变平（t≈2500–5000 斜率 −1.1~−1.4），级联减弱后（t≈8500–9000）
   才二次穿越 −5/3；衰减早期偏快（n=1.69，E 衰减 48.3×）。
3. **N=128 的 −5/3 是数值耗散补偿的巧合**：该分辨率下数值耗散恰好补足亚格子耗散缺口，
   形成 t≈2000–4000 的短暂穿越（其后单调变陡至 −2.9）。三次验证均确认**无真正的惯性区平台**。
4. **Cs 微调不是 N=256 的解（第三次，决定性）**：Cs=0.12→0.13 时 N=256 预注册窗口斜率
   −1.3825→−1.3843（+17.05%→+16.94%，几乎不变），而 N=128 同区间变化明显（−1.639→−1.683）。
   N=256 的斜率/衰减指数对该 Cs 区间不敏感 ⇒ 欠耗散缺口远超 Cs 微调可补偿的范围
   （"提高 Cs 至 0.15–0.18" 建议大概率无效，除非大幅提高）。
5. 综合：Smagorinsky 固定 Cs 配置下，**四档（64/128/256×2 组 Cs）斜率演化随分辨率单调平移**——
   N=64 全程偏陡、N=128 短暂居中、N=256 先平后陡，任何两档组合都无法在同一物理窗口内同时达标 →
   档间不收敛是 **LES 模型/参数的系统性问题，非数值 bug**（全部运行：IC 无散、质量守恒 4.4e-4、
   S3≈−0.36~−0.39 负偏度 = 级联签名、无 NaN）。

## 5. 结论与建议

- **三次两档验证均未达标**：第二次 Cs=0.12（N=256 +17.05%、n=1.693）；第三次 Cs=0.13
  （N=256 +16.94%、n=1.697，档间差 slope 17.9%/n 13.8%）。N=256 斜率演化先平后陡无平台（欠耗散堆积）。
- 四次分辨率/参数组合（64/128 Cs=0.12、128 Cs=0.13/0.14、256 Cs=0.12/0.13）均无收敛的 −5/3 惯性区平台 ⇒
  **本配置（Smagorinsky bgk 固定 Cs, τ=0.501, m0=3 单次 IC）不满足 verified 判据**，继续记录未达标
  （不保存 verified/）。
- 建议（不属本次判定范围）：① 换**动态 Smagorinsky / WALE / 壁适应**等耗散自适应模型（LES 欠耗散
  是模型参数化问题）；② 若要继续固定 Cs 路线，需**大幅**提高 Cs（≥0.18）重扫 128/256 两档
  （0.12→0.13 零增益已排除微调路线）；③ 多 IC 系综平均（statistical convergence，单次 IC 的斜率穿越
  本质是统计涨落）；④ 更长运行（≥3 万步）观察 N=256 晚期是否形成稳定平台。
