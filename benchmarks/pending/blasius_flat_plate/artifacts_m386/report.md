## ① 案例介绍

### 物理背景
均匀流 $U_\infty$ 掠过半无限薄平板的层流定常边界层——经典 Blasius 问题。相似解满足：

$$f''' + \frac{1}{2}f f'' = 0, \quad f(0)=f'(0)=0, \quad f'(\infty)=1$$

其中 $\eta = (y-y_w)\sqrt{U/(\nu x)}$，壁面摩擦系数 $C_f = 2f''(0)/\sqrt{Re_x} = 0.6641146724/\sqrt{Re_x}$。

### 几何与参数

| 参数 | 值 |
|------|-----|
| 格子模型 | D2Q9 |
| 来流速度 $U$ | 0.05 (lu/tu) |
| 运动粘度 $\nu$ | 0.01 (lu²/tu) |
| 松弛时间 $\tau$ | 0.53 |
| 碰撞模型 | BGK / TRT ($\Lambda=3/16$) |
| 网格 | plate200 (240×1400), plate400 (440×1400), plate400_y1600 (440×1600) |
| 板长 | 200 / 400 lu |
| 探针位置 $x_{eff}$ | 180 lu |
| $Re_x$ | 900 |
| 步数 | 30000 + 200步平均 |
| 边界条件 | half-way BB (双侧) + Zou-He 压力出口 + 镜面上下 |

### 参考基准
Blasius ODE RK4 打靶法（$h=0.005$）：$f''(0) = 0.3320573362151963$，$C_f^{ref} = 0.022137$ at $Re_x=900$。

## ⑤ 注意点

### 根因分析
**累积位移效应（边缘加速）**：边界层位移厚度 $\delta^*$ 随 $x$ 增加，导致流道有效截面积收缩，引起边缘加速 $u_{edge}/U > 1$（plate400 探针处达 1.083）。这使得有效 $Re_x$ 增加但误差也增加。

### 关键发现
1. **误差随 $Re_x$ 单调增加**：+24.6% → +27.4%（$x_{eff}$: 30→180）
2. **碰撞模型无关**：BGK ≡ TRT（$\Lambda=3/16$），差异 <1pp
3. **域高无关**：ny=1400 ≡ ny=1600
4. **延长板长无效**：增加 $x_{eff}$ 会增大累积位移效应

### 局限性
- SDAA 设备执行确认（5000 步完成），但全规模网格（240×1400×30000步）超出 120s shell 超时
- 物理数据取自 CPU 验证运行（已独立审计）
- 当前设置无法通过参数调优改善——需引擎级改造

### 适用范围
- 本案例为**外部流**问题，LBM 周期性/受限域设置存在结构性不匹配
- 晋级路径：引入压力修正（SIMPLE/PISO）、外部流假设、或自适应网格
