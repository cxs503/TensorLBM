## ① 案例介绍

**物理背景**：均匀流 U 掠过半无限薄平板的层流定常边界层，Blasius 相似解。

**参数表**：
| 参数 | 值 |
|------|-----|
| U | 0.05 (格子单位) |
| ν | 0.01 |
| τ | 0.53 |
| 碰撞模型 | BGK / TRT (Λ=3/16) |
| 探针 x_eff | 90 (Re_x=450) |
| C_f 参考 | 0.6641/√Re_x = 0.03131 |
| 网格 | 220×150 / 220×400 |

**参考解**：Blasius ODE RK4 打靶（h=0.005），f''(0)=0.3320573362。

## ② 方法

### m410 诊断结论
中域平板+镜像 BC → 通道阻塞 → 边缘加速 → C_f 误差 +27%

### m449 修复策略
1. **壁面安装平板**（y=0）：消除中域平板的双侧边界层位移效应
2. **高域配置**（ny=400）：确保顶部 BC 不影响边界层发展
3. **对称 BC**（顶部）：f[:,−1,:] = f[:,−2,:][spec]
4. **Half-way BB**（底部壁面）：标准无滑移条件
5. **Zou-He 压力出口** + **平衡态入口**

### 工具链
- tensorlbm 库（D2Q9, collide_bgk, stream, zou_he_outlet_pressure）
- CPU 验证（无 SDAA 设备访问权限）

- **边缘加速非根因**

## ④ 结果分析

### 误差来源分解

1. ~~边缘加速~~（已排除：u_edge/U=1.0 时误差仍 +35%）
2. ~~碰撞模型~~（BGK vs TRT 差异 <1%）
3. ~~域高~~（ny=150→400 误差无改善）
4. **固有离散误差**（LBM D2Q9 + half-way BB + 均匀入口的数值误差）

### η 剖面
壁面安装配置的 η 剖面 L2 误差 ~0.24，与中域配置相当。

## ⑤ 注意点

### 踩过的坑
1. m410/m106 的根因诊断（边缘加速主导）**不正确**——消除边缘加速后误差未改善
2. 壁面安装配置并未优于中域配置——误差来源更深层
3. CPU 计算速度慢（220×400 网格 10000 步需 106s），无法进行大规模网格收敛测试

### 局限
- 仅在 CPU 上验证，未在 SDAA 设备上测试
- 网格分辨率有限（Δx=Δy=1 格子单位）
- 未尝试高阶边界条件（interpolated BB）或非均匀入口

### 适用范围
- 当前 LBM 设置（D2Q9, BGK, half-way BB）的 C_f 精度极限约 +27~35%
- 要达到 <3% 精度需要引擎级改造

| 关键量 | 基准 | 计算值 | 误差 | 是否<3% |
|--------|------|--------|------|---------|

| u_edge/U (m449 ny=400) | 1.000 | 1.000 | 0.00% | ✅ 是 |

**判定：HONEST-FAIL**

无法通过调整域尺寸或边界条件达到 <3% C_f 误差。误差来自 LBM 数值方法的固有离散误差，需要引擎级改造（高阶边界条件、非均匀入口、网格加密等）。

## 晋级路径

1. **Interpolated bounce-back**：减少壁面位置误差
2. **非均匀入口剖面**：从 leading edge 开始发展边界层
3. **高阶碰撞模型**：cumulant / central-moment
4. **Leading edge 网格加密**：捕捉边界层发展
5. **SDAA 硬件验证**：可能具有不同的数值行为
