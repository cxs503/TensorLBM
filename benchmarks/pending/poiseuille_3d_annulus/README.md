# 3D 环隙 Poiseuille 流（D3Q19）— 解析验证（not_verified 复合判决）

Wave-3（W3-B）复活重跑（旧 pending 档 Cl 不可考的粗扫被本预注册阶梯替换）。
同心环隙 a/R_o=0.5，R_o=20/40/80 三档，直接模拟 vs **精确解析解**（自推）。

## 解析解（自推，无文献数据依赖）

$$u(r) = \frac{G}{4\nu}\left[R_o^2 - r^2 + \frac{R_o^2-a^2}{\ln(R_o/a)}
\ln\frac{r}{R_o}\right],\qquad
Q = \frac{G\pi}{8\nu}\Phi,\quad \Phi = R_o^4-a^4-\frac{(R_o^2-a^2)^2}{\ln(R_o/a)}$$

## 判定方法（NOTES.md 预注册）

1. **CH1 主通道 = 全剖面反演有效几何**（taylor_couette / poiseuille_3d_pipe 的
   $R_{\text{eff}}$ 方法论移植到双参数几何）：楼梯壁两参数不能由单一积分观测量
   辨识（椭圆教训），故用 3 参数解析族 $u=c_0+c_1\ln r-c_2r^2$ 对中心 bin
   （名义解析 $|u|>0.2U_{\max}$）加权 LSQ，取两个无滑移根 = 有效半径
   (δ_i, δ_o)；梯度锚定施加流量 $G_Q = 8\nu Q_{\text{meas}}/(\pi\Phi)$；
   参考解 = (δ_i, δ_o, $G_Q$) 的精确解。
2. **CH2 名义帧直评**：名义几何 + $G_{\text{nom}}$（由 $\bar u=u_{\text{in}}$），
   单独报告。
3. 判决规则：主通道每档 ≤3% 且单调；**反演偏移跨档 spread ≤0.05 格**（复合判决
   条款）。

## 配置

D3Q19 BGK τ=0.8，u_in=0.02，L/R=6，测量面 x=nx/2（径向分环逐 bin 平均）。
Zou-He 速度入口/压力出口 + 库 `bounce_back_cells_3d`；入口洁净实证见披露 3。

## 判决

**not_verified（复合）**：δ_i 跨档 spread 0.0937 > 0.05 违反预注册"格无关"
条款（δ_o spread 0.0401 过线）—— 尽管主通道误差判据本身全过。

**根因（诊断链 + 90k 步站点平稳性证明，非欠收敛）**：内壁楼梯**曲率**致 δ_i
真实 O(1/R) 漂移（−0.381 → −0.322 → −0.287，比 1/R 略慢）；R20 加长至 90000 步
δ_i 仅移 1e-5；拟合阈值 0.15–0.30 + 全箱敏感性 ≤0.02 格；名义帧最佳缩放后残差
7.7%（R20）→ 形状失配排除，纯几何偏移主导。**平壁对照**：矩形管 da/db 跨档
spread 0.036（格无关，verified/poiseuille_3d_duct）—— 漂移是曲壁楼梯的固有
物理，非实现缺陷。预注册条款不容此漂移 → 诚实报败留 pending；条款是否放宽
（如 δ_i 允许 O(1/R) 一阶收敛）留 owner 裁定。

## 披露

1. eff 通道在控制器独立复算（独立加权 LSQ + 二分求根实现）下逐位复现；
   逐点相对口径 1.56/0.46/0.17% 同样全过单调。
2. 质量漂移 3.2/1.5/0.7% = Zou-He 稳态密度抬升（物理 G·nx/(2c_s²)），Q 沿 x
   +1.7% 同源，不影响反演稳定性。
3. **入口洁净实证**（staging `annulus/diag_ann_stations.json`，R80）：x=160–460
   各站点 δ_i/δ_o/eff 完全平坦且与正式扫描逐位一致 → 中面测量无入口污染。
4. 近出口发展度偏差 fd_max 3.5/2.0/1.1%（出口 Zou-He 局部效应）。
5. 反演敏感性（合成 ±0.3% 形状扰动）δ 移位 ≤0.011 格。
6. 全部 bin 变体（δ_i−a = −0.407/−0.342/−0.298）同漂移结构，中心 bin 选择无关。
