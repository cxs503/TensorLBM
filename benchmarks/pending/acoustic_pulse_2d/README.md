## 参考解（独立仪器）

线性化 2-D 波动方程，初值 `p(r,0)=A c_s^2 exp(-r^2/2σ^2)`、`p_t(r,0)=0`：

```
p(r,t) = A c^2 σ^2 ∫_0^∞ e^{-k^2σ^2/2} J0(k r) cos(c k t) k dk
```

（Hankel 变换对的解析结果：高斯初值的 Hankel 变换仍是高斯。）**不含任何 LBM 代码路径**。
参考解自己必须被复核，三路：
1. `t=0` 解析恒等式 → 相对误差 8e-5；
2. `scipy.integrate.quad`（另一族求积）逐点对照 → 1e-5 量级；
3. 独立显式二阶差分求解 `p_tt = c^2 ∇²p`（257²，Courant 0.5）→ **L2 0.326% / 峰值 0.358%**。

## 为什么包络门不过（诚实交代，不粉饰）

钉死的探针窗 r=30..90 内 **精确解自身的指数也只有 −0.471…−0.480**，即该窗口尚未进入
r^(-1/2) 渐近区；因此 3.3–5.4% 的偏差是**仪器窗口标定问题**，不是求解器缺陷。按本仓纪律
（未达 3% 不入 verified/）本案留在 pending/，并把该结论钉进测试
`test_real_axis_quadrature_is_limited_to_the_light_cone` 与 README，避免后人误用。

## 关键限制（后续使用者必读）

* 实轴 Fourier–Bessel 积分在 **r > c t（光锥外）严重病态**（k 区间强抵消），数值上给出与
  真实值同量级的伪场——它是积分表示的固有病态，不是物理。所有指标窗都限制在 r ≤ 0.8 c t。
* τ=0.52 时 ν=0.00667，k≲0.15 的粘性衰减 180 步内 <1%（与观测到的 0.4–0.8% 波形误差同量级），
  σ 越小（谱含量越高）误差越大——σ=8 档 0.824% 已经给出"高谱含量下 <3% 门仍有余量"的证据。
* 单相、等温、小振幅（δu/c_s ~ 1e-5），不含非线性声学与热粘性边界层效应。
