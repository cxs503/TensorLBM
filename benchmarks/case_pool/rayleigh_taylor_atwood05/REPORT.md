## ① 问题与 ref 出处

**物理**：重力场中重流体（ρ₁）位于轻流体（ρ₂）之上，界面给单模扰动（波长 λ，初始幅值 a₀ = 0.01λ），Atwood 数 A = (ρ₁−ρ₂)/(ρ₁+ρ₂) = 1/2。本题要判的量是**界面（尖峰一侧）小振幅增长率** σ：a(t) = a₀e^{σt}。A = 1/2 是本算例锚定值——它是单模 RT 里非线性最早介入的情形（(1−A)/(1+A) = 1/3），也是本仓既有算例 `rayleigh_taylor` 只当过敏感性支臂、且在旧相位输运格式下发散的工况。

**ref 出处（谱系 + 零手抄）**：任务锚点 = Tryggvason 谱系（谱方法 DNS 的 RT 校验链）。锚定文献 = Tryggvason, Scardovelli & Zaleski, *Direct Numerical Simulations of Gas–Liquid Multiphase Flows*, Cambridge University Press, 2011。该书正文在本沙箱**不可取得**（无出版商访问权；DOI 仅解析到元数据），因此**不著录任何页码/表号、也不从书上转抄任何数字**——这一点在 ⑥ 记 MU。取而代之，`ref/ref_lock.py` 做了两件可核验的事：

1. 用 Crossref API 取回该书的**书目记录**并存档哈希（`sources/crossref_tryggvason_2011.json`, sha256 `9d71e441335266b3…`, DOI `10.1017/cbo9780511975264`）——引用可核查；
2. 参考值全部由**闭式公式在代码里求值**（不是抄表）：

```text
L 线性（正常模态）增长率，等黏度修正（Chandrasekhar 1961 §92）
    sigma_inv  = sqrt(A g k)
    sigma_visc = sqrt(A g k + nu^2 k^4) - nu k^2 ,   k = 2 pi / lam
    出处: Rayleigh 1883 Proc. London Math. Soc. 14:170; Taylor 1950 Proc. R. Soc. A 201:192;
          Chandrasekhar 1961 Hydrodynamic and Hydromagnetic Stability sec. 92
N 非线性饱和尖峰/气泡速度（势流 Layzer-Goncharov），按 arXiv:2009.14655 Eq.(1), p.3 原文形式
    u_s = sqrt(2 A g / ((1-A) C k)),   u_b = sqrt(2 A g / ((1+A) C k))
```

常数约定：二维 C = 1（`ref_lock.C_2D`）。同仓兄弟算例 `rayleigh_taylor/ref/ref_lock.py` 锁的是 C = 3（三维 Layzer 常数，其自洽校验 `sqrt(1/(3π))` 也是三维值）；在二维用它会把势流速度系统性低估 √3 倍。本单把两种约定都打印出来（④ 表末两列），不隐藏分歧。

## ② 方法与实现

**复用，不另起炉灶**：求解器是仓内既有能力 `tensorlbm.rayleigh_taylor`——Boussinesq 双层 D2Q9 流动（浮力只以偏差项 `F_y = −A g φ` 进入，静水压扣除）+ 界面输运。本单只写驱动与判据：

| 文件 | 作用 |
|---|---|
| `ref/ref_lock.py` | 取回并哈希锚定文献书目记录；闭式参考值逐点求值；写 `ref/ref_lock.json` |
| `run_case.py` | 7 例参数化驱动 + 预注册判据；多拟合窗 σ、瞬时增长率、ν_eff 反演、前沿速度 |
| `postprocess` 等价物 | `run_case.py --aggregate` 从 `case.json` 重建 `summary.json` / `acceptance_table.md` |
| `make_figures.py` | 图 1–4（场云图由 `--snapshots` 重跑参考例落盘 npz 后绘制）|
| `make_report.py` | 从工件生成本报告（零手抄）|

**测量方法（关键）**：

* 界面高度用 `φ = 0` 等值线 `y_int(x)`（库内 `interface_zero_crossing`），其第一 Fourier 模态幅值 a/λ 作为界面幅值——等值线对体内膨胀不敏感；另用守恒柱高矩 `a_col` 作独立交叉核对（两估计量都写进 `history.csv`）。
* σ 由 `ln a` 对 t 的最小二乘斜率给出，**四个预注册拟合窗**并行报告：`legacy [0.010,0.050]`（兄弟算例的旧窗，作对照）、`primary [0.020,0.080]`（本单主判据）、`late [0.040,0.120]`、`late2 [0.060,0.160]`。主窗刻意上移一个初始幅值：A = 1/2 的线性区大约到 a/λ ≲ 0.1，而 t≈0 的头半个 e-folding 被（i）tanh 界面向 Allen–Cahn 平衡型的松弛与（ii）播种本征模与声场的能量交换污染。该选择是**开工前**由上述论证定的，不是看到结果后调的。
* 瞬时增长率 σ_inst = d ln a/dt（25 采样点中心窗），直接暴露“先爬升（启动瞬态）→ 平台 → 衰减（非线性）”的三段结构（图 2）。
* 由测得的 σ 反演等效黏性 ν_eff（`ref_lock.nu_eff_from_sigma`，等黏度色散关系的解析逆），把“数值耗散多少”变成一个可直接与 ν_lattice 比的数。

**读数（由上面两张表与图 2 直接读出；下列结论均为程序化计算，非事后挑选）**

1. **拟合窗效应**：同一批算例上，旧窗 [0.01,0.05] 与主窗 [0.02,0.08] 的误差差 0.15–4.56 个百分点（逐例见 ④ 第二表）；旧窗**全部**更偏负（是）。瞬时增长率曲线（图 2）显示 σ_inst 先爬升、在 a/λ≈0.03–0.05 附近成平台、随后因非线性而衰减；旧窗以初始幅值 a₀ 为下界，把爬升段一并纳入最小二乘，故系统性偏低。这是**测量口径**问题，与求解器精度无关。

3. **流速侧估计量（|u_y| 一阶模态，同一时间窗）与界面侧估计量的差**：-3.05–+0.99 个百分点（逐例见 ④ 表末 `sigma_flow(uy)` 列）。流速模态不经过任何界面输运模型，它的增长率若同样偏低且量级相当，则说明偏差在**流动/浮力耦合**一侧；若流速侧明显更接近理论，则偏差来自**界面输运模型**。上面的数字给出直接判读（结论见 ⑥ F5）。
4. **黏性支臂**：ν=0.0017: -9.26%，ν=0.0100: -11.01%——两者都落在门内，说明库内 BGK 黏性与等黏度色散关系的对应（ν=(τ−1/2)/3）在 A=1/2 下仍然成立。
5. **重力支臂**：g 减半（2.0e-04→1.0e-04）后 σ_sim 2.7725e-03→1.8768e-03（比值 0.677，√2 归一应为 0.707），误差 -13.43%（门内）——线性响应按 √(Ag) 缩放。
