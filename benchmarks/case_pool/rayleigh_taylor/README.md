## ① 问题与 ref 出处

**物理**：重力场中重流体（ρ₁）位于轻流体（ρ₂）之上，界面带单模扰动（波长 λ、初始幅值 η₀=0.01λ、
Atwood A=(ρ₁−ρ₂)/(ρ₁+ρ₂)）。两个可判据的量：

1. **线性增长率**：a(t)=a₀e^{σt}，σ_inviscid=√(Agk)，等黏度修正 σ_visc=√(Agk+ν²k⁴)−νk²，k=2π/λ
   （Rayleigh 1883 PLMS 14:170；Taylor 1950 Proc. R. Soc. A 201:192；Chandrasekhar 1961
   *Hydrodynamic and Hydromagnetic Stability* §92）。
2. **非线性饱和尖峰/气泡速度**（任务书所称"尖峰气泡增长率"）：Goncharov (2002) PRL 88:134502 势流模型，
   按 arXiv:2009.14655 **Eq. (1), p.3** 原文形式

   ```text
   u_s = sqrt( 2 A g / ((1-A) C k) )      u_b = sqrt( 2 A g / ((1+A) C k) )      C = 3 (2-D)
   ```

**零手抄与常数锁定**：`ref/ref_lock.py` 把两式写成代码并在运行时求值，写入 `ref/ref_lock.json`
（16 行参考值表 + 源抽取片段 SHA-256）。几何常数 C 是唯一有转写风险的量，用**独立文献数值反证锁定**：
arXiv:1910.03663 **Fig. 3 caption, p.6** 给出二维势流气泡值 `Fr_B = sqrt(1/(3π))`，其定义为
`Fr_B ≡ U_B/√(A g λ/(1+A))`；代入 C=3 得 `sqrt(2/(C·2π)) = sqrt(1/(3π))`，相等至 1e-15
（`ref_lock.py` 内 assert，失败即退出）。源片段：`ref/sources/arxiv_2009.14655_eq1_p3.txt`、
`ref/sources/arxiv_1910.03663_fig3_caption_p6.txt`。

**出处诚实声明（重要）**：任务书锚点写作"He/Doolen/Ding 文献尖峰气泡增长率"。本沙箱**无出版商访问权**
（pubs.aip.org / link.aps.org 均 HTTP 403），该文原表原页**未能取得**；据记忆转写页码与数值＝伪造，
故本单**不著录该文表号/页码**，改用上述可核验闭式理论（也正是 LBM 文献比对的物理基准）。此为 MU，记入 ⑥。

## ② 方法与实现

**求解器（复用，不另起炉灶）**：`src/tensorlbm/rayleigh_taylor.py` — D2Q9 双分布：流动分布只施加
Boussinesq 浮力偏差 `F_y=−A g φ`（平均静水压扣除，参考密度恒 1）；相场按 `g_i^eq = w_i φ(1+3c_i·u)` 输运
（D=c_s²(τ_φ−½)）；上下半程反弹固壁、x 周期；初始线性本征模态（`seed_eigenmode=True`）只激发增长模。

**本单新增（全是驱动与判据，不是求解器）**

| 文件 | 作用 |
|---|---|
| `run_case.py` | 6 例参数化驱动 + 预注册判据。界面由**守恒重流体柱高** N(x)=Σ_y(1+φ)/2 取 y_int=n_y−N；气泡前沿 h_b=max y_int−⟨y_int⟩、尖峰前沿 h_s=⟨y_int⟩−min y_int；σ 用库内对数线性拟合（窗口 a/λ∈[0.01,0.05]），u_b/u_s 用 τ∈[4,6] 线性斜率 |
| `postprocess.py` | 从已写出的 `history.csv` 重算（不重跑）：救回"晚期发散、线性窗口完好"的算例，并记录 `blowup_tau` |
| `ref/ref_lock.py` | 参考值锁定 + C 常数反证（见 ①） |
| `make_figures.py` | 图 1–3（线性拟合+判据条形图、前沿与尖端速度、场快照） |

**运行前探测发现并改掉的三处设计缺陷（记入 ⑥ F1–F3）**：(a) 3λ 深盒子 τ≈3 气泡即撞壁，够不到 τ∈[4,6]
→ 改用**长宽比 8** 盒子（与 arXiv:1910.03663 同）；(b) g=2e-3 时相场过冲使 |φ|→4 并在 τ≈3 变 NaN
→ 速度尺度降到 g=2e-4；(c) torch 默认 128 线程池跑小张量慢 20×（0.117→0.005 s/step），固定 4 线程。

**repro_cmd（一键复现）**

```bash
cd <repo>
python3 benchmarks/case_pool/rayleigh_taylor/ref/ref_lock.py       # 参考值锁定 + C 反证
python3 benchmarks/case_pool/rayleigh_taylor/run_case.py           # 6 例全跑（串行 ~10 min，CPU）
python3 benchmarks/case_pool/rayleigh_taylor/postprocess.py        # 从 history.csv 重算判据
python3 benchmarks/case_pool/rayleigh_taylor/make_figures.py       # 图 1–3
```

## ⑥ 失败模式、工件与生态摩擦

**失败模式**

- **F1 相场无界 → 速度过高/发散**：`g_i^eq = w_i φ(1+3c_i·u)` 无界面锐化、无自由能项，|φ| 随形变单调增长
  （基准 1.71；A=1/2 达 −341/+318），越界的 φ 又经浮力 `F=−Agφ` 反馈 → 终端速度高估 1.6–2.5×，
  最终 Ma 冲破 1 → NaN（τ_blowup：λ=128 → 6.15，A=1/2 → 7.16，g=2e-3 初版 → ≈3）。
- **F2 丢失 Atwood 非对称性**：u_s/u_b 实测 1.12（A=1/3）/1.00（A=1/2），理论 1.41/1.73。与 F1 同源：
  两侧都被同一放大的弥散通量主导，气泡/尖峰差异被抹平。
- **F3 盒子深度不足**：3λ 深盒子 τ≈3 气泡撞壁，够不到文献窗口 τ∈[4,6]（初版六例 NaN 现场留档于
  `artifacts/runs_blowup_diag_g2e-3/`）。

**建议修复（未在本单实施，避免"另起炉灶"）**：给相场加界面锐化（Cahn–Hilliard/自由能项，或压缩通量
`u_sharp ∝ −∇φ/|∇φ|·(1−φ²)`），或改走仓内 `sc_phasechange` / 锐界面路线；修好后本算例的非线性判据
（u_s/u_b）即可启用。已登记为生态缺口。
