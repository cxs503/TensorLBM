# B31: 等温 Sod 激波管（D2Q9，已达标 verified/）

## 物理问题

一维激波管：初始 x=nx/2 处密度间断 ρ_L=1.0 / ρ_R=0.25（**密度比 4:1**），速度 u=0，
分布函数取平衡态 `f=feq(ρ,u)`（精确单元间断，无人工抹平）。τ=0.8（ν=0.1），ny=4（y 向均匀）。

**参照解是等温 Riemann 解析解，不是 γ=1.4 经典 Sod 解**——D2Q9 平衡态强制等温
EOS p=ρ/3（cs²=1/3，无能量方程、温度固定），因此其正确参照是 p=c_s²ρ 的等温
Riemann 问题（激波 + 稀疏波，无接触间断；经典 Sod 的 γ=1.4 解物理上不适用）。

等温 Riemann 解（左态 ρL、右态 ρR）：
- 激波密度比 r 满足  ln(ρL/(r·ρR)) = (r−1)/√r
- 中间态 ρ* = r·ρR，u* = cs·(r−1)/√r
- 激波速度 W = cs·√r（须 < 1 = 格点最大离散速度）
- 稀疏波：头波 s=−cs，尾波 s=u*−cs，扇内 ρ = ρL·exp(−(s+cs)/cs)

本配置（4:1）解析值：ρ*=0.49662，u*=0.40410（**Ma_mid = u*/cs = 0.70**），W=0.81373。

支持（y 周期无影响，x 周期产生镜像 Riemann 问题——见下）。

## 周期边界与测量口径（本案例关键）

周期 x 边界在 x=0 处产生**镜像 Riemann 问题**（左右态反转）。其波系污染主解区：
- 镜像稀疏波头从 x=0 以 +cs·t 右行 → 干净区下限 x > cs·t
- 镜像激波从 x=nx 以 W·t 左行 → 干净区上限 x < nx − W·t

所有指标只在干净区 [cs·t, nx−W·t] 内计算（nx=2000 取 t≤400、nx=4000 取 t≤800 时
该区非空且覆盖主解全支撑）。激波位置在窗口 [xd+0.5·W·t, xd+1.5·W·t] 内取
|∂ρ/∂x| 最大格。

## 记录的限制（本模型固有）

1. **等温 EOS**：D2Q9 无能量方程，温度固定——不能表示 γ-law 气体、无接触间断、
   无激波熵增。经典 γ=1.4 Sod（ρ_L=1,ρ_R=0.125,p_L=1,p_R=0.1）**不在本模型能力内**。
2. **激波马赫上限**：等温激波 W=c_s√r 必须 <1（格点最大速度）→ 单一激波密度比
   r<3；本 4:1 管的激波 r≈1.985 可表示，但 8:1 管（r≈2.77，Ma_mid=1.06）在
   step 50 内负密度发散（τ=0.8/1.0/1.5 均失败）；16:1 管 u*>√(2/3)≈0.816 平衡态
   正性界限、W>1，完全不可表示（step 20 发散）。
3. **激波捕获**：BGK 无限制器，激波处有 ~2.6%Δρ 的局部振荡（本案例 ≤3% 仍达标），
   更强激波振荡增大直至发散。
4. **τ 稳定性边界**（4:1 管）：τ=0.55 → step 200 发散、τ=0.6 → step 400 发散、
   τ≥0.65 稳定。低 τ（低粘）在强梯度下 BGK 失稳。
