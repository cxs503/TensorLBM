## 归因结论

### 判定: 分辨率受限 (NOT 实现缺陷)

**证据链**:
1. **壁面集中**: wall_err (5.0%) >> core_err (1.8%), 误差集中在 Stokes 层内前 2 行
2. **幅值主导**: amp_rel (4.87%) >> phase_err (1.03°), 符合边界层分辨率不足的典型特征
3. **单调收敛**: H=29→59→119 误差单调下降 5.04%→2.92%→0.45%
4. **δ/Δx 阈值**: δ/Δx < 2 时误差 >3%; δ/Δx ≥ 3.7 时误差 <3%
5. **scan_out 交叉验证**: 全 skip 数据 (27 periods) 与短 skip 数据趋势一致

### honest-FAIL 声明

m110 (H=29, α=8) 的 4.890% 误差 **不是实现缺陷**, 而是 Stokes 层分辨率不足导致的
可解释物理误差。在 δ/Δx < 2 的网格下, LBM 无法充分解析 Womersley 边界层的指数衰减剖面。

### 建议

- α=8 工况要求 δ/Δx ≥ 3, 即 H ≥ 48 (对 α=8)
- 当前 benchmark 的 H=59, 119 配置已满足此要求, 全部 PASS
- H=29 配置应标记为 "resolution-limited" 而非 "failed implementation"
