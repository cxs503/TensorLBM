## 3. 为什么达不到 3%（分辨率主导，非 τ/碰撞模型主导）

- 锚 Re 匹配把晶格黏度钉死在 ν_lb = u_lb·L/Re ⇒ τ−0.5 = 1.24e-6 / 1.44e-6 / 1.65e-6（三档），
  即 τ 触 1/2 地板；首层格心 y⁺ = 2319 / 1988 / 1739 ⇒ 整个黏性底层亚网格；
  边界层厚度 δ ≈ 1.4–1.8 格。
- 同一 L、抬 Re 的探针（L=48，20 步，两 closure）：C_T 从 Re=1e3 一路塌到 Re=1.16e7
  （见 `fig_1_re_sweep_L48.png`）；MRT 与 MRT+Smagorinsky 在锚 Re 差 0.17% ⇒ **碰撞/闭合模型不是主导项**。
- 达到 y⁺≈500（壁模型可用域）需 L≈445（≈2.35e9 胞、166 GiB 分布函数、比最细档每维 3.5 倍）；
  壁解析（y⁺≈1）需 L≈2.2e5（10^17 胞）——物理上不可行，必须壁模型 + 多卡。
