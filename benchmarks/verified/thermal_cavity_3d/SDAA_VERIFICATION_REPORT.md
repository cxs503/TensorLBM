## ① 案例介绍

### 物理背景
3D 差热立方腔自然对流是自然对流 benchmark 问题的标准测试案例。立方腔内充满 Pr=0.71 的流体（空气），左壁维持高温 T_hot=1.0，右壁维持低温 T_cold=0.0，上下前后四面绝热，所有壁面无滑移。浮力驱动流体形成对流环，最终达到稳态。

### 几何与参数
- **几何**: 立方腔，边长 L = N-1（节点数 N）
- **网格**: N = 32, 48, 64, 96, 128（多网格阶梯）
- **Rayleigh 数**: Ra = 1e3, 1e4, 1e5（三个阶梯）
- **Prandtl 数**: Pr = 0.71
- **碰撞时间**: τ_f = 0.6（速度场），τ_T 自标定（温度场）

### 数值方法
- **速度场**: D3Q19 BGK 碰撞模型
- **温度场**: D3Q7 被动标量模型（W=[1/4, 1/8×6]）
- **边界条件**: 
  - 速度壁：全反弹 bounce-back（post-collision）
  - 温度壁：节点等温（#303 修复版）
- **浮力**: 碰撞后原始增量（无 Guo 因子），仅作用于流体节点（force_mask）
- **Nu 计算**: 整壁一阶差分（grad1），面积平均，Nu = (Nu_hot + Nu_cold)/2

### 参考值
参考值来自六源文献簇中位（Jiménez-Islas et al. 2014 Table 3）：

| Ra | 簇中位 Nu |
|----|-----------|
| 1e3 | 1.07065 |
| 1e4 | 2.05552 |
| 1e5 | 4.34110 |

## ⑤ 注意点

### 踩过的坑
1. **力掩码必需**: 不使用 force_mask 时，反弹壁节点被持续灌注浮力，导致慢线性不稳定（NaN @ 17k/55k/131k 步 for N=32/48/64）
2. **壁节点宏观速度置零**: 温度碰撞前必须将壁节点宏观 u 置零（#300 2D 同款修复），否则温度场污染
3. **bb=post 配对**: 全反弹 bounce-back 必须在 streaming 之后施加（壁在节点上），与 #303 节点等温温度壁同位配对；半程 pre-bounce 变体会导致壁位错位（一阶收敛）

### 局限
1. **计算成本**: 完整阶梯（9 案，最高 800k 步 N=128）在 SDAA 上需约 10 小时/案，总计 >90 小时
2. **高 Pr 能力档**: Pr=100/1000 无公开解表可锁（Turan et al. 只有 correlation），仅为稳定性披露
3. **τ 不变性**: τ=0.9 时 Ra=1e5 达 Ma=0.22，可压缩性误差 ~-1.7%，故判据档统一用 τ=0.6

### 适用范围
- **Pr**: 0.71（判据档），100/1000（能力披露）
- **Ra**: 1e3 - 1e5（判据档）
- **网格**: N ≥ 32（判据档），N ≥ 64（推荐）
- **设备**: CPU/CUDA/SDAA 均可（算法设备无关）
