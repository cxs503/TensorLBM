## 1. 物理问题

简单立方周期球阵列的 Stokes 渗透率——二维周期圆柱方阵渗透率（`verified/permeability/`）
的三维对应。参考 = **Zick & Homsy 1982**（JFM 115:13–26）无量纲曳力表：

    K(φ) = F / (6πμUa)

U = 表观（Darcy）速度，a = 球半径，φ = 真实固相分数。

## 3. 计算方法

D3Q19 BGK，τ=1.0（ν=1/6 精确），全周期单胞；球 mask 由 `make_spheres_3d` 生成。
步序：collide → stream → 掩码体力 → bounce-back。

物理核全部来自库共性路径：
- `tensorlbm.solver3d.collide_bgk3d`
- `tensorlbm.solver3d.stream3d`
- `tensorlbm.boundaries3d.bounce_back_cells_3d`
- `tensorlbm.d3q19.equilibrium3d`
- `tensorlbm.d3q19.macroscopic3d`

唯一 driver 层转写为 3D 体力（库无 3D 单相助手，一阶 Guo/Luo 形）。
测量映射：⟨u_x⟩_fluid → U = (1−φ)⟨u_x⟩ → k_sim = ν(1−φ)⟨u_x⟩/a_body
→ K_sim = ν(1−φ)⟨u_x⟩/a_body × 6πa_nom/(νN³) × N³
→ err = |k_sim/k_ref − 1|
