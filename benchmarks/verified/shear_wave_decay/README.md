# B30: 2D 衰减剪切波基准（验证 1D 粘性耗散）

**状态：✅ 已验证（真实模拟，无外推、无人工修正）**

## 物理问题

周期域 [0,H)²（晶格单位 H=N, Δx=Δt=1）上的 2D 衰减剪切波，是
不可压 Navier–Stokes 方程的**精确解析解**（纯剪切 u·∇u ≡ 0，无涡拉伸，
非线性项恒为零，只剩线性粘性衰减）：

```
u(x,y,t) = U0·sin(ky)·e^{-νk²t},   v ≡ 0
ν = (τ − 1/2)/3,   k = 2π/H
```

## 衰减率（与 Taylor–Green B17 的关键区别）

| | Taylor–Green (B17) | 衰减剪切波 (B30) |
|---|---|---|
| 波矢 | (±k, ±k) 四模叠加，\|κ\|² = 2k² | 单模 (0, k)，\|κ\|² = k² |
| 速度衰减率 | γ_vel = **2νk²** | γ_vel = **νk²** |
| 动能衰减率 | γ_E = **4νk²**（E ∝ u² 翻倍） | γ_E = **2νk²** |
| 非线性项 | u·∇u ≡ 0（TG 涡） | u·∇u ≡ 0（纯剪切，无涡拉伸） |

本 benchmark 拟合 **ln(u_max) vs t** 得 γ_vel_sim，对比 **γ_vel_theory = νk²**
（主指标）；同时拟合 **ln(E) vs t** 得 γ_E_sim，对比 **2νk²**（交叉验证，
E(t) = U0²/4·e^{−2νk²t}）。纯剪切无涡拉伸，衰减应比 TG 更接近解析。

## 判定标准

| 指标 | 公式 | 阈值 |
|------|------|------|
| 速度衰减率偏差 | \|γ_vel_sim/γ_vel_theory − 1\| | ≤ 3%（任务书标准） |
| 动能衰减率偏差（交叉验证） | \|γ_E_sim/γ_E_theory − 1\| | ≤ 3% |
| 网格收敛 | \|err\| 随 H 增大单调下降（H=64 → 128） | 必须 |
| 指数衰减质量 | ln u_max vs t 线性拟合 R² | ≥ 0.999 |

真实模拟：u_max 与动能 E 每 100 步由 `macroscopic` 实测记录，无任何外推/修正。
BGK 离散 O(k²)/O(k⁴) 修正若存在会使 γ_sim ≠ γ_theory，偏差符号如实报告。

## 配置（标准案例，两档网格同一物理参数）

- 网格：**H=64×64 与 H=128×128**，周期边界（solver `stream()` 模运算内建，无额外 BC）
- 初始场：u = U0·sin(2πy/H)，v=0，ρ=1，f = `equilibrium(ρ,u_x,u_y)`（feq 初值）
- 速度：U0 = 0.05（Ma ≈ 0.087，压缩性误差 O(Ma²)）
- τ = 0.8 ⇒ ν = (τ−1/2)/3 = 0.1（直接用 ν 定 τ，不经 Re）
- k = 2π/H（H=64 → 0.09817；H=128 → 0.04909）
- 碰撞：BGK（`collide_bgk`）；流步：`stream`；精度：float32（库默认）
- 步数：自动按 u_max/U0 → e⁻³ 衰减确定（H=64 → 3200 步；H=128 → 10000 步，任务范围 2000–10000），每 100 步记录
- 共性模块路径（三路径之二——库 solver 路径，**零手写 collide/stream/平衡态**）：
  `tensorlbm.solver.collide_bgk` + `tensorlbm.solver.stream` +
  `tensorlbm.d2q9.equilibrium` + `tensorlbm.d2q9.macroscopic`

## 结果（2026-08-18 实测，见 result.json + case_H*.json + energy_history_H*.csv）

| H | γ_vel_sim | γ_vel_theory=νk² | err_vel | γ_E_sim | γ_E_theory=2νk² | err_E | R² |
|---|-----------|------------------|---------|---------|------------------|-------|-----|
| 64 | 9.643210e-04 | 9.638286e-04 | **+0.0511% ✅** | 1.928665e-03 | 1.927657e-03 | +0.0523% | 1.000000 |
| 128 | 2.409842e-04 | 2.409571e-04 | **+0.0112% ✅** | 4.819702e-04 | 4.819143e-04 | +0.0116% | 1.000000 |

- **网格收敛**：err_vel 随 H 翻倍从 +0.051% 降到 +0.011%（≈4.5×，单调下降），
  两档均 ≪ 3% → **PASS 达标**
- **指数性**：半窗口斜率一致（H=64: 9.643236e-4 / 9.643164e-4，H=128: 2.409861e-4 / 2.409835e-4），
  R²≈1.0 —— 纯指数衰减，非拟合假象
- **质量守恒**：质量漂移相对值 2.0e-5（H=64）/ 9.2e-5（H=128）
- **偏差符号**：γ_sim **略大于** γ_theory（+0.05%~+0.01%）——BGK 离散等效粘性在该
  参数区略高于 (τ−1/2)/3，是离散格式修正的真实测量，如实记录不修正。
  注意与 TG（−0.035%，γ_sim 略小）符号相反——不同波矢/模态的离散修正方向不同。

### 补充扫描（见 scan_summary.json）

- **U0 敏感性**（Ma 0.087→0.174）：H=64: +0.0511%→+0.0511%；H=128: +0.0112%→+0.0123%
  —— 线性区无 Ma 依赖（纯剪切无非线性项，符合理论预期）
- **精度检查**：float64 对照 H=64 err_vel = +0.0514%（与 float32 差 0.0003%，舍入误差可忽略）
