# B1/B3: 静态液滴 Laplace 基准（CAC 相场两相 LBM，Route-B σ 标定）

**状态：✅ 已验证（真实模拟，无外推；σ 经 Route-B 一次性自校定，语义见下）**

## 物理问题

周期立方域中心放置静态液滴，CAC（conservative Allen–Cahn）相场两相
LBM 演化至稳态。液滴内外压差满足 **Young–Laplace 方程（3D 球）**：

```
Δp = p_in − p_out = 2σ / R      σ_rec = Δp · R / 2
```

对同一 σ 输入测多个半径 R 与多个密度比的 σ_rec：**σ_rec 恢复目标值且
R 无关、ρ 比无关**，即表面张力物理一致。

- B1（R 迁移阶梯）：R = 20 / 32 / 48，128³，密度比 100（ρ_l=1, ρ_g=0.01）
- B3（密度比迁移）：ρ 比 = 10 / 100，96³，R = 20
- 压力采样带：界面内 φ>0.9 / 界面外 φ<0.1，避开弥散界面；R 取名义半径
- 估计窗：末 2000 步（4 个采样，每 500 步采样）；共 12000 步

## 模型

- **CAC/HCH 双分布 D3Q19**（Liang, Xu, Chen, Wang, Chai, Shi,
  PRE 97, 033309）：h-LBE 输运相场 φ（CAC 对流重生项），g-LBE 输运
  压力/动量（HCH），各向同性 Eq.(27/28) 梯度/拉普拉斯模板
- `tensorlbm.cac_lbm`（本 PR 新增模块；复用库
  `d3q19`/`boundaries3d.bounce_back_cells_3d`/
  `phasefield.stream_boundary_contract.stream_d3q19_adapter`，零手写
  collide/stream，grep 校验）
- fp64 计算；**µ(φ) 连续混合律（harmonic）**：两层黏度跨界面调和平均
  （P0 判决选定，替代会引入 τ 台阶伪影的 step 律）
- ν = 0.1 两相（B3 中 µ_g = ν·ρ_g）；界面宽度 W = 4；迁移率 M = 0.05；
  p0 = 0.01；周期边界

## Route-B σ 标定（语义披露）

CAC 方案的实测表面张力 **σ_eff(W) ≠ σ_input**，是**界面宽度 W 依赖的
标定常数**（R 无关、ρ 比无关、单调趋近 1）：

| W | σ_eff(W)/σ_input（R∈{20,28,40} 均值） | 偏差 |
|---|------------------------------------------|------|
| 3 | 0.877965 | −12.20% |
| 4 | 0.923896 | −7.61% |
| 5 | 0.947994 | −5.20% |
| 6 | 0.964746 | −3.53% |
| 8 | 0.981320 | −1.87% |

- W = 2 不稳定（ρ 比 100 下全场 NaN，排除）；各 W 的 R 散布 ≤ 0.4%
- 即使 W = 8 仍差 1.87% > 1%（Route A 不可达）→ **Route B**：固定
  W = 4，模型输入一次性补偿
  **σ_model = σ_target / σ_eff(W=4) = 0.01 / 0.923896 = 0.0108237305**
- 线性度：σ_input ×0.02 → σ_eff 比值相对变化 0.057%（≤0.5% 带），
  标定常数在 σ 量级间可迁移
- 同一常数用于 B1 全部半径与 B3 全部密度比（无逐臂调参）；
  σ_rec 恢复 0.01 即验证标定的 R 无关性与 ρ 比无关性

## 判定标准

| 指标 | 阈值 |
|------|------|
| 逐臂 \|σ_rec/0.01 − 1\| | ≤ 1.5% |
| B1 三半径散布 (max−min)/mean | ≤ 1% |
| 伪速度 max \|u\|（窗内最大） | ≤ 2e-4 |
| φ 积分漂移 @10k 步 | ≤ 1e-6 |
| 全程 NaN-free | 必须 |

## 结果（见 result.json，机器值）

### B1：R 迁移（128³，ρ 比 100）

| R | σ_rec | 误差 |
|---|-----------|------|
| 20 | 0.00999376 | +0.062% |
| 32 | 0.01000035 | +0.0035% |
| 48 | 0.01004449 | +0.445% |

散布 **0.507% ✅（≤1%）**，单臂最大误差 **0.445% ✅（≤1.5%）**。

### B3：密度比迁移（96³，R = 20）

| ρ 比 | σ_rec | 误差 |
|------|-----------|------|
| 10 | 0.00999552 | +0.045% |
| 100 | 0.00999382 | +0.062% |

### 监视量（5 臂）

- 伪速度 max|u| ≤ **6.74e-05** ✅（相场模型量级，远小于 2e-4 门）
- φ 积分漂移 ≤ **8.62e-13** ✅（CAC 守恒律逐位成立）
- 5/5 臂全程 NaN-free ✅

## 结论

Route-B 一步补偿后，**Laplace σ 在 R∈{20,32,48} 与 ρ 比∈{10,100} 五臂
全部闭合 ≤0.45%**（散布 0.507%）：CAC 方案的 σ 亏（W=4 时 −7.61%）
是 **W 依赖的标定常数**而非方案缺陷——跨 R、跨密度比迁移成立，
`tensorlbm.cac_lbm` + `σ_model = σ_target/σ_eff(W)` 构成可复用的定量
相场两相基线。已知边界（本基准未覆盖）：极端参数族（W=2@ρ 比 100、
κ≤0.1 黏度比）存在 CAC 不稳定性，另行披露。
