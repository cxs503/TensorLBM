**一句话结论**：库原生 D2Q9 BGK（`collide_bgk`+`stream`，周期域，无任何人工修正）
的平面声波在 N=λ/dx∈{16,32,64} 三档细化下，波速与衰减率对**连续线性声学理论**
(c=1/√3, δ=νk², ν=c_s²(τ−½)) 的误差分别为 ≤0.22% 与 ≤1.32%，双双 **≤3% 且单调**

每波数特征值）吻合到 1e-5–1e-7 相对——管线与理论自洽闭环。τ 敏感性（0.6–1.2）
与线性性（ε≤1e-3）复核一致。次案方腔驻波：体理论被 BB 壁粘性边界层损耗支配
（+156%~214%），Kirchhoff BL 公式归因成立（16–24% 内），如实记录为限制。

## 1. 理论推导（完整；预注册于运行前，NOTES.md §1）

### 1.1 线性化

库约定（`solver.py::collide_bgk`）：`f ← f − (f − feq)/τ`，D2Q9 平衡态
`feq_q = w_q ρ(1 + 3c·u + 4.5(c·u)² − 1.5u²)`（即 c_s²=1/3 的标准二阶形式）。
绕静止态 (ρ₀=1, u=0) 线性化，只保留一阶小量：

```
feq_q^(1) = w_q (ρ' + c_qx u_x' / c_s²)
```

### 1.2 平面波本征问题（collide-then-stream）

波沿格点轴 x，`f'_q(x,t) = F_q e^{st+ikx}`。一步 = collide 后 stream：

```
f_q(x + c_qx, t+1) = (1−r) f_q(x,t) + r feq_q(x,t),   r = 1/τ
```

代入 ansatz：

```
F_q [ e^{s+ikc_qx} − 1 + r ] = r w_q ( R + c_qx U / c_s² ),
R = Σ_q F_q（质量）,  U = Σ_q c_qx F_q（动量, ρ₀=1）
```

解出 `F_q = w_q (R + c_qx U/c_s²) g(c_qx)`，`g(c) ≡ r/(e^{s+ikc}−1+r)`，
代回 R、U 两个求和得 2×2 齐次系统，非平凡解条件（**色散行列式**）：

```
(1 − S0)(1 − S2/c_s²) − S1²/c_s² = 0,    c_s² = 1/3
S_j ≡ Σ_q w_q c_qx^j g(c_qx),  j = 0,1,2
```

### 1.3 沿轴权重塌缩

c_qx 只取 {0,±1}：P(0)=4/9+2/9=2/3，P(±1)=1/9+2/36=1/6（对 D2Q9 权重直接核对）。
故行列式只需三个值 g(0), g(±1)，**这是精确等价**（9 方向求和逐项归并）。

### 1.4 独立第二法：9×9 每波数传播矩阵

对波数 k 的 Fourier 谐波，一步传播矩阵

```
A_{qp} = e^{i k c_qx} [ (1−r) δ_qp + r w_q (1 + 3 c_qx c_px) ]
```

（行 q：碰撞输出 (1−r)F_q + r w_q(R + c_qxU/c_s²)，再乘平移相位）。其特征值
λ = e^s。**两法（1.3 行列式 Newton 求根 vs 1.4 numpy 特征值）在
N∈{8,16,32,64,128}、τ∈{0.6,1,1.2} 逐点一致 < 1e-10**（theory_check.py）。

### 1.5 小 k 级数（sympy 精确有理系数，theory_a4.py）

```
s(k) = a1 k + a2 k² + a3 k³ + a4 k⁴ + O(k⁵)
a1 = i/√3
a2 = −(τ−½)/3
a3 = i(12τ²−12τ+1)√3/216
a4 = −τ³/9 + τ²/6 − τ/12 + 1/72
```

即（右/左行两支衰减相同，ω=|Im s|，δ=−Re s）：

```
连续极限:  ω = c_s k,   δ = ν k²,   ν = c_s²(τ−½) = (τ−½)/3
离散修正:  c_ph(k) = c_s (1 − β k² + O(k⁴)),   β = −(12τ²−12τ+1)/72
           δ(k)   = ν k² (1 + c₂ k² + O(k⁴)),  c₂ = (2τ−1)²/12
```

要点：
- 离散理论首项声速**恰为** c_s=1/√3（无 O(k) 修正）；离散-连续差为 O((kλ)²)，
  系数 β、c₂ 闭式给出（τ=1: β=−1/72 → c_ph 略**高**于 c_s；c₂=1/12>0 → 离散
  衰减恒略大于连续）。
- 衰减率 δ=νk² 与 LBM 剪切粘度严格同系数：CE 裸层级给出 c_s²τ k²，离散时间
  (τ−½) 修正与粘度重整化完全平行。用二维等温 NS 读法
  （平面波时间衰减 = (ζ+μ)k²/2ρ₀），LBM BGK 等价于**有效体积粘 ζ = μ**
  （bulk:shear = 1:1）——即 BGK 声衰减是物理等温 NS（ζ=0 → νk²/2）的 2 倍，
  这是 BGK 人工体积粘的定量表述。
- 截断自检：级数到 k⁴ 与精确特征值之差随 k⁴ 收缩（τ=1, N=8: 波速 +8.57e-3
  (级数) vs +9.37e-3 (精确) 等，theory_a4.py 表）。

### 1.6 预注册判据口径（NOTES.md §1.3，先于运行登记）

- 判据 A：|c_meas/c_s − 1| ≤ 3% 且随 N 单调下降。
- 判据 B：|δ_meas/(νk²) − 1| ≤ 3% 且单调。
- 口径理由：连续公式**零可调参数**（无 τ 拟合、无格点修正），独立解析参考；
  预算的离散修正 βk²、c₂k² 在最粗档 N=16 为 +0.21%/+1.31%——3% 带内**非平凡
  通过**，细化后单调收敛，判据有实际分辨力。
- 管线校验（非判据）：c_meas、δ_meas 同时对比离散精确理论（1.4），预期 ~1e-6
  量级（模拟即线性系统）——证明残差来自物理离散差而非测量。

## 2. 模拟设计（NOTES.md §1.4 预注册）

- 网格 nx=N∈{16,32,64}（域=恰一波长，k=2π/N 精确），ny=8（y 不变，周期），
  **τ=1.0 固定**（保持 LU 粘度 ν=1/6 固定口径；论证：β(τ)、c₂(τ) 为常数时
  两观测量误差 = βk²、c₂k² 严格 ∝ N⁻² 单调；若固定每波长物理衰减则 τ∝N、
  c₂∝τ² 与 k² 相消，单调无保证）。
- 初始：ρ=1+ε sin(kx)，u_x=c_s ε sin(kx)（等温声学 u'=c_sρ'/ρ₀，右行波），
  ε=1e-3，f=d2q9.equilibrium。
- 步序 collide→stream（与 1.2 特征值严格同构）；fp64 CPU；无外推/修正/强迫。
- 测量：每步 Z(n)=⟨(ρ−1)e^{−ikx}⟩；ω=LSQ(解缠绕相位斜率)，c=ω/k；
  δ 由 |Z|²=A e^{−2δn}(1+ηcos(2ω̂n+φ)) 稳健估计器（吸收反向波 2ω 差拍，
  见 §4 披露 1–2；合成自检恢复真值至 3e-7 相对）。窗口 [T/2, 15.5T]，T=N√3。
- 离散参考：9×9 特征值（§1.4）逐配置计算。

## 4. 限制与诚实披露（全表见 NOTES.md §3）

1. δ 估计器在预注册后升级（诊断出 2ω 差拍偏置 +0.033% 后改为稳健估计器）；
   模拟/判据/参考/窗口零改动，新旧双数值均入 result.json。
2. 平衡态初始化固有播种 b/a=νk/(2c_s) 反向声波（5.7%@N=16→1.4%@N=64），
   实测 b/a 与预测逐一相符；估计器精确吸收。
3. τ=0.6 管线残差 +0.018%（估计器地板），仍 <3%/170。
4. 库 W 常量为 fp32（fp64 演算中提升），权重舍入 ~6e-8 在模拟不在理论内，
   对 1e-6 级管线残差有贡献。
5. 次案方腔不作判据（壁损耗支配）。
6. 等温 EOS 固有：无能量方程，γ-law 气体声学（绝热声速、热致衰减）不在
   本模型能力内（与 sod_shock_tube README 记录一致）；本基准参考的就是
   等温线性声学。
