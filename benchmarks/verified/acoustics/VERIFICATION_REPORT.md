## 1. 物理背景

### 1.1 问题描述
D2Q9 BGK 格子 Boltzmann 方法的平面声波传播验证。等温假设下，线性化声波满足：
- 波速：c_s = 1/√3 (格子单位)
- 衰减率：δ = νk²，其中 ν = c_s²(τ - 1/2) 为运动粘度

### 1.2 验证目标
验证 TensorLBM 库原生 D2Q9 BGK 求解器（`collide_bgk` + `stream`）的：
- **色散关系**：相速度 c 与连续理论 c_s 的误差 ≤ 3%
- **衰减特性**：衰减率 δ 与连续理论 νk² 的误差 ≤ 3%
- **收敛性**：误差随网格细化单调下降，收敛阶 O(N⁻²)

### 1.3 理论参考
- **连续理论**：c = c_s = 1/√3, δ = νk²
- **离散理论**：9×9 传播矩阵特征值精确解（考虑格子离散效应）

## 2. 计算方法

### 2.1 数值设置
- **模型**：D2Q9 BGK，等温
- **碰撞**：`tensorlbm.solver.collide_bgk`
- **迁移**：`tensorlbm.solver.stream`（周期边界）
- **精度**：float64, CPU 单线程
- **平衡态**：`tensorlbm.d2q9.equilibrium`（标准二阶形式）

### 2.2 算例配置

#### 主案：网格收敛性
| 参数 | 值 |
|------|-----|
| 网格 N | 16, 32, 64 (每波长点数) |
| y 方向 | ny = 8 (周期) |
| 松弛时间 τ | 1.0 (固定) |
| 振幅 ε | 1e-3 |
| 模拟时长 | 16 个周期 |

#### 辅案 1：τ 敏感性
- N = 32, τ ∈ {0.6, 0.8, 1.0, 1.2}

#### 辅案 2：线性性
- N = 32, τ = 1.0, ε ∈ {5e-4, 1e-3, 1e-2}

#### 辅案 3：方腔驻波（限制披露）
- L ∈ {32, 64}, half-way BB 壁, (1,0) 模态

### 2.3 初始条件
右行平面波：
```
ρ(x,0) = 1 + ε sin(kx)
u_x(x,0) = c_s ε sin(kx)
u_y(x,0) = 0
```

### 2.4 测量方法
- **波速**：复振幅 Z(n) = ⟨(ρ-1)e^{-ikx}⟩ 的相位斜率
- **衰减率**：稳健估计器吸收反向波 2ω 差拍（R² > 0.999999）
- **窗口**：[T/2, 15.5T]，避免初始瞬态

## 4. 结果分析

### 4.1 三链闭环验证
1. **级数展开**（sympy 精确有理系数）→ 离散修正 βk², c₂k²
2. **精确特征值**（9×9 矩阵）→ 与级数一致 < 1e-10
3. **真实模拟**（TensorLBM）→ 与离散理论一致 1e-5~1e-7

**结论**：管线、理论、模拟自洽闭环。

### 4.2 误差来源
- **连续 vs 离散**：O((kλ)²) 格子离散效应（理论预测 +1.31% @ N=16）
- **模拟 vs 离散**：1e-5~1e-7 量级（估计器地板 + fp32 权重舍入）
- **反向波污染**：平衡态初始化播种 b/a ~ νk/(2c_s)，稳健估计器精确吸收

### 4.3 物理意义
- BGK 声衰减 = 等温 NS 的 2 倍（有效体积粘 ζ = μ）
- 这是 BGK 人工体积粘的定量表述，非 bug

## 6. 限制与适用范围

1. **等温假设**：无能量方程，不适用于绝热声学（γ-law 气体）
2. **线性范围**：ε ≤ 1e-3（ε = 1e-2 见非线性漂移）
3. **τ 范围**：0.6 ≤ τ ≤ 1.2 验证（τ 过小稳定性下降）
4. **壁面效应**：BB 壁方腔被粘性边界层支配，体理论不适用
5. **fp32 权重**：库 W 常量为 fp32，对 1e-6 级残差有贡献
