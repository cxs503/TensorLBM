# B17-3D: 3D Taylor–Green 涡衰减基准（D3Q19 周期域，OpenLB tgv3d 同款初始场）

**状态：✅ 已验证（真实模拟，无外推、无人工修正）**

## 物理问题

周期域 [0,N)³（晶格单位 N，Δx=Δt=1）上的 3D Taylor–Green 涡，初始场
（OpenLB tgv3d 同款）：

```
u = ( U0·sin(kx)·cos(ky)·cos(kz),  -U0·cos(kx)·sin(ky)·cos(kz),  0 )
ν = (τ − 1/2)/3,   k = 2π/N,   Re = U0·N/ν
```

## ⚠️ 衰减率推导（与 2D TG 的关键区别——先数波矢范数）

| | 2D TG (B17) | **3D TG（本案例）** |
|---|---|---|
| Fourier 模 | (±k, ±k) 四模 | **(±k, ±k, ±k) 八模**（sin·cos·cos 三方向各含 ±k） |
| \|κ\|² | 2k² | **3k²** |
| 速度衰减率 | 2νk² | **3νk²** |
| 动能衰减率 | 4νk² | **6νk²** |
| NS 精确解？ | 是（u·∇u 恰为压力梯度） | **否**（u·∇u 的旋度部分立即驱动涡拉伸） |

任务书/问题清单的 "e^{−2νk²t}" 是 2D TG 的**速度**衰减率；3D 场套用会报
**+200% 假误差**（本案例 err_vs_task_formula_pct ≈ +200%，仅记录不作判据）。
正确对比：拟合 **ln(E) vs t** 斜率得 γ_E_sim，对比 **γ_E_theory = 6νk²**；
交叉验证 ln(u_rms) 对比 **3νk²**。E(t) = (U0²/8)·e^{−6νk²t}。

## 物理真实性说明（3D TG 不是纯指数衰减）

3D TG 不是 NS 精确解：u·∇u 的旋度部分（涡拉伸）从 t=0 驱动 w 分量增长，
生成 |κ|²≥4k² 的小尺度模，使**能量加权平均波数 Z/E 略升** ⇒ γ_sim 略高于
6νk²。实测（本 benchmark）：w_max ≈ 0.0026·U0、E_z,max ≈ 4e-7（Re=24），
该拉伸偏差随 Re 增大而增大（扫描：Re=48 时 +1.3~1.5%），随能量衰减
（小尺度耗散更快）回归 6νk²。**如实测量报告，不做任何修正**。

## 判定标准

| 指标 | 公式 | 阈值 |
|------|------|------|
| 动能衰减率偏差 | \|γ_E_sim/γ_E_theory − 1\|，γ_E_theory=6νk² | ≤ 3%（任务书标准） |
| 网格收敛 | \|err_E\| 随 N 增大单调下降（N=64→96→128） | 必须 |
| 指数衰减质量 | ln E vs t 线性拟合 R² | ≥ 0.999 |
| 质量守恒 | 质量漂移相对值 | 报告（实测 ~3e-5） |

真实模拟：E(t) 每 50 步由 `macroscopic3d` 实测记录（含 E_x/E_y/E_z 分分量
与 w_max 历史，见 energy_history_N*.csv），无任何外推/修正。

## 规范配置（扫描定案，2026-08-19）

- 网格：**N=64³/96³/128³** 三档，周期边界（`solver3d.stream3d` 模运算内建，无额外 BC）
- 初始场：u=(U0 sin(kx)cos(ky)cos(kz), −U0 cos(kx)sin(ky)cos(kz), 0)，ρ=1，
  f = `equilibrium3d(ρ,u_x,u_y,u_z)`（feq 初值）
- **Re=24 固定**（U0=0.05，ν=U0·N/Re，τ=0.5+3ν → 0.9/1.1/1.3 @ N=64/96/128）——
  低 Re 纯层流衰减（Re_eff=U0/(νk)=Re/2π≈3.8，无转捩）；
  **固定 Re 是 3D TG 网格收敛的正确做法**：固定 τ 时 Re_eff∝N，
  err 随 N 增大而非收敛（扫描实测 Re=32 固定 τ 时 err 64→96 由 +0.59% 升到 +0.62%）
- k = 2π/N；步数：auto（E/E0→e^-10，min 2000，cap 10000）：2000/2000/2600，
  每 50 步记录（E 衰减深度 ~15/10/10 e-folds，float32 噪声地板外）
- 碰撞：BGK（`collide_bgk3d`）；流步：`stream3d`；精度：float32（库默认）
- 共性模块路径（三路径之二——库 solver 路径，**零手写 collide/stream/平衡态**）：
  `tensorlbm.solver3d.collide_bgk3d` + `tensorlbm.solver3d.stream3d` +
  `tensorlbm.d3q19.equilibrium3d` + `tensorlbm.d3q19.macroscopic3d`

## 结果（2026-08-19 实测，见 result.json + case_N*.json + energy_history_N*.csv）

| N | τ | γ_E_sim | γ_E_theory=6νk² | err_E | R² | 半窗口 γ (前/后) |
|---|-----|-----------|------------------|-------|-----|------------------|
| 64 | 0.900 | 7.734479e-03 | 7.710628e-03 | **+0.3093% ✅** | 0.999998 | 7.755e-3 / 7.734e-3 |
| 96 | 1.100 | 5.154767e-03 | 5.140419e-03 | **+0.2791% ✅** | 0.999996 | 5.179e-3 / 5.139e-3 |
| 128 | 1.300 | 3.864960e-03 | 3.855314e-03 | **+0.2502% ✅** | 0.999995 | 3.883e-3 / 3.853e-3 |

- **网格收敛**：err_E 随 N 增大 +0.309% → +0.279% → +0.250%（单调下降，
  收敛到 6νk² 线性理论 + 物理拉伸偏差 ~0.25% 的极限）→ **PASS 达标**
- **指数性**：R²≥0.999995，半窗口斜率差 ≤0.8%（N=64）——衰减近似纯指数，
  残余曲率即涡拉伸效应，如实记录
- **质量守恒**：质量漂移相对值 ~3e-5（三档一致）
- **初值**：E0_meas = U0²/8 精确（E0_theory=3.125e-4，格点 sin/cos 均值精确）
- **偏差符号**：γ_sim 略**大于** γ_theory（+0.25~0.31%）——涡拉伸 + BGK 离散
  修正的真实测量（与 2D TG 的 −0.035% 符号相反：模态数/波矢范数不同）
- **复现性**：bit-exact（确定性模拟，无 RNG；重跑 N=64 γ_E_sim=7.734479e-03 一致）
