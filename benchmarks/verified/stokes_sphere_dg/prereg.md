## 0. 物理问题与设计原理

三向周期立方盒（边长 L）内含单个固定球（解析球面，半径 a），流体受均匀体积力
ρg·e_x 驱动（Guo 2002 二阶体力格式），D3Q19 BGK。无入口/出口/壁面——周期胞
稳态由"体力 ↔ 球阻力"全局力平衡闭合。蠕动极限：目标 Ma ≤ 0.0173、
Re_eff = U_sup·a/ν ≤ 4×10⁻³（由冻结 g_x 表唯一确定，见 §3）。

**结构性消除旧失败模式**（旧档 B10 诊断见 `phase0/old_archive/old_archive_diagnosis.json`）：
- 旧档 2.15% 为巧合精度，加密恶化 53%——根因是 DG 弱形式摩擦项的胞均值一阶差分；
  镜面反射动量交换则结构性无摩擦（51%）。
- 新设计主估计器 = **体力账本** F = Σ_fluid F_node（每步机器求和；稳态周期胞
  动量守恒恒等式给出 F_drag = ρg·V_f^discrete），**不做任何边界差分/表面积分**。
- 边界测量的动量交换（BFL 逐链账本，laboratory frame）降级为交叉验证估计器（§4 S3）。
- 无入口 Dirichlet 钳制（W7-B 教训：入口钳制制造 +11% 地板）。

**与沉降问题的等价性**（写入设计的物理映射，冻结）：
固定球 + 流体体力 ρg ⟺ 压力梯度驱动 G=ρg 的同一胞问题（Stokes 线性 + 齐次问题
只有零解 ⟹ 两问题解逐点成比例），⟺ 沉降阵列的伽利略平移。三类表述的
K(φ) 在同一"表观（全域）均值 U_sup"口径下是同一个数。参考解按同口径锁定（§1）。

**无量纲量（冻结）**：

    K = F_drag / (6 π μ a U_sup)

- F_drag = 稳态体力账本（主估计器，机器值）
- U_sup = 全盒平均流速 ⟨u_x⟩_cell，**固体节点按 u≡0 计入分子与分母**
  （表观/渗流口径；LBM 实现即"全节点求和 / 总节点数"）
- μ = ρ c_s²(τ−½)Δt（格子单位 τ=1 → ν=1/6），a = R（格子上球半径）

### C.1 缺陷（控制器亲验，两轮机器复算一致）

冻结 g_x 表按 U_sup=0.01 反解，而 ν=1/6（τ=1）⟹ **Re_a = U·a/ν = 6UR = 0.06R**：
R8→0.48、R12→0.72、R16→0.96、R24→1.44，与 §0 声称的 ≤4×10⁻³ 差 2–3 个量级
（该 4e-3 为草稿残迹）。后果：(a) Hasimoto/ZH/BIE 参考全部是 Stokes 极限，
Re_a~O(1) 的惯性修正不可忽略（孤立球 Oseen 系数 3/8 → @Re_a=1.44 名义 +54%；
周期胞系数符号不定但同阶，宅内先例 W6-A 在稀释周期胞 Re=0.05 实测**负** O(Re)
修正、W9-C S1 在 Re_cell 0.5 已见 0.256% 污染）；(b) Re_a 沿 R 阶梯增长 →
惯性偏置随 R 变化，直接攻击 §5 单调收敛门对离散误差的隔离。

### C.2 裁定与选择（控制器两形式中取 (i)）

**逐档 U_sup_target(R) = 0.05/(6R)**，使 **Re_a = 0.05 在全部 12 档精确恒定**。
选择 (i) 而非 (ii)（全阶梯统一 U）的理由：惯性偏置是 Re_a 的函数——(i) 使其在
阶梯上为**常数**，err(R) = 离散误差(R) + 常数惯性偏置，单调门依旧只读离散误差；
(ii) 下 Re_a 随 R 从 0.0167 增至 0.05，惯性偏置在细端变化 ~3×，会在离散误差
