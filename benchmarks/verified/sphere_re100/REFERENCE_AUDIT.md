# sphere_re100 参考口径多源核对（Re=100 球体阻力）

本文件裁定本 benchmark 唯一正确的对标口径，并列出可追溯来源与排除项。

## 0. 问题口径 ↔ 参考口径

本 benchmark 的物理问题：**均匀来流绕光滑球，Re = U·D/ν = 100**，定常轴对称尾流
（低于涡脱落下临界）。量 = Cd = Fx / (½ρU²·πR²)。
参考应为 **Re=100 球体阻力的公认经验/数值相关式**。球体无「展长」歧义，故用
被广泛引用的低 Re 球阻力相关式族。

## 1. 采纳口径：Schiller–Naumann（主锚）

```
Cd(Re) = 24/Re · (1 + 0.15 · Re^0.687)
Cd(100) = 24/100 · (1 + 0.15 · 100^0.687) = 1.0917311
```

Schiller–Naumann (1935) 是 Re ≲ 800 球体阻力的标准工程相关式，也是本库 Re=100
球体基准族的统一锚（`benchmarks/general_sim_acceptance_sphere_re100.py::
schiller_naumann_cd`，与 `NOTES.md` §1 的锁定式逐位一致）。门：|err| ≤ 3%
→ Cd ∈ [1.05898, 1.12448]。

## 2. 交叉参考（披露，非判定）

| 来源 | 式 | Cd(100) |
|---|---|---|
| Schiller–Naumann（指数 0.681 变体） | 24/Re·(1+0.15·Re^0.681) | 1.06852 |
| Clift–Gauvin | 24/Re·(1+0.1315·Re^0.72) | 1.10923 |

三相关式带 **[1.069, 1.109]**，跨度 3.7%。**任何落在 3% 门内的判定都落在相关式
带内**，故 3% 门是保守的（比相关式互差还严）。

## 3. 不适用口径（明确排除）

- **高 Re 球阻力实验/风洞值**（Re ≫ 100）：口径不符（Re 区间不同）。
- **有限域/高阻塞数值值**：需先做阻塞修正，不能直接对标自由来流相关式。
- **把 cylinder/ship 相关式套到球**：几何口径不符。

## 4. 本仓库独立交叉核对

- **参考口径多源**：见 §1–§2，W5-B/W7 NOTE 中以 sha256 链锁定（`NOTES_sha256_chain.txt`）。
- **力法独立复核**：判定路线（BFL 逐链动量账本）与独立控制体积动量平衡
