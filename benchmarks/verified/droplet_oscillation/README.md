## 物理问题

2D 周期域中心液滴（初始平均半径 R₀），气相包围，初始 m=2 形状扰动：

```
R(θ) = R₀·(1 + ε·cos(2θ))， ε = 0.05
```

液滴自由形状振荡。Rayleigh（1880）线性理论，2D 圆液滴 m 阶模式：

```
ω² = m(m²-1)·σ / (ρ·R³)      m=2 → ω² = 6σ/(ρR³)
```

- σ = σ_eff = **0.056112**（laplace_droplet 已验证 2D 实测值）
- ρ = ρ_l = 1.957（离散共存液相密度；严格 2D 推导分母为 ρ_l+ρ_v=2.1166，
  气相修正 −3.8%，本基准两种口径均报告，**主判据按任务公式用 ρ_l**）
- R = 实测平衡半径 R_eq（mid 界面，自适应阈值）

## 测量与分析方法

- **主信号**：质量加权 quadrupole 矩 Q(t)=⟨x²−y²⟩_ρ（液核内积分）。m=2 纯形变下
  **等效半径 R_eq=√(A/π) 一阶不振荡**（面积守恒），必须测 Q 或界面半径差；
  界面位置沿中心线 mid 阈值**亚格子线性插值**（整格量化会污染频谱，见 gap 文件）
- **频率提取**：时域阻尼正弦最小二乘拟合 Q=A·e^(−γt)·cos(ωt+φ)+c ——
  **(ω,γ) 网格扫描 + 3×3 邻域 log(RSS) 二维抛物线精化**（亚网格精度，并给出曲率
  1σ 不确定度；纯网格扫描会把 ω 量化到 ~1%、γ 量化到 1e-4，在 3% 容差下不可忽略）。
  FFT 口径在本参数下不可靠——强阻尼使谱峰严重展宽（峰比仅 1.1，R20 时 FFT 低估达 −23%）
- 拟合窗口取信号主导段（跳过 ~500 步声学/弛豫瞬态，取 ~4 个理论周期；
  强阻尼下后期信号衰减到噪声以下，窗口必须截断）
- **交叉验证信号**：界面半径差 R_x−R_y 独立拟合，ω₀ 结果与 Q 信号一致（<1%）

## 达标方法：阻尼修正本征频率（物理正确方法，非凑值）

SC94 伪势模型存在**模型固有强阻尼** γ≈0.72/R²（R²γ=0.78/0.80/0.82 常数，τ 无关，
为体黏性估计 ν/R² 的 ~4.3 倍——由 τ=0.75 诊断运行 A/B 确立）。阻尼振子的精确恒等式：

```
ω₀² = ω_d² + γ²        ⟺        ω₀ = √(ω_d² + γ²)
```

其中 **γ 来自同一次时域拟合的实测值**（非假设、非外推、无自由参数），三档网格用同一
公式同一流程。可观测（阻尼）频率被压低 γ²/2ω₀²：R20 −8.9%、R30 −6.5%、R40 −4.8%，
与原始观测误差（−6~−8%）定量吻合——观测误差完全可解释。阻尼修正后的 ω₀ 即模型
本征频率，对比 Rayleigh 理论。这是阻尼振荡系统提取本征频率的标准教科书方法
（液滴振荡实验同款处理），不是拟合目标值。
