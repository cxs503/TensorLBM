## 物理问题

两平行平板间剪切流：上壁以 U0 运动、下壁静止，稳态线性速度剖面：
- **u(y) = U0·y/H**（解析精确解，对任意 Re 成立）
- 壁面剪切 τ = μ·U0/H，摩擦系数 Cf = 2τ/(ρU0²)

## 共性模块

- 上壁移动（half-way 反弹），下壁静止，x 周期
- 碰撞：BGK（τ=0.8, ν=0.1）
