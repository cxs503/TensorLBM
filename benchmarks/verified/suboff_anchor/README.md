### C1 为什么是 PARTIAL_FAIL（可达材料边界）

DTRC/NSWCCD 原始报告（Liu & Huang 1998 = CRDKNSWC/HD-1298-11 = DTIC ADA359226；
Roddy 1990 = DTRC/SHD-1298-07）**全文不在仓内，且本工作树无外网**
（2026-11-08 实测 dtic/通用域名全部超时）。仓内可达的全部材料只有：

1. **量纲实测表**（逐字）：Table 14 p.23 的 `RT[N] @ 速度[kn]`，AFF-1 6 点 + AFF-8 6 点；
2. **开放获取论文的第二次逐字转录**（CFD Letters 2024, 16(10):126-139，表 1 主尺度 + 表 3 EFD 列）；
3. **[B] 级系数区间**（仓内文档自注「精确值需核对原文」）：AFF-1 `1.2×10⁷, ≈0.0030–0.0032`。

即：**C_T 没有可逐字抄录的点值**，只有力值表与区间。因此采用「逐字力值 + 声明口径派生」
路径，并要求派生值必须落入 [B] 级转录区间才可用于下游 —— 该自检通过：
派生 CT(AFF-1) = **0.003142** ∈ [0.0030, 0.0032]，相对常用值 0.0031 偏 +1.36%。

要闭合 C1，需要在能访问原报告的环境里补录 **Table 14 之外的系数表/试验条件表（含水温与 Rn 表）**，
本单不具备该条件，不做任何"凭记忆补数"。

### C2 为什么 FAIL（归因可判定，不是量纲错误）

按 Table 14 的 5.92 kn、L = 4.356 m、ν = 1.139×10⁻⁶ m²/s（仓内冻结参考锁声明的 15 °C 淡水假设）：

```
Re = 3.04551 × 4.356 / 1.139e-6 = 1.16473e7   vs  所抄 Re = 1.2e7   →  −2.94%
```

反推隐含 ν = U·L/Re_transcribed = **1.1055×10⁻⁶ m²/s** ≈ 16.2 °C 淡水（物理合理），
与声明 ν 差 −2.94%。也就是说：差距来自**试验水温/{两位有效数字}转录精度**，不是单位换算
或量纲错误（若是量纲错，偏差会是量级级别）。要在 0.1% 内闭合，必须逐字抄录原报告的水温与
Rn 表；0.1% 门槛对一个两位有效数字的外部锚本身是过分要求，这一结论如实记录、不放宽判据。

## 零手抄机制（可执行的三条）

1. **逐字校验**：`sources/external_transcriptions.json` 里每条 quote 必须是 `archived_at`
   文件的连续子串，缺一即构建失败（并记录该文件的 sha256）。
2. **正则取数**：`anchor.json` 的全部数字由 quote 的正则解析；公式系数 0.075/2 也是解析来的，
   不是字面量。`build_anchor.py` 的 AST 自检保证脚本内**不存在**等于任何派生量
   （CT / C_F / Re / (1+k)）的浮点字面量 —— 从结构上排除"第三处手抄"。
3. **双录对校**：Table 14 的 12 行既从仓内文本解析、又与
   `tensorlbm.suboff_reference_data.SUBOFF_TOW_TANK_RESISTANCE_TABLE14` 常量逐行比对，必须完全一致。

## 口径与不确定度（下游必读）

- **定义**：`C_T = R_T / (0.5·ρ·U²·S)`，`S` = 湿表面积 5.998 m²（实验口径；与下游 LBM 参考面积一致），
  `ρ` = 1000 kg/m³，`Re = U·L/ν` 以总长 L = 4.356 m 为特征长度。
- **AFF-8 面积口径披露**：AFF-8 也按裸壳湿面积 5.998 m² 无量纲化（冻结参考锁口径）。
  若改用全附体湿面积 6.35 m²，其 C_T 变为 0.003464（−5.54%）——**跨口径数字不可混用**。
- **口径链不确定度 RSS = 0.711%**（ρ 带 997–1000: 0.15%；S 口径 5.998 vs 解析 5.9933: 0.078%；
  力舍入 0.006%；速度舍入 0.169%；ν 假设经 C_F 传递 0.669%）→ **远小于 3% 目标带**，
  即"3% 带"在锚侧可分辨。
- **未量化项（必须携带的保留）**：拖曳水池重复性（典型 ±2–5%）—— 原报告不确定度声明不在离线可达范围，
  无法逐字转录；原试验水温/水质 —— ν 为声明假设。故后续任何"<3%"声明都必须写成
  "在声明口径下 <3%，未含试验重复性"。

## 副产物：一个否定性结论（诚实入账）

派生 C_T(AFF-8) = 0.003667 落在文献常用区间 [0.0038, 0.0042] **之外（−12.7%）**。
要复现 0.0042 需 S ≈ 5.24 m²、复现 0.0038 需 S ≈ 5.79 m² —— 均**小于裸壳湿面积 5.998 m²**
（非物理）。故「AFF-8 C_T ≈ 0.004 @Re≈1.2e7」**不能由原始力在物理湿面积下复现**，
不得用作验收锚；这与仓内 `src/tensorlbm/external_survey/suboff_anchor.py` 的既有结论一致
（该模块亦因同一理由把 AFF-8 0.004 从评分器中撤下）。
