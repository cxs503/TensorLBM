## 3. 受限/通道口径（不适用于自由流）

- Sohankar et al. 1997 通道配置 Cd≈2.05（高阻塞加速）→ B19 误用致 -26.7%。
- Sharma & Eswaran 2004（arxiv 2411.03124 Table 2 转引）Re=100 Cd=1.57
  —— 该文用较小域（较高阻塞），偏高，不代表无障自由流。

## 4. 裁定

正确对标口径 = **2D 自由流、α=0°（正置）、无障/低阻塞数值基准**（本 solver
为 2D，且域 40D → blockage 2.5%，与文献 imposed-velocity 低阻塞口径一致）。

多源聚类（14 个独立数值数据点）：
- **Cd ∈ [1.44, 1.52]，中位 1.488，均值 1.485 → 取中心 Cd_ref = 1.48**
- **St ∈ [0.145, 0.149]（0.159 为离群）→ 取中心 St_ref = 0.147**

实验（Okajima 0.143-0.145）系统性低于 2D 数值（2D 忽略展向三维失稳 →
高估 St），故 2D 求解器不应以实验作为 St 参考。
