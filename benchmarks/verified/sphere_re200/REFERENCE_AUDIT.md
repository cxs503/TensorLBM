# sphere_re200 参考口径多源核对（Re=200 球体阻力）

本文件裁定本 benchmark 唯一正确的对标口径，并列出可追溯来源与排除项。
口径与已入库的 `benchmarks/verified/sphere_re100/REFERENCE_AUDIT.md` 完全同构
（同一物理量、同一相关式族、同一锁定约定），只是 Reynolds 数不同。

## 0. 问题口径 ↔ 参考口径

本 benchmark 的物理问题：**均匀来流绕光滑球，Re = U·D/ν = 200**（D 为球直径，
ν 为运动黏度），低于涡脱落下临界（球体涡脱落临界 Re_c ≈ 270），定常轴对称尾流。
量 = **Cd = Fx / (½ρU²·πR²)**（迎风截面积 πD²/4 为基准）。

球体无「展长」歧义，故参考应为 **Re=200 球体阻力的公认经验相关式族**（低 Re
球阻力标准相关式），与 Re=100 案例使用的族相同。

> ⚠️ 与 Re=100 的区分：Re=100 锁定值 **Cd=1.0917311**；Re=200 锁定值
> **Cd=0.805615**。两者不可混淆（旧任务书曾把 Re=200 写成 0.769/0.773）。

## 1. 采纳口径：Schiller–Naumann（主锚）

```
Cd(Re) = 24/Re · (1 + 0.15 · Re^0.687)          （Schiller & Naumann 1933/1935）
Cd(200) = 24/200 · (1 + 0.15 · 200^0.687) = 0.805615
```

Schiller–Naumann 是 Re ≲ 800 球体阻力的标准工程相关式；本库 Re=100 球体基准族
即以其为统一锚（`benchmarks/verified/sphere_re100/`），本案沿用同一约定以保证
Re 系列的一致性。门：|err| ≤ 3% → Cd ∈ **[0.78145, 0.82980]**。

## 2. 交叉参考（披露，非判定）

| 来源 | 式 | Cd(200) |
|---|---|---|
| Schiller–Naumann（指数 0.681 变体） | 24/Re·(1+0.15·Re^0.681) | **0.78416** |
| Clift–Grace–Weber (1978) | 24/Re·(1+0.1935·Re^0.6305) | **0.77563** |
| Clift–Gauvin | 24/Re·(1+0.1315·Re^(0.82−0.05·log10 Re)) | **0.78102** |
| Turton–Levenspiel (1997) | 24/Re·(1+0.173·Re^0.657)+0.413/(1+16300·Re^−1.09) | **0.80254** |

四相关式带 **[0.7756, 0.8056]**，跨度 **3.7%**。**落在 3% 门内的判定即落在
相关式带内**，故 3% 门比相关式互差还严（与 Re=100 案例同一性质）。

### 2.1 实验/标准阻力曲线（披露）

光滑球标准阻力曲线（Wieselsberger 1922 数据，收录于 Schlichting《Boundary-Layer
Theory》；Achenbach 1972 JFM 54:565）在 Re=200 给出 **Cd ≈ 0.77–0.80**（层流分离
态）。本库 `docs/sphere_suboff_highre_reference_data_zh.md` 表 1–2 收录该族，
并给出 Re=100 实验 ≈1.09（与 SN 1.0917 一致）。Re=200 实验值与相关式带
[0.776, 0.806] 一致。

### 2.2 任务书历史值 0.769 / 0.773 的裁定

`benchmarks/pending/sphere_re200/` 旧记录引用「任务书 SN(200)=0.769、CG(200)=0.773」。
经公式反解：SN 公式 = 0.769 对应 **Re ≈ 224**，= 0.773 对应 **Re ≈ 221** ——
**都不是 Re=200**。SN(200) 的公式精确值为 **0.805615**。故旧任务书的 0.769/0.773
是算术/口径错误，本审计不采用，判定使用公式精确值（与 Re=100 案例同一处理）。

## 3. 不适用口径（明确排除）

- **高 Re 球阻力实验/风洞值**（Re ≫ 200，如亚临界平台 0.44 或超临界 0.1–0.2）：
  Re 区间不符。
- **有限展长/高阻塞实验或数值值**：需先做阻塞修正，不能直接对标自由来流相关式。
  本案采用低阻塞大域（见 README，面积阻塞 1.60%）。
- **把 cylinder/平板相关式套到球**：几何口径不符。
- **阶梯体素球 + 全 solid Ladd MEM（历史 +264%）/ 压力积分（−16.6%）**：力法口径
  缺陷，非参考口径问题（见 README §5 负结果）。

## 4. 本仓库独立交叉核对

- **参考口径多源**：见 §1–§2，公式精确值（可用 `python -c` 复核）。
- **力法独立复核**：判定路线（BFL 逐链动量账本，interpolated 光滑壁）与独立
  控制体积动量平衡（`cv_instrument.py`）窗均应一致到 ≪1%（见 README 结果表）。
- **口径可移植性**：同一 BFL 口径在 Re=100 已入库 verified（+2.77%/+2.54%）；
  本案仅改 Re（τ），不换口径。

## 5. 本结果误差

跨度 ≤ 3%**。
