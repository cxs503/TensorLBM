# 二维周期圆柱方阵渗透率（D2Q9）— Sangani–Acrivos 1982 级数解验证

Wave-4 多孔介质弧（W4-A/W4-C）交付。单相 Stokes 渗透率：周期单位胞
d×d 内一根圆柱（名义半径 R=d·√(φ/π)），流体域掩码体力驱动，
k_sim = ν·⟨u_x⟩_fluid / a 直接对参考 k_ref = d²/((1−φ)·f_table)。
真实模拟、无外推、无重标定（`extrap: "none"`）；判定用实测值。

## 一句话判决

**fs=10 协议（主判据，修正案 #4）：两 φ 全 PASS** ——
φ=0.3 三档 **6.5335 → 2.8598 → 1.3797%**、
φ=0.5 五档 **73.870 → 27.187 → 10.390 → 3.535 → 0.0484%**，
全链严格单调、最细档 ≤3%、全档稳态。
fs=1 协议（原注册链）并列披露：φ=0.3 PASS（0.5414% 最细档）、
φ=0.5 **FAIL**（d320 非单调 19.92% —— fp32 噪声地板伪差，见下）。

## 设置

- D2Q9 BGK，τ=1.0（ν=1/6），全周期单位胞；圆柱 mask 周期折叠距离
  （风格同 `porous_media.make_random_cylinder_medium`，几何非物理核）。
- 步序：collide → stream → 掩码体力 → bounce-back（同库
  turbulent_channel 环）。核全部来自库：collide_bgk/stream
  （solver）、bounce_back_cells（boundaries）、_apply_body_force_2d
  （turbulent_channel）、equilibrium/macroscopic（d2q9）。
- Re_target = 0.05（注册常数；fs=10 协议即 Re_cell≈0.5），
  a_body = Re·ν²/(k_lu·R_real)·force_scale。
- 稳态探测器（末窗相对漂移 <1e-5）提前停；每档实测 Re_cell 与 Ma
  （fs10 链 Re 0.50–0.64、Ma ≤0.169，Stokes 干净）。

## 参考与归一化（修正经四路独立裁决）

Sangani & Acrivos 1982 Int. J. Multiphase Flow 8(2):193-206（DOI
10.1016/0301-9322(82)90029-5）压力形拖曳 f = G·L²/(μ·U_D)；表值
（φ→f）9 行与 Basilisk cylinders.c 逐字一致（另 MDPI Fluids 2021
6(9):334 Table 1 数字级同、稀释端 0.040%、润滑近似自推 0.27% 交叉）。
冻结预注册通道 A（k_ref=d²/f）推导有错（漏幻压投影 G·φL²），
修正通道 k_ref = d²/((1−φ)·f)：三路定裁 = ①Basilisk 源码约定逐字
（U=流体域平均、F=L²/(1−φ)）②控制器应力张量推导（掩码体力与
G=a 流场恒同，压力形拖曳多出投影幻压）③控制器独立 FD/MAC Stokes
解算器（修正通道收敛表值、冻结通道钉死 46–55% 不收敛）。通道 A
作披露列保留（err_prereg_A），通道 B（φ_actual 对数插值）诊断列。

## fp32 噪声地板（fs=1 d320 伪差的定源，修正案 #4 依据）

a_body ∝ d⁻³（Re_target 固定），d=320/fs=1 时 a=5.658e-8，每步每模式
体力增量 3a ≈ 1.4×fp32 ε，落入 f 值 ulp 量子化网格——实测注入动量比
r = 实际/名义 偏离 1（a 尾数的确定性函数，与流场无关，探针逐节点
min=max）。四证据链：

1. **强迫阶梯探针**（控制器 diag_ctrl/，同一 run.py --force-scale）：
   d320 fs=1/10/100/1000 → 19.92 / 0.048 / 1.69（惯性起始，Re=4.9）/
   28.13%（惯性主导，Re=36）；粗档 fs 不敏感（≤0.41pp）。
2. **注入比探针**：d320 fs1 r=**1.18513**（注力放大 18.5%，恰等于
   观测 k 超出 461.18/389.14=1.1851）；fs8/fs10 r=0.98761（亏缺
   1.24%）。三尺度闭合 k_true = k_sim/r：**389.139 / 389.311 /
   389.203**（fs1/fs8/fs10，散布 0.044%；控制器独立探针+独立算术
   逐位复现，另 fs2 387.441 在披露区间内）。
3. **控制器 FD/MAC Stokes 解算器**：N=320 连续介质解 err 1.92%
   单调收敛（32.57→6.70→4.87→1.92）→ 几何侧误差 ~1-2%，LBM d320
   异常是数值性的。
4. **近抵消披露（诚实口径）**：fs10/d320 实测 0.0484% = 真实离散
   误差 +1.2% 与注力亏缺 −1.24% 的净结果；探针校正后链（控制器
   全 8 档自算）φ=0.3 **6.54→2.83→1.35%**、φ=0.5
   **73.86→27.19→10.40→3.29→1.21%** 同样严格单调、最细档 ≤3%——
   **判决在校正前后都成立**（判定用实测值，不做探针校正重标定）。

fs=10 的选择 = "Stokes 干净（Re≈0.5，惯性效应 ≲0.05%）且全档强迫
3a/ε ≥ 14" 的唯一交点（fs=100 已显惯性 +1.69%）；协议修正先于一切
fs10 formal 写入哈希链（修正案 #4，2026-09-21 06:48:11 +0800，
