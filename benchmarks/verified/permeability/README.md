# 二维周期圆柱方阵渗透率（D2Q9）— Sangani–Acrivos 1982 验证

单相 Stokes 渗透率：周期单位胞 d×d 内一根圆柱（名义半径 R=d·√(φ/π)），
流体域掩码体力驱动，k_sim = ν·⟨u_x⟩_fluid / a，对参考
k_ref = d²/((1−φ)·f)。真实模拟、无外推、无重标定（`extrap: "none"`）。

## 判决

**fs=10 协议：φ=0.3 与 φ=0.5 均 PASS** —— 误差链严格单调、最细档 ≤3%、
全档稳态。fs=1 协议结果并列披露（其 φ=0.5 细档受 fp32 注入舍入伪差
影响，见数值注记）。

## 方法

- D2Q9 BGK，τ=1.0（ν=1/6），全周期单位胞；圆柱 mask 周期折叠距离
  （风格同 `porous_media.make_random_cylinder_medium`，几何非物理核）。
- 步序：collide → stream → 掩码体力 → bounce-back。核全部来自库：
  collide_bgk/stream（solver）、bounce_back_cells（boundaries）、
  `_apply_body_force_2d`（turbulent_channel）、equilibrium/macroscopic
  （d2q9）。
- Re_target = 0.05 × force_scale=10 → Re_cell 0.50–0.64（Stokes 区）、
  Ma ≤ 0.169；a_body = Re·ν²/(k_lu·R_real)·force_scale。
- 稳态探测（末窗相对漂移 <1e-5）提前停；表中步数为实际运行值。

## 参考

Sangani & Acrivos 1982 Int. J. Multiphase Flow 8(2):193-206
（DOI 10.1016/0301-9322(82)90029-5）压力形拖曳 f = G·L²/(μ·U_D)
（U_D = 流体域平均速度）。表值（φ→f）与 Basilisk `cylinders.c` 逐字
一致，另与 MDPI Fluids 2021 6(9):334 Table 1 数字级交叉。归一化
k_ref = d²/((1−φ)·f)（掩码体力驱动的 Darcy 定义）经独立 FD/MAC Stokes
解算器交叉验证（N=320 连续介质解 err 1.92% 单调收敛）。φ_actual 对数
插值通道作诊断列 err_B 披露。

## 数值注记

- **fp32 注入舍入（fs=1 细档伪差）**：a_body ∝ d⁻³（Re_target 固定），
  d=320/fs=1 时每模式增量 3a ≈ 1.4×fp32 ε 落入 ulp 网格 → 实际/名义
  动量注入比 r = 1.18513，恰等于该档 k 观测超出比（461.18/389.14）。
  fs=1/8/10 三尺度闭合 k_true = k_sim/r = 389.139/389.311/389.203
  （散布 0.044%）。fs=1 φ=0.5 链 d320 的非单调 19.92% 为此伪差，故
  判定采用 fs=10 协议。
- **fs=10 适用域**：全档注入增量 3a/ε ≥ 14（舍入 <0.1%）；Re_cell
  0.50–0.64 保持 Stokes 区（fs=100 时 Re≈4.9 已显惯性 +1.69%）、
  Ma ≤ 0.169。
- **d320(fs10) 0.0484%**：含真实离散误差（+1.2%）与注入亏缺（−1.24%，
  r=0.98761）的部分抵消；判定按实测值，不做该项校正。
- **d160 档 3.54%**：判定规则为最细档 ≤3%（全链严格单调成立）。

## 敏感性（result.json）
