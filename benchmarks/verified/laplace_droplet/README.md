# B23: 静态液滴 Laplace 定律基准（SCMP 单组分 Shan-Chen 表面张力验证）

**状态：✅ 已验证（真实模拟，无外推、无人工修正凑精度）**

## 物理问题

周期域中心放置一个液相液滴（ρ_l），周围充满气相（ρ_v），SCMP
（Shan–Chen 单组分）模型演化至稳态。液滴内外压差满足 **Young–Laplace 方程**：

```
2D（圆柱液滴）：Δp = p_in − p_out = σ / R
3D（球形液滴）：Δp = p_in − p_out = 2σ / R
```

对多个半径 R 测量稳态 Δp，拟合 Δp vs 1/R 的斜率提取有效表面张力 σ_eff；
**Laplace 线性关系成立**（σ_eff 与 R 无关）即为表面张力模型的物理一致性验证。

## 判定标准

| 指标 | 公式 | 阈值 |
|------|------|------|
| 逐半径 σ 一致性 | max_i \|σ_i − σ_fit\|/σ_fit（σ_i = Δp·R_eq，3D 取 Δp·R_eq/2） | ≤ 3% |
| 线性拟合质量 | Δp vs 1/R 自由截距线性拟合 R² | ≥ 0.999 |
| 过原点有效性 | \|截距\| / (斜率·max(1/R)) | ≤ 3% |

真实模拟：Δp 由稳态密度场经 EOS 压力直接测量，无外推、无修正。
半径 R 取**实测等效半径** R_eq（ρ > (ρ_in+ρ_out)/2 的液核面积/体积反推），
压力环带取 0.5R_eq 内 / 1.5R_eq 外，避开弥散界面。

## ℹ️ 库 SC 力符号约定（非 bug，基准用 G=+5 即标准吸引）

`_sc_neighbor_weighted_sum` 用后向 gather ψ(x−c) + 加速度力注入（u += τF/ρ），
构成自洽的库约定：**G>0 为吸引**。本基准用 **G=+5**（等效标准 SC94 的 G_eff=−5），
3 半径 Laplace 线性成立（σ 偏差 0.8% 2D / 1.11% 3D）。曾尝试改前向 gather，G=±5 均
NaN（破坏自洽），已回退——**不改库**。物理压力用 EOS p=ρ/3+G_eff·ψ²/6（G_eff=−5）。

## 配置

- 模型：SC94，ψ(ρ) = 1 − e^(−ρ)，物理耦合 **G_eff = −5.0**（库调用 G=+5.0），
  τ = 1.0（ν = 1/6），float32
- 半径：R = 15 / 25 / 40 格；域 L = 4R（60 / 100 / 160），周期边界
- 初场：tanh 液滴剖面（宽度 W=4），离散共存密度 ρ_l=1.957, ρ_v=0.1596
  （实测离散共存；连续 EOS 麦克斯韦值 1.7505/0.0493 仅供对照，因格子离散
  效应两者不同——液滴经质量守恒自动弛豫到实际平衡半径）
- 共性模块路径（零手写 collide/stream，grep 校验）：
  `tensorlbm.multiphase.collide_sc_single_component`（D2Q9）
  `tensorlbm.multiphase3d.collide_sc_single_component_3d`（D3Q19）
  + `solver.stream` / `solver3d.stream3d`（周期流步内建）
- 稳态判据：Δp 相对漂移 < 2e-4（2000 步窗口）且 R_eq 漂移 < 2e-3，
  min 6000 步；测量取末 3 个采样点平均

## 结果（2026-08-18 实测，见 result.json）

### 2D（D2Q9，CPU）

| R_init | R_eq | Δp | σ_i = Δp·R_eq | 相对 σ_fit 偏差 |
|--------|------|------|----------------|-----------------|
| 15 | 15.44 | 0.003627 | 0.05600 | −0.20% |
| 25 | 25.29 | 0.002224 | 0.05624 | +0.23% |
| 40 | 40.34 | 0.001402 | 0.05656 | +0.80% |

**σ_eff(2D) = 0.056112**，R² = 1.000000，截距占比 0.63%，
最大逐半径偏差 **0.80% ✅（≤3%）**。

### 3D（D3Q19，GPU cuda:0）

| R_init | R_eq | Δp | σ_i = Δp·R_eq/2 | 相对 σ_fit 偏差 |
|--------|------|------|-----------------|-----------------|
| 15 | 15.42 | 0.007256 | 0.05596 | −0.38% |
| 25 | 25.25 | 0.004475 | 0.05650 | +0.58% |
| 40 | 40.26 | 0.002822 | 0.05679 | +1.11% |

**σ_eff(3D) = 0.056170**，R² = 0.999982，截距占比 1.06%，
最大逐半径偏差 **1.11% ✅（≤3%）**。

**σ_eff(2D)=0.056112 与 σ_eff(3D)=0.056170 一致（差 0.1%）**，
D2Q9/D3Q19 各向异性在本参数下影响可忽略。

- 稳态液核密度 ρ_in ≈ 1.95-2.00，气相 ρ_out ≈ 0.159-0.165（2D/3D 略异），
  密度比 ~12:1（离散方案实测值，低于连续 EOS 麦克斯韦预测的 35:1）
- 伪速度（质量指标）max|u| ≈ 0.137-0.140（SC93 速度-平移格式典型量级）
- 质量漂移 ≤ 2e-4（周期流步守恒良好）
- 平衡半径与初值偏差 ≤ 3%（R=40 时 R_eq/R_init = 1.009；R=15 时 1.03）

## 结论

2D 三个半径 Δp·R 常数性 ≤0.8%，3D ≤1.1%，
**Young–Laplace 线性关系在 SCMP 模型（经符号补偿后）成立**，
σ_eff(2D)=0.056112 / σ_eff(3D)=0.056170 为该模型的实测有效表面张力
（2D/3D 相互一致 0.1%）。误差远小于 3% 阈值，保存至
benchmarks/verified/laplace_droplet/。
