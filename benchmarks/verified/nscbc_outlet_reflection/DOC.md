# NSCBC 出口反射系数验证面（TensorLBM，D2Q9 声脉冲）

**状态：✅ 仪器通过（两个解析锚 ±0.7%）；被测能力修复后 PASS（|R| = 0.31%，旧实现 11.2%）**

## ① 案例介绍（物理背景 / 几何 / 参数）

- **物理背景**：外流/管道算例的**出口边界**必须是"声学透明"的，否则下游会把声波
  反射回工作区，污染阻力/涡脱/声学统计。`tensorlbm.boundaries.nscbc_outlet_2d`
  声称实现 Poinsot & Lele (1992) / Thompson (1987) 特征边界（NSCBC），但在
  `boundary_capability_contract` 中长期登记为 `IMPLEMENTATION_ONLY / No tests`。
  本工作把"非反射"这一定性标签变成**可机器判定的定量指标**。
- **几何**：1-D 管道（D2Q9，y 向均匀，nx=900，ny=8，周期 y），左端零梯度入口
  （脉冲右行，入口影响 <1%），右端 x=nx−1 为被测出口。
- **参数表**（程序化写入 `result.json`）：ν=0.1（τ=0.8）、ρ0=1、来流 U0=0、
  脉冲幅值 A=1e-3（Δp ≈ 3.3e-4 ≪ ρ0cs²，线化域）、宽度 w=48 格、
  注入点 x0=200，探针 x=500/650，步数 2600。

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **相容初值**：右行特征初值 `u' = p'/(ρ0 c_s)`（d'Alembert 相容），保证注入的
   是"已知输入"而非任意的 ρ/u 组合。
2. **特征分解测量**：探针处 `A± = ½(p' ± ρ0 c_s u')`（p' = cs²Δρ，中位数去直流）；
   入射窗取理论到达时刻 ±6w/c_s，反射窗取"出口反射后回到探针"的理论时刻 ±6w/c_s，
   两窗不重叠。
3. **自标定衰减**：由两探针入射幅值比得 200 格子行程的实测衰减 a，再按往返距离
   幂律扣除 `a^(2(nx−1−xp1)/Δ)`，避免用理论黏性衰减。
4. **仪器标定（先判仪器）**：两个**解析极限**——
   压力 Dirichlet（压力节点，`pin`）与刚性壁（`mirror`）都应有 |R|=1，
   且符号相反（−/+）。锚不过 ⇒ 本次任何 R 读数判 WITHHELD。
5. **被测档**：`nscbc` σ∈{0, 0.25, 1, 5}；对照档 `zerograd`（零梯度）；
   一致性档 `neeq@σ=0`（修复实现 σ=0 应与零梯度**逐位**相同）。
6. **工具链**：全部物理核走库共性路径（`d2q9.equilibrium/macroscopic`、
   `solver.collide_bgk/stream`），零手写核；`run.py all|batch|single|assemble`
   可续跑，`result.json` 为归档工件，`tests/test_nscbc_outlet_reflection.py`
   为回归门。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **旧实现的 σ 没有时间尺度**：一步内施加 O(1) 的密度松弛等价于硬压力 Dirichlet
   的伪装，因此"σ=1 = hard pressure fix"不是极限而是无关工作点；且实测 R(σ) 非单调
   （0.148→0.005→0.112），任何"按 σ 调反射"的用法都会踩坑。
2. **修复的物理要点**：只保留外向特征 A+（令入射声学特征 A−=0），松弛必须写在时间
   尺度上（每步 `σ·c_s/L`，L=nx），并保留上游非平衡部分以输运涡量/熵波。
   这样 σ=0 时逐位退化为零梯度（可机器对照），σ 增大时连续趋向硬压力。
3. **零梯度出口并不透明**：本工况 27.9% 反射——长域 Kovasznay 用它是靠"扰动已衰减"
   而不是靠"边界不反射"，两者不可混淆。
4. **适用边界**：验证只覆盖 1-D **法向入射**线化声学（Ma≈0，Δp/ρc²≈1e-3）；
   掠射/横向模式、强非线性（激波）、以及带涡穿越边界的工况未验证（3-D
   `nscbc_outlet_3d` 同样未验证，属后续欠账）。
5. 测量下限：入射段自带左行底噪 ~0.4%，故 |R| ≲ 0.4% 的差异**不可分辨**——
   所有 nscbc 档读数都在该地板上，不应解读为"σ 无影响"以外的更多信息。
