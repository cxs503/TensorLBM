## 物理问题

顶盖驱动方腔流 Re=400，3D 展向（z）周期 ≈ 2D 基准：
- **Ghia, Ghia & Shin 1982（JCP 48:387）**：中线速度表值 + 涡心 (0.5547, 0.6055)
- Re=400 主涡 u(0.5,0.5) = -0.1148
- 几何：f 形状 (19, nz, ny, nx)，y 垂直（顶盖 y=ny-1 沿 +x 移动），z 周期
- 展向均匀性实测：ux 跨 z 标准差 ~0，|uz|_max ~1e-4 → 与 2D 方腔等价的 3D 验证

## 关键修复（根因定位：3D 顶盖 BC 方向索引 bug）

- **迁移版 /tmp/cavity3d_a.py 症状**：96²×24 100k 步 max_dev=14.5%、u_mid=-0.132、
  质量漂移 **-51289（23%）**、涡心错乱
- **根因**：自推 D3Q19 Zou-He 顶盖公式的 **z 对角对 17/18 颠倒**——
  - sum_cyp 误用 f18（未知，cy<0）代替 f17（已知，cy>0）→ rho 错
  - z 对重建覆盖已知 f17、留下被周期 y-wrap 污染的 f18（f18 顶盖值 = 底壁行
    经周期 wrap 流入的反射值）
  - 数值验证：buggy 版单步注入虚假 jy=-0.016、jz=+0.12（应精确为 0）
- **修复**：未知 cy<0 = {4,8,9,16,18}，rho = Σcy0 + 2Σcy>0（{3,7,10,15,17}），
  f16 = f15 + Sz0/2、f18 = f17 − Sz0/2（Sz0 = (f5−f6)+(f11−f12−f13+f14)）
- **修复后**：质量漂移 0.018%（-51289 → +39）、主涡 (0.558,0.611)、1.96% ≤3%
- 证据链：A/B 冒烟（32²×8）buggy 6000 步丢 10% 质量 vs 修复版 0.004%；
  单测精确守恒断言
