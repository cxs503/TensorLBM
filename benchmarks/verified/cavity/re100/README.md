- Re=100 主涡 u(0.5,0.5) = -0.20581（库内 GHIA_RE100 表值，任务上下文近似值以论文表为准）

且关键物理量（涡心、中线 u、底部回流）两档均贴合 Ghia——非巧合单点命中。

## 关键修复（V3，来自 Re=400 案例的经验迁移）

- **根因（Re=400 案例定位，2026-08-19）**：V0 的 post-streaming 反弹 + 周期 stream
  组合使**顶盖动量绕入底壁行**（底部回流过量 2.6 倍）→ 系统性偏差（Re=100 曾 22.5%，
  Re=400 曾 23.6%）
- **V3 修复**：三静止壁用 **pre-streaming 半程反弹**（流体侧反射，动量不进壁）+ 顶盖
  zou_he_moving_lid——与 OpenLB createInterpBoundaryCondition2D 同口径
- **经验迁移**：Re=400 验证 V3 后（23.6%→1.50%/0.83%），Re=100 同根因直接套用 V3，
  本轮实测 22.5%→**0.75%/0.73%**，修复成立（非 Re 相关单点巧合）
