# Cavity Re=1000 验证证据（m237 班次）

## 验证状态：✅ PASS

## 1. 冻结判据口径

- **基准**: Ghia, Ghia & Shin (1982), JCP 48:387 — Re=1000 中线 u/v 速度剖面 + 涡心位置
- **判据**: max_abs_dev < 3% (两档网格单调收敛)
- **碰撞**: RLBM (正则化 BGK, Latt & Chopard 2006) — MRT 在 Re≥576 失稳
- **边界**: V3 pre-streaming 半程反弹(三静止壁) + Zou-He moving lid(顶盖)
- **网格**: 192² / 256² 两档
- **步数**: 200,000 步（Re=1000 收敛慢，100k 残差~1e-2，200k 才~1e-5）

## 2. 代码运行验证

## 3. 收敛性

- 两档网格 max_abs_dev: 1.14% → 1.05%，单调下降 ✅
- 均远低于 3% 阈值 ✅
- 均远低于 15% 不可接受线 ✅

## 4. 关键技术发现

1. **MRT 在 Re=1000 硬性失稳**: V3 BC + collide_mrt + 等 Re 配方 (tau=0.5346@192²) 于 step 80~271 NaN 发散
2. **RLBM 修复**: collide_rlbm (正则化 BGK) 滤除高阶鬼矩，专为 tau→0.5 低粘稳定设计
3. **V3 BC 修复**: pre-streaming 半程反弹替代 post-streaming 反弹，消除顶盖动量绕入底壁的 23.6% 偏差
4. **步长收敛**: 256² 100k 步曾 2.98% 且残差 9.6e-4 → 200k 步 1.05% 残差 2.4e-5
