# B17: 2D Taylor–Green 涡衰减基准（验证 LBM 数值耗散）

**状态：✅ 已验证（真实模拟，无外推、无人工修正）**

## 物理问题

周期域 [0,L)²（晶格单位 L=N, Δx=Δt=1）上的 2D Taylor–Green 涡，是
不可压 Navier–Stokes 方程的**精确解析解**（非线性项被压力梯度精确抵消，纯粘性衰减）：

```
u(x,y,t) = -U0·cos(kx)·sin(ky)·e^{-2νk²t}
v(x,y,t) = +U0·sin(kx)·cos(ky)·e^{-2νk²t}
ν = (τ − 1/2)/3,   k = 2π/L,   Re = U0·L/ν
```

## 衰减率（关键推导：速度场与动能衰减率相差 2 倍）

TG 速度场由波矢 (±k, ±k) 的四个 Fourier 模叠加而成，|κ|² = 2k²：

- **速度场**：∂u/∂t = ν∇²u ⇒ 速度衰减率 **γ_vel = 2νk²**（即解析解中的 e^{-2νk²t}）；
- **动能**：E(t) = 0.5·⟨u²+v²⟩ = (U0²/4)·e^{-4νk²t}，E ∝ u² ⇒ 能量衰减率 **γ_E = 2·γ_vel = 4νk²**。

因此拟合 ln(E) vs t 的斜率应对比 **γ_E_theory = 4νk²**（而不是 2νk²——
后者是速度场的衰减率）。本 benchmark 同时拟合 ln(|u|_max) vs t 得到 γ_vel，
与 2νk² 交叉验证，两者均须 ≤1% 偏差。

## 判定标准

| 指标 | 公式 | 阈值 |
|------|------|------|
| 动能衰减率偏差 | \|γ_E_sim/γ_E_theory − 1\| | ≤ 1% 达标 |
| 速度衰减率偏差（交叉验证） | \|γ_vel_sim/γ_vel_theory − 1\| | ≤ 1% |
| 指数衰减质量 | ln E vs t 线性拟合 R² | ≥ 0.999 |

真实模拟：动能 E(t) 与 |u|_max 每 100 步实测记录，无任何外推/修正。
LBM 的离散数值耗散若存在，会使 γ_sim ≠ γ_theory，偏差符号如实报告。

## 配置（标准案例）

- 网格：**N=128×128**，周期边界（solver `stream()` 模运算内建，无额外 BC 处理）
- 速度：U0 = 0.05（Ma ≈ 0.087，压缩性误差 O(Ma²) ≈ 0.7%）
- Re = 100 ⇒ ν = U0·L/Re = 0.064，τ = 0.692
- k = 2π/128 = 0.04909
- 碰撞：BGK（`collide_bgk`）；流步：`stream`；精度：float32（库默认）
- 步数：自动按 E/E0 → e⁻³ 衰减确定（标准案例 ~4900 步），每 100 步记录一次

## 结果（标准案例 N=128, Re=100, U0=0.05，2026-08-18 实测，见 result.json）

| 量 | 模拟值 | 理论值 | 偏差 |
|----|--------|--------|------|
| γ_E（动能衰减率 4νk²） | 6.166361e-04 | 6.168503e-04 | **−0.0347% ✅（≤1%）** |
| γ_vel（速度衰减率 2νk²） | 3.084229e-04 | 3.084251e-04 | −0.0007% ✅ |
| ln E 拟合 R² | 1.000000 | — | 纯指数衰减 |
| 质量漂移（相对） | +5.2e-05 | 0 | 守恒良好 |

注：γ_sim 略**小于** γ_theory（约 −0.03~−0.04%），即离散 BGK 的等效粘性
在该参数区略低于 (τ−1/2)/3 —— 这是离散格式 O(k²) 修正的真实测量结果，
偏差符号如实记录，无任何人工修正。
