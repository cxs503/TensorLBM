# 圆柱 Re=100（自由流 Kármán 涡街）— Braza 验证

**状态：✅ 已入库（2026-08-19，Cd -1.5%/-2.6%、St ±2.4% 两档收敛）**

## 物理问题

自由流圆柱绕流 Re=100，Kármán 涡街：
- **Braza et al. 1986（JFM 165）**：Cd=1.35±0.05（实验）、St≈0.164-0.165
- 2D 数值文献：Cd 1.31-1.39、St 0.164-0.168

## 共性模块

库 solver 路径（D2Q9）+ **sponge 层（本次新增共性模块）**：
- solver.collide_mrt（支持 tau_field 逐格松弛）+ stream + d2q9.equilibrium
- boundaries.far_field_bc_2d + **make_sponge_strength**（下游 10D 渐变吸收）
- 入口播种：2 周期正弦扰动（St_seed=0.165，10% 振幅）后回归自由流

## 关键修复（两个根因）

1. **播种权重 bug（NaN 真根因）**：b4v3 手写 D2Q9 速度权重 `cy_w=[0,0,1,0,1,0,1,0,1]` 符号/位置错误——正确应为 `[0,0,1,0,-1,1,1,-1,-1]`。导致入口播种 uy 被算成 ≈0.277（应为 ~0.008），等价 3.5 倍来流横向射流 → 播种 18 步即爆炸。修复为直接取库常量 `d2q9.C` 列。
2. **far-field 出口尾流反射**：零梯度出口对涡街尾流反射压力波 → 20000 步发散。sponge 层（下游 10D，τ 渐变 α=10）消除反射。

## 共性模块新增（提交 2f5282f）
