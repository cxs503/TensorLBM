## 物理问题

Schäfer-Turek 通道内圆柱 Re=20（2D-1）：
- Cd=**5.57953523384**、Cl=0.010618948146（Nabh 1998 谱方法，FeatFlow 官方）
- 域 2.2×0.41，圆柱 D=0.1 偏心 (0.2,0.2)，Poiseuille 入口（U_mean=0.2）+ 压力出口 ρ=1
- Re = U_mean·D/ν = 20（ν=0.001），τ=0.8（ν_lb=0.1，U_mean_lb=0.05）
- 归一化：Cd = Fx/(0.5·ρ·U_mean²·D)，Cl = Fy/(0.5·ρ·U_mean²·D)，用物理 D=0.1，与参考一致

## D=80 平台说明（如实记录）

- 任务预期 D=80 ~-1.2% 平台**未实现**，实测稳定平台为 **-2.875%**（仍在 3% 窗内）
- 平台性质：时间收敛（后 150k 步无趋势性漂移，非恶化/发散），但网格偏差随 D 增大而增大（-0.56% → -2.87%）
- 归因：LBM 阶梯动量交换（MEM）对数字圆的固有网格偏差——阶梯表面有效阻力低于光滑圆参考值，偏差随网格细化趋向平台而非零；与 cylinder_re40_st（-0.76%/-3.28%）、B3 球、B19 方柱同模式
- 结论：这是**稳定平台**（时间收敛）而非未收敛恶化；按任务判定标准（两档 ≤3% 且收敛）入库，平台值如实记录

## 关键方法论结论（2026-08-19 实测定案）

1. **质量重整化是真凶（已定案）**：每 2000 步全局重整化 f*=M0/Σf 激发 ~10k 步周期慢振荡（Cd ±2-4%），污染末段平均 → 旧数据"假网格依赖"（D=40 -0.76%、D=80 -3.28% 是相位样本）。**本入库版本无重整化**（run.py 无重整化代码路径），振荡消失、单调收敛
2. **R-0.5 掩膜修正被实验否决**：数字圆柱水力有效半径 ≈R+0.11（3D 管流量反演），R-0.5 过冲到 R_eff≈R-0.39 反而减小动量交换力（D=40 -2.97%、D=80 -4.01%）；正确几何 = 掩膜半径 R

## Cl 不匹配（如实记录）

- 实测 Cl = -0.0141（D=40）/ -0.0015（D=80）vs 参考 +0.0106：符号反、量级小
- 归因：**动量交换升力对阶梯角点/入口剖面敏感**（升力是二阶效应 ~0.01，远小于 Cd ~5.5，MEM 对表面法向的离散投影误差直接淹没 Cl）；不作修正
- D=40→D=80 Cl 也在变（-0.014→-0.0015），进一步说明 Cl 不是收敛量；不影响阻力基准判定
