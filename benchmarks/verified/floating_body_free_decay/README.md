# B6DOF-1: 浮体静水自由衰减 — 固有频率解析闭包验证

**判决（见 `result.json`）：VERIFIED —— 无阻尼自由振荡频率在 heave / roll 两个自由度、
两个时间步档位上均 `< 3%`（实测相对解析值偏差：+1.07%/+0.26%（heave）、
+1.21%/+0.30%（roll）），两档收敛跨度 ≤ 0.91%，特征值求解器精确，时间积分器
复现辛-Euler 离散色散理论到 `< 0.001%`。

本条目验证 6DOF 闭包的**固有频率**链路；**辐射阻尼 / 流体记忆效应**为诚实记录的
未验证项（诊断显示卷积在细步长下不稳定），见下。

## 验证对象（纯闭包，无 LBM 流场）

| 组件 | 作用 |
|---|---|
| `tensorlbm.rao_analysis.compute_natural_frequencies` | 解广义特征值问题 `(M+A)⁻¹C` 得 `ω_n` |
| `tensorlbm.rigid_body_6dof.cummins_time_integration` | 时域 Cummins 方程积分器 |

无阻尼、无外力时单自由度 Cummins 方程退化为简谐振子，其**精确解析**固有频率为

```
ω_n = sqrt( C_dof,dof / ( M_dof,dof + A∞_dof,dof ) )     ........ (A)
```

`M` 为刚体质量/惯量，`A∞` 为无限频率附加质量，`C` 为静水恢复矩阵。

## 参考（多源核对）

1. **(A) 解析式**：线性浮体耐波性标准结果（Faltinsen 1990《Sea Loads on Ships and
   Offshore Structures》§5；Newman《Marine Hydrodynamics》）；即质量-弹簧-阻尼
   体系中弹簧-质量固有频率。三方交叉：解析式 (A) ≡ `compute_natural_frequencies`
   特征值 ≡ 时域自由振荡实测频率。
2. **离散色散参考**：辛-Euler（显式速度 + 位置更新）对 `ẍ=-ω²x` 的精确数值频率为
   `ω_h = arccos(1 - (ω_n·dt)²/2)/dt`（特征方程 `λ²-(2-ω²dt²)λ+1=0`，单位圆根）。
   该式用于把"积分器离散偏差"与"实测误差"分离：
   `|ω_meas - ω_h|/ω_h < 0.001%` ⇒ 积分器本身精确，相对 (A) 的 ~1% 误差**全部**
   来自辛-Euler 的 O((ω_n dt)²) 色散，且随 dt 减半而 4× 收敛。

## 模型与协议

- 两自由度：**heave**（DOF 2，`C=ρgA_wp=2000`, `m+A∞=2000` ⇒ `ω_n=1.000`）；
  **roll**（DOF 3，`C=ρg∇GM_T=4905`, `I+A∞=1600` ⇒ `ω_n=1.751`）。
- 每自由度两档：coarse `ω_n·dt=0.5`，fine `ω_n·dt=0.25`（dt 减半）。
- 激励：单步单位冲量 `F_exc[0,dof]=1`，此后自由振荡，记录 16 个周期。
- 观测：位置零穿越时刻（线性插值）线性拟合半周期 ⇒ `ω_meas`；并以定频扫描
  LSQ 正弦拟合 `ω_lsq` 独立交叉核对（两者一致到 `<0.01%`）。
- **PASS 判据**：(1) 每档 `|ω_meas-ω_n|/ω_n ≤ 3%`；(2) 同自由度两档跨度 ≤3%；
  (3) 特征值求解器 `|ω_eig-ω_n|/ω_n < 1e-3%`；(4) `|ω_meas-ω_h|/ω_h < 0.5%`。

## 未被本基准覆盖（诚实边界）

- 所有 `M / A∞ / C / B` 均为**调用者合成**系数；本闭包**不从 LBM 流场提取载荷、
  不耦合 hull、无自由面、无实验数据**。
- **辐射阻尼 / 流体记忆效应**（延迟函数卷积 `∫K(t-τ)ξ̇dτ`）**未验证**，且诊断显示
  该卷积实现**对步长敏感、细步长下不稳定**：
  | dt | B0 | ζ | ω_meas vs ω_d 解析 | 首/末周期幅值 |
  |---|---|---|---|---|
  | 0.02 | 50  | 0.0125 | +0.876% | 9.6e-6 → 1.6e-5（**放大**） |
  | 0.02 | 200 | 0.0500 | +3.192% | 8.6e-6 → 9.8e-5（**放大 11×**） |
  | 0.05 | 50  | 0.0125 | +0.015% | 2.4e-5 → 1.5e-5（衰减） |
  | 0.05 | 200 | 0.0500 | −0.014% | 2.2e-5 → 5.1e-6（衰减） |
  细步长（dt=0.02）下延迟核出现**能量注入**（幅值增长）——有限带宽
  `K(t)=(2B0/π)(sinω_max t)/t` 对 `2B0·δ(t)` 的采样在 Nyquist 附近混叠，
  加上仓库卷积的矩形法 + 500 步历史截断。故阻尼/记忆路径**列为诊断，不计入判据**。
- 因此本基准是**线性解析闭包自洽性验证**，**不是** LBM 端到端耐波/操纵验证。
