# Sphere Drag Coefficient Benchmark (BFL Interpolated Bounce-Back)

## Overview

This benchmark validates the TensorLBM D3Q19 implementation of sphere flow
against the Schiller–Naumann empirical correlation across the full
Reynolds-number range, using Bouzidi–Firdaouss–Lallemand (BFL) interpolated
bounce-back for curved boundary treatment.

## Physics Background

### Schiller–Naumann Correlation (1933)

For a smooth sphere in uniform flow:

$$C_D = \frac{24}{Re}\left(1 + 0.15\,Re^{0.687}\right) + \frac{0.42}{1 + 42500/Re^{1.16}}$$

Valid for Re ≲ 3×10⁵. In the Stokes limit (Re → 0), C_D → 24/Re.

### BFL Interpolated Bounce-Back

The Bouzidi–Firdaouss–Lallemand (2001) scheme provides second-order accurate
boundary treatment for curved surfaces by interpolating the distribution
functions at the exact wall position, rather than at the half-way point.

For a boundary link with fractional distance q ∈ (0, 1]:
- **q < 0.5** (linear): f_bc = 2q·f(d) + (1−2q)·f(d)(x−c_d)
- **q ≥ 0.5** (quadratic): f_bc = f(d)/(2q) + (2q−1)/(2q)·f(opp_d)

Reference: Bouzidi, M., Firdaouss, M., & Lallemand, P. (2001). "Momentum
transfer of a Boltzmann-lattice fluid with boundaries." *Physics of Fluids*,
13(11), 3452–3459.

## Acceptance Criteria

1. **C_D error**: Re≤1 → ≤5%, 1<Re≤100 → ≤8%, 100<Re≤1000 → ≤12%
2. **Grid convergence**: D=40 vs D=20 correction ≤5% (Re≤100)
3. **Force-moment conservation**: steady-state residual ≤1%
4. **Flow symmetry**: Re≤1 wake asymmetry ≤0.5%
5. **Reproducibility**: same seed, C_D rel<1e-12

## Implementation Notes

- **Lattice**: D3Q19 with MRT collision
- **Boundary treatment**: BFL interpolated bounce-back for sphere surface
- **Force computation**: Momentum exchange method with BFL correction
- **Domain**: Auto-sized (geometry bbox × 3 with streamwise padding)
- **Mass correction**: Every 200 steps

## Limitations

1. **High Re dissipation**: LBM has inherent numerical dissipation at high Re,
   limiting accuracy for Re > 500.
2. **Grid resolution**: D=20 may be insufficient for Re > 200; D=40 recommended.
3. **Domain size**: Small domains can cause blockage effects; domain factor ≥ 3
   recommended.
