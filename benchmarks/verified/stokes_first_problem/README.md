# B24: Stokes 第一问题（平板突然起动, D2Q9）—— 时变解析 erf 解验证

**状态：✅ 已验证（真实模拟，无外推、无人工修正）**

## 物理问题

半无限静止流体上方，y=0 处无限长平板在 **t=0 时刻突然以恒定速度 U 沿 x 方向
运动**（Stokes 第一问题 / Rayleigh 问题）。流场仅依赖 y 与 t，满足一维扩散方程
∂u/∂t = ν∂²u/∂y²，**精确解析解**（erfc 解）：

```
u(y,t) = U · erfc( y / (2·sqrt(ν·t)) ),    ν = (τ − 1/2)/3,  t 为格子步数
```

边界层厚度 δ = √(ν·t)。这是 LBM 时变边界层的标准解析验证（验证数值粘性
与扩散行为的正确性）。

## 数值设置（真实模拟，无外推）

- **库函数原语**：`d2q9.equilibrium` / `d2q9.macroscopic`、
  `solver.collide_bgk` / `solver.stream`（周期 gather）
- **域**：x 方向周期（流向均匀，nx=8 格），y 方向 H 格流体 + 上下壁行
  （ny = H+2）；初始全域静止（u=0, ρ=1），第一步起下壁以 U=0.05 运动
- **下壁（y=0，移动壁）**：pre-streaming half-way 反弹 + 动量注入
  `f_new[opp(i)] = f_pre[i] − 2·w_i·ρ_w·(c_i·u_w)/cs²`（u_w=(U,0)，ρ_w 取壁格
  当地密度；与静止 BB 相比仅多一项 O(U) 修正，U=0 时退化为普通反弹）。
  repo 已验证的 pre-streaming BB 模式（同 poiseuille_2d）
- **上壁（y=ny−1，远场）**：自由滑移镜面反弹（SPECULAR=[0,1,4,3,2,8,7,6,5]，
  翻转 c_y 保持 c_x），实现应力自由远场 ∂u/∂y≈0，x 动量严格守恒
- **参数**：τ = 0.65（ν = 0.05），U = 0.05（Ma = U/c_s ≈ 0.087，
  压缩性误差 O(Ma²) ≈ 0.75%），float32，测量剖面列取 x=0（x 均匀）
- 记录 t = 1000 / 4000 / 9000 步的 u(y) 剖面；无修正因子、无结果调参

### τ 的选择依据（半无限域截断判据，实测诊断）

erfc 解是**半无限域**解；有限高域必须满足 H ≳ 4δ 才能忽略顶边界影响。
诊断实测（τ=0.8, ν=0.1, t=9000 → δ=30, **4δ=120 > H=100**）：

| 配置 | t=9000 剖面最大相对误差 | 原因 |
|------|------------------------|------|
| H=100, τ=0.8（4δ=120>H） | **10.5%** | 扩散前沿触及顶壁，动量无法外泄，域截断 |
| H=200, τ=0.8（4δ=120<H） | **0.094%** | 半无限近似成立 |
| H=100, τ=0.65（4δ=85<H） | **0.084%** | 半无限近似成立（本 benchmark 采用） |

（静止无滑移顶壁对照：H=100, τ=0.8, t=9000 为 10.8%——顶壁强制 u=0 与
自由滑移差异不大，主因是 4δ>H 的动量截断本身。自由滑移顶壁在 4δ<H 时
与静止顶壁结果一致，且对远场条件更忠实，故采用。）

## 判定标准

| 指标 | 公式 | 阈值 |
|------|------|------|
| 剖面最大相对误差 | max_y \|u_num − u_ana\|/u_ana（u_ana > 5%·U 区域，避免 erfc 尾部除零放大） | ≤ 3% |
| 网格收敛 | H=200 各时刻 max_rel ≤ max(H=100 值, 3%)，且两档剖面一致 | 收敛 |

## 结果（τ=0.65, U=0.05, ν=0.05，2026-08-18 实测，见 result.json）

**两档网格全部时刻最大相对误差 ≤ 0.25%（阈值 3%）**，网格收敛成立：

| t（格子步） | δ=√(νt) | H=100 max_rel | H=200 max_rel | 两档剖面差（%·U） |
|-------------|---------|---------------|---------------|-------------------|
| 1000 | 7.07 | 0.248% ✅ | 0.249% ✅ | 0.001% |
| 4000 | 14.14 | 0.054% ✅ | 0.048% ✅ | 0.002% |
| 9000 | 21.21 | 0.084% ✅ | 0.074% ✅ | 0.078% |

- 误差随 t 先降后略升：t=1000 时边界层仅 ~7 格（薄层离散分辨率限制，
  最大相对误差 0.25%）；t≥4000 进入自相似区后误差 ~0.05-0.08%
- 两档网格（H=100 vs H=200）同一时刻剖面差 ≤ 0.078%·U —— 域截断收敛
- 近壁首格（y=0.5）速度误差：t=1000 时 u_num/U=0.9602 vs 解析 0.9601
  （相对偏差 ~0.007%）—— 移动壁动量注入正确
- 质量漂移 ~1e-2%（移动壁修正项 Σ w_i c_ix = 0 保证总质量守恒），finite=True
