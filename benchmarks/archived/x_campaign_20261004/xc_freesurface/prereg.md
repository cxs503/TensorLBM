### W1-A 前锋捕获出生（front-capture G→I birth）——质量运输通道恢复

对每个气胞 y（非固）与链 q（y 的拉源 x = y − c_q 为 INTERFACE）：

```
birth_capture(y) := [flag(y)=GAS] ∧ ¬solid(y) ∧ ∃q: flag(y−c_q)=INTERFACE ∧ c_q·u(y−c_q) > u_cap
```

出生态与 D4 事件出生**完全同构**：种群 = `_init_fresh_interface`（液侧邻均，函数零改动）、
`m := 0`、旗标 G→I；账本新计数 `n_g2i_capture`。u_cap 冻结 = 0.03（物理晃动 ≲0.01 与
门带 0.1 之间；敏感性消融 {0.02, 0.05}）。

**窄化变体 capture_rescue**（同式加一个源侧限定）：出生仅当拉源 x 为**孤独界面胞**
（无非固 LIQUID 邻，与 S5 no_liq 子判据同谓词）。动机：全变体的坍塌飞溅出生把
n_interface 推到 6.1×初始（τ=1.0，t=400-800），超 G2 冻结 3× 上界（v1.1 自身峰 1.90×）；
窄化把出生限于陷阱宿主邻域。消融冒烟（τ=0.55, 10⁴ 步）：全变体 uy 晚期 max 0.0244/
僵尸 2.01/膜 15.6 vs 窄化 0.0740/5.59/25.6——全变体在三判据余量上占优；两变体在 τ=1.0
均越 G2 字面（6.14×/3.97×）。**主设计定案 = 全 capture（u_cap=0.03）**；窄化降级为
机制归因消融臂 W1-R-055（§4）。若 τ=0.8 归因冒烟改写此取舍（见 NOTES.md Phase 0 记录），
以冻结版 prereg 的臂表为准。

**守恒声明**：质量账本 B = Σ_I m + Σ_L ρ 精确不变（出生 m=0 与事件出生同一论证；
交换/再分配照常）；不可能产生 L-G 直连（出生是 G→I）；fail-closed 不变量照旧。
**作用**：给被锁死的孤立/封闭界面胞一个接收者——出生后 from_if 交换链存在，质量可离开、
转换不再 starved、液滴可平移并汇入池。同时解锁溃坝前锋推进（底面三相遇角无需等
I→L 事件）。**预期杀**：T-W1(c) 僵尸宿主、starved 持续重试、M3 前锋角推进受限分量。

### W1-B 壁带闭合对称化（wall-band closure symmetrization）——固侧闭包取气侧同型

界面胞（非固）的固源链 q（拉源为 SOLID）：

```
f(q,x) := feq_q(ρ_w, u*) + feq_ō(q)(ρ_w, u*) − f̃_ō(q)(x)        （镜像形，替换 halfway BB 的 f̃_ō(q)(x)）
u* := neighbor_average_velocity(x)（与气侧 ABB 同一锚函数，零新参）
ρ_w := ρ_l（冻结）
```

液胞壁链保持标准 halfway BB（no-slip 不动）；legacy 壁模式不动。

**守恒/对称性声明**：(i) 质量账本不触（固源链从不进交换）；(ii) 种群封闭胞的逐通道
动量注入 P=0 恰成立（与气侧闭包同一镜像对称——被测量的 P_bb 整流源被构造性消除）；
(iii) 静水极限 u*=0 时镜像形与 halfway BB **代数恒等**（feq 对 rest 值 − feq_opp =
feq_q ⇒ G3 剖面不动）；(iv) 申报偏差：界面胞壁链的 no-slip 切向阻尼被对称化置换
（润湿/接触角模型仍 owner 级，不在本包）。**预期杀**：壁接触 BB 通道 +uy 整流、
壁带膜维持、近壁活跃行钉扎的壁带分量（M3 H 钉扎贡献项）。
