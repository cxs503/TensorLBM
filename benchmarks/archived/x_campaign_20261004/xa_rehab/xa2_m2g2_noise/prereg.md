## 1. 背景与假设链

- M2（SC MCMP 3D Laplace 闭合）收案 = honest FAIL，唯 G2 不过:
  err(N)=|σ_sph(N)−σ_ref|/σ_ref = 0.4718715937933545% → 0.5401836371738816% →
  0.4021058336828771%（N=96→144→192），144 处微升 +0.068312pp 杀单调条款;
  err(192)=0.40% ≤3% 本身过门。球 σ 三格带 0.11214–0.11230（带宽 0.14%）。
- 控制器遗留裁量项 #2: "G2 单调条款在 err 全 <0.6%、带宽 0.14% 噪声量级下的
  裁定"——本实验直接回答。
- **H1（主假设）**: σ_sph 点估计的末窗采样噪声（dp 尾段 std 2–6e-6 量级、
  R3 已证 σ 对运行时长敏感 ~0.2pp）与 0.068pp 的 144 微升同量级，即原阶梯的
  非单调性不可分辨于窗噪声之上。
- **H2**: 用同冻结配置延长运行（2× 步数、尾窗样本翻倍、均值噪声降 √2）后，
  err_ext(N) 恢复单调不增。
- H2 成立 → M2 升级候选（报控制器裁量，不自改 M2 判决）; H2 不成立 →
  非单调性为结构性，M2 维持 honest FAIL 关案。
- 语义边界（预注册）: 本实验**不改 M2 冻结判决**（formal/verdict.json 与
  alternative_all18.json 原样）; 输出是"延长窗读数 + 噪声尺度表"，翻案权在
  控制器。R3 先例（formal_r3/ 单臂 4000 步敏感度档）即本设计的直接前驱。

## 4. 读数定义

- **冻结前缀读数** σ_pre(N): 2× 序列截断到冻结步数的前缀, 尾段=前缀末 20%
  样本（与 formal 等长同位）→ 过原点 LSQ dp vs 2/r_eq（冻结拟合式）。
- **延长窗读数（主读数）** σ_ext(N): 全 2× 序列, 尾段=末 20% 样本 → 同拟合。
- err_pre / err_ext(N) = |σ(N) − σ_ref| / σ_ref, σ_ref 冻结值（§2）。
- 单调不增: err(96) ≥ err(144) ≥ err(192)（精确浮点比较, 相等算过; 与冻结
  条款"单调不增"同语义）。

## 5. 噪声尺度（诊断, 不载翻案判决）

- 每臂把冻结尾段与延长尾段各分 3 个不相交子窗（种子等价物; ≥3 复本）,
  每子窗给 (dp_mean, r_eq_mean) → 每 N 过原点 LSQ 得 3 个 σ_sph 子窗值,
  报告逐 N 的子窗散布 (max−min) 与 std。
- 归因表: 原 bump(+0.068312pp) 与 ext bump = err_ext(144)−err_ext(96) 并列
  各 N 子窗噪声尺度。
- 蠕变敏感度表（R3 谱系）: 逐臂 σ_pre vs σ_ext 相对移动及方向。

## 6. 门与翻案规则（预注册, 见数字后禁改）

- **R-A 确定性回执（先于一切）**: 9/9 臂 σ_pre 的尾段统计与 formal 档案
  tail_stats.dp_mean / r_eq_mean 相对差 ≤1e-9（预期逐位）。任一臂不过 →
  **停跑报环境漂移**, 无任何判决。
- **R-B 翻案条款**: R-A 过后, 若 **err_ext(96) ≥ err_ext(144) ≥ err_ext(192)
  且 err_ext(192) ≤ 3%** → "G2 在延长窗读数下单调成立" → **M2 升级候选**,
  停批报控制器裁量（是否以修正案改判 M2 由控制器决定; 本轨无自改权）。
- **R-C 维持条款**: R-B 不满足 → 144 微升非窗噪声可解释 → **结构性非单调,
  M2 维持 honest FAIL 关案**（X 轨内不再重开 M2 G2）。
- Run 级 sanity（每臂全过才计入拟合）: 无 NaN; tail-std(dp)/|dp| < 2%;
  尾段 |R_eq 漂移| < 0.5 格; 质量漂移按 R1 登记式**每步率 ≤2e-8/步**
  （2× 时程下绝对门必越界, M2 修正案 1 已登记等价形式; 全臂披露绝对值）。
- G1/G3/G4 不重判（不受本实验影响; 其冻结判决不变）。

## 7. 预算与止损

- 预算: 9 臂 ≈ (3×8000 + 3×12000 + 3×16000) 步; N192 ~19 steps/s 推得
  总 wall ≈ 55–70 min GPU6 → **≤1.5 GPU·h**（X 轨 48 GPU·h 池内）。
- 止损: 任一臂 2× 步内 NaN/失稳 → 立即停, 报原始 JSON, 无判决;
  配置不得中途修改; 超预算 1.5 GPU·h 即停批回报。
- GPU6 分时: 启动前 nvidia-smi 快照入本目录 ctrl/, 与 T4/他轨错峰,
  窗口记 NOTES.md; GPU5/T1 与 GPU0-4/7 禁碰。
