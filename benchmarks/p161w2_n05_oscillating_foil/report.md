# 扑翼/振荡翼推进 LBM 验证面成熟化（节点 p161w2-arb-n05）

> 仓库 TensorLBM · 求解器 `tensorlbm.oscillating_foil_lbm` · 解析锚 `tensorlbm.flapping_propulsion` · 机器判据 `tensorlbm.oscillating_foil_criteria`
> 场参数 U = 0.15（格点单位）、Re = 500（按弦长）、俯仰轴 a = -0.5（0.25c，自前缘）
> 基准网格 288×128（弦长 32 格）、每周期 670 步、时间平均 0.80 周期

## 1 案例介绍

扑翼推进是仿生推进与水下航行器的核心机理：翼型同时沉浮 `h(t)=h0 sin(ωt+φ_h)` 与俯仰 `α(t)=α0 sin(ωt+φ)`，前缘吸力与脱涡产生推力。本节点在 TensorLBM 建成**完整验证面**：解析侧用 Theodorsen(1935)/Garrick(1936) 线性理论闭式锚；数值侧用 D2Q9 BGK + Guo 力项 + 多轮直接强迫浸没边界（IBM）求解 NACA 0012 剖面的耦合运动，以浸没边界反力积分推力与输入功率，并用控制体动量通量做**独立**力估计。

无量纲量：`k = ωc/(2U)`、`St = fA/U`（A=2h0）、`St = 2k(h0/c)/π`；`C_T = F_x/(½ρU²c)`（正=推力，即 IBM 作用于流体的 +x 力）、`C_P = P_in/(½ρU³c)`、`η = C_T/C_P`。

## 2 怎么做（方法 / 工具链）

1. **解析锚（REAL）**：`C(k)=H₁⁽²⁾(k)/[H₁⁽²⁾(k)+iH₀⁽²⁾(k)]`，两条独立特殊函数路径（Hankel / 修正 Bessel）互校；Garrick 系数按相量法计算并与时间积分互校。
2. **纯沉浮独立代数式自校验**（本节点新增）：`C_T = 4πk²(h0/c)²|C|²`、`C_P = 4πk²(h0/c)²F`、`η = |C|²/F`；`k→0` 时 `C_T → π(h0/b)²k²`。
3. **LBM 求解器**：D2Q9 BGK + Guo 力项（`u*=u+F/2ρ`），4 点 Peskin 核（可选 2 点），标记间距 0.5 格，2 轮直接强迫；剖面内部实体填充（内点强制到刚体速度）；入口平衡态、出口零梯度 + 6% 海绵、侧向自由滑移。
4. **双独立力估计**：IBM 反力积分 vs 控制体动量通量（下游平面置于海绵层之外）。
5. **能量账**：闭合周期箱 `W_fluid = ΔKE + Φ`，耗散用连续 `2νS:S` 与离散 `-(τ-½)/τ Π^neq:∇u` 两种估计（4 阶中心差分），并以 Taylor–Green 涡解析衰减率 `4νk²` 在 pytest 中验证。
6. **判据**：C1/C1b（线性区与振幅标度）、C2（效率峰值）、C3（退化极限）、C4（能量账）、C5/C5b（St 单调性与俯仰推力反转）、C6（三网格 GCI）、C7（负控三件套）、C8（位级可复现）、C9（IBM 与控制体互校）；每条判据在 pytest 中都有正例与反例。

## 5 注意点（坑 / 局限 / 适用边界）

1. **薄椭圆几何是大坑**：上一轮（P162W1-N07）用 `t/c=0.04` 薄椭圆，c=32 时厚度仅 1.3 格、比 Peskin 核支撑还薄，有效物体被抹成钝体（C_D≈0.18 且运动几乎不改变合力）。本节点改用 NACA 0012（最大半厚 0.06c）+ 实体内部填充。
2. **数值阻力偏置是主要误差源**：锁定剖面实测 `C_D0=0.2233`（c=32），比 Re=500 层流 NACA0012 文献量级（0.02–0.05）大 5–10 倍，说明有效剖面仍偏钝，这是 C1/C2 未过的主因。
3. **核支撑宽度直接决定推力**：同一算例改 2 点核后 ΔC_T 由 -0.5011 变为 -0.4416（约 ×2.3），C_P 由 0.4926 变为 0.6012——4 点核在 3.8 格厚的剖面上等效加厚了物体。
4. **线性理论的适用域**：ĥ=0.5（h0/c=0.25）远超小振幅假设，Garrick 只能作量级锚；C1 因此只在 h0/c≤0.04、α0≤2° 裁决，其余按可分辨性标注 WITHHELD。
5. **格子声速约束**：`ḣ_max = 2kU(h0/c)`，弱可压缩要求 `ḣ_max ≲ 0.15`；k=3 与 h0/c=0.25 的组合（ḣ_max=0.225）发生数值发散，NaN 如实保留在算例表。
6. **控制体平面必须避开出口海绵**：下游平面落在 6% 海绵内会带来 ~10% 偏置（§3.5 前后对照）。
7. **统计窗口**：强脱涡算例逐周期均值标准差 ~0.1，单周期平均误差达 0.04，必须 ≥8 周期平均。

- **已建成（REAL）**：Theodorsen/Garrick 解析锚（1e-16 级自校验）、NACA0012+多轮直接强迫 IBM 的 D2Q9 求解器、C1–C9 机器判据 + pytest 正反例、Taylor–Green 验证的耗散估计器、场量云图与论文级报告全链路（零手抄，全部数字来自 JSON）。
