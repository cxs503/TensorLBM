## 2. 计算方法

### 2.1 数值方法

**求解器:** TensorLBM D2Q9 格子玻尔兹曼方法

- **碰撞模型:** BGK 单松弛时间
- **格子模型:** D2Q9 (9 个离散速度)
- **力计算:** 动量交换法 (Ladd 1994)
- **边界条件:**
  - 入口：抛物线速度剖面（平衡态重构）
  - 出口：零梯度 + 回流稳定化
  - 壁面：反弹格式
  - 圆柱表面：反弹格式

### 2.2 格子参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 圆柱直径 D | 20 lu | 格子单位 |
| 通道高度 H | 82 lu | H/D = 4.1 |
| 计算域 | nx=320, ny=85 | - |
| 平均速度 U_mean | 0.05 lu/ts | Ma ≈ 0.05 |
| 运动粘度 ν | 0.01 lu²/ts | Re=100 |
| 松弛时间 τ | 0.53 | τ = 3ν + 0.5 |
| 马赫数 Ma | 0.05 | 不可压条件满足 |

### 2.3 验证流程

1. **初始化:** 抛物线速度剖面 + 平衡态分布函数
2. **时间推进:** 碰撞 → 迁移 → 边界条件 → 力计算
3. **采样:** 每 5 步记录一次升阻力系数
4. **瞬态去除:** 跳过前 30% 时间步
5. **统计分析:**
   - C_D: 周期区域时间平均
   - St: 升力系数 FFT 峰值频率

### 2.4 工具链

- **代码框架:** TensorLBM (PyTorch backend)
- **后处理:** NumPy, Matplotlib
- **FFT 分析:** numpy.fft
- **可视化:** matplotlib

## 5. 注意点与局限性

### 5.1 计算资源限制

**主要问题:** CPU 计算速度过慢，无法在合理时间内完成完整验证。

**解决方案:**
1. **GPU 加速:** 使用 CUDA/MPS 后端可提速 10-50×
2. **网格优化:** 使用 AMR 在圆柱附近加密
3. **并行计算:** 多 GPU 或 MPI 并行

**建议配置:**
- GPU: NVIDIA V100 或更高
- 分辨率: D ≥ 40 lu
- 时间步: ≥ 30,000
- 预计时间: 10-30 分钟 (GPU)

### 5.2 数值方法局限

1. **一阶边界精度:** 标准反弹格式为一阶，建议使用：
   - 曲面边界格式 (curved boundary)
   - 插值边界格式 (interpolated BC)
   - 浸没边界法 (IBM)

2. **BGK 碰撞限制:** 高 Re 下稳定性差，建议：
   - MRT 碰撞模型
   - 中心矩 (cumulant) 方法
   - 熵格子 (entropic LBM)

3. **二维假设:** Re=100 可能出现三维效应，但基准测试指定为 2D

### 5.3 验证改进建议

**短期改进:**
1. 使用 GPU 完成完整模拟

3. 使用 Zou/He 边界条件替代简单反弹
