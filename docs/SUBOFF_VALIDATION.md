> 更新时间：2026-08-16
> 验证入口：`examples/octree_integrated_validate.py`（torchrun 2 卡，D3Q27 cumulant 粗网格 + 八叉树壳 / L1 中间块）

## 2. 阻塞（blockage）修正规范

受限域（风洞效应）下，横向壁面会加速绕体流动，正确解算器在受限域中应得到**更高**的 Cd；
因此用标准风洞因子把无限域参考值向上修正，使报告的误差反映网格/离散误差而非域尺寸伪影。

### 2.1 参数定义

| 符号 | 定义 | 本配置取值 |
|---|---|---|
| D | 船体直径 = 2 × r_over_l × L | 2 × 0.05834 × 60 = **7.0008** |
| Ly | 域宽 = ny | **64** |
| β | 阻塞比 = D / Ly | **0.10939（10.94%）** |
| f_simple | 修正因子 = 1/(1−β)²（Maskell/Bartz） | **1.26075** |
| f_glauert | 修正因子 = 1/(1−1.5β)（可选） | 1.19630 |
| Cd_ref,inf | 无限域参考 | 0.004（hull 摩擦基准） |
| Cd_ref,blocked | 修正后参考 = Cd_ref,inf × f | **0.00504299** |

> β > 12.5% 时脚本会打印建议扩大域到 Ly ≥ 8D；本配置 β=10.94% 低于该阈值，无需扩大。

### 2.2 误差定义

```
err_pct           = 100 × (Cd_mem − Cd_ref,blocked) / Cd_ref,blocked   （修正后误差，主指标）
err_pct_inf_domain = 100 × (Cd_mem − Cd_ref,inf) / Cd_ref,inf         （相对无限域参考）
```

### 2.3 JSON 输出字段（规范化格式，所有运行一致）

| 字段 | 含义 |
|---|---|
| `blockage_ratio` | β = D/Ly |
| `blockage_correction` | 修正模型字符串（`simple 1/(1-beta)^2` / `glauert 1/(1-1.5*beta)` / `off`） |
| `blockage_factor` | 修正因子 f |
| `ref_Cd_inf` | 无限域参考值 |
| `ref_Cd` | 修正后参考值 = ref_Cd_inf × f |
| `err_pct` | 相对修正后参考的误差（%） |
| `err_pct_inf_domain` | 相对无限域参考的误差（%） |
| `domain_scale_note` | β>12.5% 时的扩域建议（如触发） |

> 注意：早于 2026-08-14 的旧输出（如 `integrated_suboff3.json`）只有 `cd_mem/ref_Cd/err_pct`，
> 无 blockage 字段；数值已在本文档 §3 中按上述规范补齐。

## 4. 结论与待办

1. **两级路径**：Re ≤ 1e4 稳定收敛，Cd 随 Re 单调下降（0.8000 → 0.7553 → 0.7111），
   与高 Re 下压差阻力占比变化趋势一致；Re=1e5 因壳层粘性下限（tau→0.5）发散（NaN），为已知限制。
2. **L1 路径**：Re=100 稳定但 Cd=0.2721 显著低于两级路径 0.8000 —— 力衰减问题排查中（另一任务）。
3. **L1 Re=1000**：本次验证（tau_l1=0.5216，比 Re=100 更小）—— 结论见上表 3.2。
4. 误差量级（~1.5e4%）源于 `ref_Cd_inf=0.004` 为 hull 摩擦系数基准，与 Cd_mem 的归一化基准不一致；
   参考基定义需另案核对（不在本任务范围）。
