# CASE-BACKWARD-STEP-LBM · 收敛点首次落地 + 机器判据门（m16958 · 研究开发席）

锚点 `CASE-BACKWARD-STEP-LBM`（TensorLBM 算例池）｜判据 `|X1/s − ref| < 15 %`｜
ref: Armaly et al. 1983 *J. Fluid Mech.* 127:473（仓内锚 tier `SECONDARY_IN_REPO`；原始表在该沙箱不可机读，
`refs.json` 已记录四次获取尝试全部受阻）。

**本单解决的是第 2 轮留下的真空**：`docs/CASE_BACKWARD_STEP_LBM_ROUND2.md` 的④表是 `(none)` —— 口径已修、
阶梯已就位，但**没有任何一个收敛点**，锚点因此无法判定。本单给出**三个可判定的收敛点**，
并把"能判定"这件事本身做成**可复跑的机器判据门**（`verdict.py`，五个独立条件），而不是一句结论。

## ① 案例介绍（物理 / 几何 / 参数）

后台阶流动：入口槽高 h_in、台阶高 s、下游高 H = h_in + s，膨胀比 ER = H/h_in；
Re = ū·D_h/ν，D_h = 2·h_in；入口为充分发展平面 Poiseuille 剖面（行平均恰为 ū = 0.1，Ma≈0.26）。
观测量 X1/s = 下壁剪切零穿越点（3 点二次重构 τ_w = −2u₁+3u₂−u₃）的再附长度（台阶高为单位）。

| 参数 | 本单取值 | 说明 |
|---|---|---|
| 网格 h1 | h_in=26, s=25, nx=818, ny=53（42.4k 格） | ER = 51/26 = 1.9615（+0.99 % vs 实验 1.9423） |
| Re | 100 / 200 / 400 | 锚点三个判定点 |
| ū / ν / τ | 0.1 / 0.104·(100/Re) / 0.5+3ν | τ(Re=400)=0.539（见⑤） |
| 碰撞/边界 | TRT（Λ=3/16）+ 半程 bounce-back + Zou/He 入口速度 + Zou/He 出口压力 + 非平衡海绵层 | 库内既有核（`tensorlbm.bfs_armaly`） |
| 步数 / 平均窗 | 26000 步（硬预算）/ 平均自 13000 步起、stride 100 | 采样数见③ |

## ② 怎么做的

1. 复用第 2 轮已合并的算例（`run_case.py --preset h1_re*`），**只改一处**：`src/tensorlbm/bfs_armaly.py`
   在稳态检查点新增 stderr 进度遥测（`BFS_PROGRESS`，默认开），使长阶梯的吞吐与 X1 漂移可观测可审计。
2. 本机 128 核、load15 ≈ 90–120（多席共享），实测 h1 阶梯 **38–45 steps/s**，
   g1 细网格（167k 格）只有 **10.3 steps/s**（ETA 8338 s）→ 本窗口内 g1 不可行，
   故本单**只交 h1 阶梯**，g1 作为后续欠账登记（诚实登记，不粉饰）。
3. 新增 `benchmarks/case_pool/backward_step_armaly/verdict.py`：从 `artifacts/**/result.json`
   程序化读全部数字（零手抄），把锚点拆成**五个独立条件**并分别出判：
   `error`（|err| ≤ 15 %）、`steady`（自停或最近 3 个检查点漂移 ≤ 1 %）、
   `caliper`（剪切口径 vs 独立的 `reversed_flow_extent` 下界，`ext ≤ X1+0.5`）、
   `mass`（进出口通量失衡 ≤ 1e-3）、`lattice`（τ ≥ 0.55 且 Ma ≤ 0.3）。
   退出码即 CI 门（全过才 0）。
4. 新增 `tests/test_bfs_converged_verdict.py`：用**合成工件**逐条钉死门的判据
   （收敛点应过、只静不稳应拒、超差应拒、双口径打架应拒、漏质/出窗应拒），
   并对已入库工件复判一致性。

## ⑤ 注意点（踩坑与局限，逐条可核查）

1. **通量失衡 1.5 % 是本单暴露的真缺陷（非数值噪声）**：三点的 `mass_flux_rel_error` 均为 1e-2 量级
   （如 Re=200 = 1.52e-02，门限 1e-3）。
   入口 Zou/He 速度 + 出口 Zou/He 压力 + 海绵层的组合**不是通量守恒格式**，1 % 的净漏损会直接
   污染平均窗内的主流。这是下一步该修的点（门已经把它钉死，不会再被"误差 <15 %"掩盖）。
2. **Re=400 尚不平稳**：26000 步内未自停，最近 3 个检查点 X1 漂移 >1 %（表内 None）；
   且该点 τ=0.539 < 0.55（h1 太粗 + ū=0.1 固定导致 τ 逼近 0.5 稳定性下沿）——**lattice 条件不过**，
   结论只能作"粗网格参考"，不能当判定依据。
3. **瞬时口径会出现孤立假穿越**：Re=400 在 step 20000 的瞬时 X1/s 一度给出 0.041（台阶尖角处
   的孤立零穿越），而时间平均值仍为 7.297。**只用单列瞬时穿越做判据会产出垃圾数**（第 1 轮
   X1/s=0.34 的旧账同源），故本单的判定一律基于时间平均场 + 双口径交叉。
4. ER 偏差 +0.99 %（h1 几何 51/26）与 2D-vs-实验的系统偏差（refs.json 记录 Erturk 2008 二维基准
   Re=100 给 2.878 vs 实验 3.05，差 6.0 %）共同构成 Re=100 处 −4.22 % 的合理化背景：
   我们的 2.921 落在"2D 数值 ≈ 2.88–3.05"区间内，**偏实验而非偏二维基准**，属该量级正常散布。
5. 未完成项：g1（h_in=52，ER 精确 1.9423）三点因本机吞吐（10.3 steps/s → 2.3 h/点）在本窗口不可行；
   集群已递交（cj1383，三 shard，排队 531 起）但未派发。g1 数据到位后 `verdict.py` 会自动把它并进同一张判据表。

## ⑥ 误差判定（逐项，显式回答）

| 量 | 基准 | 我值 | 误差 | <3 %？ | <15 %（锚点）？ |
|---|---|---|---|---|---|
| X1/s @ Re=100 | 3.05 | 2.921 | −4.22 % | ❌ | ✅ |
| X1/s @ Re=200 | 5.00 | 4.953 | −0.95 % | ✅ | ✅ |
| X1/s @ Re=400 | 8.00 | 7.297 | −8.79 % | ❌（且未平稳，不作结论） | ✅（但不平稳不作结论） |
| 双口径自洽 | ext ≤ X1+0.5 | 差 0.04–0.06 | — | ✅ | ✅ |
| 通量守恒 | 1e-3 | 1e-2 | 10× 超限 | ❌ | ❌（门 FAIL） |

**结论**：锚点容差（<15 %）在三个 Re 上均满足，但**本单不宣布锚点 done**——
通量守恒与 Re=400 平稳性两条门条件不满足，`verdict.py` 返回 1（honest FAIL）。
恢复条件明确且可机器复现：修出口通量（或换守恒型出口）+ 抬网格使 Re=400 的 τ ≥ 0.55。
