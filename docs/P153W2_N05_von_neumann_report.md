# P153W2-N05: Von Neumann Linear Stability & Numerical Dispersion Verification

## 1. 案例介绍（物理背景/几何/参数表）

本节点对格子 Boltzmann 方法（LBM）进行 von Neumann 线性稳定性分析，覆盖：

| 维度 | 内容 |
|---|---|
| **格子** | D2Q9（9 速）、D3Q19（19 速） |
| **碰撞算子** | BGK（单松弛时间）、TRT（双松弛时间）、MRT（多松弛时间） |
| **分析对象** | 数值色散关系 ω(k)、耗散 Im ω(k)、稳定包络 λ_max(τ, Ma) |
| **解析对照** | Chapman–Enskog 剪切模 ω = −iνk²、Stokes 声模 ω = c_s k − i(2/3)νk² |
| **参数范围** | τ ∈ [0.5001, 2.0]，Ma ∈ [0, 0.3]，k ∈ [0, π] |

**物理目标**：给定格子/碰撞算子，机器可算地给出其数值色散 ω(k)、耗散 Im ω(k) 与稳定域，并判定是否落在解析界内。

## 2. 方法/流程/关键设置

### 2.1 von Neumann 分析原理

在均匀基态 f_i^eq(ρ₀, u₀) 上线性化 LBE，代入 Fourier 模态 δf_i = v_i exp(i(k·x − ωt))，得到特征值问题：

```
A(k) v = exp(−iω) v,   A(k) = diag(exp(−ik·c_i)) · P
```

其中 P = I − C(I − J_eq) 为线性化碰撞算子，C 为碰撞矩阵，J_eq 为平衡态 Jacobian。

特征值 μ_j = exp(−iω_j) 给出：
- **增长率** σ_j = ln|μ_j|（> 0 表示不稳定）
- **相速度** c_j = −arg(μ_j)/|k|

由于 μ = exp(−iω)，反演得 **ω = i ln μ**，故：
- Re(ω) = −arg(μ)
- Im(ω) = ln|μ|（负值 = 耗散）

### 2.2 碰撞算子实现

| 算子 | 碰撞矩阵 C | 粘度 ν |
|---|---|---|
| **BGK** | I/τ | (τ − 1/2)/3 |
| **TRT** | 对称模 1/τ₊，反对称模 1/τ₋ | (τ₊ − 1/2)/3 |
| **MRT** | M⁻¹ diag(s) M | (τ − 1/2)/3 |

TRT 的 τ₋ = 1/2 + Λ/(τ₊ − 1/2)，最优 Λ = 3/16 消除 Poiseuille 流的壁面位置误差。

### 2.3 模态识别

物理分支通过 k→0 极限下的重叠度识别：
- **剪切模**：横向速度扰动方向
- **声模**：密度扰动方向（两支：sound+ 和 sound−）

- 核心模块：`src/tensorlbm/stability/von_neumann_full.py`

**结论**：TRT(Λ=3/16) 在所有测试 k 点上非守恒模 |μ| < 1（稳定），且严格小于 Λ=0.4 的负控情形。

## 5. 注意点（踩过的坑/局限/适用范围）

### 5.1 ω 的符号约定
关键修正：μ = exp(−iω) → **ω = i ln μ**（非 −i ln μ）。此前实现中符号错误导致 Re(ω) 和 Im(ω) 均反号。

### 5.2 BGK 体粘度
BGK 碰撞算子的声学衰减系数为 ν（非 Stokes 的 2ν/3），这是因为 BGK 有固定的体粘度比 ζ/ν = 2/3（在 2D）或 5/3（在 3D）。MRT 可通过调节 s_e 独立控制体粘度。

### 5.3 MRT D3Q19 速率向量
D3Q19 MRT 的剪切应力矩（索引 9-13）必须全部设为 1/τ，此前实现中错误地混入了 1.0。已修正。

### 5.4 守恒模排除
在 k=0 处，守恒模（ρ, j_x, j_y, [j_z]）的 |μ| = 1。比较不同算子的 λ_max 时需排除这些模，否则所有算子的 λ_max 均为 1.0。

### 5.5 适用范围
- 本分析仅适用于均匀基态（无壁面、无梯度）
- 非线性效应（Ma > 0.3）需通过全非线性模拟验证
- 高 Re 数下的稳定性需结合具体几何和边界条件
