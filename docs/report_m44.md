## 1. 案例介绍

### 1.1 物理与工程背景

本项目为《基于智能体的船舶总体性能自主科研平台研究》国拨项目（4000 万/3 年）的先导实践。平台运行于 node099（LoongArch 128 核 / 1TB / 8×Tecorigin SDAA 卡×4 分区 = 32 设备），搭载 torch 2.7.1 + torch_sdaa 3.1.1a3。

**硬约束**：
- Triton 3.4 无 SDAA 后端 → 仅 CPU 解释模式（慢）
- github.com:443 不通 → 推送走 Git Data API
- LoongArch 无 Docker Hub 镜像 → 一切原生跑

### 1.2 议事会任务

议事会 session-001 需为下一阶段（扫荡线 m12-m23 之后/并行）提出 2-4 个候选方向，每个含目标/任务拆解/机器判据/预算/风险/放弃条件。

**两份候选提案**：
| 提案 | 方向 | 核心内容 |
|------|------|----------|
| strategy | D1-D4 | 性能基准线 / 10 库普查裁决 / 3D 多相上卡 / 去 triton 化 |
| models | A-C | SUBOFF 阻力战役 S0-S4 / 跨库耦合 LBM↔FVM↔BEM / 技术债清偿 |

### 1.3 验证视角的质询维度

1. **判据机器可裁性**：每个 mission 的 PASS/FAIL 能否由脚本自动判定？
2. **honest-FAIL 可能性**：是否存在"做不到就如实报 FAIL"的机制？
3. **预算/墙钟现实性**：卡时估算是否合理？是否考虑了共租户干扰？

## 5. 注意点

### 5.1 踩过的坑

1. **两份提案的 mission 重叠**：strategy D4 与 models C 的 triton 消除目标完全相同，但预算和拆解不同。质询发现后由 r3-plan 合并，释放 3 卡。
2. **质量守恒判据 100× 差距**：D3 的"≤0.1%/1e4 步"与 A S4 的"1%/1000 步"（= 10%/1e4 步）差 100 倍。统一后消除了歧义。
3. **卡位表与 mission 预算不一致**：models B 的 P3 说 S2 用 4 卡，但 S2 预算为 6 卡。质询后修正。

### 5.2 局限性

1. **质询基于文档，未实跑代码**：所有判据评估基于提案文字描述，未验证代码实现是否真能达到声称的精度。
2. **预算为人日估算**：基于 m10（2D Couette 1 天）和 m11（普查 1 天）外推，3D 和耦合复杂度更高，实际可能超期 30-50%。
3. **SDAA 显存未知**：D3 的 3D 主线依赖单卡显存容量，质询时该数据不可得，M-P2 为首步。

### 5.3 适用范围

- 本质询仅覆盖 session-001 的两份提案（strategy + models），不涉及后续 session。
- 评分为主观判断（1-5 分），但每条质询均有具体依据，可追溯。

## 6. 误差判定

### 6.1 关键量 vs 基准

| 量 | 数值 | 基准 | 误差 | 是否 <3% |
|----|------|------|------|---------|
| bench1 Cf (Cumulant Re=1000) | 0.04179 | Blasius 0.04200 | **0.50%** | ✅ 是 |
| bench2 Cf (RANS Re=1e5) | 0.00662 | ITTC-57 0.00833 | **20.5%** | ❌ 否 |
| bench3 Cf (RANS Re=1e4) | 0.01065 | ITTC-57 0.01875 | **43.2%** | ❌ 否 |

### 6.2 判定说明

- **bench1 PASS**：Cumulant D3Q19 在 Re=1000 下与 Blasius 参考值误差仅 0.50%，远优于 MRT+Smagorinsky 的 2.3%（4.6× 改善）。
- **bench2/bench3 FAIL（honest-FAIL）**：RANS k-ε 模型在 Re=1e4 和 1e5 下误差分别为 43.2% 和 20.5%，远超 3% 门槛。原因分析：
  1. RANS k-ε 的湍流粘度计算在粗网格（200×80×80）下不充分收敛；
  2. 5000 步时间平均窗口可能不足（高 Re 下湍流时间尺度更长）；
  3. `from_gradient` 法向量的精度低于 `from_suboff` 解析法。
- **无基准声明**：KBC 诊断数据（16 立方体 20 步）无外部参考值，仅用于内部稳定性诊断（BGK Cd 振荡 → 非物理负值），不做误差判定。

### 6.3 对质询结论的影响

bench2/bench3 的 FAIL 直接支撑了质询中的以下建议：
- A S1 的"verification ≤3%"判据是合理的（bench1 通过，bench2/3 不通过）
- RANS 模型需要更细网格和更长时间平均才能达标
- 方向 C（技术债清偿）优先级应高于方向 A 的 S2+（先修好底层再冲高精度）
