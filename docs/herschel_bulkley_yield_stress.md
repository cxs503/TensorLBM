## 1. Case introduction

### 1.1 Physics

A Herschel-Bulkley (H-B) material carries a yield stress `tau_y`:

```
tau = tau_y + K gamma_dot^n      (tau > tau_y),
gamma_dot = 0                    (tau <= tau_y).
```

Below the yield stress the material moves as a rigid body; in a driven duct that
rigid body is the **plug core**, and its boundary is the **yield surface**.
Special cases: `tau_y = 0, n = 1` Newtonian; `tau_y = 0` power law
(`tensorlbm.powerlaw`); `n = 1` Bingham plastic.

The two facts that organise the whole verification:

* **The stress field of a fully developed duct flow is rheology independent.**
  Axial momentum balance gives `sigma(r) = rho a r/2` (pipe of radius `R`, body
  force `a`) and `sigma(y) = rho a y` (plane slit, `y` from the mid-plane), so
  `tau_w = rho a R/2` and

  ```
  r_c   = R tau_y/tau_w                (pipe plug radius)
  y_c   = (H/2) tau_y/tau_w            (slit plug half-height)
  ```

  Both are *the same ratio* to the half-width. The campaign brief quotes
  `r_c = R(1 - tau_y/tau_w)`; that expression is the **yielded annulus
  thickness** `R - r_c`, not the plug radius. Both are computed
  (`hb_pipe_yield_radius` returns `r_c`, `yielded_annulus_thickness`,
  `plug_fraction`, `plugged`).

* **Pure plane Couette has a uniform stress**, so yield is global — either the
  whole gap shears or nothing flows. There is **no interior yield surface**.
  A *non-degenerate* plate yield surface requires a stress that varies across
  the gap, which is the Couette-Poiseuille case with an adverse gradient tuned so
  that the stress vanishes at the resting plate: `sigma(y) = beta y`,
  `tau_w = beta h`, static plug `0 <= y <= y_yield` with
  `y_yield = h tau_y/tau_w`, and a plate speed fixed by the H-B integral
  (`hb_couette_adverse_wall_velocity`).

### 1.2 Slush (ice-slurry) closure

Ice-slurry parameters are obtained from ice volume fraction with documented
engineering closures: Krieger-Dougherty for the consistency index
(`[eta] = 2.5`, `phi_max = 0.60`, the same closure as
`tensorlbm.frazil_rheology`), a linear flow-index blend `1 -> 0.45`, and a
percolation-threshold yield stress `tau_y prop ((phi - phi_yield)/(phi_max -
phi_yield))^2.5` above `phi_yield = 0.10`. `phi >= phi_max` is refused instead of
extrapolated.

## 2. Method / toolchain

1. **Analytic layer** (`herschel_bulkley.py`, ~600 lines): regularised
   viscosity, constitutive stress, yield-locus shear rate, closed-form pipe and
   slit flow rates (validated against the Bingham polynomial
   `1 - 4phi/3 + phi^4/3`, the Newtonian `pi R^4 dP/(8 mu L)` and the power-law
   `n pi R^3/(3n+1)(tau_w/K)^{1/n}` limits to machine precision), velocity
   profiles, Couette-Poiseuille adverse solution, slush closure, and a 1-D exact
   solver for the **regularised** model
   (`hb_regularized_reference_profile`) used to separate discretisation from
   regularisation bias.
2. **Lattice kernels** (`herschel_bulkley_lbm.py`): variable-viscosity BGK
   (D2Q9 and D3Q19), Guo (2002) forcing with per-cell relaxation time,
   half-way bounce-back for resting and moving walls, wall-aware
   distance-weighted gradients, threshold probes for the plug radius and the
   yield surface.
3. **Geometry first.** The staircase pipe's hydraulic radius is calibrated from
   an independent Newtonian run, `R_eff = (8 nu Q/(pi a))^{1/4} = 20.27` at
   nominal `R = 20`; the Newtonian profile then matches the Hagen-Poiseuille
   parabola to ≤ 2 % (5.9 % in the last fluid bin).
4. **Rheology second.** With `R_eff` fixed, the H-B runs are blind predictions
   compared against the closed-form solutions, with the identical threshold
   probe applied to numerics and analytics so that a definitional bias cannot be
   mistaken for a solver error.

### A discovered and fixed bias (worth recording)

The first implementation used plain central differences for the shear rate.
Next to a half-way bounce-back wall the data spans 1.5 lattice units while the
stencil divides by 2, underestimating the near-wall shear rate by up to a factor
2. Harmless for a Newtonian fluid, but `nu = tau_y/gamma_dot + K gamma_dot^{n-1}`
propagates it directly: the Bingham pipe flow rate was **−9 %** off. With the
wall-aware stencil (solid neighbours entered at half a lattice distance, and
one-sided edge planes) the error dropped to **−0.23 %**. This is the single most
important numerical lesson of the node.

## 3. Results

### 3.1 Newtonian geometry calibration and negative control N1

`R_eff = 20.2675` (nominal 20), profile error ≤ 2 % interior, flow rate matched
by construction. **No plug is detected** for `tau_y = 0` (the plug probe returns
`None`), i.e. the yield-stress capability is not accidentally active — gate N1
passes.

### 3.3 Plate Couette (D2Q9)

Adverse-gradient Couette-Poiseuille at `h = 40` (Bingham): analytic yield
surface `y_yield = h tau_y/tau_w = 28.57`, probe on the analytic profile 28.93,
probe on the 1-D regularised solution 28.74, **LBM probe 12.49 (−56 %)**. The
pure-Couette negative control is also off: the measured profile deviates from
the exact linear profile by 9.4 %, which is a convergence/wall-treatment
signature (a pure Couette should be perfectly linear). **Gate G2 fails.**

The same signature appears in the *Newtonian* plate channel: at `h = 16` the
steady LBM flow rate per unit width is **+15.2 %** above
`q = H^2 tau_w/(6K)` and the interior profile is 10.2 % off, while the 3-D pipe
Newtonian calibration is within 2 %. The steady state itself is converged (the
probe is stable to five digits from step 3 000 to 16 000). The 2-D half-way
bounce-back wall is therefore the weak link of the plate branch -- the 3-D pipe
results should be treated as the quantitative anchor, and the plate branch needs
interpolated bounce-back (BFL) before its gates can be met.

### 3.4 Slush pipeline curve

In the reduced run the body force for the slush rheology (`K = O(1)`) was
mis-scaled (`a ≈ 3e-2` instead of `O(1e-3)`), the run diverged and the gate is
reported as a **failure with `nan`** rather than silently dropped. The
engineering content (yield stress shifts the `DeltaP-Q` curve to a threshold
behaviour, absent in the Newtonian case) is captured by the closure and the
formula but **not** numerically verified in this submission.

## 6. Verdict, limitations, next steps

**Honest PARTIAL / FAIL.** What is established:

* a complete, tested H-B analytic surface (closed-form pipe/slit laws, Bingham
  and power-law limits exact, Couette-Poiseuille yield surface, slush closure),
* a working D2Q9/D3Q19 variable-viscosity H-B solver whose **integral**
  observable (pipe flow rate) verifies to ≤ 2.7 % for Bingham, including the
  discovery and repair of a factor-2 near-wall gradient bias,
* negative control N1 (`tau_y = 0` ⇒ no plug) passes.

What is **not** established (do not claim otherwise):

* the plug-radius gate (regularised cores creep and equilibrate far slower than
  the flow rate; every pipe run reports `converged = false` at 6 000 steps,
  and the 1-D regularised reference shows the LBM core is the deviating part),
* the shear-thinning branch (n = 0.6), which is systematically too fast and gets
  worse with forcing — the `gamma_dot^{n-1}` amplification of the staircase-wall
  gradient error at R ≤ 20,
* the plate branch (transient-limited; pure-Couette linearity 9.4 %),
* the slush curve (mis-scaled forcing in the reduced run).

Recommended follow-ups, in order of expected payoff: (1) interpolated
(BFL/quadratic) bounce-back to remove the staircase wall, (2) a stiff-plug run
(30 000+ steps or an implicit steady-state accelerator) for the core,
(3) an R = 28/40/56 resolution study of the n = 0.6 branch, (4) re-scaled slush
forcing (`a ~ 1e-3`) and a five-point ΔP–Q sweep.
