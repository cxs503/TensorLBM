# GAP-PP-2-lid-wall-diff · 外部锚点（Ghia 1982）τ 反演复算

**一句话结论**：判据①（τ 反演<2%）在**同链**意义下成立（`docs/GAP_PP_2_LID_WALL_DIFF.md` §8.3，0.0016 %），但它是**梯度正确性**检查，不是数据反演。改用模型从未生成过的外部数据（Ghia 1982 Re=100 表 I）反演时，模型偏好的 Re 远低于 100：n=33 试点 **Re_anchor=68.7（τ 偏 7.35 %）**，n=65 上离散最小点落在阶梯下端（Re=60）以下、拟合外推 τ 偏 12–21 %——**两种分辨率、三种坐标映射下方向一致，均 ≥2 % 门限的 3 倍以上**。故判据①不得表述为「可反演真实数据的 τ」；它只证明梯度链正确。

## 1 案例介绍（物理背景／几何／参数／基准）

二维方腔顶盖驱动流（lid 上移 u_lid，四边无滑移），Re = u_lid·H/ν，ν=(τ−1/2)/3，H=n−1（格单位）。被复核对象=`src/tensorlbm/diff_lid_cavity.py` 的 graph-preserving 运动壁面 BC（判据①的载体），反演器=`invert_relaxation_time_rootfind`（s=log(τ−1/2)，L=中线探针 MSE）。

| 参数 | 值 |
|---|---|
| 网格 | n=33（H=32，试点）／n=65（H=64，生产） |
| u_lid / Ma | 0.1 / 0.173（两组同 Ma）；u_lid=0.05 组在集群队列中未回（见 §5） |
| τ 定义 | τ = 1/2 + 3·u_lid·(n−1)/Re（逐案由代码计算，见工件 JSON 的 `tau` 字段） |
| 外部基准 | Ghia, Ghia & Shin 1982 *J. Comput. Phys.* **48**:387–411, Table I（Re=100 中线 u,v）|
| 损失 | J(Re) = rmse_u² + rmse_v²，均以 u_lid 归一化，仅取内部参考行（0<y<1, 0<x<1）|
| 坐标映射 | `node` y_j=j/(n−1)；`half` y_j=(j+0.5)/n；`halfbb` y_j=(j−0.5)/(n−1.5)（半程反弹一致）|

## 2 怎么做的（方法／流程／工具链）

1. **稳态推进**：`run_steady()` 用被测的 `diff_lid_cavity.step`（collide→stream→bounce-back→moving lid）推进到 `max|Δu_x|/u_lid < tol`（tol=1e-7 试点／3e-7 生产），记录步数/残差；发散即如实返回 `diverged`。
2. **外部损失**：`ghia_loss()` 把中心线在三种节点→坐标映射下插值到 Ghia 表 I 的站位，只取内部行（壁面行在映射变更后会被 `np.interp` 静默钳制，`docs/GHIA_METRIC_CONVENTION_AUDIT.md` F3）。同一实现与生产 `compare_ghia`（wall_offset=0，全行）在 `node` 全行模式下**逐位一致**（测试 `test_ghia_loss_matches_compare_ghia_on_the_legacy_convention`）。
3. **锚点求解**：J(Re) 为光滑一维曲线，用最小二乘抛物线与三点插值抛物线给出顶点 Re_anchor；再由 τ(Re)=1/2+3u_lid H/Re 换算 τ_anchor 与相对偏差（对 2 % 判据）。
4. **工具链**：`scripts/verify_gap_pp2_ghia_anchor_inversion.py`（shard/collect/figures 三段，程序化写 JSON，零手抄）；测试 `tests/test_ghia_anchor_inversion.py` 9 项；重算按容量纪律递交集群 `cj1762`（13 分片）。
5. **复现**：
```
PYTHONPATH=src python scripts/verify_gap_pp2_ghia_anchor_inversion.py shard --index 4/17 \
    --outdir artifacts/gap_pp2_ghia_anchor --steps-max 20000 --tol 3e-7 --threads 4
PYTHONPATH=src python scripts/verify_gap_pp2_ghia_anchor_inversion.py collect --outdir artifacts/gap_pp2_ghia_anchor
PYTHONPATH=src python scripts/verify_gap_pp2_ghia_anchor_inversion.py figures --outdir artifacts/gap_pp2_ghia_anchor
python -m pytest tests/test_ghia_anchor_inversion.py -q
```

## 5 注意点（踩过的坑／局限／适用范围）

- **n=65 阶梯未包围最小值**：离散最小点落在阶梯下端 Re=60（τ=0.820），拟合顶点 57–70 属**外推**，且该组运行以 `steps_max` 结束（残差 1.7e-4–3.7e-4），**不是收敛稳态**——其 12–21 % 只能作为量级指示，不可当作 n=65 的精确偏差。n=33 试点为收敛态（残差 ≤9.3e-7），最小值在阶梯内部（60<Re<80），故以它做定量结论。
- **映射约定贡献 5.8–8.8 个百分点**：同一流场换 `node`/`half`/`halfbb` 映射，τ 偏差在 n=65 上从 11.9 % 到 20.8 %；但**三种映射全部判 FAIL**，故结论对约定选择稳健，量值不稳健（引用必须带映射名）。
- **度量地板**：把 Ghia 表原样采到节点再插值回来，`node` 映射在 n=33 上已有 0.63 % 残差（折点项），n=129 降到 0.6 倍以下（测试 `test_ghia_loss_floor_is_metric_only_and_converges`）。这是 O(h) 项，与大偏差不是同一来源（后者是有限 Ma + 欠解析边界层）。
- **BGK 稳定性下限**：小腔要达到同样 Re 需要更小的 τ；n=17、Re=100 需 τ=0.548 直接 NaN（已固化为测试注释）。这也是阶梯从 n=33 起步的原因。
- **未完成（诚实清单）**：集群 `cj1762`（13 分片：n=65 六点阶梯、n=65/u_lid=0.05 四点、n=129 三点）仍在排队（递交时 311 单前序），**本报告不含其数字**；u_lid=0.05（半 Ma）与 n=129 的偏倚-Ma/分辨率归属因此**未作答**，下一单须先取回 `cj1762` 再补 §3 两列。

## 6 误差判定（对基准逐项；不许含糊）

| 关键量 | 基准 | 本单结果 | 是否达判据 |
|---|---|---|---|
| Ghia Re=100 涡心 x（n=65） | 0.6172 | 0.609 | 是（<3 %：|Δ|=1.3 %） |
| Ghia Re=100 涡心 y（n=65） | 0.7344 | 0.719 | 是（|Δ|=2.1 %） |
| u 中线 rmse（n=65, Re=100, halfbb 内部行） | 同表 | 4.81 % | **否**（>3 %，与 `docs/GAP_PP_2_LID_WALL_DIFF.md` §4.1 的 4.53 %（全行）同量级） |
| τ 反演偏差（判据①，n=33 试点，halfbb） | τ_true=0.59600 | 7.35 % | **否**（>2 %，3.7 倍门限） |
| τ 反演偏差（判据①，n=65 外推，halfbb） | τ_true=0.69200 | 19.97 % | **否**（>2 %；且为未包围的外推值） |
| 同链反演（判据①原证据，§8.3） | τ_true=0.69200 | 0.0016 % | 是（这是梯度正确性，非数据反演） |

**显式回答**：外部数据反演精度是否 <3 %？——否（7.35 % 起）。同链梯度一致性是否 <1e-4？——是（§4.2，9.23e-07）。两者不冲突：它们检验的不是同一件事。

## 7 结论与给下次的建议

1. 功能本身（graph-preserving lid BC）**建议维持 verified**：它与生产 BC 逐位等价、AD/FD 一致、可 vmap——这些是判据② 与等价性检查的内容，本单未推翻。
2. 判据① 的**表述必须收窄**为「同链 τ 恢复」；把它当作真实数据反演能力是**被本单否证**的假设。
3. 建议新条目（供总账收养，slug 供参考）：`GAP-PP-2-lid-wall-diff-anchor-lowma`——以 u_lid≤0.02（Ma≤0.035）+ n≥129 复算外部锚点反演，验收：τ_anchor 相对偏差 <2 % 且梯度的离散最小点位于阶梯内部（bracketed）；TensorLBM 域。先取回 `cj1762` 作为其基线。
