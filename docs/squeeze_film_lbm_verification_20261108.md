# 挤膜 LBM（squeeze_film_lbm）解析验证与口径缺陷清偿（2026-11-08，m6397）

## 0. 结论（一句话）

`tensorlbm.squeeze_film_lbm`（m5749 交付，此前**零测试、零验证记录**）在
$h/a\in[0.19,0.75]$、$a=16$ 的可用窗口内**复现了 Reynolds/Stefan 挤膜的 $h^{-3}$ 标度**
（局部指数 3.03 / 2.90 / 2.74），但绝对载荷**系统性高于** $8\mu V a^3/h^3$ 闭式解
**12.2%–37.2%**，**没有**达到 3% 验收线；同时发现两处**载荷口径缺陷**（已修）
与一处**结构性失效**（宽膜 $a\ge 24$ 定点密度压力面不稳定：$a=24,h=4$ 收敛到
$+1350\%$ 伪解、$a=32,h=4$ 发散到 NaN）。

## 1. 物理背景与参数

两块刚性平板间厚 $h$ 的黏性膜以相对速度 $V=-dh/dt$ 逼近。薄膜（$h\ll a$）极 limit 下
Reynolds (1886) / Stefan (1874) 闭式解

* 压力：$p(x)=6\mu V(a^2-x^2)/h^3$
* 平面应变载荷：$F=8\mu V a^3/h^3$（单位展向长度）

| 参数 | 值 |
|---|---|
| 半宽 $a$ | 8 / 16 / 24 / 32（格点单位） |
| 膜厚 $h$ | 3 / 4 / 6 / 8 / 12 |
| 运动黏度 $\nu$ | 0.1（$\tau=0.8$） |
| 逼近速度 $V$ | 0.005（$Ma=0.0087 \ll c_s$） |
| 密度 $\rho_0$ | 1（压力释放面定点） |
| 求解器 | `simulate_squeeze`（D2Q9 BGK + 半步反弹壁 + 顶部零动量质量源 + 两侧 Zou-He 定点密度面） |

## 2. 怎么做的

1. 先用**负控**把 ME 载荷拆成"静态基线 + 物理信号"：源项关闭时流场静止，
   `force_top` 恒等于 $n_x\rho_0c_s^2=n_x/3$（实测 $17/3=5.6667$），gauge 载荷 2.7e-15。
2. 定义 gauge 载荷 $F_g=F_{\rm ME}-n_x\rho_0c_s^2$ 并与闭式解比较（这是本次**新增的库内输出**，
   见 §4）。
3. 固定 $a$ 扫 $h$，用相邻两档做 log-log 斜率检验 $h^{-3}$ 标度（判据：指数 ∈[2.6,3.4]，
   能把 $h^{-2}$/$h^{-4}$ 判红）。
4. 双通道互校：ME gauge 载荷 vs **无源壁行** ($y=0$) 静压积分（ME 累加器与压力场是两套
   独立算法，互校同时抓漏 link 与取样行错误）。
5. 加宽域（$a=24,32$）找渐进路径——结果暴露结构性不稳定（见 §5）。
6. 全程脚本化：`artifacts/squeeze_film_lbm_verification/sweep.py` → `sweep.json` →
   `make_figures.py` → `summary.json`，报告数字由 JSON 程序化注入，无手抄。

## 4. 修的两处口径缺陷（`src/tensorlbm/squeeze_film_lbm.py`）

1. **ME 载荷含静态基线而未被暴露**：`force_top/-bottom` 是绝对载荷，含
   $n_x\rho_0c_s^2$；负控（无源）读数 5.6667 就是它。任何与解析值的直接比较都差 ~2–3 个
   数量级（首次对比时 ME 误差显示 +17758%）。→ 新增 `baseline_static_force` /
   `force_gauge_top` / `force_gauge_bottom`，docstring 写明只有 gauge 量与闭式解可比。
2. **壁面载荷取错行**：`force_pressure_integral` 原来取 $y=n_y-1$，即**质量源注入行**。
   该行在注入 + 角点处理下带压力假象：$a=16,h=8$ 时逐点压力从中心的 $-1.9e-5$ 到边角的
   $-3.8e-4$（**符号为负**，和值 +30% 偏于无源壁行）。→ 改为取无源壁行 $y=0$，
   旧值保留为 `force_pressure_integral_top_row` 供审计。
3. 附带：发散时抛 `RuntimeError`（此前静默返回 NaN 载荷）。

## 5. 注意点 / 局限（诚实登记）

* **没有达到 3% 验收线，也不在本模块当前实现下可达**：Reynolds 解本身只有 $O(h/a)$
  渐近精度，而减小 $h/a$ 只有两条路——压薄 $h$（离散分辨率下限：$h=3$ 时误差反而回升到
  +16.4%）或加宽 $a$（$a\ge24$ 触发结构性不稳定）。固定 $h=4$ 的外推截距约 6–8%，
  即离散口径本身的地板已经高于 3%。
* **结构性失效的机理解释（假设，未修）**：`simulate_squeeze` 先施加两侧 Zou-He 压力面、
  再施加半步反弹壁，角点格（$x=0/n_x-1$ 且 $y=0/n_y-1$）的壁面覆盖会**抹掉该处的定点密度
  条件**，质量源注入的流体在角点堆积 → 宽膜时压力假象累积到主导真实解（$a=24,h=4$）或
  直接发散（$a=32,h=4$）。旁证：$a=16,h=8$ 的源行压力逐点为负；把压力面的横向速度
  外推改成为 0 **不改变**不稳定（$a=24,h=4$ 仍为 NaN/伪解），说明问题在角点/行覆盖顺序
  而非外推公式。
* 该模块因此可作为**标度/趋势锚**（$h^{-3}$、量级 12–20%），**不可**作为定量载荷来源；
  冰区挤膜阻力若需要定量精度，应走 `squeeze_film.py` 的闭式解或另一个稳定求解器。
* 建议后续单：把压力面与壁面改成"角点视为固体、压力面行排除壁行"的标准处理，或换成
  特征型/海绵层出口，重跑本文 $a\in\{16,24,32\}$ 的扫描；验收判据沿用本文 3%/15% 双线。

## 6. 误差判定（逐项回答"是否 <3%"）

| 关键量 | 基准 | 最优误差 | <3% ? |
|---|---|---|---|
| 平面应变挤膜载荷（$a=16,h=4$） | Reynolds/Stefan 闭式 | +12.2% | **否**（12.2% > 3%，>15% 判据下落在"不可接受边缘但未超"） |
| 同上（$a=16,h=3$） | 同上 | +16.4% | **否**（>15%，**不可接受**） |
| 源行静压积分 vs 无源壁行（$h=8$） | 内部一致性 | +30%（源行） | **否**（口径缺陷，已修） |
| ME gauge vs 壁行静压积分（$a=16,h=6$） | 双通道互校 | 3.8% | 否（但足够证明 ME 累加器无漏 link；ledger_rel ≤ 7e-6） |
| $h^{-3}$ 指数 / $-3$ | 理论指数 | 0.9%（3.028） | **是** |
| 负控 gauge 载荷 / 0 | 0 | 2.7e-15 | **是** |

**总体判定：honest FAIL（定量验收未过）/ 部分 PASS（标度 + 口径）。** 不粉饰。
