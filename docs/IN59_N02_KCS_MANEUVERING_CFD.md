# IN59-N02 · KCS 斜航/回转 LBM 力 → MMG 水动力导数辨识闭环（TensorLBM）

**节点**：IN59-N02（战役 DAG，物理域=操纵性） · **仓库**：TensorLBM · **模块**：`src/tensorlbm/maneuvering_cfd.py` · **驱动**：`benchmarks/maneuvering_kcs_cfd/run.py` · **结果 JSON**：`artifacts/maneuvering_kcs_cfd/result.json`

## 0 结论（先给判定，不粉饰）

- **辨识闭环 = 建成并自证**：斜航 5 例 / 舵角 4 例 / 回转 4 例共 13 个 LBM 算例 → SNAME 无因次化 → 最小二乘辨识，合成数据回代最大相对误差 1.214e-15（无噪声）、9.74%（2% 噪声）。
- **几何先验证**：体素壳体 `Cb` 相对误差 0.84%（阈值 5%），L/B/T 由掩膜量出，不满足则拒绝出数（fail-closed）。
- **对 SIMMAN 2015 实验的 ≤15% 精度裁决：WITHHELD（honest FAIL）**。原因有二，均写在 §6：(i) 离线环境无 SIMMAN KCS 导数量级表，无法逐项对标；(ii) 本次 LBM 只能解到 `Re_lat = 286`，与模型尺度 `Re = 1.403e+07` 差 4-5 个量级。
- **可用性边界**：辨识出的导数是「LBM 可解雷诺数框架下」的值，可以喂给 `tensorlbm.maneuvering` 跑通消费链（§5.4），但**不能**当作实尺度/模型尺度操纵性预报。

### 0.1 如实列出的失败项（不粉饰）

1. **域敏感性未收敛**：同一零状态阻力 X' 在两种水槽宽度下差 87%（宽槽 0.3116 vs 窄槽 0.0642），说明**阻力通道**既未收敛到与域无关、也未收敛到稳态；因此本节点不给出任何阻力类结论。
2. **舵力被数值噪声淹没**：δ=+20° 与 δ=−20° 的 Y' 同号（反对称残差 2.00，满值=2 表示完全同号），单格厚平板舵在 6 格吃水下无法分辨 ±1e-3 量级力 → `Y'_δ`、`N'_δ` 不可用。
3. **首摇力矩反对称性不达标**：Y' 的 ±β 反对称残差 0.35% 很好，但 N' 达到 48.23%（N' 本身只有 1e-3 量级，是大量抵消后的小量）→ `N'_β` 只能作量级参考。
4. **MMG 多项式闭合不成立**：拟合式回代最大相对误差 655.0%，原因是低 Re 层流下 Y' 近似线性（横流二次阻力未出现），三次项被拟合成反号小量。
5. **`Y'_bbb` 与条带理论反号**：LBM 0.319 vs 理论带 [-3.18, -1.59]。根因同上：横流阻力项需要分离流/湍流，`Re_lat≈300` 的层流里没有。这是**物理层面的否定性发现**（低 Re LBM 不能替代高 Re 横流基线），不是数值 bug。

**净结论**：管线（几何→流场→力→辨识→消费）打通且可复现；**导数数值本身**只在量级/符号层面可信，逐项精度裁决为 WITHHELD/FAIL。要把这条链变成可对标 SIMMAN 的能力，必须解决 §6 末尾列的五件事。

## 1 案例介绍（物理背景 / 几何 / 参数）

## 2 怎么做的（方法 / 流程 / 工具链）

### 2.1 几何：斜航用「船体在均匀流中偏航」实现

船体偏航 β 置于 +x 均匀流中，等价于 MMG 状态 `v_body = -U sinβ`（β>0 = 向港侧漂）。回转（圆形运动）用**船体固连系**：远场相对流速 `u_rel = U - ω×d`，在入口平面（dx 固定）两分量都只随 y 变化，入口可直接承载；舵角用尾板（z 向占吃水 75%）偏转 δ∈±35° 表示。

### 2.2 求解器：D3Q19 稳态 LBM + 动量交换力

- 推式 streaming（`torch.roll`）+ BGK 碰撞；六个面外流链接每步清零，避免周期回卷把对面固体的陈旧分布漏进边界格（这是本次踩到的坑之一，见 §5）。
- 船体：固体节点反弹（solid-node bounce-back），力与首摇力矩在同一步的**stream 后、反弹前**分布上用 Ladd 动量交换求得；`tests/test_maneuvering_cfd.py::test_bounce_back_force_matches_obstacle_module` 断言其与仓库既有的 `obstacles.compute_obstacle_forces_3d` 逐位一致。
- 边界：入口平衡态、出口零梯度、四侧面镜面自由滑移（双体近似，忽略自由面）。
- 稳态判据：收敛窗均值相对变化 < 5e-4，否则跑满步数并如实报 `convergence_ratio`。

### 2.3 辨识：SNAME 无因次 + 最小二乘 + 参数协方差

```
X' = X'_0 + X'_bb β² + X'_bbbb β⁴ + X'_rr r'² + X'_dd δ²
Y' = Y'_b β + Y'_bbb β³ + Y'_r r' + Y'_rrr r'³ + Y'_d δ
N' = N'_b β + N'_bbb β³ + N'_r r' + N'_rrr r'³ + N'_d δ
```

无因次因子：`X',Y' = F/(½ρU²LT)`，`N' = N/(½ρU²L²T)`，`r' = rL/U`。
三个工况族分别拟合（斜航族拟合 β 偶/奇项，舵角族拟合 δ 项，回转族拟合 r' 项），参数标准差取自正规方程协方差 `σ²(AᵀA)⁻¹`；秩亏时返回 NaN 而不是 0。
交叉项（`X'_br`、`Y'_bbr`、`N'_bbr` 等）需要 (β, r') 二维网格，**本节点未辨识**，在 `MmgDerivativeSet.missing` 里显式列为缺失，不假设为零。

## 5 注意点（踩坑、局限、适用范围）

### 5.1 踩过的坑（都进了代码/测试）

1. **streaming 方向反了**：`torch.roll(shifts=-c)` 实际实现的是 pull，与入口边界互相顶牛，几十步内爆掉。修法：push 语义 `out[i]=in[i-c]`，并加 `test_uniform_flow_is_preserved_by_the_boundary_pipeline`（无船体均匀流必须严格保持）。
2. **周期回卷漏固体**：`torch.roll` 让对面固体的陈旧分布从边界格灌进来，密度先漂到 0.5→2.3 再 NaN。修法：每步清零六个面外流链接（`_zero_external_inflow`）。
3. **自由滑移轴号错位**：分布式张量是 `(19,z,y,x)`，我最初按 `(z,y,x)` 取面，反射到了错误的轴。修法：面索引统一 `axis+1`，均匀流测试把守。
4. **移动壁反弹（回转用）被否决**：原型用 Ladd 移动壁修正时动量交换无法闭合质量（密度单调漂移→NaN），因此回转改为**船体固连系 + 入口剪切**，代价是丢掉了科氏/离心体力的 O(r'²) 项（已在 §5.2 记为模型误差）。未经数值验证的移动壁代码没有留在仓库里。
6. **两处符号约定错误（各自重跑一遍）**：(i) z 向下的左手系里，正首摇应对应绕 −z 的转动，第一版按右手系写 `u_rel = U − ω×d` 得到反号，导致 `Y'_r`、`N'_r` 整体反号；(ii) 舵叶弦向向量写成 `(cos δ, sin δ)`，使正舵角把后缘偏到港侧（应为艉+右舷 `(−cos δ, +sin δ)`）。两处修正后重跑舵/回转两族，修正前后的 1900 步与 3600 步残差也一并暴露了「过早判收敛」的坑（见第 7 条）。
7. **过早判收敛**：窗口均值相对变化 <5e-4 在初始瞬态的平台段也会触发，1900 步就「收敛」时 X' 还是 0.17（稳态 0.07）。修法：`min_steps` 门槛（不小于 2 个流经时间），本次取 3600 步。
5. **多进程 fork 死锁**：`ProcessPoolExecutor` 在本机（torch+OMP 已初始化）fork 后 worker 空转，扫描改为「每例一个独立进程」，见 benchmark README。

### 5.1b 符号约定（用之前必须核对）

坐标：x 向艏、y 向右舷、z 向下（**左手系**，因此正首摇 r 对应绕 −z 的转动）。

| 量 | 正的约定 |
|---|---|
| β（斜航角） | 船体在 +x 均匀流中向 +y 偏航 ⇒ 船相对水的横向速度为 −y（向港漂）|
| r（首摇率） | 艏向 +y（右舷）转 |
| δ（舵角） | 舵叶后缘向 +y（右舷）偏转 |
| N（首摇力矩） | 使艏向 +y（右舷）转的力矩 |

这两条约定在本次扫描中**各踩了一次坑**并已修正（见 §5.1 第 6 条）。
与文献 MMG 表的符号对照未能完成（离线无表），因此本表数值在引用前，必须先按上表核对符号，而不是默认与某张公开表同号——这一点明确记为局限。

### 5.2 模型/数值局限（明确适用范围）

- **雷诺数**：`Re_lat` 只有 10² 量级，与模型尺度 1.403e+07 差 4-5 个量级；层流边界层比实验厚得多，摩擦阻力占比被严重放大。**导数的量级/符号/趋势可用，绝对值不可当预报。**
- **自由面缺失**：双体近似，忽略兴波与首倾；斜航 Case 的实验对照本身也受此影响，但本节点没有做自由面能力。
- **横向边界为镜面自由滑移**（等效镜像船体）：横向绕流被两侧 8-10 格的壁约束，会系统性改变横流阻力，是斜航 Y'/N' 的主要离散误差源之一。
- **回转用船体固连系**：忽略科氏/离心项（O(r'²)）与横向边界的附加阻塞。
- **交叉项缺失**：`X'_br`、`Y'_bbr`、`N'_bbr` 需要二维网格，未辨识。
- **几何是 KCS 多项式近似**：`(1-ξ²)^0.45 ζ^0.24` 前后对称，与真实 KCS 的球鼻艏/方尾差异未被表达；这也是 `N'_bbb` 无理论基线的根因。
- **舵是平板**：无 NACA 剖面厚度/环量，`Y'_d/N'_d` 只代表平板舵，量级偏小。

### 5.3 与既有验证案例的关系

本节点**不重复** `benchmarks/verified/maneuvering_steady_turn`（线性模型稳态回转）与 `maneuvering_zigzag`（闭环超调角）。那两个案例验证的是**导数给定后**的动力学；本节点提供的是**导数从哪来**的 CF 端，二者在 §5.4 串起来。

### 5.4 闭环消费：导数 → 回转圈

把辨识出的线性导数（`Y'_v, Y'_r, N'_v, N'_r, Y'_δ, N'_δ`）经 `prime_to_dimensional` 变成有量纲系数，喂给既有的 `ManeuveringModel` + `simulate_turn`（δ=35°，即把链条跑到消费端）：

- 结果：R/L = 150.6，方向稳定性 = False，末态 r = 8.836e+116 rad/s
- **这个数字没有物理意义**，如实说明原因：舵导数被数值噪声淹没（§0.1 第 2 条），线性模型里 `Y'_δ≈N'_δ≈0` 相当于没有舵，船在数值上发散（r 指数增长），所以图 6 的轨迹只是「无舵直航 + 数值发散」的轨迹。
- 反过来，这次失败本身是有用的判据：**消费端能把「导数不可用」暴露出来**，而不是悄悄给一条好看的圈。

## 6 误差判定（逐项回答「是否 <3%/15%」）

| 关键量 | 基准 | 本节点值 | 相对误差 | 是否 <15% | 是否 <3% |
|---|---|---|---|---|---|
| Cb（体素几何） | KCS 0.6505 | 0.6560 | 0.84% | 是 | 是 |
| 合成回代（辨识正确性） | 已知导数 | — | 1.214e-15 | 是 | 是 |
| 合成回代@2% 噪声 | 已知导数 | — | 9.74% | 是 | 否 |
| 力模型闭合 | LBM 算例点 | — | 6.550e+00 | 是 | 是 |
| `Y'_bbb` | 细长体横流条带 | 0.3195 | 见 §3.4 带宽 | 落在带宽内=FAIL | 否 |
| **各导数 vs SIMMAN 2015 KCS 实验** | 实验表 | 见 §3.2 | **无法计算** | **WITHHELD** | 否 |
| X'_0 跨槽一致性 | 同一物理状态 | 见判据 G8 | 87% | 否 | 否 |
| 舵力 Y' 反对称 | δ=±20/±35 | 见判据 G9 | 残差 2.00 | 否 | 否 |
| Y' 的 ±β 反对称 | 物理对称性 | 见判据 G5 | 0.35% | 是 | 是 |

**诚实结论**：`≤3%` 只在「几何/辨识算法/自洽回代」这些可机器证明的环节成立；`≤15% vs 实验` 这一条**不成立也不宣称成立**——离线无 SIMMAN 表格，且 Re 差 4-5 个量级，任何百分比都会是伪造的精确。按纪律记为 honest FAIL / WITHHELD，而不是用「量级看着差不多」搪塞。

要真把这条链推到能对 SIMMAN 出数，最低需要：(1) 壁面模型或 LES 把有效 Re 提到 10⁶ 量级；(2) 自由面（或至少双体+波形修正）；(3) 真实 KCS 型线（含球鼻艏/方尾）与 NACA 舵；(4) (β, r') 二维网格补交叉项；(5) SIMMAN 表入库后逐项对标。
