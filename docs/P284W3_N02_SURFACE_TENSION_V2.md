## 0. 一句话结论

上一版把**单相（界面两侧同密度）自由面 LBM** 的液滴振荡周期拿去比 **drop-in-vacuum** 的
Rayleigh 公式，得出 `+49 %…+59 %` 并如实判 FAIL。本次先修正**参考锚**：同密度两侧的正确线性
锚是**两流体 Rayleigh 周期**（`ρ_i = ρ_o` 时比真空式长 √2 = 41.4 %），同一批 run 的误差立刻
从 `+51 %` 降到 `+12 %`；再把 Rayleigh 锚按它本来的含义（**无黏极限**）处理，用 `τ = 0.55 /
0.60 / 0.70 / 0.80` 的黏性阶梯拟合 `T/T_ref - 1 = c·√(ν/(ωa²))`，外推 `ν→0` 的截距为
**-0.19 % ± 2.12 %**（R² = 0.981，散度取 R/σ/w 扫描残差），即**在锚所定义的无黏极限内 <5 % 达标**；单个有限黏 run（`τ=0.55`）
仍为 `+12.19 %`，作为**未达标数据如实并列**。静止锚（Young–Laplace 2D/3D）与 Marangoni 锚
在新曲率过滤下不回归：2D `≤1.55 %`、3D `≤1.97 %`（判据 <3 %）、Marangoni 系统偏差
`-7.67 %`（判据 <10 %）。曲率算符审计给出机制：按 `δ_s` 加权的 mode-2 广义刚度在原始算符下
偏高 `+3.2 %`，一次二项式预滤后为 `-1.6 %`（`w=2`），`w=4` 时 `+0.3 %`。
**未达成项（honest）**：无黏近似下的单 run 未进 5 %；`τ=0.505` 的近无黏 run 数值失稳
（`max|u|` 尾部/头部 ≈ 57×）已由稳定性筛查判红、不入账；`advection="upwind"` 对照因界面糊化失稳，
同样判红。

## 1. 案例介绍（物理背景 / 几何 / 参数）

### 1.1 物理背景

自由面（Körner 型）LBM 只解液相、界面用体积分数/颜色场 `φ` 描述，表面张力必须以体积力形式
进入动量方程。Brackbill–Kothe–Zemach (1992) 的 CSF 模型：

```
f_s(x) = σ κ(x) n̂(x) δ_s(x) = σ κ(x) ∇φ(x) ,   κ = -∇·n̂ ,  n̂ = ∇φ/|∇φ| ,  δ_s = |∇φ|   (1)
Static balance:   Δp = p_in - p_out = σ κ    →  σ/R (2D 圆柱) ,  2σ/R (3D 球)             (2)
```

本仓的 `CapillarySolver` 是**单相**自由面求解器：`φ` 两侧 `ρ ≡ ρ0 = 1`，**没有密度跳变**。
这一点决定了振荡锚该用哪个 Rayleigh 式（§2.1），也正是上一版最大的口径错误。

### 1.2 三个物理锚

| 锚 | 判据（战役 metadata） | 解析参考 | 本版做法 |
|---|---|---|---|
| A Young–Laplace 静压差 | 误差 < 3 % | `Δp = σ/R`（2D）、`2σ/R`（3D） | 半径阶梯 + 原始/预滤曲率对照 |
| B 液滴振荡周期 | 误差 < 5 % | 两流体 Rayleigh `ω² = n(n²-1)σ/((ρ_i+ρ_o)a³)`（2D，n=2）| 相位拟合 + 界面 marker 交叉校验 + 黏性阶梯外推 |

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 参考锚修正：vacuum Rayleigh vs 两流体 Rayleigh（本版核心）

经典 Rayleigh (1879) 周期

```
ω² = n(n-1)(n+2) σ/(ρ a³)        (3D, drop in vacuum)        (3)
ω² = n(n²-1)     σ/(ρ a³)        (2D 圆柱, drop in vacuum)   (4)
```

是**液滴在真空（或密度可忽略的气体）中**的结果。液滴浸没在密度 `ρ_o` 的流体里时，线性化
界面正应力平衡（Lamb, *Hydrodynamics*, art. 275）把 `ρ` 换成 `ρ_i + ρ_o`：

```
ω² = n(n²-1)   σ/((ρ_i+ρ_o) a³)    (2D)                       (5)
ω² = n(n-1)(n+2) σ/((ρ_i+ρ_o) a³)  (3D)                       (6)
```

本求解器 `ρ_i = ρ_o = 1`，因此 `T = √2 · T_vacuum`：**用真空式比同密度仿真的结果，天然带
+41.4 % 的系统偏差**，这与离散误差无关。`csf.rayleigh_period_2fluid(σ, a, ρ_i, ρ_o, mode, ndim)`
实现了式 (5)(6)，并在 `ρ_o = 0` 时与 (3)(4) 完全一致（有测试守卫）。
单相 LBM 为什么是"同密度两侧"：`CapillarySolver` 只解一种流体，`ρ` 处处为 `ρ0`，界面两侧
动量方程相同 —— 这正是 `ρ_i = ρ_o` 的极限。第 1 次尝试的 `+49 %…+59 %` 中，约 41 个百分点
来自这里。

### 2.2 曲率算符审计：点取样不可作证，改用 `δ_s` 加权投影

CSF 力的 mode-2 刚度由 `κ` 在界面上的 `cos 2θ` 分量决定。第一版我尝试在少数极角上**点取样**
`κ`，得到"原始算符只有解析值的 0.70 倍"——随后发现这个数字随亚格子取样选择在 `0.7…2.5`
之间剧烈变化（`w = 2` 时带内只有 2–3 格，`κ` 在带内变化很大），**点取样不能作为证据**。
改用与力共轭的**带加权投影**（即 mode-2 广义刚度除以 `σ` 与界面测度）：

```
A2 = Σ κ |∇φ| cos2θ / Σ |∇φ|                                            (7)
```

解析参考用精确椭圆 `r(θ) = ab/√(b²cos²θ+a²sin²θ)` 与其精确曲率做弧长加权同一投影。
结果（§3.2）稳定可复现：`w = 2` 时原始 `κ` 给 `+3.2 %`，一次二项式预滤 `(1/4,1/2,1/4)`
后 `-1.6 %`；`w = 4` 时 `+0.3 %`。也就是说**离散 CSF 的 mode-2 刚度是准的（%~量级）**，
振荡周期的 `+12 %` 不能归因于曲率算符。

### 2.3 相位估计：阻尼正弦最小二乘拟合

第一版用 `D(t)` 的零穿越，每次只有 2 次穿越，`w` 扫描出现非单调、`w²` 外推 `R² = 0.03`。
本版用

```
y(t) = e^{-γt}[a cos ωt + b sin ωt] + c                                        (8)
```

对 `(ω, γ)` 网格扫描、每个网格点对 `(a,b,c)` 做线性最小二乘，取残差最小点，同时报告 `R²`
（主例 `R² = 0.9952`，`τ` 阶梯 `R² ≥ 0.9928`）。相位也由**几何 marker** 交叉校验：
沿 4 条坐标轴找 `φ = 0.5` 的穿越位置，取 `a(t) = (r_x - r_y)/R`，与 `D(t)` 独立拟合。
实测两者相差 `≤0.5 %`（§3.3 表），说明 `D(t)` 没有因界面宽度调制而偏相。

### 2.4 无黏极限：黏性阶梯 + 外推（锚本身是无黏陈述）

Rayleigh 周期是**无黏**结果；LBM 里 `ν = (τ-1/2)/3` 不可能为零。黏性毛细振荡的周期修正
在小 `ν` 下由无量纲小参数控制

```
ε_ν = √(ν/(ω a²))        (黏性穿透深度 / 半径)                                (9)
T/T_inv - 1 = c ε_ν + O(ε_ν²)                                                 (10)
```

做法：固定 `R, w, σ`，扫 `τ`（4 档）→ 拟合 (10) 的 `c` 与截距（`ν→0`）。同时每个 run 都做
**稳定性筛查**（`max|u|` 的尾部/头部中位数比、`φ` 质量漂移），任何增长的 run 判红不入账
（`τ = 0.505` 与 `upwind` 对照正是被这样筛掉的）。

### 2.5 工具链

`CapillarySolver`（D2Q9 单相 LBGK + Guo forcing + 半拉格朗日单调三次界面输运）、
`csf.curvature(smooth=)`（二项式预滤 + 中心差分 `-∇·n̂`）、numpy 最小二乘、
matplotlib(Agg) 出图；`scripts/run_p284w3_n02_surface_tension_v2.py` 分例跑（每例单线程，
多例并行），`--case aggregate` 统一出表（`summary.json` + `summary_tables.md`）与出图。

### 3.7 数据塌缩（本版最有力的交叉验证）

`σ` 扫描与 `τ` 阶梯是两个**互相独立**的旋钮，但表 3 里出现一对完全重合的点：

| run | 旋钮 | `ε_ν = √(ν/(ωa²))` | 误差 |
|---|---|---|---|
| `osc_tau0.60` | `ν = 0.0333`（`τ`） | `0.1664` | `+15.05 %` |
| `osc_sigma0.01` | `σ = 0.01`（改变 `ω`，`ν` 不变） | `0.1664` | `+15.05 %` |

两个 run 的 `T` 相差 2 倍（1335.6 vs 2671.1）、`σ` 差 4 倍，但落在同一条 `ε_ν` 上且误差四位
一致 —— 说明残差由 `ν/(ωa²)` 这一个无量纲数控制，而**不是**分辨率 `w/R`、盒尺寸或界面厚度。
这是"残差 = 黏性修正"最直接的证据，也直接否定了第一版"弥散界面软化 `(kw)²`"的推测。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **锚的口径必须匹配模型**：单相（同密度）自由面 → 两流体 Rayleigh（式 5/6）；真两相
   （有密度跳变）→ 用 `ρ_i + ρ_o` 的一般式；真空/低密度气体 → 式 (3)(4)。混用会带进 41.4 %
   的系统偏差，且这个偏差长得像"模型坏了"。**这是第 1 次尝试 FAIL 的第一主因。**
2. **无黏锚要用无黏极限比**：Rayleigh 周期是 `ν = 0` 的陈述，在 `ν = 0.0167` 的 run 上直接比
   会得到 `+12 %`；把 `ν` 阶梯外推到 0 后截距 `-0.19 % ± 2.12 %`。反过来，也不能靠"凑一个低黏 run"
   过关：`τ = 0.505`（`ν = 0.0017`）虽然给出 `+2.2 %`，但 `max|u|` 从 `5e-4` 长到 `2.8e-2`
   （×57）、幅值不衰减 → **数值失稳，不是证据**，已判红剔除。
3. **点取样 `κ` 不可作证**：`w = 2` 时界面带仅 2–3 格，亚格子取样选择让 `cos2θ` 幅值在
   `0.7…2.5` 之间跳。必须用 `δ_s` 加权投影（式 7）或带均值，并声明这一点。
4. **`D(t)` 需要相位交叉校验**：`D` 是质量加权二阶矩，界面宽度调制会渗入；几何 marker
   `(r_x-r_y)/R` 是独立探针，两者 ≤0.5 % 一致才可作证。
5. **盒尺寸不是主因**（对照）：`L = 6R` 与 `8R` 的周期差 `0.3 %`；周期盒像相互作用的解析
   加质量在 `8R` 时只少 `0.14 %`（§2.1 的势流积分核对）。
6. **输运格式对照失败**：`advection="upwind"`（一阶迎风通量形式）在 `ν = 0.0167`、`|u|~1e-3`
   下界面从 `w = 2` 糊开、`max|u|` 增长 38×、`R² = 0.28` → 判红。半拉格朗日单调三次插值是
   本问题可用路径（第一版同样结论）。
7. **界面厚度不解释残差**：`w = 2/3/4` 的误差 `+12.2 % / +10.3 % / +10.3 %`，非单调且幅度小；
   若主因是弥散界面软化，应随 `w/R` 单调下降得多。与 (10) 的黏性标度一致。
8. **局限①**：`c` 与截距只由 4 个黏性点确定，无法把**物理黏性修正**与**格式耗散**分开
   （实测阻尼 `γ` 约为 Stokes 黏性率的 2–3 倍，说明有额外数值耗散）；故 `-0.19 %` 应读作
   "外推截距"，不是"模型误差严格 <0.2 %"（其不确定度取扫描散度 ±2.1 %）。
9. **局限②**：只做 2D 圆柱（n=2）。3D 球的振荡锚（`ω² = 4σ/(ρa³)` 同密度）未做，因为
   `R ≥ 32` 的 3D 长时程在单机 CPU 上不划算（估计 `≥ 3 h/例`）。
10. **局限③**：未做 PLIC-VOF/相场对照，也没有与实验数据对标（毛细振荡的经典实验是
    Prosperetti 1980 的振荡液滴，本环境无原始数据，故 OSC 锚只能算**解析锚**级证据）。
11. **适用范围**：本模块验证的是 CSF 算子 + 曲率 + 压力响应 + 界面输运在**低毛细数、
    低 Re、同密度**区间的正确性；不是密度比、相变、可压缩毛细流。

| 判据 | 阈值 | 实测 | 是否达标 |
|---|---|---|---|
| (a) Young–Laplace 2D（`R = 10/14/18`，预滤曲率） | < 3 % | 表 1：`+1.55 % / +0.65 % / +0.21 %`（最大 1.55 %） | **是** |

**「是否 <3 %」直接回答**：Young–Laplace 静态锚 2D **是**（最大 1.55 %），3D **是**

`-0.19 % ± 2.12 %`）；在**单个有限黏 run**上**不是**（`τ=0.55` 为 `+12.19 %`，因为 Rayleigh 式本身是
无黏陈述）。**「Marangoni 是否 <10 %」**：**是**（`-7.67 %`，系统性离散偏差，随 Ma 恒定）。
不粉饰：把"极限达标 + 单点不达标"合并成一句"通过"是不诚实的，本报告两行并列。
