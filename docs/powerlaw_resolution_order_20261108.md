   n=1.5 → 1.26%/0.99%/0.26%。**均 < 3%**（平台门槛），且 n=1.0 的中心线幅值锚定闭式解。
3. **剪切变稀（n=0.5）是真实欠账，不是基准错位**：H=40 实测 L2 = **5.70 %**（> 3%），

## 1. 案例介绍（物理背景 / 几何 / 参数）

* 物理：两无限大平板间、体力（压力梯度）驱动的 Ostwald–de Waele 幂律流体定常层流
  τ = K γ̇ⁿ、ν(γ̇) = K γ̇^(n−1)。n<1 剪切变稀，n=1 牛顿，n>1 剪切增稠。
* 几何：格点槽道，ny = H+2、nx = H；上/下壁为壁面行（行 0 与行 H+1），
  半程反弹（pre-streaming bounce-back）→ **壁面物理位置 y=0.5 与 y=H+0.5**，
  流体格心 y = 1…H，中心线 y_c = (H+1)/2，半高 Hh = H/2；x 方向周期。
* 参数族（固定"壁面黏度"与目标中心线速度，使三种 n 可比）：

  | 量 | 取值 / 关系 |
  |---|---|
  | U_target（仅用于定 K、fx） | 0.03 |
  | ν_wall | 0.05 |
  | γ̇_w = (n+1)U_target/(n·Hh) | 壁面剪切率 |
  | K = ν_wall·γ̇_w^(1−n) | 稠度系数 |
  | fx = ν_wall·γ̇_w/Hh | 体力 |
  | 黏度夹逼 | ν∈[1e−5, 0.3]（库默认 nu_min/nu_max） |

* **闭式解（幅值不拟合、不手注）**：

  u(y) = n/(n+1)·(fx/K)^(1/n)·[ Hh^((n+1)/n) − |y−y_c|^((n+1)/n) ]
  U_max = n/(n+1)·(fx/K)^(1/n)·Hh^((n+1)/n)

## 2. 怎么做的（方法 / 流程 / 工具链）

* 求解器：库自身 `collide_powerlaw_bgk_forced` + `stream` + 半程反弹 +
  `strain_rate_shear_rate_2d` / `powerlaw_viscosity` / `tau_from_viscosity`
  逐步更新 τ_eff（与 `tests/test_powerlaw.py` 完全同一套离散）。
* 网格加密：**固定物理参数族**（K、fx 由 Hh 反算，使壁面黏度与 U_target 不变），
  H = 14 / 22 / 34 三级；另做 H=40 单点复核（对齐旧测试网格）。
* 误差分解：总 L2、中心线幅值误差、**均匀滑移**（逐行差分的均值，占 U_max 比例）、
  **形状误差**（扣除均匀滑移后的 L2）。
* 收敛阶：p = log(e_H1/e_H2) / log(H2/H1)（格距固定为 1，加密即增大域高）。
* 闭合算子诊断：把**解析速度场**直接喂给库的离散剪切率算子，逐行比较
  γ̇_discrete/γ̇_exact（定位误差来源，纯后处理、无时间推进）。
* 力标度签名：同一 H 下把 fx 加倍，U_max 应按 2^(1/n) 变化（n=0.5 → 4.0，
  n=1.5 → 1.588）；牛顿核在任何 n 下都只会给 2.0，故该探针能区分流变学与受力。
* 工具链：CPU 单线程（`torch.set_num_threads(1)`）、float32、`torch.manual_seed(0)`；
  本机 load15>100（128 核），全部为单核进程。
* 复现：

### 3.2 收敛阶（诚实版：不是干净二阶）

| n | p(L2) 14→22 | p(L2) 22→34 | p(L2) 全局 | p(形状) 14→22 | p(形状) 22→34 |
|---|---|---|---|---|---|
| 0.5 | 1.23 | 0.06 | 0.66 | 1.86 | 0.77 |
| 1.0 | 1.65 | 1.19 | 1.42 | −0.25 | −0.41 |
| 1.5 | 0.54 | 3.05 | 1.77 | 1.35 | 2.99 |

* n=1.0/1.5：误差由**均匀滑移**主导（占总量 70–90%），滑移衰减比 h 慢，
  故总量阶 p≈1.4–1.8，而不是 2；形状误差在 n=1.5 已接近二阶（1.35/2.99）。
  n=1.0 的形状误差在 0.04–0.08 % 之间非单调（已到时间平均噪声量级，不可再作阶估计）。
* n=0.5：14→22 与 22→34 的阶分别为 1.23 / 0.06，**不进入渐近区**，
  且 3.3 节表明其时间推进根本没定常 → 该行的"收敛阶"不作数，如实标注。

### 3.3 剪切变稀的非定常证据（关键否定结果）

| n=0.5, H=14 | u_max | L2 vs 闭式解 | 墙钟 |
|---|---|---|---|
| 30 000 步 | 0.03588 | 20.82 % | 81 s |
| 90 000 步 | 0.05500 | 94.64 % | 239 s |
| 闭式解 | 0.03000 | — | — |

u_max 在 3 倍步数后仍单调上升 53 %（且越过解析值 83 %），说明
**在 ν_max=0.3 夹逼生效的参量族下，n=0.5 槽道没有定常解可收敛到**
（旧测试 40 000 步的"稳态剖面"其实处于缓慢增长的暂态）。

### 3.4 半格错位基准造成的误差放大（缺陷定量）

| n | H | 修正基准 L2 | 旧（半格错位）基准 L2 | 放大倍数 |
|---|---|---|---|---|
| 1.0 | 14 | 0.826 % | 11.266 % | 13.6× |
| 1.0 | 22 | 0.392 % | 7.181 % | 18.3× |
| 1.0 | 34 | 0.234 % | 4.650 % | 19.9× |
| 1.5 | 14 | 1.258 % | 11.369 % | 9.0× |
| 1.5 | 34 | 0.261 % | 4.641 % | 17.8× |
| 0.5 | 14 | 20.817 % | 24.689 % | 1.19×（真实误差本来就大） |

结构原因：错位基准把**壁面相邻流体格点**放到壁面上，返回 u=0，
而该点真实值约为 0.21–0.25·U_max —— 误差主项变成 O(h) 的几何错位，
完全掩盖了求解器本身的二阶行为。这也解释了旧 `assert l2 < 0.05` 为何能在
H=40 下"刚好通过"（错位基准在 H=40 仍报 ~3.4 %）。

### 3.5 闭合算子诊断（把解析场喂给库的剪切率算子）

| n | H | 壁面相邻行 γ̇_d/γ̇_exact | 内部行（去壁 2 行）γ̇ 偏差 |
|---|---|---|---|
| 1.0 | 14 / 22 / 34 | 0.721 / 0.732 / 0.739 | 0.000 % / 0.000 % / 0.000 % |
| 1.5 | 14 / 22 / 34 | 0.730 / 0.738 / 0.742 | 见 results_closure_bias.json（最大 ~21 %，集中在 γ̇→0 的中心区） |
| 0.5 | 14 / 22 / 34 | 0.697 / 0.716 / 0.728 | 同上（近中心 γ̇ 小处相对误差被放大，绝对量可忽略） |

结论：**牛顿时算子精确**（内部 0.000 %）；壁面相邻行的 γ̇ 系统性低估 ~26–30 %
（中心差分跨壁一侧 + 半格几何），对 n≠1 会经 ν=Kγ̇^(n−1) 放大成该行的黏度偏差。
注意：单格局部偏差**不能**直接线性外推到流量误差（本工作实测的符号与一阶局域估计相反），
故本文只把它作为"闭合离散是 n≠1 误差主源"的证据，不给定量修正公式。

## 5. 注意点 / 局限

* **参量族固定"壁面黏度"**，因此 H 增大时 γ̇_w∝1/H、K∝√H，n=0.5 的芯部黏度迅速顶到
  ν_max=0.3 夹逼；这是库默认夹逼与"同族加密"共同作用的结果，与 OpenLB powerLaw2d
  的常用做法一致，但**换一族参量（例如固定 K）结论可能不同**，故 3.3 的非定常结论
  限定在本族内。
* 未做时间步长/D3Q27/多松弛对照；未审查 `non_newtonian.py`（另一套 `torch.gradient`
  实现的幂律路径）——本验证只覆盖 `powerlaw.py`。
* 固定 `torch.manual_seed(0)`、单线程 CPU；数值与设备无关但**末位比特**可能随内核变化，
  所有判据都留了 ≥2 倍裕度。
* 旧测试文件 `tests/test_powerlaw.py` 的三条通道测试各需 ~150–330 s（H=40、40 000 步），
  本单未改其步数（避免扩大改动面），但已在文档标注其运行成本。
