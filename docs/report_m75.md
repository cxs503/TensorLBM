## 1. 案例介绍

### 1.1 物理背景

球体绕流 Re=100 是经典的低雷诺数验证基准。在该雷诺数下，流动为稳态轴对称分离泡，

该案例用于验证 LBM 求解器在 SDAA（思元加速卡）上的正确性与性能。

## 5. 注意点

### 5.1 根因分析

1. **SDAA OOM (D=40)**: 域 280×280×320 = 25,088,000 格子，预估需 4–5 GiB。
   实际分配 7.78 GiB 后尝试再分配 3.37 GiB 失败。可能原因：
   - PyTorch SDAA 后端内存碎片化
   - BFL (boundary link) 数据在 setup 阶段即超出预算
   - README 声称 D=40 可运行，但可能基于不同 SDAA 卡或不同内存状态

2. **SDAA 极端慢速 (D≤20)**: D=10 仅 100 步即超时 30s，而 CPU 同样配置仅需 5s。
   SDAA 后端比 CPU 慢 10–100×，可能原因：
   - 稀疏核函数在 SDAA 上的编译开销
   - kernel launch 效率低下
   - 内存带宽瓶颈

3. **KBC 碰撞非物理振荡**: 16³ 小域 20 步不足以收敛，BGK/KBC 的 Cd 均在 ±100 量级
   振荡，H 定理存在微量违反。这提示 KBC 实现可能存在数值稳定性问题。

### 5.2 RANS k-ε 模型精度不足

- Re=1e5 误差 20.5%，Re=1e4 误差 43.2%，远超 3% 门限
- 可能原因：k-ε 模型参数未针对 LBM 格子单位校准；壁面函数不适用当前分辨率

### 5.3 局限性

- 未尝试缩小计算域（会改变物理，不适用于验证案例）
- 未尝试其他 SDAA 卡（环境中仅一张可用）
- KBC 诊断仅 20 步，结论有限
