## 1. 案例介绍

### 1.1 物理背景

**stokes\_sphere\_dg** 是 TensorLBM 基准库中一个 *已验证 (verified)* 案例，模拟周期盒内单球 Stokes 拖曳。流体由均匀体积力 $g_x$ 驱动，无入口/无壁面，弛豫至周期 Stokes 解。

核心无量纲观测量为 **拖曳修正因子**：

$$K = \frac{F_{\text{ledger}}}{6\pi\mu a\, U_{\text{sup}}}$$

其中 $F_{\text{ledger}} = g_x \cdot N_{\text{fluid}} \cdot \Delta V$ 为精确恒定的动量收支（稳态时体积力输入 = 球体拖曳），$U_{\text{sup}}$ 为体积平均叠加流体速度。稀薄极限 $\phi \to 0$ 时 $K \to 1$；有限 $\phi$ 使 $K > 1$。

### 1.2 几何与参数

| 参数 | 值 |
|------|-----|
| 格子模型 | D3Q19 |
| 碰撞 | BGK, $\tau = 1.0$ |
| 边界 | BFL (bounce-back force ledger), sparse |
| 驱动力 | Guo force delta, $g_x$ 由 $Re_a = 0.05$ 反算 |
| 固体分数 $\phi$ | 0.005 / 0.010 / 0.020 |
| 球半径 $R$ (格子) | 8 / 12 / 16 / 24 |
| 周期盒 $L$ (格子) | 48–226 (随 $\phi$, $R$ 调整) |
| 总层数 | 3 × 4 = **12 tiers** |

### 1.3 参考值来源

$K_{\text{ref}}(\phi)$ 由两条独立路径锁定（reference\_table.json, md5 af32757f）：
- **K\_ref\_bie\_P5**：自研周期边界积分 Stokes 求解器，Hasimoto 周期 Green 函数，P5 面板分辨率
- **K\_series\_invE**：Ewald 分裂逆级数评估

两路径一致性 ≤ 9.12×10⁻⁴ %。文献锚点：Hasimoto 稀薄级数 & Zick & Homsy Table 2。

## 2. 方法 / 流程

### 2.1 SDAA 扫荡脚本

编写独立脚本 `scripts/sdaa_sweep_stokes_sphere_dg.py`（**不改业务代码**），核心设计：

1. **张量放置**：所有计算张量置于 `sdaa:0`，无 CPU 回退路径
2. **零手抄**：层参数从 `reference_table.json` 读取；步数表/门限/尾窗函数从案例 `run.py` 以模块方式导入（不执行 main）
3. **判据口径**：完全复用案例自身的 7 门判定体系（MAIN + S0–S3 + GEOM×2）

### 2.2 执行配置

| 项目 | 值 |
|------|-----|
| 设备 | sdaa:0 |

### 2.3 Triton / SDAAGraph 绕行记录

| 主题 | 处理 |
|------|------|

## 5. 注意点

1. **覆盖度不足**：仅执行 1/12 层（φ=0.02, R=8），R-ladder 收敛性门标为 `NOT_EVALUATED`。完整 4 层扫荡需 ~40 h 参考预算，超出 20 min SDAA 扫荡窗口。
2. **SDAAGraph 不可用**：sparse BFL 内核中的 advanced indexing 与 stream capture 冲突，只能 eager 执行。性能损失 ~8.6×（SDAA 892 s vs NVIDIA 归档 104 s），但数值完全一致。
3. **离散 $\phi$ 偏差**：φ=0.02, R=8 的离散固体分数 $\phi_{\text{disc}} = 0.01907$ 与目标 $\phi_{\text{gate}} = 0.01939$ 偏差 −1.66%，导致 $U_{\text{sup}}$ 偏离目标 +3.0%。这是格子离散化固有误差，非算法缺陷。
4. **Triton 无关**：案例内核全部为纯 torch op，无需 TRITON\_INTERPRET=1。
5. **不可比性声明**：本 SDAA 扫荡结果（1/12 层 PASS）不能替代原案 12/12 VERIFIED 判定，只能证明 SDAA 后端在该层的数值正确性。
