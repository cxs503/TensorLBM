## ① 案例介绍（物理背景 / 几何 / 参数表）

替代燃料（LNG=CH4、液氢、液氨）泄漏后在近地面形成可燃气云。危险区的外部边界定义为浓度等值线 `C = LFL`（lower flammability limit，可燃下限）：进入该等值线的空间即处于可燃范围。工程上要回答的是「源强 Q、风速 U、稳定度下的危险区有多远、多宽、随时间怎么变」。

本节点把这条泄漏链拆成可以**分别给出解析锚**的四环：

1. 标量（浓度/温度）输运内核：D2Q5 对流–扩散格气，含开边界通量记账；
2. Boussinesq 浮力耦合：标量异常经 Guo 力注入 D2Q9 动量方程（轻质气云上浮）；
3. 近场：LBM 直接解析连续源横风泄漏场，提取 LFL 等值线几何与网格收敛性；
4. 远场：Morton-Taylor-Turner 积分羽流（卷吸闭合）给出 `Q ∝ z^{5/3}` 自相似，Briggs/Pasquill-Gifford 高斯羽流给出工程危险区距离。

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2.1 标量 LBM：TRT 碰撞与数值扩散标定

D2Q5 标量格上 `D = c_s²(τ-1/2)`；把分布按 `g± = (g_i ± g_ī)/2` 分解后分别以 τ_s、τ_o 弛豫。**关键点（本节点踩过并已用 5×5 离散谱判明）：标量扩散由反对称（odd）部分控制**，即在 `D = c_s²(τ_o-1/2)` 中 τ_o 是扩散率，τ_s 才是自由的「鬼」模；这与 D2Q9 流体力学里「τ⁺ 控粘性」的记法正好相反。判据是 `scalar_transport.dispersion_rates()` 给出的物理分支衰减率 `-ln|λ|/k²`：

| 碰撞 | k=0.05 | k=0.2 | k=0.4 | k=0.6 |
|---|---|---|---|---|
| TRT Λ=3/16 | 0.049996 | 0.049942 | 0.049768 | 0.049477 |
| BGK (τ_s=τ_o) | 0.050005 | 0.050080 | 0.050320 | 0.050725 |

数值扩散标定（k∈[0.05,0.6] 上最小化 `|D_eff(k)/D-1|`）：最优 Λ* = 0.1250，最大偏差 0.109%；BGK 基线 1.450%。生产设置取经典 Λ=3/16=0.1875（偏差 1.05%），并在报告中同时给出 BGK 对照。

### 2.2 开边界质量账（非恒等式）

streaming 用 gather 实现：通过开放面离开的分布由**流前**分布求和得到；入口（反反弹 Dirichlet）与出口（零梯度）作为「储层」返回**带符号**的交换量；体积源按平衡权重注入。于是

```
residual = (M_final - M_initial) - (injected - outflux)
```

是由三组独立数组算出的真实残差（本跑批最大 1.20e-13，阈值 1e-12）。

### 2.3 Boussinesq 耦合

`F = +ρ0 g β_C (C-C_ref) e_up` 经 Guo 力注入；均匀异常（周期盒）下解析解为 `u_y = g β ΔC t`，实测相对偏差 1e-8（`tests/test_scalar_transport.py::test_boussinesq_impulse`）。

### 2.4 远场：积分羽流与经验高斯羽流

顶帽 MTT 方程（RK4）：`dQ/dz = 2πα b w`、`dM/dz = g'A`、`g' = B/Q`，自相似解 `Q = (3π²c₃⁴B/4)^{1/3} z^{5/3}`、`b = c₃ z`、`w ∝ z^{-1/3}`，`c₃ = 6α/5`。负控为同一积分器取 `B = 0`（纯动量射流）→ `Q = 2α√(πM) z`。危险区用 Briggs σ_y/σ_z 的高斯羽流（含地面反射）二分求 `C_ground = LFL`。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **TRT 的奇偶分工是坑**：最初按流体力学习惯把 τ⁺ 当扩散率，实测 D_eff 偏大约 11 倍；用 5×5 离散谱（`dispersion_rates`）逐波数判别后确认标量扩散由 **odd（反对称）** 弛豫率控制。该判别已固化为单元测试，任何把奇偶写反的改动都会立刻变红。
2. **gather 的开放面掩膜必须是逐节点而非逐方向**：早期实现用 `torch.all()` 把整方向置零，导致开放边界下完全不输运（表现为入口堆积、场几乎不动）；此 bug 由质量账残差 1.0 暴露。
3. **高斯锚的位置与形状要分开报**：离散对流速度有 O(1) 格子的相位偏移（本报告质心偏移 ≤0.5 格），若把位置误差也计入相对 L2，误差会被 O(1/N) 的平移主导而掩盖真实形状精度。因此同时给出「含位置」与「形状（对齐质心）」两个数字，两者均在 2% 内。
4. **二维各向同性几何的结构性局限**：二维点源下 `C_cl ∝ x^{-1/2}`（实测 -0.4874，解析 −0.5 ✓），下风延伸对风速**不敏感**；横向宽度的 U^{-3/2} 标度只在「固定绝对阈值 + 无限域」下成立，本跑批不满足该前提（阈值 = 源节点浓度分数、域有限），实测幂仅作诊断记录。三维真实气云的下风危险距离必须由三维高斯羽流/积分羽流给出，LBM 在此承担近场（源区、浮力抬升、LFL 等值线几何、网格收敛与守恒证据）。
5. **积分羽流的 5/3 是闭合模型的解析后果，不是解析出的湍流**：MTT 模型以 `u_e=αw` 卷吸闭合替代湍流，指数由该闭合与浮力通量守恒共同决定；LBM 在可负担分辨率下无法分辨湍流卷吸。本节点的诚实表述是「闭合模型实现正确性 + 自相似结构验证」，不是「湍流被解出」。
6. **高斯羽流是经验模型**：Briggs 系数对现场数据的典型不确定度为 2 倍量级；本报告用它给出区间（D/F 稳定度），不宣称优于 ±50%。
7. **反反弹入口的壁面位置**：本实现的反反弹 Dirichlet 使 `C(x=0)=C_wall`（壁面落在节点上），与半格壁面约定差 0.5 格；若按半格约定比较会出现 ≈ `0.5·|∂C/∂x|` 的系统性平台差（在 W=20 格时约 2.8%），本报告用节点壁面约定比较，残差降到 1e-4 量级。
8. **适用范围**：被动/浮力标量（不可压、低马赫、忽略凝结与化学反应）；LFL 判据是「瞬时浓度超限」，不含点火源与爆炸超压评估。
