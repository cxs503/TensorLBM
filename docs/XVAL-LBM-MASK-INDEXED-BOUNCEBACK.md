
源码逐条（不引二手描述）：流后（post-streaming）对布尔障碍掩膜做**同时性置换写**（RHS 在写入前求值）；
掩膜每几何构造一次、每步复用（`examples/benchmark.py:43,147`）；流式是周期 pull 平移（`lbm/basic.py:46-79`），
故固体格子流后持有"从邻居流进来"的值；算子**不含亚格子信息**（无壁面距离/壁速，动壁是另一套非掩膜例程 `bb.py:16-80`）；
分布是移位量 `f_i=f_i^full-w_i`（`lbm/basic.py:20`），因 `w_i=w_opp(i)` 镜像与移位可交换。

判据：本仓同算子实现（本轮新增）与 OSS 语义**逐位一致**，且物理量在 owner 15% 带内。

**执行限制**：vivsim 为 JAX，本机无 `jax`（ModuleNotFoundError）、无 GPU ⇒ OSS 臂是**逐行移植**成 torch 的等价布尔 select+scatter
（同时性相同），**不是执行 OSS 二进制**；故计时不可与 vivsim JAX 横向比较。此限制不升级。
