## 1. 问题设定与基准出处

Plane channel, `nx = 4` (x-periodic), `ny = 49` rows, halfway bounce-back walls
(`H = ny−2`), neutral-wetting (`mirror`) Shan–Chen wall. Component 1 fills the lower half,
component 2 the upper half. Driven cells use a uniform body force `G_x = 5e-5` per mixture
volume; the static control uses `G_x = 0`. `τ₁ = 1.0` (lower, heavy), `τ₂ = 0.75` (upper, light).

Reference solution: the closed-form two-layer co-moving Poiseuille profile
`u'' = −G/ν_layer`, `u(0)=u(H)=0`, `u_l(h)=u_u(h)`, `ν_l u_l'(h) = ν_u u_u'(h)`
(`cases/mcmp_stratified_poiseuille/analytic.py`, `layered_poiseuille`), with the mixture
viscosity rule `ν_layer = Σ_σ ρ_σ ν_σ / Σ_σ ρ_σ` evaluated on the **measured** coexisting
fractions. Benchmark lineage: Huang, Krafczyk & Lu (2011) MCMP analytic benchmarks; Shan &
Chen (1993, 1994) two-component pseudopotential and coexistence; Guo, Zheng & Shi (2002)
forcing; Kupershtokh et al. (2009) exact-difference (EDM) pair force.

Acceptance criteria (ledger `GAP-LBM-MCMP-POISEUILLE`, definitions unchanged since R1):
① `|Δy_int| < 5 %`; ② `|ΔQ_mix| < 10 %`; ③ `S_ifc < 0.005·u_max` (static control,
`S_ifc = max|u_y,mix|` in the interface band `|α−0.5| < 0.25`, normalised by the analytic
`u_max` of the driven case at the same resolution); ④ ①② trend consistent on two resolutions.

### 2.2 调研·方法谱系 + 选型

Three families can carry criterion ③:

1. **Pseudopotential + better forcing** (current path; Kupershtokh EDM, Guo). R3 measured EDM
   ≈ standard at late time: the interface thins because the model has no surface-tension-held
   equilibrium width.
2. **Pseudopotential at *true coexistence*** — classical coexistence measurement (Shan & Chen
   1994; Martys & Chen 1996) and a resolution rule for the diffuse interface (Krüger et al.,
   *The LBM* (2017) §9.3; Sbragaglia et al., *JFM* 628 (2009) 299). This is what this round
   implemented and tested.
3. **Free-energy / Cahn–Hilliard binary LBM** (Swift et al. 1996; Pooley et al. 2008), where
   `κ` sets an *equilibrium* interface width and the pressure tensor is z-discretisation
   consistent; literature reports spurious currents 2–4 decades below the SC model. This is
   the migration target for the next round (§6).

**Implementation this round** (`coexistence.py`, new; `r4_probe_static.py`, new;
`r4_wrapup.py`, new):

* flat interface in a **fully periodic strip** (`ny = 96`, `nx = 2`), quiescent tanh seed
  (`width = 4`), 20 000 steps, no walls, no body force, so the measurement is free of the
  wetting/wall calibration;
* coexisting densities from the two bulk halves (symmetrised), 10-90 interface thickness and
  the equivalent tanh width `w = (y₁₀ − y₉₀)/2 atanh 0.8`; interface drift and density
  steadiness over the last quarter of the run;
* **pre-registered admissibility window** (fixed before the probe):
  `3 ≤ w₁₀₋₉₀ ≤ H_min/10 = 4.70` cells (resolved interface *and* separation of scales for the
  sharp-interface reference), contrast `≥ 0.5`, drift `< 0.5` cell; tie-break = largest `|G₁₂|`;
* the selected state initialises the static control (`G_x = 0`, `ny = 49`, 30 000 steps) for
  both pair-force discretisations.

## 5. 收敛性 / 敏感性 + 失败模式

**Hypothesis of this round** (H-R4): *the R3 plateau is an initial-state artefact — starting
the static control at the model's coexistence state restores a resolved equilibrium interface
and drops `S` below the gate.* **Verdict: REFUTED.** The measured `S_ifc` moves from 7.35e-3 to
8.62e-3 (edm, +17 %), i.e. away from the gate.

The refutation is informative because of a diagnostic that R3 did not report separately:
`S_bulk = S_all` in both arms, i.e. **the largest vertical velocity is outside the interface
band**. The residual is not an interface-localised parasitic curl at all — it is a steady
**bulk vertical motion** of the whole stratified column. Its sources are structural:

* the two wall-adjacent rows see different effective viscosities (`τ = 1.0` vs `0.75`) and the
  mirror-wall pseudopotential is not symmetric between the two components, so the column
  carries a persistent normal momentum flux;
* the model has **no surface tension holding a flat interface at equilibrium**: with a linear
  `ψ = ρ` the pressure of the mixture is uniform, there is no Laplace pressure, and the
  interface width is set only by the repulsion/diffusion balance. Total density is not uniform
  near the walls, so the interface is not in mechanical equilibrium;
* consequently neither the force discretisation (edm vs standard, 1 % apart) nor the initial
  state (nominal vs coexistence) can move `S` by the required 1.2 decades.

**Corrected reading of an earlier number.** R2 reported `S_ifc/u_max ≈ 0.0019` at
`|G₁₂| = 2.0`, `ny = 49`. The calibration shows that `|G₁₂| ≤ 2.4` does not sustain a sharp
interface at all (52-cell-thick interface at −2.4, full mixing at −2.0): that 0.0019 was
measured on a *diffusing mixture*, not on a resolved interface, and must not be used as
evidence that criterion ③ is reachable with a weaker coupling. Removing that number from the
"tried and ruled out" list is one of this round's results.

**`fail_stage` = model class (surface-tension-free pseudopotential interface).**
**`failure_reason`** = at the model's own coexistence state and at both pair-force
discretisations the static control plateaus at `S_ifc = 8.6–8.7e-3` (ratio 0.0767–0.0772 vs
gate 0.005), the maximum vertical velocity sits in the bulk (`S_bulk = S_all`), and the two
levers available inside the model (initial state, force discretisation) change `S` by ≤ 17 %
and 1 % respectively — 1.2 decades short.

## 6. 下一轮迁移方案（选型沉淀，已入 `oss_solutions`）

**Decision**: replace the pseudopotential interface with a **free-energy binary LBM**
(Cahn–Hilliard convection–diffusion + consistent pressure tensor), keeping the *flow* side of
the current implementation (halfway bounce-back, Guo forcing, `viscous` velocity coupling,
`G_x` driving) and the analytic two-layer reference.

Transfer (structure taken from the catalogued OSS implementations, §2.1):

1. two distributions: `f` (density/momentum) and `g` (order parameter `φ`, chemical potential
   `μ = A(−φ + φ³) − κ∇²φ`);
2. equilibrium of `f` carries the free-energy pressure tensor
   `P_ab = [p_b − κφ∇²φ]δ_ab + ρu_a u_b + κ(∂_aφ∂_bφ − ½|∇φ|²δ_ab)` with
   `p_b = ρ/3 + A(−φ²/2 + 3φ⁴/4)` — the same closure verified to 1e-16 residual in the
   sailfish symbolic derivation (`sailfish/sym_equilibrium.py:15-71`);
3. interface force `−φ∇μ`, applied with the Guo velocity shift (`src/phi_grad_mu.c:40`);
4. **tunable** interface width/tension `ξ = √(−2κ/A)`, `σ = √(−8κA³/(9B²))`: set `ξ = 4`
   lattice cells so criterion ③ is exercised on a resolved, equilibrium interface, and
   `σ` such that the capillary number of the driven flow is small;
5. stratification comes from the free-energy double-well (coexisting `φ = ±1` phases) with a
   density contrast carried by `p_b(ρ, φ)`, so the two layers have different `ν` and the
   two-layer Poiseuille reference still applies;
6. prerequisite activation tests **before** the Poiseuille cell: (a) flat-interface profile
   vs the analytic tanh with `ξ`; (b) Laplace law `Δp = σ/R` over three radii; (c) static
   droplet spurious current vs resolution (target `< 0.005·u_max` at `ny = 49`).

Criterion ③ itself stays **unchanged** (normalisation by the driven `u_max`, interface-band
definition). Re-normalising by the capillary velocity `σ/μ`, or redefining ③ on a static
droplet, are *metric* changes and are therefore escalated, not adopted here.
