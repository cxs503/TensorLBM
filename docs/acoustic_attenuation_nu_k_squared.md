# 平面声波衰减率的正确口径：δ = νk²（LBM BGK，D2Q9）

物理注记（结论定标自 verified acoustics 基准，2026-09-20）：库原生 D2Q9 BGK
（`solver.collide_bgk` + `solver.stream`，周期域、无人工修正）的平面声波
时间衰减率，连续极限是

```
delta_cont = nu * k**2        nu = cs**2 * (tau - 1/2) = (tau - 1/2) / 3
```

即衰减系数与 LBM **剪切粘度** ν 严格同系数——既不是 νk²/2（物理等温 NS、
ζ=0 的读法），也不是 2νk²。CE 裸层级给出 cs²τk²，离散时间 (τ−½) 修正后
首系数**恰为** ν = (τ−½)/3，与粘度重整化完全平行。用二维等温 NS 读法
（平面波时间衰减 = (ζ+μ)k²/2ρ₀），BGK 等价于有效体积粘 **ζ = μ**
（bulk:shear = 1:1）——BGK 声衰减是等温 NS 的 2 倍，这是 BGK 人工体积粘
的定量表述。

## 离散修正链（小 k 级数，闭式）

对每波数 k 的一步传播算子（9×9 特征值问题）做精确级数展开
（sympy 有理系数）：

```
s(k)  = a1 k + a2 k**2 + a3 k**3 + a4 k**4 + O(k**5)
a1 = i/sqrt(3),   a2 = -(tau - 1/2)/3

delta(k) = nu * k**2 * (1 + c2 * k**2 + O(k**4)),   c2 = (2*tau - 1)**2 / 12
c_ph(k)  = cs * (1 - beta * k**2 + O(k**4)),        beta = -(12*tau**2 - 12*tau + 1) / 72
```

- 首项声速恰为 cs = 1/√3（无 O(k) 修正）；离散−连续差为 O((kλ)²)。
- τ=1 时 β = −1/72（相速度略**高**于 cs）、c₂ = 1/12 > 0（离散衰减恒略
  大于连续极限）。

## 证据链（三链闭环）

sympy 精确级数 ↔ 9×9 每波数特征值（两条独立推导路径在 N∈{8,16,32,64,128}、
τ∈{0.6, 1, 1.2} 逐点一致 < 1e-10）↔ 真实模拟（fp64 CPU，τ=1.0，
N=λ/dx∈{16,32,64}，ε=1e-3）：

| N | δ_meas vs 连续 νk² | δ_meas vs 离散理论 |
|---|---|---|
| 16 | +1.3145% | −0.00002% |
| 32 | +0.3231% | −0.00002% |
| 64 | +0.0812% | +0.00081% |

模拟与离散理论吻合到 1e-5–1e-7 相对，且模拟 vs 连续的偏差 ≡ 离散理论
预测值——级数 ↔ 特征值 ↔ 模拟三链闭环。收敛阶 O(N⁻²)（衰减误差比
4.07 / 3.98）。τ 敏感性（N=32）：+0.0301 / +0.1161 / +0.3231 / +0.6357%
（τ = 0.6 / 0.8 / 1.0 / 1.2），完全由 c₂(τ) = (2τ−1)²/12 解释。

## 实务指引

- 声学衰减预估/对标用 δ = νk²（ν 取 LBM 剪切粘度）；细网格误差预算加
  离散修正项 c₂k²（N=16、τ=1 时 +1.31%）。
- 判别：若参考/实测衰减 ≈ νk²/2，说明对端用了 ζ=0 的等温 NS 口径，
  对 BGK 不适用（差 2 倍）；若 ≈ 2νk² 则是把"BGK 为等温 NS 的 2 倍"
  双重计入（正确读法：2 × (νk²/2) = νk²），同样错。
