## 1. 物理背景与算例设置

被检验的命题：**同一个物理问题，在离散格子相对于物体/来流任意取向 θ 时，解必须在声明容差内不变；施加伽利略平移 U 后的解必须等于平移前的解加 U；残余偏离必须服从可预测的 Ma² 律。**

三个算例都以解析几何（真 SDF）描述物体，只旋转几何/驱动方向，不动格子：

1. **斜槽 Poiseuille**：宽 H 的平面槽道与格子成 θ=0/15/30/45°，壁面用 SDF 求壁距分数 q 的 Bouzidi 插值反弹；入口/出口面用非平衡外推（NEEM）施加精确抛物线速度。验收量：速度场 L2 误差随 H 的观测阶（判据 C1）。
2. **圆柱绕流**：双周期方箱内，半径 D/2 的圆（SDF=d−R），沿 (cosθ, sinθ) 方向以“定体积流量”死拍控制驱动（每步体力 f=ρ(u_target−ū)，稳态时 ᾱ·N_fluid 即阻力），Re=100/200，θ∈{0,15,30,45}°。验收量：Cd、St 的取向散布（C2/C3）。
3. **Taylor–Green 涡 + 伽利略平移**：周期箱 n=64，k=2π/n，ν=0.01，U 取使 U·T 恰为整数个格子的值（无需插值即可比较叠加解）。验收量：叠加残差随 Ma、衰减率相对偏离随 Ma 的幂律（C4/C5）。

负控（C6）：同分辨率下裸 BGK 且 τ→0.5⁺（Re_eff≈2×10⁴），其 Cd 取向散布必须**超过** C2 容差，用于证明 C2 的通过不是判据太松。

## 2. 方法与工具链

- 求解器：`tensorlbm.invariance.solver.D2Q9Solver`（纯 NumPy 单精度/双精度），BGK 或 TRT（magic=3/16）碰撞 + Guo 二阶体力；流式=周期 gather + 壁面入射分布覆盖。
- 壁面：Bouzidi et al. (2001) 线性/二次插值反弹（q<1/2 与 q≥1/2 两支），q 由解析 SDF 与 SDF 梯度沿格子方向求交得到；`bounce_back="halfway"` 冻结 q=0.5 退化为经典半步反弹，用作对照/负控。
- 几何：`tilted_channel`（真 SDF = H/2−|n̂·(r−c)|）、`circle`（SDF=|r−c|−R，外流约定，固体在圆内）。
- 驱动：斜槽用入口/出口速度 Dirichlet（NEEM）；圆柱用死拍体积流量控制；TG 用解析初场 feq(ρ=1, u_exact+U)。
- 运行：`python scripts/run_invariance_campaign.py --case all --workers 14`，多进程并行；每个算例落 JSON + 自身 SHA-256；`--case report` 汇总判据。
- 图表：`python scripts/make_invariance_figures.py`。

## 5. 注意点 / 局限 / 适用范围

- **格子层级容差**：全部结论都绑定在 D2Q9 格子与所声明分辨率（H=8…24、D=12）上；更高 Re 或更细网格需重跑本 campaign，不得外推。
- **圆柱算例的周期箱约束**：双周期方箱内 16D 间距意味着这实际是“柱阵中的流动”，Cd 绝对值高于单柱文献值（块塞比与尾流再入效应）；C2/C3 检验的是**取向散布**（同一离散化下的相对量），不宣称绝对 Cd 与实验/文献对齐。
- **驱动方式**：定体积流量死拍控制使体力量 f̄·N_fluid 成为阻力估计；该估计依赖稳态（统计平均）与周期箱动量守恒，瞬态段不计入。
- **斜槽进出口**：入口/出口施加精确物理解，误差统计剔除两端各 25% 长度，因此 C1 度量的是斜壁离散化而非流入边界条件。
- **斜槽不可能在周期箱内实现**（无限条带只在沿轴平移下不变，无法构造二维环面），故本轮以进出口面替代周期边界；这是对战役描述的有意偏差，理由见上。
- **C4 的两个定义**：主判据按战役定义与解析解比较（含格式截断误差）；另给出叠加残差 |u(U)−u(0)−U|，它隔离了格式内部破坏伽利略不变性的部分。
- **TRT 参数**：圆柱算例用 TRT（Λ=3/16）以获得 Re=200 的稳定裕度；负控保持裸 BGK。
