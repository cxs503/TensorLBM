## 1. 案例介绍

**物理背景。** 船后桨在 LBM 里过去只有两类模型：体素化实体桨（moving-wall bounce-back，代价 ~10^5 步量级）与致动盘（`actuator_disk.py`，把 `K_T(J)`/`K_Q(J)` 查表当输入，推力是**假设**的而不是**算**出来的）。本节点补上第三代模型：**致动线法 ALM**——桨叶被压成若干条径向载荷线，载荷由当地流场采样 + 翼型极曲线现算，再以高斯核涂抹到格点。

**几何与参数。** 桨盘用 B 系列类参数化重建（弦长分布按展开面积比归一、螺距近常数、厚度表取自 B 系列、NACA a=0.8 型弯度由零升力角体现）：

| 参照桨 | Z | P/D | A_E/A_0 | 用途 |
|---|---|---|---|---|
| B4-70 (P/D=1.0, Z=4) — calibration family | 4 | 1 | 0.7 | 标定族 |
| B5-75 (P/D=1.2, Z=5) — blind | 5 | 1.2 | 0.75 | 盲测族 |
| B3-50 (P/D=0.8, Z=3) — blind | 3 | 0.8 | 0.5 | 盲测族 |

**格点算例（ε 收敛与模型互裁）。** 域 96×88×88、D=20 lu、J=0.5、n=0.0025 rev/step（叶尖 Ma≈0.157）、每桨 18 个展向站、4 叶、D3Q19 + MRT-Smagorinsky、Guo 型加力。

## 2. 怎么做的

1. **叶元载荷层**（`blade_element_forces`）：三线性采样格点速度 → 转到桨叶当地 (轴向, 切向) 坐标 → 攻角 α = θ_pitch − φ，φ = atan(w_a/w_t)，w_t = Ωr − u_θ；`dT = ½ρW²c(C_L cosφ − C_D sinφ)`（推力大小）、`dF_t = ½ρW²c(C_L sinφ + C_D cosφ)`（沿 −e_t 的阻力矩）。**轴向约定（显式声明）**：来流取 +x，桨必须给流体 **+x** 动量（动量定理：盘面速度 V(1+a) 大于来流），故桨叶上的推力矢量指向 −x，流体受 +x 力被加速。这与仓内 `actuator_disk.py`（`fx = −T/V`，来流 +x 却把流体推 −x）**相反**，旧模型实为动量汇；此差异已作为审计发现登记（见 §5.8）。
2. **翼型极曲线**：线性段 `C_L = 2π·0.95·(α − α₀)`，`α₀ = −1.4°`；`C_D = C_D0 + k C_L²`，`C_D0=0.009, k=0.0075`；失速后接 Viterna-Corrigan 平板延拓。其上叠两项**叶栅级**修正：(a) 叶栅互干涉 `C_L *= max(1 − k_c σ, 0.10)`，σ = Zc/(2πr) 为当地实度，`k_c = 0.62` 是本模型**唯一标定常数**（见 §5 诚实声明）；(b) 旋转增升（Snel-Houwink-Bosschers 1993）`ΔC_L = min(2.2(c/r)(√(1+(ΔC_L,2D/0.2)²)−1), 0.15)`，仅在失速后生效。
3. **Prandtl 损失**：`F = (2/π)arccos(exp(−f))`，`f = (Z/2)(1−x)/(x sinφ)`，另叠根损 `f_hub = (Z/2)(x−x_h)/(x_h sinφ)`（只在内半径起作用）。注：任务书写成 `(1−r/R)/(2 sinφ)`，等价于 Z=1 的特殊情形；本实现用带叶数的标准形式。
4. **高斯涂抹**（`GaussianSmearer`）：marker 力先 CIC 撒到局部盒，再沿三轴做**单位和的**一维高斯卷积（截断 3ε，盒边留 3ε+2 余量），因此总力/总力矩与 ε 无关、误差 ~1e−15（这是 C5 的直接证据）；轨迹与沉降都是可分离的，单步成本 O(N_box·3ε)。
5. **诱导闭合（BEMT）**：同一叶元载荷 + 环带动量定理 `dT = 4πρ r V_a² a(1+a) F dr`、`dQ = 4πρ r³ V_a Ω a'(1+a) F dr`，对每站 Newton 解 (a, a′)，输出 K_T/K_Q。这是 ALM 的轴对称极限，也是设计/验证快通道。
6. **互裁**：在**同一** LBM 算例里跑 (i) ALM 叶线、(ii) 致动盘（把 BEMT 积分载荷均匀铺在盘面上、线涡旋分布），两者都用**力矩通量**（控制面 y–z 平面上 ρu_x²+p 与角动量通量）独立测量 K_T/K_Q。

## 5. 注意点 / 局限 / 适用范围

1. **唯一标定常数与盲测**：叶栅系数 `k_c = 0.62` 是在 B4-70 族曲线上一次定死的；因此 B4-70 的吻合**不是独立预测**。B5-75 与 B3-50 两族是完全盲测（其 P/D、A_E/A_0、Z 都不同），误差见表 3.1；B5-75 在整段 J 上 |ΔK_T| ≤ 7%，B3-50 在强推力段 |ΔK_T| ≤ 1%，近零推力端（J≥0.9，K_T→0）相对误差失去意义，已从统计中剔除并如实标注。
2. **重载区动量闭合失效**：J ≤ 0.3 时推力载荷 C_T ≈ 10–25，环带动量定理 `4a(1+a)` 早已出validity（a>1），Newton 在根部站不收敛（本报告里以 `merit` 记录），低 J 的 K_T 与 K_Q 偏差（尤其扭矩 −10%~−16%）主要来自这里。要压到 5% 需要涡尾迹/重载经验分支，不是本节点能一蹴而就的。
3. **扭矩系统性偏低**：三族在 J≤0.4 都出现 −9%~−21% 的 K_Q 低估，且与 C_D0（0.009→0.02）几乎无关，说明缺的不是型阻而是重载下的诱导扭矩/涡损失。
4. **in-repo 'KP505' 表疑似 MOCK**（审计发现）：`actuator_disk.py` 里标注 Fujisawa(2000) 的 KP505 表给出 K_T(0.7)=0.29、零推力 J≈1.10；而 5 叶 P/D=0.95 桨的叶元解给出 K_T(0.7)=0.161、零推力 J≈1.01。两者相差 45%~80%，全 J 段无交集。该表**未**被用作本文基准，已登记为待复核的疑似 MOCK 数据。
5. **格点算例是准稳态而非完全收敛**：J=0.5、n=0.0025 rev/step 时来流 u_in≈0.025 lu/step，域内尾迹穿越需 ~2600 步，而算例只跑到 1400 步（~3.5 转）。四个 ε 与致动盘都在**同一物理时刻**对比，故 ε 趋势与模型互裁有效；但 K_T 的绝对值不可与开水分辨率实验直接对齐。
6. **ε 敏感性是「自诱导」而非「总诱导」**：格点上盘面平均轴向诱导在 ε=1/2/4 分别是 0.444/0.461/0.437/0.331（几乎不变），而载荷法 K_T 从 0.317 → 0.371 → 0.452 → 0.568 逐级上升（每翻倍 +15%~+22%）。机理：ε 越大，桨叶自身那一份诱导速度被涂抹得越远离采样点，叶片「看到」的来流越未被减速 → φ 偏小 → α 偏大 → 载荷偏高。这正是 ALM 的经典自诱导奇异问题，工程做法是 ε/Δx=1~2（Troldborg 2009）+ 采样点去自诱导，本节点尚未做后者。完整扫掠 ε/Δx=1,2,4,8 的增量依次为 -44.2%/-34.7%/-20.5%（相对 ε/Δx=8），增量随 ε 增大而非衰减，C2 判据（ε/Δx≥4 时变化<2%）判定为 **FAIL**；这说明在 D=20 lu 的格点预算下增大 ε 并不能得到网格无关解，反而单调偏离致动盘/BEMT 参考。
7. **滑移网格互裁未做**：仓内 blade-resolved 路径（`propeller_benchmark`，moving-wall bounce-back）受 `LOW_MACH_TIP_GATE=0.004` 约束，3 转需 ≳7.5×10^4 步，是 ALM（1.4×10^3 步）的 50 倍以上，且体素化弦长只有 ~10 格，5% 量级的互裁在本节点预算内不可达——如实标注未完成。

8. **对 `actuator_disk.py` 的两条审计发现**：(a) 符号——来流 +x 却把体积力指向 −x，等价于把桨当成动量汇（turbine 型）；K_T 虽由查表给定因而数值自洽，但流场方向与物理桨相反，自航/尾流耦合类算例会被系统性污染；(b) 参照数据——KP505 表（Fujisawa 2000）与 5 叶 P/D=0.95 的叶元解差 45%~80%，零推力 J 也对不上（见 §5.4）。建议后续节点复核并把该表改标 MOCK。

**结论（逐条对判据）**：

- **C1**：K_T 对标 B 系列标定族 4.65%（<5% 通过），但 K_Q 15.6% 不通过 → **部分 FAIL**；盲测族 K_T 7.1%/21.7% 说明单常数标定不能跨族外推。
- **C2**：ε/Δx=1,2,4,8 全扫，最粗两级增量 25.8%（判据要求 ≥4 时 <2%）→ **FAIL**，机理见 §5.6；这是本节点最重要的负面结论。
- **C3**：ALM 与致动盘 K_T 互差 38.6%、K_Q 互差 24.7%（判据 <5%）→ **FAIL**；两者都用轴向动量通量独立校核（闭合 <1%），故差异是真实模型差异，不是测量误差。
- **C4**：Prandtl F 单调降至叶尖、叶尖载荷比 0.638 → **PASS**。
- **C5**：高斯投影力守恒 3.1e-15、质量漂移 2.3e-05、轴向动量残差 0.46% → **PASS**（<1%）。
- **C6**：pytest 38 项全绿 → **PASS**。

**净结论**：交付的是可用的 ALM 载荷/涂抹/损失层（守恒性与 B 系列 K_T 精度有硬证据），以及一个明确否定性结论——在本节点格点预算（D=20 lu、弦长 ~8 格）下，ε 未收敛、ALM 相对致动盘高估 38%，**第三代模型尚不能替代致动盘做工程预报**；需要 (i) 采样去自诱导/多次松弛、(ii) D≥40 lu 的细网格、(iii) 更长的尾迹域才能把互差压到 5%。
