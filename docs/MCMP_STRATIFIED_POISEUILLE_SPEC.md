## 1. 决策（Decision）

**要不要**把"分层 Poiseuille 两相流量误差 <10%"这一验收判据判为通过，以及
**哪一套**（参考粘度规则 + 力格式 + 度量定义）才是该判据的合法载体。

本规格书的结果将写入两条互斥互证结论之一：

- **D1（判据成立）**：在*分层成立*的耦合档（见 §6 分层闸门）上，混合物流量误差
  <10%，判据 ① 通过；A 臂原判 FAIL 的根因是**参考解/度量设定错误**（非数值精度）。
- **D2（判据不成立）**：即使分层成立，误差仍 ≥10%，则 A 臂 FAIL 成立，
  且必须给出残余机理（力格式 / 界面滑移 / 粘度混合规则）。

## 2. 备选方案（Alternatives）

| 编号 | 方案 | 说明 |
|---|---|---|
| A0 | 现状（velocity-shift 力 + u_eq=self） | 上游 A 臂实现，历史 FAIL |
| A1 | **Guo 二阶力项**（`force_scheme="guo"`，本轮新增） | 平衡态用 u*=u+F/(2ρ)，显式源项带 (1−1/2τ) 因子 |
| A2 | 力修正 NEBB（半程反弹、壁面在 y=±1/2） | 只改壁面约定，不改界面物理 |
| A3 | 自由能压强张量力 | 只记录，不在本轮实现（超范围） |

方案 A1/A2 与 A0 **同几何、同初值、同驱动、同步数**，只改一个变量。

## 3. 假设（Hypothesis，可证伪）

- **H1（力格式）**：把 velocity-shift 换成 Guo 二阶力项，会使界面伪流速度下降，
  并使混合物流量误差向参考解收敛。
- **H2（设定/度量，更强）**：A 臂报的 20% 流量误差**不是力格式误差**，
  而是 (a) 该参数档（G₁₂=−1.0，ρ_heavy/light=0.7/0.3）根本不能维持分层，
  两相退化为均相混合物；(b) 逐组分流量 Q_σ=∫u_σdy 在迹组分（ρ_σ→0）处
  被力移速 1/ρ 放大，不是连续介质速度，不能作为守恒量比较。
- **零假设 H0**：误差为真实离散误差，随网格加密收敛且与度量定义无关。

证伪条件：若 G₁₂=−1.0 档实测 φ 反差 >0.5（仍分层）→ H2(a) 被证伪；
若 Q_mix 与 Q_σ 的误差量级一致 → H2(b) 被证伪。

## 4. 度量（Metrics，全部程序化注入，零手抄）

| 符号 | 定义 | 说明 |
|---|---|---|
| Q_σ | Σ_y ū_σ(y) | 逐组分体积流量（上游 A 臂口径，保留作对照） |
| Q_mix | Σ_y ū_mix(y)，u_mix=(ρ₁u₁+ρ₂u₂)/(ρ₁+ρ₂) | **主判据**：混合物体积流量 |
| Q_mix^low/up | 以 y=half 分层的 Q_mix 积分 | 分层内部分配 |
| φ_contrast | max(α)−min(α)（去壁行），α=(ρ₁−ρ_l)/(ρ_h−ρ_l) | **分层闸门** |
| y_int | α=0.5 线性插值交点 | 界面位置 |
| S | max|u_y,mix|（流体行） | 伪流强度 |
| u_max,mix | max|u_x,mix| | 参考速度尺度 |
| M_drift | Σρ_σ 相对初值漂移 | 质量守恒 |
| steady | 末 3 采样点 Q_tot 相对变化 <1e-3 | 稳态闸门 |
| trace_vel | ρ_σ<0.05 处 max|u_σ| | 迹组分速度放大诊断 |

参考解 `analytic.layered_poiseuille`：两层共动、界面上速度与剪应力连续、
每层 u″=−G/ν，壁面在**壁格中心**（H=ny−1，行 0 与 ny−1）。
两种粘度规则都报：

- `component`：ν_层 = 该层组分自身 ν_σ（QR 审计口径）；
- `mixture`：ν_层 = ρ₁ν₁+ρ₂ν₂（两相共动时动量方程的连续极限，模型可复现的唯一口径）。

## 5. 基线与对照（Baseline / control）

- **壁面约定基线**（`--mode walls`）：同一条 collision/stream/bounce-back 代码路径上
  跑单相 Poiseuille，τ=1.0 与 0.75，ny=25/33/49，比较 H=ny−1 与 H=ny−2 两种参考，
  用误差随 ny 的收敛性判定有效壁面（QR 结论 H=ny−1 由本席独立复现）。
- **对照臂 G₁₂=−1.0**：上游 A 臂参数，用于 H2 检验。
- **力格式对照**：同一格 shift vs guo。

## 6. 预注册阈值与停止规则（Thresholds / stopping rule）

| 判据 | 阈值 | 依据 |
|---|---|---|
| 窗① 分层闸门 | φ_contrast > 0.5 | 否则该格**不作两相计量**，只登记为"非两相"，不参与 ①② 判定 |
| 判据① 主 | \|err Q_mix\| < 10%（ny=25 与 ny=33 同时） | 任务锚点验收铁三角之一 |
| 判据① 辅 | \|err Q_mix^low\|, \|err Q_mix^up\| < 15% | 分层内分配（更严，不参与唯一判据） |
| 判据② 界面 | \|y_int − half\|/half < 5% | 上游已 PASS，复核 |
| 判据③ 伪流 | S / u_max,mix < 0.005 | 上游 FAIL，本轮只作改进量记录，不作验收 |
| 稳态闸门 | steady=True | 否则只报瞬态值，不判 PASS |
| 发散 | 任一场非有限 | 立即记 FAIL，不重试参数 |

**停止规则**：矩阵一次性跑完（ny=25/33/49 × shift/guo × G₁₂=−2.5，加 G₁₂=−1.0 对照臂），
**不看结果调整阈值**，不删除不利格。若 guo 未能改善，如实报 H1 证伪。

## 7. 变量与混杂因子（Variables / confounders）

- 控制变量：nx=4（x 周期）、初值 tanh-3、ρ 交换 0.7/0.3、G_x=5e-5、步数随 ny 定
  （20000/30000/45000）、CPU float32、单线程确定性。
- 改变变量：G₁₂（−1.0/−2.5）、force_scheme（shift/guo）、ny（25/33/49）。
- 混杂因子：**界面迁移**——干壁（wall ψ=0）使重相在底壁富集，界面相对 half 下沉
  约 0.4–0.5 格，与 ny 无关；对 Q 的影响 ~3%（ny=25），随 ny 减小。
  **迹组分速度放大**——1/ρ_σ 放大，只影响 Q_σ 口径，不影响 Q_mix（ρ_σ u_σ 有界）。
  **界面弥散厚度**（~3–5 格）——在 ny=25 时占通道 20%，随 ny 减小。
- 不控制的量：无（无随机性；初值确定）。

## 8. 重复与样本量（Repetition rationale）

全部为确定性计算，无随机数 ⇒ 每格单次运行即可重复到机器精度。
"样本"维度用**分辨率**（ny=25/33/49）替代：既提供离散误差趋势，
又提供互相独立的复算点。不接受"单点达标即通过"：判据① 要求 ny=25 与 33 同时达标。

## 12. 解释边界（Interpretation limits）

- 结论只对 D2Q9 + 线性伪势 + 所选 (τ₁,τ₂,ρ_h,ρ_l,G₁₂) 窗口成立，不外推到
  强分相（|G₁₂|>3）、大密度比（>10）或 3D。
- 单精度 float32；误差 <1e-6 的差异不作物理结论。
- 壁面/界面厚度效应随 ny 变化，ny=25 的 3% 量级几何不确定度已计入误差预算。
- 本规格书不裁定"自由能模型/NEBB 会不会更好"（A2/A3 未实现，登记为剩余嫌疑）。

## 13. 结果与结论（运行后追加，不改上文阈值）

全部数字来自 `artifacts/mcmp_stratified_poiseuille/analysis.json`
（`analyze.py` 由 24 条 run record 重算）+ `benchmarks/verified/mcmp_stratified_poiseuille/result.json`。
四条 conclusion：

### C1 壁面约定（控制实验，判据悬案的裁决）

同一条 collision/stream/bounce-back 路径跑单相 Poiseuille（`--mode walls`，ny=25/33/49，τ=1.0/0.75）：

| ny | τ | u_max 误差 H=ny−1 | Q 误差 H=ny−1 | u_max 误差 H=ny−2 | Q 误差 H=ny−2 |
|---|---|---|---|---|---|
| 25 | 1.00 | −8.23% | −12.17% | **−0.08%** | **−0.20%** |
| 25 | 0.75 | −8.35% | −12.25% | **−0.21%** | **−0.30%** |
| 33 | 1.00 | −6.20% | −9.20% | **−0.06%** | **−0.12%** |
| 33 | 0.75 | −6.27% | −9.24% | **−0.12%** | **−0.18%** |
| 49 | 1.00 | −4.15% | −6.18% | **−0.03%** | **−0.06%** |
| 49 | 0.75 | −4.16% | −6.18% | **−0.04%** | **−0.07%** |

有效壁面在**半程**（wall row 与首个流体行之间，H=ny−2）。
⇒ QR 报告 `docs/REPORT_qr_pilot_a.md` 的"H=ny−1（壁格中心）"结论被**证伪**；
⇒ 上游开发方使用的 H_eff=ny−2、h=half−0.5 约定**是对的**；
⇒ QR 据此给出的"正确参考下 20.2%/16.8% FAIL"因此不成立（其参考解偏大 10% 量级）。

### C2 参数档合法性（H2 成立）

G₁₂=−1.0（QR 审计参数）在 ny=25/33 一律**退化为均相混合物**（φ_contrast=0.14–0.15，界面不复存在），
两相分层 Poiseuille 在该档**不成立**；逐组分流量 Q_σ 在迹组分处被力移速 1/ρ_σ 放大，
不是连续介质通量。G₁₂=−2.5 才维持分层（φ_contrast=1.00）。⇒ 原 A 臂 FAIL 的度量与参数设定均不合法。

### C3 三嫌疑人定位

| 嫌疑人 | 处置 | 证据 |
|---|---|---|
| Porter/Guo 显式力项 | **必要但不充分**：单独换 guo 使误差**变差**（self/guo +12.5%~+16.1%，self/shift +8.5%~+10.6%，半程约定/组分粘度） | analysis.json `cp_*_self_*` |
| 力修正 NEBB | **无需改代码**：有效壁面已是半程；错的是参考解约定（见 C1） | `wall_calibration` |
| 自由能压强张量 | 未实现、未检验（残余嫌疑，登记） | — |
| （新定位）界面速度不连续 | **主误差源**：self 模式界面滑移，轻相层流量 +23~29%，总流量 +8.5~13.6% | `u_profile_mix` vs 参考 |

### C4 修复：Guo 力项 + 黏性加权速度耦合

`u_eq="viscous"` 在旧力格式下**发散**（与旧 claim `tkc:...:mcmp-viscous-velocity-coupling` 一致），
但换成 Guo 二阶力项后**稳定**且精确：

| 配置 | ny | 步数 | φ | 稳态 | err Q_mix（半程/组分） | err Q_mix（半程/混合） |
|---|---|---|---|---|---|---|
| self + shift（A0） | 25 | 20000 | 1.00 | ✓ | +8.5% | +11.4% |
| self + shift（A0） | 33 | 30000 | 1.00 | ✓ | +9.8% | +12.7% |
| self + guo | 25 | 20000 | 1.00 | ✓ | +12.5% | +15.5% |
| **viscous + guo** | 25 | 20000 | 1.00 | ✓ | **−2.7%** | **−0.1%** |
| **viscous + guo** | 33 | 109200 | 1.00 | ✓ | **−2.0%** | **+0.6%** |
| viscous + guo（hold-out） | 49 | 45000 | 1.00 | 未达稳态 | +1.2% | +3.9% |
| mixture + guo | 25 | 20000 | 1.00 | ✓ | −6.8% | −4.3% |
| mixture/viscous + shift | 25/33 | — | — | **发散** | — | — |

**判据① PASS**（|err|≤2.7%，两档分辨率、两种参考粘度口径、稳态+分层闸门全满足；hold-out 亦 <4%）。
分层内分配（辅判据 15%）在修复配置下**同时通过**（self 模式为 −18%~−25%，修复后 |err|<15%）。
伪流比 S/U 未改善（viscous+guo 3.0/1.7，self/shift 2.3/1.3）——**如实登记为代价，不是验收门**。
