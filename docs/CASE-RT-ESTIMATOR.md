# CASE-RT-INSTABILITY-ATWOOD — 前沿估计量的标定与修复（有限密度比支臂，工具层）

**结论先行**：本单修好了 m21884 判为「仪器失效」的那件仪器，并把失效的**真实机理**测出来了；
但锚点「A = 1/2 尖峰增长率」**仍然没有取得可判定值**，原因是换了第二个、更硬的物理障碍
（模型的界面厚度 `kδ = 0.88`，锐界面参考解在此不适用）。两条都如实记。

| 项 | 结论 | 证据 |
|---|---|---|

## ① 案例与问题

`CASE-RT-INSTABILITY-ATWOOD` 锚点问的是单模 Rayleigh–Taylor（重流体在上）在 **Atwood = 1/2** 时的
**尖峰增长率**，容差 <15 %，参考链为 Tryggvason et al. 2011 谱系（正文不可取得，参考值由闭式公式在代码内求值，
见 `ref/ref_lock.py`）。Boussinesq 支臂（`run_case.py`）在 `(φ,y)→(−φ,−y)` 下不变，尖峰与气泡是同一个前沿
（实测比 1.0004 vs 两流体预测 1.732），因此该支臂已在 m21799 判为线性支量 PASS（−10.1 %）、非线性支量不可测；
有限密度比支臂（SCMP，`tensorlbm.rayleigh_taylor_twofluid`）是为回答锚点而新增的。

m21884 在该支臂上做到「越过第 5 步中止」之后，用三段标定（播种回读 / 空动力对照 / 整箱压缩）否定了当时的前沿估计量，
留下三件必办事项；本单做的是其中第 2 件（**估计量先过标定**）。

几何/参数：一个波长 λ = 64 格（x 周期），4λ 高（探针）/6λ（物理试跑），τ = 1.0，ν = 1/6，
伪势 `ψ = 1 − exp(−ρ)`、`sc_g = 2.8`，`g = 2.0e−4`（格子），符号见 `layzer_velocity`。

## ② 做了什么

| 改动 | 内容 |
|---|---|
| `src/tensorlbm/rayleigh_taylor_twofluid.py` | 新增 `interface_profile_gradient`（逐列 `\|∂ρ/∂y\|` 锁定 + 抛物线亚格精化 + 梯度加权质心）与 `gradient_front_state`（输出键与 `column_front_state` 完全同构，可直接互换）；`run_scmp_rt(..., front_estimator="gradient")`（默认值仍是旧路径，向后兼容）|
| `benchmarks/case_pool/.../probe_estimator_calibration.py` | 一命令标定器：K1 播种回读（真实放松界面，振幅扫描 0.005–0.2λ，旧/新估计量并列）、K3 整箱压缩（ε = `gH/c²` = 0.154 及其 3 倍与反号）与贴壁稀薄层、K2 空动力对照、K4 共沸收敛、K5 物理试跑 |
| `benchmarks/case_pool/.../make_estimator_figure.py` | 由 JSON 程序化出图（零手抄）|
| `tests/test_rayleigh_taylor_twofluid.py` | 新增 6 例：回读精度、亚格分辨率地板、整箱压缩不动幅值、贴壁稀薄层不动前沿、诊断量自检、`front_estimator="gradient"` 通路 |

**机理（实测，不是猜的）**：`column_height` 是「守恒式质量矩」——把每列的重流体折算行数做和。对一次近似纯垂直位移，
被和的剖面整体平移，总和只经**端部截断项**变化，因此对位置几乎不敏感。K1 在真实放松界面上给出：
施加已知 `a₀ = 0.02λ`（±1.28 行）余弦后，逐列矩的**跨列变化仅 0.063 行**（= 施加信号的 2.4 %），
拟合幅值 **5.4e−5 λ**（误差 −99.7 %）。m21884 P4 独立记录的 −0.0021λ 与本测同源。
m21884 猜的「`clamp` 饱和」只是次要加重项：合成剖面里把体相抬到 `ρ_high` 之上 36 %，矩仍能跟上位移到 −0.9 %。
所以不是调 `rho_high` 能救的，必须换泛函——这就是新估计量的由来。

## ③ 结果（数字表，全部由脚本落盘）

**K1 播种回读**（真实放松界面；`err = 回读/施加 − 1`）

| a₀/λ | 0.005 | 0.010 | 0.020 | 0.050 | 0.100 | 0.200 |
|---|---|---|---|---|---|---|
| 旧 `column_height` | −96.9 % | −100.5 % | −99.7 % | −97.6 % | −91.4 % | −80.2 % |
| 新 `gradient` | +16.0 % | −3.1 % | **+0.55 %** | −0.40 % | +0.41 % | +0.09 % |

新估计量在 a₀ ≥ 0.01λ 满足 <5 % 判据；0.005λ（0.32 行）落在亚格分辨率地板上（≈2e−3 λ），已单列一个测试固定住。

**K3 整箱压缩与贴壁稀薄层**（施加 a₀ = 0.02λ）

| 扰动 | 旧幅值误差 | 新幅值误差 | 新共模 |
|---|---|---|---|
| ε = +0.154（= `gH/c²`）| −104.3 % | +0.56 % | +3.1e−5 λ |
| ε = +0.461 | −107.6 % | +2.92 % | +4.1e−4 λ |
| ε = −0.154 | −88.5 % | +0.55 % | −1.5e−4 λ |
| 贴壁层 ρ=0.05（第 1–4 行）| 幅值 −0.0037λ（被污染）| **+0.0201λ（+0.55 %）** | −5e−5 λ |

即：新估计量在高斯共模（解析已知量级 15 %、乃至 46 % 的密度斜坡）与贴壁稀薄层下都不动幅值——
m21884 L3 里让 `φ = 0` 穿越估计量多出假穿越的两个污染源，在此都不再进入判据。

**界面几何（新发现，决定参考值可用性）**：放松后界面 10–90 % 宽度 **9 行 = 0.141λ**，
`kδ = 2π·9/64 = 0.88`；实测体相 ρ ≈ 0.347 / 1.105，共沸标定目标 0.255 / 1.208（体相被标定窗**夹在内侧**，
这正是旧矩失效的参数区，也说明共沸标定本身仍偏）。锐界面 Layzer–Goncharov 参考要求 `kδ ≪ 0.2`，
本模型差 4.4 倍 → **即使仪器完美，用 <15 % 门去对锐界面解析解判分也不成立**。

## ⑤ 注意点

| 编号 | 内容 |
|---|---|
| N1 | `column_height` 的敏感度实际上来自 `clamp` 截断边界随界面移动；标定把体相夹在 `(ρ_l, ρ_h)` 内时截断消失、敏感度随之消失。它的「有时能用」是伪迹，不可用于门判 |
| N2 | 新估计量的分辨率地板 ≈ 2e−3 λ（亚格插值 + 逐列锁定抖动）；线性增长率拟合窗 `a ∈ [0.03, 0.08]λ` 远高于地板，可用 |
| N3 | **`kδ = 0.88` 是本支臂的硬边界**：要回到锐界面区，必须把界面压薄到 `kδ ≲ 0.2`（界面 ≤ 2 行）或减小 `sc_g`/提高 EOS 锐度——SCMP 在本参数区做不到（L5 的寄生电流地板亦同源）|
| N4 | 共沸标定不收敛（A 随箱高/步数 0.505↔0.652，m21884 L4）在本单仍未解决；K4 已写好（双箱双步数 + `u_s(A)` 敏感度）但作业 cj3897 仍在队列，未取回 |
| N5 | 本单未改动物理结论，也未关闭总账条目；不覆盖任何既有 honest FAIL |
