# Mission 26 补报：SDAA Sweep — laplace_pr_eos 高密度比液滴 Laplace 基准

> **补报性质**：原 mission 26 已成功交付（SDAA sweep 全 6 门 PASS），但缺论文级进展报告。本报告按 owner 常设指令补发。

---

## 1. 案例介绍

### 1.1 物理背景

Peng-Robinson (PR) 状态方程伪势单组分（SCMP）多相格兹曼模型在高密度比（ρ_l/ρ_v ≈ 400–556）条件下演化周期域圆形液滴至稳态，验证 Laplace 定律 ΔP = σ/R_eff 及表面张力 σ 的网格收敛性。

### 1.2 参数表

| 参数 | 值 |
|------|-----|
| EOS | Peng-Robinson（YS2006: a=2/49, b=2/21, R=1） |
| T_r / T | 0.55 / 0.0401055 |
| G / τ | +1 / 1.0 |
| Forcing | EDM（精确差分法） |
| 伪势 ψ | 修正符号：ψ² = 2(ρcs² − p_EOS)/cs² |
| 格子 | D2Q9, float32, 周期边界 |
| 共存密度 | ρ_l=7.99784, ρ_v=0.06491 |
| 网格档 L | {128, 192, 256} |
| 半径（主档） | R = {12,16,20,24}×L/128 |
| max_steps | 15000（原基准 40000） |

### 1.3 设备

| 字段 | 值 |
|------|-----|
| 设备 | SDAA (/dev/tcaicard23) |
| PyTorch | 2.7.1 |
| Triton | TRITON_INTERPRET=1（源码确认无 triton kernel） |

---

## 2. 方法

1. 独立脚本 `scripts/sdaa_sweep_laplace_pr_eos.py`，不改业务代码
2. 张量放 sdaa 设备
3. 3 档网格 × 4 半径 = 12 算例
4. ΔP vs 1/R_eff LSQ 线性拟合提取 σ
5. 六门判决：clause_i（残差≤3%）、clause_ii（|Δσ|非增）、稳定性、质量守恒、ψ定义域、sim_ratio

## 5. 注意点

1. **步数限制**：max_steps=15000（原基准 40000），L=256 大液滴未达严格收敛，但 ΔP 末段平均有效
2. **L=256 偏差**：−2.41%，可归因于步数不足，非算法错误
3. **Triton 绕行**：无影响（源码确认无 triton kernel）
4. **设备争用**：总壁钟 1500s 含并发争用开销
