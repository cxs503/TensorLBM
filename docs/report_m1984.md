## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 运动方程

内核为无量纲标准 MMG 模型（RK4 定步长；dt = 0.4 / 0.2 / 0.1 s 三档结果差 < 1e-3，离散化已收敛）：

```
(m'+m_x')u̇' - (m'+m_y')v'r' = X' = X_H' + X_P' + X_R'
(m'+m_y')v̇' + (m'+m_x')u'r' = Y' = Y_H' + Y_R'
(I_zz'+J_zz')ṙ'                = N' = N_H' + N_R'
```

### 五条缺陷的处置

**D1 舵来流加速因子**：旧转写 `1 + 8T'd'/(πD'⁴n'²)` 在代数上恒等于 `1 + 16K_T/π`，
缺的是文献式的 `1/J²` 标度；而文献式 `1 + 8K_T/(πJ²)` 直译在 u′→0 时发散。

修复采用**代数等价、数值稳定**的写法：

```python
u_R'² = ε² [ (1-w_P)²u'² + η · 8 K_T n'² D'² / π ]
```

u′→0 时退化为螺旋桨射流 `ε n' D' sqrt(8K_T/π)`，不发散、不变号；`η` 为**舵-射流加权**
（舵位于桨后 0.5–0.7 D，并非完全浸在远尾流中，故射流项需加权）。

**D2 纵荡方程**：常数 `R0` → `R0·u'²`，恢复「降速 → 阻力下降」的回正通道。

**D3 舵失速限幅**：有效攻角钳在 |α_R| ≤ 35°（`alpha_R` 与 `alpha_eff` 同时回传，越界打 `stalled` 标记）。

**D4 端点指标口径**：`T_d = |y(ψ=180°)|`（不乘 2），与 `backend/methods/manoeuvring/manoeuvres.py`
同一口径 —— 本单用合成定常圆把两套实现交叉比对，adv/tr/T_d 差 < 1e-3；并在响应中回传
`definition` / `reference` / `developed_ratio = |y(180°)|/(2R_ss)`。

**D5 Z 形初值**：以「自航点转速 + 压舵角」的定常直航起算；KVLCC2 对称系数集下压舵角解析为 0，
可测判据是 200 s 自由直航的速度漂移：实测 **0.000%**（v′、r′ 残量 < 1e-6）。

## ⑤ 注意点（坑与局限）

### 5.1 文献式不可直接替换

η=1（即 m1979 的文献量级）时模型在 δ=35° 下**失去纵荡平衡** ——
`V4_stable_full_jet` 实跑 u_ss = −0.177，u 在 ψ≈144° 后转负（与 m1979「u'<0、船被倒退」一致）；
`V3_literature_literal` 更直接数值发散。

**机制**：射流项 ∝ K_T n′²D′² 与船速无关，定转速下舵阻力 (1−t_R)F_N sinδ ≈ 8.6 MN 超过可用推力上限
（≈8.7 MN），平衡点被推出正速域。这也是「稳定式必须与 D2/D3 同批改」的真实原因：单靠 D1 只会换一种方式发散。

### 5.2 η 是标定参数（不是第一性推导）

由五项判据「带内归一化误差最小」标定（η=0.09），物理解释是舵的部分射流浸没，但本仓未做模型试验标定，
**不具备唯一性**：`V1_resistance_only`（保留 J 无关来流、只修 D2）同样得 5/6 入带。
m1979 的「参数不可唯一辨识」在本仓复现。

### 5.3 回转带与 Z 形带不可同时满足（本单最重要的负面结论）

η 从 0.09 增到 1.0，adv 3.45→1.69、OS1 67.5°→17.9°，全部单调同向。OS ≤ 18° 需要 η≈1（adv 1.69L ≪ 2.70L 下限）；
adv/tr/T_d/D_ss 入带需要 η ≤ 0.09（OS ≥ 60°）。两族判据无交集，且与 m1979「ITTC 初值下 OS1≈55°」互证。

已写成回归 `test_known_frontier_turning_vs_zigzag`，防止后续被静默「修好」。

### 5.4 端点接线受白名单限制

本单 `EDIT_WHITELIST: src/, tests/, docs/`，而平台内核在 `backend/api/`。
按机器门规则未越界改 `backend/`；接线补丁见 `docs/verifier/patches/mmg_kernel_wiring.patch`，
需人工裁决后合入。因此**端点实跑未做**（8001/8002 亦不可达）。
