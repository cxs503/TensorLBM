## 1. 案例介绍（物理背景／几何／参数）

浮冰盖把自由面重力波改成**弯曲-重力波**（flexural-gravity wave）：冰盖的抗弯刚度 `D = E h_i^3 / (12 (1-nu^2))` 给自由面条件增加了一个四阶空间导数项，使高频（短波）分量获得额外回复力。本节点验证的频散关系（节点规定形式，**无质量薄板极限**）：

```
omega^2 = (g k + D k^5 / rho_w) * tanh(k h)
c_p = omega / k,    c_g = d omega / d k
```

物理意义：`g k` 是重力回复项，`D k^5 / rho_w` 是弹性弯曲回复项；两者的比 `(D/rho_w) k^4 / g` 决定「重力区 → 弯曲区」的过渡波数。本节点的 10 档波数刻意落在**弯曲区**（`k = 0.209 … 0.586 rad/m`，`lambda = 30 … 10.7 m`），这是冰盖对波浪影响最大的频段；长波（`lambda > 100 m`）在 1 m 冰厚下弹性项只占 <1 %，对冰盖识别不敏感。

|---|---|---|
| 重力加速度 g | 9.81 m/s^2 | 常量 |

## 2. 怎么做的（方法／流程／工具链）

**(a) 解析臂。** `analytic.dispersion_omega / phase_speed / group_speed`：群速度用解析导数而不是差分——令 `N = gk + Dk^5/rho_w`、`M = 1 + m k`、`Q = N/M`、`F = Q tanh(kh)`，则 `dF/dk = [(N'M - NM')/M^2] tanh(kh) + Q h sech^2(kh)`、`c_g = dF/dk / (2 omega)`。同一函数支持**质量加载**版本 `omega^2 = (gk + Dk^5/rho_w)/(1+mk) tanh(kh)`（`m = rho_i h_i/rho_w`），用来量化「无质量薄板」这一规定形式的适用边界（§5）。

**(b) 数值臂（数值水槽）。** 线性化势流 + 弹性板自由面条件：

```
Laplace(phi) = 0            -h < z < 0, x 周期
dphi/dz = 0                 z = -h
phi = phi_s(x,t)            z = 0
eta_t = dphi/dz             z = 0        (运动学)
phi_t = -g eta - (D/rho_w) eta_xxxx      z = 0   (动力学, 无质量板)
```

离散：水平方向 4 阶周期中心差分（`[-1,16,-30,16,-1]/12dx^2`），垂直方向 2 阶，底部 Neumann 镜像虚节点，表面 `dphi/dz` 用 4 阶单侧差分。每一步的椭圆子问题**精确求解**（无迭代误差）：矩阵在 x 方向循环（circulant），故用 DFT 对角化后退化为 `nx` 个独立的垂直三对角系统（Thomas），与整体系稀疏 LU 解**逐位相同**（两条解路径互裁：最大相对差 1.24e-13，见判据 C4）。时间推进为交错蛙跳（`eta` 在半步、`phi_s` 在整步），二阶精度。

**(c) 频率提取。** 单一波数初值 `eta = a cos(kx + 0.37)`、`phi_s = 0`（与驻波本征态相容），取 6 个探针中信号最强者记录 `eta(t)`；对固定 omega 的模型 `a cos(omega t) + b sin(omega t) + c` 关于 `(a,b,c)` 线性，用正规方程把它们消去，再对 omega 做「粗扫 + 黄金分割」最小化残差。**omega 是自由参数，不锚定解析值**（这是本节点与「把理论频率写死」类测量的根本区别）。

**(d) 误差预算。** 同时给出离散系统的**精确本征频率** `omega_N = sqrt(s_d(kappa) (g + D kappa^4/rho_w))`（`s_d` = 离散 Dirichlet-to-Neumann 符号），于是误差可分解为空间（`omega_N/omega_analytic - 1`）与时间（`omega/omega_N - 1`）两部分，避免用「总误差小」掩盖机制。

**(e) 群速度两条独立路径。** ①对测得的 `omega(k)` 曲线做中心差分（并剔除 `c_p` 极小点附近 `c_g → 0` 的病态单元，剔除规则 `|c_g| > 0.2 * max|c_g| for that thickness (c_g -> 0 at the c_p minimum)`，剔除 2 个单元）；②**波包追踪**：长周期域内高斯包络窄带波包，用 Hilbert 包络的右行部分能量质心随时间漂移求斜率。

**(f) 工具链。** `python -m tensorlbm.wave_ice_dispersion.campaign --out artifacts/p338w3_n05_wave_ice_dispersion`；报告 JSON 由程序写出，本文档由 `scripts/p338w3_n05_report.py` 从 JSON 渲染（零手抄）；图由 matplotlib 在同一进程内生成。

## 5. 注意点（踩过的坑／局限／适用范围）

1. **动力学边界条件符号**：`phi_t = -g eta - (D/rho_w) eta_xxxx`。写成 `+` 会让所有波数指数发散（本节点第一版即踩此坑，表现为 NaN 溢出）；可用 `D → 0` 退化自由面作为符号自检（NC1）。

2. **显式时间推进对弯曲项是刚性的**：稳定性要求 `dt < 2/omega_max(离散)`，`omega_max ~ sqrt(D/rho_w) k_Nyq^2`，网格越细越刚；1 m 冰在 dx≈1 m 网格上使 `dt ~ 5e-4 s`，长波 20 个周期需 10^5–10^6 步。生产求解器**必须**对弯曲项做隐式/谱处理（本模块用循环对角化得到椭圆算子精确解，时间推进仍受 ω dt < 2 约束，但每步成本降到 O(nx log nx)）。

3. **垂直表面导数是误差主项之一**：2 阶单侧差分在 `kappa dz ~ 0.25` 时带 1 % 量级偏差；换 4 阶单侧差分后同网格降到 0.4 %。垂直方向加密只能线性改善（离散特征衰减率误差），所以生产配置取 nz = 48 并把误差预算公开。

4. **`c_g → 0` 处的群速度不可比**：`c_p(k)` 有极小点（质量加载时即临界速度 c_min），其邻域 `d omega/dk ≈ 0`，任何有限差分/相对误差都被放大。本节点按 `|c_g| > 0.2 * max|c_g| for that thickness (c_g -> 0 at the c_p minimum)` 剔除 2 个单元并显式记录。

5. **无质量薄板只是薄板极限**（本节点最重要的适用边界）：规定形式不含冰的惯性项，`D ∝ h_i^3` 使 `omega ∝ h_i^{3/2}` 发散。加入质量加载 `m = rho_i h_i/rho_w` 后 `omega^2 = (gk + Dk^5/rho_w)/(1+mk) tanh(kh)`，发散指数降到 1、整条曲线下移，并把最小相速度 `c_min` 移位（`c_min` 之下无稳态波，正是冰区船舶临界速度峰值的来源；本节点参数下无质量分支 `c_min = 15.858` m/s，质量加载分支 `c_min = 15.499` m/s）。因此 NC2 只是**代数自洽性**负控，不能当作厚冰物理判据；冰区工程谱关系应使用质量加载形式（或直接耦合板动力学）。

6. **线性势流、无粘无旋、无破碎**：数值水槽是线性化模型，因此它验证的是**离散格式 + 提取算子**的频散保真度，不能反映有限振幅、冰盖开裂、边界层衰减等非线性机制。振幅取 0.01 m（`a k << 1`）。

7. **周期域 + 单一波数初值**：驻波初值（`eta_t = 0`）保证只激发一个频散支；波包追踪必须等左右两支分离（`t > 3 sigma/c_g`）后计时，否则质心被污染（本节点第二版修）。

## 6. 误差判定（逐项 vs 基准）

| 判据 | 含义 | 实测 | 阈值 | 结论 |
|---|---|---|---|---|
| C1 | 5x10 矩阵相速度最大相对误差 | +0.4409 % | 3 % | PASS |
| C2 | 群速度：差分保真度 / 波包 vs 解析 | +0.952 % / +1.090 % | 2 % / 10 % | PASS |
| C3 | 网格收敛观测阶（水平 / 垂直） | 3.34 / 1.82 | > 1.5 | PASS |
| C4 | 两条解路径末态场最大相对差 | 1.2e-13 | 1e-8 | PASS |
| NC1 | h_i→0 退化为自由面 | +0.13693 % | 1 % | PASS |
| NC2 | h_i→∞ log-log 斜率 | 1.49973 | 1.5 ± 0.02 | PASS |
| NC3 | k→0 趋于 sqrt(gh) | +0.00667 % | 1 % | PASS |
| NC4 | D+10 % 可检测性 | +4.88 % (ratio>3: 50/50) | 存在 ratio > 3 | PASS |

**是否 < 3 %？** 相速度：是——全矩阵最大 +0.4409 %，中位数 +0.1148 %，比 3 % 验收线好约 7 倍。群速度：波包追踪 +1.090 % （与离散格式自身 c_g 的差 +0.0224 %）< 3 %；差分估计器对平滑解析 c_g 的偏差最大 +16.267 %，但同法作用于解析样本即为 +16.334 %，故数值保真度 +0.952 % < 3 %。**结论：相速度与群速度两个关键量均 < 3 %；差分估计器本身的截断偏差（最大 16 %）如实单列，不计入数值误差。**
