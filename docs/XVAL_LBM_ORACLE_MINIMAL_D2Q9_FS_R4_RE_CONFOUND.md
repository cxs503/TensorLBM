# XVAL-LBM-ORACLE-MINIMAL-D2Q9-FS · R4：把「分辨率阶梯」还原成「雷诺数扫描」

**锚点** `XVAL-LBM-ORACLE-MINIMAL-D2Q9-FS`（Maarten-vd-Sande/lbm 的 oracle-minimal-d2q9-fs 做法）· 仓 `TensorLBM` · 轮次 R4
**承接** R1（m18073，8 runs）→ R2（m20893，阶梯/τ 扫描声明但仅标量存活）→ R3（m21017，交付形态+指标口径+红测试+基准登记）
**本轮性质**：验证欠账（把已合并的自由面 D2Q9 求解器对文献基点复核）+ 前序结论的**否证性复核**。不新增求解器功能。

## ① 案例介绍

二维矩形水柱瞬时坍塌，Körner/Thürey 自由面 D2Q9 + BGK，四边固壁、无表面张力、无出入口。

| 参数 | 值 | 说明 |
|---|---|---|
| 水柱宽 `a` | 16 / 24 / 32 / 48 / 64 | 阶梯（本轮不变） |
| 初始高 `h0` | `2a` | 纵横比 2（Martin & Moyce 几何） |
| 域 | `nx=5a`, `ny=3a` | 顶部 1a 气相裕量；**下游壁距初始液块右缘仅 4a** |
| 重力（格子） | `g = 5e-5` | 全阶梯同一值 |
| 松弛时间 | `τ = 1`（阶梯）/ `0.6…1.4`（a=32 扫描） | `ν=(τ−1/2)/3` |
| 窗口 | `T∈[0.5,4.0]`，ΔT=0.25 | `T=t√(g/h0)`, `Z=x_front/a` |
| 基准 | Martin & Moyce (1952) 17 点数字化前锋 | [Martin–Moyce digitization](../src/tensorlbm/verification/refdata/martin_moyce_1952_dam_break.json) |
| 验收 | 窗口内 `max|rel err| ≤ 15 %`（owner 标准），目标 3 % | 台账 `XVAL-LBM-ORACLE-MINIMAL-D2Q9-FS` |

## ② 怎么做的（本轮的方法与关键设置）

1. **先查量纲一致性，而不是先加网格**：阶梯固定在**格子单位**的 `τ`（⇒ `ν` 固定），而深度 `h0=2a`
   与重力波速 `U0=√(g h0)` 都随 `a` 增长，于是
   `Re = U0·h0/ν ∝ a^{3/2}`。**每一级阶梯都是不同的物理问题**（Re = 7.68 / 14.11 / 21.72 / 39.91 / 61.44）。
   R2/R3 把 `E(a)` 的非单调当作离散误差并做 Richardson 外推，前提不成立。
2. **符号化误差**：R2/R3 只报 `max|err|`，丢掉符号。本轮逐 T 报带符号误差，才能区分「前锋滞后」与「前锋超前」。
3. **壁面污染度量**：`wall clearance = (nx−2−x_front)/a`。`a=48/64` 在 `T=4` 时离下游壁仅 0.77a / 0.25a，
   晚窗数值不可无条件当作物理结果。
4. **Re 匹配阶梯（决定性实验）**：由 `τ = 0.5 + 3ν`、`ν = √(g h0)·h0/Re₀` 反解，使 `a=24/48` 与参考级
   `a=32, τ=1`（`Re₀=21.7223`）同 Re。若三者 `E` 平坦 ⇒ 残余误差是 Re 失配（比较口径问题）而非离散；
   若仍随 `a` 变化 ⇒ 真为离散。已递交 `cj3218`（另含 τ 扫描复算取回符号序列、`a=64, nx=8a` 域宽对照）。
5. **顺带修的真实缺陷**：`cj3126`（R3 递交的 τ 扫描）跑完 8 个 run 后在**分析阶段崩溃**
   （`TypeError: unsupported format string passed to NoneType.__format__`，`resolution_study.py:708`），
   逐 run 工件随之丢失。本轮加 `None` 守卫（打印 `n/a`）、把域宽写进 label、使 `analyze()` 排除非默认域宽，
   并为其补回归测试（`tests/test_xval_oracle_minimal_d2q9_fs_r4.py`）。
6. 工件链路：`runs_r3/*.json`（逐 run 全 T 序列，来自 `cj3125` 的 fetch 包）→ `re_confound.py` →
   `artifacts/re_analysis.json` + `artifacts/re_numbers.md` + `figures/fig_r4_re_confound.png`。
   `cj3126` 只留下标量（`artifacts/recovered_cj3126_tau_sweep.json`，含 provenance 与"无符号"声明）。

**核心结果（新）**：同一「分辨率阶梯」上误差**变号**——低 Re 前锋**滞后**（Re=7.68 时 −27.4 %），高 Re 前锋**超前**
（Re=61.4 时 +42.2 %）；带符号晚窗误差的零交点 **Re\* ≈ 18.9**（线性内插于 Re=14.11/21.72 之间，−8.44 %→+4.93 %）。
`cj3126` 的 τ 扫描标量（仅幅值）与之一致：a=32 上 Re=108.6（τ=0.6）→ 65.1 %、Re=36.2（τ=0.8）→ 24.8 %、
Re=21.7 → 14.7 %、Re=15.5（τ=1.2）→ 16.3 %、Re=12.1（τ=1.4）→ 17.1 %，即在 Re≈20 附近取到 |err| 极小，
向两侧单调恶化——**阶梯与 τ 扫描落在同一条 E(Re) 曲线上**，这正是 Re 失配（而非网格分辨率）的签名。

## ④ 误差判定（逐项，显式回答）

| 关键量 | 值 | <15 %？ | <3 %？ |
|---|---|---|---|
| `a=32, τ=1`（R2/R3 的"最佳级"）`Z_sub` | 14.66 % | 是（勉强） | **否** |
| 同上 `Z_cell`（R3 报告值） | 13.81 % | 是 | 否 |
| `a=16` / `a=24` / `a=48` / `a=64` | 27.39 / 15.88 / 27.37 / 42.19 % | **否** | 否 |
| 5 级中满足 15 % 的级数 | 1 / 5 | — | — |
| 质量账漂移（液量守恒） | ≤ 0.10 %（各处） | 是（门 1 %） | — |
| `u_max`（马赫） | 0.238–0.259（Ma ≤ 0.26/√3） | 是（门 0.5） | — |
| H1（`E(a)→E_inf <3 %`） | **被否证**（阶梯非收敛序列，且 E 变号） | — | **否** |

**诚实结论**：锚点验收（<15 %）在 5 级阶梯里只有 1 级勉强满足，**关键量没有任何一项 <3 %**。
但这不等于"求解器错了"：本轮证明该阶段不能作为收敛序列使用——固定 `τ` 时 `Re ∝ a^{3/2}`，
误差是 Re 的强函数且穿过零点。**新的可证伪判据**（已写入 `plan_re()` 的 docstring 与测试）：
在 Re 匹配的 `a=24/32/48` 三件套上，若 `max|err|` 的 `a` 展布 ≤ 3 个百分点，则残余误差归因于 Re 失配，
锚点应以「Re 匹配下 ≤15 %」而非「a→∞ 外推 ≤3 %」验收；该三件套 + 域宽对照 `cj3218` 已递交（排队中），
数据回填后 `re_confound.py` 会自动产出 `fixed_re_trio` / `width_control` 两节，无需改口径。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **壁面污染（本轮新发现的隐患）**：域宽只有 5a，而 `a=48/64` 的前锋在 `T=4` 距下游壁 0.77a/0.25a。
   `a=64` 的 +42 % 晚窗误差**不能**排除反射波贡献；`cj3218` 的 `a=64, nx=8a` 对照若把 +42 % 显著拉低，
   则 R2 的"48/64 回升"结论须改写为域宽不足。这是本轮**未闭环**的部分。
2. **`cj3126` 数据抢救有边界**：只剩标量（无符号、无逐 T），单独不能支撑任何符号性结论；
   文件头已写 provenance 与 `sign_available: false`，复算 `cj3218` 到位后以其为准。
3. **OSS port 在 a=48 发散**：`u_max=0.8165`（Ma≈1.6）、液量漂移 **609.8 %**、79.4 % 前锋误差 ——
   R2 的 port 阶梯 `a=48` 该级结果无效（不是"误差大"，是**数值发散**），引用时必须标注。
4. **指标口径**：主指标用亚格子趾 `f=0.05`；`Z_cell` 比它高约 0.3–1.0 %（a=32 时 13.81 vs 14.66），
   两者都未越 15 % 门，但跨轮次比较必须同口径。
5. **Rebuttal 适用范围**：结论仅对「格子重力固定 + 自由面 BGK + 固态四壁」的这套设置成立；
   Re 匹配手段会改变 `τ`，从而改变边界层分辨率，故 Re 匹配三件套不是"纯网格"实验（这也是为什么要在
   同 Re 下同时看 `a` 展布与壁距，而不是只报一个数字）。
