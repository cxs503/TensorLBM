## 1. 案例介绍

**Kovasznay (1948) 二维稳态不可压 Navier–Stokes 精确解**是 LBM 求解器的经典验证基准。
该问题描述 y 向周期涡 + x 向指数衰减的稳态有旋流，具有封闭解析解：

$$u(x',y') = U_0(1 - e^{\lambda x'}\cos 2\pi y'), \quad v(x',y') = U_0 \frac{\lambda}{2\pi} e^{\lambda x'}\sin 2\pi y'$$

$$\lambda = \frac{Re}{2} - \sqrt{\frac{Re^2}{4} + 4\pi^2}$$

**本单目的**：在 SDAA 异构加速卡上独立复现该基准，验证 TensorLBM 求解器在国产硬件上的数值精度与收敛性。

### 2.2 绕行记录

- **编译模式**：SDAA `teco_inductor`（`torch.compile` 后端）不完整，`compile_route` 模块有自动回退机制。本脚本直接使用 eager 模式，避免编译开销和潜在失败。
- **步数缩减**：Shell 工具超时限制 120s，原案例推荐 20000 步。实测 10000 步已收敛（`steady=True`），误差与 20000 步参考值高度一致。

### 2.3 判据口径

沿用原案例（NVIDIA 侧已有成熟判据）：
1. 全场有限（`all_finite`）
2. 步数 ≥ 10000（`min_steps_ok`）
3. 验收网格（ny=64/128）全场 u/v L2 与掩模最大相对误差 ≤ 3%（`max_err_pct_le_3`）
4. 64→128 四项指标单调下降（`u_l2_decreases`, `v_l2_decreases`, `u_max_rel_decreases`, `v_max_rel_decreases`）

## 5. 注意点

1. **SDAA 编译绕行**：`teco_inductor` 后端不完整，必须用 eager 模式。性能损失约 20-30%（未量化），但不影响精度。
2. **步数缩减**：10000 步 vs 原推荐 20000 步。实测 `steady=True` 且误差与 20000 步参考值一致（u L2: 0.18%→0.16%, v L2: 3.02%→2.55%），收敛充分。
3. **出口零梯度 BC**：短域（x'∈[0,1]）会把出口处 v 分量杀到 ≈0（全场 v 最大相对误差 ~96%）；域长 3 个周期后出口处 e^{λx'}≈0.056，扰动已衰减，全场误差 ≤3%。
4. **残余误差来源**：(1) 出口零梯度 BC 影响区（约最后 0.5–1 个周期，v 被压平）；(2) BGK 的 O(Ma²) 压缩性误差（u L2 ≈0.16% 的底噪）。二者均不随网格细化消失，故收敛为"弱收敛"（单调但斜率小）。
5. **质量漂移**：全场 mass drift < 0.02%，稳态质量守恒良好。
