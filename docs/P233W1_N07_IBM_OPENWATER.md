## ① 案例介绍

冰-桨相互作用的 Phase 0 目标是先回答一个可判定的问题：**本项目自研的浸入边界法（IBM）能否
在格点尺度上定量传递水动力，从而支撑后续"螺旋桨-碎冰"流固耦合？** 因此本节点做两件事：

1. **格子玻尔兹曼（D3Q19）+ Peskin 四点 δ 核直接强迫型 IBM**，驱动一个**参数化旋转桨叶**，
   扫进速系数 `J = U/(nD)`，给出敞水曲线 `K_T(J)`、`K_Q(J)`、`η_0(J)`，与 KP505 敞水试验
   资料对比；
2. 用**二维圆柱绕流阻力**（`Re = 20…200`）作为 IBM 力传递精度的"硬门"，并做**闭箱动量守恒审计**。

|---|---|---|

| 毂径比 `D_hub/D` | 0.18 | 毂以 Eulerian mask 实现，随转子刚性旋转 |

## ② 怎么做的

**数值骨架**（`src/tensorlbm/ibm_openwater.py`）

1. **D3Q19 MRT-LBM**（`solver3d.collide_mrt3d` + `stream3d`），所有量 `float32/float64` 可选；
   网格布局 `(nz,ny,nx)`，`x`（流向/桨轴）为最后一维。
2. **IBM 直接强迫（Peskin 4 点核）**：标记点力 `f_k` 经稀疏模板
   （`ibm_force_transfer.build_stencil`，插值/散布互为伴随）投到 Euler 场，再用
   `body_source_3d` 注入——其**一阶矩恰为力本身**（无 Guo `1−1/(2τ)` 衰减），因此
   (a) 转子反力 `= −Σ_k f_k` 是恒等式，(b) 单遍直接强迫（`n_correctors=0`）自洽。
3. **三类标记力模型**（`marker_forcing`）：`noslip`（经典全速度差）／`slip`（只锁法向不可穿透）／
   `slip_friction`（slip + 平板摩阻闭合 `F_t = ½C_f A |w_t| w_t`，`C_f = 1.328/√Re_c`）。
   生产算例用 `slip_friction`，理由见 ⑤。
4. **参数化叶片标记面**（`PropellerGeometry` / `blade_sheet`）：每站弦长按椭圆律、弦向按
   `spacing=0.9` 格布点，每步按 `Ω·Δt` 刚性旋转并重建模板；同时返回**逐点单位法向** `n` 与
   **标记面元** `A`（供摩阻闭合使用）。
5. **轷以 Eulerian mask 实现**并随转子刚性旋转（目标速度 `Ω×r`）。
6. **系数换算**：`K_T = T/(ρn²D⁴)`、`K_Q = Q/(ρn²D⁵)`、`η_0 = J·K_T/(2πK_Q)`；
   `Q` 取流体获得力矩沿转轴分量（取向使 `K_Q>0`、`P=2πnQ>0`）。
7. **审计**：每步记录 `|注入流体动量 − (桨叶反力 + 毂反力)|`（机器精度 1e-16）；
   另有闭箱（周期、无进出流）动量守恒审计 `momentum_balance_audit`。

**执行方式**：控制面共享、负载 160–520/128 核，因此每个点写成独立进程 + JSON 产物
（`scripts/p233w1_n07_run_points.py`），聚合脚本把逐点 JSON 合成曲线/网格收敛产物
（`--kind aggregate`）；报告中所有数字均由 `report.json` 读回，无手抄。

**先做的定标（关键）**：二维单剖面试验（平板在相对流中，IBM + `slip_friction`）
在 `Re_c≈1600`、攻角 8° 给出 `C_l = 0.84`，与薄翼理论 `2πα = 0.877` 相差 4 %——
证明"法向不可穿透 + 摩阻闭合"的 IBM 在**有环量升力**的构型上方向与量级都正确，
这条定标同时被用来判定 3D 桨的旋转手性（见 ⑤ 陷阱 1、2）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **旋转手性陷阱**：把"桨叶弦向 = 螺线切向"写对之后，还要确认相对流从**前缘**进入。
   我们用二维单剖面试验（`β=23.4°`、`φ=12.8°`）直接量力向，得到了正确解：**`ω>0`（本几何）**
   给出正推力；`ω<0` 给出负推力。仅靠纸面符号推导在本问题上极易出错（本人第一版推翻过两次）。
2. **Eulerian 内部掩模会把阻力算反**：把圆柱**内部**流体每步强行拉到 0 并计入"机体受力"，
   会引入一个非物理的动量汇，其反力量级 O(1)，把 `C_D` 的符号都翻掉（实测 `C_D=−0.36`）。
   正确做法：封闭标记壳已经保证不可穿透，**内部不再强迫**；掩模只在毂处用于阻塞质量通量，
   其力**不计入** `K_T`（产物中单列 `KT_hub_mask`）。
3. **零厚度单层叶片的"全 no-slip"是摩阻灾难**：`noslip` 模式下 4 点核把动量边界层抹厚到
   ~1.5 格（≈ 弦长的 25 %），摩阻扭矩被放大一个量级（实测 `10K_Q ≈ 5.7`，应为 0.55），
   并在 3D 中驱动虚假的整体旋流。改用 `slip_friction`（只锁法向 + `C_f` 闭合）后
   `10K_Q` 回到 ~0.8。**适用边界**：当 `δ ≈ c/√Re_c ≪ 1 格` 时这是正确的极限；若分辨率
   足以解析边界层则应回到 `noslip`。
4. **单层零厚度叶片在 3D 里缺少环量**：二维剖面定标（`C_l = 0.84 ≈ 2πα`）说明力模型本身
   能给出升力；但三维桨的自由 `K_T(J)` 呈"桨板"型（随 `J` 反升、`J≈1` 不过零），
   说明在**窄弦（4–6 格）+ 强展向流 + 周期侧向边界**下，标记面的展向泄漏/梢涡主导了受力，
   环量未能按 Kutta 条件锁定。这是 AC2 失败的**首因**，也是最明确的下一步（见 ⑦）。
5. **瞬态与对流/扩散时间尺度**：`D/U` 在 `J=0.2` 时约 1560 步，而预算只允许 450 步；
   低 Re 圆柱的扩散时间 `D²/ν` 达 3600–16000 步。这解释了低 Re 圆柱 +21 % 与敞水窗口未收敛。
6. **共享控制面负载 160–520/128 核**，torch 默认 128 线程反而更慢（实测 4 线程比 32 线程快 3–5 倍）；
   已统一在驱动/测试里限线程。集群队列本时段基本停滞（提交 60 min 未派发），因此全部算例在本机完成。
7. **`build_stencil` 强制 float64**，与 float32 场混用会把整个求解器静默提升为 float64（内存流量翻倍）；
   已加 `_stencil_in()` 统一权重 dtype。

### 可信的部分（可被后续节点直接复用）

* IBM 力传递/动量记账：闭箱残差 3e−11、每步注入动量与反力一致到 1e−16 —— **可作为冰-桨耦合的
  力矩/推力计量底座**；
* 二维剖面定标：`C_l = 0.84` vs `2πα = 0.877`（−4.2 %）—— **slip+摩阻闭合的力模型方向与幅值可用**；
* 圆柱 `Re=60/100`：−1.1 % / +4.0 % —— **IBM 边界实施本身没有系统性偏差**。

## ⑦ 局限与下一步

1. **（首因）三维零厚度叶片缺环量** → 改用**双面/带厚度的闭合标记壳**（NACA 厚度 + 中弧曲度），
   或给标记面加**涡量—环量约束**（Kutta 条件松弛）；预计可恢复 `K_T(J)` 的下降趋势。
2. **网格/时长**：敞水与低 Re 圆柱都需要 `D ≥ 16`、`>1500` 步（对流/扩散时间）预算——
   本机负载不可行，需等集群队列恢复后按 shard 重跑（脚本已支持逐点 JSON + 聚合）。
3. **冰-桨耦合**：动量底座已达标（AC3），下一步在 `ibm_ice_propeller`（DEM 两相耦合）上接
   本模块的 `marker_forcing` + `blade_sheet`，替换其单层力模型。
4. **AC4 的诚实口径**：三套网格只在 `J=0.5` 有共同点，因此网格收敛结论仅对 `J=0.5` 成立，
   报告中已注明 `common_advance_ratios: [0.5]`；扩到全 `J` 需要 15 个算例点的算力。
