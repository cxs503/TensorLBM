## 1. 案例介绍（物理背景 / 几何 / 参数）

球体定常绕流阻力是 LBM 曲壁边界条件最标准的验证算例，也是船海 CFD（螺旋桨桨叶前缘、球鼻艏、系泊浮体、泥沙颗粒）绕流阻力的最小可证单元。

- **求解器**: `src/tensorlbm/sphere_curved_wall.py`（633 行，D3Q19，周期立方盒 + 体积力驱动）
- **曲壁边界**: BFL 二阶插值 bounce-back（Bouzidi–Firdaouss–Lallemand 2001），按壁链分数距离 q 分两支：
  `q≥1/2: f_ī(x_f)=f_i*/(2q)+(1−1/(2q))f_ī*`；`q<1/2: f_ī(x_f)=2q f_i*(x_f)+(1−2q)f_i*(x_f−e_i)`
- **阻力仪**: 动量平衡 `C_D = g·N_fluid / (½ U² A_front)`（验收用）；逐链动量交换 `Σ e_i(f_i*+f_ī^out)` 仅作诊断（实现自述偏差 10–20%，**不用于验收**）
- **工况矩阵**: 11 个真实 LBM 算例，Re(实测) 8.0–198.0，D=6/8/10 格，L/D=5/6/8，步数上限 3200，τ=0.506–0.620，BGK/TRT
- **外部锚**: `tensor_benchmark_cases` id=8 — `GAP-LBM-SPHERE / 球绕流阻力关联 / Clift-Grace-Weber 球阻力标准关联 / metric = C_D vs 关联值 / tolerance = <8% / status=pending`

## 5. 注意点（坑 / 局限 / 适用范围）

1. **前审计 m14991 审错了对象**：它核的是 `benchmarks/verified/sphere_drag_bfl/results.json`（那是 GitHub main 上 **e72dd1aa** 提交的既有占位文件，`elapsed_s=0/all_results={}/note=…pending cluster cj832`，与 m14672 无关）与 `tests/test_bfl_sparse.py`（既有库测试，非 m14672 交付）。m14672 的真实交付是 `sphere_curved_wall.py` + `benchmarks/sphere_drag_curved_wall.py` + `tests/test_sphere_curved_wall.py` + 11 个 `case_*.json`。本审计全部指向后者。
2. **判分口径错位**：交付侧 err 是对「CGW 表 + CGW 关联 + Schiller-Naumann」**均值**的偏差，平台声明锚是 CGW 关联；两者差 0.5–1.7 个百分点（如 Re100_D8_L48 交付 8.58% → 声明口径 8.15%）。方向不变（都在容差外），但口径必须统一，否则同一算例可被「换分母」刷进容差。
3. **动量交换诊断与动量平衡差最多 84%**：说明当前壁面力仪在高阻塞/少步数下不可信；实现自述 10–20% 偏低，是自评偏乐观。
4. **交付测试有一红项**：负对照断言「无驱动力 ⟹ drag_balance=0」，但驱动量 g 由 Schiller-Naumann 初值给定且 `flow_control=False` 时不回零，故必然非零。这是交付物自身的红测试，任务自评 checks 里却写成「零驱动负对照 drag_balance < 1e-12 已证」——**自评与树内实况不符**。
5. **未覆盖**：L/D→0 外推、Re=500/1000 点、网格无关性三档的收敛级验证、`__init__` 导出与生产接入均缺位。
6. 本审计只读被审树，未改动 m14672 任何文件；审计侧代码/数据另存于 `runs/m15138_audit_m14672/`。

## 6. 误差判定（显式回答）

- 平台验收判据 = **C_D vs Clift-Grace-Weber 关联 <8%**：**未满足**（4/11 例落带，7/11 超带，最差 +52.06%；且 11/11 例 `converged=false`，落带的 4 例同样是未收敛值）。
- 六要素口径的「是否 <3%」：**否**，0/11 例满足 <3%（最好 +3.77%）。
- 结论：m14672 交付了**真实可复现的 LBM 曲壁阻力能力**（功能实质成立 → L2），但**数值验收不达标**，其自评「succeeded + honest-FAIL」中的 FAIL 判定是诚实的；本审计维持 NOT MET，不做粉饰，也不因其未达标而否认实现为真。
