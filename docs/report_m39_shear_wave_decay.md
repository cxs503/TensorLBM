## 1. 案例介绍（物理背景 / 几何 / 参数表）

### 物理问题

2D 衰减剪切波是不可压 Navier–Stokes 方程的**精确解析解**：周期域 [0,H)² 上单 Fourier 模 (0, k) 的纯剪切流，非线性项 u·∇u ≡ 0（无涡拉伸），只剩线性粘性耗散：

$$u(x,y,t) = U_0 \sin(ky) \cdot e^{-\nu k^2 t}, \quad v \equiv 0$$

$$\nu = (\tau - 1/2)/3, \quad k = 2\pi/H$$

速度衰减率 γ_vel = νk²（主指标），动能衰减率 γ_E = 2νk²（交叉验证）。

### 与 Taylor–Green (B17) 的互补关系

| | Taylor–Green (B17) | 衰减剪切波 (B30) |
|---|---|---|
| 波矢 | (±k, ±k)，|κ|² = 2k² | 单模 (0, k)，|κ|² = k² |
| 速度衰减率 | 2νk² | **νk²** |
| 动能衰减率 | 4νk² | **2νk²** |
| 非线性项 | u·∇u ≡ 0（TG 涡） | u·∇u ≡ 0（纯剪切） |

### 计算参数表

| 参数 | 取值 | 说明 |
|---|---|---|
| 格子/碰撞 | D2Q9 / BGK | tensorlbm.solver.collide_bgk + stream（周期 wrap 内建） |
| 网格 | H=64×64, H=128×128 | 两档网格收敛验证 |
| 弛豫时间 | τ = 0.8 → ν = 0.1 | 直接用 ν 定 τ |
| 波数 | k = 2π/H（H=64: 0.098175; H=128: 0.049087） | 单 Fourier 模 |
| 速度幅值 | U₀ = 0.05 | Ma ≈ 0.087 |
| 步数 | H=64: 3200; H=128: 10000 | 自动按 u_max/U₀ → e⁻³ |
| 记录间隔 | 每 100 步 | u_max 与 E 由 macroscopic 实测 |
| 精度/设备 | float32 / CPU（入库档）；SDAA 扫荡使用 sdaa 设备 | — |
| 共用模块 | solver.collide_bgk, solver.stream, d2q9.equilibrium, d2q9.macroscopic | 零手写碰撞/迁移 |

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### SDAA 验证流程

1. **读取案例文档**：阅读 benchmarks/verified/shear_wave_decay/README.md 与 result.json，明确既有判据口径——该案例在 NVIDIA 侧已有成熟判据（γ 偏差 ≤ 3% + 单调收敛 + R² ≥ 0.999），按原口径执行。

2. **编写独立运行脚本** scripts/sdaa_sweep_shear_wave_decay.py（不改业务代码）：
   - 将张量放 sdaa 设备（device='sdaa'）
   - 入口依赖 tensorlbm.solver.collide_bgk + stream + d2q9.equilibrium + d2q9.macroscopic（共性模块路径，零手写 collide/stream/平衡态）
   - 若入口依赖 Triton，使用 TRITON_INTERPRET=1 并如实记录绕过情况
   - 两档网格（H=64/128）同一物理参数，与入库档完全对齐

3. **测量协议**：
   - u_max 与动能 E 每 100 步由 macroscopic 实测记录，无任何外推/修正
   - 拟合 ln(u_max) vs t 得 γ_vel_sim，对比 γ_vel_theory = νk²（主指标）
   - 拟合 ln(E) vs t 得 γ_E_sim，对比 γ_E_theory = 2νk²（交叉验证）
   - 半窗口斜率一致性检查（验证纯指数衰减，防拟合假象）

4. **判定标准**：
   - |γ_sim/γ_theory − 1| ≤ 3%（任务书标准）
   - |err| 随 H 增大单调下降
   - R² ≥ 0.999（指数性检查）

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **偏差符号的物理信息**：本案例 γ_sim **略大于** γ_theory（+0.05%→+0.01%），而 2D TG 为 −0.035%（略小）——不同波矢/模态的 BGK 离散等效粘性修正方向不同。数值如实记录，不做任何人工修正。

2. **E₀ 实测 vs 理论**：E₀_meas = 5.148405e-04（理论 U₀²/4 = 6.250000e-04），差异来自离散动能定义（LBM 分布函数动能含高阶矩贡献），不影响衰减率测量。

3. **SDAA 设备适配**：SDAA 扫荡脚本将张量放 sdaa 设备，通过 TRITON_INTERPRET=1 绕过 Triton 编译（如入口依赖 Triton）。物理参数与入库档完全对齐，判据口径不变。

4. **适用范围**：本验证仅覆盖 BGK 碰撞 + D2Q9 + 周期边界 + 单 Fourier 模。多松弛时间（MRT/cumulant）或复杂边界需另行验证。

5. **网格收敛阶**：err 从 H=64 到 H=128 降约 4.5×（接近 4× = 2²），与 BGK 的 O(k²) 离散误差一致（k 减半 → 误差降 4 倍）。
