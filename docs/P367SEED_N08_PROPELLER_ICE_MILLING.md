## 1. 案例介绍（物理背景 / 几何 / 参数）

冰级推进器的冰载现有工程做法是**经验脉冲**：把叶片-冰相互作用扭矩写成叶频脉冲串，幅值由冰破碎压力
（如 ISO 19906 全局冰压 `p_G = C_R σ_c (h/w)^n`）乘破碎接触面积再乘接触半径得到。该模型里没有任何
"流"，因此无法给出脉冲形状、上升时间，也无法回答"载荷里有多少是流体动力"。

本节点用 LBM 直接求解**叶栅环道内被冰块部分堵塞时的瞬态流场**，把经验脉冲换成求解结果。二维中弧面切割模型
（"铣削槽"切割面）：

| 项 | 取值（格子单位） |
|---|---|
| 域 | `n×n` 封闭方箱，四周 2 层无滑移壁 |
| 轮毂 | 静止圆盘 `r ≤ 0.32R`（无力矩） |
| 叶片 | 2 片径向薄板，厚 `0.12R`，`0.32R ≤ r ≤ R`，刚性转动 `Ω` |
| 冰块（刚体、静止） | 环向扇区 `R+gap ≤ r ≤ r_out`、`|θ| ≤ 30°`；`gap = 0.15R` |
| 间隙 / 叶片尺度 | n=64: gap 3.84 格、叶片厚 3.07 格；n=80: 4.80 / 3.84；n=96: 5.76 / 4.61 |
| 运动学 | 叶尖 Mach `U_tip/c_s = 0.18`（`c_s = 1/√3`） |
| 粘性 | 转动 Re `= ΩR²/ν = 120` → `τ = 0.5665 / 0.5831 / 0.6072` |
| 时间分辨率 | 每转 1547.8 / 1934.7 / 2321.7 步（n=64/80/96） |

冰块占据叶栅环道外半侧的一个 60° 扇区，环道在扇区内只剩叶尖间隙这一条通路（**壅塞通道**），叶片每次扫过
就把流体从间隙挤过去 → 每次过冰产生一个扭矩脉冲。叶频 `f_BPF = N_b·f_rot`。

数值方法：D2Q9 BGK；半程反弹 + Ladd 动壁修正 `f_q = f_̄q + 6w_qρ(c_q·u_w)`（`u_w = Ω×(x−x_hub)`）；
每根边界链元的动量交换 `dF = −(f_q+f_̄q)c_q` 按固壁类别（壁/轮毂/叶片/冰）分别累加，得到叶片扭矩、冰反力矩、
箱壁力矩三个可分离量；叶片扫过/让出的格子记入显式质量/能量台账（`mass_added/removed`、`ke_added/removed`）。
对角"两侧皆固壁"的链元改为**纯交换**（`f_q ← f_̄q`）以保证质量守恒，并从力统计中剔除。

## 2. 怎么做的（方法 / 流程 / 工具链）

1. `run_milling(cfg)` 逐位推进；每步重建叶栅标签（`GeometryCache` 预存静态几何，仅叶片掩膜随角度变化）、
   记录叶片扭矩、冰力矩、动能、内能、总质量、粘性耗散、动壁质量源。
2. 网格收敛族 n = 64/80/96（几何自相似族，间隙、板厚、扇区角均按 `R` 固定比例缩放，Re 与 Ma 固定）。
3. 周期性例（n=64，1.75 转，1936 样本）做 FFT：先做 boxcar 低通（窗 = 周期/16，一阶零点在 8×`f_BPF`，
   远高于脉冲宽度 ~周期/6）以抑制体素化转动叶片的格点级锯齿噪声，再取峰。
4. 负控 A：无冰；负控 B：静止冰（基线）单峰计数。
5. 守恒审计：质量台账残差；总能平衡 `∫P dt = Δ(KE + c_s²M) + ∫ε dt + 边界项`，其中
   `ε = σ_ab S_ab`、`σ = −(1−1/2τ)Π^neq`、`S` 取中心差分。
6. ISO 19906 经验基线：`p_G = C_Rσ_c(h/w)^n = 2.39 MPa`、`A_c = d_c·b = 0.01 m²` → `F = 23.9 kN`、
   `T_emp = 23.42 kN·m`；与 LBM 无量纲脉冲系数 `C_T = ΔT/(ρΩ²R⁴b)` 在给定工况点（R=1 m、n=2 rev/s、
   b=0.5 m、ρ=1025）比对，并做工况/冰强扫掠。
7. 图 6 张 + `metrics.json`（判据数字与产物路径全部落库）。

工具链：PyTorch D2Q9（`torch.set_num_threads(1)`）、numpy/scipy（FFT、find_peaks）、matplotlib(Agg)、pytest。
全部数字由脚本注入 `metrics.json`，本报告未手抄（可逐项对照 `artifacts/p367seed_n08/metrics.json`）。

### 3.6 脉冲形状（LBM 对经验模型）

| 量 | LBM | 经验半正弦 |
|---|---|---|
| 半显著度以上占空比 | **2.9 %** | 33.3 % |
| 峰/时均、谷/时均 | −0.083、−1.468 | 正峰（+1/−0 型） |

**定性结论**：在不含破碎接触的刚体冰模型里，叶片进入壅塞扇区时**阻力矩反而下降**（冰块占位减少了湿面积与粘性
阻力），"脉冲"是**负向凹陷**，而不是经验模型预设的正向尖峰；正向尖峰只能来自冰破碎接触力（固体力学项），
流体求解无法产生 MPa 级破碎压力。这是 C5 判据不成立的物理解释。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **体素化转动叶片的几何锯齿噪声**：原始扭矩信号被格点级尖峰主导（raw std 21.5–27.7，脉冲幅值 30–37，
   同量级），且伪峰锁相在 `4 f_rot`（方格子旋转对称周期 π/2），恰为 `2 f_BPF`——用未滤波信号做 FFT 会得到
   `f = 2.008 f_BPF` 的假主频。必须用低通（窗 ≪ 脉冲宽度）后再判频；本报告用 周期/16 并在图 1 同时给出原始信号。
2. **阶数非渐近**：网格族细化比只有 1.25，Richardson 得到 p=6.35（形式上满足 ≥1），但该数字不可作为收敛性的
   定量证据；真正的证据是"脉冲幅值在三套网格上一致到 ±10 %（34.6/30.8/36.9 格）"。**绝对扭矩水平不收敛**
   （时均 −6.4/−11.6/−14.9，绝对峰值变号），说明 2D 壅塞环道的阻力被粗网格的粘性/几何误差主导。
3. **动壁边界是质量源**：Ladd 项 `6w_qρ(c_q·u_w)` 并非零和，1.25 转内注入 5.96 % 质量（等温 LBM 在离心压力场
   下压缩，Δρ/ρ ≈ 3u²/2c_s³ 量级）。台账显式记账后残差降到 float32 底噪 3.1e-5，但**判据 1e-10 只能在静止
   转子（Ω=0）审计中达到**。
4. **动量交换力的半步相位**：瞬时力有 2 步周期的振荡（Ladd 格式固有），pytest 中以时均判据断言阻力符号。
5. **C5 的对比是量纲分析而非 Reynolds 相似**：格子 Re=120（粘性主导）、真实螺旋桨 Re~1e6，`C_T` 不可跨 Re
   平移；8.01 的偏离里既有 Re 失配也有二维封闭箱的阻塞效应，**不能**当作"LBM 高估 8 倍"的定量结论。
6. **未建模项**：冰破碎接触（强度/断裂/碎屑输运）、真实叶片几何（无螺距/扭角、二维切割面）、自由面与
   空化、冰的进给运动与 DEM 接触。冰块按刚体静止处理，故"冰块动能"项恒为 0。
7. **自由面缺口**：C3 判据原文要求"自由面 LBM 质量残差"。本节点实现为**单相**封闭域 + 移动边界台账，
   自由面 Körner 版未接入（如实标注，未用既有 `free_surface_mass_ledger` 复测）。

## 6. 误差判定（逐项回答是否 <3 %）

| 关键量 | 基准 | 误差 | <3 %？ |
|---|---|---|---|
| 粘性耗散估计 `∫ε dt` | Taylor–Green 解析衰减 `−ΔKE` | **2.8 %** | **是** |
| 扭矩谱主频 | `f_BPF`（运动学恒等式，非实验值） | 0.93 % | 是（判据阈值 1 %） |
| 脉冲幅值 `C_T`（n=96 vs 外推 2.107） | Richardson 外推 | 10.0 % | **否**（且外推本身不可信，见 §5.2） |
| 脉冲幅值跨网格一致性（34.6/30.8/36.9 格） | 三网格互相 | ±10 % | 否 |
| LBM 扭矩峰值 | ISO 19906 经验值 23.42 kN·m | 比值 8.01（偏离 701 %） | **否** |
| 无冰时扭矩脉动 | 稳态（rms ≤1 %） | 39.6 % | **否** |
| 质量台账残差 | 1e-10 | 3.12e-5（移动）/ ≤1e-10（静止） | 移动否 / 静止是 |
| 总能残差 | ≤5 % | 5.70 %（n=96）、2.18 %（n=80） | 否（临界）/ n=80 是 |

**机器判据总判**：`metrics.json → verdict` = C1 通过（**带非渐近保留意见**）、C2 通过、C3 不通过、
C4 不通过（5.70 % vs 5 %，临界）、C5 不通过、C6 一半通过（单峰通过、无冰稳态不通过），`all_pass=false`。

**honest FAIL 声明**：本节点**未能**证明"LBM 直接求解可替代经验脉冲"用于冰载定量设计。证据指向
本实现（2D、体素化刚体冰、Re=120、R≤38 格）**网格不足以解析冰桨间隙流场并给出收敛的绝对扭矩**（C1 的
绝对量不收敛 + C5 偏离因子 8 + C6 无冰脉动 39.6 %），这正是节点预设的失败模式。可复用的正面结论是：
（i）脉冲主频与叶频在 0.93 % 内一致，说明"过冰脉冲 = 叶频节律"这一经验模型的**运动学假设**被直接求解证实；
（ii）刚体冰的流体动力响应是**负向凹陷**且占空比 2.9 %（经验 33 %），说明经验脉冲的**形状/正负号**假设错误，
真正的正向尖峰必须由冰破碎接触给出——这为下一节点指明了唯一正确的技术路线（LBM 流体 + 冰破碎/接触本构）。
