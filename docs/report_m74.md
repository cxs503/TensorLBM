## 1. 案例介绍

### 1.1 物理背景

圆管 Poiseuille 流动是流体力学最经典的解析基准之一。在充分发展的层流条件下，圆管内轴向速度呈抛物线分布：

$$u(r) = U_{\max}\left(1 - \frac{r^2}{R_{\text{eff}}^2}\right)$$

其中 U_max = 2*u_in 为轴线速度，R_eff 为有效水力半径。该案例是 LBM 弯曲边界（staircase bounce-back）精度的标准验证算例。

### 1.2 几何与数值参数

| 参数 | 值 | 说明 |
|------|-----|------|

| 网格 ny×nz×nx | 43×43×120 | 含壁面 |
| L/R | 6.0 | 入口到出口长度/半径 |

### 1.3 有效水力半径

阶梯近似圆管的实际水力半径 R_eff^Q 由流量反演得到（独立积分观测量，非拟合）：

$$R_{\text{eff}}^Q = \sqrt{\frac{2\,Q}{\pi\,U_{\max}}} = 20.1087

与名义 R=20 的偏差仅 +0.1087，在阶梯近似的理论预期范围内。

## 2. 方法

### 2.1 求解流程

1. **几何构建**：在 43×43 截面上以圆心 (21.5, 21.5)、半径 R=20 画圆，阶梯化（half-way bounce-back）得到 1,257 个流体格子/截面。
2. **初始化**：全域平衡态分布（均匀密度 ρ=1，速度 u_in=0.02 沿 x 方向）。
3. **时间推进**：BGK 碰撞 → streaming → Zou-He 边界 → bounce-back 壁面，循环 20,000 步。
4. **稳态检测**：每 2,000 步检查 u_max 漂移，< 1e-5 即判稳态。
5. **后处理**：在充分发展段（x 中部截面）做径向分 bin 平均，与解析抛物线比较。

### 2.2 关键设置

- **R_eff^Q 策略**：不用名义 R+0.5，而是由实测流量 Q 反演水力半径，消除阶梯几何的系统偏差。
- **双解析基准**：同时对比 R_eff^Q 解析解和 R+0.5 解析解，前者为主判据。
- **SDAA 设备验证**：独立 probe 确认所有计算张量确在 sdaa:0 上，无 CPU/CUDA 回退。

### 2.3 工具链

- TensorLBM (benchmarks/verified/poiseuille_3d_pipe)
- PyTorch 2.7.1 + torch_sdaa 3.1.1a3
- Python 3.12, eager 模式

## 5. 注意点

### 5.1 阶梯近似误差

圆管在 Cartesian 格子上的 staircase 表示引入系统性几何误差。R_eff^Q = 20.109 与名义 R=20 的偏差 (+0.109) 正是这一效应的量化。使用 R_eff^Q 而非 R+0.5 作为比较基准，消除了这一系统偏差，使判据真正反映 LBM 求解器精度而非几何离散误差。

### 5.2 单格子散射

中心区个别 bin 的 per-cell 最大相对误差达 6.45%（超 3%），但 bin 平均后降至 2.36%。这是 staircase 边界在粗分辨率下的固有特征（README 已披露 6.45% @ R=20），不影响工程精度结论。

### 5.3 质量守恒

Zou-He 速度入口 + 压力出口组合在逐步意义上不严格守恒，质量漂移 0.6077%。这在稳态层流中可接受，但对长时间瞬态或多相流需注意。

### 5.4 编译模式限制

torch_sdaa 3.1.1a3 的 teco_inductor 无法编译 LBM step chain（已知 L5 缺陷），只能 eager 执行。这不影响数值正确性，但吞吐量受限（39.9 steps/s）。

### 5.5 单档局限

本次仅执行 R=20 单档。README 定义的多档收敛阶梯（R=20 → R=40）未执行，因此不声称完整 "verified" 属性。完整收敛性验证需后续补充。

### 5.6 u_max_dp_err 诊断

基于 R+0.5 中点假设的 Hagen-Poiseuille u_max 推断误差达 -22.9%，这是因为阶梯管道的真实水力半径并非 R+0.5。此量仅作诊断，不作为判据。
