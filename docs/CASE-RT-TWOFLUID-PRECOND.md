# CASE-RT-INSTABILITY-ATWOOD — 有限密度比（SCMP）支臂的启动瞬态、噪声地板与估计量否定

**结论先行（honest FAIL，不粉饰）**：本单**没有**取得锚点「A = 1/2 尖峰增长率」的可判定值。
本轮把 m21799 那张 `steps_run = 5` 中止单的**病灶定位到启动冲量**，并按该单「下一步」清单做了分级启动
（平界面预弛豫 → 剖面移位播种 → 重力斜坡），成功让算例越过第 5 步；但随后的**仪器标定**（空动力对照 + 播种回读）
证明：**当前的相场前沿估计量看不见 0.02λ 的播种模态**，且 SCMP 在 A≈1/2 的寄生电流地板与目标终端速度同量级。
在此两条未清除之前，任何把它判成 PASS/FAIL 的 <15% 门都是假的。以下数字全部由
`probe_twofluid_precond.py` 程序化产出并落盘 `artifacts_twofluid_precond/probe.json`（零手抄）。

## ① 案例介绍（物理背景 / 几何 / 参数）

单模 Rayleigh–Taylor 不稳定性，重流体在上、轻流体在下，界面单模扰动波长 λ，初始幅值 a₀ = 0.02λ，
Atwood 数锚定 A = (ρ₁−ρ₂)/(ρ₁+ρ₂) = 1/2。锚点问的是**尖峰（重流体下探一侧）增长率**。Boussinesq 支臂
（`run_case.py`）在 `(φ,y)→(−φ,−y)` 下不变，尖峰/气泡是同一个前沿（实测比 1.0004 vs 两流体预测 1.743），
无法回答该问题，故 m21799 新增 SCMP 有限密度比支臂 `tensorlbm.rayleigh_taylor_twofluid`。本单在其上继续。

| 量 | 记号 | 本单取值 | 说明 |
|---|---|---|---|
| 耦合强度 | sc_g | 2.80 | 伪势 `ψ = 1 − exp(−ρ)`；标定点（见 ⑤ D1 的告警）|
| 网格 | λ × layers | 64 × 4（探针）/ 64 × 6（试算）| x 周期（一个波长），y 上下半程反弹壁 |
| 松弛时间 | τ | 0.8 / 1.0 / 1.2 / 1.5 | ν = (τ−1/2)/3 |
| 重力 | g | 7.5e−5 / 2.0e−4 | 格子单位，向下 |
| 初始幅值 | a₀/λ | 0.02 | 探针播种回读的目标值 |
| 预弛豫 | n_relax | 600 | g = 0，平界面 |
| 重力斜坡 | n_ramp | 0 / 200 / 400 | 线性升到 −g |

## ② 方法（做了哪些改动、怎么验的）

在 `src/tensorlbm/rayleigh_taylor_twofluid.py` 上做**向后兼容**扩展（默认参数复现 m21799 的单发启动路径，
`tests/test_rayleigh_taylor_twofluid.py` 原有 13 例中 11 例改前改后同样通过，2 例为基线已有的红例，已在 ⑥ 处理）：

| 新增 | 作用 |
|---|---|
| `precondition_scmp_rt(cfg, …, relax_steps)` | 分级启动第 1–2 步：平界面 + **g = 0** 预弛豫到寄生电流稳定 → 重建分布函数（速度归零，清掉残余伪动量）→ 按剖面移位播种单模；返回寄生电流衰减曲线 |
| `_perturb_density(…)` | 播种改为**采样弛豫后的 1-D 剖面** `ρ(y − d(x))`，而不是把理想 `tanh(width)` 写回盒内（后者会重新引入启动冲量）|
| `run_scmp_rt(…, precondition_steps, ramp_steps, ma_guard, gravity_scale, front_estimator, amp_window)` | 重力线性斜坡；`gravity_scale = 0` 即**空动力对照**；马赫护栏可切 `all / iface / bulk`（接口带内属伪势伪迹，只报不判）|
| `_ma_split(ux, uy, band)` | 同步输出 `ma_all / ma_iface / ma_bulk`（m21799 报告「下一步 2」）|
| `column_height` / `column_front_state` | 重流体柱高矩估计量（替代 `φ = 0` 穿越），并**以瞬时平均界面为参考**消除重压下整箱压缩的共模位移 |
| `gradient_front_state(rho, cfg, …)` | 密度梯度质心估计量（替代 `φ = 0` 穿越），对整箱压缩共模免疫，对壁面耗损层免疫（见 ⑤ L3）|
| `run_scmp_rt` 内新增 `sigma_amp / sigma_theory_visc / sigma_theory_inv / err_sigma_pct` | 界面幅值的线性增长率 σ 对等黏度色散关系 `σ = sqrt(Agk + ν²k⁴) − νk²` 的逐例误差（锚点「增长率」的线性支）|

验证方式：`probe_twofluid_precond.py` 四段探针（P1 复现旧中止 / P2 寄生电流地板 vs τ / P3 空动力对照 /
P4 播种回读），全部落盘 JSON；再加单元测试（见 ⑥）。

## ③ 计算结果（程序化注入）

**P1 启动瞬态（复现 m21799 的 `steps_run = 5` 中止）**

| 步 | 1 | 2 | 3 | 4 | 5 | 峰值 |
|---|---|---|---|---|---|---|
| Ma（旧路径：tanh(width=2) + 第 1 步即开重力）| 0.285 | 0.225 | 0.232 | 0.253 | 0.224 | **0.326** |

护栏 0.20 → 第 1 步即越限。**病灶是初始剖面与模型平衡剖面不匹配造成的力冲量 `|F|/ρ`，不是流动发散**
（平界面、g = 0 的同初值实测 Ma 从 0.067 衰减到 0.042，见 ⑤ L1）。

**P2 寄生电流地板 vs 松弛时间（平界面、g = 0、600 步后）**

| τ | ν | Ma 地板 | u_spurious | 目标 u_s（λ=64, g=7.5e−5 / 2e−4）| 信噪比 |
|---|---|---|---|---|---|
| 0.8 | 0.100 | 0.186 | 0.107 | 0.0394 / 0.0644 | 0.6 |
| **1.0** | 0.167 | **0.0555** | **0.032** | 0.0394 / 0.0644 | 1.2 |
| 1.2 | 0.233 | 0.129 | 0.074 | 同上 | 0.9 |
| 1.5 | 0.333 | 0.192 | 0.111 | 同上 | 0.6 |

地板**非单调**（τ = 1.0 最优），说明它不是单纯的黏性耗散，而随「该 τ 下弛豫出的界面/两相密度结构」变化。

**P3 空动力对照（播种 + g ≡ 0，600 步，gradient 估计量）**：前沿位移全程 ≤ **0.0066λ**（逐点 −0.002 / −0.0029 / −0.0012 / −0.0025 / −0.0008 / −0.0019），
即位置估计量的噪声地板 ~6.6e−3λ。

**P4 播种回读（关键否定结果，gradient 估计量）**：计划 a₀/λ = 0.0200，柱高矩读回 **0.00028**（比值 **0.014**），
且 300 步内幅值一直在 ±0.005 内游走——**与 P3 的噪声地板同量级**。也就是说该估计量根本没看见播种模态。
同时斜坡段 `ma_bulk` 仍到 0.414，`sigma_amp` 无法拟合（NaN）。

> **注意**：P4 使用 `front_estimator="gradient"`（而非被壁面污染的 `crossings`）。
> 单元测试 `test_gradient_estimator_reads_back_a_known_amplitude` 在合成 tanh 剖面
> 上验证了 gradient 估计量可正确读回 a₀（误差 <5%），但在实际 SCMP 弛豫剖面上失效。
> 机理未定：候选 (i) 质量型积分 `Σclamp(frac)` 对整窗平移的不变性；(ii) 参考密度取自另一 τ 的共沸跑导致
> clamp 饱和下的实现缺陷。无论哪一个，该估计量**不得**用于门判。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

| 编号 | 发现 | 证据 |
|---|---|---|
| L1 | 旧路径的「马赫爆炸」是**力冲量**而非不稳定：平界面 g=0 时 Ma 由 0.067 单调衰减到 0.042；g 开在第 1 步时首步即 0.285 | P1、P2 |
| L2 | **柱高矩估计量在本实现下看不见界面位移**（本次否定，可复现）：把弛豫后的剖面按**已知的 1.28 行余弦**移位后回读 **−0.00005λ**（应读 0.02λ）；播种回读同样给 0.00028λ（0.014 a₀）。机理未定，两个候选未分辨：(i) 质量型积分 `Σclamp(frac)` 对整窗平移的不变性；(ii) 参考密度取自另一 τ 的共沸跑导致 clamp 饱和下的实现缺陷。无论哪一个，该估计量**不得**用于门判 | P4 + 合成对照 C（同一 JSON/探针内）|
| L3 | `φ = 0` 穿越估计量被**两处**污染：(i) 底壁附近蒸汽耗损形成一条均匀低密度层，令每列都多出一个假穿越（实测 ncol 由 64 变 128、tip 从 −0.27λ 跳到 −2.88λ）；(ii) 重力静压使整箱密度抬升 `Δρ/ρ ~ gH/c_s²`，固定阈值把共模抬升读成界面整体漂移（700 步内均匀下移 17 行）| 见 `probe_spurious.py` 轨迹与本节推导 |
| L4 | **共沸标定不收敛**：同一 sc_g = 2.8 在 (ny=64, 3000 步) 给出 A = 0.505、在 (ny=48, 1500 步) 给出 A = 0.652（差 30%）。参考式 `u_s = sqrt(2Ag/((1−A)Ck))` 对 A 敏感（A: 0.505→0.652 时 u_s 变化 +38%），故 **A 未收敛前 15% 门无意义** | P2/P4 两跑共沸值 |
| L5 | 信噪比 ≈ 1：SCMP 在 A≈1/2 的寄生电流地板 0.032–0.111 与目标终端速度 0.039–0.064 同量级；要过 15% 门需把寄生电流压到 ≲0.006（≥5× 改善），τ/g 调参做不到 | P2 |
| L6 | 适用边界：以上结论限定于 SCMP + EDM 力项 + 半程反弹壁 + 本文参数区；换成压力演化/双分布变密度模型（Fakhari & Bolster 2017 类）时须重测 L2–L5 | — |

## ⑦ 下一步（可单干、按性价比排序）

1. **换模型而不是继续调参**：压力演化 / 双分布变密度 LBM（Fakhari & Bolster 2017），或独立的谱方法变密度
   参考解算器（2D FFT 压力投影 + 守恒型密度输运，~300 行）。L5 说明 SCMP 的参数区已经用尽。
2. **估计量先过标定再谈物理**：对任何候选前沿估计量，先跑 (i) 播种回读（必须读回 a₀ 误差 <5%）、
   (ii) 空动力对照（g ≡ 0 位移 <0.1 u_s）、(iii) 整箱压缩共模剔除；三项不过不得进入门判。
3. **共沸标定加收敛判据**：A 对 (ny, steps) 做双序列收敛，报告 A 的不确定度，并把参考式对 A 的敏感度
   一并列出（L4 实测 +38%/ΔA=0.15）。
