## 1. 案例介绍

### 物理背景
真实壁面的切向动量适应系数（tangential momentum accommodation coefficient, TMAC）介于 0（完美滑移）与 1（无滑移）之间。LBM 中最经济的连续可调实现是**混合反弹/镜面**（mixed bounce-back / specular reflection）：

$$f_q^{wall} = (1-\sigma) f_{opp(q)}^{wall} + \sigma f_{M(q)}^{wall}$$

其中 $\sigma$ 为镜面分数（specular fraction），$opp(q)$ 为反方向（完全吸收切向动量），$M(q)$ 为关于壁法向的镜面方向（完全保存切向动量）。这正是 Maxwell 一阶滑移条件 $u_t|_w = b \cdot (\partial u_t / \partial n)|_w$ 在离散层面的实现。

### 几何与参数

| 参数 | 平面通道 | 圆管 |
|------|---------|------|
| 格子分辨率 | ny=33 (H=15.5 lu) | nr=33 (R=31.5 lu) |
| 松弛时间 τ | 0.8 | 0.8 |
| 运动粘度 ν | 0.1 lu²/step | 0.1 lu²/step |
| 体积力 g | 10⁻⁵ lu/step² | 10⁻⁵ lu/step² |
| 镜面分数 σ | {0, 0.1, ..., 0.9, 1.0} | {0, 0.1, ..., 0.5} |
| 收敛容差 | 10⁻¹² | 10⁻¹⁰ |

### 解析解
- **平面滑移 Poiseuille**: $u(y) = \frac{g}{2\nu}(H^2 - s^2) + \frac{gHb}{\nu}$，其中 $s = y - y_c$
- **圆管滑移 Hagen-Poiseuille**: $u(r) = \frac{g}{4\nu}(R^2 - r^2) + \frac{gRb}{2\nu}$

## 2. 方法

### 实现路径
1. **混合反弹/镜面算子** (`partial_slip_wall.py`): D2Q9 一维列简化，壁面位于半格点 (y=0.5, y=ny-1.5)
2. **D3Q19 三维提升** (`partial_slip_wall3d.py`): 完整三维格子，验证一维简化精确性
3. **滑移长度反演**: 对速度剖面做最小二乘二次拟合 $u = A + B(y-y_c)^2$，由 $b = (A+BL^2)\nu/(gL)$ 反解
4. **Maxwell 条件审计** (`slip_wall_calibration.py`): 从算子动量簿记直接读壁面速度 $u_w$，与流场外推梯度 $\dot\gamma_w$ 独立比较 $u_w = b\dot\gamma_w$
5. **标定律拟合**: $b(\sigma) = a\sigma/(1-\sigma) + c$，最小二乘选择最优形式
6. **减阻律**: 层流类比模型 $C_f/C_{f0} = (1 + k b^+/\delta^+)^{-2}$
7. **净收益账本**: 减阻节省功率 vs 维持滑移（注气）代价

### 工具链
- Python 3.11, NumPy, Matplotlib
- TensorLBM 本地源码 (src/tensorlbm/boundary/)
- pytest 测试框架

## 5. 注意点与局限

### 已验证
1. **代数恒等**: σ=0 逐位等价于半程反弹；σ=1 等价于纯镜面
2. **剖面层**: 定常强迫下离散解在体区精确为二次式（中心差分对二次式无截断误差）
3. **Maxwell 条件**: 算子动量簿记与流场外推给出一致的 b，误差 < 5%
4. **标定律**: b = 0.3σ/(1-σ) - 0.004 在格子单位下是常数，R²=1.0

### 局限与未完成项
1. **湍流减阻**: 层流类比模型严重低估湍流减阻（0.24% vs DNS 5-15%）。正确模型需要 DNS 数据或湍流模型（如 Spalart-Allmaras + 滑移修正）。**显式标 WITHHELD**。
2. **净收益账本**: 注气通量系数无仓内文献锚点，盈亏平衡分析以参数族形式给出。**显式标 WITHHELD**。
3. **曲线壁**: 镜面反射非局部，本模块不做（轴对齐壁假设）。
4. **分辨率依赖**: b 在格子单位下是常数，但物理滑移长度 b_phys = b_lu × dx 随网格线性变化。需重标定 σ(b_phys, dx) 以钉住物理滑移长度。
5. **高 σ 收敛**: σ>0.9 时需要更多步数收敛（扩散时间尺度 ~H²）。

### 适用范围
- 低 Mach、不可压、单相、纯 BGK
- 轴对齐壁（平面通道；圆管用轴对称列）
- D2Q9 / D3Q19 / D3Q27 速度集
