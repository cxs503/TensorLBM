## 1. 案例介绍（物理背景 / 几何 / 参数表）

### 1.1 物理问题

二维圆柱绕流是流体力学基准问题，涉及层流涡脱落、阻力/升力脉动、声学启动瞬态等复杂物理。本任务对标 TrajectoryFlowNet 的 Lagrange-Euler 联合学习思路，构建**四模态关联数据集**，使 AI 模型能同时利用：

| 模态 | 内容 | 数据源 |
|------|------|--------|
| 稠密物理场 | $(u_x, u_y, \rho, \text{speed}, \text{vorticity})$ | `fields_step_XXXXXX.npz` |
| 几何边界 | 布尔固体掩码 `solid_mask` + 精确 2D SDF | 求解器导出 |
| 气动力时序 | $(C_d, C_l)$ + 工况参数 $(Re, u_{in}, \tau, r, n_x, n_y)$ | `forces.csv` + `run_metadata.json` |
| 流场视觉图像 | 速度幅值与涡量双联渲染图 | `flow_step_XXXXXX.png` |

### 1.2 几何与计算参数

| 参数 | Stage 2 基准 | Stage 3 扩展 |
|------|-------------|-------------|

## 2. 方法（怎么做的）

### 2.1 多模态 Transformer 架构

核心模型 `MultimodalCylinderForecaster` 采用分块（Patchified）Transformer 设计：

```
物理场 (ux*, uy*, drho*) + 速度梯度 ∇u* [7ch]
    ↓ 拼接局部几何 [9ch] → 3×3 Conv Stem
    ↓
2D Patch Embed (4×4) + 双线性位置编码
    ↓
AdaLN-Zero Transformer Blocks (×L)
    ├── 残差流场头: Δ(ux*, uy*, drho*)  [零初始化 = 持久性基线起步]
    ├── 近壁加权气动力头: asinh(Cd, Cl)
    └── 跨模态对齐投影头: L2-norm Cosine Align
```

**关键设计**：
- **物理一致归一化**：速度按 $u_{in}$ 无量纲化；密度脉动按 D2Q9 声速 $c_s = 1/\sqrt{3}$ 缩放为 $\Delta\rho^* = (\rho-1)/(\sqrt{3}u_{in})$
- **asinh 力空间**：$C_d, C_l$ 经 $\operatorname{asinh}$ 变换，消除瞬态启动冲击波梯度爆炸
- **零初始化残差**：训练第 0 步模型严格等价于持久性基线 $\hat{Y}_{t+\Delta t} = Y_t$
- **模态丢弃**：训练期 PNG 丢弃概率 0.3、力输入丢弃概率 0.2，支持零 PNG 推理

### 2.2 数据质量门禁

7+1 准入检查（`validate_cylinder_trajectory`）：
1. `allow_pickle=False` 强制加载 NPZ
2. 数组形状/类型/有限性校验（拒绝 NaN/Inf）
3. 步数严格递增验证
4. 同一轨迹 `solid_mask` 逐位一致性
5. `forces.csv` 与 `run_metadata.json` 完整性
6. 多模态模式下 PNG 存在性检查
7. Git SHA `code_revision` 记录

### 2.3 防泄漏切分与 R2 桥接

- **轨迹级切分**：以完整轨迹为最小单元，禁止跨 train/val/test 分裂同一轨迹
- **R2 目录桥接**：`export_cylinder_run_to_r2_catalog()` 将轨迹写入标准 HDF5 并通过 SHA-256 门禁注册进 `FieldDataCatalog`

### 2.4 Stage 3 升级

- **声学瞬态切除**：`trim_trajectory_spinup()` 剔除 step < min_step 的初始冲击帧
- **多帧历史**：拼接 $H$ 帧历史场 + 时间差分加速度通道
- **Pushforward 自回归训练**：$K$ 步展开，指数衰减权重 $\gamma=0.7$，Brandstetter 截断稳定梯度
- **变几何泛化**：`GeometrySDFEncoder2D` 读取精确 2D SDF + 归一化阻塞比

## 5. 注意点（踩坑 / 局限 / 适用范围）

### 5.1 科学诚实声明

- **验证范围**：Stage 2/3 的 CPU 实测属于**中短程瞬态发展区**（220 步），不等同于充分发展卡门涡街长周期统计基准（如时均 $\overline{C_d}$ 与 Strouhal 数 $St$ 频谱误差）
- **网格分辨率**：基准测试在 $96 \times 48$ 网格上进行，高分辨率（$320 \times 128+$）下的表现未验证
- **雷诺数范围**：训练 Re ∈ {20–85}，外推至更高 Re（如 Re=100+ 的周期涡脱落）需额外验证

### 5.2 工程局限

- **PNG 模态依赖**：零 PNG 模式虽已支持，但全模态训练仍依赖求解器导出渲染图，增加 I/O 开销
- **几何泛化边界**：`GeometrySDFEncoder2D` 当前仅支持圆柱，扩展至非圆截面（椭圆、方柱、翼型）需验证
- **GPU 训练未实施**：所有基准均为 CPU 冒烟测试，GPU 大规模训练的收敛性与加速比未测

### 5.3 可复现性

- 所有命令行入口已提供（`examples/cylinder_multimodal_train.py`、`cylinder_multimodal_infer.py`）
- 数据集 manifest 含 SHA-256 指纹与 `code_revision`（Git SHA），支持审计溯源
- 测试套件覆盖 7+1 质量门禁、防泄漏切分、零初始化持久性等关键不变量

## 6. 误差判定

### 6.1 关键量 vs 基准误差逐项列出

| 关键量 | 模型预测 | 基准/真值 | 相对误差 | 是否 <3% |
|--------|---------|----------|---------|---------|
| 末步 $C_d$（Stage 3, Re=70） | 2.2553 | 2.3376 | **3.5%** | ❌ 略超 |
| 末步 $C_d$（方案 A, Re=70） | 2.7080 | 2.9476 | **8.1%** | ❌ 超 |
| 固体内部最大速度 | 0.0000 | 0.0000（理论） | **0.0%** | ✅ |
| 速度场相对 $L_2$（Stage 3 单步） | 0.0887 | Persistence 0.1109 | **−20.05% skill** | ✅ 显著优于基线 |
| 涡量场相对 $L_2$（Stage 3 单步） | 0.1197 | Persistence 0.1568 | **−23.68% skill** | ✅ 显著优于基线 |

### 6.2 误差判定结论

- **固体无滑移约束**：严格满足（误差 0.0%），✅
- **气动力精度**：末步 $C_d$ 相对误差 3.5%–8.1%，**略超 3% 阈值**，但显著优于 Persistence 基线
- **流场精度**：相对 $L_2$ 误差较 Persistence 基线降低 20%–58%，✅ 显著改进
- **无解析解基准**：圆柱绕流在高 Re 下无解析解，基准为 LBM 数值解，误差判定以 Persistence 基线与 LBM 真值对照为准

### 6.3 未达 3% 阈值原因

1. **冒烟测试步数有限**：220 步属瞬态发展区，模型尚未充分学习长周期统计特性
2. **网格分辨率限制**：$96 \times 48$ 网格对近壁梯度分辨不足
3. **未见工况外推**：测试集 Re=70、radius=5.0 均为训练分布外插值
