# GAP-PP-3-adjoint-ootc 验收：长时域 LBM 反演的 out-of-core adjoint

- 仓: TensorLBM · mission 20040 · commit `0953885a29b4d7af8815fff9b9766bca11429b0a` · 2026-11-14T09:05:40+00:00
- 锚点: `GAP-PP-3-adjoint-ootc` — out-of-core adjoint / 截断 BPTT（长时域反演内存）
- 验收判据: 10^4 步 128^2 τ 反演峰值内存 < 8 GiB；梯度与 BPTT 参考差 < 1e-5

## 1. 案例介绍（物理背景 / 算例 / 参数）

可微 LBM（JOUR-DIFFLBM 第 4 节）需要把终端目标对物性参数的反演梯度算出来。
本算例是 D2Q9 BGK 二维周期性方腔中一个高斯密度脉冲的衰减：反演参数是松弛时间
τ（等价于运动黏度 ν=(τ-1/2)/3），目标函数

  J(τ) = ½‖u_T(τ) − u_ref‖²，u_ref = 0.9·u_T(τ_ref)（终端速度失配）

| 参数 | 值 |
|---|---|
| 网格 | 128×128（D2Q9，周期边界） |
| 时域步数 T | 10000（验收要求 10^4） |
| τ | 1.0 |
| 初始脉冲 | amp=0.05, σ=16.0 |
| 检查点间隔 k | 100 / 1000 |
| 差分步长 | tau: h=0.0001, f0 方向: h=1e-05 |

## 2. 怎么做的（方法 / 工具链）

**前向**：`tensorlbm.adjoint.lbm2d`，numpy float64，逐位确定（BGK 碰撞＋周期 streaming）。

**参考梯度（BPTT）**：全轨迹存储的反向传播，内存 O(T·N·Q)。碰撞 Jacobian 用转置
`Bᵀ=∂feq/∂f` 作用（修正 m17532 的 D1/D2 缺陷后已与复步 Jacobian 逐列吻合）。

**Out-of-core adjoint（本锚点主体）**：Griewank–Walther 检查点/重算（gradient
checkpointing）：前向每 k 步把状态写入磁盘 memmap，内存只保留当前段；反向按段读回
检查点、逐位重算该段再传播伴随，内存 O(k·N·Q) 与 T 无关。尾段 T mod k 单独重算。

**本次新增（capability extension）**：OOTC 与 BPTT 均可返回完整伴随场
`dJ/df⁰`（`return_field=True`），代价仅多一个 (9,ny,nx) 数组，不改变内存标度——
这使「初始场/全场反演」与 τ 反演共用同一次反向扫描。该场由①逐列暴力 FD Jacobian
②方向导数中心差分 两条独立路径验证（tests/test_adjoint_field_gradient.py）。

**工具链**：集群作业 `cj2481`（节点 n330，8 核，全尺度验收；各变体在独立子进程
中运行以获得干净 VmHWM）、`cj2482`（节点 n330，T 标度 / k 扫描 / τ 反演）；
本机仅跑 <2 min 的单元测试与作图。（更早的 `cj2448`/`cj2451` 在旧版
`stream()` 上因 numpy 版本差异 TypeError 失败，见第 5 节 D5；`cj1625` 结果写进
节点 /tmp 而丢失。）

## 5. 注意点（踩过的坑 / 局限）

1. **模块内自洽 ≠ 正确**：OOTC 逐位复算 BPTT 公式，所以 OOTC-vs-BPTT 全绿也不能
   证明推导对——m17532 的 D1（用 B 而非 Bᵀ）、D2（多除一个 ρ）正是这样漏掉的。
   本单因此坚持两条独立基准：τ 中心差分 + 全场方向导数 FD。
2. **证据落盘位置**：上一单 cj1625 作业 succeeded，但结果写进节点 /tmp，取工件只 tar
   仓库目录，数字永久丢失，锚点因此仍 open。本单把结果默认写到仓库内
   `artifacts/adjoint_ootc_acceptance/`，并把验收脚本的 /tmp 默认值改掉。
3. **方向向量标度陷阱（本次实测踩到）**：方向导数检验里 FD 侧把 v 归一化到 |f0|、
   伴随侧用原始 v，比值恰好是 ‖v‖/‖f0‖=6.0，一度被误判成 adjoint 错 6 倍；
   两侧必须用同一个已保存的 v（微小 N 上暴力 Jacobian 证明伴随场误差 2.9e-13）。
4. **目标函数局限**：J 用周期边界 + 终端速度失配，τ 是唯一标量参数；边界参数/
   多参数反演仍在 BPTT 框架外（现可复用 dJ/df⁰ 做初始场反演，但尚未做壁面参数）。
5. **前向轴标签**：streaming 把 EX 滚在 y 轴、EY 滚在 x 轴（D2Q9 在 x↔y 下对称，
   物理不变），伴随与前向共用同一 roll 约定，未改动。

## 6. 误差判定（逐项，是否 <3%）

| 关键量 | 基准 | 误差 | <3%? |
|---|---|---|---|
| dJ/dτ (OOTC, T=10^4) | BPTT | rel 0.000e+00 | 是 |
| dJ/dτ (BPTT, T=10^4) | 中心差分 h=1e-4 | rel 3.362e-06 | 是 |
| <dJ/df⁰, v> (OOTC, T=10^4) | 方向中心差分 | rel 7.693e-11 | 是 |
| 恢复 τ | τ_true | rel 2.000e-01 | **否（未收敛）** |
| J 地形极小点 τ* | τ_true | rel 6.250e-02 | **否（未收敛）** |

**梯度类关键量是否 <3%？** 梯度本身全部 <1e-5（多数 1e-10~1e-16），远优于 3% 判据。

**τ 反演是否 <3%？** 否——本次反演只跑了 12 次梯度下降，
τ 从 1.2 单调降到 0.9600，|Δτ|=0.160
（rel 20.0%），方向始终正确、J 单调下降（见 3.5 与图 3），但**迭代预算不足**，
未收敛到 τ_true。这是反演驱动器的收敛预算问题，不是梯度精度问题：每一步的 dJ/dτ
本身已由中心差分独立验证到 1e-6 量级。诚实结论：τ 反演在本单为 UNFINISHED。
