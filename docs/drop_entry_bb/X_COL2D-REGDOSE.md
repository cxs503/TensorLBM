## 4. 判决（对照预登记）
- **判决：NON_MONOTONIC**（预登记的「peak 随剂量单调升、2×∈[1.60,1.75]D」被**证伪**；证伪判据「任一高剂量臂 peak < 1× 的 1.555257D」触发：reg_d200, reg_d400）
  - 0.5×（τ=0.25019385）：**触稳定性边界**——health_limit @ 0.0365ms（接触前，无接触步），漂移 3.494e-04>1e-4 门、mach_max 0.2956<0.3 门 ⇒ 死于体积漂移而非爆速
  - 2×（τ=1.0007754）：满窗 window_complete，peak 0.250609D（误差 -86.508%，Δ1× -1.304648D = -83.89%），峰时 8.2328ms(pc)，接触后健康 24.005ms，漂移 1.902e-05
  - 4×（τ=2.0015508）：满窗 window_complete，peak 0.129175D（误差 -93.046%，Δ1× -1.426083D = -91.69%），峰时 3.9522ms(pc)，接触后健康 24.005ms，漂移 2.904e-05
  - 对照（引值）：ctrl 1.435220D / 1× REG 1.555257D；⇒ 剂量响应单峰，最优点在 1×（BGK 稳定底），增益 +0.120037D（+8.36%）

## 5. 机制解读
- 剂量响应是**单峰（内点最优）**：最深点在 1×（τ=0.5003877 = BGK 稳定底），两侧都变差——向下 τ=0.25019385<0.5 负黏性（ν/ν₁×=-644.33）立即暴毙（0.0365 ms 接触前、漂移 3.494e-04>1e-4 门）；向上黏性主导、落体变慢（接触步 45→75→244）而空穴变浅（2× 0.250609D，4× 0.129175D）
- 解读：COL2 的 +0.120D 收益来自「贴稳定底时界面振荡阻尼被移除」这一**边缘稳定**效应（BGK τ=0.5004 时 mach_max 0.2598 逼近 0.3 门）；REG 一旦离开稳定底，黏性主导、空穴被压浅 ⇒ 剂量↑≠更强的正则化，而是更黏
- 与 COL2 互补：窗内 τ 是连续旋钮（rr_t4995=1.486759D 落在 ctrl 1.435220D 与 rr_base 1.555257D 之间），窗外两侧本单已量化（0.5× 死、2×/4× 浅）⇒ REG 可用剂量区间极窄，**天花板 ≈ +8~15%**（与 campaign 预登记一致），战场原句「REG 天花板≈8-15%」获独立支持

## 6. 诚实披露
- **本单证伪了预登记预测**（honest-FAIL）：实测为非单调——高剂量臂 peak（0.250609D / 0.129175D）远低于 1× 的 1.555257D，与「单调升、2×∈[1.60,1.75]D」相反；0.5× 触稳定性边界（早死），4× 未触边界但空穴最浅
- 未产出任何比 1× 引值更深的完整臂 ⇒ campaign 3% 精度门未达（最佳完整臂仍为 1× 引值，深度误差 -16.269%、时刻误差 +18.40%）
- 剂量轴与黏性轴在本实现中不可分离（只有 rr_tau 一个通道，禁改实现故未加独立正则化权重参数）⇒ 本单不能回答「纯投影强度」的剂量响应
- 车道与硬件：SDAA（太初卡）32 卡，容器镜像 lbm_test:snap_1114；1×/ctrl 为引值（禁重跑），ctrl 另做一次 planes 复跑仅用于场量图与位级锚核对；planes 复跑臂不参与主判决
- 回归：本机 free-surface/collision 回归 78 项通过 + 1 跳过（含新增 4 项剂量语义测试）；集群账单号 cj6079 rc=0 但集群节点缺依赖致 121 项收集错误（回归结论以本机为准）；仓库既有 test_free_surface_surface_tension.py 收集失败（csf 缺 tanh_droplet_phi，main 上已存在，非本单引入）
