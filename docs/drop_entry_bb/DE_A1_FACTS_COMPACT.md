## 3) 峰值与验收
- **峰值**：最大观测深度 **1.8574 D** @ **10.394 ms**（README L18；CSV 第 11 行 depth_over_D=1.857434、time_ms=10.39446）。
- **≤3% 判据**：相对误差 = |模拟值 − 实验值| / 实验值 ≤ 0.03。① 每时刻时序误差 ≤3%；② 峰值相对误差 ≤3%（README L27）。
- **网格收敛**：至少两档网格，误差严格递减（`require_strictly_decreasing_maximum_point_error: true` 与 `require_strictly_decreasing_peak_error: true`）。
- **Gates**：maximum_each_point_relative_error=0.03；maximum_peak_depth_relative_error=0.03；minimum_grid_count=2；maximum_impact_speed_relative_error=0.03；maximum_liquid_volume_relative_drift=0.0001；maximum_lattice_mach=0.3；time_origin=首连通液桥；coverage=全部正深度观测；impact_speed_measurement=撞前 1 ms 投影轮廓中心位移。
