# T2-P3 处方卡 · 存活修复处方（处方员丙）

## 1. 假设
**H1（主）**：早期死亡（health_limit @~1.36ms）由**近空 INTERFACE 胞原始宏观密度非正**触发——暴力冲击（触水瞬间射流/凹坑）使界面胞 fill→0，`free_surface_probe.py` L127 健康检查读**原始** `macroscopic3d` 密度（`dens[active].min()`），而 solver 内部 `rho_s=clamp(1e-6,3rho)`（free_surface_lbm.py L~860）只保护碰撞路径、不保护诊断路径；近空胞 ABB 重建/平衡产生负种群 → 原始密度 ≤0 → 杀。默认窄 span（4.0D）经壁面伪反射把动量回注入近空界面区，放大该不稳定性。

**H2（次）**：`drift>1e-4`（体积漂移）在暴力冲击期因质量交换（refill）过度激进而超限，独立于密度崩溃。

**H3（次）**：`mach>0.3`（马赫超限）——近空胞速度未钳制时 u=momentum/rho 无界，驱动 f→inf/nan（`TL_FS_INPUT_GUARD` 正是为此设，若被关则触发）。

## 2. 处方
**改什么**（free_surface_probe.py 参数级，最小改动）：
1. **加宽 span**：`--span 6.0`（默认 4.0，L41）——给射流/凹坑更多横向空间，减壁面伪反射回注。**这是已证路径**：`case3_wide8`（宽 span）活到 24.005ms、误差 0.68%（DE_A3_DIAG §2）。
2. **强制 `TL_FS_INPUT_GUARD=1`**（env，默认 True）——钳界面速度至 [-0.5,0.5]、rho 至 1e-6 底，防近空胞无界速度驱动 f→inf/nan。这是第一道防线，须确认未被关。
3. **可选 `--simple-exchange`**（simple_mass_exchange=True）——保守质量交换，避免激进 refill 产生负密度。

**为什么能活过 10.394ms**：宽 span 消除壁面伪反射这一放大因子（H1 机制链的末端），使近空界面胞在暴力冲击期保持有限密度；input guard 兜底速度/rho 无界。两者叠加后界面胞 fill 不再塌到 0，原始密度保持正，`rho_min<=0` 不再触发。

## 3. 预测
- **postcontact_healthy_ms ∈ [20.0, 24.005]**（即达 `window_complete`@24.005ms，覆盖含 10.394ms 峰值的完整 24ms 观测窗）。
- **可证伪判据**：若 postcontact_healthy_ms < 10.394（峰值前死），则 H1 错——根因在质量交换方案而非 span，须转 `--simple-exchange` 或改 refill。
- **误差预期**：峰值深度相对误差 ≤3%（对标 1.8574D@10.394ms，DE_A1 §3），且 ≥2 档网格误差严格递减（protocol.json gates）。

## 5. 风险
- **最可能死点**：即使宽 span，暴力冲击最烈期（触水后 ~1-2ms 凹坑形成）界面仍塌——根因是质量交换方案本身而非 span；此时须转 `--simple-exchange` 或改 refill 方案（H2 升级为主）。
- **次风险**：宽 span 增计算量（更多胞），可能撞 `step_limit`（默认 10000 步）——需确认 24ms 窗内步数够。
- **三风险**：`TL_FS_INPUT_GUARD` 若被某 run 显式关掉（`TL_FS_INPUT_GUARD=0`），本处方失效——须先查该 env 在目标 run 的取值。
- **honest-FAIL**：若两档均未过 3% 或未严格递减，如实报，不粉饰。
