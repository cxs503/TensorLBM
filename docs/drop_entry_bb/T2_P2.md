# T2-P2 处方卡（m26268·GLM）——计算域加宽路线（单变量，不动界面算法/速度）
## 1. 假设
因果链一句话：fsp 默认 span=4D/pool_depth=3D 把侧壁压到 crater 半径约 2 倍内（free_surface_probe.py#probe L50-51：side=span·n、level=pool_depth·n+0.5），触水后 crater-冠缘流场被边界条件畸变、反射压力持续泵入薄冠片，界面质量交换误差被放大 → 触水后 ~1.36ms mach_max>0.3 或 volume_drift>1e-4 触发 health_limit（基线 1.362ms=A3#1；health_limit×5=A3#3）。
依据：实验水槽=40mm 玻璃立方≈17.6D 宽、满水近槽口（A1#1），真实侧壁在 ~8.8D、底在 ~17.6D——fsp 默认域比实验窄 4 倍以上；case3_wide8（8 cells/D，推断为加宽域）存活 24.005ms 且 impact_speed 误差 0.68% 全表最低（A3#1/#2）。
## 2. 处方
改什么：只动域几何，单变量；capacity/nearest/speed 减半是 P1 路线，本卡不碰，便于归因。
- CLI 级（零代码）：--span 8.0 --pool-depth 6.0（默认 4.0/3.0，free_surface_probe.py L251-252）。
- 代码级最小补丁（E1 集成用）：free_surface_probe.py#probe 签名默认 span 4.0→8.0（L41）、pool_depth 3.0→6.0（L42），CLI default 同步（L251-252）。
为何能活过 10.4ms：span=8D 使侧壁退到实验位置 8.8D 附近，pool_depth=6D 使峰值深度 1.8574D（A1#3）下方仍余 >4D 水体；边界畸变/反射在观测窗内不再污染冠缘薄液膜 → 健康四条（mach≤0.3、rho_min>0、drift≤1e-4、depth≥0，A2#3 表）不再被边界项触发；wide8 已实证此路线满窗存活。
## 3. 预测
- postcontact_healthy_ms ∈ [20.0, 24.005]，中心 24.005（满窗）；峰值时刻 10.394ms（A1#3）被覆盖。
- 若落 (10.394, 20.0)：方向对但晚期限速另有其因（飞溅回缩期质量交换），需二诊再定位。
- 可证伪判据：span=8 仍在 <10.394ms 触发 health_limit，且先触发项（mach/volume_drift/rho_min）与 span=4 基线相同 → 边界假说证伪，转向备选假设「薄气膜崩溃质量交换缺陷」（gap_fraction 路线）。
## 4. 成本
步数换算：cells=8、speed=0.04 → dt=speed·dx/U=8.11µs/步（run.py#scales L35-37），24ms 窗≈2960 步+触水前 ~50 步，--steps 4000 足够。
# 对照（复现 1.362ms 基线，可选）
python benchmarks/water_entry/single_drop/free_surface_probe.py --cells 8 --steps 4000 --out /tmp/p2_ctrl.json
# 处方跑（最小判别）
python benchmarks/water_entry/single_drop/free_surface_probe.py --cells 8 --span 8.0 --pool-depth 6.0 --steps 4000 --out /tmp/p2_span8.json
# 判读
python benchmarks/water_entry/single_drop/score.py /tmp/p2_span8.json --output /tmp/p2_span8_score.json; echo exit=$?
算力：域 66×64×64≈27 万格点≈基线 42×32×32 的 6.3 倍，4000 步单线程 <1h；紧张则先 --span 6.0 --pool-depth 4.0（≈11.5 万格点，2.7 倍）取下界。
## 5. 风险
- 命名推断风险：「wide8」语义是推断（A2#1a：fsp 无 width 开关，"wide" 只能落 span/pool_depth），若实为其他组合，本卡退化为纯几何假设，靠 §4 对照+处方跑判别。
- 物理风险：加宽域不消除触水薄气膜崩溃本身的质量交换误差；若死因在界面算法，存活仍 ~1.4ms（即 §3 证伪判据）。
- 成本风险：span=8 单线程墙钟 30-60min，超时降 span=6。
- 协议风险：domain_and_material_match_confirmed=false（protocol.json L40）须 E1 确认后置 true；加宽域是向实验水槽（A1#1）靠拢，与协议不冲突。
## 6. 互读备注（本卡落板后读 P1/P3）
- 与 P3 收敛：P3#2 亦选 span 加宽（6.0）并引 wide8 为"宽 span"实证；P3-H1（近空界面胞原始密度≤0，诊断路径不受 solver rho_s clamp 保护）是本卡 §1 机制的细化，相容。差异：本卡加 pool_depth 3→6D（实验槽深 ~17.6D，A1#1）且坚持单变量归因；P3 要求核查 TL_FS_INPUT_GUARD env——建议 E1 采纳该核查。
- 与 P1 分歧：P1#2 称 wide8 为 span=4.0 下幸存并以其为无开关对照，与 A3#1 矛盾（默认 d8 于 1.046ms health_limit 死；wide8 若=默认配置不可能满窗存活）——"wide"语义须 E1 仲裁；若 wide8 实为 span=4，本卡 §3 证伪判据自动生效。
- 集成建议：P2+P3 同路线可合并判别（span 6 vs 8 两档+guard 核查）；P1 三开关作第二臂独立验证，避免变量混杂。
