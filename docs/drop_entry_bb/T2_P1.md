# T2-P1 处方卡 · 存活修复（自由面·参数标定）

> 战役=DE · 队=T2 黑板队 · 处方官=甲 · 靶子=存活修复处方
> 只读共享事实基座：A1/A2/A3/A4（本卡不读原料，数字可回溯至卡名#节）

## 1. 假设
**一句话因果链**：1.36ms 崩（`case3_cac12` mach_limit / `case3_flux8` step_limit）不是物理撞击本身（撞击速度 1.4 m/s 映射到晶格 `speed=0.04`→Mach≈0.069，远低于 0.3 门），而是**自由面界面处的伪电流/伪速度（spurious pseudo-current）**——质量交换/refilling 不平衡在界面胞产生局部高速射流，把局部晶格 Mach 顶过 0.3（A4#4 已知坑：伪电流 u_max 高于良调锚 5-25×）。

## 2. 处方
**改什么**：`benchmarks/water_entry/single_drop/free_surface_probe.py` `probe()`（L32）——走**自由面**路径（A4 判据 S1 首选，A3 已有 5 个 window_complete 幸存者），做**参数标定**而非改求解器内核。
**怎么改**（三开关组合，直接压伪电流）：
1. `--capacity`（capacity_redistribution=True，L38）——界面胞容量再分配，压质量交换失衡产生的伪速度；
2. `--nearest-surface`（nearest=True，L39）——最近面速度取法，压界面伪速度；
3. `--speed 0.02`（默认 0.04 减半，L35）——把基座晶格 Mach 从 0.069 降到 0.035，给局部射流留 8× 余量（0.3/0.035≈8.6）才触门；
4. 保持 `--span 4.0`（A3 `case3_wide8` 已证 24.005ms/0.68% 幸存）、`--cells 8`（CLI 下限，最便宜）。
**为什么能活过 10.4ms**：峰值时刻 10.394ms 是回缩段（A1 第 11 点 depth 1.8574D），伪电流在触水后 1-15ms 内触发（A3#3），三开关把触发源（界面伪速度）压到门内，使健康检查（mach>0.3 / rho_min≤0 / drift>1e-4，fsp L126-128）不再提前 break，跑满 24ms 窗口。

## 3. 预测
- **postcontact_healthy_ms ∈ [24.0, 24.01]**（window_complete 满窗，A3 幸存者同量级）；
- 峰值 10.394ms 被完整覆盖，`peak_depth_relative_error ≤ 3%`（A1 判据）；
- **可证伪判据**：若 `--capacity --nearest --speed 0.02` 组合仍在触水后 <10ms 触发 `mach_limit`，则伪电流假说被否，真因是分辨率/τ 窗口（A4#4④），改走 `--cells 12` 或 `--simple-exchange`。

## 5. 风险
- **最可能死点**：`--speed 0.02` 使 dt 减半→步数翻倍（24ms 需 ~2× 步），`--steps 10000` 可能不够→`step_limit`（A3 `case3_flux8` 即死于 step_limit）；若如此，把 `--steps` 提到 20000 或改 `--cells 12`。
- **capacity_redistribution 自身漂移**：可能引入新的 `geometric_volume_drift` 超 1e-4 门（fsp L300 退出码 1），需 `--simple-exchange` 兜底。
- **伪电流非真因**：若真因是界面胞膨胀（A4#4⑥，interface 计数随细化恶化），本处方只治标不治本，需改 refilling 方案（EQ→AVG，A4 已修 8.6 点）。
- **honest-FAIL**：若三开关组合仍 <10ms 崩，如实报 `mach_limit`，不粉饰，转交 P2/P3 读友卡后修正。
