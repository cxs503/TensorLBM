Holtrop-Mennen (1984) 是船舶总体性能学科（阻力方向）中经典的**经验阻力预报方法**，由 J. Holtrop 与 G.G.J. Mennen 基于大量船模试验数据回归得到，将总阻力分解为：

```
Rt = Rf(1+k) + Rapp + Rw + Rb + Rtr + Ra
```

- **Rf**: ITTC-57 摩擦阻力，Cf = 0.075/(log₁₀Re − 2)²
- **(1+k)**: 形状因子（Holtrop 回归）
- **Rw**: 兴波阻力（c1~c7, m1, m2, λ 回归）
- **Rb**: 球鼻艏修正
- **Rtr**: 艉封板修正
- **Ra**: 粗糙度/相关补贴
- **Rapp**: 附体阻力

该方法适用于常规商船（Fn ≈ 0.10~0.45，Cb ≈ 0.55~0.85，船长 100~400 m），是工程初估与验证的标准工具。
