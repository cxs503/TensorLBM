## 1 案例介绍（物理背景 / 几何 / 参数表）

LNG 船液货舱在部分充装（10%–95%）航行时，舱内自由液面晃荡会产生壁面冲击压力，是舱壁结构强度（sloshing 载荷）与液位操作限制（filling limit）的直接输入。本节点取二维矩形舱切片作为可控基准：一阶共振频率有 Abramson (1966) 势流解析锚，线性壁压有 Faltinsen & Timokha (2009) 解析律，冲击（非线性）区则有明确的理论失效边界。

| 项目 | 取值（格点单位） | 物理对应（40 m 舱宽切片） |
|---|---|---|
| 舱宽 L | 80 | 40.0 m |
| 静水深 h | h/L ∈ [0.10, 1.00]·L | 4–40 m |
| 气相层高 | 0.35 L | 14 m |
| 重力 g | 0.0005 | 9.81 m/s²，dx=0.500 m，dt=0.0050 s |
| 松弛时间 τ | 0.6 | ν = 0.0333（格点）= 1.65 m²/s |
| 液体/气体密度 | 1.0 / 1.0 | ρ_l 归一，ρ_g 仅作气体压力 |
| 谐摇幅值 X₀ | 0.010 L（压力扫描）/ 0.015 L（波形对比） | 0.40 m / 0.60 m |
| 对应一阶共振频率 f₁(h/L=0.5) | 0.000675 | 0.1338 Hz |
| 采样 | 每周期 250 帧 | 自由衰减 5 周期；强迫 16 周期（后 40% 取稳态窗） |

**物理量的无量纲化**：频率 `f/√(g/L)`，压力 `p_max/(ρ g h)`（压力水头/水深），液面升高 `η/h`。这样不同充装率与网格分辨率下的结果可同图比较。

注：格点粘度映射到物理粘度 ν≈1.7 m²/s，远大于水的 1e-6 m²/s（等效 Re 仅 ~6.1e-07 倍水的量级），因此本模型的数值阻尼（实测 ζ≈0.06）明显大于真实水的 0.005–0.01：**共振幅值与共振压力被系统性低估**，是本次结果的第一位局限（见 §5）。

## 2 方法（怎么做的）

### 2.1 求解器：Körner 自由液面 LBM（复用已审计实现）

自由液面追踪采用仓库已审计的 Körner (2005) 自由液面模型 `tensorlbm.free_surface_lbm_2d.koerner_step_2d`：单元分类 GAS/LIQUID/INTERFACE/SOLID、独立质量账本 m（fill ε=m/ρ_l）、界面 anti-bounce-back 气体压力重构、流体侧半程反弹壁、Körner 式质量交换与转换包络。本节点只在其上新增「液舱层」（`lng_sloshing/tank.py`）：矩形舱几何（底+两侧壁固体，顶部定压气相）、子格精度自由液面初值、静水压力预置初场（ρ(y)=1+3g(h−y)，消除启动声波）、舱体平动等效惯性体积力 gx(t)=X₀ω²sin(ωt)、以及两类测量面。

### 2.2 激励与测量

- **自由衰减**（判据①）：初值 η(x,0)=A cos(k₁x)，A=min(0.02L, 0.10h)，零速度；记录一阶模态坐标并对时间做最小二乘周期图（含多项式冗余项，抑制质量账本慢漂移）得 f₁；同一记录用分窗衰减拟合得阻尼比 ζ。
- **强迫谐摇**（判据②③）：定幅 X₀ 正弦惯性力，稳态窗内做频率 ω 的谐波最小二乘拟合；一阶升幅 η₁ 取**液面场的截尾余弦投影**（去掉贴壁 2 列，避开壁面挂液假象），x 质心测量作独立交叉校验。
- **壁面动压**：动压表 p=c_s²(ρ−ρ̄)，取壁面首两列流向线性外推到壁面 x=0；4 个测深 y=0, −0.1h, −0.3h, −0.6h（相对静水面）。判定用固定基准表 y=−0.1h（冲击带），静水面表 y=0 单独作为**冲击峰值**指标（该表格周期性露出，其峰值是真实冲击尖峰而非线性幅值）。

### 2.3 解析锚（REAL，闭式）

- **Abramson (1966) NASA SP-106**：ωₙ² = g kₙ tanh(kₙ h)，kₙ = nπ/L；给出 f₁、f₂ 及浅水/深水极限（k h→0 得 ω=k√(gh)；k h→∞ 得 ω=√(gk)），单测检验。
- **线性强迫响应**：一阶模态方程 η̈₁+ω₁²η₁ = β₁ a_x，β₁=4tanh(k₁h)/π，得 |η₁| = X₀ω²β₁/√((ω₁²−ω²)²+(2ζω₁ω)²)。
- **线性壁压律（本节点修正版）**：p/(ρg) = |tilt + modal·e^{−iφ}|，其中modal = |η₁|(ω²/ω₁²)cosh(k(y+h))/cosh(kh)，tilt = X₀ω²L/(2g)，φ = atan2(2ζr, 1−r²)，r=ω/ω₁。**这两项（惯性倾斜项与相位）是本次用 LBM 对撞解析模型时发现的缺失项**：只写 modal 项会使低/高频比下的壁压低估 2–4 倍（详见 §5）。
- **Wagner (1932) 驻点压力界** p=½ρV²：以实测液相最大水平速度给出冲击压的上界量级对照。

### 2.4 工具链与并行

- 20 个算例（10 个充装率 + 7 个频率比 + 1 个波形 + 2 个网格收敛）各自独立 JSON：`python -m tensorlbm.lng_sloshing.campaign run --shard i/20`。

- 汇总/作图：`campaign summarize`（读算例 JSON → 判据 → 3 张图 → `campaign_report.json`）。

## 5 注意点（踩过的坑 / 局限 / 适用范围）

1. **解析壁压律最初写错了两处，是 LBM 对撞发现的**：(a) 缺少惯性/准静态倾斜项 ρa_x L/2（来自 Bernoulli 方程中 a_x(x−L/2)，由体积守恒定原点）；(b) 缺少两项之间的相位差 φ。只保留 modal 项时，低/高频比下壁压被低估 2–4 倍（r=1.2 实测 1.74 格水头，错版理论给 3.75，修正后 2.12，实测/修正 = −18%）。修正版已固化进 `abramson.py` 并由单测锁定静态与反相极限。
2. **模态测量的两个陷阱**：(i) 贴壁首列存在挂液假象（约 0.5–0.8 格液体滞留），且 cos(kx) 在贴壁处最大，未截尾的投影会被它污染 → 所有模态投影现在都截掉两侧 2 列；(ii) 小振幅下（η₁<1 格）转换抖动使投影信噪比降到 ~1，最初把 r=0.6 的幅值拟合成了 8.2 格（真值 0.54）——原因是谐波拟合里加的多项式冗余项与低频正弦几乎共线；改为固定幅值加倍（X₀=0.01L）+ 场投影 + 无冗余项后恢复。x 质心测量只对奇数空间模态敏感，用作交叉校验。
3. **阻尼拟合**：全局 Hilbert 包络 + 多项式去趋势会把强阻尼指数衰减的 ζ 低估 30% 以上（合成数据检验：真值 0.06 → 0.039）。现改为分窗最小二乘幅值 + log 线性拟合，合成算例 10% 内。
4. **数值阻尼是关键局限**：τ=0.6 → ν=0.033 格点，实测 ζ≈0.06（深充装）/0.13–0.35（浅充装），比真实水的 0.005–0.01 大一个量级。后果：(a) 共振幅值/压力被低估；(b) 浅充装共振频率偏低（h/L=0.1 时 −24%）。真实 LNG 舱的共振响应会显著强于本模型给出的量级。
5. **共振区不能当稳态看**：r=1.0 时模型在 16 周期内基本到达平台（窗口增长 −1%），但静水面表峰值 0.618 与基准表 0.524 相差 18%，说明冲击尖峰对测点位置极敏感——冲击压力是局部量，网格尺度 0.5 m 下不能作为结构设计载荷绝对值使用。
6. **反相区灵敏度**：r>1.2 时 modal 项与 tilt 项接近反相抵消，预测对相位/ζ 极敏感，相对偏差可达 −35%（r=1.4），这是物理上的近抵消而非求解失败。
7. **适用边界**：二维、单舱切片、无舱内构件/无弹性壁、气相加定压（忽略气体惯性）；线性区（η₁/h ≲ 0.1，ω/ω₁ 远离 1）定量可信；冲击区只能给量级与趋势。
