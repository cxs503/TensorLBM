# 涡识别判据的解析基准验证（Q / λ₂ / Ω）

**对象**：`src/tensorlbm/vortex_identification.py`（Q-criterion、λ₂-criterion、Ω-criterion，2-D/3-D）
**任务**：m4761 自找活（验证欠账类）——该模块此前只有随机场烟雾测试（shape / 符号检查），
没有任何对解析解或文献基准的定量复核。
**结论**：三个判据全部通过 Lamb–Oseen 解析基准复核，网格收敛**二阶**，
n=128 时 Q 场 L∞ 相对误差 0.39 %、涡核半径误差 0.24 %（判据：<3 % → 通过）。
3-D 路径（batched 特征值）n=96 时 Q 误差 0.69 %；过程中发现并修复一个**量纲缺陷**：梯度差分硬编码单位网格，`dx≠1` 时 Q/λ₂ 幅值偏差 `1/dx²`
（n=128, h=0.0625 的实测偏差因子 1/h² ≈ 256，即 30.7 倍的场幅值误差 → 修复后为 0）。

---

## ① 案例介绍（物理背景 / 几何 / 参数）

涡识别判据是船体尾流、桨梢涡、船体-附体分离涡分析的标准后处理工具
（PowerFlow / Fluent / OpenFOAM 均提供 Q、λ₂、Ω 三种判据）。本验证采用
**Lamb–Oseen 黏性涡**作为基准解：它是 Navier–Stokes 方程的精确自相似解，
也是尾涡/梢涡的经典解析模型（Oseen 1911；Lamb 1932），且它的
速度梯度不变量有闭式表达，因此可以逐点检验判据实现。

切向速度（取环量归一 `Γ/2π = 1`、涡核半径 `r_c = 1`）：

```
u_θ(r) = (Γ / 2π r) · (1 − exp(−r²/r_c²)) ,   u_r = u_z = 0
```

参数表：

| 量 | 取值 | 说明 |
|---|---|---|
| 涡核半径 `r_c` | 1（长度单位） | 归一化，`x = r²/r_c²` 为相似变量 |
| 环量 `Γ` | 2π | 归一化为 `Γ/2π = 1`，于是 `max Q = 1`、`max u_θ = 0.638 r_c·ω₀` |
| 计算域 | 8 r_c × 8 r_c 方形 | 边界上解析 `|Q| ≤ 3.97e-3`（<0.4 % 峰值），边界影响可分辨 |
| 节点布局 | 单元中心（offset 网格） | 避免节点落在 `r=0` 的 `0/0` 奇点 |
| 网格 | n = 32 / 64 / 128 / 256 / 512 | h/r_c = 0.25 → 0.0156 |
| 3-D 检验 | 96² × 8（z 向周期挤出，L_z = 2 r_c） | 检验 3-D 特征值路径 |

## ② 怎么做的（方法 / 流程 / 工具链）

1. **解析不变量推导**（本报告独立推导，未取自实现）。设 `x = r²/r_c²`：
   ```
   ω_z/2 = e^{−x}                                   （涡量）
   s = S_rθ = [(x+1)e^{−x} − 1] / x                  （应变率）
   Q = ½(‖Ω‖² − ‖S‖²) = e^{−2x} − s²
   λ₂ = −Q                                           （圆涡：两特征值相等）
   Ω_Liu = ω² / (ω² + s² + ε)
   ```
   Q 的两个解析特征点（本验证的标量验收量）：
   - `Q = 0` ⟺ `(2x+1)e^{−x} = 1` ⟹ **r_Q = 1.120906 r_c**（二分法求根，200 次迭代）
   - `Ω_Liu = 0.52`（Liu et al. 2016 阈值）⟹ **r = 1.106100 r_c**
2. **数值侧**：把 `u_θ` 采样到节点 → 转 `torch.Tensor` → 调用被验证模块的
   `q_criterion_2d / lambda2_criterion_2d / omega_criterion_2d`（2-D）与
   `q_criterion_3d / lambda2_criterion_3d / omega_criterion_3d`（3-D，含 batched
   `torch.linalg.eigvalsh` 特征值路径），统一传 `dx = dy = h`。
3. **误差度量**：只统计去掉 1 层边界环的内部节点（边界环无单侧差分，见 ⑤）；
   场误差用 `‖e‖∞ / max|Q|`（Q 在 `r→0` 处为有限值 1、在 Q=0 附近有对消，
   纯局部相对误差会放大，故用峰值归一）；另用 L2 范数交叉印证。
4. **标量验收**：沿 y≈0 的节点射线对 Q、Ω 场做线性插值求过零点/过阈值点，
   与解析半径比。
5. **收敛阶**：相邻两套网格误差比 `p = log₂(e(h)/e(h/2))`，与 `O(h²)` 参考线（中心差分）比对。
6. **工具链**：`torch 2.7.1`（CPU）、`numpy`、`matplotlib`（Agg）、`pytest`（`tests/test_vortex_identification_analytic.py`，10 项）；
   一键复算脚本 `scripts/verify_vortex_identification.py` → `artifacts/vortex_identification_verification/{table.json,fig1_q_field_profiles.png,fig2_convergence.png}`。
   全部为轻量算例（最大 512²）——本机 load15 ≈ 124（>100），故只做轻量验证活，未起重算力作业。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **已修缺陷：网格间距缺失**。修复前 `_velocity_gradients_2d/3d` 只差分成 `(…) / 2`，
   隐含 `dx=dy=dz=1`。Q、λ₂ 量纲为 `1/time²`，物理网格上幅值会整体错 `1/h²`
   （h=0.0625 时 256 倍）。本次给全部 8 个公开函数与 2 个 wrapper 增加
   `dx, dy, dz`（默认 1.0，**向后兼容**：平台 API 的 LBM 格点单位场 dx=1，行为不变）。
   验收见上表 `dx_scaling`（rel_dev = 0）。
2. **边界环无梯度（已知局限，未改）**。中心差分在首/末行（3-D 为边界壳）保留零梯度，
   该环 Q=0、λ₂=0、Ω=0。本验证算例中边界解析 `|Q| ≤ 3.97e-3`（<0.4 % 峰值），
   故对收敛结论无影响；但**若涡核与边界相交**（尾流出口、贴壁涡），该环局部误差可达 100 %。
   建议用场时只统计到边界内 1 层；如需修，改为单侧差分属独立改动（会改变现有 API 数值），
   列为后续项而非本次范围。
3. **2-D λ₂ 取较大特征值、3-D 取中间特征值**。平面流嵌入 3-D 时 `A = S²+Ω²` 的第三个
   特征值为 0，二者在圆涡（两特征值相等 = −Q）上一致（实测 `‖λ₂+Q‖∞/max|Q| = 8.6e-5`），
   但在一般平面流（两特征值异号）下 2-D "较大" 与 3-D "中间" 语义不同，跨维度比较 λ₂ 需注意。
4. **Ω 判据的 ε 稳定项**。实现中 `ε = 1e-5·max(‖S‖²+‖Ω‖²)`，故与无 ε 解析式对照时
   残余偏差 ~1e-3 量级（上表 `‖Ω−Ω_ex‖∞` 已含此项），不随网格继续下降符合预期。
5. **适用面**：结论覆盖光滑解析场（无固壁/无多相界面）。真实 LBM 场含噪声与掩膜，
   判据阈值（`Q>0`、`Ω>0.52`）对噪声敏感，阈值选择仍需案例标定。
6. **网格-物理对应**：Lamb–Oseen 是黏性衰减涡，本验证只检验**瞬时**场判据；
   时间推进中的涡量衰减 `ω₀(t)= Γ/(4πνt)` 不在本次范围。

## ⑥ 误差判定（关键量 vs 基准，逐项回答"是否 <3%"）

| 关键量 | 基准 | 误差（n=128，主验收网格） | <3 %？ |
|---|---|---|---|
| Q 场（L∞/max\|Q\|） | Lamb–Oseen 闭式 | 0.39 % | **是** |
| Q 场（L2/max\|Q\|） | 同上 | 0.036 % | **是** |
| λ₂ 场 vs −Q 恒等式 | 圆涡解析恒等式 | 8.6e-5（相对峰值） | **是** |
| Ω 场（L∞） | Liu 闭式（含 ε） | 1.7e-3（绝对） | **是** |
| Q=0 涡核半径 `r_Q` | 1.120906 r_c | 0.24 % | **是** |
| `Ω=0.52` 涡核半径 | 1.106100 r_c | 0.077 % | **是** |
| 网格收敛阶 p | 中心差分理论值 2.0 | 2.00（256→128 段） | **是**（=理论值） |
| 刚体旋转 Q = ω₀² | 闭式 2.8900 | 3.3e-15 相对 | **是** |
| 纯应变 Q = −a² / λ₂ = +a² | 闭式 ∓1.6900 | Q: 4.4e-15, λ₂: 1.2e-8 相对 | **是** |
| 3-D 轴对称 Q（n=96, nz=8） | Lamb–Oseen 闭式 | 0.69 %（L∞/峰值） | **是** |
| 网格间距标度 `Q(1)/Q(h)` | `h²` | 相对偏差 0.0 | **是** |

唯一超标项：**漏传 `dx` 时**的场幅值（h=0.0625 下低估 256 倍）——这是被本次修复的缺陷本身，
修复后（默认 `dx=1` 的 LBM 格点单位语义不变）不再出现。
