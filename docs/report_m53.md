## 1. 案例介绍

Mission 53 执行 SDAA（Hygon DCU 加速卡）验证案例扫荡，核心目标：

1. **cylinder_3d**（`benchmarks/verified/cylinder_3d`）：3D 挤出圆柱绕流 Re=40，对标 Dennis & Chang 1970 / Fornberg 1985 二维数值基准 Cd≈1.50。
2. **KBC 16-cube 诊断**：16³ 立方体顶盖驱动流，对比 BGK 与 KBC 碰撞模型的 Cd 收敛行为。
3. **SUBOFF 三基准扫荡**：B1 Cumulant Re=1000、B2 RANS k-ε Re=10⁵、B3 RANS k-ε Re=10⁴。

m20 里程碑报告 cylinder_3d 三项指标全部 FAIL：G1 误差 +6.62%、G2 误差 +16.25%（超过 15% 不可接受红线）、G3 网格跨度 9.62%。本任务对失败进行根因诊断并给出绕行方案。

## 2. 方法

### 2.1 诊断流程

1. **提取 m20 失败证据**：从 `result.json` 程序化读取 G1/G2/G3 数值，零手抄。
2. **口径对比实验**：在同一验证基准（D20/D40 网格、40000 步）上，分别提取 `cd_mem_surface`（仅表面积分）与 `cd_mem_all`（含内部伪力）两种口径的 Cd。
3. **SDAA 新鲜运行**：D=10、320×320×1、2000 步快速收敛测试，验证 SDAA 设备上求解器稳定性。
4. **编译路径审计**：确认 SDAA 上 `teco_inductor` 后端不完整，自动回退 eager 模式；cylinder_3d 不使用 Triton 内核。

**发现**：

## 5. 注意点

1. **口径选择至关重要**：`cd_mem_surface`（表面积分）vs `cd_mem_all`（含内部伪力）可导致 3~9% 的 Cd 差异。所有阻力验证必须使用 `cd_mem_surface`。
2. **SDAA 编译回退**：`teco_inductor` 后端对完整 LBM 步链支持不完整，自动回退 eager 模式。当前不影响数值精度，但性能未优化。
3. **Triton 无依赖**：cylinder_3d 基准不使用 Triton 内核，纯 PyTorch 操作。
4. **RANS k-ε 壁面函数缺失**：B2/B3 的摩擦阻力严重低估源于缺少壁面函数，近壁网格分辨率不足。
5. **KBC 需更严格验证**：16³ 网格 + 20 步远不足以评估 KBC 碰撞模型，需在更细网格（≥64³）和更多步数（≥10000）下重新验证。
