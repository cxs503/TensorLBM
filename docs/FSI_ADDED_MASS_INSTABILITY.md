# P49-N02 · TensorLBM 流固耦合附加质量不稳定性定标

1D 解析收敛因子 · Aitken/IQN-ILS 稳定化 · 轻质浮体负控 · 稳定域图

## ① 案例介绍

分区(partitioned)流固耦合在每个时间步用子迭代求界面不动点。当结构质量与流体附加质量同量级时,显式(Dirichlet-Neumann)子迭代的误差传播因子趋近或超过 1,出现**附加质量不稳定性**(Causin-Gerbeau-Nobile 2005)。本节点把该不稳定性的判据变成可复算量:

$$
\rho_{dd}=\left|1-\omega\,c_a\,\frac{\rho_f}{\rho_s}\right|,\qquad c_a=\frac{A}{\rho_f V}
$$

其中 `c_a·ρ_f/ρ_s = A/m_s` 为附加质量与结构质量之比,`ω` 为松弛因子(ω=1 即显式)。稳定判据 `ρ_dd<1 ⇔ ρ_s/ρ_f > ω c_a/2`;临界密度比 `(ρ_s/ρ_f)_cr = ω c_a/2`。

几何与参数:

| 项目 | 值 |
|---|---|
| 流体 | D2Q9 BGK, ρ_f=1, τ=0.55(稳定性研究)/0.51(自由衰减), float64 |
| 域 / 刚体 | 周期方盒 48×48,圆盘 R=6(截面面积 V=πR²)| 
| 自由度 | 1(垂荡),弹簧刚度 C=2.0,耦合窗口 window=10 LBM 步 |
| 密度比 | ρ_s/ρ_f ∈ {0.1, 0.5, 1.0}(m_s=ratio·ρ_f·V)| 
| 测得的界面附加质量算子 | c_a=0.9515(window=10)| 
| 子迭代 | ω=1 显式 / Aitken 动态松弛 / IQN-ILS(5 对历史)| 

## ② 方法与工具链

1. **1D 解析锚**:实现活塞/气球型 1-DOF 线性附加质量界面模型的伪时间(增量)不动点
   `v^{k+1}=v^k+ω(I(v^k)+I_ext)/m_s`,`I(v)=-A(v-v^n)+I_0`;其误差放大因子恰为上式。
   数值侧用**步进增量序列** `d_k=|v^{k+1}-v^k|` 估计 ρ_dd(比值几何平均 + 对数线性拟合斜率)。
2. **2D LBM + 1-DOF 升沉刚体**:复用 `tensorlbm.moving_boundary_2d.MovingDisk`(动量交换反弹),`window=10` 步的壁面冲量作为界面力;每个子迭代从窗口起点的流体状态重新求解(快照克隆,非 JSON 往返),
   使不动点映射确定且无状态污染。
3. **稳定化**:Aitken `ω_k=-ω_{k-1} r^{k-1}·Δr/|Δr|²`;IQN-ILS 用 5 对 (Δr, Δx) 历史做最小二乘割线,`Δx=-W c`,`c=argmin‖V c-r‖`,SVD 截断滤波。
4. **物理不变性**:三条独立通道——(A) 同网格势流 Laplace 解 `A=ρ∫|∇ψ|²`;(B) LBM 冲量算子随窗口长度的序列;(C) 稳定化耦合自由衰减识别 `ω,ζ,A=C/ω²-m_s`。
5. **稳定域**:`ρ_s/ρ_f × ω` 二维扫描,以 ρ_dd=1 插值交点定边界,与解析线比较。
6. 工具链:`pytest` 20 项、全部脚本化(`scripts/fsi_added_mass_{campaign,invariance,figures,report}.py`),重计算以 8 进程并行(单机 128 核)执行;外协方双节点集群当次 GitHub 检出不可达(GitHub 443 超时),未能投递,如实记录。

## ⑤ 注意点 / 踩过的坑

1. **IQN-ILS 割线步长写错会假收敛/假发散**:首版实现写成 `Δx=r-Wc`(c 解 `Vc=-r`),对线性标量映射给出放大因子 `λ+2`(λ=-0.95 → 1.0485,实测 1.0485)。正解为 `Δx=-Wc`,`c=argmin‖Vc-r‖`;修正后线性映射 2 次迭代精确收敛(pytest `test_iqn_ils_secant_is_exact_for_linear_map`)。
2. **两种不动点形式的放大因子不同**:增量(伪时间)形式 `1-ωA/m_s`(本报告的解析式);把结构自身惯性写进残差的残差形式 `1-ω(1+A/m_s)`(教科书 DN 值)。两者临界密度比差 2 倍(`ωc_a/2` vs `c_a`),混用会把稳定性判据弄错。时间精确耦合(自由衰减)必须用残差形式,子迭代不加 Aitken 时 ρ_dd≈0.9,12 次迭代仍差 30%,会产生**虚假能量注入**。
3. **自由衰减反演失效的主因是界面力算子而非声学**:把 ω 降到 ωL/c_s=0.38(近不可压)后反演 c_a 反而升到 3.46(见通道 D),说明污染来自动量交换壁面力的**数值阻抗分量**(与窗口长度同量级增长:窗口 10/20/30/40 的算子 c_a=0.95/1.50/1.78/1.91,见通道 B),而不是声学(ωL/c_s≫1 只是叠加因素)。因此本工作把 LBM 冲量当**界面算子**标定(与稳定性理论自洽),不当作连续介质附加质量;要得到物理附加质量需按加速度/速度双分量拟合(受迫振荡)或改用压力积分力。
4. **MovingDisk 的全局密度重整**是显式数值储层(其 docstring 已声明),会给冲量叠加非势流分量;因此本工作把 LBM 冲量当**界面算子**标定(与稳定性理论自洽),不当作连续介质附加质量。
5. **性能**:`torch` 默认多线程在此规模反而线程颠簸,`torch.set_num_threads(1)` 提速约 20 倍;子迭代必须用张量克隆而非 `snapshot()`(toList/JSON 往返占总耗时 90%)。
6. **适用范围**:结论针对低 Mach(≤0.05)、单自由度垂荡、刚性圆盘、周期方盒;细长体/自由面/强涡脱落未覆盖。
