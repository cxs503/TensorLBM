# CASE LBM · 圆管 Graetz 入口段 Nu(x*) 独立物理验证（L3 自评）

**锚点** `KPI-LBM-VERIFIED-CAPS` ｜ **仓** TensorLBM ｜ **工件** `benchmarks/verified/graetz_tube/`
（`prereg.json`, `study.py`, `reference_series.py`, `result.json`, `figures/fig1_nu_and_error.png`,
`figures/fig2_field.png`）｜ **测试** `tests/test_graetz_tube_verified.py`

## ① 案例介绍
常壁温圆管内充分发展层流（u/u_m=2(1−ρ²)）的入口段换热：无量纲
`Θ=(T−T_w)/(T_in−T_w)`，`x*=αx/(u_mD²)`，局部 `Nu(x*)=−2(∂Θ/∂ρ)|₁/Θ_m`，
`Θ_m` 为 cup-mixing 温度。物理意义：验证 D2Q5 对流-扩散算子在**轴对称为源项**的
笛卡尔 (x,r) 表达下的稳态精度——这是 CHT 阶梯（`cht_ladder.G8`）唯一没有外部参考的锚。

参数：u_m=0.05、α=0.03（τ=0.59）、T_in=1、T_w=0、站位 x*∈{0.002,0.005,0.01,0.02,0.04}，
两级 n_r∈{40,56}。d 域长按 x* 固定（n_x=456/862），步数至周期稳态。

## ② 怎么做的
- **参考独立化**：`reference_series.py` 自写 RK4 求特征函数、以 Sturm–Liouville 权
  ρ(1−ρ²) 求系数（C=1.4764,−0.8061,0.5888,−0.4759,0.4050,…），仅输入文献特征值
  λ_n（Chandrasekhar 1961；Shah & London 1978）与 Nu_∞=λ₁²/2=3.6568。
  与库内 `graetz_exact`（自有打靶特征值）差 0.056%，与库内 `graetz_marching`（径向 FV +
  Crank–Nicolson）差 <0.4% → 三路互证。
- **两级加密**：同物理参数、同 x* 站位，n_r 40→56。
- **几何约定对照**：`orig`（库现行：速度剖面 R=n_r−1、壁面 anti-bounce-back 半格外）
  与 `reff`（R_eff=n_r−0.5 一致几何）同算子并列。
- **预注册**：参考/站位/阈值/判决规则在细档开跑前落盘；降档 amendment 如实记录。

## ⑤ 注意点 / 局限
- 两条约定**都**满足 G1+G2：原假设「库现行几何属两误差抵销、应改 R_eff」被概率化结果否定
  （orig 误差随加密单调变小 → 非抵销对），故**不改库源码**；结论是伪假设。
- 仅两级、无观测收敛阶；x*=0.002 入口站（边界层 ~2–3 格）reff 2.76% 仍 >3%，已披露不设门。
- orig 在 x*=0.002/n_r=56 出现 0.002% 单站抵销，不可读作精度。
