## 1. 案例介绍

### 1.1 物理背景

LNG 船在部分充装工况下，液货舱自由液面的低阶驻波（sloshing）与船体运动耦合：激励频率接近舱液一阶固有频率时发生共振，液面爬高、卷破并在舱壁产生冲击压力（slamming），是液舱结构疲劳与围护系统（membrane）强度校核的载荷来源。本节点验证的正是**共振频率**与**壁面冲击压力峰值**这两个工程载荷链上最上游的物理量。

### 1.3 解析锚（REAL，闭式）

Abramson (1966, NASA SP-106 §2) / Faltinsen & Timokha (2009, eq. 4.13) 矩形舱驻波：

```
k_n = n·π/L,   ω_n² = g·k_n·tanh(k_n·h),   f_n = ω_n/(2π)
```

> **注意（任务书公式勘误）**：节点书写的 `f_n=(n/2L)·√(g·tanh(nπh/L))` 量纲不为频率（量纲 L^-1/2 T^-1）。与本式等价且量纲正确的写法是 `f_n=(n/2L)·√(g·L/(nπ)·tanh(nπh/L))`。`theory.abramson_brief_formula()` 实现了后者，并在 `tests/test_sloshing_resonance_p87w2.py::test_abramson_frequency_matches_brief_formula_and_known_value` 中断言两者在 1e-12 相对误差内相等——判据 (a)/(b) 一律以 ω_n²=g k_n tanh(k_n h) 为准。

线性自由衰减解（判据 (c) 的参考）：`η(x,t)=A·cos(k_n x)·cos(ω_n t)`，即在 t=T/4 处过零、t=3T/4 处**向上**过零（本实现的相位判据正是与这一过零栅格对齐）。壁面动压振幅（相对静水静压场）：`|p_dyn(y)| = ρ g a·cosh(k_n(y+h))/cosh(k_n h)`，在静水线取 ρ g a，舱底为其 1/cosh(k_n h) 倍。

## 2. 怎么做的

### 2.1 求解器与自由液面模型

物理核复用仓库已审计的 Körner 自由液面 LBM（`tensorlbm.free_surface_lbm_2d.koerner_step_2d`）：独立质量账本 m(x)、反对称反弹（ABB）气相压力重构、半程壁面、Thürey 单元转换；本节点只加**液舱层**（`tensorlbm.sloshing_resonance.tank2d`），不改核。与既有 `sloshing_tank`（两相颜色梯度 + 受迫）、`lng_sloshing`（1:1 格子单位 + 受迫摆激励）的差别是：本包用 **SI 锚定的 Froude/Mach 一致标定**、**单模态自由衰减释放**（一阶与二阶）、**阻尼感知的识别量**（f_d、ζ、f_n）与**相位判据**，因此是新的验证面而不是重复既有算例。

### 2.2 格子标定（GCI 的前提）

固定格子速度 `u_lat = u_char·dt/dx`（u_char = 一阶模态静水线水平速度 A·ω₁·coth(k₁h)）：网格加密时 dx、dt 同步减半，Froude 数与格子 Mach 数保持网格无关。基础网格 Δx = H/40、dt = 0.012500 m / 0.0020·dx/u_char；弱可压比 3g h/c_s² ≤ 0.005（远小于 1，避免了 LBM 重力波常见的可压缩频移）。

### 2.3 初始条件与测量

列向充装分数由 `η(x,0)` 直接给出（亚格子），单元标记含一胞界面包络；密度场按静水关系 `ρ(y)=ρ₀(1+3g(H_col−y))` 预处理，抑制首声学瞬态。测量量：

- 自由液面 **列液高**（Körner 质量账本求和，亚格子精确，壁面 2 列做投影修剪以剔除壁面薄膜假象）；
- 模态幅值 `a_n(t)` 与壁面动压规 `p_dyn = c_s²(ρ−ρ_ref)`（前两列线性外推到壁面）；
- 液体存量账本（质量守恒判据）。

识别（`sloshing_resonance.identify`）：向上过零求阻尼周期 T_d；极值包络对数线性拟合求 λ；由阻尼振子关系 `ω_n=√(λ²+ω_d²)` 得**无粘固有频率 f_n**，`ζ=λ/ω_n`。同时给出 FFT 峰值作为独立交叉检查，以及**首周期**相位误差（累计相位漂移单列诊断，不参与判据）。

### 2.4 为什么壁面取 free-slip

Abramson 锚是无粘势流解，而格子 BGK 的粘性远大于水（格子 ν 由 τ 定，物理 ν 可达 1e-3 m²/s 量级）：**无滑移壁面边界层会把共振频率系统性拉低**。实测（同算例 h=0.20 m、τ=0.502、4 周期）：无滑移 f_d = 0.6406 Hz（-2.84%）、ζ = 0.0196；自由滑移 f_d = 0.6471 Hz（-1.86%）、ζ = 0.0023。因此判据在自由滑移（无粘极限）下评估，无滑移作为**粘性敏感性**单独报告——两者都如实给出，不做取舍性隐藏。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **格子粘性远大于水 ⇒ 自由衰减必然过阻尼**。τ=0.55 时 ζ≈0.14、f_d 偏低 6.6%；τ=0.502 无滑移仍有 ζ≈0.02。Körner 模型的耗散主要来自壁面边界层与界面重构，不能当作水的粘性读。
2. **无滑移壁面会系统性拉低共振频率**（本次实测约 −3%），而 Abramson 是无粘解；判据必须在无粘极限（free-slip）下评估，否则用数值粘性去对抗解析无粘解，结论没有物理意义。
3. **相位参考系容易错**：`η=A cos(ωt)` 从**幅值最大**出发，向上过零在 3T/4、7T/4 …；首版误用 T/4 栅格导致相位误差算成 180°（见 git 历史），已修正为 (4k−1)/4f。
4. **列液高必须用质量账本**，不能除以物理密度 ρ=1000：账本是格子密度单位，除以 ρ 会把液高缩小三个量级（首版就踩了，导致模态幅值≈0、频率识别退化）。
5. **壁面液膜假象**：Körner 模型在壁面留有一层薄液膜，而 cos(k x) 在壁面取极值，模态投影必须在壁面修剪若干列（本实现 trim=2），否则投影被液膜污染。
6. **弱可压比 3g h/c_s²** 必须远小于 1（本算例 ≤0.005）；否则 LBM 的重力波会出现与可压缩性同阶的系统频移。u_lat 与 τ 的选择直接决定该比值与每周期步数（成本 ∝ 1/√(g_lat)）。
7. **判据 (d) 不能闭环**：仓库内没有 Faltinsen 实验数据的数字化件，节点纪律禁止伪造，故如实记为 WITHHELD，而非填一个漂亮的误差百分数。
8. **适用范围**：小/中幅（A/h ≲ 0.1）、层流、二维、闭舱恒压气垫；不覆盖卷破、飞溅、气垫压缩与三维横向模态耦合。
9. **g→0 负控的正确读法**：无恢复力时液面不振荡（0 次变号），但界面会**单调松弛**（峰峰变化达 0.44–0.53 A₀，纯扩散、非振荡）。若直接用峰峰值当判据会误判成「有振荡」；本实现用「去三次趋势后的残差 + 变号次数」分离两者。
10. **最浅充装欠解析**：h/H=0.2（h=0.10 m）在基础网格只有 8 个水层，壁面液膜与修剪列占比过大，相位初相偏到 4.8°（h/H≥0.4 时 ≤1.4°）。要覆盖 20% 充装需加密到 H/80 以上。
11. **强非线性工况越界**：共振大幅算例的格子马赫可达 0.2–0.7、液面可触顶，此时自由液面账本的精度下降（质量漂移 0.4%→1.6%）、压力峰值不可作定量证据。这类工况只能用于「是否出现冲击」的定性判断。

**是一阶共振频率在所有充装率下误差 < 3%**（最差 +2.70%，h/H 覆盖 20%–90%）。

## 8. 结论

1. 在 1.0×0.5 m 矩形舱、20%–90% 充装、A=0.01 m 单模态释放的验证面上，Körner 自由液面 LBM 的一阶共振频率与 Abramson 解析解最差偏差 **+2.70% < 3%**，二阶 **+4.26% < 5%**，三套网格 f₁ 散布 **0.80% < 2%**：频率面判据 (a)(b)(e) **通过**。
2. 质量账本在校验集（自由衰减 + 负控）最大漂移 **0.494% < 0.5%**；近破碎冲击工况漂移至 **1.57%**，判据 (f) 全场记 FAIL（如实）。
3. 相位判据 (c) 在 h/H≥0.4 全部 ≤1.40°（<2°），但最浅充装 h/H=0.2 达 4.78°，且「一周期累计相位」与判据 (a) 的 3% 容差自相矛盾（2° 相当于频率精度 0.56%）——记为部分 FAIL，并把两种度量都列出。
4. 压力链被两条硬锚钉住：静压 ρgA（偏差 ≤0.12%）与弱非线性区一阶谐波 vs 线性壁压（≤3%）。冲击压力与实验的对标因**无数据**而 WITHHELD；共振大幅工况已进入模型适用范围之外（马赫/触顶），其 p_peak/(ρgh)=1.7–11 只能作定性趋势。
5. 工程含义：本节点给出的共振频率面可直接用于液舱频率规避（误差带 <3%）；冲击压力面在补齐实验数据之前不应进入结构载荷链。
