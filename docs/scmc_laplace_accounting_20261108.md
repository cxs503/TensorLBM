## 0 结论（一句话）

库内 `multiphase_benchmarks.run_static_droplet` 对 Shan-Chen 双组分（SCMC）与 Color-Gradient（CG）
两支都打 `laplace_physical_validation: NOT_VALIDATED`，压力用理想气体代理 `cs²ρ` 测量——本单把
**这个「欠账」拆成可裁定的三条**并给出机制级答案：
(a) 新增 SCMC **离散机械压力张量**（等温极限解析精确，见 §3 表 A）；
(b) 首次测绘 SCMC 参数区：`|G₁₂| ≤ 2.0` 时两组分**互溶**（对比度 0.0125，σ_flat ≡ 0），
    出厂默认 `G₁₂ = −0.9` 正落在此区——SCMC 臂的 `σ_eff` 不是表面张力（R=6/9/12 上
    `σ_eff` = −1.8e−5 / 1.1e−4 / 4.2e−4，**变号且散度 256%**）；
(c) 有界面的区（`|G₁₂| = 2.4–3.5`）里离散法向应力在平板静止界面上**不守恒**
    （残差 35–71%），故绝对 σ 仍**不可认证**——这是可复现的量化阻塞，路线=界面分辨率研究；
(d) 反向给出**正面证据**：CG 臂在收敛设置（64², 4000 步）下 `ΔP·R` 跨半径散度 **0.52% < 5%**，
    Young-Laplace 线性律成立（σ ≈ 0.0104 ± 0.0001），伪电流 1.3e−3–2.1e−3 落在文献量级。

## 1 案例介绍（物理背景 / 几何 / 参数表）

Young-Laplace 律：静止液滴跨界面压差 `ΔP = σ/R`（二维圆形界面）。两支模型：
SCMC（两组分 Shan-Chen，`F_σ = −G ρ_σ Σ_i w_i c_i ρ_σ'(x−c_i)`）与 CG（color-gradient，
`A, β` 重着色）。几何：平板界面 `8×32`（法向 y，x 向均匀，周期）；液滴 `N²` 方格（`4R ≤ N`）。

| 参数 | SCMC 扫描 | 液滴（默认） | CG |
|---|---|---|---|
| 网格 | 8×32，3000 步 | 64²，4000 步 | 48²/64²，2500/4000 步 |
| ρ_heavy / ρ_light | 0.7 / 0.3 | 0.7 / 0.3 | 0.65 / 0.05 |
| 耦合 | G₁₂ = −0.9 … −4.0 | G₁₂ = −0.9 | A=0.04, β=0.7 |
| τ | 1.0 | 1.0 | 1.0 |
| 半径 | — | 8, 12 | 6, 9, 12 / 8, 12 |

## 2 怎么做的（方法 / 流程 / 工具链）

1. **机械压力张量**（新增 `src/tensorlbm/scmc_pressure_tensor.py`）：
   `P_ab = cs²(ρ₁+ρ₂)δ_ab + (G/2)Σ_i w_i c_ia c_ib [ρ₁(x)ρ₂(x+c_i) + ρ₂(x)ρ₁(x+c_i)]`
   （Shan 2006 对称两点形式；Landau-Lifshitz 符号，正=压缩）。同时保留 `isotropic`
   纯梯度候选作**负控**（丢掉各向异性部分）。
2. **平板界面判据（物理，不是拟合）**：静止平板界面必须满足 `∂_n P_NN = 0`。把
   `flatness = max|P_NN − <P_NN>| / <P_NN>` 作为压力**公式**是否为机械压力的判别量：
   代理 `cs²ρ` 通不过，我们实测它也确实通不过（§3 表 B）。
3. **界面存在性**：`contrast = max|ρ₁ − ρ₂|`（均匀互溶 → 0）。用它把 SCMC 参数区划为
   互溶 / 有界面 / 发散三段。
4. **液滴压差**：`ΔP = <P>_{r<R/2} − <P>_{r>1.5R}`，`P = (P_xx+P_yy)/2`（采样区避开扩散界面），
   `σ = ΔP·R`；与出厂代理路线并列输出以便对照。
5. **工具链**：`tools/scmc_laplace_accounting.py` 全程程序化产出
   `artifacts/scmc_laplace_20261108/results.json` + 3 张图（零手抄）；
   `torch.set_num_threads(1)`，所有实验 ≤ 64²、≤ 4000 步（控制面 load15≈128，不做重算力）。

## 4 注意点（坑 / 局限 / 适用范围）

* **SCMC 的“互溶”不是数值缺陷而是模型性质**：`G<0` 时混合态压力更低，故低耦合下两组分必然互溶；
  出厂示例参数恰在此区，因此它的 `σ_eff` 历史上一直是瞬态残留（本次实测变号）。
* **σ_flat 为负**：机械张量给 `P_TT > P_NN`（与正常液-气界面相反），且幅值随 |G₁₂| 单调增。
  在界面宽仅 ~1 格的条件下这既可能是分辨率不足，也可能是两点形式在强梯度下的高阶项主导；
  我们**不宣称**其符号正确，只宣称「法向应力不守恒 ⇒ 绝对 σ 不可认证」。
* **稳定性边界依赖分辨率**：`|G₁₂|=4` 在 48²/2000 步发散、32²/3000 步仍有限——
  故测试里把发散用例固定在 48² 设置，并在文中说明这是分辨率相关。
* **CG 结论带收敛条件**：48²/2500 步散度 9.9%，64²/4000 步 0.52%。低设置不收敛不是模型失效，
  但引用 σ 时必须同时给网格/步数。
* **两点形式的离散张量在平板界面上带虚假剪应力**：x 均匀场的对角模板给出
  `P_xy = (G/2)(1/36)[q(y+1) − q(y−1)] ≠ 0`，实测 `max|P_xy| ≈ 1.2e−3`（约为平均法向应力的 0.5%），
  集中在 ~1 格宽的界面上。这是离散 SC 应力本身的性质（也是绝对 σ 不可认证的第二条理由），
  已由 `test_flat_interface_carries_a_spurious_shear_stress` 钉住，而不是假装其为 0。
* 只覆盖二维 D2Q9、τ=1、`ψ=ρ`（线性）的 SCMC；三维 D3Q19、Carnahan-Starling ψ、接触角不在本账单内。
* `NOT_VALIDATED` 标签**未放开**：本单新增的是**判据与证据**，不是放行。

| 关键量 | 基准 | 实测 | 相对误差 | <3% ? |
