## 7. 选题建议

基于扫描结果，建议后续自主开发优先选题：

### 7.1 优先级 1：声源自激端（生态空白）

**提案**：TensorLBM 声源自激端——Lighthill 体积四极子从"给定源"升级为"时间推进自生源"+ 无反射吸收层

**理由**：
- 三重检索 0/0/0 命中，生态空白
- m9740 报告自承"源场是'给定的'、不是 LBM 时间推进的"为最大局限
- 物理意义明确：让声源由时间推进的流场自己产生，而非外部给定

**技术路径**：
1. 实现 Lighthill 应力张量 T_ij 的时间推进采集
2. 实现无反射吸收层（sponge layer）边界条件
3. 端到端验证：LBM 流场 → T_ij(t) → 远场声压 p'(x, t)

**验收判据**：
- 吸收层反射系数 < -40 dB
- 远场声压与解析解（如有）或文献值误差 ≤15%
- 计算效率：相比给定源方案，额外开销 < 20%

### 7.2 优先级 2：报告缺口补全

**任务**：为 m9741、m9744 补写论文级报告

**理由**：
- 已完成但报告库 0 篇，违反"每单必报"纪律
- 补报工作量小（1-2 小时/篇），收益大（完善知识台账）

**执行方式**：
- 派补报单（类似本单 m19825 补报 m2463）
- 按论文级六要素撰写
- POST 到 `/api/v1/tensor/reports`

### 7.3 优先级 3：Benchmark 待验证案例

**任务**：跑 B2（球 Re=100 D60）、B3（球 Re=200）、B6（SUBOFF Re=1000）

**理由**：
- B1 已验证，B2/B3 为自然延伸
- B6 为工业案例（SUBOFF 潜艇），工程价值高
