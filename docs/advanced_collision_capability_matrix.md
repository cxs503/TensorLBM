# 3-D advanced collision capability matrix

`tensorlbm.advanced_collision_contract` is the lattice-neutral public contract
for advanced 3-D collision selection.  A cell marked **available** has an
executable kernel exposed by `collide_advanced_3d`; a similarly named routine
elsewhere is not enough.

This table is generated by hand from `collision_capability_matrix()` and is
machine-checked against it by `tools/collision_claim_registry.py` (gate R2:
a stale `WITHHELD` line for a family the registry serves is a test failure).

| Lattice | MRT | CM / cascaded | CUMULANT | entropic KBC |
|---|---|---|---|---|
| D3Q19 | **available**: `solver3d.collide_mrt3d`, 19×19 explicit transform | **available**: `cascaded_collision.collide_cascaded_d3q19` — full central-moment hierarchy (0th–4th order) | **available**: `cumulant.collide_cumulant_d3q19` | **available**: `entropic_kbc.collide_kbc_d3q19` — per-cell entropy-optimal ghost relaxation, shear viscosity pinned to `c_s^2(tau-1/2)` by construction |
| D3Q27 | **available**: `d3q27.collide_mrt27`, full-rank 27×27 Gram–Schmidt transform/inverse | **available**: `cascaded_collision.collide_cascaded_d3q27` | **available**: `cumulant.collide_cumulant_d3q27` (Geier 2015 partition; also `collide_cumulant_geier_d3q27`) | **available**: `entropic_kbc.collide_kbc_d3q27` |

## What is *not* claimed

`advanced_collision.collide_cascaded_d3q27` and
`advanced_collision.collide_kbc_d3q27` are still **not** CM / KBC kernels: the
former is a second-order regularized reconstruction without the higher central
moments, and the latter uses a caller-supplied blend `beta` instead of an
entropy solve.  They keep their legacy names and are not routed through
`collide_advanced_3d`; the registered CM/KBC entry points are the
`cascaded_collision` / `entropic_kbc` modules above.

Availability is not an accuracy statement.  Where each family stands
quantitatively:

| Family | Evidence | Status |
|---|---|---|
| MRT, TRT, RLBM, BGK | `benchmarks/pending/collision_kernels_3d_tg/` (3-D TG decay) | decay rate within 0.5 % of `6 nu k^2` |
| CM / cascaded | same benchmark, plus `docs/CUMULANT_D3Q27_VERIFICATION.md` | within 0.42 % |
| CUMULANT | same benchmark, `docs/CUMULANT_D3Q27_VERIFICATION.md` | within 0.42 % |
| entropic KBC | `entropic_kbc` docstring + collision-level τ-control; the fp32 3-D TG sweep in `benchmarks/pending/collision_kernels_3d_tg/` reports a **FAIL** for `collide_kbc_d3q19` (+8.59 / −16.19 / −36.51 %), which is under re-measurement in float64 (`docs/m23154/`, mission 23154) | **WITHHELD at decay-rate level** until the float64 verdict lands |

The ledger `docs/m23154/COLLISION_CLAIM_REGISTRY.json` is the machine-readable
form of the table above; regenerate it with
`python tools/collision_claim_registry.py emit-ledger`.

## Executable interface

```python
from tensorlbm import collide_advanced_3d, collision_capability_matrix

f_post = collide_advanced_3d("D3Q27", "MRT", f, tau=0.8, s_e=1.19)
f_post = collide_advanced_3d("D3Q27", "KBC", f, tau=0.8)     # entropic_kbc
f_post = collide_advanced_3d("D3Q19", "CM", f, tau=0.8)      # cascaded_collision
matrix = collision_capability_matrix()
```

The dispatcher checks the population direction dimension (`19` or `27`),
four-dimensional population shape, and `tau > 0.5`; it never routes D3Q27
requests through a D3Q19 kernel.  Aliases: `CM` / `cascaded`,
`KBC` / `entropic_kbc`, `BGK` / `SRT`.
