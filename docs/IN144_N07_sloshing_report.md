## 1. 案例介绍

### 1.1 物理背景
LNG船液货舱在海洋环境中经历复杂的晃荡动力学行为。部分充装条件下，液体自由液面在激励作用下产生大幅振荡，导致壁面冲击压力，对结构疲劳寿命构成威胁。

### 1.2 几何参数

## 2. 方法

### 2.1 LBM自由液面追踪
采用Körner等人（2005）提出的自由液面LBM模型，实现于TensorLBM仓库：

**核心算法**:
- **网格**: D2Q9（二维）/ D3Q19（三维）
- **单元类型**: GAS / LIQUID / INTERFACE / SOLID
- **质量追踪**: 独立质量场 m(x)，填充率 ε = m/ρ_l
- **质量交换**: Körner方程(9)，反对称半权重保证质量守恒
- **界面重构**: 反弹回（ABB）气体压力重建 + Laplace气泡压力
- **拓扑转换**: I→L（ε≥1）和 I→G（ε≤0），包络层保证

**关键特性**:
- 大密度比支持（ρ_l/ρ_g ≈ 1000）
- 质量守恒严格保证（守恒钳制）
- 界面原子化抑制（独立质量场 vs 密度映射）

### 2.2 Abramson（1966）解析共振频率
矩形液舱共振频率解析解（势流理论）：

**二维情况**（m阶模态）:
```
f_m = (1/2π) × √(g × k_m × tanh(k_m × h))
k_m = m × π / L
```

**三维情况**（m,n阶模态）:
```
f_{m,n} = (1/2π) × √(g × k_{m,n} × tanh(k_{m,n} × h))
k_{m,n} = π × √((m/L)² + (n/B)²)
```

### 2.3 壁面冲击压力提取
- **压力计算**: p = c_s² × ρ = ρ/3（格子单位）
- **空间平均**: 壁面窗口平均（窗口大小3-5格子）
- **时间平滑**: 移动平均滤波（窗口大小5-10时间步）
- **无量纲化**: p_max / (ρgH)

### 2.4 疲劳载荷谱分析
- **雨流计数**: ASTM E1049-85四点法
- **S-N曲线**: Basquin公式 N = A / (Δσ)^m
- **累积损伤**: Miner线性累积损伤法则 D = Σ(n_i / N_i)

## 5. 注意点

### 5.1 踩过的坑
1. **质量场表示**: 早期实现使用密度映射（fill = ρ/ρ_l），导致界面原子化（界面扩散至90%计算域）。改用独立质量场后问题解决。
2. **浅水渐近线**: 初始测试用例中浅水近似公式错误，修正为 f ≈ (1/2π)√(g·k²·h)。
3. **三维频率计算**: 方舱（L=B）的一阶三维频率 f₁₁ ≠ f₁（二维），而是 f₁₁ = f₁ × √2。

### 5.2 局限性
1. **激励边界**: 当前实现为静态壁面，移动壁面边界条件（激励）尚未完全实现。
2. **三维效应**: 本工作主要聚焦二维，三维晃荡的横向模态耦合未充分研究。
3. **破碎波**: 大幅激励下的波浪破碎和飞溅现象需要更精细的界面捕捉。
4. **湍流效应**: 当前使用层流模型，高Reynolds数下的湍流效应未考虑。

### 5.3 适用范围
- **充装率**: h/H ∈ [0.1, 1.0]
- **激励幅值**: A/L < 0.05（线性/弱非线性regime）
- **频率比**: f/f₁ ∈ [0.5, 2.0]
- **密度比**: ρ_l/ρ_g ∈ [100, 10000]
