## 1 案例介绍（物理背景 / 几何 / 参数表）

受限域（槽道）内等温加热圆柱的强制对流：壁面把流动挤向圆柱，使换热相对无界基准系统偏高；
同时任何有限时长的时间平均又会把**起转瞬变/涡脱落相位**混进统计量，使结果系统性偏低或抖动。
两类偏差被假设为**可乘、可分离**：

$$ \mathrm{Nu}(H/D,\tau) = \mathrm{Nu}_\infty \cdot f(H/D)\cdot t(\tau),\qquad
   f = 1 + a (D/H)^m,\qquad t = 1 + b\,\tau^{-\beta} $$

* $H/D$：堵塞比 = 槽道有效宽 $H_{\rm eff}$ / 圆柱有效直径 $D_{\rm eff}$；
* $\tau$：统计窗长（时间平均窗口长度，单位 $D/U$）；
* 目标：用 $f$ 把任何受限域算例回推到 $H/D\to\infty$ 的无界基准 $\mathrm{Nu}_\infty$，
  用 $t$ 把任何有限窗长回推到 $\tau\to\infty$。

**几何与数值口径（写死在代码里，`src/tensorlbm/confined_cylinder_law.py`）**

| 项 | 取值 | 说明 |
|---|---|---|
| 有效直径 | $D_{\rm eff}=2R+1$ | 半程反弹壁位于固体节点与流体节点之间 |
| 有效槽宽 | $H_{\rm eff}=n_y-2$ | 上下壁中点 y=0.5 与 y=n_y-1.5 |
| 速度场 | D2Q9 BGK + 半程反弹壁 | 圆柱/槽壁同一配方（与 verified/cavity 同族） |
| 温度场 | D2Q5 ADE（`collide_thermal_bgk`） | 圆柱等温 1.0（反反弹 Dirichlet），上下壁绝热（反射） |
| 无量纲 | Re=100、Pr=0.7、$U_{\rm in}=0.1$ | $Re=U D_{\rm eff}/\nu$，$\alpha=\nu/Pr$ |
| 域长 | 上游 5D、下游 13D（$n_x=18D_{\rm eff}+2$） | |
| 时长/采样 | 110 D/U（采样 0.1 D/U） | 覆盖战役四个窗至 [60,105] |
| 网格级 | $D_{\rm eff}=11$（粗，本轮完成）、$D_{\rm eff}=17$（细，未完成） | |
| 基准 | Churchill–Bernstein (1977)：$\mathrm{Nu}_{\rm CB}(100,0.7)=5.156$ | |

## 2 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **求解器**（新增 `confined_cylinder_law.py`，~700 行）
   * 内部复用本仓 `d2q9.equilibrium/macroscopic`、`thermal.collide_thermal_bgk/temperature_equilibrium`；

     **逐位等价**（pytest 锁定）——在 loong64 上实测快 3–4 倍（gather 高级索引退化为随机访存）；
   * 壁面半程反弹改为**只对壁节点索引赋值**（避免 9×ny×nx 全阵列 gather+where）；
   * 速度入口用**内点密度外推**（定压入口会把质量流量压偏 +12%，实测），
     每 5 步把总质量归一到 $\rho_0 N$（不可压 LBM 压力水平自由）；

2. **三条互相独立的 Nu 估计器**（这是本节点最有价值的方法学产出）
   * `nu_local`：壁面法向梯度积分（非均匀三点 0/0.5/1.5 二阶单侧差分）；
   * `nu_global`：进出口焓通量差（$\dot m c_p \bar T$，绝热上下壁）；
   * `nu_bc`：**由等温反反弹边界本身计量**的放热率 $\sum_{\rm links} 2(w_iT_w-g_i)$（无插值误差）。
3. **判据程序化**：`evaluate_criteria()`（模块内）+ `scripts/finalize_p187_w1_n08.py`
   （小网格播种 + Levenberg–Marquardt 拟合、对数残差 AIC 对照、双向 ANOVA 交互项、
   嵌套 F 检验负控）。**所有数字由脚本生成，零手抄**（`artifacts/p187_w1_n08/criteria.json`）。
4. **测试**：`tests/test_confined_cylinder_law.py`（13 项）——几何口径、迁移等价、
   C-B 参考值、窗均值、**解析 Laplace 场标定表面通量积分器**、合成律可恢复性、
   AIC 判别、负控、冒烟算例。
5. **工具链**：Python 3.11 / PyTorch 2.7.1（CPU，loong64 128 核）/ NumPy / SciPy / Matplotlib。

## 4 关键发现（可复用）

1. **表面梯度积分器在薄热边界层下系统性失效**：解析 Laplace 场 $T=1+A\ln(r/R)$ 上，
   修正前的一侧三点公式误差达 −63%（并暴露**点距写错**：正确非均匀三点系数是
   $-\tfrac83 T_0+3T_1-\tfrac13T_2$，不是 $\ 3T_0-4T_1+T_2$）；修正在解析场上残差 ~15%。
   但在真实对流场（$\delta\approx D/\sqrt{Re\,Pr}$ ≈1 格）该积分器与精确能量账相差
   **1.9–5.3 倍且随网格单调恶化** ⇒ **不能**用作绝对口径。
2. **精确口径必须落在边界条件本身**：等温反反弹边界每链注入 $2(w_iT_w-g_i)$ 之和，
   是**无插值误差**的放热计（本轮已加入 `_bc_heat_flux`，测试用例覆盖）。
   *三条估计器不闭合*（5.35×/3.32×/1.93×）本身是重要负面结论：
   任何只报"一个 Nu 数字"的受限域算例都可能错 2–5 倍而不自知。
3. **窗长律指数 β≈0.41**：与"起转瞬变主导窗均值偏差"的 $\tau^{-1/2}$ 标度一致
   ⇒ **窗长偏差本质上是 burn-in 偏差**，把 $t_0<40$ D/U 的窗混进"统计窗长律"会
   把起转瞬变律当成统计律（报告第 5 节局限，已用 `STATIONARY_WINDOWS` 分离）。
4. **性能（可复用）**：loong64 上 torch 多线程对 10⁴–10⁵ 节点 2D 阵列**反而更慢**
   （1 线程 0.86 M nodes/s，8 线程 0.29，32 线程 0.09）；float32 比 float64 快 2–3×；
   roll 迁移比 gather 快 3–4×。⇒ 战役大扫掠应「多进程 × 单线程」。

## 5 注意点（踩过的坑 / 局限 / 适用范围）

1. **扫掠未跑完（本轮最大局限）**：集群队列拥堵（提交 15 min 仍 150 单排队），
   本机单次 shell ≤120 s，用分块续跑推进；12 个算例中 2 个完成、1 个到 97 D/U、
   其余 10–76 D/U。**C3/C4 因此 WITHHELD**，C1/C2 是在 3 个堵塞比、单网格级上的**不达标**结果。
2. **a<0（堵塞降低 Nu）与物理直觉相反**：本数据里 hd4→3.14、hd6→3.73、hd12→4.38，
   即堵塞越强 Nu 越低——与"槽道加速→换热增强"的直觉相反。三者网格同为 $D_{\rm eff}=11$
   但**热边界层相对分辨率随 D 不变而随 H/D 变化（涡/尾流受限）**，
   最可能的原因是低堵塞比时热线被槽壁"短路"以及尾流受限改变了驻点/侧面的换热分配。
   **结论：在未完成网格收敛前，a 的符号不可信**（这也正是 C4 必须做的原因）。
3. **C2 的"改善"不成立**：朴素基线（H/D=12 直接用）2.34% 反而优于外推 7.93%
   ⇒ 仅用 3 个堵塞比、粗网格做外推会把网格偏差误当堵塞律外推；
   外推必须在细网格 + 足够堵塞比点数上做。
4. **入口 Dirichlet 热沉**：温度入口强制 $T=0$ 会把上游扩散热全部"倒掉"，
   使 "进出口焓通量差" **系统性低算**（这也是本轮三估计器不闭合的部分原因）；
   应以 `nu_bc` 为主口径，或用零梯度入口/更长上游段。
5. **适用范围**：Re=100、Pr=0.7、2D 层流、堵塞比 4–24；不能外推到湍流/3D。

## 6 误差判定（关键量 vs 基准，逐项，显式回答"是否 <3%"）

| 关键量 | 基准 | 相对误差 | <3%？ |
|---|---|---|---|
| Churchill–Bernstein 实现 | 文献式（Re=100,Pr=0.7→5.16；Re=200→7.19；Pr=7→11.82） | <0.1% | **是** |
| 迁移算子 roll vs 仓库 gather | 逐位比较 | 0（机器精度） | **是** |
| $Re_{\rm meas}$ vs 名义 100 | 质量流量反推 | ≤0.85% | **是** |
| 表面热流积分器（解析 Laplace 场） | $\oint -{\rm d}T/{\rm d}n\,{\rm d}s=2\pi A$ | 15%（D=16）、63%（修正前） | **否** |
| Nu 绝对值（焓平衡 vs 壁面计量） | 同一算例互校 | 1.9–5.3 倍 | **否** |
| $\mathrm{Nu}_\infty$ vs C-B | 5.156 | 7.93%（粗网格 3 点外推） | **否** |
| 窗长律 β | $\tau^{-1/2}$=0.5（burn-in 理论） | 17%（0.414 vs 0.5） | **否** |

**结论**：本节点**未达到** 3%/5% 的绝对精度标准；达标路径已明确列出（第 7 节）。
