# R1: 灰体漫射辐射（radiosity / net-radiation）解析基准复核与两处静默失效修复

状态：**已实现 + 已验证**（`tests/test_thermal_radiation_analytic.py` 30 passed，解析解误差 < 1e-13 相对量级）。
范围：`src/tensorlbm/thermal_radiation.py`（`tensorlbm` 求解器库内），不涉及平台/流程仓。

## ① 案例介绍

### 物理背景

`tensorlbm.thermal_radiation` 用**净辐射法（net-radiation / radiosity）**求灰体漫射封闭腔
内各表面的净辐射热流，并把该热流作为 Neumann 型源项耦合进热 LBM（DDF）温度方程
（`apply_radiation_source`）。工程用途为电子/电池散热、太阳辐照负荷、炉膛/燃烧腔等。

模型（Modest 2013 §5.4）：

```
J_i = ε_i σ T_i⁴ + (1 − ε_i) G_i            radiosity
G_i = Σ_j F_ij J_j + q_solar,i             irradiation
q_i = J_i − G_i                             net outgoing flux  [W/m²]
```

### 几何与参数表

| 编号 | 几何 | 视角因子 | 解析参考 |
|---|---|---|---|
| A | 两块无限大平行平板 | `F12 = F21 = 1`，`F11 = F22 = 0` | Incropera 6e Eq. 13.23：`q = σ(T1⁴−T2⁴)/(1/ε1+1/ε2−1)` |
| B | 同心球（面积比 A1/A2） | `F12 = 1`，`F21 = A1/A2`，`F22 = 1−A1/A2` | Incropera 6e Eq. 13.24：`q = σ(T1⁴−T2⁴)/(1/ε1+(A1/A2)(1/ε2−1))` |
| C | 三表面等面积封闭腔 | 默认等视角因子 `F_ij = 1/(n−1)` | 能量守恒 `Σ q_i A_i = 0` |
| D | 单表面 + 冷空腔（`F = 0`） | — | `q = εσT⁴` |
| E | 太阳直射面元 | Lambert 余弦律 | `q = α I cosθ`，背光面 `cosθ<0 → 0` |

参数：`σ = 5.670374419e-8 W m⁻² K⁻⁴`（模块内常量）；温度梯度取 400/300 K、800/300 K、
500/450 K、400/350 K 四组；发射率 `ε ∈ {0.02 … 0.95}`；太阳辐照 800/1000 W m⁻²，
吸收率 `α ∈ {0.25, 0.6, 0.8, 1.0}`。

## ② 怎么做的

1. **先造判据**：把闭式解写成测试里的参考函数（`q_two_parallel_plates` / `q_concentric_spheres`），
   门限 = 关键量相对误差 `< 3%`（不可接受线 15% 另设），另加封闭腔能量守恒 `|Σ q_i A_i| < 1e-9·scale`。
2. **量化旧实现**：不凭记忆重写旧算法，而是用 `git show HEAD:src/tensorlbm/thermal_radiation.py`
   把旧模块**原样**载入，与当前模块并排跑同一批解析案例
   （`scripts/thermal_radiation_radiosity_benchmark.py`），输出 `outputs/thermal_radiation_r1/evidence.json`。
3. **定位两处静默失效**：
   - *求解器不收敛却报告成功*：旧 `radiosity_matrix_solve` 用无阻尼定点迭代
     `J ← εσT⁴ + (1−ε)(FJ + q_solar)`，谱半径 `(1−ε)·‖F‖ = 1−ε`；默认
     `max_iter=50`、`tol=1e-6` 时残差 ≈ `(1−ε)^50`。`ε=0.05` 时 50 步后残差 ~7.7%，
     `ε=0.02` 时 35.7%——**超过 15% 不可接受线**，而函数没有任何收敛标志。
   - *默认视角因子违反互易性*：`_build_view_factor_matrix` 在未给矩阵时取
     `F_ij = 1/(n−1)`，行和为 1（"封闭"），但互易律 `A_i F_ij = A_j F_ji` 只有各表面
     面积相等时才成立。面积不等时封闭腔**凭空产生/销毁能量**（实测最坏 58.6% 相对失衡），
     却照常返回"有效"结果。
4. **最小修复**（`src/tensorlbm/thermal_radiation.py`）：
   - 把 radiosity 系统改为**精确线性求解**
     `(I − diag(1−ε)F) J = εσT⁴ + (1−ε)q_solar`（`torch.linalg.solve`，float64）；
     奇异情形（全部 `ε→0`）才回落到原定点迭代，`max_iter/tol` 仅服务该回退路径。
   - 新增 `validate_view_factors(F, areas, tol)`：非负性 + 互易性（相对偏差 > tol 即
     `ValueError`）+ 闭合性（行和 < 1 视为**开放腔**，只标记 `closed=False`，不拒）。
   - 新增 `radiative_energy_residual(q, areas) = Σ q_i A_i`；`compute_net_radiation_flux`
     对闭合腔强制能量账 `Σ q_i A_i = −Σ A_i q_solar,i`，超差即 `ValueError`（fail-closed）。
   - 配置新增 `view_factor_tol: float = 1e-6`（加性字段，默认不改变既有调用）。

工具链：Python 3.11 / PyTorch(CPU, float64) / pytest / matplotlib。全部案例为闭式或
3×3 线性代数，单次运行 < 8 s，无 GPU、无长时间算例。

复算命令：

```bash
PYTHONPATH=src python3 -m pytest tests/test_thermal_radiation_analytic.py -q
PYTHONPATH=src python3 scripts/thermal_radiation_radiosity_benchmark.py   # 写 outputs/thermal_radiation_r1/
```

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

1. **陷阱：把"迭代没跑够"当"物理误差"。** 旧实现在 `ε ≥ 0.2` 时误差 < 1e-3%，很容易被
   随手挑的一个案例"验证通过"；只有扫到低发射率才暴露。验证必须覆盖参数空间的病态端
   （本模块的病态端 = 小 ε），否则等于没验。
2. **陷阱：默认参数偷偷破坏守恒律。** `F_ij = 1/(n−1)` 看起来是"均匀漫射腔"，但它不满足
   互易律，除非面积全相等。守恒量（`Σ q_i A_i`）是最便宜的哨兵，本次靠它抓到 58.6% 失衡。
3. **`total_emitted_power` 命名与语义不符（未修改，仅固定 + 记录）**：该字段返回
   `Σ σ T_i⁴ A_i`（黑体等效发射），不是灰体发射 `Σ ε σ T_i⁴ A_i`；`ε=0.05` 时两者差 20 倍
   （`1910.92 W` vs `95.55 W`）。由于是已发布 API 字段，本轮**不静默改语义**，而是用测试
   把当前定义钉住（`test_total_emitted_power_is_blackbody_equivalent_definition`），
   建议下一主版本改名或新增 `total_grey_emitted_power`。
4. **开放腔被允许**：行和 < 1 表示部分辐射逸出到未建模的 0 K 环境，这是合法的工程近似，
   测试里用 `Σ A_i q_i = +Σ A_i J_i (1 − Σ_j F_ij)` 校验其账目平衡（不强制为 0）。
5. **真实几何仍需外部视角因子**：本模块不计算视角因子（无遮挡/无交叉弦法）。面积不等的腔
   现在会明确要求调用方提供满足行和 = 1 且互易的 `view_factors`，而不是默默给出不守恒的数。
6. **HTTP 端点已改为 4xx（本轮）**：`app/backend/routers/postprocess.py` 的辐射端点先前
   用用户传入面积直接构造默认视角因子，面积不等时返回 200 + 静默不守恒结果（2.0/1.5 m²
   一例约 14% 失衡）。现在该 `ValueError` 被映射为 **HTTP 400**，`detail` 里带实测互易偏差；
   等面积输入仍返回 200。`app/tests/test_engineering_gap_closure.py` 相应新增
   `test_thermal_radiation_unequal_areas_fail_closed_with_400`。
7. **求解代价**：精确解为 `O(n³)`（n = 腔表面数）。工程腔体表面数通常 1–50，代价可忽略；
   若将来有 10³ 量级表面需求，应换迭代法 + 残差收敛判据，而不是退回无判据的定步迭代。
8. **适用范围**：灰体、漫射、非参与性介质（无吸收/发射气体），无镜面反射，
   `q_solar` 只做面元余弦投影（无遮挡、无多次反射）。

其中低发射率单点已越过 15% 不可接受线。
