## 1. 案例介绍（物理背景/几何/参数表）

### 1.1 物理背景
本验证战役填补TensorLBM可压缩流零系统验证空白，覆盖：
- **亚声速翼型绕流**：NACA0012对称翼型在Ma=0.3~0.85范围内的升阻力特性
- **跨声速激波捕捉**：Ma=0.85时激波诱导分离与阻力发散
- **声爆N波形**：超声速楔形体产生的N形压力波与Ackeret理论对标

### 1.2 几何参数
| 参数 | 值 | 说明 |
|------|-----|------|
| 翼型 | NACA0012 | 12%厚度对称翼型 |
| 弦长 | c = 1 | 无量纲化 |
| 最大厚度位置 | x/c ≈ 0.30 | 理论值 |
| 后缘 | 闭合 | y_TE = 0 |

### 1.3 物理模型
- **可压LBM**：D2Q9双分布函数法（密度f + 温度g）
- **状态方程**：理想气体 p=ρRT，γ=1.4
- **激波捕捉**：人工粘性 μ_art = c_h·ρ·Δx·|∇·u|，c_h=0.15
- **边界条件**：远场Riemann不变量 + 翼型无滑移壁面

### 1.4 验证参数矩阵
| 工况 | Ma | α(°) | 验证目标 |

| 跨声速 | 0.85 | 0 | 激波位置/阻力发散 |
| 声爆N波 | 2.0 | θ=10° | Δp vs Ackeret理论 |

### 2.2 关键算法
```python
# 双分布函数平衡态
f_eq = w·ρ·(1 + 3cu + 4.5cu² - 1.5u²)  # 密度分布
g_eq = w·T·(1 + 3cu + 4.5cu² - 1.5u²)  # 温度分布

# 人工粘性激波捕捉
μ_art = c_h · ρ · Δx · |∇·u|
ω_eff = ω / (1 + μ_art)

# Prandtl-Glauert升力线斜率
dC_L/dα = 2π / √(1 - Ma²)

# Ackeret声爆过压
Δp = ρ·U²·θ / √(Ma² - 1)
```

## 5. 注意点（踩坑/局限/适用范围）

### 5.1 已解决的坑
1. **NACA0012厚度公式**：公式返回半厚度(y_t)，全厚度=2×y_t，测试期望值需对应
2. **后缘闭合**：上下表面后缘点需分别强制y=0，否则对称性检验失败
3. **斜激波求解器**：Newton迭代需从马赫角上方开始，否则收敛到强激波解
4. **力计算类型**：wall_mask为bool类型，Fx/Fy需显式指定dtype=torch.float32

### 5.2 局限性
1. **薄翼型网格分辨率**：NACA0012最大厚度仅0.12c，在80×40网格上不足1个网格单元，需≥200×100网格才能分辨
2. **LBM马赫数限制**：标准D2Q9 LBM适用于Ma<0.3低马赫流，高马赫需人工粘性或高阶格式
3. **远场边界**：当前使用混合层边界条件，精确Riemann不变量边界需进一步实现
4. **三维扩展**：当前为2D验证，3D需D3Q19/D3Q27格子

### 5.3 适用范围
- 亚声速Ma<0.8：Prandtl-Glauert理论适用
- 跨声速Ma≈0.85：需激波捕捉格式
- 超声速Ma>1.0：Ackeret薄翼理论适用
