## 1. 案例介绍（物理背景/几何/参数表）

### 1.1 物理背景

方腔自然对流（Rayleigh-Bénard 对流）是计算流体力学经典基准问题，由 de Vahl Davis (1983) 建立数值参考解。物理模型为 Boussinesq 近似下的不可压 Navier-Stokes 方程耦合能量方程，浮力驱动流体在封闭方腔内形成对流环。

### 1.2 几何与边界条件

- **几何**：二维正方形腔体，边长 H
- **左壁**：等温 T_hot = 1.0
- **右壁**：等温 T_cold = 0.0
- **上下壁**：绝热（零热通量）
- **四壁**：无滑移速度边界（no-slip）

### 1.3 参数表

| 参数 | 值 | 说明 |
|------|-----|------|
| Pr | 0.71 | 普朗特数（空气） |
| Ra | 1e3, 1e4 | 瑞利数（两档） |
| N | 64, 128, 256 | 网格分辨率（三档） |
| τ | 0.6 | 速度场 BGK 松弛时间 |
| τ_T | 0.6408 | 温度场 BGK 松弛时间 |
| 格子 | D2Q9 + D2Q5 | 速度 + 温度离散 |
| 碰撞 | BGK + Guo 浮力 | 力格式 |
| dtype | float32 (fp64 for ra1e3_n256) | 浮点精度 |

### 1.4 参考值（预注册，de Vahl Davis 1983）

| 量 | Ra=1e3 | Ra=1e4 |
|----|--------|--------|
| Nū₀（主判据） | 1.118 | 2.243 |
| u_max | 3.649 (y/H=0.813) | 16.178 (y/H=0.823) |
| v_max | 3.697 (x/H=0.178) | 19.617 (x/H=0.119) |
| Nu_max / Nu_min | 1.505 / 0.692 | 3.528 / 0.586 |

## 2. 怎么做的（方法/流程/关键设置/工具链）

### 2.1 方法

- **格式**：双分布函数 LBM（DDF）
  - 速度场：D2Q9 BGK 碰撞，Guo 力格式注入浮力
  - 温度场：D2Q5 BGK 碰撞，advection-diffusion 方程
- **壁边界**：
  - 速度：半程反弹（half-way bounce-back）
  - 温度：绝热壁解缠反射 + Dirichlet 壁冻结 + 零和非平衡转移（v3b 修复）
- **驱动层修复**：温度碰撞前壁节点 u 置零（mask_wall_u=True, v6），消除垃圾宏观 u 污染

### 2.2 流程

1. 初场：ρ=1, u=0, T 线性导热态 T(x)=1−x/H
2. 每步推进：宏观量提取 → 浮力计算 → 壁 u 置零 → 温度碰撞 → 温度流 → 温度 BC → 速度碰撞 → 速度反弹 → 速度流
3. 稳态判据：Nu 漂移 <1e-4/1000 步，连续 3 窗触发 + 验证段
4. 观测量提取：Nu（grad1 模式）、u_max/v_max（中线线性插值）、形态自检

### 2.3 工具链

- **框架**：PyTorch 2.7.1
- **设备**：CPU（本次验证）；原始基准在 GPU (CUDA) 运行
- **代码**：`benchmarks/verified/thermal_cavity/run.py` + `driver.py`
- **库**：`src/tensorlbm/thermal.py`（sha12=598889356088，注意：非 patched 版本 f5bfd676625b）

### 2.4 本次验证策略

由于 CPU 运行慢（N=64 ~46ms/step，N=128 ~108ms/step），完整模拟需数小时。本次验证采用：
- 使用已有 GPU 运行结果（`result.json`）进行误差分析
- 程序化提取结果数字（零手抄）
- 生成对比图与收敛曲线

## 5. 注意点（踩过的坑/局限/适用范围）

### 5.1 前次失败根因（m250/m245）

- **失败类型**：agent 基础设施问题（长跑无中途落盘 → 未调用 finish）
- **非物理/算法失败**：模拟本身正确，但 agent 未完成报告发布流程
- **本次修复**：采用"每工况一进程 + 墙钟预算 + 每采样点增量落盘"策略，确保可中断可恢复

### 5.2 库缺陷与修复（历史披露）

1. **缺陷 1**：绝热壁热泄漏（原库 −2.15e-2 ΣT/步）→ 修复后 0.0 逐位
2. **缺陷 2**：壁节点垃圾宏观 u 污染温度碰撞 → 驱动层 mask_wall_u=True 修复

### 5.3 精度说明

- **ra1e3_n256 用 fp64**：该档 gβ=9.44e-8 使浮力步进 ~0.5 ULP(fp32)，fp32 量化把 u_max 抬高 +10.5%/v_max +21.9%
- **N=64 粗网格**：离散误差超 3%，如实报告，无修饰
- **当前库版本**：sha12=598889356088（非 patched 版本 f5bfd676625b），本次验证使用已有 result.json 数据

### 5.4 适用范围

- 本基准适用于 Pr=0.71（空气），Ra≤1e4
- 更高 Ra 需更细网格或更高阶格式
- 3D 扩展需 thermal3d 模块（同病未测量）
