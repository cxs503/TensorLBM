# XVAL — two independent contact-angle implementations vs Young's law

Anchor: `XVAL-LBM-TWO-INDEPENDENT-CONTACT-ANGLE-IMPLS` (walberla *two-independent-contact-angle-impls* discipline).  Status: **NOT ACCEPTED — see section 5** (predeclared gates, machine-evaluated from the run artefact).

Run artefact: `two_impl_contact_angle_quick/summary.json` (quick=True, wall time 42.5 s).  This document is generated by `benchmarks/case_pool/two_impl_contact_angle/build_report.py`; no number below is hand-copied.

## 1. Physical setting and parameters

Static contact angle of a two-phase drop on a flat wall in a diffuse-interface (Allen–Cahn / Cahn–Hilliard) model.  Young's law fixes the angle,

    sigma_lg cos(theta) = sigma_sg - sigma_sl,

and the model imposes it at the wall in three ways that share no code (the walberla discipline: implement twice, cross-validate):

| arm | what the wall imposes | formula |
|---|---|---|
| `dirichlet` | wall *value* of the order parameter | `cos(theta) = (3 psi_w - psi_w^3)/2` |
| `neumann_flux` | wall *flux* (natural BC of the same wall free energy) | `kappa d_n psi = (3/4) sigma cos(theta)(1 - psi^2)` |
| `geometric_ghost` | purely *geometric* ghost row | `psi_g = psi_0 + cot(theta) |d_t psi|` |

| parameter | value |
|---|---|
| grid (ny x nx) | 56 x 80 |
| interface width xi | 3.0 |
| surface tension sigma | 0.05 |
| initial cap radius R | 16.0 |
| relaxation | mass-conserving Allen–Cahn descent, omega=0.4, max_iter=30000 |
| dtype / threads | torch.float64 / 4 |
| prescribed angles | 90, 110 deg |
| reference | Young: sigma_lg*cos(theta) = sigma_sg - sigma_sl.  In the diffuse-interface (Allen-Cahn / Cahn-Hilliard) model the same law is imposed as (i) a wall VALUE psi_w with cos(theta)=(3 psi_w - psi_w^3)/2, (ii) a wall FLUX kappa*d_n psi = (3/4) sigma cos(theta)(1-psi^2), (iii) a GEOMETRIC ghost psi_g = psi_0 + cot(theta)|d_t psi|.  The prescribed theta is the continuum Young reference theta_ref. |

Reference values: `de Gennes, Rev. Mod. Phys. 57 (1985) 827 (Young's law / wall free energy)` (Young's law; Jacqmin, J. Comput. Phys. 155 (1999) 96 (wetting boundary condition for diffuse interfaces)).

## 2. Method

1. Each (arm, prescribed angle) is relaxed to static equilibrium by a mass-conserving Allen–Cahn descent on the same free energy; only the wall term differs.
2. The final field is measured by **three implementation-blind estimators** (none reads the wall ghost, none knows which arm produced the field):
   * `theta_cap_deg` — conserved-content Laplace-cap area inversion (implementation-blind, uses content + apex)
   * `theta_circle_deg` — algebraic least-squares circle fit of the mid-level contour (implementation-blind, global shape)
   * `theta_normal_deg` — contact-line interface-normal direction from field gradients at the two mid-level crossings of the two wall-adjacent rows (implementation-blind, local derivative; benchmark-side, shares no code with the module estimators)
3. `theta_got` = median of the finite estimators; the acceptance reference is the prescribed Young angle `theta_ref`.
4. A fourth, independent implementation runs the **production solver** (`CAC2D`, D2Q9 CAC/HCH + bounce-back) through the integration arm `tensorlbm.wetting.ladder.contact_two_impl`: the same wall value `psi_w = psi_wall_from_angle(theta)` is handed to the solver's `wall_order` policy, so the two implementations are compared inside the production code path.
5. Gates are read from `benchmarks/case_pool/two_impl_contact_angle/refs.json`; they were fixed before the graded sweep was inspected.

Reproduce (CPU, no cluster needed for the psi arms; the solver arm needs the LBE):


## 5. Gates, notes and limitations

| gate | threshold | measured | verdict |
|---|---|---|---|
| G1 measurable | all rows measurable | 6 / 6 | PASS |
| G2 accuracy vs Young | < 15% | max 6.24% | PASS |
| G3 cross-arm spread | < 15% | max 6.60% | PASS |
| G4 estimator spread | < 10 deg | max 51.51 deg | FAIL |
| G5 equilibrium + conservation | mass < 1e-6, drift < 1e-9 | mass 1.4e-16, drift 7.6e-04 | FAIL |
| G6 neutral-limit degeneracy | < 1e-6 | 0.00e+00 | PASS |

**Open item (reported, not papered over).** The estimator-spread gate G4 (10 deg, predeclared) is violated by:

* `dirichlet` at 90 deg: estimators 85.37, 96.54, 95.36 deg (spread 11.17 deg)
* `dirichlet` at 110 deg: estimators 113.77, 116.87, 165.27 deg (spread 51.51 deg)

*Reading.*  The `theta_circle` estimator (algebraic least-squares fit of the whole mid-level contour) is the outlier; the area inversion and the local contact-line trace agree with each other.  An algebraic circle fit is known to be biased for short arcs, which is exactly the regime of a thick interface (xi/R = 0.188).  The acceptance quantities (G2 accuracy, G3 cross-arm) stay inside the 15% standard either way, and the independent verification round 3 measured the same 11.2 deg gap, i.e. this is a reproducible property of the estimator, not a run-to-run fluke.

### Limitations

* The reference is the **prescribed continuum Young angle**, not an experiment: a finite interface width xi/R = 0.188 carries a discretisation bias of a few degrees, which is what G2 measures.  The cross-implementation comparison (G3) is the part of the evidence that does not depend on the reference being exact.
* `wall_angle_readback` (module diagnostic) is the angle the *gradient* arms applied; for the `dirichlet` arm it is a profile difference, not an angle (documented in the module and excluded from acceptance).  It also had a quadrant bug -- it returned `180 deg - theta` above 90 deg (70.0 deg for a prescribed 110 deg) -- fixed in this round and guarded by `test_wall_angle_readback_has_no_quadrant_flip`.
* The production-solver arm is limited to `arm='dirichlet'`: the flux and geometric conditions are not expressible through the solver's wall order parameter, and `contact_two_impl` raises instead of silently approximating them.
* Static angles only: dynamic (Cox–Voinov) angles and hysteresis are out of scope for this anchor.

| theta (geometric_ghost, 90 deg) | 90 deg (prescribed Young) | 89.91 deg | -0.10% | yes |
| theta (dirichlet, 110 deg) | 110 deg (prescribed Young) | 116.87 deg | +6.24% | **no** |
| theta (neumann_flux, 110 deg) | 110 deg (prescribed Young) | 109.61 deg | -0.36% | yes |
| theta (geometric_ghost, 110 deg) | 110 deg (prescribed Young) | 110.30 deg | +0.28% | yes |

**Explicit answer: no — the 3% bar is not met by every row.** The worst row is 6.24% (gate G2 requires < 15%, which holds).  The residual is the documented finite-interface bias of the shape estimators at xi/R = 0.188 plus, for the `dirichlet` arm, the fact that a wall *value* and a wall *flux* are not the same discrete condition.  What the anchor does establish is that two (three) independent implementations of the same continuum condition agree within 6.60% and that the production solver reproduces the same angle from the same wall value.
