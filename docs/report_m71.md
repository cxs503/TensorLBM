## ① 案例介绍

### 物理背景

Womersley 振荡流是流体力学经典解析基准（Womersley 1955; Sexl 1930），描述平面通道中受谐波压力梯度驱动的层流。其稳态周期解具有精确的复数形式（Bessel 函数剖面），是验证非定常 LBM 求解器精度与收敛性的黄金标准。

### 几何与参数

| 参数 | 值 | 说明 |
|---|---|---|
| 格子模型 | D2Q9 | 二维九速度 |
| 碰撞模型 | BGK | τ = 0.8, ν = 0.1 |
| 通道宽度 H | 29, 59 | 两档网格（2× 加密比） |
| 流向周期长度 nx | 16 | 周期边界 |
| Womersley 数 α | 4.0, 8.0 | 两档频率 |
| 峰值速度 u_peak | 0.03 | Ma ≈ 0.052（低马赫） |
| 测量周期数 | 4 | 跳过 27 个启动周期后 |
| 相位采样 | 8 个/周期 | 均布采样 |

### 解析解

平面通道（壁面 y=0, H），谐波振荡压力梯度 dp/dx = −ρ·a₀·cos(ωt)，稳态周期解：

$$U(y) = \frac{a_0}{i\omega}\left[1 - \frac{\cosh(\lambda y')}{\cosh(\lambda)}\right], \quad y' = \frac{y - H/2}{H/2}, \quad \lambda = \sqrt{i}\,\alpha$$

其中 α = (H/2)·√(ω/ν) 为 Womersley 数。解析解独立校验：PDE 残差 ~10⁻⁹，ω→0 准稳态极限退回抛物线（数值核对到 10⁻¹²）。

## ② 方法/流程

### 运行脚本

独立脚本 `scripts/sdaa_sweep_womersley.py`（不改业务代码），对 4 个配置 (H∈{29,59})×(α∈{4,8}) 逐一运行：

1. **张量设备**: 所有计算张量放置于 SDAA 设备
2. **编译路径**: 请求 `torch.compile` default → SDAA 上 teco_inductor 报 `InductorError: AssertionError: self.reduction_shape` → 自动 fallback 到 eager 模式（`compile_status: eager_fallback`）
3. **Triton 绕行**: 设置 `TRITON_INTERPRET=1`（预防性，不解决 inductor 后端缺口）
4. **壁面**: 预流半程 bounce-back（verified/poiseuille_2d 同款范式）
5. **驱动**: `tensorlbm.turbulent_channel._apply_body_force_2d`（库内部函数，一阶 Guo/Luo 体力）
6. **测量**: 跳过 27 个启动周期后，连续测量 4 个完整周期

### 判定准则（先验固定，3% 门限）

| 编号 | 准则 | 说明 |
|---|---|---|
| C1 | 剖面 L2 误差（固定尺度）≤ 3% | 8 个相位时刻，归一化到周期峰值范数 |
| C2 | 逐点最大误差 / u_peak ≤ 3% | 8 个相位时刻 |
| C3 | 复振幅相对误差 ≤ 3% | 逐行 \|U_num/U_ana − 1\|，仅 \|U_ana\| ≥ 10% u_peak 的行 |
| C4 | H→2H 误差单调下降 | α=4 和 α=8 两条线均须收敛 |

## ⑤ 注意点

### 踩过的坑

1. **torch.compile 在 SDAA 上不可用**：teco_inductor 后端报 `AssertionError: self.reduction_shape`，自动 fallback 到 eager 模式。这不影响物理结果的正确性，但性能损失显著（无法利用编译优化）。

2. **瞬时相对 L2 在换向相位病态**：α=8 时类柱塞核心在换向瞬间过零，参考范数 ‖u_ref‖ 塌缩到峰值的 ~0.28 倍，而绝对误差范数基本不变（实测 ~1–2×10⁻⁴ 逐相位近常数）。瞬时比值在 342°/162° 相位膨胀到 5.7%，但同相位逐点误差仅 1.74%。因此门限改用**固定尺度**归一化（对周期内峰值剖面范数），瞬时值仅作诊断记录。

3. **壁面约定敏感**：库的公开壁面函数 `boundaries.bounce_back_cells` 为流后全程 BB（壁面在节点上），与此解析 benchmark 的半程 BB 约定不匹配。实测全程 BB + 节点约定 H=29/59 → 12.5%/10.5% 误差不收敛；换半程 BB 范式 → 4.89%→2.90% 正常收敛。这是库壁面入口与解析 benchmark 约定的配合问题。

4. **体力入口非公开 API**：库的公开 Guo 项 `powerlaw.guo_force_term` 需与 u* 平移碰撞配套（牛顿 BGK 无此入口）。本 benchmark 使用 `turbulent_channel._apply_body_force_2d`（带下划线的模块内函数，非公开 API）。

### 局限

- SDAA 上只能 eager 运行，无法验证编译路径的正确性
- 网格仅两档（H=29, 59），无法做严格的 Richardson 外推
- α=8 高 Womersley 数时边界层薄，H=29 网格分辨率不足（第一流体行误差集中）

### 适用范围

- 本 benchmark 仅验证层流、低马赫（Ma < 0.06）、二维通道配置
- 不适用于湍流、三维、复杂几何的推广

### 显式回答

**是否所有配置所有准则均 <3%？**  
**否**。H=29, α=8 的复振幅误差 4.89% 超过 3% 门限。

**原因分析**：  
α=8 时 Womersley 边界层厚度 δ ~ H/(2α) ≈ H/16，H=29 网格仅 ~2 格分辨率，壁面第一行复振幅误差集中。网格加密到 H=59 后降至 2.90%（<3%），且所有误差单调下降（C4 通过），表明这是**网格分辨率不足**而非算法缺陷。

**总体结论**：  
- 3/4 配置全部门限通过
- 1/4 配置（H=29, α=8）因粗网格下高 Womersley 数边界层分辨率不足导致复振幅超标
- 所有配置网格收敛单调，算法本身正确
- **status = FAIL**（严格按先验门限判定，不降标准）
