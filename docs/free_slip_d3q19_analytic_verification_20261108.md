## 1. 案例介绍：为什么这个壁面必须验证

自由滑移壁不是"边角功能"。它是**溃坝/液舱晃荡/水箱/对称面**这几类算例的默认壁面
（waLBerla `DamBreakRectangular.prm` 全部壁面用 FreeSlip，本仓 docstring 即引用该实现），
也是船海场景里"自由液面舱壁 + 对称面"的标准处理。而在 2026-11-08 之前：

| 项 | 状态 |
|---|---|
| 实现 | D3Q19 三套镜像表 + 4 个入口函数（`src/tensorlbm/boundary/boundaries3d.py`） |
| 测试 | **0 个** |
| 解析判据 | **无** |
| 能力矩阵登记 | `IMPLEMENTATION_ONLY`（"docstring references waLBerla FreeSlip pattern"） |

物理设定（全部格子单位，ρ₀=1，D3Q19 BGK，τ=1 ⇒ ν=1/6，float64）：

| 参数 | 值 |
|---|---|
| 几何 | 通道 (nz,ny,nx)=(4,H+1,4)，H=32 / 64，两侧壁分别在 coord=0 与 coord=H |
| 壁面 | 自由滑移（镜面反射，`axis=1` y 面 / `axis=2` z 面）或无滑移（半路反弹，仅作负控） |
| 初始场 | 剪切驻波 u_x=A·cos(π·coord/H)，A=1e-2；动量案例 u_x=A(1+cos(π·coord/H)) |
| 推进顺序 | 碰撞(全体) → 固体格点回填碰撞前快照(NoDynamics) → 反射 → 周期 streaming，与 `lbm_step_correct` 的 BB 模式一致 |
| 判据 | 解析量相对误差 <1%（平台门槛 15% 的 1/15）；精确量 <1e-12 |

## 2. 怎么做的：三层判据 + 两枚负控

1. **代数层**：把镜像表 `C[mirror]` 与解析镜面映射 `(c_x,−c_y,c_z)` 逐方向比对，
   并检查对合（`mirror[mirror]=identity`）与双射（像集=19）。这一层能抓出"把 x 面表
   接到 y 面"这类错配（突变实验见表末）。
2. **不变量层**：算子是置换 ⇒ 单格点质量、切向动量精确守恒，法向动量精确取反；
   由此推出**两侧自由滑移壁的通道里总 x 动量精确守恒**（自由滑移不吸走动量）。
3. **谱层**：均匀流无寄生阻力（精确不动点）；剪切驻波按 ν=(τ−½)/3 衰减。
   关键手法是**先把剖面拟合成 `a·cos(k(x−δ))` 再算衰减率**——δ 与 k 双自由度最小二乘，
   避免把"壁面在哪"这个未知量硬塞成 0。
4. **负控 A**（动量）：同一初始场、同壁位，只把反射算子换成半路反弹 ⇒ 无滑移壁必须
   持续吸走流向动量。
5. **负控 B**（谱）：余弦驻波在无滑移壁上不满足零切应力 ⇒ 同流程量出的表观 ν 必须
   远离 (τ−½)/3，剖面残差必须很大。
6. **突变实验**（人工注入缺陷，验证判据有鉴别力，不入 CI）：
   * 把 y 面镜像表换成 x 面表：法向/切向动量残差 →2.0，均匀流偏差 →0.333，剪切波误差 →253%；
   * 反射算子退化为恒等：不变量残差 →2.0，剪切波误差 →253%，
     而"动量守恒"仍近似成立——**说明只有不变量层+谱层能抓住这一类缺陷**。

## 5. 注意点 / 局限（不粉饰）

1. **δ≈0.33 lu 只被测量、未被解析推导**。它稳定、自洽、与分辨率几乎无关，
   但"为什么正好是这个值"（与 ghost 格点的回收、cs²=1/3 是否有关）本文没给出推导，
   因此它只能当**经验偏移**用，不能当定理引用。
2. **这条偏置有工程后果**：自由滑移壁上的剪切模态比物理衰减**更快**，
   相对偏置 ≈4δ/H（H=32→4.3%，H=64→2.1%，H=128→1.05%）。
   对溃坝/晃荡这类"用自由滑移壁省网格"的算例，意味着**壁面附近的涡量衰减被人为加速**；
   若算例精度依赖剪切波衰减（如液舱阻尼比），需要用更密的 H 或改用 δ 修正后的判据。
3. **验证面只覆盖 D3Q19 + BGK + 单相 + CPU/float64**。MRT/TRT/Smagorinsky、多相、
   自由液面、IBM 与自由滑移壁的组合未验证；能力矩阵的最终裁决仍是
   `WITHHELD_NO_COMPLETE_COMPOSITION_EVIDENCE`（本次只把 `implementation_status`
   从 `IMPLEMENTATION_ONLY` 抬到 `PHYSICS_VALIDATED`，组合面不假装覆盖）。
4. **周期 streaming 的墙墙回收**：`stream3d` 是周期性 roll，壁格点反射后"出域"的那一支
   会 wrap 到对面壁格点。本文的判据（内部流体格点的守恒量、谱、剖面）显示这一机制
   不污染流体（否则 plug flow 精确守恒与 0.056% 的 ν 恢复都不可能成立），
   但没有单独针对该机制的测试；这是本单**未覆盖**的一项。
5. **NSCBC/远场边界** 仍是 `IMPLEMENTATION_ONLY`（见同一份能力矩阵），本单未触及。
