# 组合滑移边界的二阶重构：清偿 σ→0 的 O(1/H) 振幅偏置

节点：`p247w1-N10` · 来源：`m7963-c1` · 模块：`src/tensorlbm/boundary/partial_slip_second_order.py`
产物：`scripts/p247w1_n10_c6_grid.py`（C6 网格族）、`scripts/p247w1_n10_evidence.py`（κ/Couette/剖面）、
`artifacts/p247w1_n10_c6_grid.json`、`artifacts/p247w1_n10_evidence.json`、

## 1. 缺陷陈述

`partial_slip_wall.mixed_wall_row` 的混合反弹/镜面格式

```
f_q(wall) = (1-σ) f_post[opp(q)](adj) + σ f_post[M(q)](adj)
```

在力驱动（Poiseuille，体加速度 g）下反演出的滑移长度满足

```
b(σ) = 3 ν σ/(1-σ) + c ,      c = u_wall ν / (g H)
```

其中 `u_wall` 是**与 σ、与 H 都无关**的常值伪滑移速度，于是 `c∝1/H`：这就是 m7963-c1 报的
“σ→0 的 O(1/H) 振幅偏置”。基线取值：

| τ | ν | κ=u_wall/g | c = κν |
|---|---|---|---|
| 0.8 | 0.100 | −0.650 | −0.065 |
| 1.1 | 0.200 | +0.575 | +0.115 |
| ≈1.13 | ≈0.21 | −0.665 | −0.140 ⇒ 与 m7963-c1 的 −0.139 同源 |

（κ 在 ν=1/√48 ≈ 0.144 变号，所以“偏置”的符号随 τ 变，单一符号经验模型无法描述。）

## 2. 机制（溯源，不是拟合）

1. 体区定常解精确等于“解析抛物线 + 常值”：逐点残差沿 y 的标准差 ≤ 4e-12，二次拟合曲率比
   1.0000000（`probe_parabola_residual`）。
2. 常值方向是内部定常方程的**零空间**（u′、u″ 都不变）⇒ `u_wall` 只能由壁面条件确定，
   是**壁面伪迹**，不是体区截断误差。
3. Guo 力源项 `(1−1/(2τ))·3w_q c_xq F` 写在壁面相邻流点上，被 `f_post[opp(q)]` 原样反射回
   流体，壁面链路上多出一份 ∝F 的切向动量。对力线性：`u_wall/g` 在 g=1e-5..4e-5 上相对变化
   <1e-4 ⇒ 力项路由伪迹，不是有限 Mach 误差。
4. 闭式（τ 扫描 0.55..1.5 × g 扫描，吻合 2e-7）：

```
κ(τ) = s − 3/(4s) ,  s = 2τ−1 = 6ν        ⇒  u_wall = g [6ν − 1/(8ν)]
```

## 3. 二阶重构

```
δf_q = −2 (1−σ) · 3 w_q ρ (c_q · δ_vec) ,   δ_vec = κ(τ) F_tan/ρ ,   q 指向流体
```

结构性质（全部精确）：

* `Σ δf = 0`、`Σ c_y δf = 0`：质量与法向动量守恒，只补切向动量；法向分量被投影掉。
* `σ = 1`：修正恒为 0 ⇒ 自由滑移负控不受影响。
* `σ = 0`：系数最大（−2），恰好把半程反弹里的伪滑移清掉，`b(0)=0`。
* 权重 `(1−σ)`：切向动量只在反弹（耗散）通道被反转，伪滑移随反弹权重缩放；因子 2 来自壁面
  反馈闭合（反弹把注入的切向动量反向，稳态响应 = 注量的 −1/(2(1−σ))），该因子在 H、g、σ 上
  普适（反解出的最优系数稳定在 −2(1−σ)）。

## 5. 局限

* “力线性”区严格（O(F²) 之外未含）；g ≤ 4e-5 时 O(F²) 残差 <1e-9 相对。
* κ 的闭式是“τ/g 扫描 → 闭式 → 结构一致性核对”，**未**做逐项手推的二阶 Chapman-Enskog
  边界层展开审计。
* 平壁假定：法向任意但切向与力同向；曲线/阶梯壁的组合滑移二阶重构未实现。
* σ=1 时剖面常值由历史决定（物理上 b=∞），不对常数作断言。
* Couette 动壁注入只挂反弹通道（镜面在壁面参考系保守切向分量）；写成两通道共用会让 b 偏大约
  45 倍——这是本节点踩过的坑，注释已写在 `couette_slip` 里。
* H=128 只跑 σ=0.05/0.2（成本：每次定常解受最慢扩散模态支配，~2e5 步）。
