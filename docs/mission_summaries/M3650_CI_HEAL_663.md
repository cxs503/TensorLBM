## Trap: `from tests.<sub> import ...` passes locally, dies in CI

`python -m pytest` puts the CWD on `sys.path`, so the `tests.validation` package
resolved in single-file local runs. CI runs the `pytest` console script (no CWD
entry) **and** the full suite, where `tests/test_apps_api.py` (and friends) put
`app/` on `sys.path` — `app/` also contains a `tests` directory, so the name
`tests` could already be bound to the *wrong* namespace package by the time the
cylinder-drag test was imported:

```
tests/test_cylinder_drag_benchmark.py:35: in <module>
    from tests.validation.cylinder_drag_benchmark import (
E   ModuleNotFoundError: No module named 'tests.validation'
```

Reproduced deterministically with the CI command shape:

```
$ pytest -q -m "not slow"            # before, full-suite collection
ERROR tests/test_cylinder_drag_benchmark.py  (ModuleNotFoundError above)
```

Fix: load the harness module by file path (`importlib.util.spec_from_file_location`)
instead of through the `tests` package name. This is order-independent, works
under both `pytest` and `python -m pytest`, and needs no `__init__.py` churn in
`tests/`.

## Content fixes

1. **The drift gate tripped on its own retraction.** `test_report_numbers_match_registry`
   asserted that the literal `Cd=1.30 (Schäfer-Turek)` was absent from
   `docs/LBM_VERIFICATION_TEACHING.md`, but the retraction sentence quoted that
   exact string, so the guard could never pass. The guard is now line-scoped —
   any line that mentions both `1.30` and `Schäfer` must also carry `错误` (i.e.
   only the retracted form is allowed) — plus it requires the retraction note and
   the `WITHHELD` mark to survive. The quoted claim in the doc was reworded so it
   no longer reproduces the retracted string verbatim.
2. **The teaching doc still sold the un-reproduced Step-E table as a result.**
   The `D=24…200` convergence table has no executable record in this repo (see
   `docs/cylinder_drag_benchmark_r1.md`: no convergence with the current channel
   boundary set), so its heading, the surrounding text and the reference line now
   say **WITHHELD** and the `Cd≈1.30` anchor is attributed to the unconfined 2D
   `Re=100` level (Dennis & Chang 1970), not to DFG 2D-2.
