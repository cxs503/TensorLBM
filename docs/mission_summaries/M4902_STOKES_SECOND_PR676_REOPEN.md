## ① 案例介绍（物理背景 / 几何 / 参数）

半无限静止流体旁的无限平板沿自身平面以 U(t)=U0·cos(ωt) 振荡。充分长时间后流场只依赖 y 与 t，
满足 ∂u/∂t = ν∂²u/∂y²，其周期稳态解析解为经典 Stokes 层：

  u(y,t) = U0·e^(−y/δ)·cos(ωt − y/δ),   δ = √(2ν/ω)  （黏性穿透深度）

本案例取 δ = H/4（H 为域高），即 ω = 32ν/H²；两档网格 δ 分别 = 10 / 20 个格子，
因此**同一组参数下两档网格解的是不同的物理问题**——跨网格比较必须落在相似变量 η=y/δ 上（见 ⑤）。
x 方向周期、流向均匀（nx=8），y 方向 H 格流体 + 上下壁行（ny=H+2）。

| 参数 | 值 |
|---|---|
| 格子 / 碰撞 | D2Q9 / BGK |
| τ / ν / U0 | 0.65 / 0.05 / 0.05（Ma=0.0866） |
| H ∈ | 40, 80（门内两档，δ/Δx=10, 20）；16, 160（诊断档，δ/Δx=4, 40，非 prereg） |
| ω (H=40 / H=80) | 1.0000e-03 / 2.5000e-04（1/lattice time） |
| 周期 T (H=40 / H=80) | 6283.2 / 25132.7 步 |
| 边界 | 顶壁 pre-streaming half-way 动壁反弹（每步 u_w=U0·cos(ωt)）；底壁静止 half-way BB；x 周期 |

## ② 怎么做的（方法 / 流程 / 工具链）

* 求解路径全走库原语：`d2q9.equilibrium/macroscopic` + `solver.collide_bgk` + `solver.stream`（x 周期内建）；
  动壁替换由案例内 `moving_wall_replacement` 给出（半程 BB，U=0 退化为静止 BB），
  壁速作为**标量张量参数**传入编译步（图动态、不逐值重编译）。
  无修正因子、无外推、无结果调参，从静止初场出发。
* 预注册记录点：相位 ωt∈{0, π/2, π} × 早/晚两个周期（H=40: k=6/8；H=80: k=3/4），瞬态 e^(−ωt/2) 已衰减；
  另设同相位早/晚周期剖面差作为**周期稳态自检**。
* 判决门：主口径 max 相对误差（\|u_ana\|>10%·U0 掩码）≤3%；H=80 不劣于 max(H=40 值, 3%)；
  周期稳态差 ≤0.5%·U0；每个采样点同时输出 5%·U0 掩码值（prereg 原文口径）供审计。
* 工具链：`benchmarks/compile_route.py`（默认 default，本机回退 eager）、CPU、fp32；无 GPU 需求（本例 CPU 秒级–分钟级）。

**本轮修掉的 3 个骨架缺陷**（此前案例从未产出 result.json 的直接原因）：

1. `period_convergence()` 返回 `numpy.bool_` → `json.dumps` 抛 `TypeError`，**判决档永远写不出来**（`bool()` 修复）。
2. scan 模式打印 `pc['H']` 时 `KeyError`——该函数契约上不带 `H` 键（result.json 已写、随后崩在打印）。
3. `compare_grids()` 把**降序**的 y_profile 直接喂给 `np.interp`（剖面按距壁距离存储，H+0.5−i 递减），
   跨网格剖面差读出 97.7%·U0 这种「两档各自对解析解 0.2% 却互差 97%」的自相矛盾值；已 argsort 修正，
   并把该指标重定义为相似变量 η=y/δ 下的塌缩差（同 y 比较因 δ 随 H 变而物理上不可比，已在 result.json 注明）。

回归守卫：`tests/test_stokes_second_problem_benchmark.py`（4 passed，CPU ~15 s；覆盖上述 3 缺陷 + H=16 粗网格物理健全性）。

## ⑤ 注意点（坑 / 局限 / 适用范围）

* **prereg 口径偏差（必须披露）**：骨架设计文本写的是「\|u_ana\|>5%·U0 掩码 ≤3%」，而继承下来的 run.py 已把主判据掩码
  改为 10%·U0 并同时输出 5% 值。5% 掩码下实测 5.157%（H=80 φ=π/2；两档各相位 4.2–5.2%），**按原文口径不达标**；
  10% 掩码下 2.160%。两条都列在表里，不做取舍性隐藏。掩码敏感的物理原因：Stokes 层内 cos/sin 有过零点，
  \|u_ana\|→0 处相对误差发散而绝对误差只有 ~1.4%·U0（见表 max abs 列与右图）；但这只是「为什么」，不是豁免——
  因此本案例**不自行晋级** `verified/`，留在 `pending/` 等审计确认掩码口径。
* **两档网格解的是不同物理问题**（δ=H/4 以格计）：任何「同 y 剖面差」都按 O(δ) 存在（实测 22–34%·U0），不是离散误差；
  收敛判据必须落在相对误差或 η 相似坐标上，这也是本轮修缺陷 3 的根因。
* **分辨率阈值（本轮新测）**：诊断档 δ/Δx=4（H=16）时 φ=π/2 的最大相对误差跳到 15.76%，
  而 δ/Δx≥10 后即 ≤2.16%（10/20/40 格对应 2.16%/1.01%/0.66%）——半程动壁 BB 的 Stokes 层需要
  **每层 ≥10 格**才可用；这是可直接引用的工程使用边界。
* 收敛条款只要求「加密不变差」，不构成精度阶估计；确凿的阶数需要固定 δ、仅加密 Δx 的变体（**未做**）。
  H=160（δ/Δx=40，仅 1 档、非 prereg）最差相位 1.452%，与 H=80 的 1.012% 同量级，
  说明误差已在约 1% 地板附近，而非干净的 1 阶/2 阶幂律段。
* 适用范围：低 Ma（0.0866）、层流周期边界层；不含壁面曲率/压缩性/热效应；动壁路径为 half-way BB，
  与 verified/couette_2d 同一路径，本案例是其**时间非定常**孪生。
* 主机环境差异：本机（99 控制面，load≈200）上复跑 H=40/80 时需限制 OMP 线程数，否则线程超额认购会拖慢
  一个数量级；result.json 内的 `elapsed_s` 是原始测量值，不含该差异。

## ⑥ 误差判定（逐项 vs 解析解 / 基准）

| 关键量 | 基准 | 实测（晚周期，10%-mask） | 误差 | 是否 <3% |
|---|---|---|---|---|
| u(y) 剖面 max 相对误差, H=40（δ/Δx=10） | Stokes 层解析解 | 2.160%（φ=π/2 最差） | 2.160% | **是** |
| u(y) 剖面 max 相对误差, H=80（δ/Δx=20） | Stokes 层解析解 | 1.012%（φ=π/2 最差） | 1.012% | **是** |
| 同相位周期稳态差（H=40 / H=80） | 0（周期稳态） | 0.0299% / 0.0232%·U0 | — | **是**（门 0.5%） |
| 跨网格 η=y/δ 塌缩差（H=40 vs H=80） | 0（同一解析解） | ≤2.437%·U0 | — | **是** |
| L2 相对误差（全部采样点） | Stokes 层解析解 | 0.96–3.31% | — | 是（φ=0/π 组 <1%） |
| 5%·U0 掩码（prereg 原文口径） | Stokes 层解析解 | 5.157% | 5.157% | **否**（口径冲突，见 ⑤） |

**结论（不粉饰）**：按案例自身判决口径（10%·U0 掩码 + 加密不变差 + 周期稳态）**通过，关键量 2.160%/1.012% 均 <3%**；
按 prereg 原文 5%·U0 掩码口径**不通过（5.157% >3%）**。两项如实记录，晋级决定权交审计。
