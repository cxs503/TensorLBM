# GAP-PP-4-opt-loop: Taylor-Green τ/Re Recovery via Differentiable LBM Optimisation

## 1. 案例介绍（物理背景/几何/参数表）

**物理背景**: Taylor-Green 涡是不可压 Navier-Stokes 方程的精确解析解，其速度场随时间呈指数衰减：

$$u_x(x,y,t) = A u_0 \sin(kx)\cos(ky) e^{-2\nu k^2 t}$$
$$u_y(x,y,t) = -A u_0 \cos(kx)\sin(ky) e^{-2\nu k^2 t}$$

其中 $k = 2\pi/L$，$\nu = (\tau - 1/2)/3$ 为运动粘度。在 LBM 框架下，该衰减模式与 BGK 碰撞算子的离散时间演化完全一致，因此可作为反问题验证的"标准答案"。

**几何**: 周期性方盒，一边长 $L = n$ 个格子间距，$n \in \{16, 32\}$。D3Q19 格子，$n_z = 1$（已验证单 z 层与多层结果一致）。

**参数表**:

| 参数 | 值 | 说明 |
|------|-----|------|
| $u_0$ | 0.05 | 峰值初速（格子单位），$Ma \approx 0.087$ |
| $\tau_{true}$ | 0.55 | 真实松弛时间 |
| $\nu_{true}$ | 0.01667 | 真实运动粘度 |
| $Re_{true}$ | 48.0 (n=16) / 96.0 (n=32) | 真实雷诺数 |
| 观测点数 | 4 | 跨越 1 个 e-fold 衰减窗口 |
| 优化器 | Adam + L-BFGS | Adam 2 步 + L-BFGS 10 步抛光 |
| 学习率 | 0.3 | 余弦衰减 |
| 种子 | 0, 1, 2 | 可复现性验证 |

## 2. 方法/流程/关键设置

**核心方法**: 通过可微 LBM 步进链（`tensorlbm.autograd_path.rollout`），将离散时间步进算子本身放入反向传播图，从而对物理参数 $\tau$ 求导。

**关键设计选择**:

1. **优化 $\log \nu$ 而非 $\tau$**: 保证 $\tau > 0.5$ 的物理稳定性约束通过盒约束实现，而非损失函数中的障碍项。
2. **振幅 nuisance 参数**: 初始振幅 $A$ 作为自由参数拟合，吸收格子采样偏差（$n=16$ 时离散峰值为连续值的 0.962 倍）和平衡态初始条件的压缩性偏移。
3. **Adam + L-BFGS 抛光**: Adam 快速下降到大致区域，L-BFGS（强 Wolfe 线搜索）闭合最后差距。
4. **相对 MSE 损失**: $L = \frac{1}{N_t}\sum_t \frac{\|u_{sim} - u_{obs}\|^2}{\|u_{obs}\|^2}$，每个观测时刻等权重。

**流程**:
1. 生成观测数据（解析解或 twin 实验）
2. 从种子生成扰动初始猜测 $\tau_{init} = \tau_{true} \times (1 + \epsilon)$，$\epsilon \sim U(-0.25, 0.25)$
3. Adam 优化 2 步（余弦衰减学习率）
4. L-BFGS 抛光 10 步
5. 记录每步收敛历史到机读 JSON

## 3. 计算结果

### 3.1 各轨道 τ/Re 恢复结果

| 轨道 | $\hat{\tau}$ | $\hat{Re}$ | 相对误差 | 通过 <3% |
|------|---------|---------|----------|----------|
| analytic16 | 0.55009 | 47.914 | +0.18% | ✅ |
| analytic32 | 0.54995 | 96.096 | -0.10% | ✅ |
| twin16 | 0.55000 | 48.000 | ~0.00% | ✅ |
| analytic16_fixed | 0.54829 | 49.698 | -3.42% | ❌ (控制臂) |
| twin16_noise0.2 | 0.54998 | 48.009 | -0.04% | ✅ |
| twin16_noise1.0 | 0.54995 | 48.045 | -0.11% | ✅ |

### 3.2 关键发现

- **Twin 实验精确恢复**: twin16 轨道误差 ~0.000%，验证优化器和梯度的正确性。
- **振幅 nuisance 的必要性**: analytic16_fixed（固定振幅）误差 -3.42%，超过 3% 阈值；自由振幅降至 +0.18%。
- **网格收敛**: n=32 比 n=16 误差更小（-0.10% vs +0.18%），符合预期。
- **噪声鲁棒性**: 即使 1% 噪声，误差仍 <0.5%。
- **3 种子可复现**: 每种子的结果完全一致（无噪声轨道）或高度一致（有噪声轨道）。

## 5. 注意点

- **控制臂故意失败**: analytic16_fixed 是控制臂，用于证明振幅 nuisance 参数的必要性。其 -3.42% 的偏差是预期行为。
- **计算成本**: n=16 单作业约 26 秒，n=32 约 100 秒。全 6 轨道 × 3 种子约 14 分钟。
- **适用范围**: 本 demo 针对周期性 Taylor-Green 衰减；复杂几何/边界条件需要额外的可微边界处理。
- **局限性**: 当前仅支持单组分 D3Q19 BGK 族碰撞；多组分/非 BGK 碰撞需要扩展 autograd_path。
