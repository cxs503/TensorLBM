# Mission 40 补报：SDAA 验证案例扫荡 — Sod 激波管 (D2Q9 等温)

## 1. 案例介绍

**案例**：等温 Sod 激波管（D2Q9，BGK 碰撞）
**物理问题**：一维激波管，初始密度间断 ρ_L=1.0 / ρ_R=0.25（密度比 4:1），速度 u=0，τ=0.8（ν=0.1），ny=4（y 向均匀周期）。
**参照解**：等温 Riemann 解析解（p=ρ/3，c_s²=1/3）。注意 D2Q9 平衡态强制等温 EOS，经典 γ=1.4 Sod 解**不适用**。
**解析值**：ρ*=0.49662，u*=0.40410（Ma_mid=0.70），激波速度 W=0.81373。
**设备**：SDAA (`/dev/tcaicard1`)，无 Triton 依赖（核心路径 equilibrium/stream/collide_bgk 均为纯 torch ops）。

## 2. 方法

1. **独立运行脚本**：`scripts/sdaa_sweep_sod_shock_tube.py`，不改业务代码。
2. **两档网格**：nx=2000 (t=400) 和 nx=4000 (t=800)，周期边界 x 方向产生镜像 Riemann 问题，所有指标仅在干净区 [c_s·t, nx−W·t] 内计算。
3. **声学补充**：小扰动 ε=0.01（线性声学 Ma≈0.01）和 ε=0.25（Ma≈0.26），验证弱可压缩声学能力。
4. **判据门控**（10 项 gates）：稳定性（无 NaN/负密度）、L2(ρ)≤3%、|W_rel|≤3%、|ρ*_rel|≤3%、|u*_rel|≤3%、单调收敛。
5. **激波位置**：窗口 [xd+0.5·W·t, xd+1.5·W·t] 内取 |∂ρ/∂x| 最大格，线性拟合得 W_fit。

## 5. 注意点与局限

1. **等温 EOS 限制**：D2Q9 无能量方程，温度固定——不能表示 γ-law 气体、无接触间断、无激波熵增。经典 γ=1.4 Sod 不在本模型能力内。
2. **激波马赫上限**：等温激波 W=c_s√r 必须 <1（格点最大速度）→ 单一激波密度比 r<3；本 4:1 管 r≈1.985 可表示，但 8:1 管（r≈2.77）在 step 50 内发散。
3. **BGK 无限制器**：激波处有 ~2.6%Δρ 的局部振荡（本案例 ≤3% 仍达标），更强激波振荡增大直至发散。
4. **τ 稳定性边界**（4:1 管）：τ=0.55 → step 200 发散、τ=0.6 → step 400 发散、τ≥0.65 稳定。
5. **周期边界镜像**：x 周期产生镜像 Riemann 问题，所有指标仅在干净区内计算。
6. **Triton 绕行**：本案例核心路径无 Triton 依赖，无需 TRITON_INTERPRET=1 绕行。

## 6. 误差判定

**关键量误差是否 <3%？—— 是。**

| 关键量 | nx=2000 | nx=4000 | 判定 |
|--------|:---:|:---:|:---:|
| L2(ρ)/Δρ | 0.84% | 0.46% | <3% ✅ |
| |W_rel| | 0.090% | 0.029% | <3% ✅ |
| |ρ*_rel| | 0.016% | 0.007% | <3% ✅ |
| |u*_rel| | 0.041% | 0.026% | <3% ✅ |

所有关键量误差均远小于 3%，且随网格加密单调下降（L2(ρ): 0.84% → 0.46%），验证了 D2Q9-BGK 求解器在等温可压缩流方面的正确性。
