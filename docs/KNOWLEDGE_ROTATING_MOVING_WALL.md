# 蒸馏：旋转/移动壁 LBM 的力矩锚与阶梯壁质量契约

**规则（最小可执行形式）**

1. **弯壁（阶梯）移动壁必须逐节点质量守恒**：`ForcedD3Q19(mass_conserving_walls=True)`（默认），
   并在结果里**报出实测相对质量漂移**。格点对齐的平壁无需改动（该修正的加权均值恒为零）。
2. **弯壁力矩锚只能用剖面恒等式** $T(r)=2\pi\rho\nu L r^2\,(du_\theta/dr-u_\theta/r)$（应 r-无关，
   且 $=4\pi\mu L|B|$）；**不能用**局部 Ladd 动量交换和（粗阶梯上压力项不精确抵消）。
3. **D3Q19 弯壁移动壁暂不得作为已验证锚**；Couette 类锚用 D2Q9 环隙（`RotatingAnnulusD2Q9`），
   直到实现无滑移伪影的插值反弹（Bouzidi 型）并给出证据。

**适用边界**

- 适用：任意 LBM 代码中「壁面与格点不对齐且壁面在运动」的工况（旋转圆柱、叶轮、Taylor–Couette、旋转方管若有运动壁）。
- 不适用：格点对齐的平壁（半程反弹 + Ladd 对平壁质量守恒，实测漂移 6e-13、剖面误差 3e-6）；
  无移动壁的旋转流（Coriolis/离心力项不涉及壁面质量交换，实测漂移 7.7e-13）。
- 2D（D2Q9）阶梯移动壁的注入量比 3D（D3Q19）小一个量级（实测 2e-3 vs 2.6e-2），但**同源**，不要以为 2D 就安全。

**机理**

阶梯圆壁在轴线附近的角点处，某节点的壁面链接集合对 $k\to\bar k$ **不闭合**，于是
$\sum_{k\in\text{wall links}} w_k(\mathbf c_k\cdot\mathbf u_w)\ne0$：每个这样的节点每步注入/抽走质量。
壁面总注入为零，但节点分布的主谐波是 **m=2**（实测谐波幅值 m2 = 6.9e-3 vs m4 = 7.6e-5），
质量源本身带 m=2 对称性 ⇒ 驱动 m=2 虚假速度场（实测 $u_\theta$ 呈四象限 ±30e-3 的反向分布）。
减去节点加权均值 $\langle\mathbf c_k\cdot\mathbf u_w\rangle$ 使注入恒为零；但阶梯壁半程位置的几何误差
（轴向 1 格 vs 对角 $1/\sqrt2$ 格）仍造成切向动量滑移，故剖面误差仅从 59% 降到 14%。

**失败过的做法（保留，别再踩）**

- 用局部动量交换力矩作锚：压力项残差主导（差两个量级）。
- 仅把质量守恒化就以为修好：质量漂移归零但 m=2 速度场仍在（13.8%）。
- 加密网格解决：阶梯相对壁厚不随加密等比改善（$60^2$、gap=12 与 $40^2$、gap=8 结果同量级）。
- 换初值（静止起动 vs 解析初值）：稳态伪影相同，不是瞬态。
