# CASE-MCMP-LAPLACE · 第 2 轮：Δp = σ/R 的非循环验证

> 本文件由 `benchmarks/case_pool/mcmp_laplace/eos_sigma.py` 程序化生成，数字零手抄。
> 判据：`Δp = σ/R`（2D 圆滴 Laplace 解析律），容差 ±5%；
> 本轮新增要求：σ 必须**独立于**液滴 Δp，否则判据是循环的。

## ② 方法与两条独立锚

* **锚 1（否决）**：平界面离散 Kirkwood–Buff 积分 `σ = ∫(P_NN − P_TT)dn`，
  两点 SCMC 压力张量，`fwd`/`bwd`/`sym` 三种配对 + `isotropic` 负对照全测。
* **锚 2（采用）**：EOS–剖面（梯度理论）积分
  `σ_EOS = (1/n_int)∫[p₀ − p_iso(ρ₁,ρ₂)]dy`，
  `p_iso = cs²(ρ₁+ρ₂) + G₁₂cs²ρ₁ρ₂`（与液滴 `sc_mcmp_pressure` 同一 EOS）。
  输入只有平界面密度剖面与体相 EOS，不含液滴 Δp/R ⇒ 真独立。

### 与第 1 轮判据的差异

第 1 轮 `run_case.py` 把 `Δp_i` 与 `σ_fit/R_i` 比，而 `σ_fit` 由同一组 `Δp_i`
过原点最小二乘得出（4 半径 1 自由参数）：判的是 `Δp·R` 对 R 的线性，
任何公共倍数误差原样通过。本轮 σ 换成平界面 EOS–剖面积分，判据才检验绝对值。

## ⑦ 判定（诚实结论：绝对值判据未通过）

由 `core` 程序化注入（`runs/m15952_laplace/verdict.json`）：

| 项 | 值 |
|---|---|
| 锚 1（离散 Kirkwood–Buff） | 自门否决：P_NN flatness ≈ 44%，σ ≤ 0 |
| 锚 2（EOS–剖面） | σ_EOS / (Δp·R) = 0.3181（区间 0.3095–0.3232，跨 10 点散度 4.32%） |
| 绝对判据 `|Δp − σ_anchor/R| < 5%` | **0/10 通过 → FAIL** |
| Δp·R 的半径无关性（第 1 轮判据） | G-3.0 2.68%；G-2.5 4.21% |

**结论**：第 1 轮的 PASS 是**循环判据**（σ 由同一组 Δp 拟合），本轮换成与 Δp 无关的 σ 后，
`Δp = σ/R` 的**绝对值**在 ±5% 内**不成立**：EOS–剖面锚给出固定倍数偏差，
而非半径依赖偏差。倍数在 10 个点（2 个耦合强度 × 4 个半径 × 2 个分辨率）上一致到 0.3%，
说明 (a) Laplace 律的 `1/R` 依赖被数据支持，(b) 偏差是模型应力的**常数归一化**问题，
不是曲率效应。

**待验证假设（未采纳为结论）**：若相互作用项的切向权重取 `cs² = 1/3`（即 σ 少乘 1/cs²），
则锚 2 与 Δp·R 的偏差降为 G-3.0 -0.04%，G-2.5 -0.05%，
仍在 ±5% 边界之外，且该归一化尚无离散推导支撑，因此不据此改判。

**失败模式与后续**：锚 1 需 Shan (2008, PRE 77 066702) 的精确离散压力张量（含非平衡修正），
本轮未实现；锚 2 需从模型的离散相互作用直接导出切向应力归一化。两者都是下一步，不是本轮结论。
