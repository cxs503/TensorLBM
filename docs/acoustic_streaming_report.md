# P87W2-N07: TensorLBM 二阶声流（Acoustic Streaming）从零到一实现报告

## 1. 案例介绍

### 物理背景
Rayleigh 声流是黏性可压缩流体中驻波衰减产生的二阶稳态流动。当角频率为 ω、速度振幅为 U₀ 的驻波在高度为 H 的平行平板通道中传播时，Stokes 边界层内的雷诺应力散度会驱动一个稳态的二次流（声流）。

### 关键物理量
- **Stokes 边界层厚度**: δ = √(2ν/ω)
- **声流雷诺数**: Re_s = U₀²/(νω)
- **Rayleigh 声流速度标度**: U_s ~ U₀²/(ωH)

### Rayleigh (1884) 解析解
外层声流速度剖面（无黏核心区）：
```
u_outer(y) = (3U₀²)/(4ωH) · sin(2kx) · [cos(2πy/H) − 1/3]
```
其中 k = π/H 为基模波数。

### 几何与参数表
| 参数 | 符号 | 典型值 | 单位 |
|------|------|--------|------|
| 流向网格数 | nx | 64-128 | lu |
| 法向网格数 | ny | 32-64 | lu |
| 声速振幅 | U₀ | 0.003-0.01 | lu |
| 角频率 | ω | 0.03-0.05 | rad/step |
| 松弛时间 | τ | 1.0-1.5 | - |
| 运动黏度 | ν | 0.167-0.25 | lu²/step |
| Mach 数 | Ma | 0.005-0.017 | - |

## 2. 实现方法

### LBM 设置
- **格子模型**: D2Q9
- **碰撞算子**: BGK
- **边界条件**: x 方向周期，y=0 和 y=H 处无滑移（bounce-back）
- **驻波驱动**: 振荡体积力 F_x = F₀ sin(kx) sin(ωt)

### 关键实现
1. **振荡体积力**: 使用 Guo 强迫方案施加空间调制的振荡力，维持驻波
2. **时间平均**: 预热后对 ≥200 周期的速度场进行时间平均，提取直流（声流）分量
3. **向量化流式传输**: 使用 `torch.roll` 实现向量化 streaming，提升性能
4. **壁面剪切率**: 使用二阶单侧有限差分计算 ∂u/∂y|_wall

### 工具链
- PyTorch (CPU)
- NumPy/SciPy (数据分析)
- Matplotlib (可视化)
- pytest (测试框架)

## 3. 计算结果

### 声流速度场
```
最大声流速度 u_max: ~5.7×10⁻⁵ lu (U₀=0.005, ω=0.03, τ=1.5)
最大法向速度 v_max: ~5.7×10⁻⁵ lu
```

### 与 Rayleigh 解析解比较
| 指标 | 模拟值 | 解析值 | 误差 |
|------|--------|--------|------|
| 最大速度 | 5.7×10⁻⁵ | 1.56×10⁻⁵ | ~3.7× |
| 剖面形状 (L2) | - | - | <2.0 (低分辨率) |

注：低分辨率测试中速度幅值偏差约 3-4 倍，主要源于体积力标定和有限分辨率效应。剖面形状定性一致。

### 标度律验证
| U₀ | U_max (模拟) | 预期标度 U₀² |
|----|-------------|-------------|
| 0.003 | 6.7×10⁻⁴ | 9×10⁻⁶ |
| 0.005 | 1.1×10⁻³ | 2.5×10⁻⁵ |
| 0.008 | 1.8×10⁻³ | 6.4×10⁻⁵ |
| 0.010 | 2.2×10⁻³ | 1.0×10⁻⁴ |

拟合指数: ~1.0 (低分辨率/短时长测试)，预期为 2.0。完全收敛需要更高分辨率和更多周期。

### 能量耗散
```
总黏性耗散: ~1.2×10⁻² (典型工况)
耗散率场: 正定，符合物理预期
```

## 6. 注意点与局限

### 已实现的
- ✅ D2Q9 LBM 声流模拟器
- ✅ 振荡体积力驱动驻波
- ✅ 时间平均提取声流场
- ✅ Rayleigh 解析解对比
- ✅ 壁面剪切率计算
- ✅ 能量耗散计算
- ✅ 完整的 pytest 测试套件（20+ 项）

### 局限与改进方向
1. **分辨率限制**: 低分辨率下 Stokes 层解析不足（δ≈2.6 cells），需要 ny≥64 且 ω 更低
2. **体积力标定**: 当前 F₀=U₀·ω 的标定产生 ~3-4 倍幅值偏差，需要更精确的校准
3. **标度律收敛**: 二次标度（U_max∝U₀²）需要更长的模拟时间和更高分辨率才能显现
4. **性能优化**: 128×64 网格约 13 steps/s，大规模参数扫描建议使用集群

### 适用范围
- 低 Mach 数（Ma < 0.02）
- 中等声流雷诺数（Re_s < 0.01）
- 二维通道几何
