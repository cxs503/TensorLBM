## 质检方法说明

1. **结构检查**: 逐篇核对五节（目的/方法/关键结果/审计/局限）是否存在
2. **数字溯源**: 每篇抽 3 个关键数字，grep 对应 mission 的 `artifacts/*.json` 复核
3. **honest-FAIL**: 检查原结论为 FAIL 的报告是否被粉饰
4. **图件**: 检查场量云图+比较曲线是否齐备，缺类是否有理由
5. **误差判定**: 检查是否逐项列出误差并显式回答 <3%
6. **结论审查**: 检查是否有超出数据支撑的断言
