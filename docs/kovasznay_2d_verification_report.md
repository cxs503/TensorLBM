## 1. 案例介绍

### 物理背景
Kovasznay 流是二维定常不可压 Navier-Stokes 方程的经典解析解，描述网格后方的层流尾迹。该解在 CFD 验证中被广泛使用，因其提供了精确的速度场和压力场参考值。

### 解析解
$$u(x',y') = U_0 \left[1 - e^{\lambda x'}\cos(2\pi y')\right]$$
$$v(x',y') = U_0 \frac{\lambda}{2\pi} e^{\lambda x'}\sin(2\pi y')$$
$$p(x',y') = \frac{1}{2}U_0^2 \left[1 - e^{2\lambda x'}\right]$$

其中 $\lambda$ 是方程 $\lambda^2 - Re\cdot\lambda - 4\pi^2 = 0$ 的负根：
$$\lambda = \frac{Re}{2} - \sqrt{\frac{Re^2}{4} + 4\pi^2}$$

### 参数表
| 参数 | 值 | 说明 |
|------|-----|------|
| Re | 40 | 雷诺数 |
| U0 | 0.03 | 特征速度（晶格单位） |
| λ | -0.9637405 | 衰减率（精确计算） |
| Ma_max | 0.104 | 最大马赫数 |
| τ | 0.572/0.644/0.788 | 松弛时间（ny=32/64/128） |
| 域 | x'∈[0,3], y'∈[0,1] | 3 个 y 周期长度 |
| 网格 | 96×32, 192×64, 384×128 | D2Q9 晶格 |

### 边界条件
- **入口** (x=0): Zou-He 速度边界（解析 Dirichlet）
- **出口** (x=nx-1): 零梯度 Neumann (∂f/∂x=0)
- **y 方向**: 周期边界

## 2. 方法

### 数值格式
- **晶格**: D2Q9（标准序：0 静止，1-4 轴向，5-8 对角）
- **碰撞**: BGK (Bhatnagar-Gross-Krook)
- **迁移**: 标准 shift 操作（y 向周期 roll，x 向边界覆盖）
- **稳态判据**: ‖u(t)−u(t−2500)‖₂/‖u(t)‖₂ < 5e-5

### 独立复核实现
独立审计脚本 (`benchmarks/verified/kovasznay_2d/independent_audit.py`) 使用**完全不依赖 tensorlbm 求解器**的自包含 D2Q9 BGK 实现，确保验证的独立性：
- 自实现 equilibrium、stream、zou_he_inlet
- 自实现 N-S 残差计算（离散差分算子）
- 自实现误差度量（L2 相对误差、掩模最大相对误差）

### 验收判据
- 速度场 L2 相对误差 vs 精确解 < 3%（Re=40, N≥128）
- 网格收敛：ny=64→128 各误差指标单调下降
- 全场有限（无 NaN/Inf）
- 稳态达到（最小步数 ≥ 20000）

## 5. 注意点

1. **出口边界条件是主要误差源**：零梯度 Neumann 出口在短域内会严重污染 v 分量（短域 x'∈[0,1] 时 v 最大相对误差 ~96%）。本算例采用 x'∈[0,3] 长域，使出口处 e^{λx'} 衰减至 0.056 以下，全场误差 ≤3%。

2. **可压缩性底噪**：BGK 格式的 O(Ma²) 可压缩性误差在 U0=0.03 时贡献约 1% 的绝对误差。这是方法固有局限，非网格离散误差。

3. **λ 值纠正**：任务书"λ≈−0.5"口径错误，精确值 λ(Re=40)=−0.9637。

4. **v 分量误差较大**：v 的幅值远小于 u（max|v|/U0 ≈ 0.15），导致 v 的相对误差天然较大。掩模判据（|v_ana|>0.1·max|v_ana|）排除了近零值区域的噪声放大。

5. **质量泄漏**：Zou-He 入口 + 零梯度出口存在 ~0.005%/20000 步的缓慢质量泄漏，不影响速度场收敛。

6. **独立实现验证**：独立审计脚本在 ny=32/64 与主求解器偏差 <0.1%，且反例测试（Zou-He 配对错误）正确捕获发散，证明审计工具有判别力。
