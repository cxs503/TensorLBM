## ① 问题与参考出处（零手抄）

**问题**：TensorLBM 有两相 Shan-Chen（`src/tensorlbm/multiphase.py`）与若干 Allen-Cahn 相场核
（`cac_lbm2d`、`phasefield/cac_h_population`，**速度给定**），但**没有**"压力演化"型速度求解器：
即压力由 `p` 自身演化方程推进、与密度不通过状态方程耦合的公式。TCLB 有这一支
（Fakhari-Geier-Lee 血统，被报头声称已过 layered Poiseuille / Rayleigh-Taylor / 平面气泡）。
本单回答：**该公式能否被本仓采纳，其离散核与 OSS 是否同族、差多少，Laplace 压力跳变能否定量复现。**

**参考侧不可执行（生态摩擦，如实记）**：OSS 模型生成器是 **Python 2**
（`Dynamics.c.Rt` L51 `from cStringIO import StringIO`），工具链需 `nvcc`；本机 `python2`/`nvcc` 均不存在
（`which nvcc` 空、`python2 --version` → not found）。因此**没有做 TCLB 二进制输出的逐场对照**，
判据落在**解析参考**上（见 ④），OSS 侧只做**源码文本的程序化抽取 + 结构化等价核验**（P1–P14）。
这一点是本报告的硬性适用边界，不做"已与 OSS 数值一致"的宣称。

## ② 方法与实现

**Arm P（port）**＝本单新增 `src/tensorlbm/phasefield/pf_pressure_evolution.py`（clean-room，
按公开公式实现，数字不在源码里手抄）：D2Q9 双群 `f`（承压）/`h`（相场），float64 PyTorch，周期 pull 流式。
一步为：`φ=Σh` → `ρ=ρ_l+Δρ·φ̃`、`μ`、`∇φ` → `u=(3/ρ)[Σf c + (μ∇φ+F_b)/6]` →
`p=Σf+Δρ(∇φ·u)/6` → `gbar^eq=Γρ/3+w(p−ρ/3)` → `R=f−gbar^eq+½I(中心差分)+½F_b` →
MRT 只松弛 p_xx/p_xy（`1/(τ+½)`）→ `f←f−R'+I(混合差分)+F_b` → h 碰撞（用**已碰撞** f 的速度，与 OSS stage 顺序一致）→ 流式。

**结构核验（P1–P14，零手抄）**：把抽取到的文本重建为可求值表达式，在光滑随机场（确定性、种子固定）上与移植实现
逐点相减。**14 项全部 PASS，最大残差 8.3e-17**（P1/P2/P3/P5/P8/P9/P11/P12/P13/P14 = 0）。

**物理判据（解析参考，替代不可执行的 OSS 二进制）**
- **G1** 静态液滴 → 二维 Young-Laplace `Δp = σ/R_eff`，`R_eff=√(A/π)` 由守恒的过量相面积 `A=Σφ` 测得（无自由参数）；
- **G2** Taylor-Green `u_x=U sin(ky)` → 拟合 `ν = −slope/k²` vs 输入 ν；
- **G3** 相质量守恒（`Σ_i θw_i(c_i·n)=0` 由格点对称性成立 ⇒ 应到机器精度）；
- **G4** `Δp` 对密度比的独立性（同 R、同参数，ratio 1 vs 100）。

## ⑤ 收敛性 / 参数敏感性（≥2 点）

1. **界面分辨率 R/W**（W=4 固定，R=13→23，即 R/W=3.25→5.75）：err 由 +0.99%→−2.66%（ratio 1）
   与 −1.91%→−3.13%（ratio 100），非单调、量级 ~1–3%，无发散趋势 ⇒ 判据不是某单一 R 的偶然。
2. **迁移率 M**（ratio 1，R=20）：M=0.02 → +1.46%，M=0.05 → −1.94%，M=0.10 → −2.61%；
   寄生流 `|u|max` 1.24e-4/7.47e-5/7.36e-5 ⇒ `Δp` 对 M 只有 ~1% 量级敏感，宽 M 区间内判据稳定。
3. **密度比**（R=20）：ratio 1/10/100/1000 → −1.94/−2.75/−2.98/−3.02%。寄生流随密度比**单调下降**
   （7.5e-5 → 5.2e-7），即高压差工况下压力场更干净——这正是"压力演化"公式的宣传性质（G4=1.06% 佐证）。
4. **时间收敛**：ratio 100 在 2500–4000 步即满足 `|Δdp|<2e-3·dp_ref`（conv=True）；ratio 1 到 6000 步仍缓慢漂移
   （conv=False，如实标注），漂移源见 ⑥-3。

## ⑥ 失败模式、局限与工件

1. **OSS 不可执行**（结构性局限）：报出"Python 2 + nvcc 缺失"作为生态摩擦，并把它转成方法选择——OSS 侧做文本抽取 + 结构化核验，数值判据落在解析解。这是本报告最重要的适用边界。
2. **移植期两个真实陷阱（已入负知识候选）**
   - **黏性矩索引**：TCLB 的 `S[7]/S[8]` 是 **0 基**矩向量下标（p_xx/p_xy）；若按"1 基第 7、8 个"误读成 0 基 6、7，则松弛落到 q_y/… 上，**ν 与输入无关、恒为 1/6**——G2 立刻给出 +66.7% 误差抓住它（这就是把 G2 放进判据的理由）。
   - **混合差分末项符号**：`Rm=¼(−φ_{+2c}+5φ_{+c}−3φ_0−φ_{−c})`，末项是**减**。写成加号时 `Σ_i I_i≈½φ_0≠0`，f 群获得恒定压力源，`|p|` 随步数线性增大直至 nan（32² 小算例 11 步即见 |p| 从 1e-3 涨到 1.3e-2）；测试 `test_interface_term_has_no_pressure_source_when_static` 固化了这一性质。
3. **OSS 继承缺陷（非移植缺陷）**：混合（迎风）差分的权重和只到二阶为零，实测 `Σ_i I_i = 3.0e-5`（力标度 3.0e-4 的 10%，W=4）⇒ f 群有 O(截断) 压力源，正是 ratio=1 算例 6000 步仍 −1.9% 漂移、而 ratio=100/1000 早已收敛的主因（密度比越大，同一源项相对越弱）。测试把"源项 ∈ (0, 0.2×力标度)"作为回归带，防止未来改动悄悄放大它。
4. **未覆盖**：壁面/入口出口节点类型（`Solid/Wall/EVelocity/WPressure`）未移植 ⇒ 无壁面算例（layered Poiseuille、RT、气泡上升）本轮不做；浮力/重力项未验证；3D（`d3q27_pf_velocity`）属另一支压力处理，范围外；动态湿润/接触角不在本单。
