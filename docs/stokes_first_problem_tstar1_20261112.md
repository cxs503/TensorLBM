## ① 问题设定与基准出处

半无限静止流体（y>0）下方 y=0 处无限大平板在 t=0 时刻**突然**以恒定速度 U 沿 x 方向起动。
流向均匀、不可压、无压力梯度，动量方程退化为**一维扩散方程**

```
∂u/∂t = ν ∂²u/∂y² ,   u(y,0)=0 ,   u(0,t)=U ,  u(∞,t)=0
```

相似解（Stokes 1851；Schlichting 1979 §5 "Rayleigh 问题/脉冲起动平板"）：

```
u(y,t) / U = erfc(η) ,     η = y / (2 sqrt(ν t)) ,     δ(t) = sqrt(ν t)
```

**为什么本题在 LBM 里有"尾部陷阱"**：判据要求 η 到 2，而 `erfc(2) = 4.678e-3`——即误差是被 0.47% 的板速判分的。
仓内既有 benchmark `benchmarks/verified/stokes_first_problem/run.py`（B24）只在 `u_ana > 5%·U`
区域统计误差（避开尾部除零放大），因此**不足以判本题**；本轮新增 `run_tstar1.py` 直接在 η∈[0,2]
逐点判分（这正是上一轮 m16213 未留原因的失败点：没有把判据换算到尾部的绝对精度量级）。

### t\* 的定义（判据只给了 "t\*=1.0"，本单显式固定并记录）

```
t* ≡ ν t / δ_ref² ,   δ_ref = 25 粗格点单位（= t*=1 时 δ = sqrt(ν t) = 25）
⇒ t* = 1  ⇒ 测量窗 η∈[0,2] 对应 y∈[0,4δ]=[0,100] ⊂ (0.5, 199.5) 域内部，顶壁在 η=4
```

选 δ_ref=25 的依据（实测，见 §⑤）：δ≥20 时半无限近似成立、且离散节点能分辨到 η=0.01；
δ 每加倍误差二阶下降。加密一致性：网格 2 倍加密（Δx/2、Δt/2）时 `δ_ref→50`、`ν→2ν`、`t→2t`，
`t*` 定义不变（同一物理态）。

**关键实现细节（踩坑点，全部实测过）**

1. **壁面偏移 0.5 格必须进解析解**：η 用 `y−0.5`。若误用 `y=i`，在 δ=25 时 η=2 处相对误差直接 ~4%。
2. **float64 不是"保险"而是硬需求**：U=1e-3 时 float32 尾部误差 **98%**（§⑤），float64 为 0.0038%。
3. **判据窗口内 η<1/(4δ) 处没有离散自由度**：半步壁面在 y=0.5，最近节点 η₁=1/(4δ)=0.01（δ=25），
   因此 η=0 端点只能取钳位值，其偏差有**闭式恒等式** `1−erfc(1/(4δ))`（δ=25 → 1.128%，δ=50 → 0.564%），
   不是格式误差。测试 `tests/test_stokes_first_problem_tstar1.py::test_eta_zero_gap_is_the_half_way_wall_artifact` 固化了这一点。

## ⑤ 收敛性与参数敏感性（≥2 分辨率 / ≥2 参数点）

**A. 分辨率（δ=20 / 25 / 50，固定 t\*）**

| δ | 配置 | η∈[0.1,2] | 全节点 | η=2 |
|---|---|---|---|---|
| 20 | H=200, ν=0.05, t\*=0.64 | 0.0874% | 0.139% | 0.0064% |
| 25 | H=200, ν=0.05, t\*=1.0 | 0.0781% | 0.0895% | 0.0040% |
| 50 | H=400, ν=0.10, t\*=1.0 | **0.0154%** | **0.0130%** | 0.0093% |

δ 加倍（25→50）误差降 **5.07×**（η∈[0.1,2]）/ **7.15×**（全节点），拟合收敛阶 log₂5.07 = **2.34**→**二阶收敛**（`fig_convergence.png`，含 slope −2 参考线）。

**B. 时间（启动瞬态衰减）**：同一 H=200 域内 t\*=0.04→1.0 的 9 个快照（`fig_spacetime.png`）：
最大相对误差 2.000% → 0.732% → 0.536% → 0.261% → 0.218% → 0.133% → 0.087% → 0.081% → 0.078%（单调衰减，t\*≥0.16 即 <0.54%）。
物理原因：t\*=0.04 时 δ=5 格，阶跃初值尚未被扩散抹平（Skordos 初值的欠分辨瞬态）。

**C. 压缩性 / Ma 扫描（U = 1e-3, 1e-2, 5e-2）**——**负面结论，但很有价值**：
三者归一化剖面**逐位相同**（η=2 处均 0.00467755），`ρ` 最大偏差 1.05e-12（机器零）。
即本题 LBM 的 **Ma² 压缩性误差结构性为零**：流动单向、无散、无压力梯度，`f_eq` 的二阶项
`w_i(4.5c_ix²−1.5)U²` 的**一阶矩恒为零**，不产生速度修正；切向脉冲起动也不激发声波（无活塞效应）。
⇒ 本题不存在"靠降 Ma 提高精度"的杠杆（B24 时代的 `U=0.05` 没有任何损失），误差只由**空间分辨率 + 壁面模型 + 数值精度**决定。

**D. 数值精度（决定性因子，float32 vs float64）**

| U | float32 尾部 η=2 | float64 尾部 η=2 | float32 质量漂移 |
|---|---|---|---|
| 5e-2 | 0.977% | 0.0040% | 1.3e-2 % |
| 1e-2 | **24.4%** | 0.0040% | 1.2e-2 % |
| 1e-3 | **98.1%（灾难）** | 0.0038% | 1.2e-2 % |

float32 的舍入地板（每步 ~1e-9 相对）在 12500 步内积累成 1e-2% 的系统质量漂移，并直接吞掉
量级 1e-6 的尾部速度信号——**在 float32 里做 U 扫描其实是在扫舍入噪声**。这条是本单最重要的工程结论。

**E. 碰撞模型与远场条件**：TRT(Λ=3/16) 在壁面节点更准（1.5e-7 vs BGK 1.6e-6），但**尾部差 47 倍**
（0.19% vs 0.004%）——反对称模的强制阻尼扰动了长波扩散尾；故主配置取 BGK。
顶壁 noslip 与 specular 结果**完全相同**（0.0040%）：δ=25 时 4δ=100 < H=200，远场条件不可见（半无限近似成立）。

**失败模式清单（本单踩到或量到的）**

1. **判据换算失误（上一轮 m16213 的死法）**：`t*` 与 `δ_ref` 未固定、尾部判据被当成单点小量处理，
   容易得出"误差 10% 级"的假失败。→ 本单把 t\* 定义写死在代码常量 `DELTA_REF=25` 并进测试。
2. **float32 + 小 U**：尾部灾难性误差（98%），且表面"质量守恒看起来还好"（1e-2%）——极易被误判为物理失败。
3. **壁面 0.5 格偏移漏算**：η=2 处 ~4% 系统偏差。
4. **η=0 端点的坐标伪误差**：`1−erfc(1/(4δ))`（δ=25 → 1.128%），若不知其闭式来源会误判为格式不达标。
5. **域截断**：4δ>H 时（如 H=100、δ=30）误差 10% 级（B24 README 已记录），本单用 4δ=100 ≪ H=200 规避。
6. **未做/未证**：η=0 端点未用插值 bounce-back（Bouzidi）把壁面精确落在 y=0；三维/湍流不适用；
   未做多 ν 扫描（Re 固定 0.5，本题 ε 与 ν 无关属预期，未验证）。
