## 4. 审计与分析

### 4.1 精度评估

SDAA 上两档网格的 max_rel_err 均在 0.02% 量级，远低于 3% 验收门，物理精度完全达标。与 CPU 基线对比：
- H=40：SDAA 0.0202% vs CPU 0.0198%（差异 ~0.0004%，属浮点噪声级别）
- H=80：SDAA 0.0209% vs CPU 0.0146%（差异 ~0.006%，SDAA 略高但仍远低于阈值）

### 4.2 收敛性失败分析

收敛判据失败的原因：H=80 的 max_rel_err（0.0209%）略高于 H=40（0.0202%），未满足"误差随网格加密单调下降"的要求。

**根因分析**：
1. 两档误差差异极小（0.0007% 绝对量级），处于数值噪声水平；
2. CPU 基线中 H=80 误差（0.0146%）明显低于 H=40（0.0198%），说明算法本身具有正确收敛性；
3. SDAA 上 H=80 误差未下降，可能原因：
   - SDAA 浮点运算顺序/精度与 CPU 存在微小差异（如归约顺序、FMA 合并）；
   - 10000 步对 H=80 可能未完全收敛到稳态（虽然 steady 判据通过，但残差可能仍在缓慢下降）；
   - max_rel_err 对局部极值敏感，单点波动可导致收敛判据失败。

### 4.3 Triton 绕行

compile_mode='eager' 完全绕过 torch.compile，因此不需要 TRITON_INTERPRET=1 环境变量。这是 SDAA 设备当前的标准做法。

### 4.4 质量守恒

两档网格的质量漂移均 < 0.001%（H=40: 0.00072%, H=80: 0.00052%），表明 SDAA 上的数值守恒性良好。

## 5. 局限与后续

### 5.1 本单局限

1. **收敛判据失败**：虽然物理精度达标，但严格的网格收敛性未在 SDAA 上复现。需进一步调查 SDAA 浮点行为或增加迭代步数。
2. **仅 BGK 碰撞**：本次仅验证 BGK 碰撞，MRT/KBC 等高级碰撞模型在 SDAA 上的 Couette 验证未覆盖。
3. **单卡运行**：仅 sdaa:0 单卡验证，多卡并行下的数值一致性未检验。
4. **网格范围有限**：仅 H=40/80 两档，更细网格（H=160+）的收敛趋势未获取。

### 5.2 后续建议

1. 增加 H=80 的迭代步数（如 30000-60000 步），确认是否达到完全稳态；
2. 增加 H=160 网格，观察更宽范围的收敛趋势；
3. 对比 SDAA 与 CPU 的逐场（field-by-field）差异，定位浮点偏差来源；
4. 扩展至 MRT 碰撞与 3D Couette（Taylor-Couette）案例。
