# 方柱 Re=100 算例独立审计（CASE-LBM-SQUARE-CYL-NORBERG）— m16608 / verifier 席

**一句话结论：算例自身的数值是自洽且可机器复核的，但「Cd/St 均 <3%」这一头条结论
（a）依赖参考中心的选择——在所引文献带内 Cd 的 |误差| 可达 4.41%；（b）在**注册口径**上
并不对应锚点：`feature_ledger` 把 CASE-LBM-SQUARE-CYL-NORBERG 注册为 Re=200 / 阻塞比 1/20 /
Norberg 1993 **实验**口径 / 容差 <8% St·<10% Cd，而交付算例是 Re=100 / 阻塞比 1/40 /
数值簇口径 / 3% 门。因此本单处置 = **request_changes**：算例可以按自己的口径成立，
但它**不能按现在写的样子**结掉该锚点。**

## ① 案例介绍（物理背景/几何/参数表）

二维自由流方柱（正置 α=0°）涡脱落。目标量：平均阻力系数 Cd = Fx/(½ρU²D)、Strouhal 数
St = f·D/U。算例目录 `benchmarks/verified/square_cylinder/`（前序单 m16553 返修，文中所有
测量值为 2026-09-29 归档）。

| 参数 | D=32 | D=48 | D=64 |
|---|---|---|---|
| 域 | 40D×40D（blockage 2.5%） | 同 | 同 |
| 网格 nx=ny | 1280 | 1920 | 2560 |
| Re = U·D/ν | 100 | 100 | 100 |
| u_in / ν / τ | 0.05 / 0.016 / 0.548 | 0.05 / 0.024 / 0.572 | 0.05 / 0.032 / 0.596 |
| 步数 / 统计窗 | 60000 / 后 50% | 90000 / 后 50% | 120000 / 后 50%（12 块） |
| 主测力列 | summary | summary | pair（三列 schema 的主列） |

## ② 怎么做的（方法/流程/工具链）

不做新仿真，做**第二意见**。新增 `benchmarks/verified/square_cylinder/independent_audit.py`，
刻意**不 import** `refspec` / `verify` / `verify_traces` / `run`（有结构性测试断言它们不出现）：

1. **自带常量**：Cd_ref=1.48、St_ref=0.147、门=3%（在本审计里重新打一遍，算例目录改常量
   时本审计必须**反对**而不是跟随）。
2. **算术独立重算**：从 `case_D*.json` 原始字段自己算块均值/误差/A-B 列差/St 估计子跨度，
   与归档的 `err_*` 列对账，并按命中哪个约定归因为 `locked` / `superseded(1.4785/0.1456)`
   / `unattributable`（未命中任何具名约定才是 blocking）。
3. **参考带独立重导**：解析 `result.json` 里存储的文献条目列表，重算带的 min/max/中位，
   检验锁定中心是否落在带内、与中位差多少 —— 用**来源**校核常量，而不是用常量校核自己。
4. **口径（scope）检查**：读 `feature_ledger` 的 acceptance 原文，与算例实际 Re/阻塞比/容差
   逐项比对。这是目录内的裁判**做不到**的检查（它是 scope 检查，不是数值检查）。
5. **结论稳健性**：把参考中心在带内扫过，给出 |误差| 的包络；任一端越过 3% 门即
   `verdict-conditional-on-centre`。
6. **缺证据显式化**：归档无块均值（D=32/48）、无新一轮全量重跑 → 报 `not_run`，绝不并入 PASS。

工具链：Python 3.11 + stdlib + matplotlib（图）；无 torch 依赖，可在任意机器机械复核。

```bash
python benchmarks/verified/square_cylinder/independent_audit.py \
    --ledger-acceptance <(psql -At -c "SELECT acceptance FROM feature_ledger \
        WHERE slug='CASE-LBM-SQUARE-CYL-NORBERG'") \
    --json artifacts/square_cylinder_independent_audit.json    # exit 1 = 存在 blocking
pytest tests/benchmarks/test_square_cylinder_independent_audit.py -q   # 7 passed
```

## ⑤ 注意点 / 局限

1. **blocking：锚点口径不一致**。`feature_ledger` 原文：
   「指标: St=fD/U 与 Cd 均值 vs Norberg1993 (Re=200, 阻塞比 1/20)」，容差「<8% St / <10% Cd」。
   交付算例是 Re=100、阻塞比 1/40、3% 门、且刻意**不用** Norberg 实验值（REFERENCE_AUDIT.md
   论证 2D 求解器不得对标 3D 实验）。前序单把命名冲突写进了 `ref_source`，但**Re 差异从未披露**。
   → 结论：交付物是**一个新算例**（LBM-SQUARE-CYL-RE100-NUMERICAL），不是注册锚点的兑现。
   建议锚点层二选一：改锚点（Re=100/数值簇/3% 门，属口径变更需登记）或另建新锚点。
2. **advisory：3% PASS 依赖中心选择**。Cd 在带内可到 4.41% > 3%。任何"Cd 误差 <3%"的表述
   必须同时写清中心 = 1.48 与其依据；否者是把"选中心"的自由度当成了精度。
3. **advisory：中心不是其来源列表的统计量**。St 中心 0.147 比所列 10 条的中位 0.1455 高 1.03%。
   带内最坏 |St err| = 2.21% 仍在 3% 内 → 该结论不翻，但"中位/均值"式叙述不成立。
4. **advisory：St 定义二义**。归档同时存谱估计与零穿越估计，两者差 0.61–0.96%，门取较大者
   （也是离参考更近者）。仍未越门，但定义必须和 St 数一起披露。
5. **not_run：独立复现未完成**。审计项 4（全量重跑 D=32 60k 步）本单发起了：
   SDAA 编译路径因 teco-inductor 缺陷回退 eager（`InductorError: reduction_shape [1,9,1638400]`
   vs `ncw [9,1638400,1]`），实测 0.26 s/步 → 60k 步 ≈ 4.3 h，超出本单窗口，**未完成、不计 PASS**。
   归档的 D=32/48 亦无块均值，故其统计不确定度无法从仓库重建。
6. 本单未修改任何测量值、未动 `src/tensorlbm/**`、未改算例裁判常量。

| 关键量 | got | 基准（锁定中心） | 误差 | <3%？ |
|---|---|---|---|---|
| Cd D=32 | 1.4816 | 1.48 | +0.11% | 是 |
| Cd D=48 | 1.4844 | 1.48 | +0.30% | 是 |
| Cd D=64 | 1.4870 | 1.48 | +0.47% | 是 |
| St D=32 | 0.1482 | 0.147 | +0.82% | 是 |
| St D=48 | 0.1480 | 0.147 | +0.68% | 是 |
| St D=64 | 0.1479 | 0.147 | +0.61% | 是 |
| Cd D=64（中心取带低端 1.44） | 1.4870 | 1.44 | **+3.26%** | **否** |

**是（在锁定中心 1.48/0.147 下全部 <3%）；但该"是"有前提**：中心一换到所引带的端点，
Cd 就出局（最大 4.41%）。且这些数字全部来自 2026-09-29 归档、**本单未独立复现**——
成立的是"工件-基准对账"，不是"独立复现"。锚点层面还有 Re=200 vs 100 的口径不一致未裁决。
