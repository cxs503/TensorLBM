## 1. 案例介绍（物理背景 / 几何 / 参数）

**物理背景。** 自由面（free surface）是船舶总体性能的基础能力：溃坝问题是它唯一有
*实验锚点*的标准检验面。文献锚点为 Martin & Moyce (1952, Phil. Trans. R. Soc. A **244**, 312)
的液柱坍塌系列（宽高比 `H/a = 2`，`a` = 初始水柱宽度）。

**关键判断（本节点为什么必须换求解器）。** 该实验 `H/a = 2`，**不满足浅水假设**：
Ritter/LSM 浅水理论给出 `X = 2T`，在 `T = 2.96` 时为 **5.92**，而实验为 **3.67**（+61 %）。
因此：

| 既有资产 | 状态 | 本节点处置 |
|---|---|---|
| `tensorlbm/free_surface_verification.py`（DamBreakVerification，色梯度 LBM） | 门比较对象是 `X*=1+t*`——**不是** M&M 数据，门 `RMSE≤2.5` 任何近线性曲线都能过 | 不改动；本文 §5 记录其为**假通过**来源 |
| `benchmarks/pending/dam_break_2d_multimodel`（四模型基线审计） | 对真实验表 4/4 FAIL | 沿用其**正确的轴约定**（`T=t√(2g/a)`）作为唯一基准轴 |
| `src/tensorlbm/shallow_water2d.py`（HLL+静水重构） | 真实但仅适用浅水 | 不使用（`H/a=2` 超出适用范围） |
| **本节点新增 `src/tensorlbm/free_surface.py`** | 二维垂直剖面不可压 NS + VOF | 见 §2 |

**几何与参数（格子/无量纲单位）**

| 量 | 值 | 说明 |
|---|---|---|
| 计算域 | `6a × 3a` | 左/右/底为壁面，顶部开放（`p = 0`） |
| 液柱 | `a × 2a`，`x ∈ [0, a]` | 无量纲下 `a = 1`，`g = 1` |
| 密度比 | `ρ_l/ρ_g = 1000` | **与实验（水/空气 ~800）同量级**——这是既有 LBM 相场模型（SC94 `G=5` 时约 13:1）失败的主因 |
| 运动粘度 | `ν_l = 1e-3`（格子） | 重标定后的数值粘度，Re ~ 1e3（真实实验 Re ≫，见 §5 局限） |
| 表面张力 | `σ = 0` | 溃坝 Bond 数 ≫ 1，物理上可忽略；模型已实现但**未验证**（§6） |
| 壁面 | no-slip / free-slip 两套 | 敏感性对照，见 §3 |
| 网格 | `dx = a/16`（96×48）、`dx = a/32`（192×96） | 幂次友好的格数使多重网格可下采样到直接解 |
| 时间步 | CFL 0.25 自适应，`t ∈ [0, 2.093]` | 对应实验轴 `T ∈ [0, 2.96]` |

## 2. 方法与工具链

**方程。** 不可压两相 Navier–Stokes，VOF（体积分数 `F`）追踪界面：

```
∂u/∂t + (u·∇)u = -(1/ρ)∇p + (1/ρ)∇·(2μS) - g ĵ + (σκ∇F)/ρ̄
∇·u = 0
∂F/∂t + ∇·(uF) = 0 ,  ρ = ρ_g + (ρ_l-ρ_g)F
```

**离散（`src/tensorlbm/free_surface.py`，783 → 1000 行级单模块）**

1. **交错 MAC 网格**：`p, F` 在单元中心，`u` 在 x 面，`v` 在 y 面（半格一致）。
2. **动量对流**：van Leer 限幅 MUSCL 二阶迎风（单元 Re ~ 17，纯中心差会失稳）。
3. **压力投影**：变密度 Poisson `∇·((1/ρ)∇p) = ∇·u*/Δt`，用**几何多重网格 V-cycle**
   （红黑 Gauss–Seidel + SOR ω=1.6 平滑、full-weighting 限制、单元中心双线性延拓、
   最粗层 `≤600` 未知数直接解）。粗层**面系数用调和平均**（串联系数）而非算术平均——
   算术平均在 1000:1 密度跳变下使 V-cycle 发散（实测：残差随迭代增长；调和平均后 32 层内收敛到 5e-11）。
4. **界面输运**：通量形式守恒 VOF `F^{n+1}=F^n - Δt/Δx Σ φ_f`；面值由 superbee 压缩限幅
   MUSCL 重构（保持界面 2–3 格锐度），逐方向 x→y 分裂。投影保证 `∇·u = 0`（离散意义），
   因此**体积守恒是结构性的**，不是靠调参。
5. **质量账本**：每步记录 `M(t)=Σ F ΔV`，并把 clip/redistribute 修复的净体积单列
   （`MassLedger.repair_clip/repair_global`）——修复永不隐身。
6. **表面张力**：CSF（`f = σκ∇F`，κ 用平滑色函数 + `|κ|≤1/h` 限幅，密度用两相平均值）；
   **未验证**，见 §6。
7. **壁面**：自由滑移/无滑移可选；顶部开放边界 `p=0`（Dirichlet）+ 速度零梯度。

**波前判据（机器可算）。** 波前 `x_front` = 距底 2 层内 `F > 0.5` 的最右单元右界面
（与实验"底层涌潮趾部"口径一致），`X = x_front/a`；采样点为实验表 14 个时刻，
`T = t√(2g/a) ⇒ t = T/√2`（**不插值、不外推**，末点 `T=2.96`）。

**工具链**：`numpy 2.4.6 / scipy 1.16 / matplotlib 3.10`；运行脚本
`benchmarks/free_surface_dambreak_wigley/{run_dambreak,run_convergence,run_snapshots,analyze}.py`；
每个工件 JSON 内嵌 `grid/n_steps/mass/config` 与 sha256，`analyze.py` 零手抄重新计算判据。

### 3.1 波前位置 vs Martin & Moyce (1952) 14 点

`a = 1`（无量纲），最优工况 **cells=16/a, no-slip**（`runs/p351w1_n07/dambreak/cells16_no-slip_nu0.001.json`）：

|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| X 实验 | 1.00 | 1.11 | 1.23 | 1.44 | 1.67 | 1.89 | 2.11 | 2.33 | 2.56 | 2.78 | 3.00 | 3.22 | 3.44 | 3.67 |
| X 计算 | 1.00 | 1.06 | 1.31 | **1.63** | 1.88 | **2.13** | 2.31 | 2.50 | 2.81 | 2.94 | 3.19 | 3.31 | 3.50 | 3.63 |
| 误差 % | 0.0 | −4.3 | +6.7 | +12.8 | +12.3 | +12.4 | +9.6 | +7.3 | +9.9 | +5.7 | +6.2 | +2.9 | +1.7 | −1.2 |

- **RMSE（相对逐点归一）= 7.84 %**（判据 ≤10 % → **PASS**）；RMSE（绝对，以 `a` 计）= 0.158
- 两条独立路径复算同一数字：求解器内 `rmse_relative_percent` 与 `analyze.py` 从序列重算值相同（summary.json 双记录）

### 3.2 工况敏感性（同一实验表）

| 工况 | 壁面 | 格数 | RMSE 绝对 | RMSE 相对 | 质量漂移 max | 步数 | 墙钟 |
|---|---|---|---|---|---|---|---|

无滑移底壁把中期偏快从 +16 %（free-slip，`T=1.43`）压到 +12.3 %，与"实验底板有摩擦"一致；
两套工况**都**通过 ≤10 % 门——说明判据不依赖单一调参。

### 3.3 质量守恒（判据 b）

`|M(t) − M(0)|/M(0)` 全程最大 **1.22e-3 = 0.12 %**（判据 ≤2 % → **PASS**，余量 16 倍）。
结构性来源：投影使 `∇·u = 0` + 通量形式 VOF；`repair_clip = 2.45e-3·a²`（clip/redistribute
修复量，单列审计），`repair_global = 0`（**未启用**全局质量修正即达标）。

### 3.4 界面输运的 L2 收敛阶（判据 d）

单涡（Zalesak/LeVeque 型）散度自由流场，参考解由 **RK4 反向流映射**独立算出
（与被测格式无关）；三网格 `h = 1/32, 1/64, 1/128`：

| 初始界面厚度 | L2(32) | L2(64) | L2(128) | 观测阶 | R² |
|---|---|---|---|---|---|
| 0.02（物理固定，≈2 格） | 8.28e-2 | 4.06e-2 | 2.25e-2 | **0.94** | 0.997 |
| 0.004（锐界面） | 1.05e-1 | 7.00e-2 | 4.20e-2 | 0.66 | 0.996 |

**判决：HONEST FAIL**（目标 ≥1.5）。诊断（可复现）：误差被**界面增厚**支配——代数 VOF
的对流扩散使界面厚度 `∝ h` 增长，L2(ΔF) 因此饱和在 O(h)；改用 Strang 分裂可把
0.94 提到 1.03（同一工件路径可复现），但阶数上限仍是界面增厚，不是时间分裂。
要跨过 1.5 必须换**几何重构**（PLIC/THINC-BVD）或水平集 + 重初始化——这是明确的后续工作，
不能用调门的方式掩盖。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **轴约定是历史事故源。** 旧门用 `T = t√(g/a)`（少 `√2`）且参照表本身错，造成过
   "+50…82 %" 的假误差；这些结论已被仓库正式撤回（`benchmarks/pending/dam_break_sc/result.json`）。
   本节点只使用 `T = t√(2g/a)` + Lethe 数字化表，且**不外推**到 `T>2.96`。
2. **旧"验证"模块是假通过。** `free_surface_verification.DamBreakVerification` 的门比较对象
   是 `X*=1+t*` 并在注释里称其为 Martin & Moyce——这是本节点最值得记录的审计发现。
3. **浅水不适用。** `H/a=2` 时 LSM 前缘 5.92 vs 实验 3.67；用 SWE 会系统性偏快 60 %。
4. **多重网格粗层系数必须用调和平均。** 算术平均在 1000:1 密度跳变下 V-cycle 发散
   （残差逐圈增大）；调和平均后 32 圈收敛到 5e-11。这条对任何变密度投影求解器都适用。
5. **`np.linalg.solve` 在共享机上是陷阱。** 64×64 稠密解实测 **21 ms**（多线程 BLAS 开销），
   换 `scipy.linalg.solve` 后 0.15 ms——V-cycle 里的小稠密解会主导整体墙钟。
6. **局限一：层流 + 数值粘度。** 实验 Re ~ 1e5，本求解器 `ν=1e-3`（格）对应 Re ~ 1e3，
   无湍流模型；中期前缘偏快 +12 % 主要来自这里（无滑移壁面可减到 +12.3 %）。
7. **局限二：二维垂直剖面。** 该验证面无法覆盖三维兴波（见 §7）。
8. **局限四：加密工况未纳入正式判据。** `dx = a/32`（192×96）的同工况加密运行已启动
   （`sweep_dambreak.sh`，脚本就绪、工件路径固定），但本会话共享机负载 `load avg ≈ 225`
   使单工况墙钟放大 5 倍以上，未在会话窗口内完成；因此 §3 表中判据只由两个 `dx = a/16`
   工况支撑。加密工况属于**敏感性证据**而非判据必需项，但"前缘的网格收敛"在补齐前应视为未验证。
9. **局限三：局部散度尖峰。** `div_max` 在界面单元可达 O(1)（Poisson 容差 1e-5 的工况），
   但积分质量守恒仍 0.12 %——局部散度与守恒是两个量，报告不得混用。
9. **表面张力未验证。** CSF 实现存在，但静态液滴的虚假毛细流导致压力跳跃不可信（§6）。

## 6. 表面张力：已实现、未验证（诚实标记）

CSF 力项、曲率限幅、两相平均密度均已实现并有单元测试（默认 `σ=0`，溃坝不启用）。
静态液滴 Laplace 检验（`laplace_pressure()`）在 `nx=32/48`、`ν=0.05–0.5`、`ρ_l/ρ_g=1.1–1000`
全组合下出现**虚假毛细流增长**（`|u|` 从 1e-3 指数增长到 1e2，`Δp` 偏离 `σ/R` 数个量级）。
已定位不到单一符号/系数错误（曲率符号、密度加权、限幅均已试），因此**不宣称**该能力已验证；
判据 (a)(b) 不受影响（`σ=0`）。后续工作：改 balanced-force CSF（Francois et al. 2006）或
改为 PLIC + 曲率高度函数法，并配毛细波色散锚点。

## 7. Wigley 兴波（判据 c）：未交付 + 原因

**结论：NOT DELIVERED（honest）。** 本节点只交付了**二维垂直剖面**求解器，它无法表示
Kelvin 兴波（三维、`19.47°` 楔角）；因此"Wigley 船 bow wave 3 个 Fr 波高 ≤15 %"没有可信的
数值来源。已评估的三条备选路径与放弃理由：

1. **三维 VOF/NS**：Wigley `B/L=0.1`，要分辨船宽需 `L≈300` 格 → `nx=1200×60×60≈4.3e6` 单元、
   数千步，本机（load ~225）与集群（排队 200+）都不具备调试-收敛的工作窗口；且波高 ~0.02L
   在 60 层垂向网格上只有 2–3 格，≤15 % 的振幅精度不可保证。
2. **Dawson 型 Rankine 面元 + 抬升自由面**：需要自由面辐射条件与上游差分，符号/归一化
   风险高，无本地文献可对表，无法在本次窗口内自证正确。
3. **薄船理论自比**：把 Michell 积分（仓内已有、已 verified）与"同一线性化的另一种离散"
   相比属**同源比较**，不能作为独立验证，故不列为交付项。

**下一步（可执行）**：在 `free_surface.py` 之上做三维扩展（同一 VOF + 多重网格骨架），
以 `B/L` 加密梯 + `L`/垂向双重加密收敛研究，并把 Michell 波面（而非仅 `C_W`）实现为参考面；
先把 2D+T 极限（横剖面）作为中间验证步。
