## ① 案例介绍（物理背景 / 几何 / 参数）

**物理目标**：把分辨率花在尾流/间隙/边界层而不是全场，用两级静态加密（coarse↔fine 加密比 $r=2$）
在同等成本下把工程量误差降下来。本次交付的是**二维 D2Q9 两级静态加密求解器**（已有 3D 静态块
`static_block_amr.py` 为 D3Q19/D3Q27；本次按任务要求新建 2D 通道，因 2D 才能在会话算力内跑完
圆柱绕流与守恒扫描）。

**数值方案**（`two_level_amr2d.py`）：

| 组件 | 实现 |
|---|---|
| 粗/细时间推进 | 对流标度 $\Delta x,\Delta t\to \Delta x/r,\Delta t/r$，粗走 1 步、细走 $r$ 个子步 |
| 松弛时间 | $\tau_f=\tfrac12+r(\tau_c-\tfrac12)$（`convective_refined_tau`，与 3D 运行时一致） |
| 粗→细（ghost） | 双线性空间插值 + 时间线性插值（$t{+}0.25\Delta t$、$t{+}0.75\Delta t$），再拆平衡/非平衡：$f^{neq}_f=\dfrac{\tau_f}{r\tau_c}f^{neq}_c$ |
| 细→粗（restriction） | $r\times r$ 子格算术平均（体积权重 $r^{-2}$）+ 非平衡回缩因子 $\dfrac{r\tau_c}{\tau_f}$（与上式互为逆） |
| 回流（reflux） | 质量用目标式记账（步前/步后体积加权总质量差），动量用**跨界面通量台账**（两层各自 crossing-link 求和），以纯密度增量 / 纯动量增量（零质量）注入界面环带 |
| 边界 | 半程反弹（solid mask）+ 逐轴周期性（`stream_mask`）；Guo→Ladd 体积力（$\sum_i c_i S_i=F$ 精确） |
| 障碍物力 | 动量交换法（`obstacle_force`），用于圆柱 $C_D$ |

**几何/参数（各判据）**

| 门 | 域 | patch（粗索引） | $\tau_c/\tau_f$ | 其他 |
|---|---|---|---|---|
| (a) 守恒 | $64\times64$ 双向周期 | $x\!\in\![16,48),y\!\in\![16,48)$ | 0.60 / 0.70 | $\rho=1+10^{-3}\sin kx\cos ky$，$u_x=0.02$，200 步 |
| (b) Poiseuille | $26\times64$，上下固壁 | $x\!\in\![24,40),y\!\in\![3,23)$ | 0.65 / 0.80 | $\nu_{lat}=0.05$，$F=3.4722\times10^{-5}$，$u_{max}=0.0499$，1500 步 |
| (c) 伪声反射 | $10\times200$ 双向周期 | $x\!\in\![100,140),y\!\in\![1,9)$ | 0.56 / 0.62 | 声脉冲 $\Delta\rho=10^{-4}e^{-(x-40)^2/2\sigma^2}$，探针 $x=70$，200 步 |

| (f) 负控 | 同 (a)/(b) | — | — | 断回流、错标度 |

## ② 怎么做的（方法/流程/工具链）

1. **先读后写**：复用仓内既有的 3D AMR 约定（`static_block_amr.convective_refined_tau`、
   `amr_population_transfer.rescale_nonequilibrium` 的 `spatial_ratio = 目标间距/源间距` 语义、
   `d2q9.equilibrium/macroscopic`），保证 2D 与 3D 的标度约定可比。
2. **算子定标**：用「同一物理剪切流在两个层级上的非平衡幅值实测」直接确认标度：
   粗通道 $\tau_c=0.65$ / 细通道 $\tau_f=0.80$、同一 $u_{max}$ 收敛后，$f^{neq}_{(1,1)}$ 之比
   **实测 0.615 = $\tau_f/(2\tau_c)$**（见 §⑤ 定标表），据此定粗→细因子。
3. **能力门** `two_level_gates.py`：六个独立可机器裁的判据，各自返回数字+阈值+`passed`，
   `run_gate_suite()` 汇总为 JSON 工件；运行器 `scripts/p387w2_n05_two_level_gates.py` 可分门单独跑
   （会话 shell 有 115 s 上限，故按门分块执行并把结果合并进同一工件）。
4. **负控先行**：每条"合格"判据都要有对应的"坏算子必须挂"的证据（断回流、错标度），否则判据无效。
5. **单测**：`tests/test_two_level_amr2d.py` 11 例（标度互逆、往返一致、均匀流保持、守恒、回流负控、
   错标度负控、混周期回归、通道解析峰值、动量交换力）——`pytest -q` **11 passed, 28.7 s**。
6. **工具链**：PyTorch float64（CPU），matplotlib 出图。**注意**：这类小网格上多线程 torch 会被线程
   启动开销拖垮（实测同一步数 8 线程 vs 1 线程差 3–5 倍），本会话为运行器/单测都固定 `num_threads≤2`。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

### 由能力门抓出的三个真缺陷

1. **混周期采样销毁对角population（已修，实测影响 5.8×）**
   流式采样原先"只要一个轴非周期就把两个轴的环绕带都清零"，通道（x 周期、y 固壁）里
   对角 population 在 x 边界被静默删除 → 通道峰值速度 **0.00746 vs 解析 0.04320（5.8 倍偏低）**，
   且动量平衡自洽（$dP/\text{step}\approx0$）所以"看起来正常"。改为逐轴独立填充后峰值误差 **0.09 %**。
   回归守卫：`test_mixed_periodicity_keeps_diagonal_populations`、`test_poiseuille_peak_matches_analytic`。
2. **restriction 用了粗→细的空间比而非其倒数（已修）**
   原实现细→粗非平衡因子取 $\tau_c/(2\tau_f)$，往返会丢 4 倍非平衡幅值；修正为
   $\tau_c/(0.5\tau_f)=1.625$ 后 `prolongate∘restrict` 在 patch 内**精确回到原态**（单测 1e-12）。
   但修正后 (b)(c) 反而更差 → 见第 3 条与定标表：这是**未解的标度-精度discrepancy**，如实登记。
3. **回流台账在含壁面上会注入伪动量（已缓解，未根治）**
   台账式动量回流在闭合周期盒内精确（残差 $2\times10^{-14}$），但在含固壁通道里每步注入约
   **11 % 体积力当量**的伪动量（开回流时全域速度偏 +7 %，关掉 +0.7 %）。故壁面门用
   `momentum_reflux=False`，仅保留目标式质量回流；周期门保留完整回流。
   **根因**：两层对同一界面的离散通量本就不相等（相对 1e-4），回流只是强行配平，未消除不一致。

### 局限与适用范围

- 界面闭合是**一阶**的（单层 ghost + 双线性 + 单标度 FH），界面层真实存在：Poiseuille 紧邻界面行
  8.7 %、第 2 行 3.5 %、带内其余仍 3–8 %；仓内 3D 运行时用 `interface_filter`/`regularize_*`
  抑制同类伪应力，2D 版尚未接入（阻尼扫描见 §③，只解掉约 1/4）。
- 只在**低速不可压**（$u\lesssim0.1$、$Ma\lesssim0.15$）与**静态** patch（拓扑不随时间变）下验证；
  移动/多块/多层嵌套不支持。
- 细层 ghost 环必须是流体（patch 严格内嵌），因此**不能把 patch 贴到固壁**——这正是 (b) 里
  界面最靠近壁（2 格）而误差最大的原因之一。
- 精度阶门需要"带 Chapman–Enskog 非平衡初值"的 TG（或先弛豫 1–2 个 $\tau$ 再取基准），当前实现缺此。
