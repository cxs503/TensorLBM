# N01 颗粒润湿动力学成熟化报告

## 1. 案例介绍（物理背景/几何/参数表）

### 物理背景

颗粒润湿动力学是船舶总体性能中船体-水-气三相相互作用的基础物理过程。
接触角决定了船体表面的润湿特性，进而影响摩擦阻力、兴波阻力和气泡附着行为。
本节点基于 Shan-Chen 赝势 LBM 模型，通过壁面赝势参数 f_w = ψ_w/ψ(ρ_l) 控制接触角。

### 几何与参数

- **模型**: D2Q9 Shan-Chen 单组分赝势 LBM
- **表面张力**: σ = 0.05611 (lu)
- **液相密度**: ρ_l = 1.957 (lu)
- **气相密度**: ρ_v = 0.1596 (lu)
- **接触角目标**: θ_e = (30.0, 60.0, 90.0, 120.0, 150.0)°
- **毛细管半径**: R = (0.25, 0.5, 1.0, 2.0, 4.0) mm

## 2. 方法（流程/关键设置/工具链）

1. **接触角标定**: 通过预计算的 wall_fraction → θ_e 标定曲线，二分法反推 f_w
2. **液滴初始化**: 壁面上方放置圆形液滴，tanh 剖面初始化密度场
3. **弛豫**: 8000 步 BGK + Streaming + 壁面反弹
4. **接触角测量**: ρ=(ρ_l+ρ_v)/2 等值线，Kasa 圆拟合 + Gauss-Newton 精化
5. **不确定度**: Bootstrap + 窗口扫描 + 壁面偏移

## 5. 注意点（局限/适用范围）

1. **二维模型**: D2Q9 二维，三维效应未完全捕捉
2. **密度比**: ρ_l/ρ_v ≈ 12.3，低于实际水-气比 (~1000)
3. **界面厚度**: 扩散界面宽 3-5 lu，粗网格下影响测量
4. **伪电流**: 静态液滴存在残余伪电流，限制低 Ca 测量

适用范围: θ_e = 30°~175°, Bo = 0.01~10
