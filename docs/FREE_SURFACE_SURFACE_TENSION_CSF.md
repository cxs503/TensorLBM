## 0. 一句话结论

在 TensorLBM 自由面框架里补上了**可验证的 CSF（Brackbill 连续表面力）表面张力**：曲率算子、
`f = σκ∇φ` 力、Marangoni 切向力、Young–Laplace 静压差、液滴振荡、寄生流收敛、界面质量守恒
六类机器可算锚点全部落地。**2D Young–Laplace（<3%）、3D 球形液滴（<5%）、Marangoni 线性
（R²>0.95）、寄生流 h² 收敛（指数 2.01）、质量守恒（2.9e-15）全部通过；液滴振荡周期未通过
（对照 Rayleigh n=2 偏长 +49%~+59%，如实判 FAIL，根因已定位为弥散界面软化 mode-2 回复力，
见 §5/§7）。**

## 1. 案例介绍（物理背景 / 几何 / 参数）

自由面（Körner type）LBM 只解液相、界面靠体积分数/颜色场 `φ` 描述，**表面张力必须以体积力
形式进入**，否则液滴/气泡/射流的一切毛细现象都不存在。仓库原有
`free_surface_common.surface_tension_force_3d` 只有三行 `σκ∇φ`，**无任何物理验证**
（无 Young–Laplace 锚、无曲率精度检验、无 Marangoni、无收敛性研究），在能力台账上属于
WITHHELD。本节点把它提升为可验证能力。

物理模型（Brackbill, Kothe & Zemach 1992）：

```
f_s(x) = σ κ(x) n̂(x) δ_s(x) = σ κ(x) ∇φ(x)            (1)
κ      = -∇·n̂ ,  n̂ = ∇φ/|∇φ| ,  δ_s = |∇φ|            (2)
Δp     = p_in - p_out = σ κ                            (3)
```

`κ` 是**主曲率之和**：2D 圆柱 `κ=1/R`（`Δp=σ/R`），3D 球 `κ=2/R`（`Δp=2σ/R`）。
Num 方向约定：`φ=1` 为液相内部 ⇒ 凸液滴 `κ>0`、`f` 指向内、内压高。

## 2. 怎么做的（方法 / 流程 / 工具链）

### 2.1 算子层 `csf.py`
* `gradient/divergence`：各向同性二阶中心差分（周期），与 LBM 压力梯度的模板族一致 —— 这是
  **balanced-force**（力与 `∇p` 用同一算子族）的前提，也是寄生流能按 `h²` 收敛的机制来源。
* `curvature(φ) = -div(∇φ/|∇φ|)`：圆/球 tanh 剖面上误差 `O(h²)`（实测：`R=10/14/18` 的
  `κ_num/(1/R)-1 = +0.098%/-0.031%/-0.083%`）。
* `csf_force`、`marangoni_force`（`f_M = ∇_s σ · δ_s`，切向投影 `(I - n̂n̂)`）、
  `laplace_pressure`、`rayleigh_period`、`tanh_*_phi` 界面构造器。
* 与既有 `free_surface_common.mean_curvature_3d` 的一致性由测试
  `test_curvature_matches_free_surface_common` 守卫（逐点 `1e-10`）。

### 2.2 求解器层 `solver.py`（验证用最小基座，不是新通用求解器）
D2Q9 / D3Q19 **LBGK + Guo forcing**：`f_i ← f_i - (f_i-f_i^eq)/τ + F_i`，
`F_i = w_i(1-1/2τ)[(c_i-u)/c_s² + (c_i·u)c_i/c_s⁴]·F`，宏观量 `ρu = Σ c_i f_i + F/2`
（半力修正，否则报告的是"错误的速度"）。逐节点 `τ(φ)`。界面输运两条路径：
* **守恒通量形式**（一阶迎风 + `conservative_clamp`）：离散散度在周期盒内逐项相消，`Σφ`
  到机器精度守恒（实测 `2.9e-15`）——质量守恒判据用它。
* **半拉格朗日三次插值（单调限幅）**：毛细流 CFL~1e-2，回溯位移远小于一格，数值扩散极小
  （实测 2000 步界面宽度 5→4 格；一阶迎风 5→11 格）——振荡判据用它。非严格守恒，
  实测质量漂移 6e-4~1e-3（如实记录）。

### 2.3 平衡初值（消除声学瞬态）
静液滴的精确平衡是 `∇p = σκ∇φ` ⇒ `p = p_out + σκφ`。用**数值曲率** `κ̄`（界面带加权平均）
初始化 `ρ = 1 + 3σκ̄(φ-1)`，把声学瞬态去掉，使残余流动单独暴露（寄生流研究）与
"从零开始"两条路都在报告里给出：Young–Laplace 判据用 `init_laplace=False`（**不占初值便宜**，
纯动力学收敛到平衡），寄生流判据用 `init_laplace=True`（隔离稳态残差）。

### 2.4 工具链
`scripts/run_free_surface_tension_verification.py --case <case> --index i --total n` 分片跑 →
`artifacts/free_surface_tension/<case>__<i>.json`；`--case aggregate` 汇总判据、出图
（matplotlib → `artifacts/free_surface_tension/figures/*.png`）。报告里所有数字均由该 JSON 注入。

### 3.5 寄生流收敛（判据 ≥1.8，**通过**）

`w/R=1/3` 同步加密（4 档，σ=0.05，τ=0.9，1500 步）：

| R | h=1/R | max|u| |
|---|---|---|
| 12 | 0.0833 | 2.210e-04 |
| 18 | 0.0556 | 9.904e-05 |
| 26 | 0.0385 | 4.787e-05 |
| 36 | 0.0278 | 2.416e-05 |

幂律拟合指数 **2.01**（`R²≈1`）。

定厚对照（`w=3` 固定，只加大 R，= 改变无量纲界面厚度，不是加密）：

| R | 8 | 12 | 18 | 26 |
|---|---|---|---|---|
| max|u| | 5.008e-04 | 4.225e-04 | 3.953e-04 | 3.923e-04 |

指数 ≈0.05（≈常数）。**这两行合起来才是完整结论：寄生流由"每界面厚度多少格"（`h/w`）
控制，而不是由 `h/R` 控制**；真正的网格加密必须保持 `w/R` 不变，此时指数 2.01。

### 3.6 质量守恒（判据 <0.1%，**通过**）

保守通量形式 + `conservative_clamp`，1000 步：`Σφ` 从 457.0574593558972 到
457.0574593558959，相对损失 **2.9e-15**。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **半格坐标陷阱**：半拉格朗日回溯必须用**数组索引坐标**（格心物理位置 `i+0.5` 对应索引
   `i`）。写成 `arange+0.5` 会让每次插值等效于 0.5 格模糊，900 步内质量暴涨 137%。
2. **`atanh` 截断**：由 `φ` 反解距离 `d=(w/2)atanh(1-2φ)` 时若截断在 `0.99`，全场体相被
   抬到 `φ=0.005`，每次调用悄悄注入约 1/200 个域面积的质量（1000 步后质量涨 6.4 倍）。
   必须截到 `1-1e-12`。
3. **质量修正的 Newton 符号**：`dm/dd = -周长`，故 `d ← d + (m-m_target)/周长`；符号写反会
   让质量按 2 倍发散。
4. **一阶迎风太扩散**：毛细流 `|u|~1e-2`，1400 步界面从 5 格糊到 11 格，宽过渡层直接改变
   振荡动力学。改用单调限幅三次半拉格朗日（宽度 5→4 格）。MUSCL/superbee 通量形式在本问题
   下不稳定（NaN），已从代码中移除，避免留下坏路径。
5. **寄生流的正确判据是 `h/w` 不是 `h/R`**：定 `w=3` 只加大 `R`，等于同时改变无量纲界面
   厚度，测得指数≈0；这不是加密研究。见 §3.5。
6. **平衡初值不能用于"答案敏感"的判据**：Young–Laplace 判据一律 `init_laplace=False`，
   只用数值曲率做初值的版本仅用于隔离寄生流。
7. **LBM 单流体模型**：无密度跳变（自由面模型本来就是只解液相），因此本模块验证的是
   **CSF 算子 + 曲率 + 压力响应**，不是密度比/相变；跨密度比扩展需另接自由面质量账本。
8. **局限（振荡）**：见 §7；弥散界面 `w/R=0.17` 下 mode-2 回复力被软化约
   `(kw)²` 量级，实测周期偏长 30–38%（对 2D 正确参考）。仓库内 `L=4R` 周期盒的液滴像
   阵列相互作用、强黏性阻尼也是叠加误差源。

## 7. 振荡周期的失败分析（honest）

* 观测：`T/T_2D` 三档 σ 稳定在 **1.29–1.38**，σ 变化 4 倍而比值几乎不变 ⇒ 不是黏性
  （`τ=0.6/0.9/1.2` 三档测得 588/603/580，几乎不动）、不是非线性（`ε=0.02`，线性区）。
* 界面厚度依赖：`w=2 → 516`、`w=3 → 603`（+17%），趋势符合"越厚越慢"，但 `w=4.5` 回落
  520 且 `w=1.5` 无零穿越 ⇒ 三点非单调、`w²` 拟合 `R²=0.03`，**无法据此外推**。
  单靠 `w` 不能解释全部偏差（即使强行外推 `T₀=558`，对 2D 参考仍 +48%）。
* 物理解释（与相场/弥散界面文献一致）：界面张力由宽度 `w` 的过渡层承载，mode-2 形变的
  角向曲率扰动波数 `k~2/R`，过渡层对曲率扰动的低通滤波 + 界面自身惯量使有效回复力
  下降约 `(k w)²` 量级；本配置 `k w = 2w/R = 0.33`，与实测软化幅度同阶。
* 结论：**该实现目前不适合做 <5% 量级的毛细振荡定量预测**。要把判据做绿，需要同时
  (i) `w/R ≲ 0.05`（例如 `R=40, w=2`，`L=160`，单周期 ~2300 步）以压低弥散界面软化，
  (ii) 把周期盒放大到 `L ≥ 8R` 以消除像相互作用，
  (iii) 换更稳健的相位提取（速度自相关/FFT，而不是 2 次零穿越）。
  或改用相场/锐界面（PLIC-VOF）输运。这属于**已定位的架构性局限**，不是参数没调好。
* 已排除项（都实测过）：黏性阻尼频移（0.7% 量级，可忽略）、`init_laplace` 初值造成的
  相位滞后（两种初值均同样偏长）、对流格式（迎风/单调三次半拉格朗日结论一致）。
