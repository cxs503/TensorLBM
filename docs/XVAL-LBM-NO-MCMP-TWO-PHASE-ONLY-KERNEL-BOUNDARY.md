## ① 案例介绍（物理背景 / 模型 / 参数）

waLBerla 的做法是**类型层面**的：两相晶格模型**不带任何 MCMP 力处理器**，所以两相求解器里不可能
混入多组分相互作用项；反过来，MCMP 模型即使把交叉耦合置零也**不会**变成两相模型。TensorLBM 把两种
物理放在同一模块 `tensorlbm.multiphase` 里：

| 模型 | 入口 | 物理含义 | 耦合符号 |
|---|---|---|---|
| 两相（two-phase-only, SCMP 单组分伪势） | `sc_single_component_force` / `collide_sc_single_component` | 同种分子自作用 → 液/气共存 | `G > 0` = 同种吸引 = 凝结 |
| 多组分（MCMP, Shan–Chen 交叉作用） | `sc_two_component_force` / `collide_sc_two_component` | A/B 组分间作用 → 贴合或互斥 | `G_12 > 0` = 异种吸引，`G_12 < 0` = 互斥分相 |

两者**共用同一个相互作用核**（D2Q9 加权求和 + backward gather），但符号含义相反。锚点「no-mcmp」
要回答的就是：这条共用核在什么条件下可证明是同一算子、在什么条件下必须保持两条独立物理路径。
前序切片（`REPORT.md`）量化的是「把两组分降级为两相分层」在分层 Poiseuille 上的精度代价；
本切片量化的是**算子/模型层面的等价边界**，两者互补。

算例设置（D2Q9、晶格单位、`cs² = 1/3`）：

| 参数 | 取值 |
|---|---|
| 域 | 周期方形/矩形 32²–64²（G6 用 64×2 条带，双周期平界面） |
| 步数 | G1/G2 无推进；G3/G4/G5 400 步；G6 8000 步 |
| 松弛时间 | `τ = 1.0` |
| 伪势 | `ψ_exp(ρ)=ρ0(1−e^{−ρ/ρ0})`, `ρ0=1`；G1 另测 `ψ_linear` |
| 耦合 | `G = G_12 ∈ {−1, ±0.5, 1, 4.5, 5}`；G3 取 `G = G_12 = 5` |
| 强制 | `velocity_shift`（SCMP）/`shift`（MCMP）；G6 用 `edm` |
| 精度 | float64（G1 另测 float32） |

## ② 怎么做的

六道闸门全为纯函数（驱动与 pytest 跑同一份代码）：

* **G1 核同一性**：`ρ_B := ρ_A`、`G_12 := G` 时交叉力 `F_1 = −G ψ Σ_i w_i c_i ψ(x−c_i)` 与
  自作用力**代数恒等**；判据 ≤1e-12 相对力幅值，四种变体（`ψ_exp`/`ψ_linear`、`G=5`/`G=−1`、
  float64/float32）+ 交换对称 + 非平凡性。
* **G2 零耦合纯净性**：`G_12 = 0` 力恒为零（MCMP 无法"贡献"于两相配置）；均匀伙伴力恒为零
  （`Σ_i w_i c_i = 0` 精确）；同构型 `G_12 = −1` 的力作**消融对照**证明判据有牙。
* **G3 动力学归约**：SCMP 与「伙伴复制」MCMP 同初值同参数积分 400 步逐步比密度场；并要求两相模型
  确实相分离（否则等价性空判）。
* **G4 MCMP 核内无自作用**：A 为液滴、B 均匀（惰性）⇒ A 只能被粘性扩散抹平，对比度不许增长；
  对照 `B = ρ_max+ρ_min−A` 必须维持分相。
* **G5 耦合符号语义**：①**精确**力对齐 `Σ_x F_A·∇ψ_B`（`Σ_i w_i c_i ψ_B(x−c_i) = −cs²∇ψ_B+O(h²)`
  ⇒ 应为 `G_12` 的奇函数）；②**示踪剂**：B 冻结、A 初始均匀，400 步后 `corr(ρ_A, ψ_B)` 的符号即物理方向。
* **G6 两相路径物理基准**：周期平界面共存密度 vs 同一晶格 EOS `p = cs²ρ − (G cs²/2)ψ²` 的
  **Maxwell 等面积构造**（解析，不用求解器）。

工具链：PyTorch float64 + pytest + matplotlib；9 道子闸门总计约 3 分钟单核，本机跑，
分阶段落 `gates_G*.json` 后 `--merge` 汇总出图（论文级可复现）。

**被否定的一条自设假设**：最初用「双组分小幅噪声混合物的相关函数演化」判分相方向；`|G_12|ψψ' ≈ 0.25 ≪ 1`
时混合物线性稳定，测得相关由噪声主导（`G_12=±1` 一致为负），**无判别力**。改用「冻结伙伴 + 示踪」
后才得到干净的奇对称结论（见 G5）。该失败记录在此以免后人重犯。

## ⑤ 注意点

1. **符号是本锚点最大的坑**：核同一（G1 精确 0）⇒ `G` 与 `G_12` 在同一数值下给出同一逐组分力，
   但物理含义相反；跨模型复制参数会静默翻转结论。
2. **小振幅双组分混合物不能判分相方向**（见 ②的否定假设），请用冻结伙伴示踪或精确力对齐。
3. **等价性适用范围**：G3 的逐位等价要求 ①伙伴逐点复制 ②`τ_1 = τ_2` ③同强制格式。任一条破坏
   （`u_eq="mixture"`、`force_scheme="guo"`）即不再逐位一致；此时 MCMP 多出交叉项，EOS 也不同
   （`p_mix = cs²(ρ_A+ρ_B) + (G_12/2)cs²ψ_Aψ_B` vs `p_SC = cs²ρ − (G/2)cs²ψ²`），
   **逐位等价不得外推为热力学等价**。
4. G4 仅 `G_12 = −1` 单点，判据为定性不变量（对比度不增长）。
5. G6 参考是同一晶格 EOS 的 Maxwell 构造 ⇒ 验证的是离散格式与自身 EOS 的热力学一致性，
   **不**验证 `ψ_exp` 对真实工质的适用性。
6. 本环境无网络，未取得锚点仓库源码；「做法」按锚点名称与 waLBerla lattice-model 习惯语义复述，
   验证对象是 TensorLBM 侧的模型边界，未做源码级逐行对照（诚实局限）。
