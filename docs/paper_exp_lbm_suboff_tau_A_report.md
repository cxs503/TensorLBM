# paper-exp lbm-suboff-tau · 第 A 项报告（平台报告的仓内落盘副本）

## ① 案例介绍

**物理背景**：DARPA SUBOFF Model 4740 裸艇（AFF-1）深潜拖曳阻力。本单（research_plan 第 A 项）只做**判据侧**：
把 C_T 点值逐字落盘（#8800 判 C1 PARTIAL_FAIL 的修复），并把锚 Re 阶梯改成可执行设计（#8854 报 61–144 h/档）。

**几何/流体（引句可核）**：L_max = 4.356 m，D = 0.508 m（L/D=8.57），S = 5.998 m²（实验口径 WSA），
ρ = 1000 kg/m³，ν = 1.139e-06 m²/s（淡水 15 °C 声明假设），
C_T = R_T/(0.5ρU²S)，Re = U·L/ν，深潜无自由面（Fr 非相似参数）。

## ② 怎么做的

1. **逐字转录 + 机检**：`sources/anchor_points_transcriptions.json` 45 条引句（file+行号+正则），构建时校验
   「quote == 该文件第 N 行原文 + 正则可解析」，命中率 100%（失配即失败）。
   力值取 DTRC Table 14 p.23（`suboff_reference_data.py:94-99` + `docs/suboff_experimental_resistance_validation_2026-08-01.md:23` 双录对校），
   4 位有效数字 Re 阶梯取 IN25-T6 表 2（`docs/survey/IN25_T6_external_mature_tech_survey.md:95-100`）。
2. **零手抄三层**：数字全部正则解析；公式系数（0.075/2、0.455/2.58、0.37/−0.2、26.66、150、u_lb、m）亦解析；
   AST 自检禁止脚本内出现等于派生量的浮点字面量（81 字面量 / 30 派生量，0 违规）。
3. **ITTC-78 C_F 三路复算**：direct_log10 / via_natural_log / 60 位 Decimal。
4. **可达性**：`cells=26.66·N³`、`steps=150·N`、`y+=0.5(u_τ/U)Re/N`、`u_τ/U=sqrt(C_F/2)`、`δ/L=0.37Re^-0.2`；
   吞吐用本单新测集群数据（loong64 n315，job c1794214063_38，D3Q19+MRT 64³ = 8.75 MLUPS/节点）
   与仓内整解器实测 1.155 MLUPS/节点（gci_v4.json）。
5. **相似性误差预算**：单常数形式因子 + 双摩擦线（ITTC-78 vs Schoenherr）差。

## ⑤ 注意点

1. **退役锚**：`Re=1.2×10⁷`（[B] 级、两位有效数字）与 4 位阶梯差 2.94%；按仓内 ν(15 °C)/ν(20 °C) 反解
   它对应约 16.2 °C、声明 ν 对应约 15.0 °C
   ⇒ 差异可由水温解释，故弃用该锚（不是放宽 0.1% 判据）。
2. **Re 阶梯是仓内派生量**（grade=DERIVED_IN_REPO）：C2 的 ≤0.1% 验证「单位/特征长度/转录无漂移」，非独立物理验证；ν 假设影响单列（1.11%，经 m=−0.0935）。
3. **两个 y+ 带必须分开**：预注册操作带 [30,5000] 按它取网格仅 N≈45、δ/h≈0.64 格（无意义）；精度判据须用标定带 [30,150]。
4. **仓内实测警示**：锚 Re 档在 y+ 均值 1878–4660 时最差 C_T 误差 2962.7%（IN12_S6_WALL_LADDER.md）—— 算得动 ≠ 可信。
5. **吞吐口径**：8.75 MLUPS/节点是纯核上界；生产路径 1.155 MLUPS/节点。两率都给，结论对其不敏感（差 3 个数量级）。
6. **离线**：ADA359226 / CFD Letters 原 PDF 不在工作树内 ⇒ 全部锚为仓内已归档文本的逐字二手转录（工件内已披露）。
