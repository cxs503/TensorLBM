## 1. 案例介绍（物理背景 / 几何 / 参数表）

### 1.1 物理背景

船舶操纵性模型验证分两类：
- **开环**：固定舵角的稳态回转（turning circle），验证"稳到哪"
- **闭环**：zig-zag（跌路/超调）试验，验证"操舵后什么时候停得住"，是 IMO MSC.137(76) 强制衡准

本任务覆盖两类，使用线性横荡–首摇（sway–yaw）模型（Abkowitz 1964 / Nomoto 1957 / Fossen 2011 ch.7）：

```
M q̇ = A q + b(δ) + f_nl(v),   q = [v, r]^T,   ψ̇ = r,   R = U/r,   K = r/δ
```

### 1.2 船舶参数（KVLCC2 级大型油轮，实尺度）

| 参数 | 值 | 参数 | 值 |
|---|---|---|---|
| L_pp | 320.0 m | Cb | 0.81 |
| B | 58.0 m | ρ | 1000 kg/m³ |
| T | 20.8 m | U | 7.97 m/s (≈15.5 kn) |
| Δ = ρ·Cb·L·B·T | 3.116e8 kg | I_z = Δ(0.25L)² | 1.993e12 kg·m² |
| L/V | 40.2 s | 导数集 | `NOMINAL_TANKER_PRIME`（代表性线性集，**非** PMM 反演） |

**关键声明**：水动力导数为代表性线性集，**非**从 PMM 实验或 CFD 反演得到；无自由面、无桨舵尾流、无横倾/横摇耦合。因此本任务的证据等级是**内部验证**，不是对某条实船的绝对精度声明。

## 2. 怎么做的（方法 / 流程 / 关键设置）

### 2.1 稳态回转（开环）

**代码位置**: `src/tensorlbm/maneuvering.py` — `ManeuveringModel.steady_turn`（精确 2×2 固定点求解）、`simulate_turn`（半隐式 Euler + RK4 时间积分）、`analytic_transient`（精确模态瞬态解）

**验证策略**:
1. 数值积分 vs 解析固定点：每个 (舵角, dt) 水平的稳态回转半径 R 和漂角 β 与解析解比较
2. 双水平网格收敛：coarse (dt=1.0 s) vs fine (dt=0.25 s)，span ≤ 3%
3. 独立代数路线互裁：NumPy 直接求解 vs Nomoto 闭式 vs 库函数，相对差 < 1e-6%
4. 瞬态收敛阶：Euler 观测阶 ∈ [0.8, 1.3]，RK4 观测阶 ≳ 3.5

**判据**（先于动手定）:
- C1–C2: 每水平 |R_err|, |β_err| ≤ 3%
- C3: 双水平 span ≤ 3%
- C4: 独立代数路线一致 < 1e-6%
- C5–C7: 瞬态误差 ≤ 3%，加密比 > 3
- C8: 方向稳定性（所有特征值实部 < 0）

### 2.2 Zig-zag（闭环）

**代码位置**: `src/tensorlbm/maneuvering.py` — `simulate_zigzag`（事件驱动数值积分）、`analytic_zigzag`（精确分段模态解）、`ZigZagResult`、`imo_msc137_zigzag_limits`、`check_imo_msc137_zigzag`

**关键创新**:
- **事件驱动积分**：换舵时刻（ψ 达到 ±ψ_zz）与首向极值时刻（r 变号）都在**步内**用二分定位（分数二分到 1e-13），因此换舵时间误差是积分器截断误差量级，而不是 dt 量化误差
- **精确分段模态解**：每段舵角恒定 ⇒ LTI，`q(t)`、`ψ(t)` 是双指数闭式，换舵/极值时刻是闭式的根（扫描 + 二分到 1e-14 s）
- **ψ 求积阶数修复**：最初用 Simpson，中点首摇率取自预测态（O(dt²)），且末段错用积分后的平均态 → 观测阶稳定在 3.02；把 ψ 当第 3 个 RK4 状态、四段求积全部取**段值**后，ψ 误差比值回到 16（4 阶），整案观测阶 4.02

**判据**:
- 两路线相对差 < 1e-4
- Euler 观测阶 ∈ [0.8, 1.3]
- RK4 观测阶 ≳ 3.5 且最细 dt 相对误差 < 1e-5
- 线性尺度不变性 < 1e-9
- IMO 判据对名义船 PASS、对降级船 FAIL

### 2.3 工具链

- 基准: `benchmarks/verified/maneuvering_steady_turn/{run.py, result.json}`、`benchmarks/verified/maneuvering_zigzag/{run.py, result.json}`

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

### 5.1 踩过的坑

1. **ψ 求积阶数会悄悄把 RK4 降成 3 阶**（本任务实踩）：最初用 Simpson，中点首摇率取自 `q + dt/2·k1` 的**预测态**（O(dt²)），且末段错用积分后的平均态 `q_new[1]` 而非 `k3` 段值 → 观测阶稳定在 3.02，而 `q` 本身是 4 阶（r 误差比值 16）。把 ψ 当第 3 个 RK4 状态、四段求积全部取**段值**后，ψ 误差比值回到 16（4 阶），整案观测阶 4.02。诊断手法：单独 `_step_sway_yaw` 定舵角积分到已知 T，与 `_segment_solution` 闭式比，看误差比值是否 =2^p。

2. **换舵/极值必须在步内定位**：若按"先整步走完再看是否越过"，换舵时间带 O(dt) 量化误差，超调角对 dt 的收敛会退化成 1 阶，且两条路线无法互相裁决到 1e-12。

### 5.2 局限

1. **线性模型 10/10 与 20/20 尺度不变**（§3.4）。因此这两档**不是**两个独立证据，而是同一解的等比放大；真正提供第二个独立证据的是 cross-flow 案例与 Euler/RK4 两种离散。

2. **绝对精度未验（WITHELD）**：导数集是代表性线性集，非 PMM/CFD 反演；无舵速限制、无桨舵尾流、无横倾/横摇耦合、无自由面。本任务的证据等级是**内部验证**（两条独立路线一致 + 收敛阶正确 + 判据有鉴别力），不是对某条实船的绝对精度声明。文献上 KVLCC2 的 20/20 首超调约 10–15°，本线性集给 4.2°，差距主要来自导数集与缺少非线性。

3. **IMO 判据的适用范围**：MSC.137(76) 只规定 10/10 与 20/20；其它组合（如 20/10）返回 `applicable: False` 而不是编一个阈值。10/10 的限值依赖 L/V（<10 s → 10°，≥10 s → 20°），未给 L/V 时直接拒绝出结论。

4. **端到端流体-操纵耦合仍是结构阻塞**：水动力导数未从 LBM 流场提取，无自由面，无桨舵尾流。完整链条（LBM → 导数识别 → 操纵预报）待后续任务。

### 5.3 适用范围

- 本验证适用于**线性横荡-首摇模型**的内部一致性检查
- 不适用于非线性操纵性预报（如大舵角、横倾耦合、浅水效应）
- 不适用于实船操纵性衡准符合性声明（需 PMM 实验或全尺度试航数据）
