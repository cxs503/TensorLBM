**节点**：tp-ver-5 自找活 · mission 16728 · 分支 `agent/m16728` · 仓 TensorLBM
**锚点**：`KPI-LBM-VERIFIED-CAPS`（周新增通过独立物理验证的能力）——本单为 `trt_collision` 模块补上
`intl_bench` 证据阶梯第 4/5 级（标准算例 + 网格收敛），其审计缺口原文为「TRT 无独立算例」（tier 2）。

## ① 案例介绍（物理/几何/参数）

平面 Poiseuille 流（充分发展、x 向周期），均匀体积力 g 驱动，上下壁 pre-streaming 半程反弹（仓内约定）：

    u(y) = g/(2ν)(y−1/2)(H+1/2−y),   Q = gH³/(12ν),   ν = (τ₊−1/2)/3

| 参数 | 值 |
|---|---|
| 体积力 g | 2e-6（Δρ 由 gL 平衡，Ma≈0.004） |
| 格子/精度 | D2Q9，float64，x 向 4 格周期（不提分辨率） |
| 壁面 | 半程反弹，壁面位于 y=1/2 与 y=H+1/2（H=流体行数） |
| 碰撞 | BGK(τ) vs TRT(τ₊, Λ=3/16)（`solver.collide_bgk` / `solver.collide_trt`） |
| 初值/稳态 | 标称解析剖面作初值（免瞬态）；3000 步，末 200 步时均；Q 平台 <1e-7 |
| 台阶 | H = 8/16/32（τ=0.80）；τ 扫描 0.55–1.90（H=32） |

**待验命题**（`collide_trt` docstring 原话）：「Λ=3/16 eliminates wall placement errors in Poiseuille flow
（Ginzburg 2008）」。观测量：δ_eff = H_eff − H，H_eff 由流量反解（不做剖面拟合）。

## ② 怎么做的

`verify_trt_wall.py` 一套驱动、一套初值、一套测量算子，只切换碰撞算子；无外推（extrap: none）、
无壁面修正因子。两个独立观测量 \((Q \to δ_{eff})\) 与（剖面 L2 / 中心线相对误差）互校。

## ⑤ 注意点（坑与局限）

1. **两条独立证据同向**：δ_eff(τ) 的 BGK 曲线在 τ≈0.933 取最小（Λ_BGK=(τ−1/2)²=3/16 处），
   且该 τ 上 BGK 与 TRT **逐位一致**（δ_eff=−0.00374 双方相同）——这正是 Ginzburg 参数化的签名，
   说明测量装置抓到的是壁面位移物理而非驱动缺陷。
2. **「eliminate」应读作 <0.01 cell**：τ≤1.2 时 TRT |δ_eff|≤0.0094，而 τ=1.9 仍有 −0.024 cell
   （BGK 同 τ 为 +0.123，5 倍差）。高阶项不消失，docstring 措辞（eliminate）宜改为
   「top up to O(1%) of a cell」。
3. **驱动实现坑（本单自伤，记录）**：先按「从静止起算 + Guo (1−1/2τ) 前因子」实现时，
   τ→0.5 附近前因子→0 而宏观速度未补 +g/2 半步动量，得到恒定 −32% 流量；
   改为「常数源项 3w_ic_ix g + 解析剖面初值」后与解析差 <0.1%。量纲自检 Σ_i F_i c_ix = g 是必要门。
4. 适用范围：充分发展层流、半程反弹壁；不覆盖曲面/插值反弹（见 `staircase_wall_offset`、
   `poiseuille_3d_ellipse` 两案，均 honest-FAIL）。

## ⑥ 误差判定（vs 解析基准，逐项、显式回答是否 <3%）

| 量 | 基准 | 实测误差 | <3%? |
|---|---|---|---|
| TRT H=32 profile L2（τ=0.55…1.90 全区） | 解析抛物线 | ≤0.250% | **是** |
| TRT H=16 profile L2（τ=0.80） | 解析抛物线 | 0.2140% | **是** |
| TRT H=32 中心线速度（τ=0.80） | 解析 | −0.0393% | **是** |
| BGK H=32 τ=1.90 profile L2 | 解析 | 1.014% | **是**（但 δ_eff 0.123 cell = 0.38%·H，τ 依赖） |
| TRT 壁面位移 δ_eff | 半程壁面平面 | ≤0.0094 cell（τ≤1.2）/ 0.024 cell（τ=1.9） | **是**（相对 H=32） |

结论：命题**成立到定量精度**——TRT(Λ=3/16) 把半程反弹的 τ 依赖壁面位移压低约 10 倍（τ≤1.2），
网格收敛二阶（p≈2.00）；残余 τ=1.9 尾部如实登记，不作「完全消除」的粉饰。
