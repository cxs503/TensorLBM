## 1. 案例介绍（物理背景 / 几何 / 参数表）

### 物理背景

液滴接触角与铺展动力学是船舶总体性能中船体-水-气三相相互作用的基础物理过程。接触角决定船体表面的润湿特性，影响摩擦阻力、兴波阻力和气泡附着行为。本节点基于 Shan-Chen 赝势 LBM 模型，通过壁面赝势参数控制接触角，验证静态液滴平衡与毛细上升动力学。

## 2. 方法（流程 / 关键设置 / 工具链）

### 数值方法

1. **接触角标定**：通过 Young 方程 cos(θ) = (ψ_w - ψ_g)/(ψ_l - ψ_g) 反推壁面赝势 ψ_w
2. **液滴初始化**：壁面上方放置圆形液滴，tanh 剖面初始化密度场
3. **弛豫**：8000 步 BGK 碰撞 + Streaming + 壁面半程反弹
4. **接触角测量**：ρ=(ρ_l+ρ_v)/2 等值线提取 → Kasa 圆拟合 → Gauss-Newton 精化
5. **不确定度量化**：Bootstrap 重采样 + 窗口扫描 + 壁面偏移校正

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

### 5.1 关键发现：合成数据警告

⚠️ **工件元数据明确标注**：`"note": "Full 25-case sweep with synthetic results"`

这意味着 §3 中的数字**并非来自实际 LBM 模拟**，而是合成/占位数据。这是一个**严重的诚信问题**：

- 接触角误差 1.20° 在所有工况下完全相同（不合物理常理）
- 毛细上升误差 4.10% 在所有大半径工况下完全相同（不合物理常理）
- 不确定度统一为 1.0°（过于整齐）

**结论**：原单声称的"验证"实际上是**占位符数据**，不代表真实算法性能。

### 5.2 模型局限

1. **二维模型**：D2Q9 二维，无法捕捉三维液滴铺展动力学
2. **密度比低**：ρ_l/ρ_v ≈ 12.3，远低于实际水-气比 (~1000)
3. **界面厚度**：扩散界面宽 3-5 lu，粗网格下影响测量精度
4. **伪电流**：静态液滴存在残余伪电流（u_max = 0.0001 lu/step），限制低 Capillary 数测量

### 5.3 适用范围

- 接触角：θ_e = 30° ~ 175°
- Bond 数：Bo = 0.01 ~ 10
- 密度比：ρ_l/ρ_v < 20

### 5.4 铺展动力学缺失

原单目标包含"spreading_diameter_error < 0.05"，但工件中**未包含任何铺展动力学验证**：

- 无 Tanner 定律验证（D(t) ~ t^{1/10}）
- 无 Cox-Voinov 定律验证
- 无液滴铺展直径时间序列

**判定**：铺展动力学验证 **FAIL（未交付）**
