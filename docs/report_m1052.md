## 1. 案例介绍（物理背景 / 方法学 / 参数表）

### 1.1 物理背景

极地航线航行面临不确定冰场：冰厚/浓度/强度随时间和空间变化，且预报存在集合离散性。
船舶需根据冰情做出操作决策——是否进入某区域、以何航速通过、是否需要破冰船护航。

**IMO MSC.1/Circ.1519 POLARIS 方法学** 提供了标准化的极地操作限制风险评估框架：
- 输入：冰情观测（厚度、浓度、冰龄）+ 船舶冰级（Ice Class）
- 核心量：RIV（Risk Index Value）→ RIA（Aggregate）→ RIB（Baseline）→ RIO（Outcome）
- 判据：RIO ≥ 0 不受限；-1 ≤ RIO < 0 需护航；RIO < -1 不允许作业

### 1.2 模块架构

| 子模块 | 职责 | 证据等级 |
|--------|------|----------|
| `risk_tables.py` | RIV 矩阵（12 冰级 × 10 冰情 = 120 格），冰情分类 | REAL（表驱动，导入即自校验） |
| `engine.py` | RIV/RIA/RIO/RIB 合成、RiO 判据、单调二分窗口搜索、96 格单调性预检 | REAL（精确代数，无拟合） |

## 2. 方法 / 流程 / 关键设置

### 2.1 RIV/RIA/RIO/RIB 合成

**单冰情闭式**：
```
RIO(t, C) = 3 + C × (RIV(regime(t)) - 3)
```
对浓度 C、对冰厚（经冰情序号）**单调不增**——这是窗口边界单调搜索（二分）成立的前提。

**多冰情聚合**：
```
RIA = Σ_i C_i × RIV_i      （已报告冰情类别按密集度加权）
RIB = (1 - Σ_i C_i) × 3    （开阔水域基线贡献）
RIO = RIA + RIB              （归一化到 [-3, +3]）
```

### 2.2 操作窗口搜索

给定冰级和月历气候态，对每个 (月, 冰厚) 格点：
1. 计算 RIO(t, C_month)
2. 若 RIO ≥ 0 → 该格点允许
3. 利用单调性（RIO 对冰厚单调不增），二分搜索最大可操作冰厚
4. 若提供船舶积冰参数，叠加 GM 判据门：GM' ≥ GM_min 才允许

### 2.3 积冰-GM 链

```
m_ice = (30 × A_deck + 7.5 × A_lat) / 1000   (t)
GM' = (Δ × GM₀ - m_ice × z_ice) / (Δ + m_ice)
判据: GM' ≥ 0.15 m
```

时变：积冰随低温线性累积（6 h 达满额），气温 > -2°C 时融化，人工除冰按比例移除。

## 5. 注意点 / 局限 / 适用范围

### 5.1 RIV 矩阵转录风险

RIV_MATRIX 由 IMO MSC.1/Circ.1519 附件 1 风险指数表手工转录，工作树内无通函原件。
引擎与判据逻辑不依赖具体表值（只依赖单调性结构），但**交付或对外引用前须以原件逐格复核**。

### 5.2 集合预报未实现

W6-N06 的核心目标是"集合冰预报驱动的鲁棒优化"，但当前交付仅为确定性 POLARIS 引擎。
集合成员扫描、概率聚合（如 P50/P90 操作窗口）、风险分位数等**未留档**。
这可能是后续工作（W6-N06 的 Phase 2）或与其他模块（如 W5-N06 脱冰动力学）的集成接口。

### 5.3 气候态为参数化预设

`climatology.py` 提供的是参数化月历预设（北极边缘/波罗的海），非真实再分析数据。
生产环境需接入真实冰情气候态或预报场。

### 5.4 积冰模型为简化

内置积冰模型为线性累积 + 温度阈值融化，未考虑：
- 风速/浪溅对积冰速率的影响
- 积冰分布的非均匀性
- 积冰对水动力性能的耦合影响

### 5.5 适用范围

- 本模块适用于 **POLARIS 方法学框架内** 的极地操作限制风险评估
- 不适用于：结构冰载荷计算、破冰阻力预报、冰区航线气象导航（需耦合其他模块）
- 冰级映射支持 Cat I/II/III 别名，但最终以 PC1–PC7 / IAS–IC / NOC 为准
