## ① 案例介绍

**物理背景**：周期域中心一个液相液滴（ρ_l）浸没于气相（ρ_v），用 SCMP 伪势模型 `ψ(ρ)=1−e^{−ρ}`（Shan–Chen 1993/94 指数型）演化到稳态。弯曲界面两侧的压强跳跃满足 **Young–Laplace 方程**：2D 圆柱 `Δp = σ/R`，3D 球 `Δp = 2σ/R`。对多个半径测量稳态 Δp，若 `Δp` 与 `1/R_eq` 严格线性（截距≈0，逐半径 σ 一致），则说明该伪势模型给出的表面张力与曲率无关，即 Laplace 关系成立、σ_eff 是模型的自洽属性。这正是多相格子 Boltzmann 进入工程计算（气泡/液滴/相变）前必须通过的物理一致性检验。

**几何与参数表**（逐项来自各 run 的 `meta.json`）：

|---|---|---|
| 格点模型 | D2Q9 `tensorlbm.multiphase.collide_sc_single_component` | D3Q19 `multiphase3d.collide_sc_single_component_3d` |

| 耦合常数 | 物理 G_eff=-5.0（库调用 G_lib=+5.0，见 ⑤-1） | 同左 |

## ② 怎么做的（含 mission 25 失败诊断）

### 诊断结论

mission 25 的失败证据是 `status=failed, result=未完成：模型未调用 finish`——这是**流程/预算型失败，不是算法失败**。三条互证的线索：

1. **硬件与案例缺省参数不匹配**：`run.py` 缺省 `--device3d cuda:0`，本机 `torch.cuda.is_available()=False`，按缺省跑 3D 立即抛异常；README 的复现命令也假定了 GPU。
2. **全量串行在 CPU 上远超单任务预算**：实测单步成本（表6）最高为 D3Q19 R=40 L=160 的 2337.8 ms/步 → 单个配置 6000 步即需 14027 s，案例缺省全量（2D×3 + 3D×3 串行、每配置 ≥6000 步）合计约 **317 分钟**，若按 `--max-steps 30000` 上限更久。一次“照文档全量跑完”的尝试必然把整单时间吃光。
3. **长跑没有任何中途落盘**：被打断后既无 artifact 也无 finish → 记录成“未调用 finish”。

### 绕行方案（本单实际方法）

把“一次大跑”拆成 **每个 (dim, R) 一个独立进程**并并行执行，每个进程带**墙钟预算 + 每采样点增量落盘 + NaN 守卫 + 异常也落盘**，因此无论收敛、被截断还是崩溃，工件都存在：

```
sweep_m183.py     每 (dim,R) 一进程（12–20 线程，eager 路由，预算 900–2400 s）
   ├─ 物理不重写：从案例 run.py 导入 init_rho / eos_pressure / fit_laplace / _radius_field，
   │             从 tensorlbm 导入 collide_sc_* / stream* / equilibrium*（零手写 collide/stream）
   ├─ 测量自检：本驱动的 band 参数化 measure() 必须与案例 measure() 完全一致（实测 rel err = 0）
   └─ 增量产物：meta / history.json（每 1000 步）/ profile.json / snapshot.npy / run.json
analyze_m183.py   复用案例 fit_laplace 判定；对比 result.json 基线；域尺寸独立性与被中断 run 归档
mechcheck_m183.py 独立力学路线（压强张量）交叉验证 → honest-negative（见 ⑥）
plot_m183.py      6 张图（场云图/剖面、Laplace 拟合、复现误差、收敛、域敏感性+成本、力学路线）
report_m183.py    docs markdown + 报告 API 发布（数字全部程序化注入）
```

## ⑤ 注意点 / 踩过的坑 / 局限

1. **库的 SC 力符号约定（最大的坑，案例 README 已标注）**：`_sc_neighbor_weighted_sum` 用后向 gather ψ(x−c) 注入加速度力，使库内力 = 标准 SC94 力的相反数，**必须用 G_lib=+5.0 才实现标准吸引 G_eff=−5.0**；照字面传 G=−5.0 得到的是排斥。EOS 压力必须用 `p=ρ/3+G_effψ²/6`（G_eff=−5），否则 Δp 符号相反。本单 smoke 测试（200 步）出现 Δp<0 只是瞬态未平衡，不是符号错误——6000 步后 Δp>0 且与基线吻合到 1e−7。
2. **本机无 GPU**：`torch.cuda.is_available()=False`，3D 只能 CPU 跑。为把墙钟压进单任务预算，3D 半径集合取较小尺度、且砍掉了最贵的 3D R=40（L=160，4.1M 格点，实测 2338 ms/步 → 6000 步 ≈ 234 分钟）。**这是时间预算妥协、不是精度妥协**（判据是 σ 与 R 无关），但确实使 3D 半径集合与基线不完全相同，因此 3D 只做“半径配对点（R=15）+ 基线趋势线（表3b）”两重比较；结论部分已如实记为 FAIL（过原点判据 3.02% 微超 3%）。
3. **离散共存 ≠ 麦克斯韦共存**：初场 ρ_l/ρ_v=1.957/0.1596 是本方案实测离散值（密度比 ~12:1），远低于连续 EOS 麦克斯韦构造的 1.7505/0.0493（~35:1），属伪势格点离散效应，不是 bug；液滴靠质量守恒自动弛豫到 R_eq（与 R_init 差 ≤3%）。
4. **伪速度不为零**：max|u|≈0.13–0.14，为 SC93 速度-平移格式固有伪流；因此 Δp 必须取稳态末 3 点平均并检查漂移（表1 给了采样散度）。
5. **测量口径敏感性**（表4）：压力环带从 0.5/1.5 收紧到 0.6/1.4 R_eq，Δp 变化 0.007%–0.24%，说明 σ 的测量不确定度主要来自界面弥散层取样位置，而非统计噪声。
6. **域尺寸效应**（表5）：同一半径换周期盒尺寸，σ_i 最大变化 ~1%，其中主要来自 R_eq 的 1% 级漂移（盒体积改变 → 气相密度改变 → mid-density 阈值与等效半径变化），Δp 本身变化 <0.3%。
7. **力学路线交叉验证失败（如实记录）**：见 ⑥ 与图4，朴素离散压强张量三种写法都复现不出 σ，偏差 46%–126%；这属于本单后处理诊断的局限（一阶/单侧 SC 压强张量在 W≈4 弥散界面上不满足散度一致性，D2Q9 四阶矩各向异性项与物理信号同量级），需要梯度修正/散度一致的压强张量才能闭合，而修库超出本单范围（纪律：不改业务代码）。**未把该路线用于精度判定。**
8. **未做**：3D 力学路线（需完整 3D 场，本单只落中心切片）；SDAA 加速卡上 compile/eager 的 A/B 对照（本机无加速卡）；3D R=40 与 R=25（成本见 ⑤-2，超预算被主动终止，工件已归档在 `runs/m183_laplace/_aborted/`）。
