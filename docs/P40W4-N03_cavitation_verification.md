## ① 案例介绍

空化是水翼/螺旋桨/舵的升力上限与结构剥蚀来源。本节点选取两个教科书级验证面：

* **片状空化**：NACA0015（t/c = 0.15，几何在 `test_cavitation_p40w4n03.py` 与
  `docs/P41-N02_cavitation_airfoil_validation.md` 中已核验，最大厚度误差 < 0.3%），
  alpha = 5 deg、Re = 1e5、sigma = 1.0 / 0.8 / 0.6，量：空泡长度 L_cav/c 与最大厚度
  delta_cav/c，基准 Brennen (1994/1995) 水洞实验 + Merkle, Feng & Buelow (1998) 数值解；
* **云状空化**：Clark-Y（t_max = 0.117 @ x/c = 0.40），alpha = 6 deg、Re = 1e5、
  sigma = 0.5 / 0.4，量：脱落 Strouhal 数 St = f c / U，基准 Franc & Michel (1985,
  JFM 154) 实验 + Franc (2001) 综述。

无量纲化：长度/弦长、速度/U、压力/(rho_l U^2)、时间/(c/U)（故 St = f）。空化数通过
蒸汽压进入：p_inf = 0 => p_v = -sigma/2。基准表（`reference_data()`，
provenance = **literature-digest**，转录不确定度 ±10%/@L_cav、±15%/@delta、±20%/@St）：

| sigma | L_cav/c (Brennen 1994 exp) | L_cav/c (Merkle 1998 num) | delta_cav/c (Brennen 1994) |
|---|---|---|---|
| 1.0 | 0.25 | 0.23 | 0.025 |
| 0.8 | 0.4 | 0.37 | 0.038 |
| 0.6 | 0.65 | 0.6 | 0.055 |

**几何先验核验**：NACA0015 最大厚度 0.150、面积 0.1016 c^2（误差 < 1%）；Clark-Y 为
声明过的解析拟合（t_max = 0.117 @ 0.40、弯度 0.034 @ 0.42），逐点表格差异计入局限。

## ② 怎么做的

### 求解器家族（两条路线）

1. **动力学（kinetic）混合物模型**（`tensorlbm.cavitation_airfoil.MixtureCavitationSolver`，
   既有）：不可压液体动量 + 气相体积分数输运 + Schnerr-Sauer 相变源项（Rayleigh-Plesset
   前因子已由 `tests/test_cavitation_schnerr_sauer_reference.py` 解析锚定）；MAC 交错网格、
   二阶迎风对流、Smagorinsky SGS、纯 Neumann 投影（FFT 对角化）、翼型用 Brinkman 罚函数
   刚性体。
2. **平衡（equilibrium / 常压空泡）模型**（本节点新建 `tensorlbm.cavitation_equilibrium`）：
   用同一套液体动量，但把气相区压到 **p = p_v 的 Dirichlet 条件**（Riabouchinsky 常压空泡
   闭合），自由边界由 `p < p_v` 的自洽不动点决定。压力方程变成混合 Dirichlet/Neumann
   问题，用 **以常系数 FFT Neumann 解为预条件的共轭梯度**求解（`mixed_poisson`，
   逐次收敛到 1e-13，见测试）。alpha 用刚性极限
   `alpha = clip((p_v - p)/switch_width + 0.5)` 弛豫（switch_width = 0.02 的敏感性见 ⑤）。

这两条路线对应任务书 (c) 的相变源项路线与经典常压空泡路线；伪势（Shan-Chen）路线在
1e3 密度比、c = 20~200 网格下界面无法解析（库内 `docs/g_ledger_g3_cavitation_coexistence.md`
同结论），本节点不再重复尝试。

### 本节点对既有求解器的两处改动（都有测试）

* **D1 修复：入口核化（nuclei）Dirichlet 边条件**（`CavitationFlowConfig.nuclei_inflow`，
  默认关以保证历史位级可复现）：入口列 alpha >= alpha_nuclei，且必须在 alpha 输运/源项
  *之后*施加（否则同一步内就被凝结支吞掉）。
* **压力基准锚**（`pressure_anchor`）：纯 Neumann 投影的压力水平任意，`p < p_v` 判据
  因此落在任意常数上；锚定入口平均压力为 0 后才与 p_v = -sigma/2 可比。

### 数值/工具链

* 计算：本地 torch float64（cpx 20 诊断）+ 集群作业 `cj243`（4 分片，TensorLBM 仓，
  c/c = 50/100 生产算例，4000~6000 步，`artifacts/p40w4n03/campaign.py`）；
* 度量：`cavity_metrics`（弦向坐标系逐站扫描吸力面法向，阈值 alpha > 0.5）、
  `dominant_frequency`（Hann 窗 rFFT，返回 St = f c/U）；
* 验收：`artifacts/p40w4n03/analyze.py` 读工件 JSON 生成判据表 `acceptance.json`；
* 测试：`tests/test_cavitation_p40w4n03.py`（15 例）验证"仪器"——混合 Dirichlet/Neumann
  Poisson 对算子残差 < 1e-10、Dirichlet 行精确、平衡开关饱和/单调、平衡求解器质量守恒、
  冷启动无空泡、核化边条件、空泡度量在合成场上恢复已知长度/delta ±0.02、Strouhal 估计
  在合成信号上恢复已知频率 ±5%、基准表单调性。

## ⑤ 注意点（坑、局限、适用范围）

1. **D1 无核化边条件的 starving（已修）**：凝结支（p > p_v，几乎全域）以 ~O(100) /(c/U)
   的速率吞掉气相分数，而入口没有核化补给 —— 初值种子 alpha ~ 1e-6/1e-4 在 0.4 个
   时间单位内衰到 1e-7 量级（`artifacts/p40w4n03/instr_s1_n20.json`）。本节点加入入口核化
   Dirichlet 边条件并加测试；但**必要不充分**（见 D2）。
2. **D2 无压力反馈 ⇒ 空泡长度塌到单相等压线**：σ = 1.0 下每步只有 **2 个网格**满足
   p < p_v（c/c = 20），Schnerr-Sauer 源项在 2 格宽的袋里增长速率 52 /(c/U) 却同时被
   平流以 h/U = 0.05 的时间尺度冲走 —— 稳态 alpha 只有 1e-7~1e-2；人工种子 alpha = 0.9
   在 2 个时间单位内衰减到 0.24 且最小压力从 -0.596 回升到 -0.538，即**没有把空泡
   压在 p_v 的反馈机制**。这正是 P41-N02 用"单相 p_v 等压判据"代替空泡长度、从而
   L_cav 偏小 3~5 倍的根因。
3. **D3 基座 MAC 求解器存在增长的奇偶模态（未修，阻断全部物理判据）**：投影后液相
   散度残差从 1e-15 起**每步约 ×2** 增长（12 步 → 3.4e-10），力系数无稳态：
   C_l 8.31 → 3.41、C_d 48.6 → 2.9（12 步），2300 步后仍无平台；eta = 1e-3 时罚函数
   泄漏 ~7%（C_d ~ 2.8，物理值 ~0.02 量级），eta = 1e-5 时 C_d ~ 228（1/eta 放大后的
   离散残差噪声底）。**因此 (a)(b)(c) 的物理量即便数值可比也不可信**——这是本节点
   判 FAIL 的决定性理由，而不是"调参没调好"。可复现脚本：`artifacts/p40w4n03/long_run.py`。
4. **D4 压力基准任意（已加锚定）**：纯 Neumann 投影的水平不定；开锚定前后 L_cav 由
   0 变为可用判据，是必要修正。
5. **基准数据出处等级**：Brennen/Merkle/Franc 的表格值是 literature-digest 转录，
   运行时无法核对原文，不确定度 ±10~20% 记在 `reference_data()`；本节点的误差是
   3~5 倍量级，不因该不确定度反转结论。
6. **平衡模型的 switch_width / relax_steps** 是数值正则化（不是物理量）：switch_width
   = 0.02（p 单位）、relax_steps = 4 步。因 D3 阻断，其敏感性未被验证 —— 记为未完成项。
7. **D5 平衡模型的 alpha 开关在钉住格子上有退化不动点（本节点新发现，未修）**：被钉在
   p = p_v 的格子其弛豫目标恰为 alpha = clip(0.5 + 0) = 0.5，故空泡一旦失去种子就会
   向 0.5 收敛并跌破判据 —— 实测种子空泡（L/c = 0.192）在 40 步内退化到 3 格、60 步内
   归零（`artifacts/p40w4n03/eq_seeded_decay.json`）。正确做法是**双边界面试探**（对界面格子
   再解一次"不钉"的压力，用两侧压力判开闭），本节点未实现，列为后续最小可证单元。
8. **下一步最小可证单元**（供后续节点）：先用一个独立验证面（例如 NACA0015 单相
   C_l/C_d 在 c/c = 50/100 与 Abbott 数据 < 15%）把基座 MAC 求解器修到可用
   （Rhie-Chow 动量插值或压力-速度耦合与固壁一致性），再谈空化；否则任何空泡长度都是
   在不可信的速度场上量的。

## 结论（honest FAIL，不可覆盖）

* **(1)(2)(3)(5) FAIL**，根因是基座不可压求解器的奇偶增长模态（D3）与动力学模型缺少
  压力反馈（D2），两者都被量化并可复现；
* **(4)** 在可用数据上为空泡恒零，判据退化，不给 PASS；
* **(6) FAIL**：动力学求解器在 c/c = 20 的散度残差 2.16e-4 > 1e-4（本节点新建的平衡
  求解器在 c/c = 12 为 O(1e-5)，同一判据在它身上通过——差别正是 ⑤ D2/D5 的模型差异）；
* **(7) PASS**：新增 15 例 + 既有 42 例（另 1 xfail 为历史记录的 c/c=30 不稳定）全绿；
* 本节点**新增**：平衡（常压空泡）求解器模块与混合 Dirichlet/Neumann PCG、核化入口
  边条件（含测试）、四缺陷量化登记、以及一套可复用的验证脚手架
  （`campaign.py` / `analyze.py` / `figures.py` / `build_report.py`）。
