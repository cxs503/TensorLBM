**锚点**：NEW（总账外缺口）——`tensorlbm.boundary.suction.SuctionWallBC` 与

**类别**：defect（缺陷取证 + 门禁）；不是精度达标声明。

---

## ① 案例介绍（物理背景 / 几何 / 参数表）

**目标物理**：抽吸边界层 ASBL（asymptotic suction boundary layer）。半无限平板以均匀法向
速度 V 抽吸，流向速度剖面满足 N–S **精确解**（Schlichting）：

- u(y) = U∞ (1 − e^{−V y/ν})，v(y) = −V，δ = ν/V（与 x 无关），
- 壁面剪应力恒等式 **τ_w = ρ U∞ V**，对应 **C_f = 2V/U∞**（与 Re_x 无关）。

解析解自洽性（本单独立核验，非引用）：代入 x 动量 `v u_y = ν u_yy`：
LHS = −V·(U∞ V/ν)e^{−Vy/ν} = −U∞V²/ν·e^{−Vy/ν}；RHS = ν·(−U∞V²/ν²)e^{−Vy/ν} = 同值 →
**恒等成立（0 残差）**。因此这是一个"有硬解析锚"的验证面，唯一缺的是可信的 LBM 端实现。

**参数表（复现命令见 ③）**

| 量 | 值 | 说明 |
|---|---|---|
| U∞ | 0.1（诊断） / 0.05（Couette 对照） | 格子单位 |
| V | 0.002 / 0.00125 | 抽吸速度 |
| ν | 0.02 | τ = 0.5+3ν = 0.56 |
| 域 | 48² / 16×4 | 驱动默认域 / 最小 Couette 对照域 |
| Ma | 0.17 / 0.087 | O(Ma²) 可压误差 ~3% / 0.8% |
| δ/dx | 10 / 16 | ν/V |

## ② 怎么做的（方法 / 流程 / 工具链）

1. **代码审计**（读 `boundary/suction.py`、`verification/asbl/*.py`，逐行对照 Zou & He 1997 的三条件闭合）。
2. **对照实验**（真实运行，torch float64 CPU，`solver2d.collide_bgk2d/stream2d/macroscopic2d`）：
   - A 组：按库自带驱动 `ASBLSimulation` 的默认参数跑，记录质量/速度时间历程直至发散；
   - B 组：最小 Couette 对照（下壁 u=0、上壁 u=U、V=0）——**解析解已知为线性剖面**，
     用于检验"壁面切向速度是否真的被施加"；
   - C 组：按 Zou–He 标准闭合重写后重跑 A/B。
3. **门禁化**：把不可用的 BC 改为**默认 raise**（`SuctionWallBCUnverifiedError`），
   诊断用途需显式 `allow_unverified=True`；`verification.asbl` 同步 withdrawn 并显式 opt-in。
4. **回归测试**：`tests/test_suction_wall_bc_audit.py`（5 项，全绿）。

工具链：Python 3.11 + torch（float64）+ pytest；数值原始量见
`artifacts/m16154/audit_numbers.json`，图 `artifacts/m16154/fig_audit_m16154.png`。

## ③ 计算结果（数字表，`artifacts/m16154/audit_numbers.json` 程序化写盘）

### 缺陷清单（合入版代码，逐条有复现）

| # | 缺陷 | 证据（实测） | 影响 |
|---|---|---|---|
| D1 | 壁面切向速度被写成 **u_wall = U∞**（自由流值），而非无滑移 0 | 代码行 `u_wall = full(nx, self.U_inf)`；ASBL 解析解 u(0)=0 与之矛盾 | 抽吸边界层无法存在 |
| D2 | `wall_y != 0`（顶壁）为**静默 no-op**：函数直接返回未改动的分布 | 原代码只有 `if self.wall_y == 0:` 分支，无 else/raise | 顶壁注/抽吸"注了等于没注" |
| D3 | 两条对角线**同时**用非平衡反弹闭合，丢掉流向动量方程 | 纯 Couette 对照（下壁 0、上壁 U=0.05、V=0、4000 步）实测 **u ≡ 0（全场逐点）** —— 施加的 U 完全没进入重构 | 切向壁速失效 |
| D4 | 自带 ASBL 驱动默认参数即发散 | 48², U=0.1, V=0.002, ν=0.02：`rho_min` 1.00 → 0.25（1000 步）→ 1100 步溢出 → 1600 步全 NaN；壁面行 u 反向至 −0.48 | 报告若引用=造假风险 |

### 修复尝试（D1/D2/D3 已改，D4 未达标）与残余缺陷

修复内容：加 `u_wall` 形参（默认 0 = 无滑移）、补顶壁分支（未知量 4/7/8）、
按 Zou–He 三条件闭合（ρ 由质量+法向动量、一对对角非平衡反弹、**另一对角由流向动量**给出）。

| 检查 | 解析/期望 | 修复后实测 | 结论 |
|---|---|---|---|
| 质量守恒（48² 1200 步） | ρ ≈ 1 | `rho_min` = 1.000000000000000（全程） | ✓ 不再发散 |
| 壁面无滑移生效 | u(0) = 0 | 壁面行 u = 0.0 | ✓ |
| **解析剖面是否为不动点** | 解析剖面 = 稳态 | 以解析剖面起步 1200 步：ρ、壁面 u 无漂移 | ✓（弱证据，仅说明不动点性质） |
| **Couette 对照（从静止起动）** | 线性 u = U y/H，斜率 U/(ny−1)=3.33e−3/格 | 内部斜率 **6.7e−3/格（2.0×）**；贴壁首行 u = **−1.84e−2 = −0.37 U** | ✗ 未达标 |
| τ_w 口径可校准性 | τ_w = ρU∞V | 因流场非物理，测得 −7.4e−4/−2.7e−4/−8.6e−5（δ=4/8/16）vs 解析 +2.5e−4/1.25e−4/6.3e−5 | **不可判**（WITHHELD，不给因子结论） |

**判定**：修复后"不再发散、切向壁速进入重构、解析剖面是不动点"，但**从静止起的
Couette 自检仍 2× 偏差 + 贴壁回流**，说明壁面闭合/半格位置口径仍有系统性错误 →
**WITHHELD，不得作为验证面引用**。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **本单没有把 ASBL 变成可用验证面**；产出是"缺陷取证 + 门禁 + 复现脚本/测试"。
   任何后续 ASBL 报告必须自己重跑并附原始 json，不能引用本模块的实现作为精度证据。
2. **"以解析解起步不动"不是精度证据**：不动点性质弱于收敛性与网格收敛；本单明确区分。
3. **Zou–He 闭合的三种写法极易写错**（对角用哪个、动量方程解哪个未知量、ρ 的 1±v 分母）。
   本单踩到的两处符号错误（流向动量两处）都以"Couette 对角行逐点 u=0 / 2× 斜率"暴露——
   说明**任何壁面 BC 必须配一条可控解析对照**，否则静默错精度。
4. **`wall_y != 0` 静默 no-op 是最危险的一类缺陷**（不报错、结果仍"看起来像流场"）。
   门禁化后这类路径会直接 raise。
5. `boundary/solver2d.compute_wall_shear_stress` 用的是 `−Σ c_ix c_iy f^neq /(2τ)`；
   文献常见口径是 `−Π^neq (1 − 1/(2τ))`。本单**未能**给出该因子的裁定（没有可用流场），
   下一步应以 ASBL 恒等式 τ_w = ρU∞V 作为校准实验再下结论。

## ⑥ 误差判定（逐项，禁止含糊）

| 关键量 | 基准 | 误差 | 是否 <3% |
|---|---|---|---|
| ASBL 剖面 u(y) | 解析解 | **无法测量**（无可用 LBM 稳态） | **否 / 不可判** |
| C_f | 2V/U∞ = 2 | **无法测量** | **否 / 不可判** |
| Couette 内部剪切斜率（自检） | U/(ny−1) = 3.33e−3/格 | **+100%（2.0×）** | 否 |
| Couette 贴壁行 u | 解析 ≈ 3.33e−3 | **−1.84e−2（差 −0.37U）** | 否 |
| 质量守恒 | ρ = 1 | ≤ 1e−15（1200 步） | 是（但不足以支撑精度结论） |

**结论：本能力当前无任何关键量达到 3% 判据；判定 WITHHELD（诚实 FAIL），
不得登记为已实现能力。** 明确不满足，非"未评估"。
