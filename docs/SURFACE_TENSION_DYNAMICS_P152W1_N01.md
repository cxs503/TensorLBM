## 0. 一句话结论

* **毛细波色散（主判据）**：参考工况（k=0.0982, W=2, kW=0.196）实测 `omega=0.00433` vs 解析 `0.00485`，相对误差 **-10.86%**（判据 <5%：**未通过**）；同一 k 下把界面宽度从 W=1.5 扫到 W=4.0，误差随 kW 单调恶化（W=1.0 因界面不足一格被判不可靠、登记剔除）；给出**可量化的软化律**与可用窗口。
* **零表面张力负控**：σ=0 时界面模态振幅最大偏离 0.00000000（初值 0.3337），`max|u|=0.00000000`，证明测到的振荡来自毛细力而非界面追踪器/声学伪迹：**通过**。
* **Marangoni 对流速度场**：`dσ/dx=2.0e-05` 工况的 u_x(y) 全剖面相对 L2 误差 **+1.00%**（判据 <10%：**通过**），界面速度线性外推误差 -1.65%。
* **液滴合并时间标度**：无量纲合并时间 `tau* = t(r_b=R/2)/sqrt(rho R^3/sigma)` = 1.030（c_R12_g2）, 0.849（c_R12_g2_s010），量级为 O(1)；但**自相似惯性区指数在本分辨率下不可分辨**，且求解器密度比为 1、本地无实验数据源，故该子判据如实判 **WITHHELD/FAIL**（理由见 §6）。

## 1. 案例介绍（物理背景 / 几何 / 参数）

### 1.1 为什么验“动力学”而不是“静力学”

TensorLBM 的自由面/毛细能力此前只做过**静态**锚点（Young–Laplace 压差、曲率精度、寄生流收敛，见 `docs/FREE_SURFACE_SURFACE_TENSION_CSF.md`）。静态只检验 Korteweg 应力与 `sigma` 输入的自洽；船海自由面（兴波、气泡/液滴、气层减阻、冰水界面）依赖的是同一系数的**动态响应**：界面对曲率扰动的响应频率、界面切向应力向流体内部的动量传递、以及拓扑事件（合并）的时间尺度。本节点把这三件事做成机器可裁决的判据。

### 1.2 三个锚点与解析/文献基准

| 锚点 | 数值格式 | 基准 | 判据 |
|---|---|---|---|
| (a) 毛细波色散/阻尼 | CSF（Brackbill）表面力 `f=σκη∇φ` + 半拉格朗日界面输运，LBGK+Guo 力 | `ω²=σk³tanh(kH)/(ρl+ρg)`、`γ=2νk²`（Kelvin 1871；Landau & Lifshitz §62） | ω 相对误差 <5% |
| (b) Marangoni 对流 | 界面切向力 `f=(I-nnᵀ)∇σ|∇φ|`，上下固壁通道 | 双层 Couette 精确解 `u_i=(dσ/dx)h₁h₂/((h₁+h₂)μ)` 及其分段线性剖面 | 全剖面相对 L2 误差 <10% |
| (c) 液滴合并 | 两个等径 2D 液滴（周期盒）合并，颈半径 r_b(t) | 量纲分析 `r_b~(σ/ρ)^{1/3}t^{2/3}`、`τ_ci=√(ρR³/σ)`；实验文献（Aarts 2005 / Eggers-Listers-Stone 1999） | τ* 对实验 <15% |

## 2. 怎么做的（方法 / 流程 / 工具链）

1. **测量链（新模块）**：
   * `capillary_wave.py`：驻波初值、`phi=0.5` 等值线界面追踪、`cos(kx)` 模态投影；频率由**三种独立估计**给出——极值间距（主）、过零点、周期图峰值；阻尼用阻尼正弦拟合/包络。有限深色散 `tanh(kH)` 因子显式进入解析基准（H=ny/2，界面到周期镜像的对称面）。
   * `marangoni.py`：稳态分段线性 Stokes 剖面 + 界面速度（抛物线插值与下层内部线性外推双读数），给出全剖面相对 L2、界面带内/带外分解误差、收敛漂移。
   * `coalescence.py`：两圆液滴并集初值（可设间隙）、对称面颈半径线性插值测量、幂律拟合、无量纲时间 `τ*=t(r_b=R/2)/τ_ci`。
2. **一次一变量**：kW 扫描（固定 k=0.0982，W=1.0/1.5/2.0/4.0）、k 扫描（固定 W=2，k=0.196）、振幅减半（线性性）、黏度减半（τ=0.51）、σ=0 负控；Marangoni 三档 dσ/dx + 非对称层高；合并两档 σ。
3. **收敛性纪律（本单踩到的真坑，见 §5）**：Marangoni 剖面的黏性充填时间 `h²/ν≈7.7e3` 步，6000 步的短跑会给 −14.8% 的假误差，24000 步收敛后为 −3.8%；因此判据只采用收敛工况。
4. **工具链**：`tools/surface_tension_dynamics_verification.py run --suite {wave,marangoni,coalescence} --shard i --shards n` 分片并行（每进程单线程，torch 线程已钉死），`aggregate` 汇总并计算判据；`tools/make_surface_tension_dynamics_report.py` 从 JSON 出图；`tools/make_surface_tension_dynamics_doc.py`（本脚本）把 JSON 数字注入本报告——报告中所有数字均来自 JSON，无手抄。
5. **复现**：

```bash
PYTHONPATH=src python3 tools/surface_tension_dynamics_verification.py run --suite wave --shard 0 --shards 6
PYTHONPATH=src python3 tools/surface_tension_dynamics_verification.py aggregate
python3 tools/make_surface_tension_dynamics_report.py
python3 tools/make_surface_tension_dynamics_doc.py
```

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **有限深修正不是可选项**：周期盒里界面到镜像的对称面距离 H=ny/2，浅盒（kH=1.57）用深水公式会把基准抬高 8%，实测偏差立刻从 −8% 变成 +12% 的“假通过/假失败”。本模块的解析基准已内置 `tanh(kH)`。
2. **强阻尼下不能用“整段阻尼正弦拟合”读频率**：初始冲击（位移界面、零速度）不是离散算子的本征态，前约 1/3 个周期存在形状松弛，单段拟合会被拖到错误频率（本单早期版本给出 −40% 的假值，被 bounds 夹死）。改用**极值间距**：`a=Ae^{-γt}cos(ωt+φ)` 的极值严格等距（π/ω），与阻尼无关；过零点与周期图作为独立交叉检验。
3. **极值检测必须先低通**：界面追踪器在格点尺度留抖动，直接用 argmax 会数出 5 步量级的伪极值（本单早期版本给出 ω=0.628，即半周期 = 采样间隔）。平滑窗取预测半周期的 15%，并把窗长与样本数写进 JSON（`smooth_steps`、`n_half_periods`）以便审计。
4. **Marangoni 必须跑到黏性充填时间**：`h²/ν≈7.7e3` 步。6000 步时内部斜率低 13%、剖面 L2=8.2%；24000 步后 L2=1.0%。短跑会给“模型错”的假诊断。
5. **界面切向应力对分辨率的敏感性**：Marangoni 界面速度的**点值**（抛物线插值）系统性偏低（-3.79%），而内部线性外推只偏低 -1.65%——弥散界面把 V 形顶点磨圆，点值不是物理量；报告同时给两个读数，判据用全剖面 L2。
6. **密度比为 1 是合并算例的结构性限制**：`CapillarySolver` 只有单一密度，两个“相”是同种流体，被加速的质量是液+环境两侧，因此 τ* 对应密度比 1，不能直接对标“空气中的液滴”实验。
7. **黏度趋势把亏损拆成两段（本单最有信息量的对照）**：同一 k/W 下把碰撞黏度从 `tau=0.60 (nu=0.0333)` 降到 `tau=0.51 (nu=0.0033)`，误差从 −10.9% 回到 −6.2%；再降到 `tau=0.505 (nu=0.0017)` 仍是 −6.2%（半周期离散度 2.8/3.6，是本组最干净的读数）——即 **约 4.7 个百分点随黏性耗散消失，但还剩约 6% 的“地板”与黏度无关**。结合静态 Laplace 与 Marangoni 两条独立锚点都在 1–3% 内（力归一化是对的），地板的候选根因是半拉格朗日界面输运的数值抹宽与弥散界面把力铺在 ~W 格上；这条地板就是 5% 判据在本格式上过不去的直接原因。
8. **界面锐度监控自身踩到周期回绕陷阱（本单第二处，已修 + 加回归测试）**：盒在 y 方向周期，液带在 y=0/-1 处从 φ=1 跳到 0，**朴素的中心差分 |∇φ| 在接缝处恒为 0.5**——于是监控器对 W=1/1.5/2/4 一律报 0.5，把“界面被抹宽”这件事彻底藏起来（与前一份 CAC 报告 §5.1 的界面能量积分陷阱同源）。修正后 `interface_sharpness` 剔除首末行，读数回到 `0.5·tanh(2/W)`（W=2 → 0.383、W=4 → 0.231），并由 `test_interface_sharpness_ignores_the_periodic_seam` 钉住。工件里已记录的锐度历史是用旧读数采的，仅作审计留存，不能当作界面宽度结论。
9. **算力**：本机 load 170–490（128 核被其他智能体占满），所有工况单线程、盒子 ≤8k 格点；单工况 60–600 s。集群队列排队 250+，未占用。

## 6. 误差判定（逐项，显式回答“是否 <3% / <5% / <10% / <15%”）
