# TensorLBM 多相流前沿验证面：VIV 锁定共振 · 空化动力学 · 非牛顿流变

> TensorLBM · 战役 p40w2-n02 · 全部数字由 `artifacts/p40w2_n02/*.json` 程序化注入（零手抄）。模块 `src/tensorlbm/multiphase_frontier/`，驱动 `scripts/run_p40w2_n02_frontier.py`，测试 `tests/test_multiphase_frontier.py`（31 项全绿，22 s）。

## ① 案例介绍（物理背景 / 几何 / 参数表）

三条互不相同的多相/非牛顿验证腿，每条都配独立参考（解析式、精确不变量或已发表基准），避免「自证其说」：

- **(a) VIV 锁定共振**：弹性支承圆柱横向单自由度振动。绕流动的最经典难点是动边界——本仓旧模块 `fsi_viv_ibm` 的固定圆柱阻力被 IBM 内部拉格朗日点抬高到 Cd=32.3（基准 1.34），判为 WITHHELD。本次改用**加速参考系变换**：圆柱在网格上固定，相对运动进入流体（远场速度 `(U, -V_y)`、全场伪加速度 `-dV/dt`），应力对参考系平移不变，因此动量交换力仍是有物理意义的载荷。
- **(b) 空化动力学**：Rayleigh-Plesset 单泡动力学核 + Schnerr-Sauer 相变源项的一致性。对照组为 Rayleigh(1917) 溃灭时间 `0.9147 R0 sqrt(rho/dp)`、Minnaert 固有频率 `(1/2πR0)sqrt(3κp0/rho)`，以及 `dα/dt = 3α(1-α)Ṙ/R` 这条几何恒等式。
- **(c) 非牛顿流变**：幂律 / Carreau-Yasuda / Cross 三种本构的 Poiseuille 流动，两个**互相独立**的数值解（平面通道 FV、轴对称管流 FV）对同一个求积参考解。

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**工具链**：纯 numpy/CPU，单算例单进程；扫描用 `multiprocessing` 撒 7-8 个进程；无外部求解器依赖。

**(a) VIV 求解器**（`multiphase_frontier/viv.py`）：D2Q9 双松弛时间（TRT，`s+ = 1/tau`、`s- = 1/(1/2 + (3/16)/(tau-1/2))`，魔法参数 Λ=3/16 使半程反弹的壁面位置与 tau 无关）；Guo 力项承载伪加速度；圆柱用阶梯半程反弹 + Ladd 动量交换求力；上游/上下远场平衡态速度入口、下游零梯度出流；结构为 1-DOF 弹簧-质量-阻尼，速度 Verlet 步进（流体载荷滞后一步，m*=10 时稳定）。增益/阻尼由 `U_r = U/(f_n D)`、`m*`、`ζ` 反解 `k`、`c`。起始给 0.02D 初始位移打破完全对称的死点。

**(b) 空化动力学**（`cavitation_dynamics.py`）：`R R'' + 3/2 Ṙ² = (p_b - p_inf)/rho`，`p_b = p_v + p_g0 (R0/R)^{3κ} - 2σ/R - 4μṘ/R`，RK4 定步长积分；溃灭时间以`R = R0/100` 为事件；相变源项用 Schnerr-Sauer 形式并与同一 RP 解的 `dα/dt` 对照。

**(c) 非牛顿**（`rheology.py` + `poiseuille.py`）：本构取 `mu(gamma_dot)`；参考解用**精确动量平衡**得到的剪应力分布（平面 `tau = G s`、管流 `tau = G r/2`），先对 `mu(γ)γ = τ` 做对数区间二分反解剪率，再对剪率求积得速度剖面。数值解：①平面通道 1-D 守恒有限体积（面心剪率 Picard 迭代）；②轴对称管流 1-D 守恒有限体积（径向权 `r`）。两者共享本构但不共享离散，也都与求积参考解无关。**LBM 通道路径**另立一条诚实记录（见 ⑤）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **加速参考系是这次 VIV 能过关的关键**：几何固定 ⇒ 无阶梯抖动、无力尖峰。代价是显式耦合要求 `m* > 1` 且伪加速度需按 Guo 力项精确进入流体方程；`m* ≲ 1` 的强附加质量区需要子迭代耦合，本节点未做。
2. **LBM 广义牛顿通道 = 诚实 FAIL**（记录在 `rheology.json` 的 `lbm_channel` 键）：BGK + Guo 力 + 半程反弹的通道在**牛顿极限**下 1000 步内误差 0.85%，随后单调漂移（24000 步 17.1%），把黏度按步反馈给局部松弛时间后直接发散。三个部件各自都是教科书级的，因此这是本模块实现层面的缺陷，**未在本节点解决**；同一 LBM 代码库的TRT 圆柱路径（④ 的 VIV 结果）不受影响。故非牛顿结论只由两套 FV 解 + 求积参考给出，LBM 只在 (a) 腿贡献已验证能力。
3. **空化只验证了单泡动力学核**，没有重做 P41-N02 已交付的 NACA0015 片状空穴长度与 Clark-Y 云状脱落频率（禁止重复已验证案例）；本节点的价值是给那个求解器的源项提供解析锚点，并量化了源项闭合与完整 RP 动力学之间约 100% 的偏差——使用该源项做云空化频率预测时必须记住这一系统性偏差。
4. **VIV 只覆盖 Re=100 层流**。任务书要求的 Re≤1e4 与 Trim 2005 / Chaplin 2005 高 Re 立管实验**未做**：二维 LBM 在 Re=1e4 需要三维 LES + 上千倍直径的展向长度，本节点的算力与二维模型均不适用；判为 WITHHELD 而非降级替代。Re=200 也无法在 D=16、U=0.1 下稳定（tau=0.524 触发格式失稳，已实测发散），需要 D≥32。
5. **阶梯圆柱的离散面积**比理想圆小 0.1%-2%（见 `area_error`），等效直径偏小约 1%，是 Cd/St 残差的来源之一；管流/通道 FV 的面心黏度必须用**同一个面**的剪率（早期版本把上表面的 mu 用在下表面，导致幂律管流最大速度偏低 37%——已修复，修复后 1e-6 级吻合）。
6. **适用范围**：本模块给出的是验证基线（固定圆柱载荷、锁定区间、解析锚点），不是工程预报器；高 Re、湍流、三维、多圆柱干涉、细长柔性立管均在其外。

**显式结论**：凡有严格基准的量（Cd、St、Rayleigh 时间、Minnaert 频率、Schnerr-Sauer 几何恒等式、非牛顿剖面）中，除 **St（D=12/16）** 与**Schnerr-Sauer 源项闭合**外全部 <3%；St 的粗网格残差与 FFT/峰值估计精度、阶梯面积偏小同量级，D=20 时降到 3.1%，D=16 窄域算例（堵塞比 6.25%）为 1.2%——**分辨率/域宽是主要原因，已量化**。VIV 振幅只与二维文献区间（[0.5, 0.6]）比较，属区间对照而非精确值对照，置信度低于固定圆柱项。

**未完成项（honest FAIL，不覆盖）**：(1) Re≤1e4 高 Re VIV 与 Trim/Chaplin 实验对照；(2) 广义牛顿 LBM 通道路径；(3) NACA0015/Clark-Y 空化算例（P41-N02 已交付，按纪律不重复）。
