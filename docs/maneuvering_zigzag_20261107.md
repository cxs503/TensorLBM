# 操纵性闭环验证：zig-zag（超调角）+ IMO MSC.137(76) 判据（2026-11-07）

## 0. 结论（一句话）

`tensorlbm.maneuvering` 此前只有**开环**固定舵角的稳态回转（`simulate_turn`，已被
`benchmarks/verified/maneuvering_steady_turn` 验证到 0.01%），**没有任何闭环操舵能力**，
也没有超调角（overshoot）指标——全仓 grep `zigzag|overshoot` 零命中。
本任务补上闭环 helm 逻辑与超调角，并用**两条独立路线**（事件驱动数值积分 vs 精确分段模态解）
互相裁决：**6 个量 × 2 个试验的最大相对差 1.2e-12**，时间步收敛阶 Euler **p=0.998**、
RK4 **p=4.02**，IMO 判据对"舵向保持变差的船"能判 FAIL。

## 1. 案例介绍（物理背景 / 几何 / 参数表）

回转试验（turning circle）只验证"稳到哪"，zig-zag（跌路/超调）试验验证"操舵后什么时候停得住"，
是 IMO 操纵性衡准的核心指标之一：舵角 δ 下达后，当首向偏差达到 ψ_zz 时反向操舵，首向会继续
越过 ψ_zz，越过量即**超调角**。10°/10°、20°/20° 两档是 MSC.137(76) 的强制衡准。

线性横荡–首摇（sway–yaw）模型（Abkowitz 1964 / Nomoto 1957 / Fossen 2011 ch.7）：

```
M q̇ = A q + b(δ) + f_nl(v),   q = [v, r]^T,   ψ̇ = r,   R = U/r,   K = r/δ
```

船：KVLCC2 级大型油轮实尺度（与 `maneuvering_steady_turn` 同一套参数，便于对表）。

| 参数 | 值 | 参数 | 值 |
|---|---|---|---|
| L_pp | 320.0 m | Cb | 0.81 |
| B | 58.0 m | ρ | 1000 kg/m³ |
| T | 20.8 m | U | 7.97 m/s (≈15.5 kn) |
| Δ = ρ·Cb·L·B·T | 3.116e8 kg | I_z = Δ(0.25L)² | 1.993e12 kg·m² |
| L/V | 40.2 s | 导数集 | `NOMINAL_TANKER_PRIME`（代表性线性集，非 PMM 反演） |

L/V = 40.2 s ≥ 10 s ⇒ 10/10 判据走 20° 分支（非 10° 分支），这条在代码里是显式的。

## 2. 怎么做的（方法 / 流程 / 关键设置）

新增（`src/tensorlbm/maneuvering.py`，`__all__` 已导出）：

* `simulate_zigzag(model, delta_deg, heading_deg=None, dt, integrator="rk4"|"semi_implicit_euler")`
  —— 事件驱动积分：**换舵时刻**（ψ 达到 ±ψ_zz）与**首向极值时刻**（r 变号）都在**步内**用二分
  定位（分数二分到 1e-13），因此换舵时间误差是积分器截断误差量级，而不是 dt 量化误差；
  ψ 作为第 3 个 RK4 状态用完整四段求积（Euler 路径用 `ψ += r_new·dt`，与 `simulate_turn` 一致）。
* `analytic_zigzag(model, ...)` —— 精确分段模态解：每段舵角恒定 ⇒ LTI，`q(t)`、`ψ(t)` 是双指数
  闭式，换舵/极值时刻是闭式的根（扫描 + 二分到 1e-14 s）。模型带 cross-flow 项时**直接
  `ValueError` 拒绝**，不静默丢项。
* `ZigZagResult`（超调角、换舵/极值时刻、事件表、历程）、`imo_msc137_zigzag_limits`、
  `check_imo_msc137_zigzag`。

判据（先于动手定）：两路线相对差 <1e-4；Euler 观测阶 ∈[0.8,1.3]；RK4 观测阶 ≳3.5 且最细 dt 相对
误差 <1e-5；线性尺度不变性 <1e-9；IMO 判据对名义船 PASS、对降级船 FAIL。

工具链：`benchmarks/verified/maneuvering_zigzag/run.py`（程序化写 `result.json` + 3 张图），
`tests/test_maneuvering_zigzag.py`（13 条 fast 测试，35 s）。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **ψ 求积阶数会悄悄把 RK4 降成 3 阶**（本任务实踩）：最初用 Simpson，中点首摇率取自
   `q + dt/2·k1` 的**预测态**（O(dt²)），且末段错用积分后的平均态 `q_new[1]` 而非 `k3` 段值
   → 观测阶稳定在 3.02，而 `q` 本身是 4 阶（r 误差比值 16）。把 ψ 当第 3 个 RK4 状态、四段
   求积全部取**段值**后，ψ 误差比值回到 16（4 阶），整案观测阶 4.02。诊断手法：单独
   `_step_sway_yaw` 定舵角积分到已知 T，与 `_segment_solution` 闭式比，看误差比值是否 =2^p。
2. **换舵/极值必须在步内定位**：若按"先整步走完再看是否越过"，换舵时间带 O(dt) 量化误差，
   超调角对 dt 的收敛会退化成 1 阶，且两条路线无法互相裁决到 1e-12。
3. **线性模型 10/10 与 20/20 尺度不变**（§3.3）。因此这两档**不是**两个独立证据，而是同一
   解的等比放大；真正提供第二个独立证据的是 cross-flow 案例与 Euler/RK4 两种离散。
4. **绝对精度未验（WITHELD）**：导数集是代表性线性集，非 PMM/CFD 反演；无舵速限制、无桨舵
   尾流、无横倾/横摇耦合、无自由面。本任务的证据等级是**内部验证**（两条独立路线一致 + 收敛
   阶正确 + 判据有鉴别力），不是对某条实船的绝对精度声明。文献上 KVLCC2 的 20/20 首超调约
   10–15°，本线性集给 4.2°，差距主要来自导数集与缺少非线性。
5. **IMO 判据的适用范围**：MSC.137(76) 只规定 10/10 与 20/20；其它组合（如 20/10）返回
   `applicable: False` 而不是编一个阈值。10/10 的限值依赖 L/V（<10 s → 10°，≥10 s → 20°），
   未给 L/V 时直接拒绝出结论。
6. **降级船族不是真船**：`N′_r×0.5` 已给出 R/L=0.2（小于一个船长）且 `×0.4` 起方向不稳定，
   只用于证明判据有鉴别力，不可当作"某船不合格"的证据。

## 6. 误差判定（逐项回答是否 <3%）

| 关键量 | 基准 | 误差 | <3% ? |
|---|---|---|---|
| 第一/第二超调角（10/10、20/20） | `analytic_zigzag` 闭式解 | 1.5e-12 / 1.1e-12 相对 | **是** |
| 换舵时刻 / 首向极值时刻（4 个） | 同上 | ≤1.1e-10 相对 | **是** |
| 线性尺度不变性 20/20 = 2×10/10 | 解析恒等式 | 0.0 | **是** |
| 左/右舵镜像 | 对称性 | 0.0 | **是** |
| Euler 观测阶 | 理论 1 | 0.998（−0.2%） | **是** |
| RK4 观测阶 | 理论 4 | 4.02（+0.5%） | **是** |
| 绝对超调角 vs 实船 | 无可用基准（导数集非实船反演） | — | **无法判定，如实声明 WITHELD** |
