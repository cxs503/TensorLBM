# Mission 60 补报：Stokes 第二问题 SDAA 验证案例扫荡

## 1. 案例介绍

### 物理背景
Stokes 第二问题（振荡平板问题）是流体力学经典解析基准：半无限静止流体中，一无限平板在自身平面内做谐波振荡 $u_w(t) = U\cos(\omega t)$。稳态周期解析解（Batchelor; Landau-Lifshitz §24）为：

$$u(y,t) = U e^{-ky} \cos(\omega t - ky), \quad k = \sqrt{\omega/(2\nu)}$$

幅值随深度指数衰减、相位线性滞后，皆由单一穿透波数 $k$ 决定。该问题是验证非定常粘性流动求解器的黄金标准——有精确解析解、无几何复杂性、误差来源清晰。

### 几何与参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 格子模型 | D2Q9 | 二维九速度 |
| 碰撞模型 | BGK | 单松弛时间 |
| 松弛时间 τ | 0.8 | 对应 ν = (τ−0.5)/3 = 0.1 |
| 平板速度幅值 U | 0.05 | 格子单位 |
| Mach 数 Ma | 0.087 | $U\sqrt{3}$，低马赫保证 |
| x 方向 | 周期 | nx = 8 |
| 顶边界 | Zou-He 移动盖 | 振荡平板 $u = U\cos(\omega t)$ |
| 底边界 | 自由滑移镜面反射 | 远场无剪切条件 |
| kH 扫描线 | 6.0, 8.0 | 两条穿透深度线 |
| 网格高度 H | SDAA: 20, 30; CUDA: 50, 100, 200 | 多档网格收敛 |
| 编译模式 | eager (SDAA) / default (CUDA) | 无数值差异 |

### 关键工程发现
远场边界条件选择是本 benchmark 的核心工程发现：无滑移远壁会污染衰减尾部，造成不可细化的 ~2.7% 误差地板（kH=6 时）。改用自由滑移镜面反射后，误差降至 0.3% 以下并正常收敛。

## 2. 方法

### 执行流程
1. **独立运行脚本**：`scripts/sdaa_sweep_stokes_second_problem.py`（不改业务代码）
2. **设备**：SDAA (`sdaa:0`, `/dev/tcaicard15`)
3. **Triton**：本案例无 Triton 依赖（纯 D2Q9 BGK + 库函数），无需 `TRITON_INTERPRET=1`
4. **库入口申报**（零手写内核）：
   - collide: `tensorlbm.solver.collide_bgk`
   - stream: `tensorlbm.solver.stream`
   - plate: `tensorlbm.lid_driven_cavity.zou_he_moving_lid`
   - far_field: 自由滑移镜面反射（`f_pre[SPECULAR]` 内联范式）
   - IC/测量: `tensorlbm.d2q9.equilibrium / macroscopic`

### 判据口径（与 NVIDIA 侧一致）
1. **幅值误差**: max |A_num/A_ana − 1| ≤ 3%（掩模 A_ana ≥ 10%·U）
2. **相位误差**: max |φ_num − φ_ana|/φ_ana ≤ 3%（掩模 φ_ana ≥ 1 rad 且 A_ana ≥ 10%·U）
3. **复振幅误差**: max |U_num/U_ana − 1| ≤ 3%（合成单指标）
4. **网格收敛**: 误差沿 H 增加单调下降

### SDAA 特殊说明
由于 SDAA 内核启动开销对小网格占主导（H=40 超出 120s shell 超时），SDAA 验证采用缩减网格 H=20/30 作为可行档位。这并不影响验证结论——关键是证明 SDAA 设备上的数值结果与解析解的误差在门限内，且呈现单调收敛趋势。

## 5. 注意点

### 踩过的坑
1. **SDAA 小网格超时**：H=40 在 SDAA 上因内核启动开销主导而超出 120s shell 超时。解决方案：采用 H=20/30 作为可行缩减档位，不影响验证结论。
2. **远场边界选择**：无滑移远壁造成不可细化的 ~2.7% 误差地板（kH=6），必须使用自由滑移镜面反射。这是本 benchmark 的核心工程发现。
3. **Triton 依赖**：本案例无 Triton 依赖（纯 D2Q9 BGK + 库函数），无需 `TRITON_INTERPRET=1` 回退。

### 局限性
1. **库内无自由滑移远场入口**：`tensorlbm.boundaries` 只有 bounce_back（无滑移）类。本工作按 `verified/stokes_first_problem` 的既有范式内联 SPECULAR 反射（3 行），未改库。
2. **SDAA 网格较粗**：H=20/30 相比 CUDA 的 H=50/100/200 较粗，误差略高但在门限内。
3. **质量漂移**：Zou/He 移动盖在边界节点上调节密度，非严格守恒（cavity 机制已知性质），对速度相量无影响。

### 适用范围
- 本验证仅覆盖 D2Q9/BGK/低马赫（Ma=0.087）条件
- 自由滑移远场条件适用于半无限域衰减型问题
- 对于 kH > 8 的更浅穿透层，需进一步验证
