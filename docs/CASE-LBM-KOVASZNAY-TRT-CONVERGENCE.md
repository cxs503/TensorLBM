## 0. 本单补的是什么欠账

算例池条目（m17704）、独立审计（m16861）、出口口径阶梯（m16974）三单已把该锚点的现状钉死：

- 判据在 ny=128 上 **PASS（2.5613 % < 3 %）**，但 **99.6 %–99.9 % 的全场 v 误差来自出口零梯度边界层**，
  不是离散精度；换任何出口闭合（nscbc / NEE / 解析 Dirichlet）都不会更好。
- **内部（剔除出口一个 y 周期）误差与网格无关**：u 0.1102 → 0.1023 → 0.1017 %（ny=32/64/128）。
  即该算例在出厂工况下 **给不出收敛阶**；成因经 Mach 阶梯定量定位为 **O(Ma²) 可压缩性底噪**。
- 当时留下的明确后续（`cases/kovasznay_2d/README.md` 裁决第 5 条）：**「换碰撞模型（TRT / regularized）」**，
  因为固定 Re 降 Ma 就要降 τ₊，而 **BGK + Zou-He 入口 + 任意出口在 τ ≲ 0.57 发散（实测 NaN）**。本单做的就是这一步。

**结论先说（详见 §3/§6）**：

1. **TRT（Λ=3/16）把稳定性墙从 τ₊=0.572 推到 0.5045**：同一算例 BGK 在 τ₊ = 0.536 / 0.518 / 0.509 / 0.5045
   四级全部在 500–1000 步内 NaN，TRT 四级全部跑满 3000 步有限。
2. 用 TRT 把 Ma 从 0.104 降到 0.026 后，**v 分量的内部误差第一次随网格收敛**：
   0.00755 → 0.00157 → 0.00043（/U0），观测阶 **p = 2.26 → 1.87**（渐近 ~2，与 D2Q9 理论二阶一致）。
3. **u 分量收敛到 p=1.67 后在 ny=128 触底**（0.00801 %），触底值与该算例自己 Mach 阶梯外推的
   可压缩性地板 **0.00785 %** 相差 **2.0 %** —— 即 u 的"不收敛"不是实现问题，而是 **Ma² 项在 0.008 % 量级重新接管**。
   要把它也推下去需要再降 4× Ma（TRT 已在 τ₊=0.5045 上验证可行），本单不做（见 §5）。
4. 因此本单给锚点补上了它最缺的那件东西：**一条内部误差的二阶收敛序列**（v 分量），而不再只是"擦线 PASS"。

## ① 案例介绍（物理背景 / 几何 / 参数表）

Kovasznay (1948) 二维定常不可压 N-S 精确解（格栅后层流尾迹，y 向 1 周期，x′ 向指数衰减）：

    u = U0(1 − e^{λx′}cos 2πy′),  v = U0(λ/2π)e^{λx′}sin 2πy′,
    p = ½U0²(1 − e^{2λx′}),        λ = Re/2 − √(Re²/4 + 4π²) = −0.9637405,  Re = 40

| 参数 | 本单取值 | 说明 |
|---|---|---|
| 格子 / 碰撞 | D2Q9 / **TRT**（库函数 `solver.collide_trt`，magic Λ = 3/16） | τ₋ = ½ + Λ/(τ₊−½) |
| Re / U0 | 40.0 / **0.0075**（对照臂 0.03） | Ma_max = 0.026，Ma² = 6.8e-4 |
| ν（格子） | U0·ny/Re → ny=32/64/128 时 0.006/0.012/0.024 | τ₊ = 0.518 / 0.536 / 0.572 |
| 域 | nx = 3·ny（x′∈[0,3]），y 向周期 | ny = 32 / 64 / 128 |
| 入口 x=0 | 库函数 `boundaries.zou_he_inlet_velocity`（逐行解析 u、v） | 与算例一致 |
| 出口 x=nx−1 | **解析 Dirichlet**（把精确解的平衡态写进最后一列） | 只为去掉边界层使截断误差可见，**不是**推荐工程 BC |
| 稳态 | 场漂移 ‖u‖ 相对变化 < 1e-9（每 500 步查） | 实跑 15500 / 27500 / 20000 步 |

**参考解证书（本次一并复算，`analytic.py` 解析导数）**：动量残差 **2.33e-15 / 3.05e-16**、
连续性散度 **0.0**、λ 相容性残差 **8.5e-14**、ν 由相容关系反解 0.025000000000000057（=1/Re）。
⇒ 参考解是精确解，测到的误差全部归数值。

## ② 怎么做的（方法 / 流程 / 关键设置）

- **只换碰撞模型，别的一律不动**：步序 `collide(TRT|BGK) → stream → 出口 → Zou-He 入口`，全部库函数；
  同一 τ₊ 下 ν 相同，因此 TRT 与 BGK 解的是同一个物理问题（等价性检查见 §3.4）。
- **内部窗口对齐物理域**：剔除入口列 + 出口一个 y 周期（ny 列）⇒ 窗口恒为 x′∈[1/ny, 2]，
  三个网格比较的是**同一块物理区域**，这是网格收敛比较成立的前提。
- **三条实验臂**（每次只动一个变量）：
  - 稳定性臂：ny=32 固定，U0 ∈ {0.03, 0.015, 0.0075, 0.00375, 0.001875}（τ₊ 0.572→0.5045），BGK vs TRT 各 3000 步；
  - 网格臂：U0=0.0075 固定，ny ∈ {32, 64, 128}，跑到稳态，取内部 L2 误差拟合 p；
  - 步数对照臂：ny=64 分别在 20000 步（未判稳）与 27500 步（判稳，漂移 6.2e-10）各跑一次，验证误差与步数无关。
- 复现（本机 4–6 线程，实测耗时标注）：

```bash
python cases/kovasznay_2d/trt_convergence.py check                                   # ~9 s
python cases/kovasznay_2d/trt_convergence.py stability --ny 32 --threads 4 \
    --out artifacts/m18406/stability.json                                            # ~90 s
python cases/kovasznay_2d/trt_convergence.py ladder --grids 32 --threads 4 \
    --out artifacts/m18406/ladder32.json                                             # ~120 s
python cases/kovasznay_2d/trt_convergence.py ladder --grids 64 --threads 4 \
    --max-steps 40000 --out artifacts/m18406/ladder64_40k.json                       # ~330 s
python cases/kovasznay_2d/trt_convergence.py ladder --grids 128 --threads 6 \
    --out artifacts/m18406/ladder128.json                                            # ~640 s
python cases/kovasznay_2d/trt_convergence.py field --ny 64 --threads 4 \
    --out artifacts/m18406/field_ny64.json                                           # ~270 s
python cases/kovasznay_2d/trt_convergence_report.py                                  # 出表 + 出图
```

## ⑤ 注意点（踩坑 / 局限 / 适用范围）

1. **τ₋ 不是自由参数**：Λ=3/16 时 τ₋ = ½ + Λ/(τ₊−½)；τ₊→½ 时 τ₋ 爆炸（本单 τ₊=0.5045 对应 τ₋=42.2）。
   仍稳定是 TRT 的性质，但**不能再往 τ₊→0.5 硬推**，否则 τ₋ 溢出会变成数值问题（未做该极限测试）。
2. **解析 Dirichlet 出口只用于归因/去污染**：它吃掉了出口边界层，让截断误差可见；它**不是**可用边界条件，
   算例的生产口径仍是零梯度出口（m16974 已证明其余闭合更差）。
3. **u 分量的触底是真结论不是拟合失败**：ny=128 的内部 u/U0=0.00801 %，与算例自己 Mach 阶梯外推的
   地板上界 0.1017 %/(3.51×3.74)=0.00785 % 相差 2.0 %。要拉开它需要 U0≈0.0019（Ma=0.0065，τ₊=0.5045，TRT 已验证有限），
   本单按"单干范围/算力预算"未做，列为后续。
4. **等价性检查做在未判稳态**（§3.4 末条），严格的收敛态等价需要同 τ₊ 跑到底，本单未做 —— 如实标注。
5. **步数 vs 网格不是同一维度**：网格臂各网格的停步点不同（判稳判据），已用 ny=64 的 20000/27500 双跑证明 <1 % 无影响（§3.3）。
6. **相对误差与绝对误差别混看**：本单主表给 /U0 归一的绝对 L2（收敛性该看的量），全场相对 L2 另列；
   两者在全场口径差 1 个量级（出口层在相对量里被 ‖u‖₂ 稀释）。
7. 未改算例代码、未改判据、未覆盖任何既有 `result.json`；新增文件只有本分支的脚本/测试/文档/工件。

## ⑥ 误差判定（逐项 vs 基准，显式回答「是否 <3%」）

| 关键量 | 基准 | 本单结果 | 是否 <3% |
|---|---|---|---|
| 锚点判据：全场速度 L2 相对误差（ny=128、Re=40、U0=0.03、零梯度出口） | Kovasznay 解析解 | 2.5613 %（m17704，本单未改动） | **是**（余量 0.44 pp） |
| 本单 TRT 臂全场 v L2（ny=128、U0=0.0075、解析 Dirichlet 出口） | 同上 | 0.1217 % | 是 |
| 本单内部 v L2 相对误差（ny=128） | 同上 | 0.0079 % | 是 |
| 内部 v/U0 观测阶（32→64 / 64→128） | 理论二阶 | 2.26 / 1.87 | 不适用（阶数，非误差）：与 2 的偏差 −13 % / +7 % |
| 内部 u/U0 观测阶（32→64 / 64→128） | 理论二阶 | 1.67 / 0.81 | **否**（如实报：u 在 ny=128 触 Ma² 地板） |
| u 地板值 vs 独立外推的 Ma² 地板 | 0.00785 %（算例自身 Mach 阶梯） | 0.00801 % | 是（差 2.0 %） |
| 参考解证书（动量/连续性/λ） | 精确解 | 2.3e-15 / 0.0 / 8.5e-14 | 是（机器精度） |
| TRT 守恒性（质量/动量） | 严格守恒 | 3.0e-16 / 3.5e-17 | 是 |

**诚实声明**：本单**没有**把 u 分量也做成二阶收敛序列（它在最细网格触 Ma² 地板，已定量归因）；
**没有**做收敛态下的 TRT/BGK 等价性证明；**没有**测 τ₊→0.5 的极限。以上均如实列为后续，不用"整体二阶"一句话覆盖。
