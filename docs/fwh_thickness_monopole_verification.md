# FWH thickness (monopole) term: implementation and analytic verification

Status: **ANALYTIC_VERIFIED** for the FWH far field (contract entry `fwh_far_field`/`N/A`); acoustic *physics* validation (experiment, coupled flow solver) remains **WITHHELD**.  All numbers below are injected by `tools/verify_fwh_thickness_monopole.py` from `artifacts/fwh_thickness/verification.json`; figures are generated by the same run.

## 1. Case: why a monopole reference

Before this change `compute_fwh_far_field` implemented only the Farassat-1A **loading** (dipole) term.  A breathing / pulsating / volume-displacing surface has a uniform surface pressure on a closed surface, so the loading term integrates to exactly zero and the solver returned **silence** for a source that physically radiates as a monopole.  The **thickness** term was missing outright.

The verification case is therefore a sphere of radius `a` whose surface moves radially with `u_n(t) = U cos(wt)` (pure thickness source).  It has two independent closed-form references:

- compact monopole (Farassat 1A, `M = 0`): `p'(r,t) = -(rho0 a^2 U w / r) sin(w (t - r/c0))`;
- exact exterior solution with the radius velocity prescribed at `r = a`: `p = Re[A e^{i(kr-wt)}/r]`, `|A| = w rho0 a^2 U / sqrt(1 + (ka)^2)`,

| parameter | value |
|---|---|
| sphere radius a | 0.05 m |
| surface velocity amplitude U | 0.1 m/s |
| ambient density rho0 | 1.225 kg/m3 |
| speed of sound c0 | 343.0 m/s |
| observer distance r | 5.0 m |
| surface quadrature | Fibonacci sphere, N = 128 / 512 / 2048, areas exactly 4 pi a^2 / N |
| time discretisation | 256 samples per period, central differences in observer time |

## 2. Method

Implemented in `src/tensorlbm/acoustics.py`:

```
p'_T(x,t) = rho0/(4 pi) d/dt [ sum_n v_n(tau_n) A_n / r_n ],   tau_n = t - r_n/c0
```

- `FWHSurface` gains `normal_velocity` (shape `(N, T)`, outward positive) and `rho0` (default 1.225 kg/m3).  `normal_velocity=None` keeps the historical loading-only behaviour bit-for-bit (`test_regression_loading_only_path_unchanged`).
- The retarded integrand is assembled first and differentiated in observer time afterwards: the derivative acts on the surface integral, which is the exact stationary-surface (`M = 0`) Farassat-1A form.  The second thickness term of Farassat 1A is proportional to the surface Mach number and vanishes for a stationary surface.
- Retarded times use the module's existing nearest-sample convention, so the thickness term is consistent with the loading term.
- Tool chain: `tools/verify_fwh_thickness_monopole.py` (tournament: ka sweep x mesh x observer direction x distance, plus controls) -> `artifacts/fwh_thickness/verification.json` + 4 PNG -> this document.  Tests: `tests/test_fwh_thickness_monopole.py` (10 tests).

## 4. Error judgement (item by item vs benchmark)

| quantity | reference | error | < 3%? |
|---|---|---|---|
| amplitude, ka = 0.050 | exact sphere | 0.07 % | **yes** |
| amplitude, ka = 0.183 | exact sphere | 1.08 % | **yes** |
| waveform relRMS, ka = 0.183 | exact sphere | 1.09 % | **yes** |
| waveform relRMS, ka = 0.183 | compact monopole | 0.57 % | **yes** |
| amplitude, ka = 0.366 | exact sphere | 4.12 % | **no** (outside compact regime) |
| amplitude, ka = 0.916 | exact sphere | 17.41 % | **no** (outside compact regime) |
| directivity spread | isotropy | 0.041 % | **yes** |
| p*r drift, r = 5 -> 20 m | 1/r law | 0.002 % | **yes** |

The residual against the exact sphere solution follows `(ka)^2/2` (predicted ratio `sqrt(1+(ka)^2)`; measured 1.0108 vs predicted 1.0166 at ka = 0.183).  Crossing the 3% line therefore happens at `ka ~ 0.24`: this is an intrinsic property of a compact-source far-field analogy, not an implementation error.

## 5. Caveats / applicability

1. **Applicability window.**  `ka <~ 0.24` for 3% accuracy against the exact sphere; ≈1% at ka = 0.183.  For f = 1 kHz and a = 0.05 m (ka = 0.92) the error is 24.7% - do not use this term above the compact range.
2. **Zero-net-flux residual.**  A translating rigid sphere (`v_n = U cos theta`, net flux zero) still radiates 579.40% of the pulsating level in this compact formulation.  That is the known `O(ka)` compact-source artifact, not a bug, but it means the thickness term cannot be used to argue that a translating body is silent.
3. **Only the `M = 0` branch.**  Moving/deforming control surfaces need the full Farassat-1A Doppler factors `(1-M_r)^{-2}`, `(1-M_r)^{-3}`; those are not implemented and remain withheld.
4. **No quadrupole/volume term, no flow convection.**  Same limitation as the loading term; the module never claimed to carry the Lighthill tensor.
5. **Not physics validation.**  The comparison is against closed-form solutions of the same acoustic analogy.  No experiment, no coupled LBM source, no absolute-SPL claim.  The capability contract status stays `WITHHELD_NO_PHYSICS_VALIDATION`.
6. **Geometry trap.**  `tensorlbm` in this environment resolves through an editable install pointing at a *different* worktree; every command above ran with `PYTHONPATH=src` so the numbers describe this tree.
