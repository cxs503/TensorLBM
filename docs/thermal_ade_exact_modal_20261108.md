# D2Q5 热 advection-diffusion 解析验证：离散模态闭式 + 对流偏差律

TensorLBM · 验证欠账清偿单（m6540 / selfstart）· 2026-11-08

## 0. 一句话结论

库内热双分布（DDF）路径的 **D2Q5 温度场**第一次被**解析闭式**裁决：
模拟的模态增长率与相速度对 5×5 离散算子精确特征值吻合到
**1.1e-04（γ）/ 6.6e-15（U）**（n ≥ 64 时 1.5e-11），
热扩散率标定 **≤ 0.6523%**（τ_T=1 处机器精度），
离散误差随 k **二阶收敛（拟合阶 2.00）**；
并定量定出 D2Q5 的**对流偏差律 α_eff/α = 1 + δ_k − 3u²**（3 = 1/c_s²，与 τ_T、k 无关），
16 档残差 **≤ 0.0032 pp**。由此给出可直接引用的适用边界：
u ≤ 0.0183 时热扩散率偏差 < 0.1%，u ≤ 0.0577 时 < 1%，
u = 0.1 时偏差 −2.95%。

## 1. 案例介绍（物理背景 / 几何 / 参数）

**物理**：温度作为被动标量在给定速度场 u 中的对流-扩散
∂_t T + u·∇T = α∇²T。TensorLBM 的 `src/tensorlbm/thermal.py` 用 D2Q5 BGK
（`g_eq = w_i T (1 + 3 c_i·u)`，α = (τ_T − ½)/3）实现该场，
是热对流方腔（`verified/thermal_cavity*`）、CHT 热防护、冰区/结冰导热等路径的公共内核。

**欠账**：该内核此前只有 `tests/test_thermal.py::test_pure_diffusion_matches_cosine_decay`
一条 2% 宽容差、单网格、u = 0 的检查——**对流一致性（u ≠ 0）从未被量化**，
既无离散阶、也无实现/方法解耦。本单补齐。

**几何 / 设置**：周期域 ny × n（ny = 4 仅为张量形状，y 向无变化），
初值 T(x) = cos(kx)（单一 Fourier 模态 ⇒ 线性系统内解析可解），
速度 u = (u, 0) **外部给定**（纯被动、无浮力反馈），fp64，单线程。

| 参数 | 取值 |
|---|---|
| 格子 | D2Q5（权重 ¼ 轴向 + ⅓ 静止，fp32 归一化后精确和为 1） |
| τ_T | 0.55 / 0.65 / 0.8 / 1.0 / 1.5 / 2.0 |
| α | (τ_T − ½)/3 = 0.0167 … 0.5 |
| k | 2π·periods/n，periods ∈ {{1,2,4,8}}，n ∈ {{32,…,512}} |
| u | 0 … 0.1（Ma ≤ 0.17） |
| 步数 | 按 e 折数自适应（1.5–2 e-folds），上限 20000 |
| dtype | float64（torch.set_num_threads(1)） |
| 库入口 | temperature_equilibrium / temperature_collision / temperature_stream（零手写核） |

## 2. 怎么做的（方法 / 关键设置 / 工具链）

**方法：离散解有闭式。** D2Q5 BGK + 周期 streaming 对单一 Fourier 模态是**线性**算子，
其每步放大因子可精确写出（5×5，无需展开多尺度）：

```
g_eq_i = w_i (1 + 3 c_ix u) T,  T = Σ_i g_i
A  = (1 − 1/τ_T) I + P/τ_T,     P_i = w_i (1 + 3 c_ix u)     ← 碰撞（局部线性）
M(k,u) = diag(e^{−i k c_ix}) · A                              ← 周期 streaming 只乘相位
λ = argmax|eig M|  ⇒  γ_disc = −ln|λ|,  U_disc = −arg(λ)/k
```

于是把判据拆成两级，互不掩盖：

* **L1 实现正确性**：模拟测得 (γ, U) 必须等于 (γ_disc, U_disc) → 机器精度。
  任何 streaming 索引错、碰撞公式错、权重错、壁面约定错都会在此暴露，
  且**与网格分辨率无关**（不靠加密掩盖）。
* **L2/L3 物理精度**：γ_disc 对连续 αk²、U_disc 对连续 u 的相对差 = 离散误差，
  报量级与阶（用 k 阶梯拟合）。

**测量**：初值先跑到准稳态，取末段 300 步的**逐段（Δt = 1）复幅值比**做几何平均
（`mu = exp⟨ln(a_{t+1}/a_t)⟩`），γ = −ln|mu|、U = −arg(mu)/k。
逐段估计天然避免相位缠绕（|k·u·Δt| ≪ π）。

**工具链**：`artifacts/thermal_ade_verification_20261108/run_verification.py`
（全部数字写入 `results.json`）→ `make_figures.py`（读 json 出图）→ 本文档由
`make_doc.py` 从 json 渲染（**表内数字零手抄**）。回归判据在
`tests/test_thermal_ade_exact_modal.py`（17 用例，29.5 s，CPU 单线程）。

## 5. 注意点 / 局限

**踩过的坑（均已固化为判据或注释）**

1. **尾窗首个比值跨暖机段**：若把"进入测量窗的第一段"也算进均值，其跨度是
   `steps − tail`（本次 19600 步）而非 1 步，γ 被抬高 **50 倍**（0.0030 vs 6.02e-5）——
   而且**物理偏差律看起来仍然"对"**（因为错误是常数比例），极具欺骗性。
   正解：`t > steps − tail` 才计入比值（见 `run_verification.py` 注释与测试）。
2. **相位缠绕**：把 `arg` 直接用于整段相位，当 k·u·Δt > π 时会折返（实测 u ≥ 0.05 报 85% 误差）。
   正解：逐段 Δt = 1 的复增长因子。
3. **按固定步数而非 e 折数设步长**：小 k 档幅值衰减到 fp64 噪声底，测量全废（首版 n=32 曾报 105%）。
   正解：`steps ≈ efolds/(αk²)`，并保证末窗幅值 > 1e-300。

**局限（适用范围，勿外推）**

* 只验证了 **与坐标轴对齐** 的对流。D2Q5 无对角分量（交叉矩恒零，见下），
  斜向流会额外产生 spurious ∂_x∂_y：本单**未**验证，属开放项。
* 线性单模态分析：不含浮力反馈（热对流方腔的 u 由解本身决定），也不含非线性振幅效应。
  但对流偏差律在给定 u 下成立，可直接叠加到 Ra/Pr 定标上。
* fp64 结论。fp32 的舍入底（~1e-7/步）会掩盖 n ≥ 512 档的 1e-11 判据，故测试全用 fp64。
* **结构缺陷的代数证据**（解释了 −3u²）：D2Q5 平衡态二阶矩**与 u 无关**
  （M_xx = M_yy = 1/3 恒等，M_xy ≡ 0，见 `test_negative_control_d2q5_equilibrium_has_no_u2_second_moment`），
  即 g_eq 缺少正确的 O(u²) 应力项 ⇒ 平流把一部分扩散"吃掉"。若要消除该偏差，
  需给 g_eq 补二阶矩（或改用 D2Q9 温度格子），属**格式改动**，未在本单实施。

| 相速度 U（实现层面） | 闭式特征值 | 6.6e-15 | 是 |

## 7. 对使用者的直接取值建议

热对流/CHT 参数化若工作在 **u ≤ 0.018**（多数自然对流方腔），
D2Q5 的有效热扩散率偏差 < 0.1%，可忽略；
若强制对流/射流局部 u ~ 0.05，α 偏低 **0.70%**（等效 Pr 偏高），
对 Nu、壁温的贡献与 3% 门槛同量级，**需在结论中声明或改用补齐二阶矩的温度格式**。
