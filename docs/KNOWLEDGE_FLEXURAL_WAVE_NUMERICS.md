# 知识蒸馏：弯曲-重力波（弹性冰盖）数值频散的可靠验证方法

**Title / rule**：验证「弹性板 + 自由面」类频散关系时，必须先钉死三件事——(1) 动力学边界条件的
**符号**、(2) 柔性项的**时间积分刚性**、(3) 群速度**比对基准的选择**。任一条错，误差会伪装成
「物理偏差」而不是「实现缺陷」。

**适用范围**：线性/弱非线性势流或 LBM 自由面 + 薄板（Euler-Bernoulli）耦合的频散验证；
冰盖（弯曲-重力波）、弹性浮体、膜结构水波，以及任何 `omega^2 = (g k + D k^5/rho) tanh(kh)`
形式的色散关系。不适用于：有限振幅/破碎波、板的大变形与开裂、粘弹性冰。

**证据 / 出处**
- 节点 `p338w3-n05`，mission 13934，仓库 TensorLBM，commit `10837c33`（2026-11-11）。
- 工件：`artifacts/p338w3_n05_wave_ice_dispersion/report.json`（每单元解析值/数值值/dt/步数/拟合残差）、
  `docs/P338W3_N05_WAVE_ICE_DISPERSION.md`、`tests/test_wave_ice_dispersion.py`（19 例）。
- 关键数字：相速度最大误差 0.44 %（中位 0.11 %，50 单元）；波包群速度 1.09 %（对离散格式自身
  `c_g` 仅 0.02 %）；四负控 PASS；收敛阶 3.34（nx）/ 1.82（nz）；两条解路径一致 1.2e-13。

**机制（为什么）**
1. **符号**：`phi_t = -g eta - (D/rho_w) eta_xxxx`。误写成 `+` 时算子变成「负刚度」，
   所有波数指数增长（表现为 NaN/溢出），而不是「频散曲线偏移」——所以符号错不会自报错。
2. **刚性**：显式格式稳定性要求 `dt < 2/omega_max`，而 `omega_max ~ sqrt(D/rho_w) k_Nyq^2`，
   即 `dt ~ dx^2/(2 sqrt(D/rho_w) k_Nyq^2)`：**网格越细越刚**（成本 ∝ dx^-3.5）。
   1 m 冰、dx≈1 m 时 `dt ~ 5e-4 s`，长波 20 周期需 1e5 步。因此生产求解器必须对柔性项做
   隐式或谱处理，不能靠「加密网格提高精度」。
3. **群速度**：`c_p(k)` 存在极小点，其邻域 `c_g = d omega/dk → 0`，任何差分的相对误差被放大；
   且 10 点 `k` 网格的差分截断本身可达 16 %。必须把「差分截断」与「数值解误差」分离：
   对**解析** `omega(k)` 在同一 `k` 网格上做同样差分，两者之差才是数值误差。

**推荐流程**
1. 写死解析臂（含 `c_g` 的解析导数）。
2. 数值臂用「椭圆子问题精确解 + 时间推进」结构：能循环对角化的（周期、常系数）就用
   DFT + 三对角，成本从 O(nx·nz·迭代) 降到 O(nx log nx)。
3. 用**两条独立解路径**实现同一离散方程（整体系稀疏 LU vs 循环对角化），互裁到 1e-13
   ——最便宜的实现回归护栏。
4. 频率提取必须**自由**（不锚定解析值）：`a cos + b sin + c` 关于系数线性，
   消去后用一维搜索求 `omega`。
5. 负控四件套：`h_i→0`（退化自由面）、`h_i→∞`（代数斜率）、`k→0`（浅水 `sqrt(gh)`）、
   参数扰动 10 %（可检测性 = 偏移 / 数值底噪 > 3）。
6. 报告里同时给「空间误差 / 时间误差」两块预算，禁止只给总误差。

**反例 / 局限**
- `h_i→∞` 在**无质量薄板**形式下发散指数 3/2，加入质量加载 `m = rho_i h_i/rho_w` 后降为 1，
  并整条曲线下移、`c_min` 移位。故该负控只能作代数自洽性检查，不能当「厚冰物理」判据
  （本节点曾在报告里误称质量加载使 omega 随冰厚下降，被 pytest 用例当场证伪并更正）。
- 纯弯曲分支的群/相速度比为 **5/2**（`omega ∝ k^{5/2}`），不是 2 —— 直觉式断言同样需要用例锁死。
- 线性势流模型不含破碎、涡、边界层衰减，对强非线性冰区工况不给结论。
