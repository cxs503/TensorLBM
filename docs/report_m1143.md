## 2. 方法（引自 Report #882 §2）

**三层多尺度框架**：

1. **Kerr 弹性基础梁理论**：冰板在集中载荷下挠度的解析解（基准）
2. **混合 FEM**：Mindlin-Reissner 壳单元（全局）+ 实体单元（局部接触）
3. **内聚颗粒 DEM**：线性弹簧-阻尼器 + 内聚力模拟颗粒龙骨

**耦合策略**：FEM-DEM 通过罚函数接触法耦合，加权力传递；时间步长比由稳定性准则确定。

**验证指标**：挠度误差、阻力误差、Spearman 相关系数、局部破碎误差、网格收敛性。

**测试覆盖**：34 项 pytest 测试全部通过（引自 Report #882 §3）。
