## 1. 物理背景与目标

船舶自航点预报的核心是「螺旋桨推力 = 船体阻力」这一平衡。要把它放进 LBM 里做，
必须解决四个层次的建模问题，本节点逐层实现并逐层取证：

1. **致动盘体积力分布**：不解析叶片几何，把推力/扭矩以体积力形式分布到盘面区域
   `f_r(r, z) = T/(πR²) · g(r/R) · h(z/δ)`，`g` 为径向分布函数（均匀 / 椭圆 / Betz 型），
   `h` 为轴向厚度分布（box / cosine / Gauss）。
2. **自航点迭代**：给定船速 `U`，迭代求出转速 `n`（等价求 `J`）使 `T(n) − R(U) = 0`。
   用带区间保护的 Newton-Raphson（导数取解析 `dK_T/dJ`），并以 Brent 法独立复核。
3. **推力-扭矩-进速系数互裁**：`K_T = T/(ρn²D⁴)`、`K_Q = Q/(ρn²D⁵)`、`J = U/(nD)`，
   三条独立来源（敞水解析锚 / 几何 BEM / LBM 动量反演）互相裁决。
4. **敞水曲线解析锚**：与公开发表的敞水曲线对比。

正交的物理校验量取 **Rankine–Froude 致动盘动量理论**：

```
C_T = T / (0.5 ρ U² A),   C_T = 4a(1+a)
u_d = U(1+a),             u_w = U(1+2a),        η_ideal = 1/(1+a)
P_in = T u_d = 0.5 ρ A u_d (u_w² − U²)   （能量恒等式）
```

## 2. 方法

### 2.1 体积力离散（精确积分）

在离散网格上直接对权重 `h(s)·g(ε)` 求和做归一化：

```
f_x(i)      = +T · w_i / Σ w,        w_i = h(s_i) g(ε_i)
f_θ(i)      = +Q · u_i / (r_i Σ u),  u_i = h(s_i) w(ε_i)
Σ f_x ΔV = T,   Σ r f_θ ΔV = Q       （精确到 1e-12 相对误差；见用例 12 组合参数化测试）
```

不使用连续积分 `π(R²−R_h²)` 归一化——笛卡尔网格上的离散环面积与连续值差几个百分点，
会让施加推力与名义推力不符，进而污染「T=0 负控」与动量反演判据。**力加在流体 +x（下游）
方向**，船舶得到 −x 反作用，即推力。

### 2.2 自航点迭代

```
T(n) = K_T(J) ρ n² D⁴,  J = U(1−w)/(nD)
res(n) = (1−t)T(n) − R(U)                （mode="effective"；"gross" 时 (1−t)→1）
dT/dn  = ρD⁴ (2nK_T − n J dK_T/dJ)
```

初值取锚有效区间的中点对应 `J`（`n₀ = U(1−w)/(J_mid D)`）：用 `K_T(0)` 估初值在
`J ≳ 1` 的自航点会显著跑偏（本例即如此），Newton 一步越界后只能退化为二分、收敛掉到线性。
区间保护：Newton 步出界即改二分；迭代历史逐条记录 `|res|/R`。

### 2.3 LBM 取证口径

* **推力不看施加值**：由流场**轴向动量通量跃变**反演
  `T_mom = Σ[(ρu_x² + p)]_{x=x_dn} − Σ[...]_{x=x_up}`（`p = c_s²ρ`）。
* **功率**：每步在盘区累积 `Σ F·u`，稳态窗口内平均。
* **能量残差**：`P_in − [(动能+压力能)通量差] − 2μ∫S_ijS_ij dV`，其中
  `S_ij` 由速度场中心差分得到。

## 5. 注意点（踩过的坑）

1. **力的方向符号**：若把体积力施加为 −x（“把水往后推”的直觉写法），在“来流 +x”的
   数值风洞里就等于给流体减速，致动盘变成阻力盘，远场速度会低于自由来流，与 Rankine
   理论符号相反。正确做法：流体系受力 +x（下游），船舶受 −x 反作用。
2. **侧壁自由滑移必须只反法向分量**：镜面反射 `(c_x, c_y, c_z) → (c_x, −c_y, c_z)`；
   若图省事用全反向 `(−c_x,−c_y,−c_z)`（那是 bounce-back），均匀流会凭空产生切向动量，
   `T=0` 负控偏差可达 6% 量级——本节点 C4 正是靠这一条抓到的 bug。
3. **Newton 初值**：`K_T(0)` 估 `n₀` 只在 `J→0` 附近成立；自航点常落在 `J≈0.8~1.0`，
   初值偏 30% 以上会让首步越界、退化为二分。应取锚区间中点对应 `J` 作初值。
4. **离散归一化 vs 连续积分**：见 2.1。
5. **有限域堵塞**：侧壁距轴约 2D，自由滑移壁对诱导速度有 O(5%) 量级影响；C1 的 5%
   判据内含该系统性误差，本节点不宣称更低容差。
6. **`text{Betz}` 形状**：`g = ε√(1−ε²)` 只是「零根零梢 + 最小诱导损失」的*形状族*，
   不是 Goldstein 精确解。
7. **敞水锚的来源**：本仓无 Wageningen B-series 系数表，**不臆造系数**；改用仓内已引用
   的 KP505 实测敞水表做多项式解析锚（更硬的证据：实测曲线而非回归），并由几何 BEM 独立互裁。

## 6. 误差判定

见 `artifacts/p162w1_n05/criteria.json` 与 `REPORT.md` 第 6 节：逐项列出关键量误差与
是否满足阈值，并对「是否 < 3%」逐项显式回答。要点：

* **< 3% 的项**：LBM 动量反演 K_Q（0.16%）、解析动量理论能量恒等式（6e-16）、C4 负控（3.6e-6）。
* **未达 3% 但满足节点判据的项**：C1 远场速度 4.83%（判据 5%）；LBM 动量反演 K_T 3.82%（判据 10%）。
* **未达判据的项（honest FAIL，不覆盖）**：几何 BEM 的 K_T 在 J=0.7 与实测敞水曲线差 10.58%
  （>10%），其 K_Q 仅差 0.63%——说明 BEM 的推力侧偏保守（低 Re 段更差，J=0.4 时 +35%）；
  能量守恒数值口径残差 −3.14%（>1%），主因是有限时长未完全稳态（storage 项 ~1%）与等温 LBM
  的压力/压缩功记账项在离散边界上不闭合（实测 ∫p∇·u 被边界闭合误差主导，已标记不用于裁决）。

## 7. 局限与适用范围

* 致动盘模型不含叶片数、侧斜、叶厚等几何效应，只能给出积分量（T、Q、诱导速度场），
  不能给出桨叶表面压力/空化性能；叶频激励需滑移网格或浸没边界。
* 均布载荷假设（Rankine）与径向形状（Betz 族）用于校验时，`C_T` 必须按**盘面积**
  `πR²` 而非环面积定义；本模块的 `rankine_disk` 即按盘面积定义。
* 层流 `Re_D = 60`：为了在可承受的格点预算内得到干净的解析对照，未做湍流模化；
  实尺度自航（`Re_D ~ 10⁶`）需要 LES/DES 壁面模化，属后续节点。
* 侧壁自由滑移 + 有限域：堵塞效应 O(5%)，需更大域或远场无反射边界才能压到 1% 以下。
