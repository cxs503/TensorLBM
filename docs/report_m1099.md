## 1. 案例介绍（物理背景与参数）

### 1.1 物理问题
二维圆柱绕流 Re=100，层流 Kármán 涡街。这是经典的 CFD 验证案例，具有明确的实验/数值参考解，用于检验求解器的：
- 涡脱落频率捕捉能力（Strouhal 数）
- 时间平均阻力系数精度
- 网格收敛性与统计充分性

### 1.2 几何与计算域
- **圆柱直径**：D = 1（格子单位）
- **计算域**：[0, 40D] × [0, 40D]，圆心位于 (7.5D, 20D)
- **网格分辨率**：
  - D/10 档：D=10，400×400 网格（初步验证）
  - D/48 档：D=48，1920×1920 网格（主判档）
  - D/64 档：D=64，2560×2560 网格（收敛验证）

### 1.3 边界条件
- **入口**（左边界）：均匀来流 U，Ma < 0.17（低马赫数保证不可压假设）
- **出口**（右边界）：零梯度出流 + **下游 10D sponge 吸收层**（消除尾流反射）
- **上下边界**：自由流 Dirichlet（far_field_bc_2d）
- **圆柱表面**：immersed boundary / bounce-back

### 1.4 物理参数（Re=100）
| 参数 | 值 | 说明 |
|------|-----|------|
| Re | 100 | 基于直径 D 和来流速度 U |
| U_in | 0.05 (lb) | 格子单位来流速度 |
| ν | 0.005 (lb) | 运动粘度（格子单位） |
| τ | 0.515 | BGK 松弛时间 |
| Ma | ~0.05 | 马赫数（U/c_s，c_s=1/√3） |

### 1.5 参考解（判据来源）
- **Braza et al. 1986 (JFM 165)**：Cd = 1.35 ± 0.05（实验），St ≈ 0.164-0.165
- **2D DNS 文献**：Cd 1.31-1.39，St 0.164-0.168
- **e2e1 冻结门**：Cd ∈ [1.28, 1.42]，St ∈ [0.160, 0.172]

## 2. 方法（怎么做的）

### 2.1 求解器与数值方法
- **格子 Boltzmann 方法**（LBM）：D2Q9 模型
- **碰撞算子**：MRT（Multiple Relaxation Time），支持逐格松弛率 τ_field
- ** streaming**：标准 LBM streaming
- **平衡态**：d2q9.equilibrium（库函数）

### 2.2 边界处理
- **far_field_bc_2d**：入口/两侧自由流 Dirichlet + 出口零梯度 + obstacle bounce-back（一次调用）
- **sponge 吸收层**（本次关键新增）：
  - 下游最后 10D 区域，τ_field 渐变（α=10，τ_max=7.17，ν 放大 43 倍）
  - 平滑平方渐变：`make_sponge_strength(ny, nx, x0, width, power=2)`
  - **作用**：消除 far-field 零梯度出口对涡街尾流的压力波反射（原 20000 步发散根因）

### 2.3 涡脱落激发
- **入口播种**（seed）：前 2 个 St_seed 周期（St_seed=0.165）施加 10% 振幅正弦横向扰动
- **播种权重修复**（关键 bug fix）：
  - 原手写 D2Q9 速度权重 `cy_w=[0,0,1,0,1,0,1,0,1]` 符号/位置错误
  - 正确应为 `[0,0,1,0,-1,1,1,-1,-1]`（直接取库常量 `d2q9.C` 列）
  - 错误导致 uy_seed ≈ 0.277（应为 ~0.008），等价 3.5 倍来流横向射流 → 18 步即 NaN
  - **修复**：使用库常量，消除手写错误

### 2.4 力计算与统计
- **Cd/Cl 计算**：Ladd 动量交换法（`compute_obstacle_forces`），post-stream、pre-bounce-back 采样
- **统计窗**：
  - D/10 档：8000 步，warmup_frac=0.5（前 4000 步丢弃）
  - D/48 档：60000 步，warmup_frac=0.5（前 30000 步丢弃）
  - D/64 档：90000 步，warmup_frac=0.5（前 45000 步丢弃）
- **St 提取**：升力 Cl 过零检测（主频）

### 2.5 工具链
- **求解器**：TensorLBM src/（库 solver + 库 BC，零手写 collide/stream/equilibrium）
- **编译优化**：tensorlbm.compile_utils（播种期/自由流期双变体，避免逐步重编译）
- **后处理**：Python 脚本从输出文件直读 Cd/St（零手抄纪律）
- **运行环境**：CUDA GPU（具体型号未留档）

### 2.6 自主协作模式（B臂特色）
- **无预设角色**：2 席自行分工，可互派 evo1-b-* 子单
- **发现面共享**：POST/GET http://127.0.0.1:8011/directory（全臂同备）
- **预算约束**：全臂 ≤400 工具调用 + ≤12M tokens + 24h 墙钟

- **涡脱落周期数**：
  - D/48 档：60000 步，St=0.166 → 脱落频率 f = St·U/D = 0.166·0.05/1 = 0.0083 (lb)

  - 统计窗（后 30000 步）= 30000/120.5 ≈ **249 个脱落周期** >> 30 周期要求 ✅

## 5. 注意点（踩坑与局限）

### 5.1 关键修复（两个根因）
1. **播种权重 bug（NaN 真根因）**：
   - 手写 D2Q9 速度权重符号/位置错误 → uy_seed 放大 35 倍 → 18 步爆炸
   - **教训**：手写物理常量易错，必须使用库常量（`d2q9.C`）
   
2. **far-field 出口尾流反射**：
   - 零梯度出口对涡街尾流反射压力波 → 20000 步发散
   - **解决**：下游 10D sponge 层（τ 渐变 α=10）
   - **教训**：开放域流动必须考虑出口反射，sponge 层是标准做法

### 5.2 局限性
1. **2D 假设**：Re=100 为层流涡街，2D 模拟合理；但 Re>200 后 3D 效应显著，本案例不覆盖
2. **GCI 未显式计算**：仅凭两档网格误差 <3% 判定收敛，未做 Richardson 外推+安全因子
3. **统计窗起始点**：warmup_frac=0.5 丢弃前 50% 步数，但未显式验证过渡期已结束（可通过 Cd 时序确认）
4. **边界条件敏感性**：未做上下边界（自由流 vs 周期）敏感性分析
5. **工件未留档**：原单未保存可视化文件（png/npz），补报无法补充

### 5.3 适用范围
- **适用**：Re ≤ 200 层流涡街验证、LBM 求解器精度检验、sponge 层工程实践
- **不适用**：Re > 200 过渡区/湍流（需 3D + 湍流模型）、高 Ma 可压流动

### 5.4 自主协作观察（B臂特色）
- **无预设角色**：2 席自行分工，具体协作模式未留档（原单声明"自行决定分工"）
- **发现面共享**：通过 directory API 共享中间发现，避免重复工作
- **预算效率**：原单声明"成功交付"，具体工具调用数/tokens 消耗未留档
