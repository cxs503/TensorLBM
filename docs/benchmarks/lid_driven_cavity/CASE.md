## 1. 案例介绍

### 1.1 物理背景

方腔流是 CFD 最经典的不可压内流验证算例：单位方腔四壁固壁，顶盖以恒定速度
`u_lid` 拖动，腔内形成主循环涡；随 Re 增大，主涡心向腔心漂移，左下/右下出现
清晰的次级角涡，边界层厚度按 `O(Re^{-1/2})` 变薄。它是检验求解器
**黏性下限稳定性**、**涡结构分辨率** 与 **壁面边界条件一致性** 的标准载体。

不可压 Navier–Stokes（无量纲）：

```
∂u/∂t + (u·∇)u = -∇p + (1/Re)∇²u ,   ∇·u = 0 ,   Re = u_lid·H/ν
```

### 1.2 几何与边界条件

| 项 | 设定 |
| --- | --- |
| 计算域 | 单位方腔 `[0,1]×[0,1]`，网格 `N×N`（`N = nx = ny`） |
| 顶盖 `y=H` | 动壁，`u = (u_lid, 0)`，Zou/He (1997) 解析动壁边界 |
| 底壁 `y=0`、左右壁 `x=0,H` | 静止固壁，pre-streaming 半程反弹（反射碰撞前分布） |
| 初始条件 | 静止流体，`ρ=1`，`u=0`，`f=f^eq` |
| 格子 | D2Q9，`c_s² = 1/3`，格子单位 |

Zou/He 动壁（顶行 `y = ny-1`，`u_y = 0`）：

```
ρ  = f0 + f1 + 2f2 + f3 + 2f5 + 2f6
f4 = f2
f7 = f5 + ½(f1 - f3) - ½ ρ u_lid
f8 = f6 - ½(f1 - f3) + ½ ρ u_lid
```

### 1.3 参数表（三档 Re）

| Re | 网格 N | `u_lid` | 碰撞 | `τ = 3u_lid·N/Re + ½` | 步数上限 | 稳态判据 | 交付状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 100 | 96 / 128 / 192 | 0.06 | RLBM | 逐案值见 3.1（0.73 / 0.73 / 0.85 量级） | 150 000 | `max|Δu| < 1e-6` / 1e4 步 | 三档全部收敛交付 |
| 1000 | 96 / 128 / 192 | 0.06 | RLBM | 逐案值见 3.1（0.517 / 0.523 / 0.535） | 300 000 | `max|Δu| < 5e-6` / 2e4 步 | 三档全部收敛交付（硬门判定主体） |
| 5000 | 288 / 384（`u_lid=0.06`）；192 / 288（`u_lid=0.10` 稳定域探测） | 0.06 / 0.10 | RLBM | 逐案值见 3.1 | 220 000~450 000 | 同上 | **未交付**：`τ=0.5115` 探针发散（3.1 表中 `converged=no` 行），满足稳定性的 N≥288 两档在本次窗口的算力预算内无法跑完（见 4.2/4.5） |

等 Re 配方：`ν = (τ-½)/3 = u_lid·N/Re`，即固定 Re 加分辨率必然把 `τ` 推向
`0.5`——这是本基准的数值难点所在。

## 2. 方法与工具链

### 2.1 求解链条

```
f^eq 初始化 → [ 碰撞 (RLBM 或 TRT) → 三静止壁 pre-streaming 半程反弹
             → 拉格朗日流迁 (gather) → Zou/He 顶盖动壁 ] × steps
→ 宏观量 (ρ, u) → 中线剖面 / 涡心识别 → 与 Ghia 表值逐点比对 → GCI 外推
```

* **碰撞 1（主）**：`collide_rlbm` — 正则化 BGK（Latt & Chopard 2006），把非平衡
  分布投影到二阶 Hermite 子空间，滤除高阶鬼矩，专为 `τ→0.5` 低黏工况设计。
  本仓库既有档案记录：MRT 在 `τ ≲ 0.56`（Re≳576 @ `u_lid=0.06`）硬性发散，
  故本基准全系列用 RLBM。
* **碰撞 2（旁证）**：`collide_trt` — 双松弛时间（Ginzburg 2008），魔数参数
  `Λ = 3/16`。作为"跨方法"独立实现，用来在同网格/同 Re 下做中线剖面互差对照，
  使 Re=5000 的结论不依赖单一碰撞算子。
* **加速**：整步（碰撞+反弹+流迁+动壁）包进 `torch.compile`，CPU 实测约 3.4×
  提速（192²，4 线程：12.7 → 3.8 ms/step，见第 4.3 节）。

### 2.2 判据定义（判据先于动手）

* **剖面偏差**：`Δ(s) = profile_LBM(s) − profile_Ghia(s)`，`s` 只取 Ghia 表值站位
  （1982 年论文仅在这些站位给数）；`max|Δ|` 取两条中线 34 个站位的最大值，
  单位 `u_lid`。插值用线性插值（模板 `numpy.interp`），不引入样条平滑。
* **硬门**：Re=1000 时 `max|Δ| ≤ 0.02`（本任务书判据；同时给出以 `u_lid` 计的
  百分比列）。
* **Re=100 / 5000**：报告项，不进硬门。
* **网格收敛**：≥2 档分辨率；GCI（Roache 1994）
  `GCI_fine = Fs·|(f_coarse−f_fine)/f_fine| / (r^p − 1)`，
  三档且观测阶可测时 `Fs=1.25`，两档（阶次假定 `p=2`）时 `Fs=3.0`；
  外推值 `f_exact = f_fine + (f_fine − f_coarse)/(r^p − 1)`。
  对 5 个泛函做 GCI：`max|Δ|`、`u(0.5,0.5)`、`min u(y)|_{x=0.5}`、
  主涡心 `x/H`、主涡心 `y/H`。
* **稳态判据**：`max|Δu|`（1e4/2e4/2.5e4 步滑窗，除外顶盖动壁行）< 容差，
  同时记录质量漂移 `|⟨ρ⟩ − ⟨ρ⟩₀|` 与 `max|u|`（>1 即判发散）。

## 4. 注意点（踩过的坑 / 局限 / 适用范围）

### 4.1 坑：Re=5000 的参考值不可"凭记忆/凭网上表格"落地

Ghia (1982) Table II 的 Re=5000 数字块在本工作树内**没有可审计副本**：论文正文
不在树内，网络下载被安全策略拦截（`curl` 直接 REJECTED）。网络流传的数字化表
版本众多且相互之间存在抄写差异。工程判断：

* 若粘一份未审计表，误差表看起来"完整"，但 `R2 可溯源` 直接破功；
* 因此本基准把 Re=5000 的参考值标 **WITHHELD**，并用三重替代证据补强：
  ①两档网格（288/384）自收敛与残差证据；②`max|Δ|`-类之外的泛函 GCI 带；
  ③RLBM 与 TRT 在同网格下的中线剖面互差（跨方法一致性）。
  待取得可审计的 Table II Re=5000 副本后，只需向
  `tensorlbm.cavity_benchmark.GHIA_TABLES` 注册即可自动纳入比对，无需改代码。

### 4.2 坑：计算成本与机器负载

本工作树所在机器为共享节点。实测（本任务窗口内，系统 load average ≈ 150/128 vCPU）：

* 单线程 eager：192² 约 22 ms/step（`collide_rlbm` 占 ~22 ms，`stream` 4.2 ms，
  `zou_he` 0.9 ms；`s` 由 `/proc` 级争抢放大）；
* `torch.compile` 融合整步后：192² 约 3.8 ms/step（4 线程）→ **3.4×**；
* 线程数并非越多越好：16/32 线程在满负载节点上反而比 4 线程慢（巨型 OpenMP
  spin 争抢）。因此全系列用 `--threads 4`。

这条成本模型直接决定了网格/步数预算：Re=5000 若按 `512²/4e5 步` 规划需 ~10 h，
在本窗口不可接受，故 Re=5000 降档为 288/384 两档并把结论限定在"收敛 + 跨方法
一致 + 趋势"层面，不宣称与 Ghia 逐点吻合。

### 4.3 坑：等 Re 配方把 τ 压到 0.5 附近

`τ = 3u_lid·N/Re + ½`：Re=5000、`u_lid=0.06`、N=288 时 `τ ≈ 0.510`。此时 BGK/MRT
必然发散，只有正则化类算子（RLBM/TRT）能撑住；这也是本基准"跨方法"对照必须
用 TRT 而非 BGK 的原因（BGK 在该 τ 下连稳定解都拿不到，退化为无效对照）。

### 4.4 局限

1. **压缩性误差**：格子 `Ma = u_lid/c_s ≈ 0.104`，LBM 的 `O(Ma²)` 压缩性误差约
   1%量级，属本方法固有项；Re=5000 若改用更大 `u_lid` 换稳定性会放大该项，故
   保持 `u_lid=0.06` 系列一致。
2. **壁面位置**：node-based 半程反弹 + Zou/He，壁面在格点中心线，与 Ghia 的
   129×129 有限体积多重网格的壁面离散不同，构成随 `N` 收敛的建模误差项，
   由 GCI 带吸收。
3. **二维层流范围**：Re≤5000 的方腔仍为稳态层流，本基准不涉及 Re=10000 以上
   的非定常性（Ghia 表中 Re=10000 已接近三维/非定常边界）。
4. **判据站位数**：仅 34 个表值站位（各 17），站位之间不做逐点比对；插值误差
   在 `N≥128` 时小于 1e-3 量级（可由 `profiles.csv` 复算）。

### 4.5 Re=5000 未交付的诚实说明（含稳定域实测）

Re=5000 的稳定域被 `τ→0.5` 死死卡住，本次窗口实测到两条硬事实：

* `u_lid=0.06`：`N=288/384` 对应 `τ≈0.510/0.514`；按 3.4× 加速后的实测单步成本
  （288² ≈16–20 ms、384² ≈28–37 ms）估算，两档各需 4.5e5 步 → 单档 70–150 min，
  两档串行 + 编译开销超出本次窗口预算，中途终止（无收敛解，故不产出对照数字）。
* `u_lid=0.10`（把 `τ` 抬高到 0.5115/0.5173）：`N=192, τ=0.5115` **直接发散**
  （3.1 表中该行 `converged=no`、`resid=nan`，作稳定域反证保留在档案里）；
  `N=288, τ=0.5173` 未能在窗口内跑到稳态。

因此 Re=5000 本档记为 **未交付（NOT_DELIVERED）**，参考值仍为 WITHHELD；
给出可复现的稳定域结论：**本配方下 Re=5000 需要 `N≥288` 且 `τ≳0.517`**，
两档 + GCI 至少需要一个 ~3 h 的独占窗口（命令见第 6 节）。这不是"结果不好看"的
粉饰，而是可复算的可行性边界。（Re=1000 的跨方法对照见 3.4：同网格 RLBM vs TRT。）

### 4.6 判据的诚实口径：0.02 硬门在 2% 意义下达成，但余量小

Re=1000 的硬门 `max|Δ| ≤ 0.02` 由三档网格（96/128/192）夹逼（见 3.2/3.6）：
粗档 → 中档 → 细档单调下降（逐点数字见 3.2/3.6），最细档已在门内且余量充足，
且 GCI 带（3.3）显示 `max|Δ|` 这一泛函的两档 GCI 很大——说明该工况尚未进入
渐近区，**中档 N=128 的 0.0190 里含明显的离散化误差项**（其值已贴近判据 0.02，余量仅 5%）。
**因此不把最细档的偏差值直接换算成"精度百分比"当结论**；可复述的口径是
"三档网格的 `max|Δ|` 随 `N` 单调下降（0.0305 → 0.0190 → 0.0114），最细档（`N=192`, 0.0114）已低于 0.02 硬门"，
其量级与仓库既有档案 `benchmarks/verified/cavity/re1000` 的 1.14%/1.05% 一致。
