## ① 案例介绍

### 物理背景

顶盖驱动方腔流（Lid-driven cavity）是计算流体力学经典基准问题。顶盖以速度 U 移动驱动腔体内流动，雷诺数 Re = U·H/ν 决定流态。Re=400 时为层流单涡+次级涡结构，存在 Ghia et al. (1982) 的高精度参考解。

### 几何与参数

| 参数 | 值 |
|------|-----|
| 几何 | 2D 方腔 (H×H) |
| Re | 400 |
| U_lid | 0.06 (格子单位) |
| 网格 | 128² / 192² |
| 碰撞模型 | MRT (D2Q9) |
| 边界条件 | V3: pre-streaming 半程反弹(三静止壁) + zou_he_moving_lid(顶盖) |
| 基准 | Ghia, Ghia & Shin 1982, JCP 48:387 |

### 验证目标

1. **设备一致性**：SDAA 设备与 CPU 数值结果一致性（逐步对比分布函数 f）
2. **网格收敛**：128² → 192² 误差单调下降
3. **精度达标**：最大绝对偏差 < 3%（硬门 ≤ 2%）

## ② 方法

### 工具链

- **求解器**：TensorLBM (`tensorlbm.solver.collide_mrt` / `stream` / `tensorlbm.lid_driven_cavity.zou_he_moving_lid`)
- **设备**：SDAA（/dev/tcaicard0，Torch-SDAA 3.1.1a3）
- **参考解**：Ghia 1982 中线速度剖面表值

### 流程

1. **设备验证**：确认 SDAA 可用（32卡，/dev/tcaicard0）
2. **数值一致性验证**：CPU vs SDAA 逐步对比 f 分布（200步，nx=128），证明 bit-identical
3. **短程 SDAA 运行**：128²/192² 各 20000 步，验证设备可运行且流场与 CPU 一致
4. **收敛判据**：引用已验证的 CPU 基准结果（100k 步收敛）

### 关键设置

- **边界修复**：V3 pre-streaming 半程反弹（V0 post-streaming 曾导致 23.6% 偏差）
- **收敛标准**：残差 < 1e-5 或 100k 步

## ⑤ 注意点

### 原报告 758 缺陷清单

原报告 §⑥ 误差判定节存在以下缺陷（已在本 meta-报告中修正）：

1. **网格标识错误**：将最粗档 N=96 误标为"最细档"（正确最细档为 N=192）
2. **数学错误**：声称"3.05% < 2%"（3.05 > 2，数学不可能）
3. **结论矛盾**：声称"硬门达成（3.05% < 2%）"与硬门 ≤0.02 矛盾（0.0305 > 0.02）
4. **判定矛盾**：§⑥ 判定"通过"与 §③ 表中数据不一致

### 本补报处理

- **诚实标注**：原报告 758 中 N=96 的具体误差数据**未留档**（工件目录未保留该网格的运行结果）
- **仅引用可验证数据**：本 meta-报告仅引用工件 `artifacts/sdaa_cavity_evidence.json` 中明确记录的 128²/192² 数据
- **不编造缺失数据**：原报告中 3.05% 的来源无法溯源，本补报不重复该数字

### 技术局限

1. **SDAA 速度**：SDAA 128² 约 23s/5k步，比 CPU 慢（CPU 约 4s/10k步）。完整 100k 步收敛需 ~40 分钟。
2. **收敛行为**：残差在前 80k 步维持在 ~0.09 水平，最后 20k 步急剧下降至 1e-6 级别——这是方腔流的固有特性（长 transient），非设备问题。
3. **V3 修复**：pre-streaming 半程反弹是关键修复，V0 的 post-streaming 反弹曾导致 23.6% 偏差。

## ⑥ 误差判定

### 关键量 vs 基准误差

| 网格 | 关键量 | 计算值 | 基准值 (Ghia 1982) | 绝对偏差 | 相对误差 | 是否<3% |

| 128² | u_mid (x=0.5, y=0.5) | -0.1211 | -0.1148 | 0.0063 | 5.49% | ❌ NO |
| 128² | Max |dev| (全中线) | — | — | — | 1.50% | ✅ YES |
| 192² | u_mid (x=0.5, y=0.5) | -0.1193 | -0.1148 | 0.0045 | 3.92% | ❌ NO |
| 192² | Max |dev| (全中线) | — | — | — | 0.83% | ✅ YES |

**注**：u_mid 单点偏差 > 3%，但全中线最大绝对偏差 < 3%。判据采用全中线最大偏差（更稳健）。

### 硬门判定

- **硬门标准**：Max |dev| ≤ 2%
- **128²**：1.50% ≤ 2% ✅ **PASS**
- **192²**：0.83% ≤ 2% ✅ **PASS**

- **网格收敛**：✅ 误差从 1.50% 降至 0.83%，单调下降

- **总体判定**：✅ **PASS**
