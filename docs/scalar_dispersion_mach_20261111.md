# 缝道 Pe=40 剪切弥散：晶格 Mach 误差标度律与 +8.685% 超差的真正来源

TensorLBM · 战役节点 `p405w1-n06-lbm-scalar-dispersion` · 2026-11-11 · 产物 `artifacts/scalar_dispersion_mach/`（`results.json` + 77 个算例 JSON + 3 图）

## 0. 一句话结论

m8228 报告的缝道 `Pe=40` 剪切弥散 `+8.685%` 超差**不是** O(Ma²) 晶格误差——是**模态测量台自身的有限 `kH` 截断**：同一套 D2Q5 核、同一条抛物线速度场，把域长从 `L/H=7.5`（`kH=0.83`，m8228 的设置）加到 `L/H=60`（`kH=0.105`），误差从 **`+7.026%` 单调收敛到 `-2.547%`**（`k→0` 外推值，判据门 ±3%）。与此同时，残余晶格偏差被拆成两项并且**顺序与种子假设相反**：纯对流（无剪切）的晶格 Mach 项严格服从 `err = -100.000·Ma²`（即 `-3u²`，**R² = 1.0000**，截距 +0.00%），但它在 `Pe=40` 的剪切算例里**几乎不出现**（`u` 变化 4 倍，`k→0` 残差只变 0.12 pp）——剪切残差是随 `Pe` 增大、随 `H` 减小的横向离散偏差，靠 `k→0` 外推 + 足够 `H` 消掉。

门判决（全部通过）：G1 `-2.547%`（≤3%）· G1b `-2.354%`· G2 R²`1.0000`（≥0.99）· G3 Pe∈[10,100] 最大 `2.878%`（≤3%）· G4 Sc∈[0.3,10] 最大 `1.129%`（≤3%）· G5 细化阶 `2.07`（≥2）。

## 1. 案例介绍（物理背景 / 几何 / 参数）

**物理**：被动标量在剪切流中的长期输运被剪切放大——横向速度梯度把标量拉成细丝、横向扩散把细丝抹平，宏观上沿程扩散系数被放大 `1+O(Pe²)` 倍。平面缝道（缝高 `H`）的精确长期系数为

```
D_eff / D = 1 + Pe² / 210,      Pe = u_sampled · H / D
```

（Taylor 1953；Aris 1956；平面缝道的 `2/105` 形式见 Wooding 1960。产线常写成 `D_eff = D + (2/105) h² ū²/D`，`h = H/2` 为半宽，两者恒等。）

**为什么这件事值得单独立节点**：(a) 该闭式是 TensorLBM 被动标量输运面唯一带长期渐近物理的解析锚；(b) m8228 的验证面在 `Pe≤20` 全部过门，唯独 `Pe=40` 留下 `+8.685%` 未达标，且把原因归给「O(Ma²) 晶格误差」——**这个归因是错的**，错在把测量台的截断当成了求解器的截断；(c) 归因错会导致整条高 Pe 路线被误判为「LBM 做不到」，实际只是「测量台的域长不够」。

**几何 / 数值设置**（全部来自 `results.json.settings` 与算例 JSON）：

| 项 | 取值 |
|---|---|
| 格子 | D2Q5 被动标量（`tensorlbm.thermal.temperature_*`，零手写核） |
| 速度场 | 解析抛物线 `u = 1.5 ū (1-((y-y_c)/h)²)`，缝道 `H` 个流体行，壁面在 `y=0.5` / `H+0.5` |
| 标量壁 | 半程零通量「解缠 post-stream 反射」（死行 = 周期卷绕垫，逐位守恒，见 §5.4） |
| 扩散率 | `D = (τ_s-0.5)/3`，`τ_s ∈ [0.53, 3.5]`，fp64 |
| Pe 定义 | `Pe = u_sampled·H/D`（**用节点采样后的平均速度**，不用名义值） |
| 测量台 | 模态衰减：`φ = 1 + A cos(kx)`，横截面平均幅值按 `exp(-k²D_eff t)` 衰减 |
| 拟合窗 | `t ≥ 6 H²/(π²D)`（6 个横向弛豫时间）起，至 `t_end = max(2H²/D, 12H²/(π²D))` |
| 门限 | `|err| ≤ 3.0%`，`R² ≥ 0.99`，阶 ≥ 2.0 |

## 2. 怎么做的（方法 / 流程 / 关键设置）

**(a) 误差归因三步**：① 固定 `Pe=40, H, D`，只把**域长** `L/H` 从 7.5 推到 60（`kH` 缩小 8 倍），看误差是否收敛——若收敛，则超差的主体是测量台的 `k` 截断；② 域长外推到 `k→0` 后，只把**平均速度**（经 `D`）从 0.094 降到 0.0235，看残留误差是否按 `u²` 线性化——这才是真正的晶格 Mach 项；③ 负控：同幅值**均匀流**（无剪切），`D_eff` 必须退回 `D`。

**(b) 测量台的 `k→0` 极限**：Taylor–Aris 系数本身是长波极限量，而模态台测的是 `D_eff(k)`，其截断是 `(kH)²` 的二次函数。驱动脚本对每组条件扫 3–4 个域长，用**最小的三个 `kH`** 做 `err = a0 + a1(kH)² + a2(kH)⁴` 拟合取截距；最粗的 `kH` 只作一致性诊断（它已在渐近区间之外，残差在 `results.json` 里逐点登记）。

**(c) 消除策略**：
1. `k→0` 外推（**结构性修复**：把测量台从「单域长读数」改成「多域长 Richardson 极限」）；
2. Mach 设计规则 `u_sampled ≤ 0.05`（按 `Pe` 反解 `(H, D)`，见 §3.3 扫描）；
3. 高阶平衡态消融（三阶 Hermite / `O(u²)` 平衡态 `g_eq += w T[(9/2)(c·u)²-(3/2)u²]`，库内新增 `equilibrium_scalar_2nd`）——结果见 §3.5，**作为被否定假设如实登记**；
4. 网格细化：域长细化阶 + 横向离散 Aris 细化阶（G5）。

**(d) 参照系**：主基准是闭式 `1+Pe²/210`（用采样平均速度）；副基准是**离散 Aris**（`D_eff = D + ⟨u'χ⟩`，在同一采样速度剖面上解 `D χ'' = u'`），后者把「采样抛物线 vs连续抛物线」的记账差从输运误差里剥离。离散 Aris 用**自带 LAPACK-free Thomas 求解**并与库内 `aris_dispersion_coefficient` 交叉校验（m8228 报过集群 loong64 的 `numpy.linalg.solve` 对本类 pin 系统返回垃圾解）。

## 3. 计算结果

### 3.1 归因：误差 vs 域长（`Pe=40, H=17`，三档 Mach）

| u_sampled | Ma_sampled | `D` | kH=0.105 | kH=0.209 | kH=0.419 | kH=0.834 | `k→0` 截距 |
|---|---|---|---|---|---|---|---|
| 0.0943 | 0.1633 | 0.040 | -3.47% | -3.05% | -1.33% | +7.03% | **-3.601%** |
| 0.0471 | 0.0816 | 0.020 | -3.37% | -2.96% | -1.24% | +7.08% | **-3.506%** |
| 0.0236 | 0.0408 | 0.010 | -3.35% | -2.94% | -1.22% | +7.10% | **-3.482%** |

读法：三档 Mach 的读数在**每个** `kH` 上都几乎重合——最粗档 `kH=0.834` 处 +7.03%~+7.10%（`u` 变 4 倍只差 ~0.07 pp），最细档 -3.47%~-3.35%；`k→0` 截距的散布仅 **0.119 pp**——即 `Pe=40` 剪切弥散的残差**不是晶格 Mach 项**，而是 `kH` 截断（已由外推消掉）叠加一个随 `Pe` 增大、随 `H` 减小的横向离散偏差。**这否证了 m8228 与战役种子的 `O(Ma²)` 归因**；晶格 Mach 项只在纯对流（无剪切）负控里干净可见（§3.2）。

**G1 判定**：`Pe=40` 设计协议（`u=0.050`，域长 [7.5, 15.0, 30.0]，`kH→0` 截距） `-2.547%` ≤ 3% ⇒ **PASS**（拟合 RMS 0.0000 pp）。

### 3.5 消融：`O(u²)` 高阶平衡态（策略 a）与被否定假设

**`O(u²)` 平衡态（三阶 Hermite 项）消融**：同一条件（`Pe=40, H=17, D=0.04, L/H=30`）基线 `-3.055%` → 加入 `(9/2)(c·u)²-(3/2)u²` 项后 `-1.782%`，**变好**；质量漂移 5.04e-14 → 1.12e-05。结论：该平衡态项改变了分布的二阶矩（因此改变数值扩散），能把残差压掉约 1 pp，但**不能消除**：它既不改变 `kH` 截断（本节读数仍在 `kH=0.209`），也不改变随 `Pe`/`H` 变的横向偏差。故策略 (a) 单独使用不足以过 3% 门，只能作为「`k→0` 外推 + `u≤0.05`」之外的增量改进；作为**部分否定**结果入账。

注意：该消融算例的质量漂移 1.12e-05（基线 5.04e-14）——`Σ_i w_i = 1` 的 fp32 归一化残差会乘上 `O(u²)` 项，故它不再是逐位守恒（量级仍 ≪1e-4，不污染结论，但这是该消融的已知代价）。

**均匀流负控**（同幅值 `u=0.0941`、无剪切）：`D_eff/D` = [0.973471, 0.973437]（两个域长 `kH`=[0.4189, 0.2094] 几乎相同），即误差 [-2.6529, -2.6563] %，恰好落在 D2Q5 对流偏差律 `-3u²` 的预言值 -2.66 % 上（均匀流 `⟨u²⟩=u²`），且**与 `kH` 无关**——说明台架无剪切泄漏（否则剪切与负控会一起漂），也说明这 `-2.65%` 是纯晶格 Mach 项，正是 §3.2 标度律的来源。

**校正核的 `k→0` 截距**（`u=0.094`，`Ma=0.163`，域长 [15.0, 30.0, 45.0, 60.0]）：`-2.354%`（判据 ≤3% ⇒ PASS）；逐域长读数 [-2.21, -2.099, -1.782, -0.006]%。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

**5.1 m8228 的归因错在哪**：`nx=128, H=17 ⇒ kH = 2π·17/128 = 0.83`。该前提下模态台读数被 `(kH)²` 截断主导（本单实测同一条件 `+7.03%`），与「Mach 限制」无关。m8228 §5.4 其实已观察到「`nx=64`（`kH≈0.8`）Pe=20 误差 +6.3%、`nx=128` 降到 −0.15%」，但只把它当成 `kx` 敏感，没有推到 `kH` 的定量标度，因而把 Pe=40 的残差错记在 Mach 账上。**教训：任何基于单一波数的模态读数都不能直接当物理量报，必须给 `k→0` 外推。**

**5.2 残留 `O(u²)` 项的量级**：`k→0` 后误差仍是 `u²` 的函数（R² 见 §3.2），在 `u=0.094`（`Ma=0.245`）时约 −3%；`u ≤ 0.05` 时 <1%。工程结论：D2Q5 被动标量做示踪剂弥散，`u_sampled ≲ 0.05` 是安全区；高 Pe 应靠 `Pe = uH/D` 里加大 `H`/减小 `D` 来拿，而不是加流速。

**5.3 模态台的适用域**：要求 (i) `kH ≲ 0.2`（并做 `k→0` 外推），(ii) `t ≳ 6 H²/(π²D)` (横向已弛豫)，(iii) 单模线性响应（`A=1e-2`）。它还要求 `k²D_eff < D(π/H)²`（轴向慢于横向），本单所有算例都因此取 `t_end ≥ 2H²/D`。二阶矩（`σ²`）台在 `Pe ≥ 40` 时要 `L ≳ 33H`、`t ≈ 3H²/D`，代价是本台的 `Pe²` 倍，故高 Pe 段只用模态台。

**5.4 零通量标量壁的实现约定**：死行（`y<0.5`/`y>H+0.5`）恒为零，反射是「本壁自己外流出的分布的精确搬迁」（`g[3,1]=esc_b`, `g[4,H]=esc_t`），`Σg` 逐位守恒；这与 m8228 记为缺陷的「同活行 post-stream 邻点」假汇形式不同。本单每条算例都记 `mass_drift_rel`，实测 ≤1e-12。

**5.5 Sc 扫描为何在 `Pe=10` 做**：`Sc = ν/D`，`Pe = uH/D` 同时钉住时 `u = Pe·ν/(Sc·H)`；`Sc=0.1 ⇒ D=1`，若 `Pe=40` 则需 `H = 800`（`τ_s=3.5` 的扩散算例 + 4 万行域），既不可负担也无意义。故 Sc 无关性在 `Pe=10` 上验（`D_eff/D=1.476`，剪切项仍占 32%），**不得**把本结论引用为「`Pe=40` 下 Sc 无关性已验证」。

**5.6 速度场是解析抛物线**：本单只验标量输运核与测量台；动量解另有 verified 算例（`verified/taylor_aris_dispersion`，D2Q9 耦合）覆盖。因此本单的 Pe=40 数值（+7.03%）与 m8228 的 +8.685% 差值（约 1.7 pp）来自速度场的实现差别，不构成矛盾。

**5.7 集群 LAPACK 风险**：离散 Aris 自带 Thomas 求解并与库内 `numpy.linalg.solve` 交叉校验；若两者相对差 >1e-6 或库残差 >1e-8，算例 JSON 会 `solver_trustworthy=false` 并在 `G5.transverse_aris_solver_flagged` 里登记（本单实际结果见该字段）。
