## 0. 一句话结论

给 TensorLBM 的被动标量（advection–diffusion）核建立了**四条可机器裁决的外部锚**：
Taylor–Aris 剪切弥散闭式在 `Pe ∈ [0.1, 100]` 上误差 **≤ 0.0002%（离散 Aris）/ ≤ 0.666%（时推进
LBM，Pe≤20）**；erf 扩散剖面 **L2 收敛阶 2.001 / 1.994**；`Sc ∈ [0.7, 10]` 的 `D_eff/D` 散布
**1.606%**；离散质量漂移 **2.66e-12**。同时落地三条负面/边界结论：(a) 战役种子把圆管系数
写成 `1/210` 是**勘误**（圆管是 `1/48`，两者本单都验）；(b) 集群 loong64 节点的
`numpy.linalg.solve` 对本类 pin 过的三对角系统**返回垃圾解**（残差 1.9e2 vs 1.1e-12），已用
LAPACK-free 的 Thomas 求解绕开并交叉校验入账；(c) 时推进 LBM 在高 Pe（本设置 40）会因
`O(Ma²)` 晶格误差失效（+8.7%），故高 Pe 段由离散 Aris 参考覆盖。

## 1. 案例介绍（物理背景 / 几何 / 参数）

**物理**：被动标量在剪切流中的长期输运被剪切放大：横向速度梯度把标量拉成细丝、横向扩散
抹平细丝，宏观上沿程扩散系数被放大 `1 + O(Pe²)`。Taylor (1953) / Aris (1956) 对两种经典
几何给出精确的长期等效扩散系数：

| 几何 | 闭式 | Pe 定义 |
|---|---|---|
| 平面缝道（缝高 H） | `D_eff/D = 1 + Pe²/210` | `Pe = U H / D` |
| 圆管（半径 a） | `D_eff/D = 1 + Pe²/48` | `Pe = U a / D`（= `1 + Pe_D²/192`, `Pe_D = 2aU/D`） |

**勘误登记**：战役种子写「`D_eff/D_m = 1 + Pe²/210`（圆管）」。`1/210` 属**平面缝道**；
圆管系数是 `1/48`。本单把两种几何都纳入验证，并在 artifact 的
`criteria.G1.geometry_attribution.campaign_seed_erratum` 中显式登记，避免下游引用错配。

**为什么落 TensorLBM**：标量核本身在库内（D2Q5：`scalar_transport`；D2Q9+零通量壁：
`taylor_aris`），此前只有"形状/守恒/有限值"这类结构性测试与两个分散的弥散算例，**缺失**
的是「扩散截断阶、质量守恒量级、Sc 无关性」这类基础输运属性的可裁决锚。全部物理核复用
库内入口，无手写物理核（唯一自写数值件是 LAPACK-free 三对角求解，见 §5.1）。

**参数表（形式跑，`VerificationSpec()` 默认）**

| 项 | 取值 |
|---|---|
| 几何/格子 | 平面缝道 D2Q9 标量（时推进，`ny=17`, 壁面半程零通量）；1D 平面前沿 D2Q5（erf，`ny=4` 行横向均匀，周期 x） |
| 离散 Aris | 横截面节点 `n=64`（Pe 扫描）/`n=16…256`（网格收敛），间距 1，零通量壁（圆管含 `1/r` 与轴上零通量） |
| 扩散系数 | `D=0.1`（锚/erf）、`D=0.04`（LBM 弥散扫描）、`D=ν/Sc`（Sc 扫描） |
| Pe 扫描 | `{0.1, 1, 5, 20, 50, 100}`（离散 Aris，两几何）+ `{0.1, 2, 5, 20}`（LBM 时推进）+ 探针 `{40}` |
| erf 网格 | `nx = 128/256/512`，`dx = 1/½/¼`，`dt = dx²`（扩散标度），`τ_s = 0.8` 固定，`t = 200` |
| Sc 扫描 | `ν = 0.1`（`τ_f=0.8`），`Sc ∈ {0.7, 1, 2.5, 5, 10}`，`Pe = 3` 固定，`nx = 128`, `ny = 17` |
| dtype / 硬件 | float64 / 集群 loong64 节点（`torch 2.13.0`, `numpy 2.0.1`, 16 线程），wall clock 153.5 s |

## 2. 怎么做的（方法 / 流程 / 关键设置）

**(a) 闭式锚**：`taylor_aris_ratio(pe, geometry)` 直接给出 `D_eff/D`；`taylor_aris_effective_diffusivity`
是同样的有理式乘 `D`，`u=0` 时严格退化为 `D`（有单测）。

**(b) 离散 Aris 辅助问题**（G1 的第一条独立证据线）：解 `D∇²χ = -u'`，壁面零通量，
`D_eff = D + <u'χ>`。

* 缝道：二阶差分 + 两侧奇反射（`χ_{-1}=χ_0`, `χ_n=χ_{n-1}`），pin 末节点消常数零空间。
* 圆管：有限体积柱算子 `(1/r_j)[r_{j+1/2}(χ_{j+1}-χ_j) - r_{j-1/2}(χ_j-χ_{j-1})]/h²`，
  `r_{-1/2}=0`（轴上零通量），`r_{n-1/2}=a`（壁面零通量），面积权重 `r_j` 做截面平均。
* 关键设计：`Pe` 用**节点采样后**的离散平均速度算，而不是施加的连续 `U`——这样残差只剩
  求积/曲率误差，不会把「节点平均 vs 连续平均」的记账差误判成物理误差。

**(c) 时推进 LBM**（G1 第二条证据线）：`taylor_aris.simulate_channel_dispersion`（`method="mode"`）。
释放 `φ = 1 + A cos(kx)`，跟踪截面平均场的基频幅值衰减率 → `D_eff`；`steps = 4h²/D`，
拟合窗 `t ≥ max(3h²/D, 0.2 t_end)`，幅值重归一化避免幅值先撞舍入地板。选模态法而非二阶矩法
是因为单模态在周期域内无域长/混叠偏置，短盒即够。

**(d) erf 前沿**（G2）：1D 半空间阶跃（`C=1 (x<x0)`, `0 (x>x0)`）在周期域上用 D2Q5 核推进，
与 `0.5·erfc((x-x0)/√(4Dt))` 比 L2。**网格加密必须用扩散标度 `dt ∝ dx²`**：固定 `τ_s`
⇒ 晶格扩散系数恒定，截断误差 `O(dx²)+O(dt)=O(dx²)`；若用声学标度（`dt ∝ dx`），`O(dt)`
项会把观测阶压到 1。误差只在 `|x-x0| ≤ 3√(4Dt)` 内统计（周期镜像 <1e-19）。

**(e) Sc 无关性**（G3）：`ν` 由伴随水力松弛钉住（`τ_f=0.8 → ν=0.1`），`D = ν/Sc`；同时把
施加流速按 `u_mean = Pe·D/H` 缩放 → **无量纲问题完全相同**，唯一变化的是标量松弛时间
`τ_d = 3D+0.5`（`0.53 … 0.93`）。任何 `D_eff/D` 的散布都是 `τ_d` 相关的数值伪扩散，即
Schmidt 无关性的数值形式。另设**分辨率对照**（最差档 Sc=0.7 在 `ny=33` 重跑）判定残差归属。

## 5. 注意点（踩过的坑 / 局限 / 适用域）

**5.1 集群 loong64 的 `numpy.linalg.solve` 返回垃圾解（真实平台缺陷）**
首轮形式跑在离散 Aris 段就炸了：`n=16/32` 正常，`n≥64` 误差 +19% / +51285% / +2.9e7%。
同矩阵直接体检：`numpy.linalg.solve` 残差 **1.87e2（n=64）/ 1.17e6（n=128）**，
`scipy.linalg.solve` 同矩阵残差 **1.1e-12**，两者解相差 O(1e2–1e6)；本机（x86, numpy 2.4.6）
同一系统残差 3.8e-13。结论：**该节点 LAPACK（openblas 0.3.27.dev/LOONGSON3R5）对本类 pin 过
的、条件数 ~n² 的三对角系统不可信**，与我的物理无关。处理：验证面自带 O(n) Thomas 三对角求解
（LAPACK-free、确定性、跨平台），并保留库内 `aris_dispersion_coefficient` 的解作为
`library_cross_check`（`trustworthy=false` 即触发告警）。**这条对全仓所有在集群上跑
`numpy.linalg.solve` 的算例都是风险**，建议后续普查。

**5.2 erf 前沿的周期镜像（第一版全错的原因）** 初版用 `nx=64, t=200`：三档 L2 误差都是
5.8e-2，阶≈0。原因是 `3√(4Dt)=26.8` 已贴到半域宽 32，窗口边缘经周期性折回只相距 10.2 个格
（<扩散长度），镜像污染成为主误差项。改成半域宽 64（`nx=128` 起，物理域长 128）后立刻回到
二阶。

**5.3 Pe 上限是晶格 Mach 限制，不是物理限制** 时推进 LBM 需 `|u| < 0.1` 且 `t ≫ h²/D`，
两者结合把本设置的可用 Pe 压到约 20–30。Pe=40（`u=0.094`）实测 +8.7%，误差方向与量级符合
`O(Ma²)` 晶格误差，故作为**失效探针**保留在 artifact 里（`role=resolution_limit_probe`），
明确不计入 G1。高 Pe 端由离散 Aris 参考覆盖（它不含时间推进，因此无 Mach 限制）。

**5.4 模态法对 `kh` 敏感** `nx=64`（`kh≈0.8`）时 Pe=20 误差 +6.3%；`nx=128`（`kh≈0.42`）降到
−0.15%，`nx=256` 与 128 一致。所以形参 `lbm_nx=128` 是精度下限而非随手值，快速冒烟用 64
时该门**必然不过**（`--smoke` 只验管线）。

**5.5 低 Pe 端的 0.45% 负偏差** `Pe=0.1` 时 `D_eff/D` 应等于 1.000048，实测 0.995516——纯扩散
情形下 `D_eff` 略小于分子 `D`，说明该测量台（模态衰减率 / k²）存在约 0.4% 的系统负偏置
（"rate 由下方趋近"）。对 3% 门无碍，但**不能用它去测 0.1% 量级的效应**。G3 的 1.8% 残差与此
同源（见 3.3 的分辨率对照）。

**局限（与 artifact `limitations` 一致）**
1. **圆管没有时推进 LBM 实跑**：库内标量核是笛卡尔的，缺少轴对称源项 `(1/r)∂_r(r∂_rφ)`，
   圆管锚由离散柱 Aris 解 + 闭式承担（离散解本身已 O(h²) 收敛到 `1/48`）。要做真管，需新增
   轴对称标量核——明确列为后续工作，不假装已做。
2. **速度场是解析抛物线**：LBM 段只验标量核；动量解另有 verified 算例覆盖。
3. **Sc 只通过 `τ_d` 进入离散问题**（`τ_f` 固定），未做 `τ_f` 联动的全耦合 Sc 研究。
4. `D_eff` 是**长期渐近**量：所有 LBM 拟合窗都在 `t ≥ 3h²/D` 之后；短时行为不在本验证面范围。
