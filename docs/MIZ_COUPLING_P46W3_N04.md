# MIZ 船舶阻力与耐波性耦合模型（P46W3-N04）

> 节点：**P46W3-N04 | 边际冰区(MIZ)船舶阻力与耐波性耦合** · 仓：TensorLBM
> 模块：`src/tensorlbm/miz_resistance.py`、`src/tensorlbm/miz_seakeeping.py`
> 基准：`benchmarks/miz_coupling/` · 测试：`tests/test_miz_resistance_seakeeping.py`（33 项）
> 上游依赖：node 61（flexural-gravity dispersion）、node 34（broken ice RAO）——
> 本节点在其上补齐「波浪衰减 → 破碎粒径谱 → 阻力叠加 → 6-DOF 运动」的闭链与能量审计。

## 1. 案例介绍（物理背景 / 几何 / 参数）

边际冰区（MIZ）是敞水与连续冰盖之间的过渡带，特征为离散浮冰（floe）浓度
`C_floe` 由冰缘向内递减。船舶在此环境中同时受三种载荷：波浪、浮冰、以及二者
的耦合（波浪被冰吸收/散射后衰减；波浪弯曲应力超冰强度时把冰盖破碎成特征尺度
`a_floe` 的浮冰；浮冰的存在改变船体附加质量与阻尼）。本节点建立系统级（非 CFD/DEM
分辨率级）半解析耦合模型，用于方案设计与参数研究。

## 2. 怎么做的（方法 / 流程 / 工具链）

四个物理环节全部闭式、无随机数、无查表：

1. **挠性重力波色散**（node 61）
   `ω² = (g k + D k⁵/ρ_w)·tanh(k d)`，`D = E h³/(12(1-ν²))`，Newton 迭代求解 k；
   深水/有限水深均支持；`h → 0` 精确退化为 `ω² = g k tanh(kd)`
   （验收：相对误差 0）。
2. **波浪衰减**（判据 a）
   每块浮冰 Rayleigh 散射截面 `σ_s = (2/3)(ka)⁴a`，数密度 `n = C/(γ a²)`（γ = π/4），
   得 `α_scat = n σ_s/2 = C (ka)⁴/(3 γ a)`；耗散支 `α_diss = β C α_scat`，β = 0.05。
   `E(x) = E_0 exp(-2αx)`。
3. **破碎与粒径谱**（判据 b）
   薄板弯曲应力 `σ_b = E h A k²/(2(1-ν²))`；`σ_b ≥ σ_f` 时冰破碎。破碎粒径取
   `a_floe = max(ℓ_b, μ·λ)`，`μ = 0.1 (σ_b/σ_f)^{-1/5}`，
   弯曲长度 `ℓ_b = (D/(ρ_w g))^{1/4}` 是硬下界（小于 ℓ_b 的浮冰随波刚体运动、不再
   弯断）。P(a) 由谱逐带（96 bands，只保留 σ_b ≥ σ_f 的带）按能量加权合成。
4. **阻力与运动**
   - `R_ow`：ITTC-57 摩擦线 + 形状因子 1.15 + 附体 1.05；
   - `R_wave`：`0.5 ρ g Hs² B c_aw`，`c_aw = 0.13 kB/(1+0.2kB) + 0.35 Fr²`；
   - `R_ice`（Lindqvist 型破碎冰）：断裂能×遭遇率 `C B π σ_f² h³/(2 E γ a)`
     + 浸没 `C(1+0.021ψ)(ρ_w-ρ_ice) g h B T` + 摩擦 `μ C ρ_ice g h A_contact`；
   - 耦合项：①船位处衰减后波高 `Hs_eff = Hs e^{-α x_ship}`；②本地破碎一致粒径；
     ③浮冰轨道速度改变相对撞击速度 `(1+u_ice²/2V²)`；④夹带浮冰附加质量反馈
     `R_wave ×(1+κ k_a C)`，κ = 0.5，k_a = 0.30；
   - 运动：三单自由度（heave/pitch/roll）频域解
     `RAO = F/(C-(I+A)ω²+iBω)`，冰附加质量 `A(1+k_a C)`、冰阻尼
     `B(1+k_b C√(a h))`（k_b = 1.0）、冰恢复力 `C(1+k_c C h/T)`。

补充量（非判据，但为物理可信度证据）：

- α 量级 2.46e-4 – 5.4e-3 m⁻¹，落在 MIZ 现场观测 1e-3–1e-2 m⁻¹ 区间内。
- 谱导出 P(a)：38 个破碎带，ā = 9.04 m，λ_peak = 106.8 m，ā/λ = 0.0847。
- R_ow(100 m, 10 kn) = 72.3 kN；R_ice(C=0.5, h=0.5, a=8.69 m) = 56.3 kN
  （断裂 14.4 / 浸没 51.8 / 摩擦 4.5 kN）；R_total ≈ 141 kN。
- 冰阻尼使纵摇峰值 RAO 由 0.0829 降至 0.0527 rad/m（−36 %），heave 1.062 → 0.992 m/m。
- 有义横摇 1.99°（敞水）→ 1.86°（MIZ, C=0.5）。
- **朴素叠加**（船位用冰缘波高、忽略衰减）相对误差最大 **45.5 %**——这量化了把
  `Hs` 当作空间常数时叠加法的失效边界（判据 c 因此要求"C×耦合一致"的叠加口径）。

## 4. 注意点（坑 / 局限 / 适用域）

1. **扭转点：船不是冰区耗散的一部分。** 初版把船体横摇阻尼功率直接当作冰区波场
   的汇，导致 P_ship ≈ 2–5 倍入射功率、残差符号乱跳。物理上船从**透射流**取能，
   账本必须记作 "P_trans_net = P_trans − P_ship"（代数上与把它列为独立汇等价，
   但符号物理）。改后残差稳定 ≤ 2 %。
2. **量纲一致性坑（横摇 RAO）**：先把 RAO 归一化到波陡（rad/rad）又乘波高谱
   `S_zeta(m²s)`，等价于多乘/少乘 `(0.85k)²`，使横摇响应急剧放大 300 倍，
   P_ship 虚高。现统一为 **rad per m 波幅**（RAO²·S_ζ 直接是响应谱）。
3. **共振窄峰的数值积分**：横摇响应谱在 ζ = 0.08 时带宽 ~2ζω_n，粗网格
   （Δω ≈ 0.02）会高估积分 20 倍；响应谱用 3000 点网格。
4. **消能分配的可信度最低**：α 的散射/耗散拆分（β）是模型中最弱的环节。
   `mech_over_diss = (拖曳+破碎)/(耗散份额)` 在 C ≤ 0.3 时达 1.5–4.9（> 1 表示
   机械汇超过耗散份额），C ≥ 0.5 时 0.49–0.96。说明常数 β 无法在低浓度端同时
   满足"耗散份额足够供能"，需要浓度依赖的 β 或显式碰撞耗散模型。**这是本节点的
   已知局限，如实登记**（不影响 (e) 的总账闭合，因为该三项本身占 P_in 的极小部分）。
5. **冰厚对 floe 尺度的非单调性**：ℓ_b ∝ h^{3/4} 上升，而 σ_b ∝ h 上升使 μ 下降；
   浅海薄冰段（ℓ_b 主导）a 随 h 增，长波厚冰段（μ 主导）a 随 h 减。已在测试中
   只断言模型在该参数域内成立的趋势，并保留 ℓ_b 硬下界不变式。
6. **线性化假设**：无 3D 辐射/衍射求解器；横摇阻尼为经验临界阻尼比（敞水 8 %）；
   heave/pitch/roll 解耦；无速度损失自洽求解（否则叠加判据不适用，速度损失另属
   破冰航速课题）。非线性横摇阻尼、参数横摇、冰-船碰撞冲量过程均未覆盖。

## 5. 误差判定（逐项，显式回答是否 < 3 %）

| 量 | 基准 | 误差 | < 3 % ? |
|---|---|---|---|
| 色散 h→0 极限 k | 解析 g k = ω² | 0（1e-16 量级） | 是 |
| 群速度 cg | 数值 dω/dk | < 1e-9 相对 | 是 |
| 指数衰减斜率 | −2α 解析 | 1.9e-15 相对 | 是 |
| ITTC-57 Cf(Re=1e9) | 1.536e-3 | 0.35 % | 是 |
| 能量账本闭合 | 入射功率 | ≤ 2.05 %（18 组，最大） | 是 |
| 叠加 vs 耦合 | 耦合模型 | ≤ 2.01 %（60 组，最大） | 是 |
| 衰减 α 绝对值 | MIZ 现场观测 1e-3–1e-2 m⁻¹ | 量级一致（无同条件实测谱，不能给百分比） | **否（声明原因：无同条件实测基准）** |
| floe 尺度 a/λ | Squire 窗 [0.05, 0.2] | 窗内，无单点基准 | **否（声明原因：Squire 给的是窗口而非单值）** |
| 横摇 RAO 降幅 | 文献 30–50 %（Kiviranta & Matusiak 2010） | 本模型 23–76 %，参考态 51 % | **否（声明原因：文献为条件相关区间）** |

结论：模型内部一致性（解析极限、守恒、叠加一致性）达到 < 3 % 级；绝对精度受限于
MIZ 现场/模型试验基准数据的可得性，只能做到量级/区间一致，已在表中显式标注。
