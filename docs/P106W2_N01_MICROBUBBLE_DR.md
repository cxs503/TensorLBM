## 1. 案例介绍（物理背景 / 几何 / 参数）

微气泡减阻（microbubble drag reduction, MDR）的工程图景：船底湍流边界层内注入微气泡（直径 d⁺ = 10~100 壁面单位），
气泡受浮力压向船底板，形成低黏度气液混合层，使壁面摩擦阻力下降。文献把总减阻拆成三项机理：

| 机理 | 物理内容 | 本实现的观测量 |
|---|---|---|
| 滑移（slip） | 气液相对滑移 / 界面应力承担部分动量输运 | 界面+漂移应力残差 τ_b(y) = μ_m du/dy − ρ⟨u′v′⟩ − τ(y) |
| 湍流调制（turbulence modulation） | 气泡抑制雷诺切应力、改变 ⟨u′v′⟩ 剖面 | 实测 −ρ⟨u′v′⟩ 剖面积分 |
| 有效黏度（viscosity） | 混合黏度 μ_m = ρν（气相密度低 ⇒ 低黏度）重分布速度梯度 | 实测 r = μ_ref/μ(y) 场 |

几何：平面槽道，`x` 流向周期、`z` 展向周期、`y` 上下两壁半程反弹（half-way bounce-back）。
**船底板 = y=0 底壁**（真实船底朝下、气泡被浮力压在板上），浮力项 F_y = (ρ_l − ρ)·g_b，g_b < 0 把气推向 y=0；
上壁为对照壁。驱动是**单位体积均匀体力** F0（不是单位质量），因此平均总应力剖面与密度分布无关，
`τ_bottom + |τ_top| = F0·H` **恒成立**——这是两相壁面剪切可审计的根基。

参数（格子单位，程序化注入 `tensorlbm.microbubble_dr.campaign.base_config()`）：

| 参数 | 值 | 说明 |
|---|---|---|
| 单相槽道 | nx=56, ny=40, nz=24（5.4×10^4 格点） | Lx⁺≈504, Lz⁺≈216, Δy⁺≈9 |
| Re_tau 目标 | 180 | ν = u_tau·h/Re_tau = 6.67e-4 ⇒ τ = 0.502 |
| U_b 目标（控制器锁定） | 0.108（= 18 u_tau，u_tau = 0.006） | 格子 Mach 0.187 |
| 两相模型 | D3Q19 Shan-Chen 单组分，ψ = 1 − e^(−ρ)，G = 4.3 | 实测共存密度 ρ_l≈1.31~1.42, ρ_g≈0.27（比 4.7~5.3） |
| 碰撞 | TRT（ω₊ = 1/τ 定黏度，ω₋ = 1 抑界面临界模） | 单 τ 无法在 τ→1/2 生存 |
| 气泡 | 球状 d = d⁺ν/u_tau，置于 y≈0 壁面带 | d⁺=60 ⇒ 6.7 格（勉强可分辨） |
| 工况组 | 基线 / 负控（α→0）/ α∈{0.3,1,3}% / d⁺∈{60,120,180} | 共 7 例 |

## 2. 怎么做的（方法 / 工具链）

新增领域模块 `src/tensorlbm/microbubble_dr/`（本节点新建，无既有实现可复用）：

| 文件 | 建立的能力 |
|---|---|
| `kernel.py` | D3Q19 槽道核：半程反弹壁、周期 x/z、Guo 力、TRT 碰撞（Guo 源项**按对称/反对称拆分**，保证碰撞后动量严格等于 ρu+F）、Shan-Chen 伪势自作用力（镜像中性润湿壁）、Ladd 动量交换测壁面剪切 |
| `fik.py` | 广义 **FIK 恒等式**（变黏度 + 变体力通道）：由实测平均剖面反解壁面剪切 C = (μ_ref U_b + F0 j₂ + num_re + num_bub)/j₁，并**伸缩式**分解三项机理（每步只加一项实测机理），另给出 u_tau 三口径（壁面速度梯度 / 雷诺应力拟合 / 总动量输入）自洽性 |
| `channel.py` | 工况跑批：积分控制器把体积平均速度锁到 U_b（同流量对比）、时间+x+z 三重平均统计、α 场（按实测共存密度归一）、质量/α 积分守恒记账、实测 Re_tau |
| `campaign.py` | 战役驱动：`--probe / --only / --merge`，落 JSON + 图，判据数值写进 `campaign.json` |

**机理分离的数学骨架**（论文级，可复算）：取 τ(y) = C − F0 y，u(y) = ∫₀^y (τ + ρ⟨u′v′⟩ + τ_b)/μ dy′，
分部积分得

```
U_b = (1/H)∫₀^H (H−y)(τ + ρ⟨u′v′⟩ + τ_b)/μ dy
⇒ C = (μ_ref U_b + F0 j₂ + num_re + num_bub)/j₁
   j₁ = (1/H)∫(H−y) r dy,  j₂ = (1/H)∫ y(H−y) r dy,  r = μ_ref/μ(y)
```

层流校核：num_re = num_bub = 0, r = 1 ⇒ C = 2μU_b/H + F0H/3 = F0H/2（解析值）——**公式自带量纲与符号自检**。
机理项按 ΔC_f = C_f0 − C_f 符号约定取负增量，三项之和与总减阻**代数恒等**（残差 0），
而**实质校验**是 FIK 反解的 C 与独立测得的动量交换 C_MEM 相互印证。

工具链：本地开发 + 外协方双节点 loong64 集群（`run_cluster`，stage_dir 直送工作树）。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **LBM 的 Re_tau=180 与两相不可兼得（本节点核心发现）**：Re_tau 固定时 ν = u_tau h/Re_tau ∝ u_tau/Re_tau，
   要让 τ 离开 0.5 必须加 h。实测：Shan-Chen 界面在 τ−1/2 ≲ 2.5e-3 发散（G=4.5），单相 TRT 在 τ−1/2 = 2e-3 也发散。
   取 ν ≥ 3.3e-3（τ = 0.51）且 Ma ≤ 0.19（u_tau = 0.006）⇒ h = 99 ⇒ ny=198、Lx=396、Lz=150 ≈ **1.18×10^7 格点**，
   按实测核吞吐 ~1.5 MLUPS 需 ~7.8 s/步，20 个涡翻转（3.3×10^5 步）≈ **715 小时**单核批——超出本节点预算两个量级。
2. **尺度不可分辨的微气泡**：Δy⁺=9 时 d⁺=60 只有 6.7 格、d⁺=20 只有 2.2 格（< 界面厚度）。真实微气泡 d⁺=10~50
   在本分辨率下**不可分辨**，d⁺ 扫描只能覆盖 60~180，且 d⁺ 与 α 受域体积量化耦合（一个气泡的 α = πd³/6 / V），
   故 d⁺ 扫描按"等气泡个数"设计并在报告里给出实得 α。
3. **α 不是自由输入**：两相共存下 α 由杠杆定律（总质量 + 共存密度）决定，播种 α 只是初值；本文一律报**实测** α 积分。
4. **loong64 环境缺陷**：两相路径上出现原生堆错误，与 OPP gather / BLAS 路径相关；已改为逐元素实现，
   仍偶发（单相路径未出现）。这是**平台缺陷**，建议后续用 TRT-regularized 或新的 gather 实现复测。
5. **FIK 的 O(1/H) 壁面偏置**：半程反弹壁位置在首节点外半格，使 FIK 反解在 H=16/32 偏高 6 %/3 %，
   生产 H=40 时 <2 %；若需 <1 % 应改用插值反弹或把壁面位置做几何修正。

## 6. 误差判定（逐项回答"是否 < 3%"）

| 判据 | 阈值 | 实测 | 是否达标 |
|---|---|---|---|
| 层流 U_b vs 解析 | ≤ 3 % | −0.04 % | **是** |
| 动量交换 τ_w vs 解析 | ≤ 3 % | < 0.01 % | **是** |
| FIK 反解 τ_w vs 解析（H=32） | ≤ 3 % | +3.0 % | **临界**（O(1/H) 壁面偏置，见 5.5） |
| FIK 三机理之和 vs 总减阻 | ≤ 3 % | 0（代数恒等）+ 实质校验待两相数据 | 恒等成立，**实质项 WITHHELD** |
| u_tau 三口径自洽（两相湍流） | ≤ 2 % | 层流控制上一致性 < 0.01 %；湍流两相无数据 | **WITHHELD** |
| 气泡 α 积分守恒 | ≤ 1 % | 单相 1.4e-5；两相无统计窗 | **WITHHELD** |
| 负控 ΔC_f→0 | ≤ 0.5 % | 恒等测试 −2.2e-8（机器精度）；实验负控无数据 | 恒等成立，**实验 WITHHELD** |
| 与 DNS/实验对标（Re_tau=180 两相） | ≤ 15 % | 无 | **WITHHELD**（缺：可运行的两相湍流解；需 DNS/实验的 ΔC_f(α, d⁺, Re) 与相分布数据） |

**翻 REAL 所需数据**：(a) 一个稳定可统计的 Re_tau≥180 两相通道解（需 1.2×10^7 格点或 GPU 级吞吐）；
(b) 实验/文献的微气泡减阻基准 ΔC_f(α, d⁺)（如 Madavan 1984、Merkle & Deutsch 1992 的平板数据）与壁面 α 分布、气泡尺寸谱；
(c) 若要分离"滑移"机理到壁面滑移长度口径，还需壁面滑移边界层剖面（PIV/LDA）。
