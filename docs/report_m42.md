## 1. 案例介绍

### 物理背景

均匀来流绕球（Re = 100）是经典低雷诺数验证基准。在 Re=100 时，球尾迹为稳态轴对称环流，阻力系数 Cd 有成熟的经验关联式可供对比。本案例是 `verified/sphere_re100`（D3Q19 + MRT）的 **D3Q27 孪生版本**，用于验证高速度离散模板在弯曲边界（BFL sparse link）下的精度与一致性。

- **脚本**: `scripts/sdaa_sweep_sphere_re100_d3q27.py`（独立运行脚本，不改业务代码）

### 流程

1. 参考值 cd_ref = 1.0917311 从已验证 D3Q19 归档中 sha256-pinned 提取，运行前锁定
2. 在 SDAA 设备上以 D8/D16 两个降分辨率层级运行 D3Q27/BFL 完整链路
3. 采集力历史，取最后 20% 窗口计算 Cd_window
4. 逐门（G1 精度 / G2 单调 / G3 健康 / 环境）判定

- 碰撞：BGK27（库中无低内存 MRT27，已在 prereg.md 中提前披露）
- 5 个热核函数使用就地镜像实现（`torch.equal` 验证与库原版一致）
- 活集上限 3 个 full (27,N) 场，使 D60 可装入 32 GB 卡

## 5. 注意点

### 踩过的坑

1. **窗口统计样本稀薄**：D8 仅 n=5、D16 仅 n=6 个样本（力采样间隔 50 步，窗口 = 20% 步数），统计意义有限
2. **未覆盖对流时间**：步数 < 1 个对流时间/层级，0.8–1.0 窗口仍处于瞬态阶段——这是 drift 和 CV closure 失败的直接原因
3. **设备共享**：SDAA 卡 `/dev/tcaicard27` 有多个 tensorlbm 进程驻留，D16 阶段 per-step 成本退化 2.5×，导致超预算 82%
4. **降分辨率 ≠ 归档质量**：D8/D16（175K/1.59M 单元）与归档（25.1M/84.7M 单元）差距巨大，SDAA 扫荡测量的是小尺度下的端口正确性，不是归档级精度

### 局限性

- 未能在 SDAA 上复现归档全分辨率（受 20 分钟预算和共享卡限制）
- 无 MRT27 低内存实现，碰撞选用 BGK27（已提前披露，影响 < 0.02%）
- 无场量 npz 输出，无法生成云图

### 适用范围

- 本扫荡证明 SDAA 端口可运行真实 D3Q27/BFL 链路
- 归档 PASS 结论不受影响（归档运行在专用卡上，非本次扫荡）
- 若需在 SDAA 上达到归档精度，需独占卡 + 更长时间预算

### 显式回答

- **归档全分辨率**: Cd 误差 2.79%/2.57%，**均 < 3%** ✅
- **SDAA 降分辨率扫荡**: Cd 误差 13.72%/7.74%，**均 > 3%** ❌
- **原因**: 降分辨率 + 步数不足导致流场未充分发展至稳态，Cd 仍在弛豫中
- **G2 单调性通过**: 误差随分辨率严格递减（13.72% → 7.74%），表明网格收敛方向正确
- **无基准声明原因**: 不适用——基准 cd_ref = 1.0917（Schiller-Naumann）已明确声明并 sha256-pinned
