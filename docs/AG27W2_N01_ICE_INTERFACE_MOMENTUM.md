## 1. 案例介绍

### 1.1 物理背景与三条力学事实

Ladd 动量交换法（MEM, Ladd 1994）是格子 Boltzmann 方法测量壁面受力的标准工具：对每条流体→固体
连接，力为 $2 c_q f_q$（$c_q$ 指向壁面）。IN37-N05 在层冰通道（$D=12$ 方块阻塞，$Re=20$）上发现，
同一估计量在**直通道壁面**上精确到 $<10^{-3}$，而在**冰面**上只能复现全局动量收支的约 50 %。

1. **离散交换恒等式.** 闭合槽位 $(x,k)$（x 的上游 $x-c_k$ 为冰）上，一步内流体获得的质量与动量严格为
   $\Delta m=f_{\mathrm{new},k}(x)-f_{\mathrm{post},\bar k}(x)$、
   $\Delta p=c_k(f_{\mathrm{new},k}(x)+f_{\mathrm{post},\bar k}(x))$。
   静止半程反弹给出 $\Delta m\equiv 0$ 并退化为经典 Ladd 形式；移动界面给出
   $\Delta m=2w_q\rho(c_q\cdot u_w)/c_s^2\ne 0$（界面质量通量）。
2. **不变性缺陷.** 静态 Ladd 公式丢掉移动界面项，其相对大小在格点单位下为
   $2w\rho(c\cdot u_w)/c_s^2$ 比 $2w\rho$，即 $|u_w|/c_s^2=3|u_w|$；对冰速 0.03–0.17 即
   **9 %–51 %**，与 IN37-N05 的「约 50 %」同量级。
3. **几何缺陷.** 台阶闭合把每条被阻连接一律记为完全浸润（$\chi=1$），抹掉亚格点壁面位置；
   亚格点浸润因子 $\chi$（连接段落在冰内的长度比）与 Ladd 浸润权重 $w=\mathrm{clip}(2\chi,0,1)$
   把这一信息还给格式（$w=1$ 即台阶极限）。

## 2. 方法

1. **亚格点浸润因子** `subgrid_wetted_fraction(iface, nx, ny)`：解析 level set（半平面 / 圆盘）给出符号
   距离；逐格水体积分数 `alpha`（中点求积）；逐连接 `chi[k]`（连接段落在冰内的长度比）；`w=clip(2 chi,0,1)`。
2. **界面质量通量记账** `InterfaceMassFlux`：每步按闭合槽位累计 $\Delta m$、$\Delta p$、
   $r\times\Delta p$（角动量）、$\Delta p\cdot u_w$（壁面对水做功），并单独给出注入动量的对流估计。
3. **四级守恒判据门** `ConservationGates`，每一级都用两条独立路径（连接级台账 vs 宏观量体积分）对比：
   - C1 质量：$\Delta M_{\mathrm{vol}}=\int \dot m\,dt$，容差 $10^{-10}$；
   - C2 动量：$\Delta P_{\mathrm{vol}}=\sum\rho g\,dt+\int\dot p\,dt$，容差 $10^{-9}$；
   - C3 角动量：$\Delta L_z=$ 外力矩冲量 + 界面角动量流 + $x$-周期缝输运，容差 $10^{-9}$；
   - C4 能量：用格点能量线性泛函 $E=\sum_q f_q|c_q|^2/2$ 写严格收支
     $\Delta E_{\mathrm{lat}}=e_{\mathrm{src}}+e_{\mathrm{closure}}-e_{\mathrm{coll}}$，容差 1 %，
     并另报物理量 $\Delta KE=W_{\mathrm{ext}}+W_{\mathrm{wall}}-D$ 的残差（$D$ 取 BGK 熵产生）。
4. **执行台** `IceInterfaceChannel`：D2Q9 + Guo 力 + BFL 亚格点反弹（$q$ 由 level set 给出），
   移动界面加 Ladd 速度项；缺陷开关 `subgrid=False` / `moving_term=False` / `corner_links=False`
   用于复现候选成因。
5. **工具链**：numpy + pytest + matplotlib；`steps_scale=0.5` 全套约 2 min 单机可复现。

## 5. 注意点（踩坑 / 局限 / 适用范围）

1. **「约 50 %」不是单一原因.** 对既有 `ice_resistance_factor` 的复算显示，该估计量在 $D=12$ 上
   2500 步时收支比 0.40（≈历史「50 %」），18000 步收敛到 **1.0000**：历史数字属
   **未到稳态 + 忽略存储项**。同时**移动界面项缺失**与**亚格点壁面位置抹平**都能独立制造同量级
   确定性亏空（§3.3 H2/H3），三者叠加可解释历史观测。
2. **C3 在移动界面算例 honest FAIL**（残差 6.89e-01）。原因已定位：$x$-周期缝的角动量输运项目前
   只按内点流项推导，移动界面质量注入在缝处的那部分未入账；静止算例 C3 闭合到 4.82e-14，
   说明台账本身正确、缺的是缝上的移动项。**不粉饰：该级判据在移动算例上未通过。**
3. **移动项下受力仍超解析值 35.474 %**（速度剖面 RMS 仅 0.003 %）。这是 Ladd 移动壁面闭合的
   一阶 $O(u_w)$ 系统偏差（$\delta f=2w\rho(c\cdot u_w)/c_s^2$ 在亚格点插值下未按 BFL 权重同步缩放），
   已登记为后继靶子，**不宣称 3 % 达标**。
4. **体积分项固有偏差**：Poiseuille 壁面力对物理基准 1.250 % 的残差主要来自台阶体积量子化
   （体力作用在整格：$n_{\mathrm{open}}=288$ 行 vs 真实 $A=17.259999999999998$），与闭合无关；
   判定改进应看 $u(y)$ RMS 与对 $g\,n_{\mathrm{open}}$ 的收支比。
5. **适用范围**：二维 D2Q9、静止/匀速移动刚性冰面、低 Mach（$u\le0.17$）；不含相变与冰体弹性。
   相变场景下 $\dot m$ 不再自消，需把账本质量项接到冰相质量上。
