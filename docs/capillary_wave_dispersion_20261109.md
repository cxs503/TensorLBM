# 毛细波色散验证：CAC 相场 LBM 的动/静态表面张力一致性（2026-11-09）

> 结论先行（honest FAIL）：`tensorlbm.cac_lbm` 的 `sigma` 输入参数**没有通过 15% 验收线**——
> 静态（界面能量积分）偏高 **+30.3%**，动态（毛细波频率）偏低 **-18.7%**（k=0.196）/ **-27.2%**（k=0.295），
> 振幅衰减率只达 `2 ν k²` 的 **0.58 倍**。因此 CAC 的自由面/毛细动力学在本平台精度标准下仍是**未验证能力**，
> 本报告把它登记为一条可复现的验证欠账，并交付测量工具链（模块 + 工具 + 测试），而非把它包装成"通过"。

---

## 1. 案例介绍（物理背景 / 几何 / 参数）

### 1.1 为什么验这一项

`tensorlbm.cac_lbm`（保守 Allen–Cahn 相场 + He-Luo 压力型双分布，D3Q19）把表面张力当作**输入参数**：

```
beta = 12 sigma / W ,   k = 1.5 sigma W          (Liang et al., PRE 97, 033309, Eq.7)
```

静态算例（液滴 Laplace 压差、平面界面 tanh 剖面）只能证明**静态** Korteweg 应力与这个参数自洽；
而船海自由面（兴波、气泡/液滴、气层减阻、冰水界面）靠的是同一个系数的**动态响应**：
若界面对曲率扰动的响应频率错了，即使所有静态基准全绿，自由面力链依然是错的。
这就是本次补的验证台阶：**驻立毛细波**。

### 1.2 物理基准（精确解，非拟合）

两层等密度流体界面、无重力、小幅驻波（Kelvin 1871；Landau & Lifshitz《流体力学》§62）：

```
omega^2 = sigma k^3 / (rho_l + rho_g)                            (1)  色散
gamma   = 2 nu k^2                                               (2)  界面振幅黏性衰减率
```

`(1)(2)` 都是闭式解析结果，参数只来自模型输入（`sigma`、`nu`、`rho_l`、`rho_g`），**没有任何可调量**，
因此这是一次真正的盲预测检验，而不是"拿模拟拟合模拟"。

### 1.3 几何与参数表

| 项 | 取值 | 说明 |
|---|---|---|
| 求解器 | `tensorlbm.cac_lbm.CACSim` | CAC 相场，D3Q19，fp32 |
| 计算域 | `nz=2, ny=32, nx=64`，`axes="ppp"` | 三向全周期（准二维，z 向均匀） |
| 界面 | `phi = 0.5 + 0.5 tanh(2 (y_i(x) - y)/W)`，`y_i = ny/2 + A cos(kx)` | 驻波初值，单界面 |
| 波数 | `k = 2 pi m / nx`，m=2 → k=0.1963；m=3 → k=0.2945 | 深水条件 `k d ≈ 3.1 / 4.7`（层厚 d=16） |
| 振幅 | `A = 0.5`（`A k = 0.098`），对照 `A = 0.25` | 线性区 |
| 表面张力输入 | `sigma = 0.05` | |
| 运动黏度 | `nu = mu/rho = 0.05`（对照 0.03） | `tau_g = 0.5 + 3 mu/rho` |
| AC 迁移率 | `M = 0.05`（对照 0.02 / 0.20） | 只影响相场方程松弛，理论上不应进入 `omega` |
| 界面宽度 | `W = 4`（扫描 2 / 3 / 6） | `k W = 0.79` |
| 步数 | 2500–3000，每 10 步采样界面高度 | 覆盖 4–8 个波周期 |

## 2. 怎么做的（方法 / 流程 / 工具链）

1. **测量链**（新模块 `src/tensorlbm/capillary_wave.py`）
   - `perturbed_layer_phi`：构造被扰动的分层界面初值；
   - `interface_height`：把相场 `phi` 转成每列高度 `h(x,t)`（在 `phi=0.5` 处线性插值定位）；
   - `modal_amplitude`：投影到 `cos(kx)` 模态，得 `a(t)`；
   - `damped_sinusoid_fit`：把 `a(t) ≈ e^{-gamma t}(C cos omega t + S sin omega t)`
     在 `(omega, gamma)` 上做变投影最小二乘（粗网格 + 逐级细化），返回 `omega / gamma / R²`；
   - `run_capillary_wave`：跑一次驻波并给出 `omega_meas`、`gamma_meas`、`(1)(2)` 理论值、
     `sigma_eff = omega_meas² (rho_l+rho_g)/k³`。
2. **静态标定两条独立路线**
   - 平面界面能量积分：`sigma = k_coef ∫ (dphi/dn)² dn`（`k_coef = 1.5 sigma W`）。
     只在**内部行**做中心差分——周期回绕行对 `phi` 差 ~1，若含进去会把积分抬高 3.9 倍（见 §5 陷阱）；
   - 圆柱液滴 Laplace 压差：`Delta p = sigma / R`，压差直接用 `_macro_fp64` 的 `p` 场测。
3. **一次一变量控制组**：振幅减半（线性性）、黏度 0.03（衰减随 `nu` 标度）、
   AC 迁移率 0.02/0.20（相场松弛是否泄漏进 `omega`）、界面宽度 2/3/6（离散分辨率）。
4. **工具链**：`tools/capillary_wave_verification.py --jobs 5` 并行产出
   `artifacts/capillary_wave_20261109/{results.json, laplace.json, flat_interface.json, figures/*.png}`；
   本报告所有数字均由该脚本写入 JSON 后生成，无手抄。
5. **测试**：`tests/test_capillary_wave_dispersion.py`（21 个用例）
   测量链对合成信号做精确回归（含"两个频率必须被区分开"的负控），
   并对参考工况的**动态亏损区间**做回归钉扎（`slow` 标记，PR 不跑）。

## 3. 计算结果（数字表，程序化注入）

### 3.1 动态：驻波频率与衰减（参考工况 `k=0.1963, W=4, nu=0.05, A=0.5`）

| 量 | 测量 | 理论 `(1)(2)` | 相对误差 | 判据（<3%） |
|---|---|---|---|---|
| omega | 0.011180 | 0.013757 | **-18.75%** | 否 |
| gamma | 0.002249 | 0.003855 | **-41.7%** | 否 |
| sigma_eff = omega²(ρ_l+ρ_g)/k³ | 0.03301 | 0.05（输入） | **-34.0%** | 否 |
| 拟合质量 R² | 0.9981 | — | — | — |

### 3.2 扫描与对照（每行一次独立模拟）

| 工况 | k | kW | omega 误差 | sigma_eff/sigma | gamma/(2νk²) | R² |
|---|---|---|---|---|---|---|
| 参考 (W=4, ν=0.05, A=0.5) | 0.1963 | 0.79 | -18.75% | 0.660 | 0.583 | 0.9981 |
| m=3（短波） | 0.2945 | 1.18 | -27.19% | 0.530 | 0.458 | 1.0000 |
| W=2（界面未解析） | 0.1963 | 0.39 | -53.44% | 0.217 | 0.385 | 0.9935 |
| W=3 | 0.1963 | 0.59 | -19.69% | 0.645 | 0.583 | 0.9989 |
| W=6 | 0.1963 | 1.18 | -19.69% | 0.645 | 0.642 | 0.9976 |
| 振幅减半 A=0.25 | 0.1963 | 0.79 | -18.75% | 0.660 | 0.583 | 0.9987 |
| ν=0.03（黏度减半） | 0.1963 | 0.79 | -17.81% | 0.676 | 0.780 | 0.9952 |
| AC 迁移率 M=0.02 | 0.1963 | 0.79 | -18.75% | 0.660 | 0.583 | 0.9988 |
| AC 迁移率 M=0.20 | 0.1963 | 0.79 | -19.69% | 0.645 | 0.596 | 0.9987 |

读法：
* **振幅无关**（A=0.5 与 0.25 误差完全一致）→ 不是非线性效应；
* **AC 迁移率无关**（M 差 10 倍，omega 变化 <1%）→ 不是相场松弛泄漏；
* **黏度几乎不影响 omega**（ν 减半，omega 只变 +0.9%）→ 与 `(1)` 一致（`omega` 无 `nu` 依赖），
  但 **衰减率不随 ν 线性标度**（ν 减半时 `gamma` 只降 22%，理论应降 40%）；
* **界面宽度 W≥3 后误差饱和在 -19% 左右，W=2（界面只有 ~2 格）急剧恶化到 -53%** → 亏空不是单一分辨率的锅。

### 3.3 静态：两条独立路线

| 路线 | 量 | 测量 | 输入/解析 | 比值 |
|---|---|---|---|---|
| 平面界面能量积分（松弛后） | sigma_profile | 0.06517 | 0.05 | **1.303** |
| 平面界面能量积分（初始 tanh） | sigma_profile | 0.04696 | 0.05 | 0.939（纯中心差分偏差） |
| 界面宽度 | lambda | 2.230 | 2.000（W/2） | 1.115 |
| 液滴 Laplace（R=8，未完全松弛） | Delta p R | 0.04458 | 0.05 | 0.892 |
| 液滴 Laplace（R=12，未完全松弛） | Delta p R | 0.04154 | 0.05 | 0.831 |
| 液滴 Laplace（R=16，未完全松弛） | Delta p R | 0.03817 | 0.05 | 0.763 |

液滴路线的黏性松弛时间 `R²/ν` = 1280 / 2880 / 5120 步，而每个液滴只跑了 3000 步：
R=12/16 已被标为 `relaxation_limited=true`，其 `Delta p` 尚未收敛，**只能当下界读**
（R=8 未触发该标记，但 3000 步也只是 2.3 个黏性时间）；
平面界面路线不涉及慢模态，4000 步已收敛，因此静态结论以它为准：**+30.3%**。

## 5. 注意点（踩过的坑 / 局限）

1. **周期回绕污染界面能量积分（本单真实踩到）**：在周期域里对 `phi` 做中心差分，
   首尾两行差 ≈1（液体 vs 气体），`∫(phi')²` 会被抬高到解析值的 3.9 倍
   （初始 tanh：0.6565 vs 0.1667）。修正后只取内部行，得 0.1565（-6%，属中心差分本身的截断）。
   `sigma_from_profile` 的测试专门守这一条。
2. **液滴 Laplace 不能短跑**：压差按黏性时间 `R²/ν` 松弛，R=16 需 ~5000 步，3000 步只是下界；
   初值强行灌入解析 Laplace 压差再短跑同样会被释放（R=12 跑 2000 步只剩 0.58 倍），**不可取**。
3. **界面追踪器的系统偏差**：线性插值定位 `phi=0.5` 对 W=4 的 tanh 有 +1.8% 的振幅放大（本单已实测），
   这是追踪器而非求解器误差；由于偏差与振幅成正比，它只缩放振幅、不移动频率。
4. **拟合窗口敏感性**：参考工况把起始窗口从 10% 挪到 45%，`omega` 估计在 -20.0% ~ -12.7% 之间漂移；
   短波 m=3 稳定在 -27.0% ~ -27.5%（R²=1.0000）。因此本报告的动态误差给的是**区间**（-18.7 ± 4%），
   不宣称小数点后两位。
5. **未做的部分**：没有做网格加密（nx=128）与密度比（1:0.5 以上）系统扫描；
   等密度（`rho_l=rho_g=1`）是 CAC 的退化工况（`drho=0`），不能代表模型在气/水密度比下的表现。
   亏空的**根因未定位**：候选是界面离散（实测界面比 tanh 宽 11.5%）、Korteweg 力与应力的离散不一致、
   以及 He-Luo 压力型格式在界面带内的动量耦合；这需要单独的 RCA 单，不在本单范围。
6. 本机 load15 长期 >200（nproc=128），所有模拟单线程、每个工况 ≤3000 步，未占用集群。

## 6. 误差判定（逐项，显式回答"是否 <3%"）

| 关键量 | 基准 | 误差 | <3%？ |
|---|---|---|---|
| 毛细波频率 omega（k=0.1963） | `sqrt(σk³/(ρ_l+ρ_g))` | -18.75%（窗口敏感 ±4%） | **否** |
| 毛细波频率 omega（k=0.2945） | 同上 | -27.19% | **否** |
| 振幅衰减率 gamma | `2 ν k²` | -41.7% | **否** |
| 静态表面张力（平面界面能量积分） | 输入 σ | +30.3% | **否** |
| 静态表面张力（液滴 Laplace，下界） | 输入 σ | -10.8% … -23.7%（未收敛） | 否（且不可作为通过证据） |
| 界面宽度 | `W/2` | +11.5% | 否 |

**判定**：CAC 相场 LBM 的 `sigma` 输入在**静态**与**动态**两条独立路线上都不满足 15% 验收线，
更谈不上 3% 标准；该自由面动力学能力维持 **NOT_VALIDATED**，不得用于兴波/气泡/气层类精度声明。
可用性边界：若只做定性流动形态（界面拓扑、宏观流动结构）可用；任何按表面张力定量的结论
（Weber 数、气泡脱离直径、毛细波/毛细长度）须先做静态标定，并把 ~19% 的频率亏欠计入不确定度。
