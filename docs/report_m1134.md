## ① 案例介绍（物理背景与目标）

### 物理背景
冰区航行船舶螺旋桨面临独特的设计挑战：
- **冰扭矩载荷**：桨叶与冰块碰撞产生瞬态高扭矩，需满足 IACS 冰级扭矩包络
- **扭矩脉动**：冰-桨相互作用引起非定常扭矩波动，影响轴系疲劳寿命
- **空化风险**：冰区工况下桨叶负荷变化剧烈，空化裕度需额外保守

### 设计目标
在多约束条件下反设计桨叶几何（弦长分布、螺距分布、侧斜 skew、叶厚分布），使设计点敞水效率最大化，并给出约束边界上的权衡前沿（Pareto front）。

### 约束条件
1. **强度约束**：冰扭矩下单叶片梁模型（根弯矩 + 剖面模数 + 许用应力）
2. **脉动约束**：扭矩脉动幅值比限值（对齐 P02 口径）
3. **空化约束**：Keller 准则 + 盘面空化数裕度

### 技术路径
1. 设计核复用：B 系列/升力线设计（propeller_design.py + lifting_line.py）
2. 强度约束：单叶片梁模型（系数可配置）
3. 脉动约束：扭矩脉动幅值比限值
4. 空化约束：Keller 准则 + 盘面空化数裕度
5. 优化：多起点投影梯度/NSGA-II 生成 Pareto 前沿（效率 vs 强度裕度）
6. 端点集成：POST /api/v1/propulsion/ice-design，含 Pareto 表输出与 schema 验证
