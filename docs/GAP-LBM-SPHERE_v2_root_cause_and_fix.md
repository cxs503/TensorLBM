## 1. 案例介绍（物理背景 / 几何 / 参数表）

m16085 想用「曲面壁（BFL 插值反弹）+ 解析半径球 + 受限 Stokes 解析解」认证曲面边界力法，
判据 S1：`C_D` 对 Hasimoto 阵列解误差 < 3 %。它跑出的 `C_D` 比解析值小 10 倍，且两个独立力估计量
（全局动量平衡 `F_mb`、BFL 壁面账本 `F_bfl`）彼此一致到 12 %——说明「测出来的阻力就是 10 倍小」，
而不是某个力估计量坏了。m16085 把这一格记为 honest FAIL，并把「把控制器移出回路」列为下一步。

本节点做的是**归因**：这个 10 倍缺口到底来自曲面壁，还是来自碰撞算符/参数区？

| item | m16085 生产算例 | 本节点对照算例 |
|---|---|---|
| lattice / collision | D3Q19 / BGK | 同 |
| sphere | SDF `R = 6`（`D = 12`） | 同 |
| box | periodic `L = 36`（`λ = R/L = 1/6`） | 同 |
| `Re`（目标） | 0.1 | 0.1 |
| 达到 `Re` 的手段 | 大黏性 `ν = 6` → `τ = 18.5` | **小来流** `u = 0.0025` → `ν = 0.3`，`τ = 1.4` |
| 动理学平均自由程 `c_s τ` | 10.7 格（**> R = 6**） | 0.81 格（**≪ R**） |
| `c_s τ / R` | 1.780 | 0.135 |
| steps | 3000 | 4000 |

第二行加粗处就是全部变量：**几何、壁面格式、离散、力估计量都不变，只把「怎么达到 Re=0.1」从
「加黏性」换成「减来流」**。

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **先修一个报告口径 bug**（`driver.py`）：`Re = ρ u D / μ`，格子里 `ρ = 1` ⇒ `μ = ν`；
   m16085 写的是 `mu = nu / 3.0`，把 `Re_measured` 报大了 3.0 倍（0.2944 而非 0.0981）。
   已修，并加回归测试 `test_re_measured_uses_dynamic_viscosity_not_nu_over_3`。
2. **动理学黏性探针**（`diag_visc_k.py`，独立于壁面格式）：周期盒内加**稳态单模体力**
   `g_x(y) = g0 cos(ky)`，稳态动量平衡给出 `ν_eff(k,τ) = (1−1/(2τ)) g0 /(|A| k²)`。
   这是**稳态**测量，没有瞬态拟合窗口，也不受 ghost mode 污染；同时覆盖到 `k ~ 1/R`
   （剪切波**衰减**法到不了那里：`ν k² > 1`/step，一步就衰减没了——见 `diag_m16085_gap.py`
   里那条 −72.6 % 的初版测量，本节点把它标为方法学陷阱而不是结论）。
3. **单变量对照算例**：同几何、同 BFL、同离散，只把 `τ` 从 18.5 换成 1.4（`u` 从 0.05 降到 0.0025）。
4. `analysis_v2.py` 只读上面脚本的 JSON 出数字与图（零手抄）。

## 5. 注意点（坑 / 局限 / 适用范围）

1. **剪切波衰减法在 τ 大时不可用**：`ν k² > 0.1`/step 时拟合窗口落在 ghost-mode 污染区，
   初版测得 τ=18.5 为 −72.6 %，与稳态单模法的 −86.5 % 差 14 个百分点。本节点一律以**稳态**探针为准，
   并把这条写进测试注释（方法学陷阱，不是结果）。
2. **「ν_eff 预测」不是闭合解**：Kn ~ O(1) 时黏性依赖波数，取 `k = 2π/L` 还是 `1/R` 会让预测在
   ×0.5 ~ ×1.5 之间漂移（实测需要 `ν_eff ≈ 0.594`，即插值到 `k ≈ 0.22 ≈ 1.3/R` 才正好闭合）。
   因此**不能说「10 倍缺口被精确解释」，只能说「量级与符号被解释，残差 36 % 归因于波数选择」**。
   这正是 Kn ~ O(1) 区不可做绝对解析对标的根本原因。
3. **对照算例未收敛**：4000 步 < 盒扩散时间 4320 步（`L²/ν`），`steady=False`，且控制器把 `g`
   钉在 `F_bfl`（账本系统性偏低 14 %）上，导致 `u` 停在目标值的 77 %。所以它的 `C_D` 只作**趋势**证据：
   相对目标 Re +15.5 %、相对实测 Re −10.7 %，比 m16085 的 −89.9 % 改善约一个量级，但**不构成 S1 通过**。
4. **方法学结论（可直接复用于全仓）**：格子里用「加大 ν」去压 Re，会同时把 `c_s τ` 推过几何尺度，
   进入非流体力学区；正确做法是**降来流速度**（Ma 可以低到 1e-3）而不是加大 τ。
   `driver.py` 现在把 `mfp_over_R` 与 `hydrodynamic_regime` 写进每条记录，并有测试守住
   （τ=18.5/R=6 → 1.78，判 False）。

## 6. 误差判定（逐项，显式回答「是否 < 3 %」）

| criterion | 判据 | 数字 | 是否 < 3 % |
|---|---|---|---|
| `Re` 报告口径（`μ = ρν`） | 精确恒等 | `Re_measured` 曾被高报 **3.000×** | 已修；回归测试锁定 |
| `ν_eff` 在 hydrodynamic regime（τ=1.4, k=0.1745） | vs `(τ−1/2)/3` | **+0.69 %** | **是** |
| `ν_eff` 在 m16085 生产区（τ=18.5, k=0.1745） | vs `(τ−1/2)/3` | **−86.52 %** | 否（这是根因，不是误差） |
| m16085 `C_D` vs 解析受限 Stokes | 预注册 S1 `< 3 %` | **−89.93 %**（`C_D` 44.499 / 441.96） | 否 — 且本节点证明该算例**不可解释**（Kn=1.78） |
| m16085 `C_D` vs ν_eff 修正预测 | 同量级 | **+36.5 %**（预测 60.72 / 实测 44.50） | 否，但 10.1× → 1.37× |
| 对照算例 `C_D` vs 解析 @ 实测 Re | `< 3 %` | **−10.65 %** | 否（未收敛，`steady=False`） |
| `F_bfl` vs `F_mb` | 预注册 S2 `< 2 %` | **−14.09 %** | 否（与 m16085 的 −12.35 % 同量级，说明是账本的系统偏差，非 τ 特有） |

**结论（honest）**：m16085 的 10× 缺口**不是曲面壁造成的**——同一壁面格式在 τ=1.4 下把误差从
−89.9 % 压回到 −10.7 %（未收敛，趋势值）。缺口的主因是**参数区**：用大 ν 压 Re 把
`c_s τ` 推到 10.7 格，超过球半径 6 格，BGK 在这个波数上的黏性只有 `(τ−1/2)/3` 的 13 %。
`GAP-LBM-SPHERE` 因此**仍未通过**，但失败原因从「曲面壁不可信」改写为「协议不可解释 + 对照算例欠收敛」。
