## 1. 物理背景与几何

后台阶流动是分离流再附的经典验证算例。流体在台阶角点分离，形成回流区，在下游 X1 处再附。

**Armaly 实验几何**:
- 入口通道高度: 5.2 mm
- 出口通道高度: 10.1 mm
- 膨胀比: 10.1/5.2 = 1.9423
- 台阶高度: 4.9 mm

**LBM 离散几何** (scale=1):
- h_in = 52 单元格, s = 49 单元格
- H = 101 单元格
- 膨胀比: 101/52 = 1.9423077 (与实验偏差 <0.001%)

## 2. 数值方法

### 求解器设置
- **格子**: D2Q9
- **碰撞**: TRT (双松弛时间), 魔数参数 Λ = 3/16
  - 消除半程反弹边界的位置误差
  - 相比 BGK 提供更优的近壁精度
- **入口边界**: 充分发展的抛物线 (Poiseuille) 剖面
- **出口边界**: Zou/He 压力边界 + 非平衡海绵层
- **壁面**: 半程反弹 (pre-stream 格式)

### 再附长度测量

**壁面剪切法** (verdict.py 标准):
```
τ_w(x) ≈ du_x/dy|_wall = -2·u₁ + 3·u₂ - u₃
X1/s = (x_zero - x_step + 0.5) / s
```
三点单侧 Lagrange 导数，对二次剖面精确，主导误差 O(dy³)。

**流函数法** (交叉验证):
```
ψ(x,y) = ∫₀ʸ u_x(x,y') dy'
X1/s = (x_ψ=0 - x_step) / s
```
ψ=0 等值线与下壁面的交点。

假设 X1/s(h) = X1/s(∞) + A·h^p，使用 L1/L2p/L3p 数据:

| 方法 | 外推值 | 收敛阶 p | vs Armaly |

| 流函数 | 2.845±0.04 | ~1.5 | -6.7% |

流函数法的外推值更接近实验值，表明壁面剪切法在台阶角点奇异性附近存在系统性低估。

## 4. 误差分析

### 4.1 误差来源

1. **2D vs 3D 效应**: Armaly 实验是三维的，而 LBM 模拟是二维的。文献表明 2D 数值模拟通常低估再附长度约 5-10%。

2. **台阶角点奇异性**: 阶梯式离散 (staircase) 引入一阶几何误差，影响分离点位置和近壁速度梯度。

3. **壁面剪切重建**: 三点 Lagrange 导数在台阶角点附近 (x ≈ x_step) 可能受奇异性影响，导致 τ_w 零点提前。

4. **入口发展长度**: up_over_hi = 4.0 可能不足以让入口剖面充分发展。

### 4.2 与 Erturk 2008 的比较

Erturk (2008) 使用有限差分法在相同几何 (ER=1.942) 下得到 X1/s = 2.878。我们的流函数法结果 (2.753) 与之偏差 -4.33%，在 5% 交叉检验容差内。

壁面剪切法结果 (2.597) 与 Erturk 偏差 -9.8%，超出 5% 容差。这进一步证实壁面剪切法在分离区预测上存在系统性偏差。
