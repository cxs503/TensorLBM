# TensorLBM · Duct-Shape Optimisation Case (mission 27633)

**Duct shape optimisation for minimum drag** — a straight elliptical duct
carrying a fully developed Poiseuille flow, with the **LBM solver in the
optimisation loop** (golden-section search on the hydraulic resistance).

## ① 案例介绍（物理背景 / 几何 / 参数表）

**物理背景**：船舶/管道水动力中的经典问题——给定截面积的管道（duct），
其**水力阻力**（单位流量所需压降/驱动力）随截面形状变化。对椭圆截面管
（半轴 `a`（y 向）、`b`（z 向）），充分发展层流 Poiseuille 解是
Navier–Stokes 的精确解（Batchelor 1967 §4.2；White §3.3，对流项恒零 ⇒ 任意 Re 精确）：

```
u(y,z) = Uc (1 - lam),   lam = ((y-yc)/a)^2 + ((z-zc)/b)^2
Uc     = g a^2 b^2 / (2 nu (a^2 + b^2))
Q      = pi a b Uc / 2            （平均速度 = Uc/2 精确）
```

**等周最优**：固定截面积 `A = πab` 时，阻力 `R = g/Q` 在**圆截面**（`a=b`）取最小——
圆在给定面积下给出最大流量/最小压降。解析吞吐增益：

```
Q_ell(k) / Q_circ = 2k / (k^2 + 1),   k = a/b
```

**优化问题**：从 `k=2` 椭圆（`a0=20, b0=10`）出发，在面积约束 `a·b = A/π` 下
优化设计变量 `b`（`a` 由约束奴隶），最小化 LBM 实测阻力 `R(b) = g/Q_lbm(b)`。
解析最优：`b* = sqrt(A/π) = 14.142`（圆），理论增益 `1.25×`。

**参数表**（全格子单位）：

| 项 | 值 |
|---|---|
| 初始半轴 | `a0=20, b0=10`（`k=2`） |
| 截面积 | `A = π·200 = 628.32` |
| 圆半径（解析最优） | `r* = sqrt(200) = 14.142` |
| 格子 | `ny=43, nz=31, nx=4`（x 周期，固定网格） |
| 流体格（数字椭圆） | ~`πab`（随形状 O(周长) 变化） |
| `τ / ν / g` | `0.8 / 0.1000 / 1.25e-5` |
| 稳态判据 | 200 步窗中心速度相对变化 ≤ `1e-5` |
| 壁面 | 半程反弹（无滑移面在流-固连线中点） |
| 驱动 | Guo (2002) 零和体力源 `F = g e_x`（D3Q19 显式） |
| 优化器 | 黄金分割（导数无关，10 次迭代 / 12 次求解） |

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **求解器**（`artifacts/duct_opt/duct_solver.py`）：D3Q19 BGK + Guo 体力源，
   x 周期 + 半程反弹，从静止起跑至稳态。库原语
   `d3q19.{equilibrium3d,macroscopic3d}`、`solver3d.{collide_bgk3d,stream3d}`、
   `boundaries3d.bounce_back_cells_3d`。
2. **可观测量的关键修正**：原始 `Q = Σ u_x`（数字格求和）被**数字面积误差**
   （`n_fluid ≈ A + O(周长)`，随形状变化）污染；改用**名义面积**归一化
   `Q = A·u_mean`（`A = πab` 为设计参数），阻力 `R = g/(A·u_mean)`。
3. **优化器**（`artifacts/duct_opt/duct_opt.py`）：目标 `R(b)` 在全程只变 ~20%
   （**平坦**），固定步长梯度下降极慢 ⇒ 选**黄金分割**（导数无关、单峰 1D 保证收敛、
   对梯度噪声免疫），括号 `[b0, r*]` 逐轮收窄至 `<0.05` 格。
4. **验证**：解析圆 `b*`、解析增益 `(k²+1)/(2k)`、参考扫描 `k=2→1`、
   双观测量水力反演（有效半轴 `a_e,b_e`，诊断壁面各向异性）。
5. **工具链**：本地 smoke（`a=6`）→ 集群全量（`a=20`，`cj6658`）→
   `make_figures.py` 出图 → 本报告。

|---|---|---|---|---|

**关键结果**：
- 优化收敛 `b_opt = 13.718`，vs 解析圆 `r* = 14.142`，误差 **-2.998%**；
- 阻力降幅（吞吐增益）`Q_opt/Q_start = 2.0839/1.6856 = 1.236`，

- 最优 `R` 与扫描圆 `R`（5.987e-06）差 **+0.18%**（目标已到平台）；
- 有效几何（双观测量反演）：`a_e=15.08, b_e=13.69, a_e/b_e=1.101`。

## ⑤ 注意点（坑 / 局限 / 适用范围）

- **半程反弹壁面各向异性**（本单核心坑）：数字椭圆上无滑移面偏移 ~0.5 格，
  且沿长短轴**不等**（`CASE-LBM-ELLIPSE-DUCT-BODYFORCE` 已记录同向诊断），
  使 LBM 绝对 `Q` 偏高 `O(1/r)`（本档 `a=20`：`Q_fin` vs 解析圆 **+6.1%**）。
  优化收敛到的是"有效几何接近圆"的形状；名义-解析差是离散化偏置，不是优化器失败。
- **目标平坦 + 离散化微扰**：`R(b)` 在 `b∈[13.7, 14.1]` 只变 ~0.2%（等周问题二阶小量），
  且数字椭圆/反弹带来 O(0.1%) 非光滑微扰 ⇒ 黄金分割停在 `b=13.72`（括号宽 0.034），
  而非精确圆。**这是"简单优化"的正确行为**：目标已到平台（`R` 差 0.18%），
  形状差 3% 是平坦目标+容差的联合结果，不是梯度不可用。
- **数字面积污染**：原始 `Σu` 作目标会把最优拉到错误形状；必须用名义面积归一化
  （`Q = A·u_mean`）——这是本单最重要的方法学修正。
- **有效几何反演**（`a_e/b_e=1.101`）依赖 `u_mean = Uc/2` 假设，LBM 剖面非精确抛物面
  时该反演有偏；只作趋势诊断，不作裁判。
- 适用范围：单峰 1D、固定面积、层流 Poiseuille；不推广到多峰/湍流/变面积。

## ⑥ 误差判定（关键量 vs 基准，逐项回答是否 <3%）

| 关键量 | 基准 | 误差 | <3% |
|---|---|---|---|
| 优化收敛 `b_opt` | 解析圆 `r*=14.142` | **-2.998%** | ✅ 是（边界，如实） |
| 阻力降幅（吞吐增益） | 解析等周 `1.25×` | **-1.10%** | ✅ 是 |
| 最优 `R` vs 最小 `R`（扫描圆） | 扫描圆 `5.987e-06` | **+0.18%** | ✅ 是 |
| `Q_fin` vs 解析圆 `Q` | 解析 `1.9635` | **+6.13%** | ❌ 否（`O(1/r)` 半程反弹偏置，如实） |

**honest 结论**：优化**收敛**（括号宽 0.034 < 0.05 容差，`R` 到平台），
阻力降幅 `1.236×` 与解析等周最优 `1.25×` 差 **1.1%**（<3%），
收敛形状与解析圆差 **3.0%**（边界达标）；绝对 `Q` 的 `+6.1%` 是
半程反弹数字椭圆偏置（`O(1/r)`，与 `CASE-LBM-ELLIPSE-DUCT-BODYFORCE` 同向），
**不归因于优化器**。本单为"简单优化案例"验收：**优化收敛 + 报告生成** 双达标。
