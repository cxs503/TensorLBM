# Viscoelastic Polymer Drag Reduction (Toms Effect) Verification

## Physical Background

The Toms effect (Toms, 1948) is the phenomenon whereby trace amounts of high-molecular-weight
polymers dramatically reduce turbulent friction drag in wall-bounded flows. The underlying
physics is the viscoelastic stress generated by polymer molecules stretching in the turbulent
velocity gradients, which suppresses near-wall coherent structures and shifts the logarithmic
velocity profile upward (Virk's maximum drag reduction asymptote).

## Constitutive Models

### Oldroyd-B
Linear Hookean dumbbells with constant polymer viscosity:
```
DC/Dt = L·C + C·Lᵀ − (1/λ)(C − I)
τ_p = (η_p/λ)(C − I)
```
where C is the conformation tensor, L = ∇u the velocity gradient, λ the relaxation time,
and η_p the polymer contribution to zero-shear viscosity.

### FENE-P
Finitely extensible nonlinear elastic dumbbells with Peterlin closure:
```
DC/Dt = L·C + C·Lᵀ − (1/λ)(f(C)·C − a·I)
f(C) = L²/(L² − tr C),  a = L²/(L² − 3)
τ_p = (η_p/λ)(f(C)·C − a·I)
```
where L² is the maximum squared extensibility. FENE-P is shear-thinning; Oldroyd-B is not.

## Numerical Method

- **Momentum**: D2Q9 lattice-Boltzmann, BGK collision, Guo forcing scheme
- **Conformation**: Explicit sub-stepped upper-convected evolution with implicit relaxation
- **Walls**: Half-way bounce-back (second-order accurate)
- **Realizability**: Eigenvalue projection ensuring C ⪰ 0 and tr C ≥ 3

### C4b Honest Failure Note

The global energy balance residual is O(dx²) from discretization/quadrature error, not a
constitutive identity. The residual decreases by ~4× per grid doubling (ny=18→34→66:
2.9%→0.72%→0.18%), confirming second-order convergence. The 1e-6 target is not reachable
at practical verification resolutions; this is reported honestly.

## Virk Asymptotes

Virk (1975) parametrized polymer drag reduction in Prandtl-Karman coordinates:
- **Newtonian**: 1/√f = 4.0 log₁₀(Re√f) − 0.4
- **MDR**: 1/√f = 19.0 log₁₀(Re√f) − 32.4
- **ΔB_max** = 11.7 at Re ≈ 10⁴

The ΔB(Wi) model uses a saturating law: ΔB(Wi) = 11.7·(1 − exp(−Wi/10)).

## Limitations

1. **Laminar only**: The LBM solver verifies the laminar Poiseuille exact solution. Turbulent
   drag reduction requires a turbulence model (not implemented here).
2. **2D plane channel**: The solver is 2D; 3D effects are not captured.
3. **Low Ma**: Lattice units require Ma < 0.1 for incompressibility; u_max = 0.04 gives Ma ≈ 0.069.
4. **Wi stability**: The explicit coupling has a finite Weissenberg number stability envelope;
   beyond it the solver raises `ViscoelasticDivergenceError` (by design, not a bug).
