## 1. 为什么重写这个文件（欠账诊断）

`tests/test_lbm_verification.py` 原版本自称"LBM 求解器基础物理 100% 正确"，但：

| 缺陷 | 后果 | 证据 |
|---|---|---|
| 四个案例默认参数 `device="sdaa:0"` | CPU-only CI 直接抛错 → 被 4 行写进 `ci_quarantine.txt` 长期隔离 | quarantine 注释："102 verified identical failures on stock main" |
| 案例函数**返回 bool** 而非 `assert` | 即便跑到 SDAA 上，物理错了 pytest 也判 pass——**验证是形同虚设的** | 原文件 `return passed` |
| 体力源用 `f_q += w_q·3·c_qx·G` | 这不是 Guo (2002) 源项，缺少 `(1−1/(2τ))` 与 `u` 相关项，Poiseuille 峰值在 τ=1 时系统偏低 25% | 原 Step C 代码；本次改为库内 `guo_force_delta_3d` |
| 收敛判据用 `max|u|` 相对变化 | 一旦有 Dirichlet 行，`max|u|` 立刻恒定 → 内部还在瞬态就"收敛"（实测 200 步假收敛） | 首次重跑 Couette：`steps=200`、剖面非直线 |

R1 的修正：设备走 `TENSORLBM_TEST_DEVICE`（默认 `cpu`，SDAA 不可用则告警回退），
每个案例以 `assert` 收尾，收敛判据改为**检查窗内速度场的最大变化**（相对 1e-6，float32 合理值）。

## 2. 四个案例与判据

| 测试 | 解析基准 | 判据 |
|---|---|---|
| A 剪切波衰减 | `u_y = A cos(kx) e^{−νk²t}`, `ν=(τ−1/2)/3` | `ν_meas` 相对误差 <1 %；质量漂移 <1e-5 |
| B Couette | 内部严格线性，`du/dy = u_lid/H`, `H=(ny−1)−0.5` | 斜率误差 <1 %（H=32.5）；内部线性残差 <1 %·u_lid |
| C Poiseuille | `u=G/(2ν)·y_c(H−y_c)`, `G=8νu_max/H²` | 剖面最大误差 <1 %；加密后误差单调下降 |
| D 壁面摩擦 | 稳态动量平衡 `2·F_wall = G·N_fluid` | 相对误差 <1 %；横向泄漏 <1e-6 |

## 3. 结果（程序化注入，见 `artifacts/verification/lbm_analytic_suite.md`）

### S1 剪切波粘度（Step A）

| tau | ν_exact | ν_measured | 相对误差 |
|---|---|---|---|
| 0.55 | 0.016667 | 0.017128 | 2.7660 % |
| 0.6 | 0.033333 | 0.033818 | 1.4552 % |
| 0.7 | 0.066667 | 0.067186 | 0.7789 % |
| 0.8 | 0.100000 | 0.100494 | 0.4937 % |
| **1.0** | 0.166667 | 0.166672 | **0.0030 %** |
| 1.5 | 0.333333 | 0.328931 | 1.3206 % |
| 2.0 | 0.500000 | 0.483527 | 3.2947 % |
| 2.5 | 0.666667 | 0.626405 | 6.0393 % |

**发现 1**：1 % 门只在 τ≲1 成立。误差随 |τ−1| 增长、并在 τ=1 处几乎为零（0.003 %），
这是 BGK 剪切波**衰减**的离散修正（格子色散对 ν 的高阶修正），不是求解器 bug。
因此测试固定 τ∈{0.7, 0.8, 1.0}；τ>1.5 时 `ν_meas` 已不可用作粘度标定（τ=2.5 偏低 6 %）。

### S2 Poiseuille 剖面与加密（Step C）

| H | 剖面最大误差 | 峰值误差 | 到稳态步数 | 反推壁面偏移 |
|---|---|---|---|---|
| 8 | 0.8241 % | 0.8179 % | 600 | 0.048 |
| 16 | 0.2017 % | 0.1832 % | 1800 | 0.023 |
| 32 | 0.0499 % | 0.0145 % | 4600 | 0.009 |

误差随 H 大致按 H⁻² 下降（0.82→0.20→0.05），与半程反弹壁面的二阶精度一致。
**发现 2**：反推"壁面偏移"随 H 缩小（0.048→0.009），说明 Poiseuille 里半程反弹**没有**
固定壁面偏移，是真正的二阶收敛——与 Couette 的 O(1/H) 行为形成对照（见 S3）。

### S3 Couette 内部剪切率（Step B）

| H | 斜率拟合 | 斜率精确 | 相对误差 | 线性残差 | 步数 |
|---|---|---|---|---|---|
| 16.5 | 0.00306747 | 0.00303030 | 1.2264 % | 9.85e-07 | 2100 |
| 32.5 | 0.00154798 | 0.00153846 | 0.6187 % | 6.17e-06 | 4200 |

**发现 3**：内部剖面是**严格线性**（残差 ~1e-6，纯浮点量级），但斜率系统性偏高，且
`H × 误差` 在两种分辨率下都等于 **0.201 ± 0.001 格子单位**——即"有效壁面位置"存在一个
与分辨率无关的固定偏移 δ≈0.20（顶端移动壁用平衡态覆盖节点行 y=ny−1 实现，与半程反弹
的下壁 0.5 不在同一约定下）。所以斜率误差 = δ/H = O(1/H)。测试因此把 1 % 门挂在
H=32.5（实测 0.62 %），并在文档里如实记录这个 artefact，而不是靠调宽容差掩盖。

### S4 壁面阻力：观测器 vs 精确动量平衡（Step D）

| 量 | 值 |
|---|---|
| 精确 `G·N_fluid`（两壁合计） | 1.600000e-02 |
| wet-node 动量交换 | 1.600105e-02（**误差 0.0065 %**） |
| Ladd 求和式（`momentum_exchange_standard`） | 2.933514e-02（**比值 1.833**） |
| 壁面切应力（wet-node） | 5.000327e-04，精确 5.000000e-04 |
| 横向泄漏 f_y, f_z | 1.79e-07, 0.00e+00 |

**发现 4（本次最重要的审计结论）**：在**平面**通道壁上，"Ladd 求和式"动量交换比精确动量平衡
高 **1.83 倍**，而 `momentum_exchange_background_subtracted`（背景扣除版）给出**完全相同**的
1.83 倍——即背景扣除在这个构型上不起作用，与其 docstring"平面壁上背景会自动抵消"的断言不符。
`momentum_exchange_wet_node`（全连接预算形式）则与精确平衡吻合到 0.0065 %。
因此 Step D 的断言挂在 wet-node 形式上，并把 1.833 这个比值作为回归量写进返回值
（`standard_over_wet_ratio`），供后续排查。
**未验证的归因**（如实标注）：怀疑求和式里的 `f_opp(x_s)` 项取自 NoDynamics 还原后的固体格点、
其分布是陈旧值而非"注入壁面的相反方向分布"，属该实现的时序约定问题；**本次未做逐项
分解证明**，故只作为假设记录，不据此改库代码。

## 4. 适用边界与局限

1. 全部为**低马赫数**（u ≲ 0.05）、**单相**、**D3Q19 BGK**（+Guo 源项）范围；MRT、多相、
   自由液面、AMR 不在本验证体系覆盖内（各自有 capability contract 测试）。
2. 精度门 1 % 只对"格子在 16–32 节点跨度、τ∈[0.7,1.0]"这一窗口做过实测；τ>1.5 的剪切波
   粘度、H<8 的壁面解析度都会超门（见 S1/S2 数据）。
3. Couette 的 δ≈0.20 是**约定 artefact**，不是物性；若将来把移动壁改成 momentum-corrected
   反弹或 BFL，需重测 δ 并更新 S3 表。
4. Step D 的 1.83 倍只在一个 `H=8` 的通道构型上测得；未做曲率（球/圆柱）与移动壁的
   MEM 交叉验证，未断言其在其他构型同样 1.83。
