# IN101-N01 — 冰底龙骨形态阻力与冰-海拖曳系数 C_d 的摩阻/形阻分解

**节点**: IN101-N01（战役 DAG，物理域） · **仓**: TensorLBM · **分支**: `agent/m8342`
**产物**: `src/tensorlbm/ice_keel_drag/`（新模块）+ `artifacts/IN101_N01/`（判据 JSON + 4 图）+ `tests/test_ice_keel_drag.py`（12 用例）

**一句话结论**: 把冰底形态→C_d 的分解链路做成了可机器验收的流水线，并在途中修掉内核 4 处真缺陷；
**5 条验收判据机器判 2 通过（b、e）/ 3 诚实 FAIL（a、c、d）**。诚实 FAIL 的根因全部量化给出：
本内核（BGK 极限 TRT）在可达分辨率下**够不到湍流支**，且**壁面压力/剪切面积分未标定**——
两者都不是"再跑久一点"能解决的，而是需要换求解路径（§6）。

---

## 1. 案例介绍（物理背景 / 几何 / 参数）

冰底并非平底：解冻/挤压形成三角断面龙骨阵（keel），其形阻是冰-海拖曳系数 C_d 的主要贡献者，
而 C_d 直接决定海冰漂移速度与冰情预报。观测反演（Hibler 1979; McPhee 1980/2008）给出
`C_d ≈ 0.004–0.02` 的窄带，但该带**不分**摩阻与形阻。本节点要的就是这个分解：

```
tau = rho C_d U^2,   C_d = C_d^skin + C_d^form,   C_d = Cf/2 (Cf = 2 tau/(rho U^2))
```

**几何（voxel 三角龙骨）**：周期槽道 `(nz, ny, nx)`，`z` 为壁法向，上下壁各一层固体并可镜像龙骨；
脊线方向 `angle=90°`（横流），脊距 `p = ny / n_ridges`，基宽 `w = round(lambda·p)`，
断面深度 `d = h_keel(1 - 2|t|/w)`，`lambda = w/p` 为面积龙骨密度，`h_keel/h_i` 为形态比
（`h_eff = 12 h_i` 为内核锚定假设，见 `LEVEL_ICE_TO_HALF_CLEARANCE`）。

| 族 | 网格 | Re_tau | u_tau | 初场 | 用途 |
|---|---|---|---|---|---|
| smooth 阶梯 L1/L2/L3 | 24×24×50 / 32×32×66 / 48×48×98 | 180 | 0.002 | 精确抛物（稳态） | 判据 (a) GCI + 求解器校验 |
| smooth_ref（负控参考） | 32×32×66 | 20 | 0.002 | 精确抛物 | 判据 (e) 与 (d) 同工况基准 |
| keel 扫掠（12 例） | 32×32×66 | 20 | 0.002 | 精确抛物 | 判据 (b)(c)(d) |
| turbulent_attempt | 32×32×66 | 180 | 0.002 | 对数律 + 3% 扰动 | 判据 (a) 湍流支可达性 |

keel 扫掠：`lambda ∈ {0.4,0.6,0.8} × h_keel ∈ {2,3,4,6}` cells，`n_ridges = 2`（脊距 16 cells）。
无扰动（`noise=0`）以保证可复现与稳定；`h_eff = 32` 格。

1. **内核复用与修复**：求解路径为 `tensorlbm.underice_drag`（C/OpenMP 与 torch 双后端）。

- **GCI（Roache，r≈4/3，三网格）**：观测阶 `p = 1.106`，`GCI_fine = 4.81e-4`（0.048 %）→ **≤5% 达标**
- 与对数律（`Cf=2/(lnRe_tau/kappa+B)^2`，Re_tau=180）相对误差 **91.3 %**；与 Dean `0.073 Re_h^-0.25`（Re_h=10799）**92.2 %** → **>5% 不达标**

**读数**：求解器对**精确层流解**的复现精度是 1e-4 量级、GCI 0.05%，即**数值实现是对的**；
但对数律/Dean 描述的是**湍流支**，本内核在可达分辨率下走的是层流吸引子（下一条给出的次生证据）。

- **(b) 形阻标度**：`C_d^form = 0.0712·(S_fr/S_plan)^1.096`，**指数误差 9.6 % ≤ 15 %（机器判 PASS）**，R²=0.847。

  用**动量平衡可背书的超量阻力** `C_d-C_d,flat` 重拟合得 `指数 = 1.672`（误差 67 %，R²=0.956）→ **认证判据 FAIL**。
- **(c) 动量预算**：光滑底动量残差 0.1 %（优），keel 例最大 **43.3 %**（未定常 x 龙骨绕流）；闭合残差

  `tau_skin = 1.96 × rho g h_eff`（三网格一致），即一阶半格剪切差分把有效壁面位置取了 0.5Δ 而实际为 1Δ；

## 5. 注意点（踩过的坑 / 缺陷 / 局限）

复用内核 `underice_drag` 是**未被验证的孤儿模块**（无测试、无文档、无人引用），本次审计发现并修复 4 处真缺陷：

1. **默认工况不可用**：`u_tau = 0.02` 使体流速达 `Mach 0.21`，且**低于同强迫的层流解**（`U_b = g h²/3ν` 对应
   u+≈60 vs 对数律 18），态不可能是湍流 → 单调爬升并在 12000 步后 NaN。改为 `u_tau = 0.002`（Mach 0.02）。
2. **动量预算量纲错**：用**总力**（`g·n_fluid·ρ`）直接和**单位面积应力** `ρ g h_eff` 相比，
   残差恒为 O(1e2)；改为 `/(2A)` 后光滑底残差降到 0.1 %。
3. **壁面力公式错 30×**：旧式 `c_x(f*_i - f*_opp)` 含**平衡态**部分（该部分只是被来流同步补回的
   对流项，不是应力），实测比 `ρ g h_eff` 大两个量级；已改为非平衡部分 `2c_x(f*_i - feq_i)/(1-s+)`。
   **仍未解决**的是**面积分的标定**：压力积分要求 ±x 面压差在 ~1e-4 相对精度上相消（每面 p=ρ/3，
   而信号是 O(q)），实测 `C_d^form` 比总阻力还大 0.7–2.5 倍 → 压力路由**不可用**；剪切路由存在
   恒定 2× 偏差（可标定）。这是判据 (c) FAIL 的**结构性**原因，不是收敛不足。
4. **诊断指标坏**：`stationarity_drift` 用运行累加量做分母，恒等于 ~1；已改为逐样本首末差。
5. **稳定性边界（重要局限）**：`s_minus = 1/tau`（BGK 极限）在 `Re_tau=180`（τ=0.5011，s⁻=1.996）
   下**任何粗糙壁扰动都会发散**（12/12 keel 例 NaN）；只有把 Re_tau 降到 20（τ=0.5096）才稳定。
   代价就是 (d) 落在观测带之外。**结论：该内核不能用于湍流冰-海拖曳闭合**，需换 LES/高分辨率路径。
6. **几何量化退化**：`n_ridges=4` 时脊距 8 格、λ=0.15 → 基宽 1 格，`h_keel=3/5/7` 体素化为**完全相同**
   的 mask（有一致拖曳）；已把表改为 `n_ridges=2` 并留回归测试 `test_dense_ridge_set_degenerates`。
7. **适用范围**：结论仅覆盖 `Re_tau ≤ 180`、`h_eff ≤ 48` 格、三角断面（45° 阶梯化）龙骨；
   未覆盖破碎带、起伏脊高、孔洞（lead）与真实海冰厚度分布。
