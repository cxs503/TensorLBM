## 1. 案例介绍

**Stokes 第一问题**（又称 Rayleigh 问题）：一块无限大平板在 t=0 时刻突然以速度 U 启动，带动上方粘性流体运动。该问题存在精确解析解（误差函数互补函数 erfc），是验证非稳态粘性扩散的基准案例。

- **案例路径**：`benchmarks/verified/stokes_first_problem`
- **物理参数**：U = 0.05（格子单位），ν = 0.05（τ = 0.65），Ma ≈ 0.087
- **网格配置**：H ∈ {100, 200}，nx = 8，记录时刻 t ∈ {1000, 4000, 9000}
- **解析解**：u(y,t) = U · erfc(y / (2√(νt)))

## 2. 方法

### 2.1 运行方式
编写独立扫荡脚本 `scripts/sdaa_sweep_stokes_first_problem.py`，不修改业务代码。张量放置于 SDAA 设备，采用 `compile-mode=eager`（与 `run.py --compile-mode eager` 逐位一致）。

### 2.2 设备环境
| 项目 | 值 |
|------|-----|
| Python | 3.11.6 |
| PyTorch | 2.7.1 |
| torch_sdaa | 3.1.1a3+gite3971b9 |
| 平台 | Linux-6.6.52 (LoongArch64) |
| SDAA 设备 | `/dev/tcaicard25`（1 卡） |

### 2.3 Triton 依赖说明
案例入口 `run.py` 不 import triton；torch.compile 在 SDAA 上走 teco_inductor 而非 triton，故 `TRITON_INTERPRET=1` 不适用。

### 2.4 判据口径（14 条，按原口径未改动）
- **G1**（6 条）：剖面最大相对误差 ≤ 3%（仅统计 u_ana > 5%·U 区域），覆盖 2×3 = 6 组合
- **G2**（4 条）：网格收敛 — H=200 的 max_rel ≤ max(H=100 值, 3%)，3 个时刻 + 总体收敛标志
- **D1**（2 条）：波场有限（finite == True），H=100/200 各一条
- **D2**（2 条）：|质量漂移| ≤ 0.1%，H=100/200 各一条
