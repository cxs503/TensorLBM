## ① 案例介绍

### 物理背景

Stokes 第二问题是经典流体力学解析基准：半无限静止流体中，一无限平板在自身平面内做谐波振荡 $u_w(t) = U\cos(\omega t)$。稳态周期解析解（Batchelor; Landau-Lifshitz §24）为：

$$u(y,t) = U \, e^{-ky} \cos(\omega t - ky), \quad k = \sqrt{\frac{\omega}{2\nu}}$$

幅值随深度指数衰减，相位线性滞后，两者皆由单一穿透波数 $k$ 决定。

### 几何与参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 格子 | D2Q9 | 二维九速度 |
| 碰撞 | BGK | $\tau = 0.8$, $\nu = (\tau-0.5)/3 = 0.1$ |
| 板速幅值 | $U = 0.05$ | Ma = 0.0866 |
| 域高 | $H \in \{20, 50, 100, 200\}$ | ny = H+2 |
| 宽 | nx = 8 | x 方向周期 |
| 无量纲波深 | $kH \in \{4, 6, 8\}$ | 穿透深度 $\delta = 1/k$ |
| 边界 | 顶行 Zou/He 移动盖 + 底行自由滑移镜面反射 | |
| 门限 | 幅值/相位/复振幅 ≤ 3% | |

## ② 方法

### 工具链

- **求解器**: TensorLBM (D2Q9 BGK)
- **入口**: `benchmarks/verified/stokes_second_problem/run.py`
- **独立脚本**: `scripts/sdaa_sweep_stokes_second_problem.py`
- **设备**: CPU (本环境无 SDAA/CUDA)，`TRITON_INTERPRET=1` 绕行
- **编译模式**: eager（CPU 无需编译）

### 流程

1. 导入 benchmark `run_case` 函数（零修改业务代码）
2. 在 CPU 上运行 H=20, kH=4 配置（~11k 步，13s）
3. 程序化提取幅值/相位/复振幅误差
4. 与解析解比较，判定 PASS/FAIL
5. 同时引用已有 GPU 验证数据（H=50/100/200, kH=6/8）作为完整收敛性证据

### 关键设置

- 振荡平板 = 顶行 (y=ny−1)，Zou/He 移动盖机制
- 远场 = 底行 (y=0)，自由滑移镜面反射（避免无滑移远壁污染衰减尾部）
- 跳过 startup 瞬态后测量 4 个完整周期
- 锁相 demodulation 提取复振幅

## ⑤ 注意点

1. **远场边界选择**：无滑移远壁会污染衰减尾部，导致不可细化的 ~2.7% 误差地板。本 benchmark 采用自由滑移镜面反射（库内无此入口，内联 3 行 SPECULAR 反射）。
2. **CPU 性能**：LBM 在 CPU 上较慢，H=50 需 ~30k 步超时。本环境仅运行 H=20 子集，完整收敛性证据来自已有 GPU 扫描。
3. **TRITON_INTERPRET=1**：本环境无 SDAA 设备，使用 Triton 解释模式绕行。
4. **质量漂移**：Zou/He 移动盖在边界节点调节密度，非严格守恒（H=200: 0.35%），对速度相量无影响。
