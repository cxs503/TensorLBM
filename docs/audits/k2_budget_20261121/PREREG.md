# K2-BUDGET-B 预登记（Pre-registration）

> 战役 = DE·诊断主线 K 系列。本单 = **K2 动量/能量收支分解**：撞击动量在峰时刻之前流向了哪里？
> 前情（定谳勿重验）：K1-DIAG-B 已证「空穴过闭合」被直接证伪（d_cav_gap ≡ 0、p_cav = 1.0 单连通），
> −22.73 % 欠深 = 液滴物理欠穿透（d_drop_any = 1.3953 D < 0.8·exp = 1.4859 D）。
> 本单沿用 **cells=8 基线 + Santini case-3 旗标组**（gap .18 / speed .06 / rs 1.53 / pd 3.0 / ul .15），
> 锚 = 1.4352204748231814 D @ 11.090571428571428 ms（战役锚，K1-DIAG-B 复现）。
> 预登记提交于任何满窗结果产生之前；跑后一字未改。

## 1. 决策与备择（Decision & alternatives）

**决策**：撞击能量/动量在峰时刻之前的**去向**是哪个通道？下一波处方指向哪个通道？

备择（互斥的归因，不是同义词）：

| 代号 | 主张 | 可证伪预测 |
|---|---|---|
| **H1 气穴气体压力冲量主导** | 空穴气体（大气压 + Laplace）对液柱底的冲量是主通道 | ① 的冲量/能量份额 ≥ 50 % |
| **H2 界面表面能增量主导** | 撞击能量主要变成新的界面面积（σ·ΔA），水被"界面锁住"故穿不深 | ② 份额 ≥ 50 % |
| **H3 界面粘性/拖曳耗散主导** | 撞击能量在气液界面被粘性耗散掉 | ③ 份额 ≥ 50 % |
| **H4 侧向射流动能主导** | 撞击动量被转成径向（侧向）射流动能，未沿轴向深入 | ④ 份额 ≥ 50 % |
| **H5 液滴残余动能主导** | 能量仍留在滴材料里（未传递出去） | ⑤ 份额 ≥ 50 % |
| **H6 转换（液→气质量交换）吞噬主导** | 撞击能量被自由表面质量交换的 I→G 转换销毁（被气穴吞没的滴材料动能消失） | 转换通道份额 ≥ 50 % |
| **H7 收支不闭合** | 上述通道都解释不了，残差 > 10 %，缺口在未列出的渠道（伪电流限幅器 / 体积漂移伪功 / 离散耗散与连续估计之差） | 残差 > 10 % |

**为什么必须做**：K1 判定了「欠深是真实物理欠穿透」，但**没有说能量去哪了**。
处方选旋钮（耗散率、界面动力学、动量注入、网格）需要知道能量被哪个通道吃掉，否则只能盲试。

## 2. 假说、指标、分析单元（hypothesis / metrics / unit of analysis）

- **假说（主）**：撞击动量在峰时刻前被**分配到多个通道**，其中存在一个 ≥ 50 % 的主导通道；该通道即下一波处方目标。
- **指标（预登记，五个任务项 + 三个显式附加项）**：

| 编号 | 指标 | 定义（单位：格点能量 = ρ_l·dx³；冲量 = ρ_l·dx⁴/dt） |
|---|---|---|
| ① | 空穴气体压力冲量 | 空穴壁（连通气穴与初始液面以下的界面胞）上气体压强 p_gas=p_amb+σ κ 的合力矢量及其时间积分；能量形式 = 该压强对壁面做的功 ∮−p(u·n̂)dA |
| ② | 界面表面能增量 | σ·ΔA（ΔA = ∫\|∇φ\| 的增量），并分出空穴壁份额 σ·ΔA_cav |
| ③ | 界面粘性/拖曳耗散 | ∫Σ2μ\|S\|²dV dt（连续估计），分出界面邻域份额与体相份额 |
| ④ | 侧向射流动能 | ½Σm u_⊥²（u_⊥ = 水平速度），并给出空穴足迹内（r ≤ 1.5 D、初始液面以下）的子份额 |
| ⑤ | 液滴残余动能 | ½Σ m_marker \|u_marker\|²（被动示踪的滴材料） |
| ⑥（附加） | 轴向（液柱）动能 | ½Σm u_z² —— 任务五项未列，但"入水"必须含轴向项，故显式列出 |
| ⑦（附加） | 转换通道 | 质量交换把液相质量变为气相时带走的动能（conv_loss）与反向生成（conv_gain） |
| ⑧（附加） | 重力功 + 环境压功 | W_grav = ∫ρg·u dt；W_atm = −p_amb·ΔV_liq（刚体闭合域的净环境压功） |

- **分析单元**：一次满窗运行（cells=8、单工况、单网格）的一次时间序列；积分窗口 = **接触步 → 峰时刻步**（t\*，深度峰）。
- **目标总体/工况**：Santini et al. case-3 单滴入水（1.4 m/s，D = 2.27 mm，水 27 °C）。

## 3. 基线与对照（baseline / control）

- **基线**：`runs/k2budget/`（cells=8 基线 + `--diag-budget` 只读诊断）。
- **对照 1（轨迹不变性）**：`runs/k2budget_ctrl/`（同旗标、不开诊断）→ 逐字段比较 `history`，要求**位级一致**（0 差异）。
- **对照 2（战役锚）**：深度峰 1.4352204748231814 D @ 11.090571428571428 ms（K1-DIAG-B 复现值），偏差 ≤ 1e-9 视为锚复现。
- **实验基准**：实验坑深峰 1.857434 D @ 10.39446 ms（post-impact），LBM 欠深 −22.7310 %（K1 已定谳，本单不再重验）。

## 4. 预登记阈值与停止规则（thresholds & stopping rule）

- **闭合判据（主）**：在 t\* 上，收支残差
  R = ΔE_KE_liq − (W_grav + W_atm − ΔE_surf − E_diss + E_conv)
  归一化 |R| / E_scale，**E_scale = 接触时刻的液相动能 ke_liq(t_c)**。
  **PASS：|R|/E_scale < 10 %**；否则 **honest FAIL**，并用诊断量定位丢失渠道（⑦ 转换份额、伪电流限幅胞数 n_at_cap、
  体积漂移 |ΔV_liq|、离散耗散与连续估计之差）。
- **归因判据（主）**：五项 + 三个附加项中，**任一项占 E_scale 的份额 ≥ 50 %** → 判定该项主导，下一波处方指向该项。
- **欠穿透对照（任务 b 项）**：实验坑深隐含的**重力位能需求**
  ΔE_PE = ρ_l g · Δd · π R_c² / 4（抛物面坑形状，R_c 取本单 LBM 坑口半径，Δd = d_exp − d_lbm），
  与撞击能量 E_scale 比较；若 ΔE_PE/E_scale ≪ 1（预期 ~10⁻³ 量级），
  则**深度缺口不是重力位能不足造成的**，缺口必在**惯性/动量分配**侧 → 用各通道份额做归因。
  额外地，按**声明假设**（坑深 ∝ 轴向动能）给出"若达到实验深度所需的额外轴向动能"
  E_axial_need = E_axial(t\*)·(d_exp/d_lbm − 1)，与各通道的实际持有量比较，定出"吃掉"缺口的那一项。
- **停止规则**：满窗运行到 benchmark 自带 `window_complete`（接触后 24 ms）或深度峰 t\*（取先到者）；
  积分窗口固定为 [接触步, t\*]，**跑后不得改窗口、不得改阈值、不得换口径**。
- **排除规则**：接触前（步 < contact_step）的行不参与积分；诊断标记死亡（落入气穴）的滴材料标记**仍计入** ⑤（它们是能量去向的一部分）。

## 5. 变量、混淆与可辨识性（variables / confounders）

- **受控不变**：cells=8、gap .18、speed .06、rs 1.53、pd 3.0、ul .15、span 4.0、capacity+simple 质量交换、同一 commit、同一镜像。
- **混淆 1**：诊断本身可能改变轨迹 → 由对照臂逐字段位级比较排除。
- **混淆 2**：连续耗散估计（宏观应变率）≠ LBM 碰撞的真实耗散 → 残差中显式承认，并用量级比较定位。
- **混淆 3**：环境压功的两种口径（自由面局部积分 vs 刚体域净体积功）会给出行列式差异 → 主判据用**净体积功**（刚体闭合域），局部口径作交叉校核并如实披露。
- **混淆 4**：自由面"面积"用 ∫|∇φ| 估计，与求解器自身的曲率算法同源（|∇φ| 一致），但与链式（link）面积有系统偏差 → 只用**增量** ΔA，偏差大部分抵消。
- **混淆 5**：被动示踪标记受数值扩散影响（K1 已量化 ~±1 格 = ±0.125 D）→ ⑤ 只作份额判读，不作精确能量。
- **可辨识性**：若 ①–⑧ 全部 < 50 % 份额，则"主导通道"判据 UNDETERMINED（诚实留空），只报闭合性与残差定位。

## 6. 重复与不确定度（repetition rationale）

- 单工况单网格，**不重复**：本单测的是"通道份额"而非随机量；LBM 在固定旗标下是确定性的（逐位可复现），
  重复不降低随机误差，只增加算力。**不确定度来源**为数值口径（面积估计、耗散连续化、示踪扩散），
  以量级而非统计区间报告。锚复现（≤1e-9）作为一次"重复性检查"。

## 8. 判定规则与分析（analysis plan）

1. 判决脚本从 `runs/k2budget/result.json` 的 `budget_diag.rows` **程序化提取**全部数字（零手抄）。
2. 时间积分用梯形法（`budget_diag.integrate`），窗口 [contact_step, t\*]。
3. 归一化：所有能量份额以 E_scale = ke_liq(t_c) 为分母；冲量以 P_drop_z(t_c) 为参照。
4. 残差与份额同时给出格点单位与 SI 单位（ρ_l·dx³、ρ_l·dx⁴/dt）。
5. 若残差 > 10 %：报告 FAIL + 丢失渠道定位（n_at_cap/ke_at_cap、conv 份额、|ΔV_liq|），**不得**事后调阈值。

## 9. 解释边界（interpretation limits）

- 只覆盖 cells=8 单网格、单工况（Santini case-3）、单流体自由面模型（常数大气压 + Laplace）。
- 未跑 12 cells 收敛复核；本单结论不外推到其它网格/工况。
- ① 的"气体压力"在本模型中 = 环境压（rho_gas = 1，压强匹配）+ Laplace 跳跃；真实可压缩气体（空穴内增压）不在模型能力内 → ① 的结论只对"通气空穴"成立。
- 被动示踪的 ⑤ 不是严格的拉格朗日能量（质量取种子胞的质量、速度取所在胞速度）。
- 若残差超门，本单产出是**归因判决 + 丢失渠道定位**，不是精度修复（honest-FAIL 合法）。
