## 1. 前情（定谳勿重验）

- K1 双臂：欠穿透是物理真实（滴材料最深 1.3953 D < 阈 1.4859 D）。
- K2 五项收支：不闭合（|R|/E_scale = 1781.68%）；主导通道 = ⑦ 质量交换转换（248.98%）。
  机制：I→G 转换时被转液相质量的速度/动量在模型里**直接销毁**（气相速度为零），
  峰时刻轴向液柱动能只剩 11.1%；实验坑深只需 0.55% 撞击能量作重力位能 ⇒
  缺口在「能量送不进去」（惯性/动量分配侧），不在浮力侧。

## 2. 本单处方与实现（两臂赛马）

最小改动实现「动量携带转换」：I→G 转换时不再销毁被转质量的速度/动量。

| 臂 | 实现 | 语义 |
|---|---|---|
| ctrl | `momconv=off`（默认，位级不变） | 复现锚 1.4352204748 D @ 11.090571 ms |
| inherit | `momconv=inherit` | 气相胞**继承液相速度**：被转质量的动量注入转换胞所触及的 INTERFACE 胞（等分，界面注入）；继承速度同时作为 ABB 重建的气相速度 |
| redistribute | `momconv=redistribute` | 动量**按质量比重分配给邻液胞**：被转质量的动量按邻接 LIQUID 胞的受追踪质量份额分配 |

实现细节（`src/tensorlbm/free_surface_lbm.py`）：

- 新增 `free_surface_step(..., momconv="off", momconv_state=None)`；默认关 ⇒ **位级不变**。
- 转换点：`build_topology_transaction` 提交后，把被销毁的**受追踪质量动量** `m_D·u_D`
  （转换前 populations 的宏观速度 × 转换前受追踪质量）交给接收胞；
  接收方式为保密度动量踢 `Δf_q = 3 w_q (ΔP·c_q)`（精确加上 ΔP 动量、不改密度）。
- `inherit` 另记继承气相速度（跨步持久于 `momconv_state`），ABB 重建以之为气相速度。
- 诊断侧证：`budget_diag.py --diag-budget` 的 `conv_loss / conv_gain`（转换通道损耗）应显著下降。

| 量 | 门 |

| 实验判决点 | 坑深 1.857434 D @ 10.394 ms |

| **命中** | 某臂峰深相对实验 \|err\| < **12%** 且**存活 > 10.4 ms**（不死在实验时刻之前） |
| **证伪** | 两臂 \|err\| > **15%**，或两臂均**更浅**（峰深 ≤ ctrl）或**早死**（存活 < 10.4 ms） |

误差口径：err = (峰深_LBM − 1.857434) / 1.857434；存活 = 末次有效 history 的 time_ms。
