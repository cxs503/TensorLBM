## 1. 案例介绍（物理背景 / 几何 / 参数）

### 1.1 物理背景
船舶在碎冰区（brash ice / very close pack，C_i≈0.6，D50≈1 m）航行时，阻力由三部分组成：
冰-船接触力（法向挤压 + 切向摩擦）、冰-水-船两相流的阻塞/绕流效应、以及把浮冰排开/压沉所需的动量与浮力功。
本节点目标：**从第一性原理（DEM 接触力学 + LBM 流场 + 双向耦合）直接预测全船冰阻力，不依赖经验公式或 ML 代理**。

| 首柱倾角 φ | 20° |
| 船速 U | 1.5 m/s |
| 冰厚 h_ice | 0.15 m |

## 2. 方法（预报链 / 关键设置 / 工具链）

### 2.1 链架构（五个物理部件，`src/tensorlbm/ice_fullship/`）
```
floe_field.py   多分散浮冰场（RSA 无重叠装填）→ C1
lbm_porous.py   D3Q19 LBM 水相 + Darcy–Forchheimer 多孔冰层 + MEM 船体动量交换 → C2/C6
fsi.py          双向耦合审计：冰→流（覆盖率→孔隙系数）/ 流→冰（拖曳）→ C3
dem_field.py    船体坐标系 3D 浮冰 DEM（浮力/吃水/冰-冰/冰-船接触 + 摩擦）→ C4/C5
riska.py        参考模型（战役基线 Riska(1989) + Lindqvist 压沉项 + 排冰动量项）
chain.py        战役驱动：六条判据 + 图 + JSON
```

### 2.2 关键物理设置
1. **浮冰场**：直径服从截断对数正态；按“先大后小”的随机序贯吸附（RSA）无重叠装填，浮冰总体积按目标浓度反解，因此中值直径不被装填顺序截断（早期版本先达标即停，导致 D50 偏高 20%，已修正并在代码注释留痕）。
2. **水相（LBM）**：船体坐标系，入口给定速度 U，出口零梯度 + 质量守恒修正（把“外部注入的 −x 方向分布”按通量守恒因子缩放，使进出口净通量严格相等）；侧面/上下面为固体壁（bounce-back）；Re_L=200（稳态层流工况，LBM 在本链中的职责是“守恒、可收敛、可做网格研究”的水相引擎，不是复现全尺度湍流边界层——见 §5 局限）。
3. **冰→流阻塞**：冰吃水带（0.9h_ice≈0.135 m）在格点上远小于一格，故按物理体积权重 `(draft/Δz)/n_layer` 把 Darcy–Forchheimer 汇项分配到 2 层格点；渗透率用 Kozeny–Carman，惯性系数用 Ergun；**汇项作用在水-冰滑移速度**（船体坐标系中冰随流漂移，若当作静止多孔介质会把汇项高估约 50 倍）。
4. **船体受力**：半程 bounce-back 动量交换（MEM），把每个边界节点交换的动量投影到光滑化的壁面法向，得到**压差（法向）+ 摩擦（切向）**分解。
5. **冰相（DEM）**：船体坐标系，浮冰以 U 漂移，船体为 KVLCC2 偏移曲面 `|y|=b(x,z)` 的硬壁（脉冲/投影接触，无穿透）；冰-冰为弹簧-阻尼 + Coulomb 摩擦；垂向含浮力/吃水；x 向周期回收（下游出域的浮冰以 U 从上游重新注入）。
6. **FSI 双向**：冰位置→覆盖率图→局部孔隙系数（冰→流）；流场速度→逐冰拖曳（流→冰）；C3 用“独立重栅格化的汇项”与求解器实际施加的汇项对比。

### 2.3 工具链
PyTorch（LBM）、NumPy/SciPy cKDTree（DEM 邻域）、matplotlib（图）；重计算在 128 核节点上以后台/集群方式运行，单次 DEM 长程 40 000 步（40 s 物理时间）实际耗时 608 s。

### 3.3 C3 双向 FSI 动量交换（**FAIL**）
| 量 | 值 |
|---|---|
| 同一离散下的 Eular↔Lagrange 汇项残差（实现一致性） | 4.1e-8 |
| **独立加密重栅格化（sub=16）后的残差（真实粗粒化误差）** | **0.511** |
| 覆盖率均值 / 冰格点数 | 0.297 / 1 656 |

根因：格点尺度 11.5 m 与浮冰 1 m 相差 11 倍，冰覆盖率在格点上的**确定性映射不收敛**；同一离散下残差 ~1e-8 说明映射实现自洽，但粗粒化误差达 51 % → 判 FAIL。

### 3.4 C4 阻力分解能量守恒（**FAIL**）
DEM 势能/功率平衡残差 `|P_balance − R·U|/(R·U) = 1.43e9`。
根因：DEM 在受限水道内进入“挤压-弹射”状态（12 % 浮冰速度 >1.05U、峰值触及安全限速 6 m/s），
脉冲接触力以 1/dt 报出（1 ms 时步下单次碰撞即 1e5 N 量级），功率项被数值尖峰主导，**能量审计不闭合** → 判 FAIL。

### 3.5 C5 全船阻力 vs Riska(1989)（**FAIL，含根因）
| 模型/尺度 | R_ice [N] | 与链结果比 |
|---|---|---|
| **本链 DEM（40 s 物理时间均值，17565 冰）** | **6 047**（SEM 6 568） | 1.00 |
| 排冰动量（第一性原理：ρ_i C_i h B U²） | 5 996 | **1.008×**（0.85 %） |
| Lindqvist 压沉项 μ(ρ_w−ρ_i)g h B T·C_i | 6 697 | 1.108×（10.8 %） |
| **战役基线 Riska(1989) 实现**（`ship_hull_geometry.riska_ice_resistance`） | **1 563 246** | **258×** |
| ↳ 其 R_c 分量 0.5σ_c h²B/tanφ·ψ | 898 000 | — |
| ↳ 其 R_f 分量 μR_c(1+V/5) | 175 000 | — |
| ↳ 其 R_s 分量 C_s ρ_w g h B L C_b ψ | 490 000 | — |

判据要求 <15 %：与基线偏差 **99.6 %** → **C5 判 FAIL**。
同时报告（诚实、非替代判据）：链结果与两个独立第一性原理尺度分别差 **0.85 %** 与 **10.8 %**，
而基线 Riska 实现与这两个尺度相差 **230–260 倍**；其 R_s 项正比于 ρ_w g h B L C_b ψ（随机长/排水量放大），
不含 (ρ_w−ρ_i) 与真实的下沉体积，量纲上不是“压沉功”；其 R_c 项是**连续冰盖压溃**项，却被 ψ 缩放到碎冰场。
→ 结论：**基线参考模型对碎冰场（C_i=0.6, D50=1 m）不适用**（该发现记入 §6 缺陷登记）。

## 5. 注意点（踩坑 / 局限 / 适用范围）

1. **尺度分离是硬约束**：D50/L_pp = 1/230，浮冰在 LBM 格点上亚格；覆盖率映射的粗粒化误差 51 %（C3）不可通过换插值消除，必须换成“统计-孔隙闭包 + 局部 DEM 分区”架构。
2. **DEM 失稳的三次根因**（逐条留痕在代码注释里）：(a) 冰-船接触用强罚函数（k=5 MN/m）→ 挤压奇点；(b) 半宽表按吃水查错坐标系（应为 `T+z` 而非 `-z`），浮冰可深入船体 3 m 才触发接触；(c) 侧向刚性水道把 60 % 浓度的冰场压实成“塞子”，在尾部收缩段产生虚假推力。修正后仍有“挤压-弹射”残余 → 需 impulse-based 多体求解器 + 更小 Δt。
3. **LBM 的职责边界**：Re_L=200 稳态层流，仅用于守恒/耦合/网格研究；全尺度 Re≈3e8 的湍流边界层不在本链覆盖范围（阻力绝对值不可据此判读）。
4. **质量守恒的两种口径**：连续性残差 1e-7（真值，达标）；流域质量漂移 6.7e-3 是 float32 场求和的舍入下限，不是守恒失败——报告中两者并列，避免误读。
5. **不做经验拟合**：链中不含任何用实验/文献反标定的系数；冰-船摩擦系数 0.15、拖曳系数 1.0 均取文献典型值并给出敏感性（μ 线性影响摩擦分量）。

## 8. 结论与后续

本节点交付了可运行的完整预报链框架与六条机器判据的**真实数字**：浮冰场统计控制达标（1.34 %/0.32 %），
水相连续性达 1e-7，但多孔耦合工况不收敛、冰-流粗粒化误差 51 %、DEM 未统计收敛、网格研究不收敛；
因此**全船冰阻力尚不能宣称已由第一性原理预报**。

下一代工作（明确的下一步）：
1. DEM 换 impulse-based 多体后端（Project Chrono / 自研 split-impulse）+ 局部加密分区，目标 SEM/mean < 5 %；
2. 用“局部 DEM 分区 + 统计孔隙闭包”替代全域亚格覆盖率映射，消除 C3 的 51 % 粗粒化误差；
3. 阶梯船体换 immersed-boundary/BFL（仓库已有 `bfl_d3q19`），把网格研究拉回二阶，再战 C6；
4. 把 §3.5 的基线缺陷（R_s 随排水量放大、R_c 误用于碎冰）登记为平台参考模型缺陷，避免其他冰区节点继续误用。
