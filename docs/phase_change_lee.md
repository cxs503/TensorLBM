## 1. 案例与物理背景

单相 Stefan（一相）问题：半无限过热液体（过热度 ΔT = T∞ − T_sat）中气/液界面吸热蒸发，
界面温度钉在 T_sat，界面推进由界面导热通量提供潜热：

    ρ h_fg dR/dt = k_l ∂T/∂n|_int,      Ja = c_p ΔT / h_fg（密度相等理想化下 Ja = Ste）

- 参考解（平面、一相、Neumann 自相似）：`R(t) = 2λ√(αt)`，`Ja = √π·λ·erfc(λ)·e^{λ²}`；
  小 Ja 极限 `λ → Ja/√π`，即 **`R = 2 Ja √(α t/π)`** —— 正是战役 brief 给的锚公式。
- 柱（二维平面气泡，本仓二维实现对应此几何）：`e^{-2λ²}/E1(2λ²) = 2λ²/Ja`，`C=2λ`，存在上限 Ja≲0.205（无解）。
- 球（真实气泡）：`(e^{-λ²}/λ²)/(e^{-λ²}/λ − √π erfc λ) = 2λ/Ja`。

三个关系式与剖面都在 `stefan_anchors.py` 中实现并解析推导，`tests/` 里用相似 ODE 残差与 erfc 扩散解交叉验证。
**关键结论（可复用知识）**：战役锚 `2Ja√(αt/π)` 只是**平面+小 Ja**的首阶解；柱几何小 Ja 时 `C ≈ √(2Ja/ln(1/2λ²))`，
比锚大 2–4 倍，球几何 `C ≈ √(2Ja)`。因此对二维气泡必须用几何一致的精确解对标，锚仅适用于平面算例。

## 2. 方法（在 TensorLBM 里新增的两套闭合）

| 组件 | 实现 |
|---|---|
| 温度场 | D2Q9 / D1Q3 热 LBE（BGK，零速），`α = c_s²(τ−1/2)`；纯扩散步验证到 erfc 解析解误差 <0.01 |
| 源项（有限速率 Lee） | `m_dot = rate·h_fg·(T−T_sat)·ρ_g/(T_sat(ρ_l−ρ_g))`，能量源 `q = −h_fg·m_dot`（精确补偿） |
| 生产闭合（`rate→∞` 极限） | 气相加 `T = T_sat` Dirichlet（界面/气相饱和），界面按 Stefan 通量推进；界面温度由液侧三点二次外推**测量**（不施加） |
| 界面通量 | 三点 Lagrange 二次式在**实际前沿位置**求值（消除整格跳变的阶梯振荡）；二维用 16 条射线 + 双线性采样取平均（最近邻采样会使对角射线落入气相、通量塌陷 → 前沿停滞，是踩过的坑） |

全部使用格子单位、密度相等理想化（`c_p = h_fg = ρ = 1`，`T_sat = 1`，`α = 0.25`），故 `Ja = dT`。
四档过热度按 brief 的 1:2:5:10 线性映射：平面 `Ja = 0.01/0.02/0.05/0.10`，气泡 `Ja = 0.02/0.04/0.10/0.20`。

## 5. 注意点 / 局限（诚实清单）

1. **二维气泡的界面饱和判据 C3 未通过**：离散前沿 mask 使界面温度偏离 T_sat 约 1–2%·T_sat（≈5–20%·ΔT），
   远超 1e-3。一维平面在 Ja≤0.05 时几乎完全满足（偏差 ~2e-4）。
2. **二维气泡生长指数为 0.67–0.76 而非 0.5**：有限计算域（域半宽 64–256 格 vs ΔR≤10 格）+ 前沿整格跳变 +
   柱几何的对数型自相似（系数收敛极慢）共同造成；本节点的二维结果只能作为"定性标度 + 量级"结论，
   不能作为 §3 中"精确对标"的证据。诚实标注为 partial。
3. **C4 能量平衡是结构性恒等式**：前沿跟踪闭合里 `dR/dt` 由界面通量给出，`h_fg ΔR = ∫q dt` 自动成立。
   原本计划用"液侧显热减少 = 潜热生成"做独立检验，实测发现粗粒度的**气相 Dirichlet 逐步重置**交换了
   与潜热同量级（甚至 ~50×）的虚假能量（dT=0.1 平面算例：`injected_far=500.0` vs `latent=10.3`），
   故独立能量检验**不可用**，报告为 `independent_check=false`。这是本节点第一优先的后续项
   （改用半天真实界面 BC / 部分节点 bounce-back 或直接焓法 LBE 重写）。
4. 密度相等理想化（ρ_l = ρ_g）：忽略比容变化与气相压力功，与 brief 的 `Ja = c_p ΔT/h_fg` 定义一致；
   真实水蒸气 ρ_g/ρ_l ≈ 1e-3 时需改用 `Ja = ρ_l c_p ΔT/(ρ_g h_fg)`，锚的系数与几何关系需重算。
5. 计算预算：单算例受 99 分片 100 s 上限约束，最小过热度只能在粗网格、短窗口内跑（ΔR≈3 格），
   其系数误差（27%）主要来自离散化而非物理。

## 6. 误差判定（是否 <3%）

- 平面一相 Stefan 生长系数 vs 精确 Neumann：0.96% / 1.08% / 1.27% / 1.59% → **<3% ✔**
- 平面 vs 战役锚 `2Ja√(αt/π)`：1.71–2.42% → **<3% ✔**
- 网格收敛（系数最大相对变化）：0.17% → **<3% ✔**
- 三种子离散：0.32% → **<3% ✔**
- 二维气泡 vs 柱精确解：1.21%（Ja=0.20）到 26.94%（Ja=0.02） → **不满足 <3%**（如实报告 FAIL）
- 界面饱和：平面小 Ja ✔(<1e-3)；二维气泡 ✘(~5e-3)
