## 1 案例介绍

### 1.1 物理背景

LNG 船在部分充装工况下自由液面的低阶驻波与船体运动耦合：激励频率接近舱液一阶固有频率时发生共振，液面爬高并在舱壁产生冲击压力，这是围护系统（membrane）与舱壁结构疲劳载荷链的最上游量。IMO IGC Code 对部分充装晃荡评估有强制要求，ITTC 7.5-02-07-04.5 给出模型试验推荐程序。本节点把这条链的两个量——**共振频率**与**舱壁冲击压力**——放到可机器裁决的位置。

### 1.3 解析锚（REAL，闭式）

**(i) 驻波色散**（Abramson 1966 NASA SP-106 §2；Faltinsen & Timokha 2009 eq. 4.13）：

```
k_n = n·pi/L,   omega_n^2 = g·k_n·tanh(k_n·h),   f_n = omega_n/(2·pi)
f_1 = 0.659349 Hz,   f_2 = 1.152095 Hz   (L=1 m, h=0.2 m)
```

**(ii) 受迫横摇传递函数（本节点推导，REAL）**：舱体做 X(t)=X₀sin(ωt) 平动，模态展开 η(x,t)=Σ a_n(t)cos(k_n x) 后，自由面动力条件 `dphi/dt + g·eta = -Xddot·x` 投影到 Neumann 模态上（唯一的非零投影来自边界项 `∫₀ᴸ x·cos(k_n x)dx = ((−1)ⁿ−1)/k_n²`）给出：

```
addot_n + 2·zeta_n·omega_n·adot_n + omega_n^2·a_n = F_n,
F_n = -(2·Xddot/L)·((-1)^n - 1)·tanh(k_n·h)/k_n
      => 水平平动只激励奇模态（n 为偶数时 F_n ≡ 0）
      => |F_n| = 4·X0·omega^2·tanh(k_n·h)/(L·k_n)   (n 奇)
```

**静力自检（精确）**：ω→0 且加速度幅值固定时，奇模态和严格退化为刚体倾斜 `eta(x) = -Xddot·(x-L/2)/g`——`tests/test_sloshing_forced_p88w1.py::test_static_limit_reproduces_rigid_body_tilt` 以 2% 相对误差断言该恒等式，这是上述奇偶性与系数书写的独立校验。

**(iii) 压力锚**（Faltinsen & Timokha 2009 eq. 4.14 及冲击界）：线性壁面动压 `p(y)=ρg·a·cosh(k(y+h))/cosh(kh)`；Wagner 驻点界 `0.5ρV²`；涌波反射界 `ρgh(1+V/(2√(gh)))²`；静水爬高界 `ρg·η_wall`。

### 2.2 格子标定（GCI 的前提）

固定格子速度 `u_lat = u_char·Δt/Δx`，网格加密时 Δx、Δt 同步减半：Froude 数与格子 Mach 数保持网格无关，这是判据 d（2× 加密）成立的前提。基础网格的弱可压比 `3·g_lat·h_cells = 0.0132`（重力波相速偏置 < 2%），无滑移/可压性敏感度见 §3.5。

### 2.3 工况与测量

- **自由衰减**：η(x,0)=A·cos(k_n x) 静水释放（n=1,2），识别阻尼频率 f_d、极点关系 f_n=√(λ²+ω_d²)、阻尼比 ζ。
- **受迫扫描**：X₀/L=0.002（线性支）与 0.012（冲击支），f/f₁ ∈ [0.6, 0.7, 0.8, 0.9, 1.0, 1.1, 1.2, 1.4, 1.75]，覆盖一阶（1.00）与二阶（1.75）固有频率；斜坡 0.5 个自然周期抑止冲击起动。
- **测量量**：截面液高（Körner 质量账本，亚格子）、模态幅值 a₁/a₂/a₃（去壁面 2 列的投影）、舱壁动压 p_dyn=c_s²(ρ−ρ_ref)（前两列线性外推到壁面）在三个高度规（0.05h/0.5h/0.95h）。
- **识别**：受迫响应取**一阶谐波**最小二乘幅值（对瞬时尖峰鲁棒）；共振频率取扫描曲线最大值的三点抛物线细化；冲击支另取壁面爬高导数作为冲击速度 V。

## 5 注意点（局限与适用范围）

### 5.1 二维切片 vs B = 0.5 m
本节点的求解域是 L×H 的二维切片（x 沿晃荡方向，y 垂直）。任务书几何给出 B = 0.5 m，在此宽度下横向模态与纵向二阶模态近似简并（宽度方向 f_w = (1/2π)√(g·(π/B)·tanh(πh/B)) ≈ f₂），三维效应（横向驻波、角隅射流）不在本验证面范围内。**结论适用范围：B/L ≳ 1 的近似二维舱，或作为三维求解器的第一级验证。**

### 5.2 模型试验数据 = WITHHELD
判据 (b) 的原始表述要求与文献实验数据比对。本仓没有可用的数字化模型试验时历，**本次未做任何实验对标，也没有编造实验数据**：全部压力比较的对象是闭式解析锚（线性壁面压力、Wagner 驻点、涌波反射、静水爬高），证据等级因此为 REAL（解析）而非 REAL（实验）。ITTC 推荐程序下的实验对标应作为后续节点。

### 5.3 瞬时压力尖峰
壁面动压由前两列外推得到，在界面单元进出测量行时会给出尖峰（`raw_max` 与一阶谐波幅值可差数倍）。因此判据 b/d 一律用**一阶谐波幅值**，瞬时值仅作诊断；这也意味着本验证面不覆盖「空气卷入型冲击压力」（需多相可压缩 + 亚格子破碎模型）。

### 5.4 阻尼比的可辨识性
自由衰减在 4 个周期内的包络衰减低于可辨识下限，本次测得 ζ = 0.000000：相应受迫响应在 4 个强迫周期内**不进入稳态**，故线性参考用**有限时间 ODE 积分**（含起动斜坡与瞬态），而不是稳态 RAO。若要测量稳态共振增益，需要 ζ 更大的工况（更高 τ）或数十个周期的长时程。

### 5.4b 弱可压预算的适用边界（honest FAIL）
把格子 Mach 数从 u_lat=0.0035 提到 0.005（3·g_lat·h 由 0.0132 升到 0.0269）后，同一算例的液量账本漂移达 **+206.00%**、模态幅值放大 0.25 倍——该配置落在 Körner 自由液面模型在本网格下的稳定域之外，**本次敏感度实验判定为无效，不作为结论**。可用的弱可压预算仍以基准配置 3·g_lat·h = 0.0132（重力波相速偏置 < 1.5%）为准。

### 5.5 其他
1) 无滑移对照显示粘性边界层把 f₁ 拉低（§3.5），Abramson 锚为无粘理论，故主判据在 free-slip 下评估；真实 LNG 的 ν≈3×10⁻⁷ m²/s，格子粘性远大于水，这是 LBM 自由液面的固有局限。
2) 浅水/深水过渡：h/L = 0.2 属中等水深，色散关系用完整 tanh 形式（非浅水近似）。
3) 液舱为封闭顶盖（Körner 气相为常压），大振幅跑到舱顶时无气相压缩效应。
