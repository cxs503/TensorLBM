- 集群作业：**cj5053**（n330，8 核，全尺度梯度/内存门驱动器）、**cj5054**（n330，2 核，全尺度 τ 反演）；工件写回仓内 `artifacts/adjoint_ootc_acceptance/`（节点 /tmp 不随 fetch 回传——cj1625 教训）

## 1. 案例介绍（物理背景 / 几何 / 参数）

可微 LBM（JOUR-DIFFLBM 第 4 节成本/内存章）的长时域反演：D2Q9 BGK二维周期域内高斯密度脉冲衰减，反演松弛时间 τ（ν=(τ−1/2)/3），目标 J(τ)=½‖u_T(τ)−u_ref‖²，**无偏目标** u_ref=u_T(τ_true=0.8)（mission 22781 已证明 0.9 幅度缩放会让极小点偏离 τ_true 2%，本单不用）。

| 参数 | 值 |
|---|---|
| 网格 | 128×128（D2Q9，周期边界） |
| 时域步数 T | 10000（验收要求 10⁴） |
| 检查点间隔 k | 100 / 1000 |
| τ_true / τ_start | 0.8 / 1.2 |
| 初始脉冲 | amp=0.05, σ=16.0 |
| FD 步长 | τ: h=1e-4；f0 方向: h=1e-5 |

## 2. 怎么做的（方法 / 流程 / 工具链）

本单补的是锚点验收里**从未在全尺度跑过的两块**：

1. **全尺度 τ 反演驱动器**：mission 20040 在全尺度只跑了梯度/内存门（其反演 N=64/T=1000 且未收敛）；mission 22781 的收敛反演只有 N=32/T=600。本单用 `invert_tau`（括号保护 Newton/Illinois，信任域钳位）在 N=128、T=10⁴上从 τ₀=1.2 反演 τ_true=0.8，每次梯度评估用 OOTC 检查点重算（内存 O(k·N·Q)，与 T 无关）。
2. **可复算验收证据**：m20040 的全尺度工件只存在于未合并分支（agent/m20040），main 树数字不可复算（m22781 §5.4 明确欠账）。本单用 stage_dir 直送工作树重跑 `verify_ootc_acceptance.py` 全尺度驱动器，results.json 落进仓内并随本单提交。

工具链：numpy float64 逐位确定前向；5 个变体（BPTT 全存储 / OOTC k=100 / OOTC k=1000 / τ 中心差分 / f0 方向差分）各在独立子进程运行取干净 VmHWM；反演单进程顺序执行，VmHWM 逐阶段记录。

## 5. 注意点（踩坑 / 局限 / 适用范围）

1. **证据链**：results.json 的 git_sha 记为 unknown（stage_dir 直送的工作树在节点上不是 git 检出）；对应关系由本单 commit 固定——提交时scripts/ 与节点上执行的版本逐字节一致。
2. **模块内自洽 ≠ 正确**：OOTC 逐位复算 BPTT 公式，故 OOTC-vs-BPTT 门只证明实现一致；推导正确性由两条独立基准钉住（τ 中心差分 3.4e-6、f0 方向导数 7.7e-11），这是 m17532 D1/D2 缺陷的教训。
3. **单参数标量反演**：τ 是唯一参数；边界参数/多参数/初始场反演可复用 return_field=True 的 dJ/df⁰，但尚未做壁面情形。
4. **无偏目标是前提**：0.9 幅度缩放目标的极小点偏离 τ_true 2%（mission 22781），本单全部使用无偏目标。
5. 反演 nfev=16 中 3 次花在括号建立（τ₀、下界、上界各一次）；远场 J 渐近平坦是脉冲幅度指数衰减的物理性，驱动器必须带括号/信任域。

## 6. 误差判定（逐项，是否 <3%）

| 关键量 | 基准 | 误差 | <3%? |
|---|---|---|---|
| 恢复 τ* | τ_true=0.8 | rel 1.03e-13 | 是 |
| dJ/dτ（OOTC） | BPTT 参考（全尺度） | 0.0e+00 | 是 |
| dJ/dτ（BPTT） | 前向中心差分（全尺度） | 3.4e-06 | 是 |
| ⟨dJ/df⁰, v⟩ | 方向中心差分（全尺度） | 7.7e-11 | 是 |
| OOTC 峰值内存 | 8 GiB 门 | 0.26 GiB（3.2% of gate） | 是 |

**关键量是否 <3%？** 是——反演残差与梯度一致性均为机器精度量级，内存为门的 3.3%。验收两条（10⁴ 步 128² 峰值内存 <8 GiB；梯度 vs BPTT <1e-5）在全尺度直接满足，且证据落仓可复算。
