## ⑤ 注意点 / 局限
1. **仅 a=20 一档在本工作树跑完**。三档阶梯（a=20/40/80，同一代码同一判据）已递交集群
   作业 **cj4551**（TensorLBM，8 核，stage_dir=本工作树）；交单时仍在排队（递交 9 min 后
   queued，在飞约 93 单）。故本文件**不作 verified 声明**：`ladder/result.json` 与 G1–G4
   判定由 `run.py scan` 回传后程序化生成，`tests/...::test_ladder_verdict_is_recomputable`
   会从原始数字独立复算判定。
2. `curv_res` 偏大不是发散：该残差在**壁面格**上评估，half-way 反弹把无滑移面放在格间，
   二阶模板在 λ→1 的台阶过渡层上不成立（有效步长 <1 格）。它随 a 增大下降；主指标
   （中央区分箱/逐格）不受该层支配。本档 λ<0.85 仍含少量过渡格，故该数只作趋势诊断。
3. 反演 a_e−a=++0.676、b_e−b=+0.098 格：长轴端偏移明显大于
   短轴端，与既有 `../poiseuille_3d_ellipse/` 的**壁面各向异性**诊断同向。G4 把「0<Δ≤1 格」
   变成可证伪判据。
4. 解析解不含压缩性修正；本档 Ma=8.66e-03，该项 <1e-5。

## ⑥ 误差判定（逐项回答 <3 % ?）
| 关键量 | 基准 | 误差 | <3 % |
|---|---|---|---|
| 中心速度 Uc | 解析 g a²b²/(2ν(a²+b²)) | +2.909 % | 是 |
| 平均速度 / 流量 | 解析 Uc/2 | +7.312 % | 否 |
| λ 分箱剖面（反演几何） | (a_e,b_e) 解析 | 1.393 % | 是 |
| λ 分箱剖面（裸名义几何） | (a,b) 解析 | 17.592 % | 否（预期 O(1/a)，需 a>=40 档） |

**honest 结论**：单档积分观测量（Uc、流量）在 3 % 内；剖面最大误差在反演几何下
1.39 %、裸名义几何下 17.59 %（壁面偏移 ~0.5 格 ⇒ O(1/a) 效应，
a=40/80 档应进门）。三档阶梯未回传，**本单不声称 verified**。
