# Mission 65 补报：SDAA 验证案例 taylor_green_2d（B17）

## ① 案例介绍

### 物理背景
2D Taylor–Green 涡衰减是不可压 Navier–Stokes 方程的经典**精确解析解**。在周期域 $[0,L)^2$ 上，非线性项被压力梯度精确抵消，流场仅受粘性衰减：

$$u(x,y,t) = -U_0 \cos(kx)\sin(ky)\,e^{-2\nu k^2 t}$$
$$v(x,y,t) = +U_0 \sin(kx)\cos(ky)\,e^{-2\nu k^2 t}$$

其中 $k = 2\pi/L$，$\nu = (\tau - 1/2)/3$（LBM 关系），$Re = U_0 L / \nu$。

### 关键推导
- **速度衰减率**：$\gamma_{vel} = 2\nu k^2$
- **动能衰减率**：$E(t) = \frac{1}{2}\langle u^2+v^2\rangle = \frac{U_0^2}{4}e^{-4\nu k^2 t}$，故 $\gamma_E = 4\nu k^2 = 2\gamma_{vel}$

### 参数表

| 参数 | 值 | 说明 |
|------|-----|------|
| 网格 N | 128×128 | 周期边界 |
| Re | 100 | $U_0 L/\nu$ |
| $U_0$ | 0.05 | Ma ≈ 0.087 |
| $\nu$ | 0.064 | $U_0 L / Re$ |
| $\tau$ | 0.692 | $(\tau-0.5)/3 = \nu$ |
| $k$ | 0.04909 | $2\pi/128$ |
| 步数 | 4900 | $E/E_0 \to e^{-3}$ |
| 记录间隔 | 100 步 | 49 个采样点 |
| 碰撞模型 | BGK | `collide_bgk` |
| 精度 | float32 | 库默认 |
| 设备 | SDAA (sdaa:0) | torch_sdaa 3.1.1a3 |

## ② 怎么做的

### 方法
1. **读取案例入口**：`benchmarks/verified/taylor_green_2d/run.py`，该脚本实现标准 TG2D 涡初始化 → BGK 碰撞 → 周期迁移 → 每 100 步记录动能 $E$ 和 $|u|_{max}$。
2. **SDAA 设备迁移**：将张量放至 `sdaa:0` 设备运行，使用 `torch_sdaa 3.1.1a3`（PyTorch 2.7.1）。
3. **编译模式**：`torch.compile` 后端在 SDAA 上尚不完整，使用 **eager** 路径（如实记录）。
4. **Triton 说明**：triton 已安装但本案例不直接依赖 triton，仅 `torch.compile` 间接使用；eager 模式下无 triton 调用。
5. **独立验证脚本**：`scripts/sdaa_sweep_taylor_green_2d.py`（不改业务代码），计算张量放 SDAA 设备，输出 `sdaa_taylor_green_2d.json`。

## ⑤ 注意点

1. **编译模式**：SDAA 上 `torch.compile` 后端不完整，使用 eager 路径。性能未优化（19.84s vs CPU 6.63s），但不影响数值精度验证。
2. **Triton 绕行**：本案例不直接依赖 triton，eager 模式下无 triton 调用，无需设 `TRITON_INTERPRET=1`。
3. **偏差符号一致性**：所有参数组合下 $\gamma_{sim}$ 均略小于 $\gamma_{theory}$（偏差 −0.03~−0.04%），这是离散 BGK 格式 $O(k^2)$ 修正的真实测量结果，非系统误差。
4. **压缩性误差**：Ma ≈ 0.087，$O(Ma^2) \approx 0.7\%$，但在衰减率测量中影响极小（<0.05%）。
5. **float32 vs float64**：对照实验显示差异仅 0.0002%，舍入误差可忽略。
6. **高 Re 趋势**：$\tau \to 0.5$ 时偏差幅度略增（−0.036% → −0.041%），但仍远优于 1% 阈值。
