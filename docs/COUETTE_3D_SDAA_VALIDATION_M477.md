## 1. 案例介绍 (Case Introduction)

### 物理背景
Couette 流是流体力学经典基准问题，描述两平行平板间粘性流体在相对运动驱动下的层流。上板以速度 U₀ 运动，下板静止，形成线性速度剖面。该问题具有解析解，是验证数值方法精度和边界条件实现的理想基准。

### 几何与参数
| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 通道高度 | H | 8, 16, 32, 64, 128 | 网格分辨率（格子数） |
| 上板速度 | U₀ | 0.05 | 无量纲速度 |
| 松弛时间 | τ | 0.8 | BGK 碰撞参数 |
| 运动粘度 | ν | 0.1 | ν = (τ-0.5)/3 |
| 雷诺数 | Re | 7.99 - 63.99 | Re = U₀H/ν |
| 马赫数 | Ma | 0.0866 | Ma = U₀/cₛ, cₛ = 1/√3 |
| 格子模型 | - | D3Q19 | 三维19速度模型 |
| 碰撞模型 | - | BGK | 单松弛时间 |
| 边界条件 | - | Moving wall BB | 半程反弹格式 + 动量注入 |

### 解析解
稳态 Couette 流的解析解为线性速度剖面：
```
u(y) = U₀ · (y - 0.5) / H_eff
```
其中 H_eff = ny - 2 为有效通道高度，y 为壁面法向坐标。

## 2. 方法 (Methodology)

### 数值方法
- **格子 Boltzmann 方法 (LBM)**：D3Q19 模型，BGK 碰撞算子
- **边界条件**：移动壁面反弹格式（pre-streaming），包含动量注入项：
  ```
  f_wall = f_pre[opposite] + 2·w·ρ_w·(c·u_wall)/cₛ²
  ```
- **初始化**：解析速度剖面（修复了早期版本的 z-plane 零化 bug）
- **稳态判据**：顶部速度漂移 < 1e-5（连续 10 个采样点）

### 工具链
- **代码仓库**: TensorLBM (branch: agent/m477)
- **求解器**: tensorlbm.d3q19 + tensorlbm.solver3d
- **硬件**: CPU (无 GPU 可用)，fp32/fp64 双精度测试
- **诊断脚本**: runs/couette_3d_m477/diag_couette3d.py

### 关键修复
历史诊断发现 skeleton 版本存在初始化 bug：
```python
# BUG: 错误地将 z=0/z=nz-1 平面零化（从 2D 版本复制的索引错误）
u0[0, :, :] = 0.0
u0[-1, :, :] = 0.0
```
修复后在所有格子点上应用解析剖面，消除了横向非均匀性。

## 5. 注意点 (Notes & Caveats)

### 踩过的坑
1. **初始化 bug**：早期 skeleton 版本从 2D 复制了壁面索引逻辑，错误地将 z=0/z=nz-1 平面零化，导致横向非均匀性（spanwise std ~1e-3）。修复后在所有格子点应用解析剖面。
2. **计算成本**：3D 案例在 CPU 上极慢（H=32 fp64 需 ~360ms/step，6000 步需 36 分钟）。本次诊断受限于无 GPU 环境，仅运行 H=8 案例。
3. **fp32 时间累积误差**：fp32 精度随时间步线性累积（diag_dtype.json 证据），长时间运行需使用 fp64。

### 局限性
- **硬件限制**：本次诊断在 CPU 上运行，未能复现 GPU/SDAA 设备环境。但历史验证结果（result.json）已在 GPU 集群上完成 H=16-128 四档测试。
- **网格范围**：本次仅运行 H=8，历史验证覆盖 H=16-128。

### 适用范围
- **低马赫数**：Ma = 0.0866 < 0.3，满足 LBM 不可压假设
- **层流 regime**：Re = 8-64，远低于湍流转捩
- **稳态问题**：Couette 流为稳态解，瞬态过程不作为验证目标
