## 1. 案例介绍（物理背景/几何/参数）

三维椭圆截面直管（半轴 a:b = 2:1）内充分发展层流，速度入口 + 压力出口驱动，
管壁无滑移。解析解（稳态、充分发展、不可压、无滑移）：

```
u(y,z) = U_max·(1 − y²/a_eff² − z²/b_eff²)，U_max = 2ū = 2u_in
```

**验证欠账**：`benchmarks/pending/poiseuille_3d_ellipse/` 记录 s^Q 单尺度比较
在 a=20 档失败（**5.107% > 3% 门**，a=40 档 2.432% 过线），根因 = 数字楼梯
椭圆壁的**各向异性**水力几何无法用单一面积等效尺度表达（非求解器缺陷——
实测剖面是精确椭圆抛物面，拟合残差 <0.2%）。

**推广路径**（benchmarks/TODO.md 命名）：**两观测量（Q + 充分发展压力梯度 G）
水力反演**有效半轴 (a_e, b_e)，随后逐格剖面比对解析椭圆抛物面。

## 2. 怎么做的（方法/流程/工具链）

本单闭合**解析核**（反演数学必须精确，模拟的 Q/G 观测量才可信），不跑重 3D 模拟：

1. **解析关系**（连续椭圆 a_e,b_e，稳态充分发展无滑移）：
   - `Q = π·a_e·b_e·U_c/2`（积分观测量）
   - `G = 2ν·U_c·(a_e²+b_e²)/(a_e²·b_e²)`（积分观测量，G=dp/L）
   - 反演（U_c=2u_in 施加）：`P=(a_e·b_e)²=(2Q/(πU_c))²` ← Q；
     `S=a_e²+b_e²=G·P/(2νU_c)` ← G；`a_e=√((S+√(S²−4P))/2)`。
2. **质量守恒重整化**（纯几何，无剖面拟合）：`U_c' = Q/M_d`，
   `M_d = Σ_{数字流体格}(1−(y/a_e)²−(z/b_e)²)`。
3. **测试**：`tests/test_poiseuille_3d_ellipse_hydraulic_inversion.py`（9 项）
   验证反演往返恢复、各向异性几何可分辨、Q 单观测量不足、质量守恒重整化、
   解析剖面是精确椭圆抛物面。

## 5. 注意点（踩过的坑/局限/适用范围）

- **本单只闭合解析核**：反演数学已机器验证，但**尚未跑通重 3D 模拟**——
  `run_hydraulic.py` 在 120s 超时被收割（3D 椭圆管 43×23×120 格、2-6 万步，
  CPU 单节点重算）。完整闭合需上集群（run_cluster）跑 a=20/a=40 两档，
  用实测 Q/G 反演 (a_e,b_e) 后逐格比对。
- **s^Q 单尺度失败是各向异性几何**：Q 单观测量只固定乘积 P=a_e·b_e，
  半轴比自由；G 是第二观测量固定和 S=a_e²+b_e²——这是数学上 s^Q 无法
  闭合各向异性壁欠账的原因（测试 `test_inversion_requires_two_observables` 钉死）。
- **适用范围**：稳态充分发展层流、连续椭圆壁；数字楼梯壁的逐格散布
  （per-cell 15.86%/6.18%）是已知一阶收敛效应，不属本核。
