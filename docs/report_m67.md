## 1. 案例介绍

3D Taylor-Green 涡衰减是验证不可压 NS 求解器的经典基准。周期域 [0,N)³，初始场：

$$u_x = U_0 \sin(kx)\cos(ky)\cos(kz), \quad u_y = -U_0 \cos(kx)\sin(ky)\cos(kz), \quad u_z = 0$$

$k = 2\pi/N$，$\nu = U_0 N / Re$。3D TG 非 NS 精确解——涡拉伸从 t=0 驱动 w 增长。

**线性理论**：波矢 $(\pm k,\pm k,\pm k)$ → $|\kappa|^2=3k^2$ → $\gamma_E = 6\nu k^2$。

| 参数 | 值 |
|---|---|
| 格子/碰撞 | D3Q19 / BGK |
| 边界 | 三周期 |
| U₀, Re | 0.05, 24 |
| 网格 | 64³, 96³, 128³ |
| 步数 | 2000/2000/2600 |
| 设备 | SDAA, torch_sdaa 3.1.1a3 |

## 2. 方法

1. 独立脚本 `scripts/sdaa_sweep_taylor_green_3d.py`，不改业务代码
2. 张量全部在 SDAA 设备创建/计算
3. 共性模块：`collide_bgk3d` + `stream3d` + `equilibrium3d` + `macroscopic3d`
4. eager 模式（SDAA teco_inductor 对 LBM 不完整）；无 Triton 依赖
5. 每 50 步记录 E(t)；对 ln(E) 线性拟合得 γ_E,sim

**判据**：|γ_E,sim/γ_E,theory − 1| ≤ 3%；网格单调收敛；R² ≥ 0.999

## 5. 注意点

1. **2D/3D 公式陷阱**：任务书 e^{−2νk²t} 是 2D 速度衰减率，3D 应为 6νk²（动能）。误用报 +200%。
2. **涡拉伸**：3D TG 非精确解，γ_sim 略高于理论 +0.25~0.31%，物理真实效应，不修正。
3. **固定 Re**：固定 τ 时 Re_eff∝N，err 不收敛。须固定 Re=24。
4. **SDAA eager 模式**：teco_inductor 不完整，不影响精度。
5. **无 Triton**：纯 PyTorch 张量运算。
6. **适用范围**：低 Re 层流（Re_eff≈3.82）。高 Re 转捩需额外验证。
