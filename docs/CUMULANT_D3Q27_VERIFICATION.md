# D3Q27 碰撞算子验证面：BGK / KBC / cumulant 的伽利略不变性、可实现性与高 Re 稳定域

**战役节点** p246w2-n01 · 仓库 TensorLBM · 支部件 `src/tensorlbm/cumulant_verification.py`

**一句话结论**：把「碰撞算子怎么选」从经验变成可测这件事，本节点给出的答案是——**应力通道的伽利略不变性缺陷不是算子属性**（BGK 与 cumulant 在 Ma=0.1 下相差 6.9e-04 相对量级，两者同在 8e-3 量级且严格 ∝ Ma²），因此任务书 A3 的「cumulant ≤1e-10」判据在标准二阶平衡函数 + 晶格平流的框架下**不可达**（honest FAIL，机制已定位并给出替代判据）；真正分离算子的通道是**稳定域（A5）与可实现性（A4）**。

## ① 案例介绍

研究对象是 D3Q27 格子上的三种碰撞模型在同一套算例上的可直接比较行为：

* `bgk`：单弛豫时间 BGK（`d3q27.collide_bgk27`），基线算子；
* `kbc`：熵条件 KBC（`entropic_kbc.collide_kbc_d3q27`），β 用二分法解 H 定理；
* `cumulant`：Geier 2015 累积量算子（`cumulant.collide_cumulant_geier_d3q27`），按阶分层 ω₁..ω₄（默认 ω_b = ω₃ = ω₄ = 1）；
* `cumulant_single_rate`：A7 负控，令全部高阶速率 = 1/τ，即动量空间的单速率退化极限；
* `no_collision`：控制组，纯平流无碰撞（只用于分离缺陷来源）。

统一参数：ρ₀=1，c_s²=1/3，float64，全部算子共享 `d3q27.stream27_roll` 平流与同一初始场；除 τ 与算子外没有任何逐算子调参。

四个物理试验台（全部在同一模块内实现，可独立复跑）：

1. **平衡函数矩恒等（A1）** + **变换可逆/守恒（A2）**：20 组随机 (ρ∈[0.6,1.6], |u|≤0.3) 状态；
2. **伽利略不变性台（A3/A7）**：剪切波 `u=(U, A sin kx, 0)` 叠加均匀流 U，以 Chapman–Enskog 一阶非平衡态起步（`f_i^(1)=K w_i c_ix c_iy s`，`K=−2(τ−½)/c_s²`，给出精确 `Π_xy^neq = −2ρc_s²(τ−½)s`）；观测量取 `Π_xy^neq` 的 Fourier 模幅值（平移只改相位，故对均匀流平移不敏感）；
3. **可实现性台（A4）**：协方差矩阵 `κ_ij=Π_ij−ρu_iu_j` 的最小特征值 + 密度正性，逐 20 步在线监测；
4. **稳定域台（A5）**：32³ 周期 Taylor–Green 涡，τ∈0.5+{5e-2…2e-4} 扫描，对应 Re=U·2π/ν = 19…4.7e3（晶格单位）；另加 Poiseuille 通道（A6）对解析抛物线。

## ② 怎么做的

方法论上做了一件关键的事：**先把「缺陷」定义清楚，再测**。任务书的「比较 Π_ij 在 U→0 与 Ma≤0.3 下的偏差」在实现上有三种互不等价的定义，本节点把三种全部测了（定义矩阵），因为单一数字会被定义选择污染：

* **D1（单步碰撞）**：同一状态（含相同非平衡量）在 Ma 与 Ma=0 下各做一次碰撞，比较碰撞后 `Π_xy^neq`，**不含平流**，只测量碰撞算子本身；
* **D2（应力模幅值）**：`Δ = max_t |Â_Ma(t) − Â_0(t)| / Â_0(t)`，Â 为 `Π_xy^neq` 的 k 模幅值，含平流，取 300–600 步稳态窗口；
* **D3（输运系数）**：晚窗内剪切波衰减率 `λ` 的相对偏差 `|λ_Ma/λ_0 − 1|`，这是「在运动参考系里黏性是否不变」的直接量。

对照设计（控制变量）：

* **幅值对照**：A=1e-3 vs 2e-2，若两个幅值给出的 D3 相同 → 缺陷是线性响应，不是碰撞算子非线性项造成；
* **无碰撞对照**：关掉碰撞只留平流，测量缺陷里有多少是纯平流/平衡函数带来的；
* **单速率负控（A7）**：所有松弛速率取 1/τ，算子应退回 BGK 的缺陷行为；
* **同网格 τ 扫描**：Re 只由 τ 决定（`ν=c_s²(τ−½)`，`Re=U·2π/ν`），所以「稳定域边界」是直接测量，不是拟合；
* **低 Mach 复核**：u₀=0.02 与 0.05 两套，把 Ma 与 Re 两个轴分开。

工具链：PyTorch 2.7.1（loongarch64，float64），`experiments/cumulant_d3q27_verification.py` 分片跑（`--shard i/n`），每份结果自带 `meta.command / git_head / torch / threads` 审计链；报告由 `experiments/render_report.py` 从 JSON 程序化生成（零手抄）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **Poiseuille 必须先确认收敛再谈精度**：τ=0.55 时通道扩散时间 H²/ν≈1.5e4 步，6000 步的结果给出 8.2% 的「黏性误差」，其实是瞬态未走完；改 τ=0.8 并加收敛判据后剖面误差 5e-4、黏性误差 1e-8（18600 步，见 ③ A6 表）。这条是本节点最贵的一次教训：**误差数字必须先过「是否收敛」这一关**。
2. **单步碰撞测不出算子差异**：D1 对所有算子（含无碰撞控制组）都在 1e-14，因为 `Π_xy` 的松弛在动量空间就是 `(1−ω)`，二阶累积量与二阶中心矩恒等。任何「一次碰撞即可判定伽利略不变性」的说法都应被视为退化判据。
3. **缺陷依赖观测量**：同一份数据，D2/D3 是 8e-3，D1 是 1e-14。报告缺陷时必须同时写定义、归一化、观测窗口，否则数字不可比。
4. **KBC 的偏离不是「更差的不变性」而是「不同的有效黏性」**：KBC 的 β 由熵条件决定，等效地把有效松弛率压低，所以 D3 比 BGK 大 57%；这与伽利略不变性是两件事，不能混为一谈。
5. **适用范围**：Ma≤0.3、单相、等温、D3Q27、周期/半格反弹边界；伽利略结论只在无外力、无壁的周期算例上测得，不外推到高 Ma 可压缩 LBM 或强外力气固耦合情形（A6 通道用的是半力分裂力项，仅用于黏性/剖面标定，不用于伽利略判据）。
6. **KBC 的二分分辨率**：分片运行里 `kbc_max_iter` 未显式传入，实际用库默认 24；为控成本，专用 KBC 复核（`stability_kbc.json`）显式用 8。两种设置在 Re=471/942/4712 上都判为存活，β 分辨率不改变本节点的排序结论；各文件 `settings` 字段保留原始取值以便审计。
7. **一个被抓住的驱动 bug**：初版 `_stability_configs()` 的低 Mach 分支写成了 `tau=5e-3`（漏加 0.5），会在第 4 个配置抛 `ValueError` 并连带丢掉整个分片的已完成行。发现方式：分片日志计数卡在 3 行 + 配置表打印复核。修复（`tau = 0.5 + dtau` + 逐配置 try/except）后重跑受影响的行，重跑值与本文件一致（见 `stability_ded_*.json`）。**教训：批量扫描的配置生成必须先打印复核**。
8. **未完成项**（honest）：圆柱绕流 Cd（A6 第二条）未运行，理由见 ⑥；A4 的 1e5 步长程只跑到实际步数（见上表），未达任务书步数；低 Re 段的 τ−½=5e-2…2e-2 三个算子的行因共享机时紧张被裁剪（BGK 在这些点已确认存活，未影响边界判定）。

## 结论与可用判据（把「怎么选算子」变成可测）

1. **应力通道的伽利略不变性不能用来选算子**：BGK/cumulant/single-rate 三者在 Ma=0.1 的缺陷同一量级（相对差 6.9e-04），且严格 ∝ Ma²、与幅值无关、单步碰撞为零 → 缺陷来自「二阶平衡 + 晶格平流」的组合，而不是碰撞算子。任务书 A3 对 cumulant 的 1e-10 判据在该框架下不可达（honest FAIL），本节点给出的替代量是 D3（运动参考系中的输运系数偏差）。
2. **能选算子的是稳定域与可实现性**：同网格同初值下 `Re_max(算子)` 与「失稳前是否先破可实现性」是直接测量量（见 ③ 表与图 2/4）。
3. **可实现性是「有条件」的先行探测器**：BGK 类失效在 20 步监测分辨率下先出现 `λ_min(κ)<0`（早于发散 20 步）；但单速率退化算子的高 Re 失效在 `λ_min>0`、密度仍正时发生，故哨兵必须同时监测 λ_min 与 ρ/f（`covariance_spectrum` + 密度正性），不能只看其一。
4. **稳定域边界随 Ma 移动**：u₀=0.02 时 BGK 在 Re=1571 仍存活，u₀=0.05 时在 Re=942 已崩溃；所以选型判据必须写成 (Ma, τ, 网格) 的函数，本节点给出的是两个 Ma 切片上的直接测量表。
