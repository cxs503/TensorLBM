# 冰晶/碎冰悬浮液有效粘度闭合的 LBM 标定（IN13-W4-N02）

## 1 案例介绍（物理背景 / 几何 / 参数）

海冰初生阶段的 frazil 冰晶是悬浮在过冷海水中的多分散近球形/片状颗粒群体。其体积分数从稀薄（$\phi\sim0.01$）增长到接近堆积（$\phi\gtrsim0.3$），宏观流变由**相对粘度** $\eta_r=\eta_{eff}/\eta_f$ 描述；冰区航行/冰水耦合的 Bingham 与 $\mu(I)$ 内核需要一条可调用的 $\eta_r(\phi)$ 闭合。本节点用 D3Q19 格子 Boltzmann 剪切元胞直接测量硬球群体在简单剪切下的 $\eta_{eff}=\tau_{wall}/\dot\gamma$，标定三条闭式（Einstein / Batchelor / Krieger–Dougherty）的适用域，并把 $\eta_r(\phi)$ 作为 Bingham/$\mu(I)$ 内核的 $\phi$-依赖输入（插值契约）。

| 项 | 值 |
|---|---|
| 元胞 (nx×ny×nz) | 32×32×45（z 为壁法向） |
| 壁面有效间隙 | nz−2 = 43 lattice（half-way bounce-back） |
| 输入粘度 $\nu$ | 0.1 lattice |
| 壁速 $u_w$ | 0.02 → $\dot\gamma=2u_w/(nz-2)$ |
| 颗粒半径 a | 4.0 lattice（D/a=2） |
| 壁面排斥带 | 7 lattice（颗粒不进入取样带） |
| 步数 / 预热 | 1700 / 850 |
| 工况数 | 16 |

## 2 怎么做（方法 / 流程 / 关键设置）

**(a) 数值内核前置门**：单球绕流阻力对 Stokes 解 $F=6\pi\mu aU$ 在 D=8/12/16 三档网格上复算，并给出网格收敛指数 GCI（$p=2$，$r=D_{fine}/D_{coarse}$）。

**(b) 剪切元胞**：z 为壁法向，上下两壁以 $\pm u_w$ 反向运动（moving-wall bounce-back），x/y 周期。剪切率由**实测速度剖面的线性拟合斜率**给出（不用名义值），并报告拟合 $R^2$。

**(c) 颗粒动力学**：每个颗粒按 imposed rigid-body motion 运动——平动取当地基流速度 $\dot\gamma(z_c-z_{mid})$，转动取半涡量 $\Omega=\dot\gamma/2\,\hat y$，使颗粒在 Stokes 的意义上无力/无力矩（Einstein $[\eta]=5/2$ 成立的前提）。颗粒表面速度通过 bounce-back 的速度项施加（$f_{\bar q}=f^*_q-2w_q(\mathbf c_q\cdot\mathbf u_w)/c_s^2$；符号由纯流体 Couette 精确解标定）。

**(d) 应力测量**：壁面附近（无颗粒带）的**离散动量通量** $\Pi_{xz}=\sum_q c_{qx}c_{qz}(f_q-f_q^{eq})$，按 BGK 的解析关系 $\Pi^{(1)}_{xz}=-\tau c_s^2\rho\dot\gamma$ 与 NS 应力 $-\nu\rho\dot\gamma$ 的比值 $\tau/(\tau-1/2)$ 做偏置校正，得到物理单位的总应力。该平面不含颗粒，故动量通量即悬浮液总应力（无力颗粒的动量平衡）。

**(e) 相对粘度**：$\eta_r=(\tau_{susp}/\tau_{pure})\cdot(\dot\gamma_{pure}/\dot\gamma_{susp})$，同一套测量在同一壁速下做比值 → 测量器的乘性偏置与壁位误差在比值中相消。

**(f) 闭合标定**：稀薄区线性回归得 $[\eta]$ 与截距；半稀区对 Batchelor 逐点相对误差；全域对 KD 做单参数 $\phi_{max}$ 最小二乘（对数残差，golden-section）；然后把三支装配成 C1 连续契约（smootherstep 混合窗），供 Bingham/$\mu(I)$ 内核调用。

## 5 注意点（坑 / 局限 / 适用范围）

1. **壁面位置**：half-way bounce-back 的有效壁面在壁节点外 0.5 lattice，有效间隙是 `nz-2` 而不是 `nz-1`；用错会让剪切率与应力同时偏 6%（nz=17 实测 16/15）。这是纯流体负控发现的，也正是判据(e)存在的理由。
2. **动壁 MEM 的平衡态背景**：直接对动壁做 Ladd 求和会出现大数相消（本工况偏差接近 O(1)），不能直接用作应力测量；改用以 NS 关系校正后的平面动量通量。
3. **颗粒必须无力/无力矩**：Einstein 5/2 的前提是自由转动；把球钉死或反转会显著改变 $[\eta]$（实测反转时 $[\eta]$ 可翻数倍）。本实现用半涡量刚体转动 + 当地基流平动。
4. **阶梯球几何**：离散球体积与解析值差几个百分点，故 $\phi$ 一律用离散掩膜节点数；曲率误差体现在 stresslet 上，由 D=8/12/16 的阻力门与 GCI 定量。
5. **$Re_p$ 覆盖**：$[0.01,1]$ 区间可覆盖；$[1,50]$ 需要更高 $\dot\gamma$ 或更低 $\nu$，受 Ma 与 BGK 稳定性限制，本节点只做到 $Re_p\sim$ 个位数，更高 $Re_p$ 的 $\mu(I)$ 支用文献形式外推并在报告中标为未覆盖（honest 限制）。
6. **统计量**：颗粒位置是冻结的，构型噪声只能靠多 seed 平均；稀薄区已用 2 seed。
7. **非球形颗粒**：片状颗粒的取向应遵循 Jeffery 轨道，本节点对近球形（多面体）颗粒用冻结半涡量转动是合理的，但对强非球形只给趋势、不作定量承诺。
