## ① Case, geometry, parameters

Periodic box in lattice units (`Δx = Δt = 1`), D3Q27 BGK, `float64`.
Initial field = the classic (z-dependent) Taylor-Green vortex
(Taylor & Green 1937, *Proc. R. Soc. A* 158:499, doi:10.1098/rspa.1937.0150):

```
u = A sin kx cos ky cos kz,  v = -A cos kx sin ky cos kz,  w = 0,  k = 2π/N
```

| parameter | value |
|---|---|
| primary grid | 32³ |
| amplitude A / Ma | 0.05 / 0.0866 |
| Re = A·N/ν | 160 |
| ν / τ | 0.01 / 0.53 |
| steps to T = 1.0 | 102 |
| series order | 12 |

Why this field and not the z-invariant one: the z-invariant mode's convective term is a gradient
(`‖∇×(u·∇)u‖/‖(u·∇)u‖ = 2.9e-15`, machine-checked), so it never produces
`w ≠ 0`, vortex stretching or enstrophy production. The classic field does
(ratio 0.227) and therefore has **no closed form** — which is why the
reference must be a series.

## ② Method

1. **Reference** — `TG3DSeries` (`src/tensorlbm/tg3d_series.py`): write
   `u(x,t) = Σₙ tⁿ u⁽ⁿ⁾(x)`, project the NS equations (Helmholtz) and equate powers of `t`:
   `u⁽ⁿ⁺¹⁾ = (νΔu⁽ⁿ⁾ − P Σⱼ (u⁽ʲ⁾·∇)u⁽ⁿ⁻ʲ⁾)/(n+1)`. Exact spectral derivatives, no time
   discretisation (Morf–Orszag–Frisch 1980; Brachet et al. 1983).
2. **Pin the reference before using it** (this is the part that was missing from the pool):
   applied to the z-invariant mode and to the Beltrami/ABC flow — both exact NS solutions — the
   series must reproduce `exp(−ν|k|²t)` decay to machine precision: measured
   **2.2e-16** (Q0). Its own truncation is bounded by moving two knobs:
   order 10 → 12 changes the reported ratios by **1.3e-04** (Q8) and the working grid
   60 → 72 by **8.9e-16** (Q9).
3. **Measurement** — periodic D3Q27 BGK run (`run_tg3d_lbm`), sampled 10× per eddy time, compared to
   the series (a) as decay ratios, (b) field-by-field in velocity and spectral vorticity at T,
   at fixed Re over a grid ladder.
4. **Toolchain** — numpy/torch float64; all numbers written by `run_case.py` into
   `artifacts/summary.json`; tables/figures regenerated by `make_report.py` (zero hand-copying).

## ⑤ Caveats

* **Q4 carries a reference-truncation component.** The series is represented on a 2/3-dealiased
  grid, so its retained spectrum is capped at `nfft/3` no matter the order:
  `dealias_margin()` returns `margin == 0` *by construction* and is **not** a safety statement
  (an earlier reading of it as one was wrong). The honest bound is the observed spread
  1.3e-04 (Q8), i.e. the vorticity error is dominated by the LBM side, not the reference.
* **Fixed-Re ladder.** ν = A·N/Re means refining N also refines τ; the ladder is a
  physically-fixed-Re refinement, not a pure Δx refinement at fixed ν.
* **Coarse end honestly fails**: N = 16 gives 3.76 % / 4.40 % (> 8 %). Only N ≥ 24 is inside the band.
* Series validity: T ≤ 1.25 eddy times; beyond the convergence radius the reference degrades.
