# Mission 70 — SDAA Sweep: Wigley Hydrostatics Verification Report

## 1. 案例介绍

### 物理背景
Wigley 抛物线船型（Wigley, 1934）是船舶耐波性与静力学验证的经典基准体。其几何由抛物线函数精确描述，所有静水力系数均有封闭解析解，是检验体素化（voxelization）精度与网格收敛性的理想案例。

### 几何与参数
| 参数 | 值 | 说明 |
|------|------|------|
| 船型 | Wigley parabolic hull | 抛物线母线 |
| L (船长) | 640 / 960 voxels | 两级网格 |
| B (船宽) | 按比例 | L/B 固定 |
| T (吃水) | 按比例 | L/T 固定 |
| 对称性 | 中纵剖面对称 | LCB/L = 0 |

### 验证范围
**仅限静水力几何系数（geometry + static closure）**——不涉及自由液面压力场、耐波性运动或波浪载荷。自由面架构的已知限制（"no free pressure field" gap）已在 `docs/free_surface_architecture_gaps.md` 中记录。

## 2. 方法

### 计算流程
1. **体素化**：使用库内 `wigley_hull_mask` 函数生成 Wigley 船体的三维体素掩码（bitwise-identical 到库实现）
2. **分块内存安全**：z 方向按 chunk=32 分块计算，避免大网格 OOM
3. **设备**：SDAA（`/dev/tcaicard2`），纯 PyTorch tensor ops，无 Triton 依赖
4. **积分**：对体素掩码做离散求和得到排水体积 V、水线面面积 A_wp、中剖面面积 A_m，进而计算各系数
5. **水线面暴露检测**：`exp[k] = mask[k] & ~mask[k+1]` 提取水线面暴露面元

### 解析基准（Wigley 1934 封闭积分）
| 系数 | 解析值 | 来源 |
|------|--------|------|
| C_B | 4/9 ≈ 0.4444 | Faltinsen, Lewis |
| C_wp | 2/3 ≈ 0.6667 | 同上 |
| C_M | 2/3 ≈ 0.6667 | 同上 |
| C_P | 2/3 ≈ 0.6667 | 同上 |
| KB/T | 5/8 = 0.625 | 同上 |
| I_T/(B³L) | 4/105 ≈ 0.03810 | 同上 |
| I_L/(L³B) | 1/30 ≈ 0.03333 | 同上 |

## 5. 注意点

### 体素阶梯效应（Voxel Staircasing）
低网格分辨率下阶梯效应显著：
- L=20: C_B 误差 +89%
- L=160: C_B 误差 +21%
- L=320: C_B 误差 +4%
- **L≥640**: 所有系数进入 3% 门限

这是体素化方法的固有特征，非算法缺陷。工程应用中需确保网格分辨率足够。

### 适用范围
- ✅ 静水力系数验证（几何 + 静力学闭合）
- ❌ 不涉及自由液面压力场
- ❌ 不涉及耐波性/波浪中运动
- ❌ 不涉及粘性阻力或流场求解
