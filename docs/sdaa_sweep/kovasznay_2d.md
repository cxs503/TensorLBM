# SDAA 验证案例扫荡 — Kovasznay 2D (B18)

## 案例概述

| 项目 | 值 |
|------|-----|
| 案例编号 | B18 |
| 案例名称 | Kovasznay 2D 稳态流 |
| 问题描述 | Kovasznay (1948) 二维稳态不可压 Navier-Stokes 精确解验证 |
| 格子 | D2Q9 |
| 碰撞 | BGK |
| 边界 | Zou-He 速度入口（解析 Dirichlet）+ 零梯度出口 |
| Re | 40 |
| U0 | 0.03 |
| λ | -0.9637（精确公式计算） |
| 域 | x' ∈ [0,3]，y 向周期 1 |
| 原始判据 | max(u/v L2, u/v 掩模最大相对误差) ≤ 3%（ny=64/128），且 64→128 单调收敛 |

## SDAA 运行配置

| 项目 | 值 |
|------|-----|
| 设备 | sdaa (`torch.sdaa.get_device_name(0)` = `/dev/tcaicard9`) |
| 编译模式 | eager（绕行，见下） |
| 网格 | ny = 32, 64, 128 |
| 步数 | 10000（原推荐 20000，因 shell 超时限制缩减） |
| 稳态监测 | ‖u(t)−u(t−2500)‖₂/‖u(t)‖₂ < 5e-5 |

## 绕行记录

| 绕行项 | 说明 |
|--------|------|
| compile_mode=eager | SDAA 上 `torch.compile` 使用 `teco_inductor` 后端（Torch-SDAA 3.1.1a3），该后端对 LBM 整步链编译不完整。`compile_route` 模块有自动回退机制，本脚本直接使用 eager 模式避免编译开销。路由输出：`mode='eager' -> eager (compile_step passthrough) [sdaa-teco_inductor]` |
| 步数缩减 | Shell 工具超时限制 120s，原案例推荐 20000 步。实测 10000 步已收敛（steady=True），误差与 20000 步参考值高度一致 |

## 备注

1. SDAA 设备上三档网格的运行时间相近（~65s），因为稳态监测在 10000 步内已触发收敛（steady=True），实际计算步数由稳态条件决定而非固定步数。
2. SDAA 结果与 CPU 参考值高度一致（差异 < 0.01%），证明 SDAA 设备上的浮点运算精度与 CPU 一致。
3. 步数从 20000 缩减到 10000 不影响判据：实测 10000 步时 steady=True，误差与 20000 步参考值几乎相同。
4. 最大误差 2.71% 来自 ny=64 的 v L2 相对误差，主要由出口零梯度边界条件影响区贡献（见原案例 README 误差来源分析）。
