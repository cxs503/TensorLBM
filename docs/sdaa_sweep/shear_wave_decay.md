# SDAA 验证扫荡：shear_wave_decay (B30)

## 案例概述

| 项目 | 值 |
|------|-----|
| 案例名 | shear_wave_decay (B30) |
| 物理问题 | 2D 衰减剪切波：u = U₀·sin(2πy/H)·e^{-νk²t}，纯粘性耗散验证 |
| 格子 | D2Q9 |
| 碰撞 | BGK (τ=0.8 → ν=0.1) |
| 边界 | 周期（stream 内建模运算 wrap） |
| 解析解 | γ_vel_theory = νk², γ_E_theory = 2νk²（不可压 NS 精确解，纯剪切 u·∇u≡0） |
| 原始入口 | `benchmarks/verified/shear_wave_decay/run.py` |
| 判据来源 | README.md（NVIDIA 侧成熟判据，按原口径） |

## 配置

| 参数 | H=64 | H=128 |
|------|------|-------|
| 网格 | 64×64 | 128×128 |
| τ | 0.8 | 0.8 |
| U₀ | 0.05 | 0.05 |
| ν | 0.1 | 0.1 |
| k = 2π/H | 0.09817 | 0.04909 |
| γ_vel_theory = νk² | 9.6383e-04 | 2.4096e-04 |
| γ_E_theory = 2νk² | 1.9277e-03 | 4.8191e-04 |
| 步数（auto, u_max/U₀→e⁻³） | 3200 | 10000 |
| 记录间隔 | 每 100 步 | 每 100 步 |
| 精度 | float32 | float32 |

## 备注

- 偏差符号：H=64 时 γ_sim 略大于 γ_theory（+0.049%），H=128 时略小（-0.002%），
  均在 BGK 离散修正预期范围内（README 记录 CPU 侧为 +0.051%/+0.011%）。
- 网格收敛：\|err_vel\| 从 0.049% 降至 0.002%，单调下降 ≈21×，远超收敛要求。
- 与 CPU 基准对比：SDAA 结果与 CPU 基准（result.json）数值一致，误差在舍入噪声范围内。
