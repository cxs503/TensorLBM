# SDAA 验证案例扫荡 — `laplace_cac_phasefield`

- 仓库：TensorLBM（工作树 `/root/tp-agent/work/m24`，分支 `agent/m24`）
- 案例：`benchmarks/verified/laplace_cac_phasefield`（CAC/HCH 相场两相 LBM，静态液滴 Young–Laplace）
- 脚本：`scripts/sdaa_sweep_laplace_cac_phasefield.py`（独立运行脚本，**未改动任何业务代码**）
- 机器输出：`artifacts/sdaa_laplace_cac_phasefield.json`
- 结论速览：**单臂物理闭合 PASS（|Δσ| = 0.057% ≤ 1.5%），但整案判据整体 FAIL——5 臂扫描在本卡 20 分钟预算内不可行（外推需 ≈11.1 h），B1 半径阶梯未测 → 无法宣称本案例在 SDAA 上已验证。**

## 1. 案例既有判据口径（原样沿用，未放宽）

判据不是抄的：脚本用 `importlib` 现场 import 案例自己的 `run.py`，从
`case.GATES` / `case.SIGMA_TARGET` / `case.SIGMA_ROUTE_B` 取门限与 Route-B 标定常数
（JSON 字段 `criteria_source` 记录来源）。

| 判据（案例 README/`run.py`） | 门限 | 本扫荡是否可评 |
|---|---|---|
| 逐臂 `|σ_rec/0.01 − 1|` | ≤ 1.5% | 可评 |
| B1 三半径散布 `(max−min)/mean` | ≤ 1% | **不可评**（需 R∈{20,32,48} 阶梯） |
| 伪速度 `max|u|`（窗内） | ≤ 2e-4 | 可评 |
| φ 积分漂移 @10k 步 | ≤ 1e-6 | 可评（跑了 10000 步，正好够） |
| 全程 NaN-free | 必须 | 可评 |
| 臂覆盖：B1×3 + B3×2 | 5 臂 | **FAIL**（预算只够 1 臂） |

物理口径：`σ_rec = (p_in − p_out)·R/2`，采样带 `φ>0.9` / `φ<0.1` 避开弥散界面；
估计窗 = 末 2000 步（每 500 步采样，窗内 4 个样本）；`σ_model = 0.01/0.9238958795895513
= 0.010823730488377745`（Route-B 一次性补偿，案例冻结值）。
估计量计算方式与 `run.py::run_arm` 完全同构（同一 `tensorlbm.cac_lbm`、fp64、harmonic µ(φ)、
W=4、M=0.05、p0=0.01、周期边界），仅网格/半径/步数降档。

## 3. 配置（降档与其依据）

| 项 | 案例推荐档 | 本次 SDAA 档 | 为什么降档 |
|---|---|---|---|
| 网格 | B1 128³ / B3 96³ | 64³ | 本卡实测步时（fp64）：48³ 51 ms、**64³ 108 ms**、96³ 335 ms、128³ 832 ms |
| 半径 | R = 20/32/48（B1）、20（B3） | R = 20 | 128³ 单臂 12000 步 ≈ 166 min；R=48 无法在 64³ 放下（2R=96>64） |
| 步数 | 12000 | **10000** | 108 ms/步 × 10000 ≈ 18.1 min（还够评 @10k 漂移门） |
| 臂 | 5（B1×3 + B3×2） | 1（`b3_rho100`：ρ 比 100、R=20） | 单臂 1085 s；5 臂外推 ≈ 11.1 h |
| dtype | fp64 | fp64 | 案例口径，不降 |

外推（`throughput` 字段，按格点数线性，已用 64³/96³/128³ 三个实测点校核）：
B1 三臂 @128³ ≈ **8.68 h** + B3 两臂 @96³ ≈ **2.44 h** → **整案 ≈ 11.12 h**，远超 ≤20 min 预算。
故本次只能给出「单臂物理是否在 SDAA 上闭合」的证据，不能给出整案判据。

FAIL 的唯一原因是**臂覆盖不足（预算）**，不是物理不闭合；但也正因如此，
ρ 比无关性（B3 的 ρ=10 臂）与 R 无关性（B1 阶梯）在 SDAA 上**未取得证据**，
不得用本次单臂 PASS 代替原案 5 臂判据。

### 已知降档风险（未被本扫荡排除）

1. 64³ 下周期映像间距仅 64（Ω_R=20），比 96³/128³ 更近；本次 σ_rec 与 96³ 的 NVIDIA 侧
   结果（0.009994 vs 0.00999382）差异仅 ~5e-5 相对量级，说明小盒映像效应在本案可忽略——但这是**对比观察**，不是本扫荡独立证明的。
2. 只测了一个 ρ 比，ρ 比迁移（10 vs 100）未验证。
3. 半径阶梯（尤其 R=48，128³ 需 166 min/臂）在本卡预算内不可能完成，需要更长时间窗或换更大算力卡。

## 6. 复现

```bash
# 本次扫荡（18.1 min，SDAA 单卡）
python scripts/sdaa_sweep_laplace_cac_phasefield.py \
    --arms b3_rho100 --grid 64 --radius 20 --steps 10000 \
    --out artifacts/sdaa_laplace_cac_phasefield.json

# 只刷新派生的吞吐外推字段（不重跑物理）
python scripts/sdaa_sweep_laplace_cac_phasefield.py \
    --recompute-only artifacts/sdaa_laplace_cac_phasefield.json
```

脚本自带案例同款「零手写 collide/stream」守卫（对自身源码 grep `def bounce` /
`def stream_3d` / `torch.roll(f`，必须为 0）；JSON 每 500 步落一次检查点，运行被中断时
已有采样不丢。

## 7. 建议（下一步）

1. 若需要在 SDAA 上完成整案：按 11.1 h 预算排一次长跑（建议拆 B1/B3 两次作业），或
   换卡；判据与脚本都不用改，只把 `--arms`/`--grid`/`--steps` 提到案例推荐档。
2. 若要在 20 min 档内尽量多覆盖：把 `b1_R20` 与 `b2` 对照改为同一 64³ 网格上的
   **ρ 比阶梯**（ρ=10/100，各 ~18 min 单臂，需 36 min → 仍超预算），或降到 48³/R=16 换 2 臂；
   这些都是**新口径**，需先在案例侧立新门限，不应冒充原案判据。
