# SDAA benchmark sweep reports

These reports describe historical hardware runs. The recorded commands and
results refer to the checkout used for each run.

The [sweep drivers](../../development/verification/sdaa-hardware/sweep-drivers/)
keep their original filenames. In a current checkout, run from the repository
root and substitute the driver directory in the recorded command. Keep its
case-specific arguments and device environment. The [migration ledger](../architecture/migrations/sdaa-sweep-drivers-2026-11-24.json)
lists each old path, its current location, and the Git revision for retrieving
the original. The case references and archived results remain with their
respective [benchmarks](../../benchmarks/).
