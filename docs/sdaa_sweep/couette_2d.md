# SDAA 验证案例扫荡 — couette_2d

## 案例概述

| 项目 | 值 |
|------|-----|
| 案例名称 | couette_2d |
| 物理问题 | 2D 平板剪切流（Couette flow）：上壁以 U0 运动、下壁静止，稳态线性速度剖面 u(y) = U0·y/H |
| 格子 | D2Q9 |
| 碰撞模型 | BGK (τ=0.8, ν=0.1) |
| 边界条件 | 上壁移动（half-way bounce-back + 动量注入），下壁静止，x 方向周期 |
| 解析解 | u(y) = U0·y/H_eff（精确解，对任意 Re 成立） |
| 原始判据 | max_rel ≤ 3%，两档网格收敛，稳态达到 |
| 原始结果（CPU） | H=40: max_rel=0.0198%; H=80: max_rel=0.0146% → 收敛 ✅ |

## 总体结论

**Overall: ❌ FAIL**

- 所有单网格判据（max_rel ≤ 3%、稳态、有限性）均通过。
- **收敛性判据未通过**：H=80 的 max_rel (0.0209%) 略高于 H=40 (0.0202%)，未呈现单调下降。
  - 注意：L2 误差确实下降（1.24e-04 → 1.23e-04），但 max_rel 是逐点相对误差的最大值，对局部数值波动更敏感。
  - 原始 CPU 参考值显示收敛（0.0198% → 0.0146%），SDAA 结果在量级上与之一致（~0.02%），但收敛趋势略有不同。
  - 可能原因：SDAA 设备上的浮点运算顺序/精度与 CPU 略有差异，导致逐点误差分布不同。
