# SDAA Sweep: thermal_cavity

## 案例概述

- **案例名称**: thermal_cavity (de Vahl Davis 自然对流方腔)
- **物理问题**: 方腔自然对流标准基准（de Vahl Davis 1983）
  - 左壁等温 T_hot=1.0，右壁等温 T_cold=0.0
  - 上下绝热，四壁 no-slip
  - Pr=0.71（空气），Ra∈{1e3, 1e4}
  - 网格 N∈{64, 128, 256}，共六案
- **格子模型**: D2Q9 (速度) + D2Q5 (温度)，BGK 碰撞 + Guo 浮力格式
- **参考实现**: `benchmarks/verified/thermal_cavity/`
- **原始判据**: NVIDIA 侧已验证，判据口径见 `result.json`

## 判据与参考值

### 判据定义

所有判据基于 de Vahl Davis 1983 预注册参考值：

1. **Nu 判据**: |Nu - Nu_ref| / Nu_ref ≤ 3%
2. **u_max 判据**: |u_max - u_max_ref| / u_max_ref ≤ 3%
3. **v_max 判据**: |v_max - v_max_ref| / v_max_ref ≤ 3%

### 参考值 (预注册)

| 物理量 | Ra=1e3 | Ra=1e4 |
|--------|--------|--------|
| Nu | 1.118 | 2.243 |
| u_max (扩散尺度) | 3.649 | 16.178 |
| v_max (扩散尺度) | 3.697 | 19.617 |

### 失败原因分析

**所有案例均 FAIL**，原因：

1. **未达稳态**: 本次 sweep 仅运行 800-1000 步，远未达到稳态（需要 37k-563k 步）
2. **早期发展阶段**: 
   - Ra=1e3: Nu 接近 1.0（纯导热值），速度场仍在发展（u_max/v_max 远低于参考值）
   - Ra=1e4: 对流较强，n64 案例速度场发展较快（u_max 已达参考值 90%），但 Nu 仍接近导热值
3. **物理趋势正确**: 
   - Ra=1e4 比 Ra=1e3 发展更快（浮力更强）
   - 粗网格 (N=64) 比细网格发展更快（数值扩散更大）
   - 所有案例 Nu 从 1.0 开始上升，符合物理预期
