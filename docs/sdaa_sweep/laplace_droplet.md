## 1. 案例说明

SCMP（Shan-Chen 单组分）模型在周期域中心放置液相液滴，演化至稳态后测量液滴内外压差 Δp，
验证 Young–Laplace 方程：

- **2D（圆柱液滴）**: Δp = σ / R
- **3D（球形液滴）**: Δp = 2σ / R

对多个半径 R 测量稳态 Δp，拟合 Δp vs 1/R 提取有效表面张力 σ_eff。
Laplace 线性关系成立（σ_eff 与 R 无关）即为表面张力模型的物理一致性验证。

**模型参数**: SC94, ψ(ρ) = 1 − e^(−ρ), 物理耦合 G_eff = −5.0（库调用 G=+5.0，后向 gather 符号翻转）, τ = 1.0, float32  
**共存密度**: ρ_l = 1.957, ρ_v = 0.1596（离散方案实测值）  
**EOS**: p(ρ) = ρ/3 + G_eff·ψ²/6 (G_eff = −5.0)

## 6. 失败原因分析

3D 案例的截距占比（4.010%）略超 3% 阈值，R²（0.99975）虽标为 PASS 但也接近边界。
主要原因：

1. **网格缩减**: 3D 使用 R=10,15,20（原案例 R=15,25,40）。最小液滴 R_eq=10.64 格，
   界面弥散层（W=4）相对于液滴半径的比例更大，格子离散效应更强。
2. **步数缩减**: min_steps=4000（原案例 6000）。三个 3D 液滴均在 4000 步触发收敛判据，
   但稳态可能未完全弛豫——原案例 R=40 需 12000 步才收敛。
3. **设备竞争**: 运行期间 SDAA 设备有多个其他进程并发，导致单步耗时高于独占测量值
   （如 3D R=15 实测 183s vs 独占估计 164s）。

**关键对比**: 2D 使用原案例网格（R=15,25,40），σ_eff=0.056118 与原案例 CPU 结果
σ_eff=0.056112 一致（差 0.01%），证明 SDAA eager 路径数值正确。3D 的 σ_eff=0.055235
与原案例 σ_eff=0.056170 偏差 1.7%，主要来自网格缩减而非设备精度问题。
