## 1. 案例介绍

### 物理背景
二维 Poiseuille 流动是流体力学经典基准问题：两块无限大平行平板间的充分发展层流，由压力差驱动。该问题存在精确的抛物线解析解，是验证 LBM 代码精度与边界条件实现的标准测试。

### 几何与参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 格子模型 | D2Q9 | 二维九速度 |
| 碰撞模型 | BGK | 单松弛时间 |
| 通道高度 H | 20 (lattice units) | 有效壁面间距 (ny-2) |
| 通道长度 L | 60 (= 3H) | L/H = 3 |
| 网格 ny × nx | 22 × 60 | 含壁面行 |
| 松弛时间 τ | 0.8 | |
| 运动粘度 ν | 0.1 | (τ-0.5)/3 |
| 入口密度 ρ_in | 1.0072 | Zou-He 压力入口 |
| 出口密度 ρ_out | 0.9928 | Zou-He 压力出口 |
| Δρ | 0.0144 | 驱动压差 |
| u_max (解析) | 0.04 | dp·H²/(8νL) |
| u_mean (解析) | 0.0267 | (2/3)·u_max |
| Re | 5.33 | u_mean·H/ν |
| Ma | 0.0693 | u_max/c_s |
| 边界条件 | Zou-He 压力入口/出口 + 半程反弹 | pre-streaming variant |

### 解析解
$$u(y) = 4 u_{max} \frac{y}{H}\left(1 - \frac{y}{H}\right)$$

## 2. 方法

### 工具链
- **求解器**: TensorLBM `benchmarks/verified/poiseuille_2d/run.py`
- **设备**: SDAA (`/dev/tcaicard6`)，通过 `torch.sdaa` 后端
- **编译模式**: eager（SDAA inductor 对 LBM 链不完整，回退 eager）
- **Triton**: `TRITON_INTERPRET=1`（SDAA 兼容）
- **脚本**: `scripts/sdaa_sweep_poiseuille_2d.py`

### 流程
1. 探测设备，确认 SDAA 可用
2. Patch `DEVICE` 为 `sdaa:0`
3. 运行 H=20 单工况（预算约束下的快速判定）
4. 迭代至稳态（min_steps=3000, max_steps=10000）
5. 提取中心截面速度剖面，与解析解比较
6. 计算 L2 相对误差、u_max 误差、密度线性度、质量漂移

### 关键设置
- 种子: seed=0
- 稳态判据: 内置收敛检测
- 度量: 中心行 u_max 误差、全场 L2 相对误差、密度线性度

## 5. 注意点

### 踩过的坑
1. **SDAA torch.compile 不完整**: SDAA inductor 对 LBM collide+stream 链支持不完整，必须回退 eager 模式，性能损失约 2-5×。
2. **Triton 需解释模式**: SDAA 不支持 Triton JIT 编译，需设 `TRITON_INTERPRET=1`。
3. **预算约束**: 原计划扫 H=20/40/60 三个工况，因时间预算仅完成 H=20。

### 局限
- **粗网格**: H=20 为最粗分辨率，离散化误差主导。更细网格 (H=40/60) 预期误差更低。
- **步数缩减**: 使用 3000-10000 步（原方案 10000-60000），稳态可能未完全收敛。
- **单工况**: 无法展示网格收敛趋势。

### 适用范围
- 低 Re（Re≈5.3）、低 Ma（Ma≈0.07）层流 regime
- BGK 碰撞在低 Re 下精度足够，高 Re 需 MRT/cumulant

## 6. 误差判定

### 关键量 vs 基准

| 关键量 | 数值结果 | 基准值 | 绝对误差 | 相对误差 | 是否 < 3% |
|--------|----------|--------|----------|----------|-----------|
| u_max | 0.04038 | 0.04000 | 0.000384 | **1.21%** | ✅ **是** |
| L2 全场误差 | 0.01198 | 0 (解析) | 0.01198 | **1.20%** | ✅ **是** |
| 密度线性度 | slope ratio 1.0000045 | 1.0 | 4.5e-6 | 0.00045% | ✅ **是** |
| 质量守恒 | drift -1.85e-5 % | 0 | 1.85e-5 | ~0% | ✅ **是** |

### 显式回答
- **u_max 误差 1.21% < 3%？ → ✅ 是**
- **L2 误差 1.20% < 3%？ → ✅ 是**
- **但原单阈值为 1%**：u_max_err=1.21% 和 L2_err=1.20% 均略超 1% 门限，故 verdict=FAIL。
- **若以 3% 为工程可接受标准，本案例实际通过。**

### FAIL 原因分析
1. H=20 粗网格离散化误差（二阶 LBM 在 H=20 时空间误差 ~O(1/H²) ≈ 0.25%）
2. 步数不足（7200 步 vs 原方案 10000-60000 步），稳态残差未完全衰减
3. 两者叠加导致 1.21% 略超 1% 门限

### 改进建议
- 运行 H=40/60 验证网格收敛（预期误差降至 0.3%/0.14%）
- 增加迭代步数至 30000+ 确保完全稳态
- 考虑 MRT 碰撞进一步降低误差
