## ① 案例介绍（物理背景/几何/参数表）

DFG 基准（Schäfer & Turek 1996, NNFM 48, case **2D-2**，Re=100）：直径 D=0.1 的圆柱置于
2.2×0.41 槽道内（堵塞比 D/H=0.2439，柱心 (0.2,0.2)），入口抛物线（U_max/U_mean=1.5）、
出口 p=0、壁面/柱面半程反弹，力用 Ladd 动量交换。本格点实现 D2Q9+MRT，网格档 D=20/28/40
（440×82 / 616×115 / 880×164），u_mean,lb=0.0833，步长按 17 个脱落周期（14000/20000/27200 步）。
被调查的头条数字：C_L 幅值误差 **+36.04%**（D28，容差 5%）。

| 参数 | 值 |
|---|---|
| Re = U·D/ν | 100（ν=0.001） |
| U_mean（格子） | 0.0833（τ 随 D 变：0.550/0.570/0.600） |
| 碰撞 | MRT（s_e=1.64, s_eps=1.54, s_q=1.7） |
| 边界 | Zou/He 入口(抛物线)+压力出口；半程反弹 |
| 力 | Ladd 动量交换（F=2·Σ c_i·f_i，post-stream/pre-bounce-back） |
| 统计窗 | transient_periods=5，avg_periods=12（瞬态显式剔除） |

   C3 网格 / C4 τ / C5 边界 / C6 各向异性 / C7 碰撞 / C8 力提取），每项一个判别性实验。
3. **修复**：m16827 已修估计器（基频+瞬态剔除）与窗口记账（D1/D3/D5）；本单补
