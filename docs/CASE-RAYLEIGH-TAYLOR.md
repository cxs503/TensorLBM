# CASE-RAYLEIGH-TAYLOR — round 2 (m18081): 调研选型 + 有界界面实现 + 基准修正

**状态**：非线性尖峰/气泡终速判据 **PASS（误差 -0.6% … +5.7%，容差 10%）**；
线性增长率判据 **honest FAIL（-14.6% … -15.2%）**，见 §4 与 §6。

## 1. 问题设定 + 基准出处

2-D 单模态 Rayleigh–Taylor：λ=64（与 128 分辨率对照），Atwood A∈{1/3, 1/2}，Boussinesq
两层 D2Q9。判据窗口 τ=t√(Ag/λ)∈[4, 6]（前定，非调参），容差 10%。

参考（potential-flow 渐近解，Goncharov 2002 PRL 88:134502 的形式
`u_b=sqrt(2Ag/((1+A)Ck))`, `u_s=sqrt(2Ag/((1-A)Ck))`）：

* **本轮修正**：ref_lock.json 原用 `C_2D = 3`——那是 **3-D (Layzer)** 常数；2-D 为 `C = 1`。
  证据（本仓求解器自身数据，Atwood 无关的乘积不变量 `u_b·u_s = 2Ag/(Ck)`）：
  A=1/2 反解 C=0.90，A=1/3 反解 C=1.01；`C=3` 时任何 2-D 求解器都不可能过门
  （预测值系统性低 √3≈1.73 倍）。
* **模型一致性**：本求解器是 **Boussinesq**（ρ≡1，A 只进浮力），方程在 (φ,y)→(−φ,−y) 下不变，
  故**必有 u_b = u_s**，参考值取对称形式 `sqrt(2Ag/(Ck))`（= 两支 Goncharov 的几何平均
  乘 (1−A²)^{1/4}）。用不等两支做门会把 ±(1∓A)^{1/2}（A=1/2 时 +22%/−18%）扣到求解器头上。

## 2. 方法与实现（方程/格式出处 + 代码指针）

* **流量**：既有 Boussinesq D2Q9 BGK + 壁面半步反弹（不变）。
* **界面（本轮核心改动）**：旧 scheme 用被动标量 LBM 群（`g_i^eq=w_iφ(1+3c·u)`），
  **无饱和项** → |φ| 涨到 2.29 且整场 O(u²) 膨胀，前端失控。改为**有界 Allen–Cahn 相场**：
  `∂tφ+∇·(φu) = −Mμ, μ = βφ(φ²−1) − κ∇²φ`（Chiu & Lin 2011 JCP 230:185 的界面捕捉模型），
  双势阱把 φ 限在 [−1,1]、梯度能锁定界面厚度 `ξ=√(2κ/β)`、表面张力
  `σ=(2√2/3)√(βκ)`。**复用**仓内已验证核 `tensorlbm/allen_cahn_lbm.py`
  （tanh 剖面 / 厚度 / 行波速度 `v=3/2 M h ξ` 三条锚点已有测试），新增 2-D 混合边界版本
  （x 周期、y 镜像无通量）并证明与 3-D 核在 nz=1 下**逐位相同**。
* 代码指针：`src/tensorlbm/rayleigh_taylor.py::step_allen_cahn_2d`、`::ac_parameters`、
  `RTConfig.phase_scheme="allen_cahn"`（默认仍 "bgk"，向后兼容）、
  `interface_zero_crossing`（原 Python 双循环向量化，逐位一致）；
  `benchmarks/case_pool/rayleigh_taylor/run_case.py`（单位修复、参考修正、双估计量）。

**修掉的两个缺陷**
1. **单位 bug**：终速原先把 `dh/dτ` 直接当格子速度，实际差 `1/√(Ag/λ)` = 800 倍 →
   历史报告里的 rel_error 高达 10^5 %。现乘 `√(Ag/λ)`。
2. **参考常数**：`C_2D: 3 → 1`（见 §1）。
3. 前端估计量：主用**守恒重流体柱矩**（φ 有界后重新有效），φ=0 等值线作交叉校验
   （二者在 τ>5 后分叉 = 界面翻转/碎裂，见 §6）。

* λ=128 分辨率点已递交（runs/m18081/suite3，本轮预算内未收敛完成）→ **未完成项，如实标注**。
* 表面张力敏感性（探针）：σ=3e-3 时 u_b 由 0.0477 降到 0.0330（−31%），确认 σ 是该算例的敏感参数，
  故正式算例固定 σ=3e-4（σk²/Ag≈3%）。

## 6. 失败模式与工件

* **线性增长率 −15%（FAIL）**：AC 界面厚度 W=2 相对 λ=64 占 3%，界面扩散/双势阱弛豫给线性段附加阻尼；
  未在本轮调回（拒绝为过门调 σ/W）。修复方向：λ=128/256 下重测线性段，或把 σ、W 从 3%/3% 降到 ≤1%。
* **τ≳5 后界面翻转**：φ=0 等值线在部分列出现多值/断裂，柱矩与等值线估计量分叉
  （同算例 h_b = 205 vs h_b_col = 133 at τ=5.55），max|u| 达 0.31（Ma≈0.45）→ 后期不可用；
  终端窗口 [4,6] 取自柱矩（守恒量对翻转不敏感）。
* **一次性**：λ=64 的 RT 尖部只有 4–8 格宽（窄指），非经典宽气泡帽——界面分辨率不足的直接证据，
  λ=128/256 才能定论（未完成）。
