# P96W3-N04 · TensorLBM 热对流定量验证面（Rayleigh–Bénard / 差分加热腔）
**战役节点** P96W3-N04（物理域 · 成熟化） · **仓库** TensorLBM · **mission_id** 9294
## ① 案例介绍（物理背景 / 几何 / 参数表）
研究对象是双分布（D2Q9 速度 + D2Q5 温度）Boussinesq 热对流的两条经典基准线：

* **Rayleigh–Bénard（RB）**：两块无限大水平板之间的温差驱动对流，x 方向周期、上下刚性等温壁，间隙 H、水平周期 nx。控制参数 Ra = gβΔT H³/(να)、Pr = ν/α；临界 Rayleigh 数 Ra_c = 1707.762、临界波数 a_c = 3.11632（Chandrasekhar 1961；Drazin & Reid 1981）。
* **差分加热方腔（DHC）**：方腔左热右冷、上下绝热，Pr=0.71；平均 Nu 的经典基准是 de Vahl Davis (1983)：Ra=1e3/1e4/1e5/1e6 → Nu=1.118/2.243/4.519/8.800。

本节点之前的状况是"有代码、零定量验证"：`thermal.py`/`thermal3d.py` 能跑，但没有任何一条判据把"算得对"钉死。上一波 P96W2-N04 试图建面，审计后发现三处口径问题（见 §2），故本节点重建口径自洽的验证面并给出**实测数字**。
### 离散口径（唯一真源，`src/tensorlbm/rb_convection_validation.py`）
| 项 | 口径 |
|---|---|
| 网格 | (ny, nx) 节点；半程壁面 y=−1/2 … ny−1/2 ⇒ **H = ny**（格子单位） |
| 速度 | D2Q9 BGK + Guo 力格式；pre-streaming 半程反弹（no-slip） |
| 温度 | D2Q5 BGK，α=(τ_T−1/2)/3；Dirichlet 用 anti-bounce-back（半程、二阶），绝热壁零通量反弹 |
| 壁面 u | 壁面行按 no-slip 取 u=0 后再进温度平衡（否则 ABB 的 2w·T_w 项注热，见 §5 坑 1） |
| Nu | 壁面三点二次插值求导，Nu=q·H/ΔT；另有能量平衡 Nu（独立第二估计） |
| 无量纲 | ν=(τ_f−1/2)/3，α=(τ_T−1/2)/3，Pr=ν/α，gβ=Ra·ν·α/(H³ΔT) |
| 压缩性 | Ma=u_max/c_s；Ma ≈ α·√(Ra·Pr)/(H·c_s)（高 Ra 必须小 α / 大 H） |

## ② 怎么做的（方法 / 流程 / 关键设置）
1. **审计上一版**：`tests/test_thermal_verification_p96w2n04.py` 的 C1 是用**连续谱 Orr–Sommerfeld 解算器**与文献常数 1707.76 对表（解析解 vs 文献，并未度量 LBM）；C2 的 2D 辊参考 Nu 是手写区间 2.6–2.8（无文献锚）、判据放宽到 20%；稳态判定缺失（5000 步）；`simulate_rayleigh_benard_2d` 用 H=ny 定 Ra 而 `nusselt_rb` 用 H=ny−1 归一 ⇒ Ra 有效值偏 ((ny−1)/ny)³（ny=32 时 −9%）。
2. **重建验证面**：新模块 `rb_convection_validation.py` 把几何/边界/Nu/无量纲换算集中定义；新增能量平衡 Nu 作为独立第二估计；壁面行 u=0 修正（热注入缺陷）。
3. **C1 线性起稳**：导热基态 + 单模温度扰动（幅 1e−4）时间推进，投影幅值 A(t) 取 log|A| 线性拟合得 σ（保留符号，禁 |A| 整流），σ*=σH²/α。Ra 扫描 5 臂 → σ*(Ra) 零点插值给 Ra_c；固定 Ra=1.2Ra_c 扫 5 个离散波数 → σ*(k) 抛物顶点给 k_c。
4. **C2/C3 定常 Nu**：推进到块平均 Nu 漂移 <2e−3（早停），报壁面通量 Nu 与能量平衡 Nu、Nu 时间抖动、两侧通量不平衡；多分辨率做 Roache GCI。
5. **C4 无量纲自洽**：固定 (Ra,Pr)，把 ΔT 换成 0.5/1/2（等价 β×2、g×0.5）复算。
6. **C5 负控**：关浮力 → 纯导热（Nu=1、线性剖面）；双绝热壁 → 总焓守恒 1e4 步。
7. **C6**：周期域正弦温度波衰减反演 α_eff，网格 16/32/64/128 做精度阶。
8. **C7 回归**：既有 `tests/test_thermal*.py` 全绿。

**工具链**：PyTorch float64（保精度判据）/ float32（高分辨率长跑）、脚本 `scripts/p96w3_n04_campaign.py`（每任务一 JSON，可任意分片）、`scripts/p96w3_n04_figures.py`（零手抄出图）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）
1. **ABB + 壁面伪速度 = 注热缺陷**：若把半程反弹在壁面行留下的 O(u) 伪速度喂进温度平衡，`2w·T_w` 的 anti-bounce-back 会在 100 步内让总焓漂 3.8%、Nu 反号（−2.2）。修复：壁面行按 no-slip 取 u=0 再进温度平衡。
2. **H 口径一致性**：Ra 与 Nu 必须用同一个 H（半程壁面间距 = ny）。上一版H=ny−1 与 H=ny 混用会把 Ra 悄悄改掉 ((ny−1)/ny)³（ny=32 时 −9%）。
3. **LBM 的 Ra 上限是 Ma 硬约束**：Ma ≈ α√(Ra Pr)/(H c_s)。Ra=1e6 想要 Ma≤0.1 需 H ≳ 950 以上（2D 规模 ~1e6 节点），本节点的机时内不可达；故高 Ra 只能以较大 Ma 运行并把 Ma 记入台账，误差来源是压缩性而非算法。
4. **Nu 的两个估计必须同时报**：壁面通量与能量平衡；两者在 ny=32 DHC Ra=1e4 相差 3e−4（相对），不一致即说明未定常或边界处理有问题。
5. **低 τ_f 的边界层欠分辨**：为压低 Ma 而减小 α（故减小 ν、τ_f→0.5+）会让黏性边界层只有 2–3 个格子，Nu 系统性偏低（本节点 DHC ny=32 给 1.85，低 17%）。提高分辨率同时提高 α（τ_f 随之远离 0.5）是唯一出路。
6. **几何口径标定（本节点最重要的一条）**：`thermal.py` 的 pre-streaming 半程反弹实际上把 no-slip 面放在壁面行**内侧一格**（实测 d_v/ny=0.938@ny=32，与库内已验证的 `rb_discrete_stability` 的 d=ny−2 约定一致）；而 ABB 温度壁落在半程（实测 d_T=0.999·ny）。若 Ra 用 ny 定、Nu 用 d_T 归一，Ra 被高估 (ny/(ny−2))³（ny=32 时 +21%）——这正是本节点第一轮 DHC/RB 结果系统性偏低 17%/9.7% 的根因（与实测 Ra_c=2058.6@ny=32、1940.8@ny=48 完全吻合：2058.6·(30/32)³=1696.5、1940.8·(46/48)³=1708.6），修正后 Ra_c=1707.75（0.00%）。该残差是 O(1/ny)，故高 Ra 判据仍要求足够细的网格。
7. **C5 的 1e-6 判据是 O(h²) 边界残差的下限**：ny=32 实测 Nu 与 1 的偏差 1.24e−6（略超判据 24%），剖面 L∞/ΔT=4.1e−8、绝热壁焓漂移 3.3e−16 均远优。该残差随 h² 收敛（ny=64 预期 ~3e−7），故判据应按网格给出而非单点。
8. **适用范围**：本验证面只覆盖 2D 双分布 BGK + Boussinesq；3D （`thermal3d.py`）与含辐射/共轭换热的通道不在本节点判据内。
