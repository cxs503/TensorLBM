## ⓪ R3 结论

1. **R2 的网格阶 1.15 / 1.23 是求解器估计器缺陷，不是物理效应**：R2 用 `log2(e_17/e_25)`，假设 `ny:17→25` 分辨率翻倍，而壁距 `H` 只从 16 变到 24（1.5 倍）。把分辨率显式代入后，R2 自己的数据给 **p = 1.973 / 2.000**，即二阶收敛；R2 报告中“偏离二阶、由壁面 O(dx) 误差主导”的归因不成立。`log2` 造成的低估倍数恰为 ln2/ln1.5 = 1.7095。

2. **定常解本身是精确抛物线的**：对每个稳定解作最小二乘抛物线拟合，相对残差 ≤ 3.77e-10，即离散定常解的形状与 Poiseuille 抛物线在舍入误差内一致；与解析解的全部偏差都是**可测量的有效壁位偏移**（见 ③ 表）。

3. 五分辨率扫描（`ny ∈ {17,25,33,49,65}`）的 log-log 回归阶：PORT-REG rel-L2 p=1.98、u_max p=2.00；PORT-BB rel-L2 p=2.00、u_max p=2.00。

4. 全部 22 个定常解的 rel-L2 最差 0.661 %（PORT-REG|u0.01|ny17），<15 % 判据与 <3 % 严判据同时通过；质量漂移 ≤ 1e-11 量级。

## ① 案例介绍

D2Q9 BGK，`tau = 0.5375`（`nu = 0.0125`），`nx = 2`（x 周期，状态 x 不变），`y` 向两行固壁；恒定体力密度 `F = dp/dx` 驱动（`nu u'' = -G`, `G = F/rho0`），定常解为 `u(y) = G (y-y_w)(H-(y-y_w))/(2 nu)`。两套闭环：- `PORT-REG`：节点型 regularised 壁（Latt 2008，壁在节点中心，`H = ny-1`，`y_w = 0`）+ Guo 半步冻结力（`(1-ω/2)` 权、`+F/2` 速度修正，即 OSS 约定）；- `PORT-BB`：半程反弹壁（壁在链中点，`H = ny-2`，`y_w = 0.5`）+ split Guo（本仓生产约定）。

参数：`u_max` 目标 0.0025–0.04（`Ma = u/c_s` ≤ 0.069），`Re_H` ≤ 102.4；定常判据 `max|u(y,t)-u(y,t-200)|/u_max < 1e-10`。

### 3.6 误差来源分解（重要）

- 反测有效壁位偏移随分辨率的变化斜率：PORT-REG p=1.001；PORT-BB p=1.001，即偏移本身是 **O(dx) 一阶**（与 R2 的定性判断一致）；但它进入速度误差时乘上壁面法向斜率尺度 1/H，故剖面误差仍是 **O(dx²)** —— 这正是“壁位一阶偏移 + 二阶整体收敛”可以并存的原因。

- 固定 H 时误差对 u_max 的幂次：PORT-REG p=-3.22e-09；PORT-BB p=-5.45e-10，即在本轮 Ma ≤ 0.069 范围内**不存在马赫数误差底**，误差完全由几何（有效壁位）决定 —— 这与“定常解在舍入误差内即抛物线”互为佐证。

## ⑤ 注意点

- 本轮只做 D2Q9 单相层流（`Re_H ≤ 102`），不涉及湍流/SGS；`nx = 2` 是刻意取的最小值（状态 x 不变），不代表 3D 能力；
- 阶估计必须用**壁距 H**（而非 ny、更非“翻倍”）作为分辨率长度；`observed_order` 现已在库内强制这一点，并拒绝非加密对；
- `fit_parabola` 的反测几何在噪声剖面上会退化，已加曲率显著性阈值（本次自测发现的缺陷）；
- R2 存档 JSON 与 `run_xval_r2.py` 当前矩阵/key 格式不一致（存档来自早期缩减矩阵版本），R2 存档不可由当前脚本复现；R3 存档为权威证据。

## ⑥ 误差判定（显式回答）

- 关键量 1：rel-L2 vs 精确 Poiseuille —— 最差 0.661 % ⇒ **<3 % 成立**（更 <15 %）；
- 关键量 2：u_max 相对误差 —— 网格线最差 0.498 % ⇒ **<3 % 成立**；
- 关键量 3：观测收敛阶 —— PORT-REG 1.98；PORT-BB 2.00，相对二阶基准偏差 <10 % ⇒ 二阶收敛成立（R2 的 1.15/1.23 判定撤回）；
- 关键量 4：质量漂移 —— 全行 ≤ 6.2e-11，判据 1e-9 通过。

**honest-FAIL 声明**：无。R2 的阶结论被本轮否定（不是 solver 失败，是证据链估计器缺陷），已在 ⓪ 与 ⑥ 明示，未粉饰。
