# XVAL-LBM 周期 x + 常压降 通道 R4：启动瞬态（脉冲启动）复核

> Repository migration note: the current case and replay commands are in [benchmarks/cross_validation/periodic_channel_dpdx](../../benchmarks/cross_validation/periodic_channel_dpdx/). Original mission paths below identify the archived revision. Historical scientific verdicts are not new acceptance.

锚点 `XVAL-LBM-SINGLE-PHASE-PERIODIC-X-PLUS-CONSTANT-DP`（OSS `joconnor22/LIFE`，tag `single-phase-periodic-x-plus-constant-dpdx-driving`）。R1–R3 复核的是**定常**解；R4 补齐**瞬态**证据链：把整套启动历程与 脉冲启动的精确 Fourier 级数解对比。

## ⓪ R4 结论

1. **瞬态全程对标精确解通过**：24 个采样点（2 臂 × 3 网格 × 4 个无量纲时间）的 rel-L2（以定常解 L2 范数归一，这是唯一有意义的归一化——瞬时范数在 t→0 时趋零）最差 0.508 %（PORT-REG，ny=17，τ=0.2），<3 % 严判据 **成立**。
2. **中心线增速历史**（$u_c/u_c^{steady}$ vs τ）逐点对标，最大绝对偏差 0.324 %，即启动过程的**时间形状**（不只是终值）正确。
3. **瞬态误差仍是壁距二阶**：固定 τ=0.1，H=16→64 的观测阶 1.93（逐对见 ③.3），与 R3 的定常阶一致——瞬态没有引入新的收敛障碍。
4. **新发现（定常基准看不见的）**：两种力注入约定在启动最初几步报告的**速度偏置是常数**，OSS `guo_half_frozen` 臂为 $\frac{1-\omega}{2}g$（本次三组 τ 实测与闭式解偏差 ≤ 3.1e-11），本仓 `split_guo` 臂**严格为 0**。该偏置不随时间增长，故定常解不受影响（这也解释了 R2/R3 为何看不到它），但任何**跨代码逐时刻**比对标量速度时必须扣掉它。
5. 质量漂移全程 ≤ 6.8e-12（判据 1e-9）。

## ① 案例介绍

D2Q9 BGK，`tau = 0.5375`（`nu = 0.0125`），`nx = 2`（x 周期，状态 x 不变），y 向两行固壁；从静止出发，恒定体力密度 `F = dp/dx` 在 t=0+ 施加（`nu u'' = -g`）。精确启动解

$$u(s,t)=u_\infty(s)-\frac{4gH^2}{\nu\pi^3}\sum_{k\ge0}\frac{\sin((2k+1)\pi s)}{(2k+1)^3}e^{-(2k+1)^2\pi^2\nu t/H^2},\quad u_\infty=\frac{gH^2}{2\nu}s(1-s).$$

两臂（与 R2/R3 完全相同，便于对照）：
- **PORT-REG**：regularised (Latt 2008) + Guo(1-w/2, +F/2)
- **PORT-BB**：halfway bounce-back + split Guo (full weight, no shift)

参数：`u_max` 目标 0.0100（`Ma = u/c_s ≈ 0.0173`）；无量纲时间 $\tau=\nu t/H^2 \in \{0.02, 0.05, 0.1, 0.2\}$。

## ② 怎么做的

- 驱动脚本 `xval/xval_lbm_periodic_dpdx/run_xval_r4.py`（4 进程池，递交 run_compute 集群作业，作业墙钟 43.3 s）；
- 新解析工具（本轮回写入库）`tensorlbm.periodic_channel_dpdx.poiseuille_transient`：奇次 Fourier 级数，**自适应模数**（余项相对定常峰值 < 1e-14），并对 t≤0 （级数在 t=0 仅条件收敛，精确值为 u≡0）与模数不足（小 t）显式报错；
- 三种扫描：`transient_line`（ny∈{17, 33, 65} × 两臂，在**相同无量纲时间** τ 采样）、`resolution_order`（固定 τ=0.1 跨 H 求观测阶，用 R3 的分辨率显式估计器）、`early_time`（前 6 步的速度偏置 vs 闭式解）；
- 回归测试 `tests/test_xval_life_periodic_dpdx_r4.py`（13 passed）：解析解自身（退化到定常、从静止单调增长、均匀初始加速度 u=gt、满足动量方程 du/dt=g+ν∂²u/∂y²、级数收敛与非法输入）+ 求解器瞬态门（<3 %、二阶）+ 偏置闭式解。
- 证据：`xval/xval_lbm_periodic_dpdx/out/xval_life_periodic_dpdx_r4.json`（git `6497c10ae145`，Linux-6.6.52-1.7.lns23.loongarch64-loongarch64-with-glibc2.38，numpy 2.4.6）。

## ⑤ 注意点

- 仍是 D2Q9 单相层流（`Re_H ≤ 102`、`Ma ≤ 0.069`），不含湍流/SGS/3D；
- 瞬态门用**定常解 L2 范数**归一。若用瞬时范数归一，τ→0 时分母趋零，任何方案都会显示“100 % 误差”——3.1 表两列都给出，判据只用前者；
- 级数在 t→0 需要 O((νt/H²)^-1/2) 个模数，`poiseuille_transient` 对模数不足显式报错，避免静默截断把截断误差记到求解器账上；
- 3.3 的偏置是**报告速度变量**的定义差（`Σcf/ρ` vs `Σcf/ρ+F/2ρ` 与源项权重 `1-ω/2` 的组合），不是求解器误差；它不随时间增长，也不改变定常解；
- 本轮没有重跑定常扫描；R2/R3 的定常结论不作任何改写。

## ⑥ 误差判定（显式回答）

- 关键量 1：瞬态 rel-L2（归一化到定常解）最差 0.508 % ⇒ **<3 % 成立**（<15 % 亦成立）；
- 关键量 2：中心线增速历史最大偏差 0.324 % ⇒ **<3 % 成立**；
- 关键量 3：瞬态观测阶最小 1.93（二阶基准 2.0，偏差 <25 %）⇒ 二阶收敛成立；
- 关键量 4：质量漂移 6.8e-12 ⇒ 判据 1e-9 通过；
- 关键量 5：速度偏置闭式解偏差 ≤ 3.1e-11（g 的量纲下 ~1e-11）⇒ 闭式解成立。
