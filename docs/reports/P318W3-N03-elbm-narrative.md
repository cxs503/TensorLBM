# ELBM（熵格点 Boltzmann）高 Re 槽道湍流：可续算 DNS 驱动与熵条件缺陷修复

**节点** p318w3-n03（TensorLBM）·**分支** agent/m10817 ·**算例** D3Q27 ELBM 强迫槽道，
Re_tau = 180，DNS 参照 Moser–Kim–Mansour (1999)（包内置、SHA-256 登记）。

---

## ① 案例介绍（物理背景 / 几何 / 参数）

* **物理背景**：熵格点 Boltzmann 方法（ELBM，Karlin 1999；Ansumali–Karlin 2002）
  用离散 H 定理（熵函数在碰撞下不增）替代 BGK 的固定松弛率：碰撞写成
  `f* = f + (α/τ)(f^eq − f)`，`α` 逐胞逐求解熵条件 `H(f*) = H(f)`，
  粘性 `ν = c_s²(τ/α − 1/2)`。理论上给出任意 `τ`（任意 Re）下的正性保持与
  稳定性，是"高 Re 湍流不加湍流模型"的路线。本节点把它推进到
  **壁面解析的槽道湍流 DNS 判据**（对数律斜率、雷诺应力峰位、摩擦系数）。
* **几何**：平面槽道，流向 x、展向 z 周期，壁法向 y 两面半程反弹壁
  （无滑移面在 `y = 0.5` 与 `y = ny − 1.5`，流道高 `H = ny − 2`，半高 `h = H/2`）。
  格子 D3Q27，权重 `8/27, 2/27, 1/54, 1/216`。
* **驱动**：Guo (2002) 体积力 + 半步力速度平移；因此壁面摩擦速度由动量平衡
  **解析给出** `u_tau = sqrt(g h)`（不靠剖面拟合），`C_f` 才成为干净的判据。
* **参数表**（由 `tools/elbm_dns_report.py` 从算例 meta 程序化注入，见表 1）。

## ② 怎么做的（方法 / 流程 / 工具链）

1. **算法与本征验证链**（沿用并加固仓库既有实现）：熵平衡态闭式解 vs
   拉格朗日对偶 Newton（1e-11 级一致）；H 定理逐胞；`α` 可容许区间；
   剪切波衰减率；层流 Poiseuille 剖面（0.3%）；C 内核 vs torch 参考（1e-4）。
2. **新增可续算 DNS 驱动** `src/tensorlbm/elbm_channel_dns.py`：逐步驱动融合
   OpenMP 内核（新增 `native_channel_step_inplace`，去掉每步两次全场拷贝），
   checkpoint（场 + 熵热启动 + 统计累加器 + 计数器）与 `--max-wall-clock`
   作业槽切分，跨续算的时间平均连续。验证：**40 步一次跑 == 20+20 分两段跑**
   （场与累加器逐位相同）；`--max-wall-clock=0` 存盘后反复续跑能跑完。
3. **诊断出并修复三处真实缺陷**（都是"测试绿但物理错"型）：
   * **D1 fp32 镜面点塌缩**：`f^eq` 存 float32 时，`τ≈0.5` 的镜面点（松弛率
     `1/τ≈2`，精确 `ΔH=0`）被 1e-9 的舍入放大成 `ΔH=+1.1e-5`，超过容差
     `1e-6(|H0|+1)`，求解器返回 `α=0`（**完全不碰撞**）。修：胞内代数含
     `f^eq` 全部用 double；参考实现 float32 输入内部上采样 fp64。
   * **D2 体力平移污染熵条件**：Guo 半步力平移使平衡态族熵上升
     （`ΔH ≈ ρ|u|F/2 > 0`，是外功，不属 H 定理覆盖的碰撞部分）；用它做熵判据
     会把 `α` 压到 0（实测 `ΔH=+5.2e-5`）。修：熵条件用**未平移**平衡态求解，
     碰撞仍朝**已平移**平衡态松弛（保 Guo 二阶精度），正性夹逼沿真实碰撞方向；
     H 诊断只统计无体力碰撞，另报"扣掉 fp32 噪声底"的残差。
   * **D3 `C_f` 判据归一化错误**：`_bulk_velocity_plus` 拿**半高**去除积分，
     而驱动给的是**全槽道**剖面 ⇒ `U_b+` 恰好大 2 倍、`C_f = 2/U_b+²` 小 4 倍，
     判据 (c)（`C_f` 5%）**任何算例都不可能通过**。修：按剖面跨度归一化。
4. **验证口径**：所有判据由 `channel_gates` 用 MKM-1999 数据机器计算；
   报告里的每个数字由 `tools/elbm_dns_report.py` 从算例文件程序化提取（零手抄）。
5. **工具链**：`tools/elbm_dns_bench.py`（吞吐标定）、`tools/elbm_dns_report.py`
   （判据 + 图 + markdown）、`tools/elbm_report_payload.py`（报告载荷）。

## ⑤ 注意点（坑 / 局限 / 适用范围）

1. **算力是本次唯一的硬约束**：集群作业队列在本会话内 48 分钟零派发
   （`cj581/cj586/cj596/cj598` 全部 queued，节点 load 36/128 空闲），
   控制面 99 号机 load 367/128（约 2.9 倍超订），实测本内核吞吐
   0.4–3.8 Mcell/s（对标 128 核标称值低一个量级）。壁面解析 DNS 的
   最小预算约 `10^10` 胞步（0.5–1.4 M 胞 × 6000–30000 步），
   在可用算力下只能跑**短时窗**算例。因此本报告的判据结果按实际算出的
   数字判定（含 FAIL），并给出复现命令与预算表，供算力恢复后重跑。
2. **Δy+ 与时间平均**：第一层流体 `Δy+` 与统计时窗（`T = h/u_tau` 的倍数）
   在表 1 里逐项给出；两者不足时对数律与雷诺应力必然偏离 DNS——这不是
   方法失效而是 DNS 采样不足，报告不做修饰。
3. **过渡触发**：仅用白噪声（0.06 u_tau）在 `Δy+ ≳ 5` 时会**转捩失败**并
   缓慢层流化（实测 3500 步后 `u_rms+` 仍 0.01，DNS 为 2.7；拟合 κ_eff 由
   0.41 掉到 0.24）。因此驱动新增**流向反向旋转涡对**（`--roll-amplitude`，
   波长取 2h → 展向 ~180 壁面单位，与真实条带间距同量级）作为过渡触发。
4. **H 定理的诚实边界**：熵条件是**离散**表述；体力做功不属于 H 定理覆盖的
   碰撞部分，必须单列；fp32 存储的熵有 ~1e-6 的算术底噪，报告同时给出
   原始 `ΔH` 与扣噪后的残差。
5. **Bose–Einstein 熵与 KBC 双群体**：已实现但生产碰撞用 Gauss 熵 + 单松弛
   因子，本节点未启用。

## ⑥ 误差判定（关键量 vs 基准，逐项）

见"表 2 判据对照"与"表 3 剖面一致性"（机器生成）。逐项显式回答
"是否 < 3%"：

* `U_b+`（等价 `C_f`）：见表格中 `u_bulk_plus_rel_error` 与 `cf_rel_error`
  两列——**若 < 3% 会直接写在表里**；判据 (c) 门槛为 5%。
* 对数律斜率：见 `relative_error` 列（判据门槛 5%）。本次为 FAIL ——
  原因是统计时窗只有 `≈1T`（`T = h/u_tau`）且 `Δy+ = 5.6`，湍流未发展，
  对数层不成立；这是 DNS 采样不足，不是熵条件或输运系数错误（粘性由
  `α = 1` 精确等于 BGK 值，`U_b+` 1.4%、`C_f` 2.6% 即其证据）。
* 雷诺应力峰位 `y+`：见 `error_vs_dns` 列（判据门槛 2 个壁面单位）。
* 其它量（`u_rms+` 峰值大小、`-⟨u'v'⟩+` 分布）**没有 3% 级基准声明**：
  DNS 参照只提供剖面本身，本算例的统计时窗不足以支撑 3% 的矩量级精度，
  因此按"报告数值 + 明确不下 3% 结论"处理，不粉饰。
