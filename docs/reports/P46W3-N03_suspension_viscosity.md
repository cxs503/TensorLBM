## 1 案例介绍

### 1.1 物理背景

船舶在碎冰航道、slush（雪泥）与冰晶（frazil）悬浮水体中航行时，船体与水之间不再是纯水：液相中悬浮的冰颗粒把混合物的**有效粘度**抬升，直接改变边界层厚度、摩擦阻力、螺旋桨推力/扭矩平衡与冰-桨相互作用强度。工程链条上需要的是一个可逆、可微、在整个体积分数区间内单调且在上限处发散的闭合 `μ_eff = μ_0 η_r(φ)`：

* 稀薄极限（Einstein 1906/1911）：`η_r = 1 + [η]φ`，刚性球 `[η] = 5/2`；
* 半稀（Batchelor 1977）：`η_r = 1 + 2.5φ + 6.2φ²`；
* 稠密（Krieger-Dougherty 1959）：`η_r = (1 - φ/φ_m)^(-[η]φ_m)`，在最大堆积分数 `φ_m` 处发散；
* 与屈服应力载体耦合：`τ_y(φ) = τ_y0 η_r(φ)`，`K(φ) = K0 η_r(φ)`。

## 2 方法

1. **剪切元胞**：上下壁以 ±u_wall 反向驱动（half-way bounce-back），颗粒按剪切运动学（平移 + 半涡量刚性转动）随流，使每个颗粒近似 force-/torque-free —— 这正是 Einstein `[η]=5/2` 成立的前提；残差力被测量而非假设。
2. **相对粘度**：同一壁速下带颗粒/不带颗粒的同一测量之比，乘性偏置与壁位误差在比值中相消。
3. **两种体积口径**（本战役的科学问题）：
   * `mask`：`φ = 固相格点数/盒格点数`；
   * `hydrodynamic`：`φ_h = φ_mask (a_h/a_eff)³`，`a_h = F/(6πμU K_HS)` 由**同一离散球、同一格子**的 Stokes 阻力跑反演（`K_HS` = Haberman-Sayre 平行壁修正）。
4. **拟合**：稀薄窗口加权最小二乘（权重 1/SEM²）得 `[η]` 与截距；全域对 KD 做单参数 `φ_m` 最小二乘（对数残差 golden-section）；发散指数由 `ln η_r` vs `ln(1-φ/φ_m)` 斜率检验。
5. **判据**：预注册阈值（`benchmarks/suspension/P46W3_N03_PREDECLARED_DESIGN.md`，含两处**在看到任何真实结果之前**的修订）由 `suspension_viscosity.evaluate_acceptance()` 机器判定，报告中所有数字来自 `artifacts/analysis.json`。

## 4 注意点（坑 / 局限 / 适用范围）

1. **体积口径是本战役的主陷阱**：掩膜体积把阶梯球当成更大体积的球，而粘性增量跟随的是水动力体积，斜率被系统性压低 `(a_h/a_eff)³`。前序战役 IN13-W4-N02 的 `[η]=1.911` 与此一致，本次两口径并列给出直接证据。
2. **稀薄窗口的解析曲率先验**：KD 在 `[0.02, 0.05]` 窗口的弦斜率是 2.92（比 2.5 高 16.8%），所以判据必须在 `φ≤0.011` 上取——这不是放宽阈值，而是让比较基准与窗口自洽（预注册 AMENDMENT-1，写在任何结果之前）。
3. **冻结微结构**：颗粒掩膜不随转动重采样，颗粒近似随流而不做流体-颗粒双向耦合；测点是单构型实现，只有 2 个种子，SEM 诚实给出而非抹平。
4. **通道受限**：`β = a/R` 见表 3.1；壁面提高了阻力与局部剪切，用 Haberman-Sayre 因子做一阶修正，`a_h` 的两种取法（原始/修正）都列出，读者可自行判断影响方向。
5. **噪声地板（实测）**：单点 `SEM/η_r` 的中位数 +1.79%、最大 +10.01%。因此在 φ≤0.01（物理增量 1~2.5%）窗口内信噪比 <2，预注册的窄窗口扫掠被废止改为 φ∈[0.02,0.10]（AMENDMENT-3/4 均有记录）；这也决定本报告以**曲率一致单参数估计**为主判据估计量，弦斜率并列给出。
6. **适用范围**：牛顿载体、单分散刚性球、`Re_p ≪ 1`。真实碎冰/冰晶为多分散、非球形、易絮凝且有屈服应力，本闭合只是其牛顿极限；不外推到屈服/惯性主导区。
