## ① 案例介绍（物理背景 / 几何 / 参数）

充分发展、定常、不可压层流在方管中的压力驱动流动。动量方程 `nu * lap(u) = -g`
（`g` 为单位质量体积力，等价于 `dP/dx`），四壁无滑移。工程背景：船舶/换热器管束、
滑油与冷却水管路、微通道内的黏性主导流动；此处作为 LBM 求解器的**精度基准**，
因为它有闭式解且对碰撞算子、边界算子、几何组合最敏感（两对壁面在管角叠加）。

**解析基准（方管, Boussinesq 级数；`a = L/2` 为半宽，壁面在 `y,z = ±a`）**：

    u(y,z) = 16 (g/nu) a^2/pi^3 * sum_{n odd} (-1)^((n-1)/2)/n^3
             * [1 - cosh(n pi z/(2a)) / cosh(n pi/2)] * cos(n pi y/(2a))

级数本身在使用前先自检（壁面值为 0、四重对称、解析微分后的 Laplacian 等于 `-g/nu`），
见 `duct_poiseuille_validation.check_series`；这样系数/符号错误不会伪装成小误差。

任务书给出的圆管解析解 `u(r) = (dP/4 mu L)(R^2 - r^2)` 在方管中**不成立**，本工作把
峰値匹配的抛物线当作**负对照**使用（见 ⑤ 与 ⑥）：它必须在同一个 2 % 门限下被判失败，
否则门限对剖面形状不敏感、不具备判别力。

参数表（全部格点单位, `rho = 1`；无量纲问题随分辨率保持不变）：

| 项目 | 取值 |
|---|---|
| 格子 / 碰撞 | D3Q27, MRT（`s_e=1.19`, `s_eps=1.4`, `s_q=1.2`, `s_pi=1/tau`） |
| 松弛时间 | `tau = 1`（`nu = (tau-1/2)/3 = 0.16667`） |
| 体积力 | `g = 8 nu u_nom / L^2`，仅注入流体格点（`w_i*3*c_ix*g`） |
| 名义速度 | `u_nom = 0.05`（体积力标定参数；方管实测峰值 `u_max = 0.0289`，`Ma ~ 0.050`，不可压近似范围内） |
| 壁面 | 半程反弹（half-way bounce-back），两对壁面 `y`、`z` 各 ± |
| 流向 | `x` 向周期，`nx = 4`（中线奇数格，取中间平面剖面） |
| 分辨率阶梯 | L=6 (1200 步), L=8 (1500 步), L=10 (2000 步), L=12 (2000 步) |
| 数值精度 | `float64`，cpu，单线程 |

## ② 怎么做的（方法 / 流程 / 关键设置）

1. **先查现状（任务 ①）**：仓库既有 3D Poiseuille 相关工作——`duct_poiseuille_validation.py`
   （D3Q27 MRT 方管，**单个**分辨率 `L=10` 对 Boussinesq 级数 0.4 % 级）、
   `benchmarks/pending/poiseuille_3d_ellipse/`（椭圆管水力反演）、`tests/test_poiseuille_convergence_order.py`
   （**2D** 通道收敛阶）。缺口明确：**3D 方管没有任何分辨率扫描/收敛阶证据**，
   单点吻合无法排除"离散巧合"。
2. **因此本波是扩展而非重写（任务 ③）**：复用既有算例内核 `run_duct_case`（同一 D3Q27 MRT、
   同一半程反弹、同一体积力注入、同一级数解析解），新增 `poiseuille_3d_resolution.py`
   做 `L in {4 档}` 阶梯 + 收敛阶估计（相邻对 + log-log 最小二乘拟合，给 `R^2`）+ 判据汇总 + 工件落盘。
3. **无量纲问题固定**：`g ~ 1/L^2`，使 `u_max ~ u_nom`、`Re` 不随 `L` 变，
   序列是纯离散化研究（不是顺带扫物理参数）。
4. **步数定为"收敛"而非"顺手"**：每档 `steady_rel_change_tail < 1e-9`；
   另在 `L=10` 用 1.5 倍步数（3000 vs 2000）重算，误差变化 `< 1 %`（测试断言）。
5. **三条独立量**：中心线最大范数剖面误差、截面平均速度（积分量, 与阻力系数同源）、
   总质量漂移；另有文献积分量 `f*Re = 56.91`（Shah & London 1978）作外部锚。
6. **负对照 × 2**：① 把解析解按 `nu*1.25` 误设后比较，必须在同一门限下被拒；
   ② 圆管抛物线（峰値匹配）必须在同一门限下被拒。
7. **工件 → 图 → 报告全链路程序化**：`results.json` → `make_figures.py` → 本文表格
   （本 markdown 由脚本生成，零手抄）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **线程调度 >> 物理计算**：格点只有 `~14^2*4` 量级，torch 默认多线程时单步调度开销
   使阶梯运行超时（首版 >120 s 被外部收割）；`run_ladder` 内固定 `set_num_threads(1)`
   后全程约 35 s。**教训：小张量不设单线程会误判"算不动"。**
2. **门限要分范数**：中心线**最大范数**误差在 `L=12` 为 0.96 %，但**截面平均速度**（积分量）
   误差为 1.74 %——近壁格点的半程反弹壁面位置误差在二维平均里权重更大。
   只报最大范数会给出过于乐观的印象；本工作两者都报。
3. **2 % 门限需要 `L >= 9`**：粗档 `L=6` 误差 3.9 %、`L=8` 为 2.2 %，均超门限。
   判据因此只在最细档 `L=12` 上裁（并在报告与工件里显式标注 `velocity_profile_error_length`）。
4. **抛物线不是方管解**：任务书的 `u(r)=(dP/4muL)(R^2-r^2)` 仅对圆管成立；对当前方管
   剖面，峰値匹配抛物线偏差在细档为 5.224 %（> 2 % 门限），故用作负对照而非基准。
   圆管/椭圆管的斜接（staircase）几何误差不在本文范围内（见 `benchmarks/pending/poiseuille_3d_ellipse`）。
5. **适用范围**：单相、静态几何、`tau=1`（`nu=1/6`）、`Ma~0.050`、cpu/float64；
   不覆盖湍流、多相、自由面、动边界、AMR、加速后端与 D3Q19 的对比阶梯
   （D3Q19 单点证据见 `tests/test_lbm_verification.py` Step E）。
6. **步数依赖被显式验证**：不靠"步数够大"的口头保证，而是用 1.5 倍步数重算并断言误差漂移 `< 1 %`。

| 截面平均速度（L=12） | Boussinesq 级数积分 | 1.744 % | 1.744 % | 是 |

| 总质量 | `N`（初始） | 最大漂移 2.011e-12 | 同左 | 是 |
