# NACA0012 亚声速翼型气动极线验证面（TensorLBM 外部气动首次验证）

* 仓库：TensorLBM ｜ 主极线 Re = 1e+03 ｜ 网格弦向分辨率 [64, 96, 128] 格 ｜ 求解器：D2Q9 MRT + interpolated (Bouzidi) bounce-back + Dirichlet far field + wake sponge

## 1. 案例介绍

**物理背景**：二维亚声速翼型绕流是外部空气动力学的最小验证单元：升力线斜率 $dC_L/d\alpha$、阻力极线 $C_D(C_L^2)$、压力系数分布 $C_p(x/c)$ 三个观测量共同约束求解器的压力-黏性耦合能力，单点力的对比无法区分“流场对了”与“误差相互抵消”。

**几何**：NACA 4 位数厚度律（闭合尾缘），$t/c = 0.12$，弦长 $c$（格），体轴与格点 x 轴对齐，迎角通过自由来流方向给出（$\vec U_\infty = U(\cos\alpha,\sin\alpha)$），因此离散掩膜与迎角无关。

**计算域**：上游 2.5c ／ 下游 6c ／ 半高 3c（堵塞比 $\approx t/2H = 0.020$），尾流区黏性吸收层 3c。

## 2. 方法与工具链

* 格子：D2Q9，MRT 碰撞（`tensorlbm.solver.collide_mrt`），拉取式流移（`stream`）；
* 壁面：**插值（Bouzidi）反弹**，壁距分数由解析有符号距离场给出（二阶壁面定位，避免台阶偏置）；半步反弹作为对照实现保留在 `scheme='staircase'`；
* 受力：动量交换法 $F=\sum_{\text{links}} c_i (f_i^{out}+f_i^{in})$（与壁面格式无关，即流体在壁面处损失的动量）；升阻按来流方向分解；
* 远场：入口/上下 Dirichlet 平衡态，出口零梯度，尾流黏性吸收层；
* 初场：可由面板法势流场启动（抑制起动涡瞬态）；
* 参考解（`src/tensorlbm/aero_reference.py`，自实现、自验证）：
  * 无黏：常强度涡面板法 + Kutta 条件（圆球 $C_p$ 解析对照误差见测试；薄翼型斜率 → $2\pi$）；
  * 黏性代理：Thwaites 动量厚度 + Head 形状因子 + Squire-Young 尾流阻力公式，平板极限与 Blasius 差 0.63%（测试锚定）；
  * XFOIL 与 Abbott 实验表在本工作树/镜像中不可用 → 相关判据按 WITHHELD 记（不伪造数据）。

## 5. 注意点 / 局限

* **$Re=6\times10^6$ 壁面解析不可达**：$h/c = 1/128$ 时首格 $y^+\approx1172$；要 $y^+=1$ 需弦向 约 150000 格 / 1.28e+12 格点，相当于每对流时间 ~1.5e+19 次格点更新。故本节点在可达包络的最高 Re 上评估判据，并显式给出 Re 趋势。
* 插值反弹的壁距分数由解析有符号距离近似（一阶曲率误差），薄尾缘处退化为半步反弹；
* 低 Re 下边界层相对厚度大（$\delta/c\sim Re^{-1/2}$），网格实际只解析了厚边界层/分离泡，与高 Re 实验的“壁面解析”不是同一物理状态；
* MRT 的 $\tau$ 由 $\nu = U N/Re$ 决定，高 Re + 粗网格会逼近稳定边界（表中 $\tau$ 已记录）。

| (2) 阻力极线 vs XFOIL ≤10% | WITHHELD | WITHHELD |
| (3) $C_p$ RMS vs 实验 ≤0.05 | WITHHELD | WITHHELD |
| (4) 三档网格 GCI($C_L$) ≤2% | 59.26% | FAIL |
| (5) pytest 覆盖 | 见 tests/test_naca0012_aero.py | True |
| (6) 图件落盘 | artifacts/naca0012_polar/figures | True |

**直答“是否 <3%”**：
* 升力线斜率对 $2\pi$：-64.78% → 否（若改以厚度修正理论 $2\pi(1+0.77t/c)$ 为基准，见 §3.1 中的面板斜率对比）；
* $C_L(\alpha=0)$：0.0000 → 对称性判据 通过；
* 平板摩擦阻力代理 vs Blasius：+0.63% → **是**（解析锚点，见测试）。

**honest-FAIL 声明**：判据 (2)(3) 的真实基准（XFOIL / Abbott 实验表）在本环境不可得，标注 WITHHELD 而非以代理值冒充通过；判据 (1)(4) 的实测值如上，未达标即如实记 FAIL。
