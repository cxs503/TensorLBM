## 5. 注意点

### 5.1 踩过的坑

1. **SDAA 性能陷阱**: SDAA 设备存在但性能仅为 RTX 3090 的 ~1/10。对于 2.6M 单元的 3D LBM 模拟，117.5ms/步意味着任何有意义的运行都需要数十分钟到数小时，远超 agent 120 秒超时。

2. **X_r=0 不是物理结果**: Re=200/400 的 X_r=0 是测量/运行损坏，不是物理结果。Re=200 仅跑了 500 步流场未发展；Re=400 的 X_r 序列间歇出现非零值后归零，表明再附着检测算法在 RLBM 碰撞下失效。

3. **低 Re 分离泡系统误差**: +13.2% 误差与 2D backward_step 案例的 +9~15% 误差同源——bounce-back 滑移误差 ∝(τ-0.5)·Δx。在 Re=100 时 τ=0.56，滑移显著。

### 5.2 局限

- 本诊断在 SDAA 设备上完成，无法运行完整模拟验证修复方案
- Re=200/400 的原始运行记录不完整，无法复现
- 3D 展向周期在低 Re 下等价于 2D (spanwise_std=0.0)，无法体现 3D 效应

### 5.3 适用范围

- 本诊断结论适用于 D3Q19 + BGK + bounce-back 的 3D 背向台阶设置
- 改用 interpolated bounce-back 或 MRT/TRT 碰撞可能降低系统误差
- 高 Re (≥800) 工况下 3D 展向结构更有区分度
