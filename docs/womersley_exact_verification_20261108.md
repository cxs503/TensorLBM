# 精确 Womersley（Bessel）脉动管流解：落地 + 独立验证 + 已交付近似的缺陷定量

日期 2026-11-08 · 仓 TensorLBM · 分支 agent/m6463 · 证据 `artifacts/womersley_exact_20261108/`

## 0. 结论（一句话）

TensorLBM 唯一对外提供脉动（Womersley）入口剖面的实现
`turbulence.inlet_profiles.womersley_profile` 从来不是 Womersley 解，而是一个
"δ=1/Wo 指数 Stokes 层" 的手写近似；本单补上**精确 Bessel 解**
（`turbulence.womersley_exact`，四路独立基准互证，最差相对误差 6.5e-11），
并把该近似的偏差**定量**出来：16 个 (Wo, φ) 采样点中 10 个超过 15% 工程容差，
最差 69.2%（Wo=1, φ=3.14）。
旧函数保持逐位不变（默认路径不破坏，`exact=True` 一键切换），文档内嵌实测偏差警示。

## 1. 案例介绍

**物理背景.** 管道内由谐振压力梯度驱动的充分发展脉动流（Womersley 1955），
是无阀推进、往复机械、心血管与脉动进气道的基本解。工程上它作为
**入口边界条件**给出：已知体积流量波形 Q(t)，需要截面速度剖面 u(r,t)。
无量纲参数只有一个 —— Womersley 数 Wo = R√(ω/ν)：Wo<2 近似准定常抛物，
Wo>10 则核心成"活塞"、壁面只剩薄 Stokes 层。

**几何/参数.** 圆管，半径 R（R=1 为归一化单位），径向 r̃=r/R ∈[0,1]；
时间平均体速度 u_mean；基频ω，谐波 kω；相位 φ=ωt。
网格：N=64…256 个直径向单元（剖面函数按单元中心取样，与既有 API 一致）。

**基准来源.** 解析解本身（J₀ 复 Bessel 函数），以及四条**不复用推导**的独立旁证：
面积分恒等式、准定常极限的解析系数 1/48、无 Bessel 的有限差分解、
40 位 mpmath 参考值。

## 2. 怎么做的

1. **推导 + 归一化选择.** 取 e^{iωt} 约定，动量方程
   `iωU = G/ρ + ν(U''+U'/r)`，正则解 `U ∝ J₀(kr)`，`k² = -iω/ν`，故
   `α = R·k = Wo·e^{-iπ/4}`。入口边界已知的是**流量**而非压力梯度，
   因此分母按"单位体速度"归一：
   `Ŵ(r̃) = [1 - J₀(αr̃)/J₀(α)] / [1 - 2J₁(α)/(αJ₀(α))]`，
   恒满足 `∫₀¹ Ŵ·2r̃ dr̃ = 1`。
   合成剖面 `u(r̃,φ) = 2u_mean(1-r̃²) + Σ_k (A/k²)u_mean·Re{Ŵ_k e^{ikφ}}`。
2. **数值稳健性.** 近壁 `1 - J₀(αr̃)/J₀(α)` 有灾难性相消（r̃→1 时两项同阶），
   在 `|α|(1-r̃) < 1e-5` 内改用 r̃=1 处两项 Taylor 展开（交叉点取在
   "相消 ≈2e-16/x" 与 "截断 ≈0.3x²" 的平衡处，两侧均 ~1e-11）。
3. **依赖策略.** 复 Bessel 优先用 `scipy.special.jv`；scipy 缺失时回落到
   自带幂级数 `_j0_j1_series`（不新增硬依赖）。
4. **AI 口径.** 不改既有函数默认行为：`womersley_profile(..., exact=True)`
   路由到精确解，默认仍逐位复现旧输出（回归测试锁死 4 个黄金数值）。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

* **坑 1（本单最大）: √(±i) 符号.** 首版用 `α = Wo e^{+iπ/4}`，幅值全对、频率响应全对，
  但整个解被共轭 —— 每个相位滞后都反号。四路基准里只有"无 Bessel 的有限差分"
  与"高 Wo 渐近"能看见它；mpmath 比对看不见（同一错误约定下自洽）。
  **教训：同源参考值只能验证实现，验证不了约定；必须留一条不复用同一约定/同一特殊函数的旁证。**
  该 bug 已固化为回归测试 `test_bessel_free_finite_difference_reproduces_shape_and_sign`
  与 `test_centreline_lags_the_flow_rate_at_intermediate_wo`。
* **坑 2: 折叠坐标求积.** r̃=|2y/N−1| 是折叠坐标（1→0→1），对其直接 trapz 恒等于 0；
  必须取半个直径做面积分（否则出现"流量恒为 0"的假失败）。
* **坑 3: Taylor 分支窗口.** 近壁相消的 Taylor 窗口必须窄（|α|(1−r̃)<1e-5）；
  取 0.5 时截断误差已达 9%，被流量恒等式当场抓住。
* **坑 4: 默认谐波数.** `n_harmonics=4` 时振荡体积流为 `A·Σ1/k² = 1.4236A`，
  不是 A —— 不要把它当成实现错误（本次一度误判）。
* **局限.** ①只覆盖充分发展、等温、牛顿、单相、刚性圆管；未含入口发展段、
  弹性壁（FSI）、非牛顿（可用广义 Womersley 另立）；②`Wo>100` 超出验证域
  （幂级数兜底在 Wo=100 已降到 ~1e-4）；③管壁无滑移是硬边界，壁面函数/滑移不适用；
  ④旧近似函数**未改用精确解**（保持行为兼容），仅文档警示 + `exact=True` 开关，
  是否改默认属 API 语义变更，留待下游确认。
* **容量纪律.** 本机 load15≈124/128，全部计算为 CPU 单线程且总耗时 <30 s（纯 numpy/scipy），
  未起重算力进程。

## 6. 误差判定（逐项，显式回答是否 <3%）

| 关键量 | 基准 | 误差 | <3% ? |
|---|---|---|---|
| 剖面形状 Ŵ (Wo=1…100, 9 个径向站，含近壁) | 40 位 mpmath J₀ 解 | 6.53e-11 | **是** |
| 剖面形状（无 Bessel 的 FD 旁证，n=800） | 有限差分 ODE 解 | 1.02e-05 | **是** |
| 动量算子残差均匀度 | 常体力 | 2.87e-07 | **是** |
| 体积流量归一 | 解析恒等式 =1 | 8.63e-10 | **是** |
| 准定常极限系数 | 解析 1/48 | 1.78e-05 | **是** |
| 壁剪相位渐近 (Wo=100) | 经典 +45° | 0.61° (相对 1.4%) | 绝对 0.61°，**是** |
| **旧近似 vs 精确解** | 精确解 | 最差 69.2%，10/16 点 >15% | **否（这正是本单量出的缺陷）** |

结论：新实现的每个被测量均 **<3%**（多数 <1e-6）；被检出的不达标项是**已交付的旧近似**，
已如实登记为缺陷并在文档/测试中留证，未粉饰。
