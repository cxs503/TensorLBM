## 1. 案例介绍（物理背景 / 几何 / 参数）

Allen–Cahn（AC）方程是相场法里与 Cahn–Hilliard 并列的界面演化方程；本仓的多相/自由面线用它
跟踪气液界面（自由面阻力、气泡、空化）。用双势阱自由能

ψ(φ) = β(φ²−1)²/4，化学势 μ = ψ′(φ) − κ∇²φ，演化 ∂_tφ + ∇·(φu) = −Mμ

则表面张力与平衡界面厚度有**解析关系**，可与参数表互相反解（本单固化为 `free_energy_parameters`）：

| 量 | 解析式 | 说明 |
|---|---|---|
| 表面张力 | σ = (2√2/3)·√(βκ) | 无需标定常数 |
| 平衡厚度 ξ | ξ = √(2κ/β) | 剖面 φ = tanh(s/ξ) |
| 反解 | β = 3σ/(2W)，κ = 3σW/4 | 代入得 σ_back = σ（rel 1e−12） |

算例参数（格点单位，全部可复现，无手抄）：

| 算例 | 网格 (z,y,x) | σ | W | M | 步数 | 基准 |
|---|---|---|---|---|---|---|
| A1 静态剖面 | 4×4×96 | 0.01 | 4.0 | 1.0 | 4000 | 解析 tanh(s/4) |
| A2 厚度松弛 | 4×4×96 | 0.01 | 4.0→8.0 初值 | 1.0 | 8000 | ξ = √(2κ/β) = 4.0 |
| A3 受驱行波 | 4×4×160 | 0.01 | 4.0 | 1.0 | 600（h=5e−4） | v = (3/2)Mhξ = 0.003 |
| H1/H2 稳定性 | 24³ | 0.001 | 4.0 | 0.02 | 200 | 有限性 |
| H3 静止液滴 | 32³, R=8 | 0.01 | 4.0 | 0.02 | 1500 | Δp = σ/R |

## 2. 怎么做的（方法 / 流程 / 工具链）

1. **先读后改**：`git log` 确认该模块自 2026-08-20 合并后未被任何测试引用（`tests/` 全库零引用，
   `__init__.py` 零导出），只在 `benchmarks/pending/hadamard_rybczynski_droplet/` 的探针里被调用，
   而该探针 NOTES 已记录「both init orientations dissolve」——本单把这条口头观察升级为**机器可复现的判据**。
2. **缺陷定位（读码 + 实测）**：
   - 力除以**局部气相密度**：`u_eq = u + tau*F/rho`，`rho` 取自布居和，气相 ρ_l=1e−3 →
     界面力被放大 1000 倍。实测第 1 步 `max|u| = 0.332`（格子声速量级）。
   - 表面张力**不含曲率**：旧式为 `(σ/W)(1−φ²)·n̂`，`n̂` 是单位法向 → 无法给出 Young–Laplace 压差。
   - 相场子步每步把 `g` 重置为平衡态、φ 由 `Σg` 取回，界面通量不可控。
3. **改法（最小可验证）**：相场输运改为显式 AC 更新 `step_allen_cahn_field`，Laplacian 与梯度
   **直接复用**已被 `tests/test_phasefield_common_operators.py` 覆盖的 `tensorlbm.phasefield.operators`
   （七点 Laplacian + 中心差分，避免另写第二套 stencil）；界面力改为化学势 Korteweg 力
   `F = μ∇φ`（复用 `phasefield.free_energy.force_mu_grad_phi`）；流体步改用 ρ(φ) 与 Guo 力。
4. **判据先于动手**：A1/A2 阈 1%（厚度、L∞ 漂移 <0.01、界面位移 <0.05 格）；A3 阈 10%（行波渐近解，
   已在测试里写明为何不能当紧等式）；耦合步不设「能跑就算过」的判据，而是设**有限性判据**。
5. 工具链：CPU 单线程（`torch.set_num_threads(1)`），本机 load15≈125 故全部为轻量算例；
   结果由 `scripts/allen_cahn_verify_20261108.py` 程序化写入 `artifacts/allen_cahn_r1_20261108/results.json`。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **周期边界会把 1-D 单界面变成双界面**：单界面放在周期盒里会在 x=0/95 处出现 φ=+1/−1 的
   假界面，A1 的 L∞ 漂移从 3.6e−3 暴涨到 0.81（全部在边界格点）。**正确做法是 `no_flux`**，
   这一条已写进测试与 docstring；不做这个诊断会误判「内核不稳」。
2. **厚度测量对格子采样有 1–2.5% 系统偏置**（W=2 时 2.54%，W=4 时 0.99%），因此 A2 的判据比较
   「弛豫后 vs 名义 W」时必须知道偏置量级，否则会把采样偏置当成物理误差。
3. **A3 的 7.36% 不是 bug 而是渐近性**：解析式是连续极限行波解，离散行波在有限 W 下非严格自相似
   （实测剖面厚度从 4.04 涨到 4.08），故本单把它当「带」而不是等式；若要压到 <3% 需做 h→0 的
   收敛阶扫描（本次未做，如实记录）。
4. **耦合流体步未修好**：ρ(φ) 进平衡态 + Guo 力只是去掉了「力/气相密度」与「无曲率」两个确定缺陷，
   变密度 BGK 本身缺压力演化/动量一致化，实测仍发散（比旧实现晚 1 步，但第 1 步 `max|u|` 反而
   更大 0.986 vs 0.332）。**该路径判 WITHHELD 并加硬门禁**（默认 raise，需显式
   `allow_unverified_hydro=True` 才能复现失败）。
5. **环境陷阱（值得全仓注意）**：本机 site-packages 的 `__editable__.tensorlbm-0.3.0.pth` 使
   `sys.path` 里同时存在 **6 个不同 worktree 的 `src/`**（m5758/m5543/m5435/m6150/m5550/m4635）。
   `import tensorlbm` 实际解析到 `/root/tp-agent/work/m6150/src/...`，不带 `PYTHONPATH=src` 跑测试会
   测到**别人的工作树**。本单所有命令都显式 `PYTHONPATH=<本 worktree>/src`。
6. 适用范围：单相两相的界面输运内核（扩散+反应+平流），不含流体耦合、不含壁面接触角；
   表面张力/粘性/密度比只作为参数出现，其正确性依赖耦合步（当前 WITHHELD）。
