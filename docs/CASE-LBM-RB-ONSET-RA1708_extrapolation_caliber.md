# CASE-LBM-RB-ONSET-RA1708 · 网格外推口径审计：+2.785 % FAIL 是测量还是形式选择？

> 算例：Rayleigh–Bénard 对流失稳临界 Rayleigh 数（刚-刚/等温壁，二维辊）。
> 文献值 `Ra_c = 27π⁴/4 = 1707.7597`（Chandrasekhar 1961 §II），容差 `<2%`。
> 本文件是**验证欠账**（口径复核），不是算例重跑：全部数字取自仓内既有工件
> `benchmarks/case_pool/rayleigh_benard_onset/artifacts/summary.json`，
> 由 `grid_ladder_audit.py` 程序化注入（零手抄），审计 JSON =
> `artifacts/grid_ladder_audit.json`，图 = `artifacts/grid_ladder_audit_*.png`。

## ① 案例介绍（物理背景与预登记判据）

两层无限大刚性平行板间的 Boussinesq 流体，下热上冷，x 向周期、长宽比 Γ=nx/ny=2。
纯导热基态在 `Ra > Ra_c` 后线性失稳，先出现二维定常辊。本案问**起始临界 Rayleigh 数**：
导热基态上单模扰动的增长率 σ 变号处。

算例预登记判据（`run_case.py::PREDECLARED`，跑前冻结，本审计**不修改**）：

| 项 | 内容 |
|---|---|
| 主观测 | Route A：`rb_convection_validation.measure_growth_rate` 时间推进测 σ* = σH²/α |
| 判定 | `σ* > +0.05` 不稳定 / `< −0.05` 稳定 / 其间 marginal；Ra 二分 + 零点插值 |
| 门 1 | 主网格 `Ra_c(ny=64)` 与 1707.7597 相对误差 `<2%` |
| 门 2 | `1/ny` 外推 `Ra_inf` 与 1707.7597 相对误差 `<2%` |
| 控制臂 | Route C（连续 N-S-Boussinesq 边际稳定，独立于 LBM）必须落在 1707.76 的 `0.05%` 内 |
| 交叉臂 | Route B（同一格点步进算子的 FD Jacobian 谱） |

首轮生产跑的结果：门 1 **PASS**（+1.411 %），门 2 **FAIL**（+2.785 %），判例被登记
honest-FAIL。本审计问的是**更靠前一步**的问题：门 2 的 2.785 % 是一个测量，
还是「把某一种收敛形式套在噪声上」的产物？

## ② 怎么做的（方法与工具链）

1. 把每张网格化成**带不确定度的细化点** `(h = 1/ny, Ra_c, σ)`，σ 取驱动器的二分
   分辨率下限 `Ra_c_uncertainty`（由 `sigma_marginal=0.05` 折算，≈0.40 %）。
2. 用新库件 `tensorlbm.refinement_extrapolation`（NumPy-only，本单新增）对梯子做
   **形式识别**：候选形式 `q0 + C·h^p`（p=1、p=2、p 自由拟合）与饱和形式 `q0`，
   以 `1/σ²` 加权最小二乘拟合，`χ²_red` 一致性检验决定「该形式是否被数据许可」；
   许可形式的 `q0` 张成的区间 = **形式不确定度带**（model-form band）。
3. 判定不再取单点估计：`extrapolation_verdict` 以许可带 ±`k·se` 与容差区间求交，
   结果为 `pass` / `fail` / **`undecided_form`**（数据不能定）/ `form_falsified`。
4. `still_converging`：最细两网格之差是否超过自身噪声（z 检验），判断梯子是否已
   在噪声内**饱和**——饱和的梯子不可外推，无论外推出什么数。
5. 交叉：Roache GCI 三网格（最细三联），要求单调趋近；`p_obs > 4` 视为数值饱和。
6. 工具链：`benchmarks/case_pool/rayleigh_benard_onset/grid_ladder_audit.py` →
   `artifacts/grid_ladder_audit.{json,md}` + 两张图；测试
   `tests/test_refinement_extrapolation.py`（12 项，含用本条真实梯子固化的回归）。

## ③ 计算结果（数字表，程序化注入）

**细化梯子**（σ = 二分分辨率下限，非统计误差）

| ny | Ra_c | ±σ | σ/Ra | 误差 vs 1707.7597 |
|---|---|---|---|---|
| 32 | 1711.7386 | 6.8917 | 0.403 % | +0.233 % |
| 48 | 1730.3530 | 7.0406 | 0.407 % | +1.323 % |
| 64 | 1731.8585 | 7.1307 | 0.412 % | +1.411 % |

**各收敛形式（h=1/ny，1/σ² 加权）**

| 形式 | q0 (h→0) | se(q0) | χ²_red | 被许可 |
|---|---|---|---|---|
| h¹ | 1755.468 | 14.698 | 0.349 | 是 |
| h² | 1740.687 | 8.325 | 0.171 | 是 |
| h^p（p 拟合） | 1733.929 | 5.831 | 0.022 | 是（p 区间打在上界 3.8–4.0） |
| 饱和（q0 常数） | 1724.403 | 4.052 | 2.592 | 是 |

- 形式带 `[1724.403, 1755.468]` = **1.785 %** 的中间值；加宽 `k=2σ` 后
  `[1716.299, 1784.863]`，而 ±2 % 容差区间为 `[1673.605, 1741.915]`：
  **带宽 ≈ 容差区间宽（band_vs_tol = 1.004）**，带与容差边界相交。
- 最细两网格差 1.505，合并 σ = 10.021（z = 0.15）：梯子**已在噪声内饱和**。
- 最细三联 GCI：p_obs = **8.742**（≫4 ⇒ 数值饱和），外推值 1731.991（+1.42 %），
  GCI_fine = 9.6e-5。
- 控制臂 Route C 独立得 1707.7685（+0.0005 %），故**判据机器本身没坏**，
  偏差只在 Route A 的 LBM 侧。
- **判决**：`undecided_form` —— 三条以上形式都被 χ² 检验许可（χ²_red 0.02–2.6，均低于
  阈值 3.83/3.0），而它们的极限相差 1.785 %；单取 h¹ 得到的 1755.47 只是「挑了一个
  形式」，不是测量。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **χ² 检验在纯随机噪声下没有否决力**：SSR ≈ σ²·dof 是构造性成立，因此
   「错误形式被拒」只在残差**系统性**超噪时才发生（测试
   `test_systematic_outlier_rejects_form` 固化该边界；`test_saturated_ladder_*`
   固化反面）。三个点 + 0.4 % 的分辨率地板，任何两种形式都过得去——
   这正是门 2 不可判的根因，而不是 1/ny 形式"更对"。
2. `σ` 是**分辨率地板**（来自 `sigma_marginal`/二分步长），不是统计误差；
   它随网格不变（都 ≈0.40 %），所以加密网格不会自动提高可判性，必须同时收紧
   `sigma_marginal`（或加长拟合窗）才能让梯子从噪声里露头。
3. 饱和形式在本梯子上 χ²_red = 2.59（dof=2），虽被许可但已接近阈值，
   即「+1.4 % 常量偏置」比「1/ny 收敛」更符合数据（AIC 最优的是 h^p）。
4. **未做**：ny=96/128 的更细梯子（`runs/rb_ladder_fine.log` 的加密实验在
   会话内未跑完，机器 load15 ≈ 150，按容量纪律终止）。因此本文件**不下**
   「Ra_c → 1707.76 收敛/不收敛」的最终结论，只下「三个点判不了」的结论。
5. 适用范围：本审计对任何"多网格外推 vs 参考值"的判定都通用（库件无域语义），
   但它只审计**外推**这一步；Route A 的物理建模偏差根因（热 LBM 的
   边界/弛豫误差）仍需单独归因实验。

## ⑥ 误差判定（逐项，显式回答 <3 %）

| 关键量 | 值 | 基准 | 相对误差 | <3 %？ |
|---|---|---|---|---|
| Route C 控制臂 Ra_c（Richardson） | 1707.7685 | 1707.7597 | +0.0005 % | **是** |
| 主网格 Ra_c(ny=64)（门 1） | 1731.8585 | 1707.7597 | +1.411 % | **是** |
| h¹ 外推 Ra_inf（原门 2 判决量） | 1755.468 | 1707.7597 | +2.785 % | 是（<3 %），但**判据不成立**：单形式估计，形式带 1.785 % |
| 最细三联 GCI 外推 | 1731.991 | 1707.7597 | +1.42 % | 是；p_obs=8.74 ⇒ 与最细点不可分辨 |
| 饱和形式极限 | 1724.403 | 1707.7597 | +0.975 % | 是，但 χ²_red=2.59 边缘 |
| **形式不确定度（带）** | 1.785 % | — | 带 ≈ 容差区间宽（1.004×） | **否**：单靠数据无法在 ±2 % 门内裁决 |

**结论（honest）**：门 1 通过；门 2 的可判定性不成立——首轮登记的
`Ra_inf = 1755.32 → +2.785 % FAIL` 保留在工件里**不予覆盖**，但它的判据强度应
降级为 `WITHHELD`（形式不可辨识），而不是"物理误差 2.8 %"。可判定的诚实陈述只有两条：
(a) `Ra_c(ny=64) = +1.41 %`，在 2 % 门内；(b) 细化到 ny=64 为止，LBM 侧存在约
**+1.4 % 的饱和系统偏差**，且不随网格衰减（p_obs≈8.7）。要闭合门 2，需要预登记
**≥5 张网格 + σ≤0.1 %** 的梯子，这是本审计给下一单的明确交接口。
