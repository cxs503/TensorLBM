## 1 案例介绍（物理背景 / 几何 / 参数）

真实壁面的切向动量适应系数介于 0（完美滑移）与 1（无滑移）之间。把它做成"可控滑移长度 b 的壁面"是减阻（超疏水表面、气层减阻、冰面/涂层滑移）建模的第一步。LBM 里最便宜的连续可调实现是**混合反弹/镜面壁**：

    f_q(wall) = (1 − σ) f_q̄(wall) + σ f_M(q)(wall)

- `q`：指向流体的方向；`q̄`：反方向（反弹 ⇒ 完全吸收切向动量 ⇒ 无滑移）；
- `M(q)`：关于壁法向的镜面方向（镜面 ⇒ 切向动量全部保留 ⇒ 自由滑移）；
- `σ ∈ [0,1]`：**镜面分数**。这是 Maxwell 一阶滑移条件 `u_t|_w = b ∂u_t/∂n|_w` 的离散实现，Knudsen 层被折算进有效滑移长度 `b`。

本节点**不预设** `b(σ)` 的函数形状，而是从数值实验反标定它：给定 σ 跑定常平面 Poiseuille，从速度剖面反演出 b，再对 (σ, b) 数据拟合标定律；随后用同一标定律把"目标 b"变成 σ 驱动圆管、减阻律与净收益账本。

几何与参数（全部格点单位，Δx = Δt = 1，D2Q9，流场沿 x 均匀故只需一条 y/r 列）：

| 参数 | 符号 | 取值 |
|---|---|---|
| 松弛时间 | τ | 0.8 → ν = (τ−½)/3 = 0.1 |
| 体积力密度 | g | 1.0×10⁻⁵（驱动 x 向流动） |
| 平面通道格点数 | ny | 17 / 33 / 65（半高 H = (ny−2)/2 = 7.5 / 15.5 / 31.5） |
| 平面壁面位置 | y_w | 0.5 与 ny−1.5（半程反弹壁面中面） |
| 圆管径向格点数 | nr | 49（R = nr−1.5 = 47.5；节点 0 在轴上） |
| σ 扫描 | — | {0, 0.1, 0.25, 0.4, 0.5, 0.6, 0.75, 0.9, 0.95, 0.98} |
| 减阻算例船 | — | L=200 m, B=32 m, T=12 m, C_B=0.82, U=15 kn, ρ=1025, ν=1.19×10⁻⁶ |

## 2 怎么做的（方法 / 流程 / 关键设置）

**(a) 混合壁算子与 Maxwell 等价性。** 反弹把切向动量以概率 (1−σ) 完全吸收、镜面以概率 σ 完全保留，故壁面的**切向动量适应系数 α = 1−σ**；一次碰撞后壁面切向动量的期望值正是 Maxwell 一阶滑移所要求的线性响应（滑移速度 ∝ 壁面切变率的输运系数）。三条可写出的代数事实被单独测试（`test_mirror_table_is_involution_and_keeps_cx` 等）：镜面表是对合且保切向分量；σ=0 时逐位等于半程反弹；σ=1 时逐位等于纯镜面；中间值是二者的凸组合。

**(b) 滑移长度反演（解析恒等，不是近似）。** 定常强迫 Poiseuille 的离散解在体区**精确为二次式**（中心差分作用于二次式无截断误差），故对剖面做 `u = A + B(x−x_c)²` 最小二乘后：

- 平面：`A + B H² = −2 B H b` ⇒ `b = (A + B H²)·ν/(g H)`
- 圆管：`A + B R² = −4 B R b` ⇒ `b = (A + B R²)·2ν/(g R)`（多一个因子 2：中心速度是 `gR²/(4ν)` 而滑移项是 `gRb/(2ν)`）

反演同时输出曲率自检 `B_fit / B_theory`（平面 `−g/2ν`、圆管 `−g/4ν`），实测 = 1.000000 / 0.9989，即"剖面确实是抛物线"这一前提是被检验过的，不是假设。

**(c) 圆管轴对称求解器。** 圆柱几何的 `(1/r)∂_r u` 项用**滞后几何源**并入体积力：`F(r) = g + ν(1/r)∂_r u`（r=0 用 L'Hôpital 极限 `2ν(u₁−u₀)`，壁面相邻节点用二阶单侧差分）。定常不动点满足 `ν(u_rr + u_r/r) + g = 0`，而中心差分对二次式精确 ⇒ 离散不动点**精确等于**滑移 Hagen-Poiseuille 闭式解。轴用镜像反射（r=0 平面），外壁同一混合算子。

**(d) 减阻律。** 先按"虚拟壁面位移（负粗糙度类比）"平均剖面模型 `u⁺(y⁺)=u⁺_smooth(y⁺+b⁺)`（Spalding 复合律 + 动量积分）算了一遍 —— **该模型给出的 ΔC_f(b⁺=10) 只有 0.066%，与 DNS 文献量级（10–20%）矛盾，本次据此否定该模型**（见 §5 与 `aux_virtual_wall_model`）。改用 FIK/层流类比标定律：滑移对同压降下的流量贡献 `u_s`，故

    C_f/C_f0 = (1 + k·b⁺/δ⁺)⁻²，δ⁺ = (δ/x)·Re_x·√(C_f0/2)，δ/x = 0.37 Re_x^(−1/5)

k=3 为层流滑移通道的精确值（圆管 k=4），**本仓无离线 DNS 数据，k 未对 DNS 拟合，标 WITHHELD**，并给出 k∈{1,3,6} 敏感性。C_f0 用教科书平板线 `0.0592 Re_x^(−1/5)`（局部）/`0.074 Re_L^(−1/5)`（平均）。

**(e) 净收益账本。** 节能 `ΔP = ΔC_f·½ρU³S`（S = L(1.7T+C_B B) = 9328 m²）；代价模型：气层由单位湿面积注气通量 j = cc·b⁺ 维持，注入压头 = 吃水静水压 `ρgT`，泵效率 0.6，`P_cost = ρgT·j·S/η`。代价值线性于 b⁺ 而节能饱和，故账本用**盈亏平衡系数** `cc_balance(b⁺) = ΔP·η/(ρgT·b⁺·S)` 表达：给定 cc 只在 `cc_balance = cc` 处盈亏平衡，技术可行当且仅当 `cc < max cc_balance`。

## 3 计算结果

### 3.1 b(σ) 标定律（C3）

拟合 `b = a·σ/(1−σ) + c`（取 R² 较大者，另一候选为无截距单参数式）：

| ny | a | c | R² | 原始数据单调 |
|---|---|---|---|---|
| 17 | 0.300000 | −0.008666 | 1 − 7.6×10⁻¹⁴ | 是 |
| 33 | 0.299999 | −0.004191 | 1 − 3.3×10⁻¹³ | 是 |
| 65 | 0.299998 | −0.002050 | 1 − 1.4×10⁻¹² | 是 |

**标定律（ny=33）：`b = 0.30000·σ/(1−σ) − 0.00419`，R² = 0.99999999999967。**

分辨率依赖性有清晰结构：**斜率 a 与分辨率无关（0.299998–0.300000，相对散布 7×10⁻⁶）**，截距随 H 反比衰减：`c·H = −0.147 / −0.138 / −0.133`（ny=17/33/65），即 `c ≈ −0.139/H`。物理解读：a 是格子定域的（一次碰撞的动量簿记），c 是离散解的**振幅偏差**（BGK 二阶误差 ∝ 1/H），与 `σ=0` 时 `b = c` 而不是严格 0 是同一件事（见 C4）。

σ=0.98 时 b = 14.696 lu（≈0.47H），剖面曲率自检 0.999997 —— 抛物线前提在大滑移下依然成立。

### 3.2 平面 Poiseuille 闭环反演（C1）与负控（C4）

| b_target | σ（由标定律反解） | b_inverted | 相对误差 |
|---|---|---|---|
| 0.5 | 0.6270 | 0.500000 | 1.2×10⁻⁶ |
| 1.0 | 0.7700 | 1.000000 | 6.2×10⁻⁷ |
| 2.0 | 0.8698 | 2.000000 | 2.5×10⁻⁷ |
| 3.0 | 0.9092 | 3.000000 | 5.5×10⁻⁸ |

C1 最大相对误差 **1.2×10⁻⁶**（判据 2%）。误差不是因为拟合好，而是因为反演式是代数恒等。

C4 负控（σ=0）：剖面对解析无滑移抛物线的最大相对偏差 **0.0541%**（判据 0.5%），反演 `b = −0.00419 lu`，`|b|/H = 2.7×10⁻⁴`（判据 5×10⁻³），残差 1.0×10⁻¹⁰，收敛。

### 3.3 圆管滑移 Poiseuille（C2）

先做**正控**：σ=0 圆管 `u_max` 数值 0.0562970 vs 解析 `gR²/(4ν) = 0.05640625`，相对误差 **0.194%** —— 轴对称几何源实现正确。

| b_target | σ | b_inverted（原始） | 误差 | 扣 σ=0 偏置后误差 |
|---|---|---|---|---|
| 0.5 | 0.6270 | 0.5168 | 3.37% | 0.82% |
| 1.0 | 0.7700 | 1.0168 | 1.68% | 0.55% |
| 2.0 | 0.8698 | 2.0166 | 0.83% | 0.23% |
| 3.0 | 0.9092 | 3.0164 | 0.55% | 0.06% |

C2 最大误差 **3.37%**（判据 5%）。原始偏置 `b(σ=0) = 0.0127 lu` 来自轴心环带拟合排除的 O(1) 轴层（曲率自检因此是 0.9989 而非 1.000000）；这是可标定的常数偏置，扣掉后最大误差 0.82%。

**跨几何传递**：平面标定律预测 `b(σ=0.5) = 0.2958`，圆管实测原始值 0.3127 减去偏置 0.0127 = **0.3000**（差 1.4%）。即"平面标定的 b(σ) 直接用于圆管"是成立的。

### 3.4 自由滑移极限（C5）

| σ | 1−σ | b [lu] | 1/b |
|---|---|---|---|
| 0.90 | 0.10 | 2.6958 | 0.3709 |
| 0.95 | 0.05 | 5.6958 | 0.1756 |
| 0.98 | 0.02 | 14.6958 | 0.06805 |
| 0.99 | 0.01 | 29.6956 | 0.03367 |
| 1.00 | 0 | ∞ | 0 |

`1/b` 对 `(1−σ)` 线性，斜率 3.755、R² = 0.99938（判据：发散趋势被记录）。σ=1 单独处理：**纯镜面下自由滑移通道 + 体积力不存在定常解**，实测速度剖面是塞流（相对展开 2.8×10⁻¹⁵）、曲率比 −7.7×10⁻¹⁵（完全平坦）、动量以 0.31/千步 线性增长且永不收敛 —— 这正是 `b→∞` 的动力学指纹，而不是"数值发散"。极限因此是被**记录并解释**的，不是被当成失败掩盖。

|---|---|---|---|
| 5 | 0.0197% | 0.48 | 0.033 |
| 10 | 0.0394% | 0.96 | 0.065 |
| 20 | 0.0787% | 1.93 | 0.131 |
| 50 | 0.197% | 4.81 | 0.327 |

| 200 | 0.783% | 19.15 | 1.307 |
| 400 | 1.557% | 38.07 | 2.614 |

**盈亏平衡系数 `max cc_balance = 5.13×10⁻⁸ m/s per b⁺`**。物理上注气通量系数在 10⁻⁵–10⁻⁴ 量级（模型尺度/文献量级），比 5.13×10⁻⁸ 大 2–4 个数量级 ⇒ **在开放注气代价模型下不存在盈亏平衡 b⁺（账本恒为负）**，cc ∈ {2×10⁻⁵, 5×10⁻⁵, 10⁻⁴, 2×10⁻⁴} 四个取值全部 `viable = False`。

模型尺度（L=5 m, U=3 m/s，Re_L=6.48×10⁶，δ⁺=3734）对照：b⁺=20 → ΔC_f=3.14%（节能 44 W），b⁺=50 → 7.58%。**同一 b⁺ 在船尺度只值 0.079%** —— 滑移机理按 `b⁺/δ⁺` 定价，δ⁺ 涨 40 倍，收益掉 40 倍。这是账本的核心结论，也是超疏水减阻"实验室有效、实船无效"的定量解释。

## 5 注意点（踩坑 / 局限 / 适用范围）

1. **混合反弹/镜面的成本最低实现有一个不可避免的 σ=0 偏置**：它不是零而是 `c ≈ −0.139/H`。原因是 σ=0 的离散流场本身有 O(1/H) 的振幅偏差（BGK 二阶误差），而 b 由 `A + B L²` 这个**两个同量级数之差**给出，把振幅误差放大成常数量级偏差。使用本标定律时应当**减去 c**（或直接取 `b_eff = a·σ/(1−σ)`）。这是本模块给出 c 而不只给 a 的原因。
2. **圆管的 b 反演对曲率误差极端敏感**（`b ∝ (A + B L²)`，A 与 `B L²` 近似抵消），`B` 的相对误差被 `L²` 放大。因此圆管拟合必须排除轴层（默认环带 0.2R–0.6R）。踩过的坑：把轴心包含进拟合时 b(σ=0)=0.0207、曲率比 0.9973，反演全盘偏移约 0.05 lu。
3. **虚拟壁面平均剖面模型被本次否定**（诚实负面结论）：它把滑移效应限制在 `y⁺ ≲ b⁺`，即薄层的 `b⁺/δ⁺` 份额，在 Re_θ=10⁴ 给出 ΔC_f(10)=0.066%、(30)=0.296%，与 DNS 量级不符。真机理是湍流对滑移的响应（对数区上移），平均剖面位移模型抓不到。这条结论**不因"拟合不好"而废弃，而是作为否证入账**。
4. **k=3 未经 DNS 标定（WITHHELD）**：仓内无离线 DNS 数据集，k 只由层流类比给出，敏感性 1–6 倍跨 6 倍。ΔC_f 的量级因此是本模型的不确定带，不是已知量。C6 判据只要求单调性，这一点是可靠的（模型对 k>0 恒单调）。
5. **账本的代价模型是上界**：假设开放注气（持续补气 + 对抗吃水静水压）。封闭气腔（无持续补气）时代价趋 0，账本上界即退化为"节能 = 净收益"，因此真实区间是"开放注气（强负）↔ 封闭气腔（正）"这两条边界之间；本节点的结论只对前者成立。注气通量系数无离线文献锚点，标 WITHHELD。
6. **适用范围**：低 Mach（本例 u_max ≤ 0.05）、不可压、纯 BGK、单相、壁面切向静止（`u_wall=0`）。本模块未处理壁面运动、壁面粗糙度叠加、或 Knudsen 层的一阶以上修正。3D 通道的 D3Q19 版本算子形式相同（镜面表换成轴对齐镜像），本节点只做到 D2Q9 一维列归约（目标流动沿流向均匀，无需 3D）。
7. 已有 `tensorlbm.boundary.navier_slip_bc` 里的 `β = Ls/(1+Ls)` 是**未标定的假设**（β 按插值参数线性取，无 Poiseuille 反演证据）。本节点给出的 `b(σ)` 才是可反查、可对拍的关系；两者不能混用（navier_slip_bc 的 β 参数记作插值参数，不是滑移长度）。
