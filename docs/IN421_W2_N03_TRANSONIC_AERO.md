## 1 案例介绍

### 1.1 物理背景
* **亚声速可压缩（Ma=0.3/0.5/0.7）**：NACA0012 升力线斜率随 Ma 按 Prandtl-Glauert
  `2π/β`（β=√(1−Ma²)）增大，直至临界马赫数后出现局部超声速区。
* **跨声速（Ma=0.85）**：上/下表面出现超声速泡并以**终激波**收尾。激波位置与强度是
  可压缩求解器的分水岭：位置由全局质量/动量平衡（Kutta 条件）决定，强度必须满足
  Rankine-Hugoniot（RH）关系。
* **声爆（Ma=2/4，双楔二维体）**：前楔压缩产生跃升 Δp、后楔 Prandtl-Meyer 膨胀产生
  负压，构成经典 **N 波源**；线性理论（Ackeret）与精确斜激波/P-M 关系是两条不同的
  参考线，本节点把二者的差别作为**判据本身的可证伪性**来检验（见 §3.5、§6）。

### 1.2 几何与网格
| 项 | 值 |
|---|---|
| 翼型 | NACA0012（4 位系列，t=12%，尖后缘闭合），弦长 c=1 |

| 径向 | 几何级数梯（首层 2e-3c，远场 12c），增长比按 `r_out` 反解 |

## 2 怎么做的

### 2.1 求解器内核（既有，本节点复用）
动力学通量向量分裂（**KFVS**，Pullin 1980 / Mandal-Deshpande 1994）：把 **LBM 平衡态
（Maxwellian）在半速度空间上的解析矩** 作为有限体积界面通量，

```
F_ρ = ρ_L g1⁺(q_L,σ_L) + ρ_R g1⁻(q_R,σ_R)，  σ=√(RT)
F_E 用 β=γ/(γ−1)−3/2 把单原子能量通量推广到任意 γ（γ=1.4 → β=2）
```

`gk±` 由 erf/exp 闭式给出（无积分误差）；MUSCL 二阶重构 + minmod 限制器；显式 Euler +
局部时间步；壁面为绝热滑移（纯压力通量）；远场为自由来流 KFVS 特征化边界。
该内核在 P153W1-N05 已用 Rankine-Hugoniot / 熵增 / 总焓三个解析锚定量验证（误差
0.03%–0.26%），本节点不再重复，只把它当**被验证求解器**使用。

### 2.2 判据实现（新模块 `transonic_aero.py`）
| 判据 | 函数 | 参考锚 |
|---|---|---|
| (a) 升力线斜率 | `lift_slope`（α≤4° 最小二乘）| 2π、2π/β、2π(1+0.77t) |
| (b) 阻力发散 | `run_naca_case` + `critical_mach_from_cp_min` | Abbott C_p,min→M_cr |
| (c) 激波位置 | `shock_from_surface_mach` | 等熵反算 C_p→M，**超声速泡闭合点** |
| (d) 声爆 Δp | `run_wedge_case`、`wedge_reference_table`、`wedge_expansion_reference` | Ackeret、精确斜激波、P-M 膨胀 |
| (e) 等熵关系 | `isentropic_deviation` | p/ρ^γ = const |
| (f) 网格收敛 | `gci_roache` | 三网格 Roache GCI |

**激波定位方法的改变**（吸取 P153W1-N05 的教训）：旧实现用“C_p 梯度最大”定位激波，
把激波与后缘压力恢复混为一谈（导致激波强度误差 90%）。本节点改为：由 C_p 等熵反算
表面 Mach 数 → 找超声速泡 → **泡闭合处**（M 穿越 1）线性插值定位置，RH 强度用该站
上游 Mach 计算。

### 2.3 两个求解器缺陷的定位与修复（本节点的实质增量）

**缺陷 1：壁面不是翼型，而是偏移曲线。**
`radial_levels(nj, r0, r_out)` 的首层是 `r0`，于是 O 网格的内边界是 **距翼型 r0=0.02c 的
偏移曲线**。NACA0012 前缘曲率半径仅 0.0158c < r0，偏移曲线在前缘**自交**，壁面 C_p 与
力积分都建立在一条“变形的翼型”上（弦长 1.04c、前缘起皱）。实测后果：Ma=0.3, α=2° 时
C_D=0.1240（无粘流应有 C_D≈0，即 100% 伪阻力）、C_p,min=−2.73（由 C_p 反算局部 Ma>1，
但速度场最大 Ma 只有 0.385，自相矛盾）。
**修复**：新增 `radial_levels_from_surface(nj, r_out, first_cell)`，令 **r=0 即翼型表面**，
首层高度 = 指定值。

**缺陷 2：级数梯“先定比再归一化”把壁面单元压扁。**
旧实现对固定增长率 1.12 的级数整体缩放，使得 nj=64 时首层高度 2e-3c、nj=96 时塌到
**3e-5c**（壁面单元纵横比 1e2 以上），因此“网格一加密就发散”。
**修复**：改为按 `r_out` 反解增长率（几何级数精确跨到远场），首层高度与 nj 解耦。

**修复前后对照（Ma=0.3, α=2°, 160×64）**

| 量 | 修复前（偏移壁 + 缩放梯）| 修复后（壁=表面 + 反解梯）|
|---|---|---|
| C_L | 0.2260 | 0.2396（L1）/ 0.2513（L3）|
| C_D（无粘）| **0.1240** | **0.0124（L1）/ 0.0038（L3）** |
| C_p,min | −2.727（伪，与速度场矛盾）| −0.411 |
| 加密到 320×96 | 400 步内发散（maxMa 3–6）| 收敛 14000 步，残差 1.9e-4 |
| Ma=0.85 激波强度误差 | 90%（N05 报告）| +44.5%（方法本身也换了，见 §5.3）|

新增 `mesh_quality(mesh)`（有符号面积/折叠单元诊断）把所有网格健康度变成可测数字：
三套网格均只有 **2 个折叠单元**（后缘 O 型拓扑的坐标奇点，标准 O 网格固有），
其余全为凸四边形。

### 2.4 工具链
numpy 向量化（无 C 依赖）+ `multiprocessing` 并行（14 进程，25 个算例 1208 s）；
matplotlib 出图；pytest 21 项单测（几何解析值、壁面=表面、级数梯首层、
GCI 二阶回收、斜激波 θ-β-M、P-M 膨胀、激波检测、等熵偏差、端到端冒烟）。

### 3.1 V1 几何验证（机器判据前置）
弦长误差 −2.5e-4%、最大厚度误差 −1.7e-4%、面积误差 −1.3e-4%、环路闭合 3.3e-17 →
**几何 PASS**（任何后续物理误差都不可能来自几何）。

### 3.2 V2 (a) 升力线斜率

|---|---|---|---|---|---|
| 0.3 | 6.874 | 0.1199 | **+9.37%** | **+4.33%** | **+0.12%** |
| 0.5 | 7.546 | 0.1317 | +20.1% | +4.01% | +9.94% |

## 5 注意点（踩过的坑、局限、适用范围）

### 5.1 壁面必须是翼型表面（本节点最大修复）
O 型网格径向梯的“首层 r0”设计，在**前缘曲率半径小于 r0** 时让偏移曲线自交：壁面几何、
C_p、力积分全错，且产生 100% 量级的伪阻力。任何“壁面量”都要先验证**网格第 0 层线
= 物体表面**（单测 `test_wall_nodes_are_the_airfoil_surface` 锁定）。

### 5.2 级数梯不能“定比后归一化”
固定增长率再整体缩放，nj 增大时首层高度按几何级数塌陷（nj=96 时 3e-5c）。正确做法是
**按远场距离反解增长率**。这条坑表现为“网格越密越发散”，极易误判为格式不稳定。

### 5.3 激波强度指标在 3–4 单元涂抹下有 ±40% 不确定度
等熵反算的表面 Mach 在激波涂抹带内被压低（本例站上游 Ma=1.08，而泡内峰值 1.31），
RH 预测随所用 Mach 剧烈变化（1.19 vs 2.67）。因此“激波强度误差”在本分辨率下只能作
**量级判据**；要拿到定量激波强度，需要更细网格或按马赫数等值线定义激波前后平台
（后续工作）。

### 5.4 二维 KFVS 贴体路径存在**边缘稳定性区**
实测稳定性地图（Ma=0.3, α=2°, CFL=0.4，1500–16000 步）：

| 网格 | 单元数 | 结果 |
|---|---|---|
| 160×64 | 10080 | **稳定**（16000 步，残差 1e-6）|
| 240×64 | 15360 | 稳定 |
| 320×96 | 30400 | **稳定**（14000 步，残差 1.9e-4）|
| 384×128 | 48768 | **稳定**（14000 步）|
| 80×32 / 240×96 / 256×72 / 320×128 / 400×96 / 480×128 | 2480–60960 | **发散**（100–7000 步内 maxMa→5…8）|

发散点可定位到后缘 O 型拓扑奇点处的退化单元 + 远场极坐标混合区的强剪切单元；
**不是** CFL 问题（降到 0.25 仍发散）。这也解释了判据 (f) 的网格序列为何只能用
160×64 / 320×96 / 384×128（细分比 1.27，非理想 2）。根治需要 **C 型网格尾迹切口 +
壁面 ghost-cell**，是本路径的首要技术债（后续节点）。

### 5.5 无粘（Euler）局限
无摩擦、无边界层位移、无粘性阻力发散的真实机理（激波-边界层干扰）。因此
判据 (b) 与 AGARD 粘性实验的直接比对在本求解器上**无物理意义**，只能比“波阻增量”。

### 5.6 跨声速稳态收敛慢
Ma=0.85 算例的 C_D 在 6000→14000 步内仍缓慢下降（0.0525→0.0484），残差平台
1e-4–3e-4，说明存在慢变模态（激波缓慢定位 / 后缘尾迹摆动）。本报告所有跨声速数值
都标注了残差与迭代数；GCI 判定因此**降级为不可算**而非“看起来收敛”。

### 5.7 适用域
本内核面向 Euler 可压缩流（亚声速–超声速、激波捕捉、近场声爆源）。Ma<0.3 的粘性/
热耦合仍走 DDF-LBM 路径（`compressible/naca0012_lbm.py`），两条路径不可混用于同一判据。
