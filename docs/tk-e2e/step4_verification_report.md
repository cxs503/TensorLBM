## ① 案例介绍

### 物理背景
两相 Poiseuille 流是验证多相流求解器的标准基准：两层不可混溶流体（水/气）在平面通道中受体积力驱动，达到稳态时速度剖面为分段抛物线，界面处满足速度连续和剪切应力连续条件。

### 几何与参数
| 参数 | 值 | 说明 |
|------|-----|------|
| 通道高度 H | 64/128 格 | 两层网格 |
| 周期方向 x | 8 格 | 窄通道避免三维效应 |
| 水相 τ_w | 1.0 | ν_w = 1/6 |
| 气相 τ_g | 0.75 | ν_g = 1/12 |
| 黏度比 M | 2.0 | ν_w/ν_g |
| SC 耦合 G_12 | -2.5 | 强分相 |
| 体积力 G_x | 5×10⁻⁶ | 驱动流动 |
| 界面厚度 | ~6 格 | tanh-3 初始场 |

### 解析解
两层 Poiseuille 解析解（`_two_phase_poiseuille_analytical`）：
- 下层的（水，0 ≤ y ≤ half）：u_w(y) = (G_x/(2ν_w))·y·(B-y)
- 上层的（气，half ≤ y ≤ H）：u_g(y) = (G_x/(2ν_g))·(y-H)·(A-y)
- 界面条件：u_w(half) = u_g(half)，μ_w·du_w/dy = μ_g·du_g/dy

## ② 方法

### 知识检索（Step 1）
从 TensorKnowledge `knowledge/oss-lbm/claims/` 检索到三种速度耦合约定：
1. **重均速度** (lbmpy, Shan & Doolen 1995): `u_mix = (ρ₁u₁ + ρ₂u₂)/(ρ₁ + ρ₂)`
2. **黏性加权速度** (sailfish, Martys 1996): `u_visc = (ρ₁u₁/τ₁ + ρ₂u₂/τ₂)/(ρ₁/τ₁ + ρ₂/τ₂)`
3. **自身速度** (原始 SC): 各组分使用自己的速度

### 修复方案（Step 2-3）
在 `collide_sc_two_component` 中新增 `u_eq="viscous"` 模式，实现 sailfish 风格的黏性加权速度耦合。

**代码改动**（`src/tensorlbm/multiphase.py`，第 637-651 行）：
```python
elif u_eq == "viscous":
    w1 = rho1_s / tau1
    w2 = rho2_s / tau2
    w_tot = w1 + w2
    u_visc_x = (w1 * ux1 + w2 * ux2) / w_tot
    u_visc_y = (w1 * uy1 + w2 * uy2) / w_tot
    feq1 = equilibrium(rho1, u_visc_x + tau1 * Fx1 / rho1_s, ...)
    feq2 = equilibrium(rho2, u_visc_x + tau2 * Fx2 / rho2_s, ...)
```

- 对比解析解，计算中心区域 max_rel_err

## ④ 结果分析

### 误差机理确认

**根因链**：
```
"self" 模式 → 界面处 u₁ ≠ u₂（速度不连续）
           → 等效界面滑移
           → 流动阻力降低
           → 流量高估 20-33%
           → 误差随网格加密增大（系统性偏差）
```

**证据**：
- Color-Gradient 方法使用单一速度场 → 0.2% 误差（PASS）
- SC MCMP "self" 模式允许速度不连续 → 20-33% 误差（FAIL）
- 误差随网格加密增大（26.8% → 33.2%）→ 非离散误差，是模型偏差

### 修复失败原因

**"viscous" 模式发散的机理**：
1. 黏性加权强制 u₁ = u₂ = u_visc
2. 但 SC 互作用力 F_12 ∝ ∇ρ 在界面处很大
3. 力项试图产生速度差（分相），速度耦合试图消除速度差
4. 两者冲突 → 数值振荡 → 密度越界 → 发散

**数学分析**：
- 黏性耦合的动量交换：ΔM_σ = (ρ_σ/τ_σ)(u_visc - u_σ)
- 当 τ₁ ≠ τ₂ 时，Σ_σ ΔM_σ ≠ 0（净动量源）
- 这与 "mixture" 模式的不稳定性同源

### 排除的候选机理

| 候选 | 排除理由 |
|------|----------|
| 力项离散误差 | 标准 SC 力项 O(h²)，不会导致 20%+ 误差 |
| 界面厚度效应 | tanh-3 界面足够薄，CG 方法同厚度 0.2% 误差 |
| 壁面边界 | bounce-back 标准实现，单相验证 <1% |
| 弛豫时间组合 | τ=(1.0, 0.75) 在稳定窗口内 |
| 解析解错误 | 解析解与 CG 结果一致（0.2% 误差） |

## ⑤ 注意点

### 局限性与适用范围

1. **SC MCMP 的根本限制**：
   - SC 模型通过互作用力维持界面，这要求两相可以有不同速度
   - 强制速度连续与 SC 力的物理机制冲突
   - 结论：SC MCMP "self" 模式**不适合**两相 Poiseuille 流（不等黏度）

2. **推荐替代方案**：
   - Color-Gradient 方法：单一速度场 + 重着色 → 0.2% 误差
   - Free-Energy 方法：热力学一致界面 → 待验证
   - 若必须用 SC MCMP：仅适用于等黏度或界面追踪非关键的场景

3. **"viscous" 模式的适用窗口**：
   - 仅当 G_12 较弱（|G_12| < 1.0）且 τ₁ ≈ τ₂ 时稳定
   - 即使稳定，误差也不改善（甚至更大）
   - 不推荐用于强分相场景

### 踩过的坑

1. **黏性加权 ≠ 无条件稳定**：
   - 文献中 sailfish 使用黏性加权，但未说明参数窗口
   - 实测：强 SC 耦合 + 不等 τ → 发散
   - 教训：速度耦合的稳定性取决于与力项的兼容性

2. **小网格快速测试的误导**：
   - ny=33 小网格 "self" 模式欠预测（ratio=0.93）
   - 全尺寸 H64/H128 过预测（ratio=1.27/1.31）
   - 教训：网格尺寸影响误差方向，需用全尺寸验证
