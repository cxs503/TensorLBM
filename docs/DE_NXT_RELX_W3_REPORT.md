## ① 案例介绍（物理背景 / 几何 / 参数表）

**物理背景**：单液滴撞击深水池（Santini case-3）。滴撞击水面后把空气卷入形成气穴（cavity），气穴底被液滴动量压至最深后回弹坍缩。本战役的核心量化量是**气穴峰深**及其**出现时刻**：实验基准 1.857434 D @ 10.39446 ms（post-contact 口径）。当前基线（自由面 VOF + D3Q19 BGK 碰撞）峰深 1.435220 D @ 10.543339 ms（pc），深度误差 **−22.73%**，即气穴**系统性偏浅**。

**几何 / 工况**（与战役位级锚完全同旗标）：cells=8（cells/D）；`--gap .18 --speed .06 --capacity --simple-exchange --release-speed 1.53 --span 4 --pool-depth 3`（u_limit 0.15），steps 10000，postcontact 满窗 = 24.005 ms，contact_step=45，impact 1.4092 m/s。

## ② 怎么做的（方法 / 流程 / 关键设置 / 工具链）

本单是**设计单**（设计官不跑仿真），方法链为：黑板证据审计 → **源码级审计**（找出既有卡未覆盖的结构事实）→ 构造可判决的量化框架（兑换率）→ 假说登记册（hypothesis-generation 技能：5 个竞争假说 + 判别实验 + 判决分支）→ 双臂预登记赛马卡。

**源码级审计的 4 条新事实**（本单查得，均可复现）：

| # | 事实 | 证据 |
|---|---|---|
| F1 | 气胞**从不参与碰撞**（恒置 feq_gas）⇒ "液气两相弛豫率分离"对气相结构性无效 | `src/tensorlbm/free_surface_lbm.py:987` `f_collide=where(non_gas,f,feq_gas)`；`:1094` 气/固胞回填 `f_collide` |
| F2 | `collision=="kbc"/"cascaded"/"cumulant"` 三分支是**死代码**（导入的模块不存在） | `free_surface_lbm.py:991-1002` import `.advanced_collision_d3q19`；实测 `ModuleNotFoundError`；`cg_advanced_collision.collide_cg_kbc_3d` 等为 WITHHELD 别名 |
| F3 | 真正的 RR 核在 main 且**由调用方供 feq**（⇒ Guo 半步位移可同构） | `collision_d3q19_advanced.collide_regularized_stress_d3q19(f_total, feq, tau)` |
| F4 | 真 KBC 三段熵碰撞在仓（numpy），但 **D3Q19 权重坏**（和=0.9629629629629628，断言失败）；`_D3Q19_DIRS` 序与求解器 `d3q19.C` **逐项一致**（免置换）。**本单已修并加单测**：权重改 1/3, 1/18×6, 1/36×12（与 `d3q19._W_VALUES` 逐项一致），`tests/test_kbc_d3q19_lattice.py` 5 项全过；α=1 与求解器 BGK 相对误差实测 **5.0e-05**（max abs 1.68e-05，float64 核 vs float32 求解器）⇒ ARM2 的 Gate0 由"修+验"降为"验" | `kbc_collision._weights/lattice`；实测 `ordering identical: True`；commit 5106de709 |

**核心框架（可判决量）**：把"加深旋钮"统一折算为**兑换率** rate = Δt_pc/Δdepth（ms/D）。

- 实测三点：RR 全场 **14.690**（+0.120037 D / +1.763304 ms）、界面胞 τ 分离 **6.533**（+0.236399 D / +1.544429 ms）、HYDRO **14.853**（+0.201408 D / +2.991536 ms）；三栈组合 combo_hydro **11.956**。
- 双门需求：深度门需 **+0.422214 D**；3% 时刻预算只有 **+0.162955 ms** ⇒ 可接受兑换率 **≤0.3860 ms/D**。
- 结论（可证伪的量化命题）：**既有旋钮族的最省兑换率 6.533 ms/D 比门限高 16.9×** ⇒ 沿"旋钮强度"方向不可能同时满足深度门与时刻门 ⇒ 本波必须改**结构**（高阶矩的处理方式），而不是调旋钮。

**工具链**：`docs/DE_NXT_RELX_W3_EXCHANGE_RATE.py`（数字表→派生量→图，程序化注入、零手抄）；`docs/DE_NXT_RELX_W3_HYPOTHESIS.md`（假说登记册）；`docs/DE_NXT_RELX_W3_TRACK.md`（黑板卡副本）；黑板 `BB/NEXT/TRACK_RELX_W3.md`（26 行，机器格式，task_key 前缀 DE-X-）。

## ⑤ 注意点（踩过的坑 / 局限 / 适用范围）

1. **口径陷阱（重要）**：战役内并存两套峰时刻口径（绝对 ms vs post-contact pc）。DE-X-CMB1-HYDRODCA 把 ctrl 的**绝对** 11.0906 ms（+6.70%）与 DCA 的 **pc** 10.531 ms（+1.32%）并列比较，据此宣称"DCA 提前峰时刻 +6.70%→+1.32%"。同口径重算：DCA 相对 ctrl 仅 **提前 0.0123 ms**（≈0.1%），DCA 实为"变浅"旋钮而非"提前"旋钮。本卡与本报告统一用 pc 口径（ctrl 10.543339，实验 10.39446 ⇒ +1.43%）。**建议战役层面统一口径并重算 DCA 的时刻效应。**
2. **兑换率是 n=3–4 的样本，不是定律**：三点（6.53/14.69/14.85）同号但离散度大；"16.9× 超出"这一说法对样本敏感，本卡只用它作为"该族方向已接近尽头"的**软证据**，判决仍以 ARM1/ARM2 的预登记区间为准。
3. **单分辨率**：全部数字 cells=8，无 12 cells 收敛对；TRT2/IFTRT 的早死是鲁棒信号（0.29/0.51 ms，早于任何分辨率效应），但深度结论不可外推。
4. **本单含一处真实缺陷修复**：`kbc_collision._weights` 对 D3Q19 误用 D3Q27（Qian）权重公式，权重和 26/27 ⇒ `lattice(19)` 直接断言失败，熵碰撞核在 D3Q19 上**完全不可用**；本单已修（权重与 `d3q19._W_VALUES` 逐项一致）并加 5 项契约单测，D3Q27 路径未动（回归单测覆盖）。该修复不改变任何既有可用路径（原 D3Q19 调用一律抛异常）。
5. **依赖上游 commit**：ARM1 需 cherry-pick `agent/m26958` 的 RR 端口（`edbd0a013`）；若该 commit 不可用需重写端口（工作量与风险已登记为 arm 的 Gate0 前提）。ARM2 需修 `kbc_collision._weights` 的 D3Q19 权重缺陷（**本单查出的新缺陷**，权重和 0.96296）。
6. **ENTROPY 臂的工程风险**：numpy↔torch 桥、熵求解成本（24 次 Newton/二分）未知；已预登记成本门（单步 >5×BGK ⇒ 降级为已登记的 α=0.5 固定档并如实登记，不改主判决口径）。
7. **假说残余**：H5（ABB 奇数模注入，T4-RED 根因）只残余 ≤0.07 D 量级未排除（TRT2/IFTRT 两次早死只否掉它作为主要深度增益来源）。
8. **适用范围**：结论仅对"液滴入深水池自由面 + D3Q19 + 低 τ（0.5003877 贴稳定底）"这一族工况成立；把 BGK 换成远离稳定底 τ 的算子，虚假粘性与界面振荡的相对权重会改变，本框架需重新标定。
