## 1 案例介绍（物理背景 / 几何 / 参数）

壁面滑移（superhydrophobic / gas-layer / rarefied 壁面）在连续介质层面由 **Maxwell 一阶滑移条件**
描述：`u_t|_w = b (∂u_t/∂n)|_w`，其中 b 为滑移长度。LBM 里最廉价的可连续调节实现是
**混合反弹/镜面壁**（mixed bounce-back / specular，fractional BB）：

```
f_q(wall) = (1−σ) f_opp(q)(wall) + σ f_mirror(q)(wall)
```

σ=0 为半程反弹（无滑移，壁面在流体首行外半格），σ=1 为纯镜面（自由滑移）。本站把 b 当作
**由算子产生的、可反标定**的量：给定 σ 跑滑移 Poiseuille，从剖面反演 b，再对 b–σ 拟合标定律。

本站的物理与数值设置（全部由 `results.json["config"]` 注入）：

| item | value | note |
|---|---|---|
| lattice | D3Q19 (3D) / D2Q9 1D column | tensorlbm.d3q19 tables |
| relaxation | BGK, τ=0.8 | ν=(τ−1/2)/3 |
| viscosity | 0.1000 | lattice units |
| body force | Guo, g=1.00e-05 | ρg along x |
| plane resolution | ny ∈ {17,25,33,49}, nx=nz∈{1,2,3} periodic | H=(ny−2)/2 |
| pipe resolution | nr ∈ {17,25,33} | R=nr−1.5 |
| σ grid | 0,0.1,0.25,0.4,0.5,0.6,0.75,0.9 (+1.0 for the free-slip record) | specular fraction |

两种几何：

* **平面通道**：两块混合壁夹持的平面 Poiseuille，解析解 `u(y)=g/(2ν)(H²−s²)+gHb/ν`；
* **圆管**：轴对称滑移 Hagen–Poiseuille，解析解 `u(r)=g/(4ν)(R²−r²)+gRb/(2ν)`。

两者都在**体积力驱动、定常**条件下求解，收敛判据为 `max|Δu|/max|u| < 1e-10`（终态残差见
逐 job 的 `residual`）。

## 2 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**(a) 3D 算子（新）** —
`src/tensorlbm/boundary/partial_slip_wall3d.py` 在**完整 D3Q19 格子上**实现混合壁：x、z 周期，
y 向两块固壁逐 link 施加混合反射；镜面表由仓内 canonical 的 `tensorlbm.d3q19.C` **推导**而非手抄
（`MIRROR_Y[q]` = 保 c_x、c_z、翻 c_y 的分量），因此换速度集不会静默破坏算子。

**(b) 与 Maxwell 条件的等价（解析 + 数值）** —
反演式 `b = (A + B L²)·ν/(gL)` 不是拟合技巧：由解析解
`u_w = g H²/(2ν) + gHb/ν − gH²/(2ν) = gHb/ν`（把抛物线外推到壁面），
`(∂u/∂n)|_w = gH/ν`，两者相除精确给出 b。即**反演式就是 Maxwell 一阶滑移条件在半程反弹壁面上的
离散形式**；`test_estimators_recover_analytic_*` 把它作为恒等式验证到 1e-10。

**(c) 三种互不共享误差机理的反演估计量（新）** —
1. `quadratic`：对剖面做 `u = A + B s²` 最小二乘，`b=(A+BL²)ν/(gL)`（上游方法）；
2. `model`：曲率 `B` **取解析值**不拟合，只有滑移偏置未知，取近壁带均值
   `b = mean(u−u_noslip)·ν/(gL)`；
3. `bulk`：完全不用剖面形状，用体积/流量均值
   `u_mean = g/(2ν)(L²−⟨s²⟩) + gLb/ν`（圆管 `g/(4ν)(R²−⟨r²⟩)+gRb/(2ν)`），其中 `⟨s²⟩` 用
   **采样点的二阶矩**（不是连续值 L²/3），这消除了 O(h²) 求积偏差（实测约 0.005 lu，见 §5）。

**(d) 闭环反演** — 由标定律反解 σ 使 b=b_target，再在新算例里反演 b，比较 b_inv 与 b_target。
两类闭环：**自洽**（σ 用同几何同估计量的定律反解）与**跨几何迁移**（σ 用**平面**定律反解，在
圆管里测量）——后者是非循环的预测检验。

**(e) 减阻律与净收益** — 沿用上游的虚拟壁面（Spalding 复合律 + von Kármán 动量积分）模型给出
`ΔC_f(b⁺,Re_L)`，本站重算并加入**航速敏感性**与**k 敏感性**；净收益账本把节能与注气代价
`P_cost=ρgT·j·S/η` 对比，给出盈亏平衡**代价系数**。

**工具链**：全部 numpy 定常 LBM 求解（无外部求解器）；70+ 个算例由
`artifacts/P106W1-N04/run_study.py` 在集群（loong64，28 进程并行）跑出，逐算例落
`data/job_*.json`，`--merge` 汇总为 `results.json`；图由 `figures.py` 从 `results.json` 程序化生成；
本文所有数字与表格由 `emit_report.py` 从 `results.json` 注入，零手抄。

## 3 计算结果

### 3.1 C0：一维列归约的**精确性**（新验证）

上游模块把 3D 流场压成一列（"流向均匀所以一列够用"）——这是一个**关于算子**的假设。
本站用完整 D3Q19 场检验它（固定步数，两边都不看收敛判据，因此差值只含算子差）：

| ny | periodic plane | fixed steps | |u₃D−u₁D|/u_max | x/z 面内不均匀度 |
|---|---|---|---|---|
| 17 | 3×3 | 4000 | 5.58e-14 | 1.43e-16 |
| 33 | 3×3 | 4000 | 2.68e-14 | 1.42e-16 |

**逐点最大相对差 5.58e-14，周期面内不均匀度 1.43e-16**
→ 1D 列归约对本类流动是**恒等**（到舍入），不是近似。这条结论反过来给上游模块的廉价扫描背书。
（若两边都用残差判据收敛，差值会被判据本身主导：9.99e-11 ——
这正是"看起来像模型误差、其实是停机口径不同"的坑。）

`b=(A+BL²)ν/(gL)`、`H=(ny−2)/2` 口径，可由 `results.json` 逐位复算。

三条可读结论：

1. 圆管的**二次拟合**反演有一个**常数偏置**：其定律截距 `c=0.0198`
   而模型估计给出的截距 `c=-0.0054`，两者**斜率完全相同**
   （`a=0.299879511`）→ 偏差纯加性，量级 ≈
   0.0252 lu。
   机理：`b` 由 `A + B L²` 这个"两个同量级数之差"给出。圆管离散解**不是**精确抛物线：
   实测曲率比 `B_fit/B_analytic = 0.997392`（偏差 0.261%，来自轴对称几何源的
   O(1/R) 轴层），该相对误差被 `L²/(A+BL²)` 这个放大因子（L=31.5，量级 10³）放大成加性偏置。
   平面通道没有这一项：其曲率比 = 1.000000（拟合残差 ~1e-12），所以同一公式在那里是代数恒等。
2. **模型估计量没有这个偏置**：跨几何迁移最大误差 0.288%，
   且完全不依赖经验扣偏置；体均值（第三个独立机理）0.886% 交叉确认。
3. 上游"扣掉 σ=0 偏置"的做法在本站被**量化**：它在 b=0.5 时把误差从 3.37% 变成 4.0%（因为偏置
   随 b 增长而非定值），而模型估计量直接给 0.29% —— 同一目标下更少的活动部件。

## 5 注意点（踩坑 / 局限 / 适用范围）

1. **收敛口径会把模型误差藏起来**：C0 若两边都用残差判据，差值 1e-10 全是停机时刻不同造成的；
   固定步数后才是 5.6e-14 的真实算子差。任何"两个求解器对拍"的实验都应先统一停机口径。
2. **`A + B L²` 是相消式**：b 是"两个同量级数之差"再乘 ν/(gL)，曲率误差被 L² 放大。平面通道的
   离散定常解**精确为抛物线**（拟合残差 ~1e-12），所以二次拟合在那里是代数恒等；圆管不是
   （轴对称源有一阶轴层），因此圆管必须换估计量或有意识地扣偏置。
3. **体均值估计量必须用采样二阶矩**：连续式 `L²/3` 与离散算术均值差 O(h²)，实测给 b 带 +0.005 lu
   偏置（ny=33 平面：b_bulk=+0.0027 而非 0）。用 `⟨s²⟩` 采样矩后三种几何都精确到 1e-10。
4. **圆管原始反演仍有 4.8% 误差**（b=0.5，跨几何迁移口径），满足 5% 判据但**不满足 3%**；误差来源
   已定量为加性常数偏置（§3.3），修法是换估计量而不是调参。这一点如实列出（见 §6 误差表）。
5. **k_slip=3 未标定（WITHHELD）**：仓内无离线 DNS 减阻数据集，ΔC_f 的量级是不确定带
   （k=1..6 跨 6 倍），只有"单调性"是模型无关的可靠结论。
6. **账本的代价模型是上界**：开放注气（持续补气 + 对抗吃水静水压）。封闭气腔时代价趋 0，账本上界
   退化为"节能=净收益"；真实区间在这两条边界之间，本节点结论只对开放注气成立。注气通量系数
   无离线锚点，标 WITHHELD，以"关于该系数的一族曲线"给出。
7. **适用范围**：低 Mach（u_max ≤ 0.05）、不可压、单相、纯 BGK、壁面切向静止、无粗糙度叠加、
   Knudsen 层只保留一阶（Maxwell）效应；σ 与 TMAC 的对应关系取 `α = 1−σ`（镜面分数的定义），
   未做气体动理论的平均自由程桥接（无离线标定，标 WITHHELD）。圆管实现仍是**轴对称 1D 列 +
   几何源**（不是 3D 阶梯化圆管），其离散误差（曲率比 <1、u_max 正控 0.4%）已在 §3.4 量化。
8. **上游 1D 模块的 b(σ) 数字**（a、c）在本站被独立复算并**部分修正**：a 一致（0.300），
   c·H 从 −0.139 修正为 −0.0650（口径差异，见 §3.2）。
