## 1. 案例介绍

平面槽道 Poiseuille 流是流体力学线性稳定性理论的教科书基准：无粘中性、仅由粘性（Tollmien–Schlichting 波）失稳，临界 Reynolds 数 `Re_c = 5772.22`（Orszag 1971）。本节点问的不是"连续方程是否失稳"，而是**栅格 Boltzmann 算子本身在多大 Re、多大分辨率下还能定量复现连续谱的增长率**——这是 LBM 用于船体边界层转捩/层流减阻评估的前置能力门槛（若 σ 在 Re=10⁴ 偏差 >15%，LBM 给出的转捩位置不可用）。

几何与参数（全部格点单位，`dx=dt=1`，`cs²=1/3`）：

| 项目 | 定义 | 取值 |
|---|---|---|
| 槽道 | 壁面 y=−1/2 与 y=Ny−1/2（half-way 反弹），半宽 h=Ny/2 | Ny∈{32,64,128,256} |
| 基流 | U(y)=u_max[1−((y−(Ny−1)/2)/h)²]（抛物线，壁面零速） | u_max=0.05（Ma=0.087） |
| Reynolds | Re=u_max·h/ν（中心速度+半宽，Orszag 约定） | Re∈[1000,10000] |
| 粘性 | ν=(τ−1/2)/3 | τ∈[0.50048,0.5048] |
| 波数 | α=α_nd/h，α_nd=πm/k（格点精确可表示，Nx=k·Ny） | α_nd∈{0.524,0.785,1.047,1.571} |
| 扰动 | 单流向 Fourier 模态 exp(iαx)，壁法向/流向速度由 OS 特征函数播种 | A=1e-3…1e-4 |
| 碰撞算子 | BGK / MRT(s_e=1.64,s_ε=1.54,s_q=1.7) / 正则化 BGK(RLBM) | 三种 |

## 2. 怎么做（方法 / 流程 / 工具链）

三层独立实现，互相钉住（audit chain）：

1. **连续基准** `tensorlbm.stability.orr_sommerfeld`：Chebyshev 配点 (v,ω) 形式 Orr-Sommerfeld 特征值问题，`2(N+1)` 阶 QZ 求解；对标 Orszag (1971)。
2. **栅格算子精确线性化** `tensorlbm.stability.channel_shear`：基流沿 x 不变 + 直壁 ⇒ 线性化步在 x 方向按模态解耦，状态降为 `9·Ny` 复矢量；局部 Jacobian 用 `∂f^eq/∂f`（BGK/MRT/RLBM 各自解析矩阵），流采用 `exp(−iαc_ix)` 相位，壁面用 link bounce-back（同节点反射）。特征值直接给出 `σ=ln|λ|`。
3. **非线性时间推进互校**：真实栅格上跑 `grid_channel_step`（与本库 `solver.collide_*` 逐点一致），左特征矢量投影读出模态振幅，拟合指数增长率——与特征值路径只共享 `c_i,w_i` 与碰撞模型定义。

模式识别是关键一步：槽道内近中性**声学模态**的 |λ| 也≈1，若只取"最慢衰减模态"会把声波误当 TS 波（见 §5 陷阱）。本节点用**特征函数重叠度**（栅格壁法向速度 vs OS 特征函数，Lobatto 重心插值）选支路，并要求重叠度 >0.99 才采信。

复核链（pytest，见 §6）：numpy 碰撞 == 库内 torch 碰撞（1e-17/1e-8）；解析算子 == 真实网格步的有限差分 Jacobian（1e-9）；时间推进 == 特征值（<2%）。

## 5. 注意点 / 局限 / 适用范围

1. **声学模态陷阱（本节点最大的坑）**：槽道内 `Re=1000`、`α=π/3` 时，最慢衰减特征值的 σ_h/U_max ≈ −0.013，而真实 TS 支路为 −0.040；直接取"最慢衰减"会把声波/近中性模态当成转捩模态。本模块用特征函数重叠度选支路（回归测试 `test_least_damped_mode_is_acoustic_not_orr_sommerfeld` 固化该反例）。
2. **τ→1/2 的运行限制**：本参数带 τ∈[0.50048,0.5048]，ω=1/τ≈2.0 已在 BGK 线性稳定边界附近。特征值路径不受影响（线性代数），但**非线性时间推进**在高 Re 处容易被声学残响/舍入污染，故时间推进互校只在 Ny≤32、Re≤2000 的低成本窗口做；并需用左特征矢量做模态选择性读出（否则声学支路主导读数）。
3. **无体力项进入扰动方程**：驱动基流的体积力取速度无关形式，故其对扰动 Jacobian 贡献为零——与 Orr-Sommerfeld 问题（扰动无体力）一致。若换用 Guo 全强迫，需把 `∂F_i/∂u` 补进 `local_jacobian`（已完成 FD 自校验框架，可扩展）。
4. **基线为精确抛物线**：half-way 反弹壁面使壁面正好落在 ±1/2，且抛物线在二阶离散 Laplace 下精确，故基流取解析抛物线；由此产生的基流误差为 O(Ma²) 级，未单独做基流不确定度传播（§3.7 的 Ma 敏感性给出量级）。
5. **适用域**：结论覆盖二维线性（时间模态）稳定性；不含三维斜波、非线性二次失稳（Λ 涡）、壁面粗糙度与压力梯度偏离。
6. **非正交模态谱**：非正规性使特征值对扰动敏感（近临界 Re 尤甚），本报告同时给出外推极限与偏差表，不做单点外推结论。
7. **A3 未通过的原因（honest FAIL）**：RLBM(Re=3000, p=0.68, 残差 432%) 在 16/32/64 倍增序列上观测收敛阶远低于 2（RLBM p≈0.68），三水平外推尚未进入渐近区，5% 残差判据不成立。BGK(p≈3.2)/MRT(p≈9.5) 在同序列上残差 2.9%/0.05% 通过。结论：**RLBM 的壁面闭合在本参数带是低阶的**，用 RLBM 做转捩判别需更密的 Ny 或壁面修正。
8. **未完成部分（如实记录）**：Ny=128/256 的加密与外推（含 A3 的 64/128/256 序列）、以及 Re=4500/8000/10000 在 Ny≥64 的扫描，已作为 12 片作业递交集群（cj599，109 任务分片），但递交后 28 分钟内集群队列始终有 250+ 作业在前、未获派发，故本报告的数据面为：Ny∈{16,32,64}、Re∈{1000,3000,6000,8000,10000}（Ny=32 与 Ny=64 两档）；超临界高 Re（8000/10000）仅有 Ny=32 数据，其中 σ_LBM 偏大 4.5–5.2 倍（见 §3.4 表），符合临界层厚度 (αRe)^(-1/3) 在 Ny=32 时不足 1 个格点的预期，但**未取得 Ny≥64 的超临界定量结论**。
