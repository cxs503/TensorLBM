## 1 案例介绍（物理背景 / 几何 / 参数表）

扑翼推进（flapping-foil propulsion）是水下航行器与仿生推进的核心机理：翼型同时做沉浮 `h(t)=h0 sin(ωt)` 与俯仰 `α(t)=α0 sin(ωt+φ)`，前缘吸力产生推力，输入功率来自沉浮/俯仰功。线性理论（Theodorsen 1935 + Garrick 1936）给出闭式解，是本节点的**解析锚**；LBM 侧用 D2Q9 BGK + Guo 力项 + 浸没边界（IBM）直接强迫施力，动量交换积分推力与输入功率。

### 1.1 解析侧参数

| 量 | 定义/取值 |
|---|---|
| 减缩频率 | k = ωc/(2U) = ωb/U |
| Strouhal 数 | St = f·A/U，A = 2h0（沉浮峰峰值） |
| k–St 关系 | St = 2k(h0/c)/π  ⇔  k = πSt/(2h0/c) |
| Theodorsen 函数 | C(k)=F+iG = H1⁽²⁾(k)/[H1⁽²⁾(k)+iH0⁽²⁾(k)] |
| 前缘吸力推力 | S(t)=2πρb|C(k)|²w², w=ḣ+Uα+b(½−a)α̇ |
| Garrick 推力 | T(t)=S(t) − L(t)·α(t)（含法向力倾斜项，缺此项则 η>1 违反能量守恒） |
| 输入功率 | P_in = <L·ḣ> − <M·α̇>（ḣ 向下为正、L 向上为正） |
| 推进效率 | η = C_T/C_P = C_T/(C_T+C_P_loss) |

## 2 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **解析锚**（`src/tensorlbm/flapping_propulsion.py`）：Hankel 闭式 Theodorsen 函数 + 独立 modified-Bessel 代码路径互校；Theodorsen 非定常升力/力矩相量；Garrick 推力（吸力 + 倾斜项）与输入功率的循环平均（相量法，另配 16384 点时域求积互校）；推力反转线（二分）；Roache GCI。
2. **LBM 求解器**（`src/tensorlbm/flapping_lbm_2d.py`）：D2Q9 BGK + Guo(2002) 力项、4 点 Peskin δ 核、多点直接强迫（2 趟）、薄翼（厚度 4%c 的椭圆）拉格朗日标记点；入口平衡态、出口海绵层、上下自由滑移壁；浮点 64 位、单线程、无随机数 ⇒ 位级可复现。
3. **施力与能量记账**：IBM 展布算子是插值算子的伴随 ⇒ 反作用力 `F_body=−ΣF_E` 是离散动量守恒恒等式；输入功率 `P_in=ΣF_marker·v_body`（机体实际做功）。黏性耗散两种估计：连续 `2νS:S` 与离散 `−Π_neq:∇u`（BGK 非平衡动量流），用以检验能量账。
4. **算例调度**：`run_sweep.py` 以 20 进程并行跑全部算例（numpy 单线程，无超订），汇总到 `artifacts_p162n07/results.json`，再判 C1–C8。
5. **工具链**：numpy 2.4 / scipy 1.16（特殊函数）/ matplotlib（图）/ pytest（单元与冒烟测试）。

### 2.1 离散能量账

$$W_{\rm body} = \Delta KE + \Phi_{\rm visc} + F_{\rm boundary}$$

开放域（入口速度边界 + 海绵出口）的 `F_boundary` 含边界压力功；闭合周期域中 `F_boundary≡0`，故只有周期算例是能量记账的干净检验。

## 4 注意点（坑 / 局限 / 适用范围）

1. **小振幅被黏性阻力淹没**：h0/c=0.02、α0=2° 时 Garrick 无黏推力 C_T≈1e−3…6e−3，而同 Re 下薄翼黏性阻力 C_D0≈0.18–0.23（见 3.3）。推力/阻力比 ~1%，任何黏性求解器（含本 LBM）都无法在 5% 相对精度上直接验证该量；该判据的结构性不可达是本节点的**核心诚实结论**，不是实现瑕疵。
2. **倾斜项不可缺**：Garrick 推力 = 前缘吸力 − L·α。若只取吸力，纯俯仰 η 会 >1（实测 2.3–6.4），违反能量守恒；加入倾斜项后纯俯仰在 k→0 时 C_T→0（准稳态无推力），与物理一致。
3. **Theodorsen 的 Bessel 形式**是 `K1(ik)/[K1(ik)+K0(ik)]`（K0 项不带 i），写成 `(k1+i k0)` 会与 Hankel 结果差 0.03–0.7；本模块用 1e−12 互校守住这一点。
4. **能量账在开放域不闭合**：入口速度边界 + 海绵出口不守恒能量，边界压力功比机体功大 1–2 个量级；闭合周期域才是干净检验，而周期域中平均流会随推力/阻力失衡长期漂移（ΔKE 项因此不可忽略）。
5. **两种耗散估计差 τ/(τ−½)**：连续 `2νS:S` 与离散 `−Π_neq:∇u` 相差 τ/(τ−0.5)≈22 倍（τ≈0.524）；对 ½ρu² 账本闭合的是连续估计，离散估计里含储存在非平衡矩里的「数值」部分。
6. **LBM 适用范围**：本求解器为二阶 BGK + 薄翼 IBM，Re≤500、Ma≤0.26、c≤64 格；大振幅（h0/c=0.15、k=2 时 kh0/c=0.3、有效攻角摆幅 ±25°）已超出线性理论适用范围，实测 C_P 为理论值的 1.89 倍（分离与非定常失速），属模型层面的差异而非 bug。
7. **求解器稳定性上限**：`kh0/c` 达到 0.5000 的算例（`thrust_positive`，h0/c=0.25、k=2）出现发散（C_T=NaN），说明本 BGK+单层 IBM 在 kh0/c≳0.5 时失稳；这正是 C5 的 LBM 侧穿越点无法测得的原因（该 Re 下反转需要 h0/c≈0.22 以上的振幅）。

8. **俯仰轴与相位约定**：h 向下为正、L 向上为正、α 抬头为正、pitch 轴 a·b 自弦中点计；φ 为俯仰超前沉浮的角度。约定写死在模块 docstring 与 `build_markers` 中，测试守住符号。

## 6 结论与后续

* **REAL（已建成）**：Theodorsen 函数闭式（双路径互校 1e−16）、Garrick 推力/功率/效率闭式（含倾斜项，相量与时域求积一致到 1e−15）、k→0 准稳态极限（0.32%）、推力反转线、Roache GCI、以及一个位级可复现的 D2Q9+IBM 求解器与能量账框架。
* **FAIL（诚实）**：C1/C2/C4/C5/C6 的 LBM 侧量化判据未达；根因是探测点选在推力比阻力小两个量级的参数区，以及开放域边界不守恒能量。
* **下一步可执行改进**（不改判据也能推进）：①把 C1 探测点移到推力主导区（h0/c≥0.1，k≥1），并把「基准阻力」改为同一振荡状态下的相位平均黏性基线；②C4 改用闭合周期域 + 恒定驱动力的「泵功」公式消除 ΔKE 漂移；③C6 用 Richardson 外推值做基准而非闭式理论值，避免理论-离散误差混淆；④引入多重直接强迫 + 更厚翼型（t/c=0.12）以压低 C_D0 并在 Re≥2000 复测。
