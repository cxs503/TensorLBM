# P106W2-N02 · TensorLBM 滑移壁标定：Maxwell 条件的算子级审计、格子标度滑移与减阻律括号

**节点** P106W2-N02（战役 P106W2，物理域 resistance-green）  **上游** P106W1-N04 / IN67-N04（混合反弹壁、b(sigma) 标定律、圆管反演）  **仓库** TensorLBM  **分支** agent/m8319

> 与上游的关系：上游已交付 b(sigma) 标定律、平面/圆管反演与减阻律。本节点**不重跑**这些已验证结论，而是攻上游局限清单里自认的三条未测问题：(i) 混合壁是否真的实现 Maxwell条件（上游只给了代数恒等）；(ii) b 是否是壁面属性；(iii) 固定物理滑移长度时怎么改格子。

## 1 案例介绍（物理背景 / 几何 / 参数）

壁面滑移在连续介质层面由 **Maxwell 一阶滑移条件** 描述：

    u_t|_w = b (du_t/dn)|_w

LBM 里最廉价的可连续调节实现是**混合反弹/镜面壁**（mixed bounce-back / specular，
fractional BB）：

    f_q(wall) = (1 - sigma) f_opp(q)(wall) + sigma f_M(q)(wall)

``sigma = 0`` 是半程反弹（无滑移，壁面在半格处），``sigma = 1`` 是纯镜面（切向动量零
交换，滑移长度发散）。**上游节点 P106W1-N04 已把 b(sigma) 标定律、平面/圆管反演与减阻律
做到可用**；本节点按"禁止重复已验证案例"纪律不去重跑那些结论，而是攻上游在**局限清单**
里自己写下的三条未测问题：

1. 上游对"混合壁实现 Maxwell 条件"的论证是**代数恒等**（把反演式写成 Maxwell 条件的
   离散形式），不是测量：算子隐含的壁面速度从未被单独测过；
2. b 到底是不是**壁面属性**（与驱动力、与对壁、与几何无关）从未被检验；
3. 上游报告了 ``b(sigma)`` 在格子单位下的分辨率依赖，但没有回答工程上真正的问题：
   **要在一个给定物理滑移长度下加密网格，该怎么改 sigma？**

本节点把这三条都变成可测的数字。

| item | value | note |
|---|---|---|
| lattice | D3Q19 (full 3D operator) / D2Q9 1D column | tensorlbm canonical tables |
| relaxation | BGK, tau = 0.8 | nu = (tau-1/2)/3 = 0.1 |
| body force | Guo, g = 1.0e-5 (sweep 1e-5..5e-5) | drives plane Poiseuille |
| plane resolutions | ny in {17,25,33,49,65} | H_lu = (ny-2)/2 |

| git rev | b24dd454 | worktree HEAD at study time |

* **平面通道**：两块混合壁夹持的平面 Poiseuille，解析解
  ``u(y) = g/(2 nu)(H^2 - s^2) + g H b/nu``；壁面平面 ``y = 0.5`` 与 ``y = ny-1.5``，
  ``H = (ny-2)/2``。
* **圆管**：轴对称滑移 Hagen-Poiseuille，``u(r) = g/(4 nu)(R^2 - r^2) + g R b/(2 nu)``，
  ``R = nr-1.5``（轴对称 1D 列 + 几何源，与上游同一离散化，便于逐位对账）。
* **Couette（新）**：同一 D3Q19 平面求解器加上移动壁动量注入
  ``6 w_q rho (c_q . u_wall)``，用来**独立标定壁面速度的动量簿记**（见 §2a）。

## 2 怎么做的（方法 / 流程 / 关键设置 / 工具链）

### 2a 算子侧：从壁面规则的动量簿记直接读出壁面速度（新）

混合规则相对纯反弹多出的切向动量通量为

    ΔM_x = sigma * sum_{q in inward} c_xq [ f_M(q) - f_opp(q) ]

（``inward`` = 反射后射回流体的方向）。半程反弹的**移动壁**动量注入是标准的
``6 w_q rho (c_q . u_wall)``，其切向和为

    sum_{q in inward} 6 w_q c_xq^2 rho u_w = rho u_w / 3      (D2Q9 与 D3Q19 同为 sum w_q c_xq^2 = 1/18)

因此算子隐含的壁面速度是 **``u_w = 3 ΔM_x / rho``**（加任何外部给定的壁速）。
`:func:`wall_velocity_from_rule`` 就是这个式子。它的正确性用**独立实验**钉住：
``sigma = 0`` 的移动壁 Couette，其中壁速是输入量——回读 ``u_w = ±0.02`` 与输入**逐位相同**
（断言 atol = 1e-12），且 σ=0 的 Couette 剖面与解析线性解之差 < 1e-9
（`tests/test_slip_wall_calibration.py::test_moving_wall_couette_reproduces_analytic_linear_profile`
与 `::test_rule_recovers_imposed_moving_wall_velocity`）。

### 2b 流场侧：近壁速度梯度外推（不假设剖面形状）

用**首 3 层流体节点**的一侧二次外推把速度和梯度推到壁面平面
（`:func:`one_sided_wall_fit``，只用近壁数据，不含全局抛物线拟合假设）。实测该外推梯度与
解析梯度 ``gH/nu`` 的相对差在全部 sigma 上最大
**0.000%**，即外推本身是精确的。

### 2c Maxwell 审计（两条互不共享拟合的路线相除）

* 路线 A（算子）：``b_rule = u_w / (du/dn)_w``，``u_w`` 来自 §2a，梯度来自 §2b；
* 路线 B（剖面）：上游的二次拟合反演 ``b = (A + B L^2) nu/(g L)``。

两者的差不是噪声而是一个**常数**：``b_fit - b_rule = c``，``c = -0.065/H``
（σ=0.5、ny=33 时 ``b_rule = 0.3``，
``b_fit = 0.295806547``）。这说明**路线 A 没有振幅偏置**，
路线 B 的偏置来自离散剖面本身（二阶 BGK 误差 ∝ 1/H），与滑移机理无关——上游把它记成
"σ=0 时 b 不严格为 0" 的现象，本站把它**定量归因并分离**。

### 2d 网格依赖与重标定配方（三臂）

把通道**物理**半高固定为 ``H_phys = 1``，于是格子步长 ``dx = 1/H_lu``、给定物理滑移长度
``b_phys = beta H_phys`` 对应 ``b_lu = beta H_lu``。三臂：

* ``fixed_sigma``：所有网格用**同一个** sigma（取最细网格的正确值）；
* ``ideal_retune``：每套网格按理想律 ``b_lu = a sigma/(1-sigma)`` 反解 sigma；
* ``measured_retune``：每套网格按**实测** b(sigma) 用割线迭代反解 sigma。

### 2e 圆管反演误差的分辨率收敛

对每个 b_target 取算子律给出的 sigma，在 5 个半径上跑圆管，比较三种估计量
（二次拟合 / 模型估计 / 体均值），并对 ``1/R`` 线性外推到 ``R -> inf``；同时做
``sigma = 0`` 的负控（反演 b 应为 0）。

### 2f 减阻律：两条模型路线 + 显式 WITHHELD

* 路线 A（无参数）：虚拟壁面平均剖面模型 ``u+(y+) = u+_smooth(y+ + b+)``；
* 路线 B（标定族）：FIK 层流类比 ``Cf/Cf0 = (1 + k b+/delta+)^-2``，``k`` 在仓内**无离线锚点**。

两条路线都给出单调性（模型无关结论），幅值以 ``k in [1,6]`` 与 ``Re_L in [1e6,1e8]`` 的
括号给出，文献锚点显式 **WITHHELD**。

**工具链**：纯 numpy 定常 LBM（无外部求解器）；7 个作业
（maxwell / law / plane_negctl / pipe / freeslip / resolution / locality / drag）由
`artifacts/P106W2-N02/run_study.py --job <name>` 独立落盘 `data/<name>.json`，`--merge`
汇总 `results.json`；图由 `figures.py`、本文由 `emit_report.py` 从 `results.json` 注入。

三条可读结论：

1. **``b_rule`` 与 ``0.3 sigma/(1-sigma)`` 逐位相同**（最大相对差
   6.93e-10），即混合壁的滑移长度**有一条零偏置的
   测量通道**；这条通道是 Maxwell 条件本身（``u_w = b (du/dn)_w``），不是曲线拟合。
2. **``b_fit - b_rule`` 是常数**（σ 变化 0→0.9 时
   -0.00419375
   … -0.00419343），
   数值恰好等于 ``-0.065/H``（H=15.5）。这就是上游法律里的截距 c，本站把它归因为
   **离散剖面的振幅偏差**（与滑移机理无关）。
3. ``u_w/u_1`` 随 sigma 单调上升并在 sigma→1 趋于 1（
   0.84699 at sigma=0.9），
   即"壁面速度 = 首层流体速度 × 系数 kappa(sigma)"的朴素簿记（kappa=sigma）**不成立**；
   正确的量是本节给出的动量簿记 u_w。

## 5 注意点（踩坑 / 局限 / 适用范围）

1. **"算子壁速"需要碰撞后分布**：`:func:`wall_velocity_from_rule` 读的是壁相邻层
   *碰撞后* 的分布（这正是壁面规则吃到的东西）。若上游把该层覆盖写掉再导出，测量就失效——
   本模块的求解器把该层单独保存（`PlaneChannel.f_low/f_high`），这是一个实现约束，
   不是物理假设。
2. **体均值估计量在圆管里不能直接用算术平均**：`:func:`bulk_mean_slip_length` 的
   解析式用的是**面积加权**平均（∝ r），若传径向等距算术平均会得到 +200%~800% 的
   荒谬 b（本节点实测）。必须显式传 ``u_mean = sum(r u)/sum(r)``。这是本次踩到的真实坑，
   已在 `run_study.py` 里显式构造并写进 §3.4。
3. **圆管二次拟合偏置不是严格 1/R**：``b_quadratic`` 在 5 个半径上对 1/R 的线性拟合
   R² = 0.986371，外推截距 0.00421726，说明它含 O(1/R²) 成分；因此本节点用**模型估计量**
   （曲率取解析值）作为主口径，二次拟合只用于展示"误差随网格单调下降"。
4. **振幅偏差 c = -0.065/H 不是 bug**：它是 BGK 二阶误差在 *剖面* 上的体现。任何
   从剖面反演 b 的估计量都带它；只有动量簿记路线不带。因此**"σ=0 时 b 严格为 0"这条
   负控只在算子路线成立**，用拟合路线判会看到 0.4%~0.9% 的假偏置（b~0.5 时）。
5. **纯镜面 sigma = 1 是奇异点**：没有切向应力交换，定常 Poiseuille 不存在（塞流 + 动量
   持续增长）。sigma <= 0.99 的全部算例在 78k 步内收敛；**sigma = 0.999 在 120k 步内
   未达 1e-10 残差判据**（逐算例 steps/residual 见 §3.5 表）——这是物理（耗散趋零、
   时间推进变慢）而非数值故障，且同一算例的算子路线仍给出与定律相符的 b（相对差 1.3e-5）。
   若要用剖面拟合路线做 b→inf 的定标，必须显式报告收敛状态。
6. **曲线/阶梯壁未做（明确未完成项）**：阶梯圆管上的镜面反射**非局部**（镜像方向可能
   落在另一个流体格点上），会破坏动量簿记的一致性；正确做法是插值反弹（Bouzidi）或
   曲线壁镜面反射。本节点的圆管仍是**轴对称 1D 列 + 几何源**（与上游相同离散化），
   真正的 3D 阶梯圆管留作后续节点，改法已在上面写清。
7. **减阻律幅值 WITHHELD**：仓内无离线 DNS/literature dCf(b+) 数据，k_slip 未标定。
   本节点只认证**单调性**（模型无关）并给出 k in [1,6]、Re_L in [1e6,1e8] 的括号；
   任何把括号里的某个数当"减阻率"引用的行为都是越权。
8. **适用范围**：低 Mach（u_max ≤ 0.05）、不可压、单相、纯 BGK、壁面切向静止（Couette
   仅用于标定动量簿记）、sigma 与 TMAC 的对应取 alpha = 1 - sigma（未做气体动理论桥接，
   WITHHELD，与上游一致）。

## 6 误差判定（关键量 vs 基准，逐项）

| 判据/量 | 关键量 | 基准 | 误差 | <3%? |
|---|---|---|---|---|
| [平面] b 反演误差 (算子路线) | b_rule | 0.3 sigma/(1-sigma) | 0.000000% | 是 |
| [平面] b 反演误差 (剖面拟合, 全 sigma) | b_fit | 0.3 sigma/(1-sigma) | 12.580% | 否 |
| [平面] b 反演误差 (剖面拟合, sigma>=0.4 即 b>=0.2) | b_fit | 0.3 sigma/(1-sigma) | 2.097% | 是 |
| [圆管] b 反演误差 (模型估计, nr>=33) | b_model | b_target | 1.25% | 是 |
| [圆管] b 反演误差 (二次拟合, nr>=33) | b_quadratic | b_target | 3.92% | 否(满足 5% 判据) |
| [标定律] R² (算子路线, 最小) | R² | 1 | 0 | 是 |
| [标定律] R² (剖面拟合, 最小) | R² | 1 | 2.22e-16 | 是 |

| [极限] 1/b vs (1-sigma)/sigma 斜率 (算子路线) | 3.33333359 | 3.33333 | 0.000% | 是 |
| [极限] 1/b vs (1-sigma)/sigma 线性度 R² (算子路线) | 1 | 1 | 1.24e-14 | 是 |
| [网格] 重标定后 b_phys 误差 (最大) | b_phys/H | 0.1 | 0.0002% | 是 |
| [局部性] b 随驱动力变化 (最大) | b | const | 1.24e-13 | 是 |

| [减阻] dCf 幅值 vs 文献 | dCf(b+=20) | DNS 10-20% | 未对照 | WITHHELD |

**是否 <3%？** 逐项回答：

* 平面 b 反演：**是**。算子路线相对设定值的误差 0.000000%（机器精度量级）。
  剖面拟合路线**在 b 很小时不行**：全 sigma 最差 12.580%（σ=0.1，
  b=0.033；此时常数振幅偏差 0.0042 本身就占 12%），σ>=0.25（b>=0.1）时最差 4.19%，
  只有 σ>=0.4（b>=0.2）才 <3%（实测 2.097%）。
  **因此"b 反演 ≤2%"这条判据本节点只用算子路线认证，并建议 b<0.2 时不要用剖面拟合路线**
  ——这是本次得到的具体工程结论，不是粉饰。
* 圆管 b 反演：模型估计量 nr>=33 时最大 1.25%，**是**；二次拟合最大
  3.92%，**否但满足 5% 判据**，且误差随半径单调下降（§3.4），来源已定量。
* 标定律：两条路线 R² 均 >= 0.999（1-R² 见 §3.2 表），单调性由**原始数据**单独核验
  （`monotone` 列），**是**。
* 负控：sigma=0 剖面偏差 0.024%、算子 b 精确 0，**是**。
* 自由滑移极限：1/b 线性律斜率相对误差 0.000%，**是**；
  sigma=1 本身是奇异情形，按"记录极限"处理（未崩溃）。
* 减阻律：**单调性 <3% 无意义**（这是定性/序关系判据，已通过）；**幅值 vs 文献 = WITHHELD**
  （无离线数据，k 未标定），不做粉饰。
