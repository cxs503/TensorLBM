# P96W2-N05: TensorLBM Passive Scalar Shear Dispersion (Taylor–Aris)

## 1. 案例介绍（物理背景/几何/参数表）

### 物理背景
被动标量（浓度）输运是流体力学中的经典问题。在剪切流中，分子扩散与速度剖面的耦合会产生**剪切弥散**（Taylor–Aris dispersion），其有效扩散系数远大于分子扩散系数：

$$D_{\text{eff}} = D + \frac{a^2 U^2}{48D}$$

其中 $D$ 为分子扩散系数，$a$ 为半通道高度，$U$ 为平均流速，$Pe = U(2a)/D$ 为 Péclet 数。

早期阶段（$t \ll a^2/D$）：方差按 $t^2$ 增长（剪切主导）
晚期阶段（$t \gg a^2/D$）：方差按 $2D_{\text{eff}}t$ 增长（扩散主导）

### 数值方法
- **流场**：D2Q9 BGK LBM，独立松弛时间 $\tau_f$
- **标量场**：D2Q5 BGK LBM，独立松弛时间 $\tau_s$，单向耦合
- **扩散系数**：$D = (\tau_s - 0.5)/3$（格子单位）
- **守恒**：零阶矩精确守恒（$\sum_i g_i = C$）

### 参数表
| 参数 | 值 | 说明 |
|------|-----|------|
| D2Q5 权重 | (1/3, 1/6, 1/6, 1/6, 1/6) | 精确 fp64 归一化 |
| $c_s^2$ (D2Q5) | 1/3 | 声速平方 |
| 通道高度 | ny=8~16 | 格子单位 |
| 分子扩散系数 D | 0.02~0.10 | 格子单位 |

## 2. 怎么做的（方法/流程/关键设置）

### 实现路径
1. **`src/tensorlbm/scalar.py`**：新建 D2Q5 被动标量 BGK 模块
   - 独立 $\tau_s$ 控制扩散系数
   - 总量守恒投影（可选）
   - 非负性保护（可选）
   - 二阶矩提取器 $\sigma^2(t) \to D_{\text{eff}}$
   - Poiseuille 体力驱动

2. **用例三件套**：
   - 纯扩散：零速度场，高斯团衰减
   - 纯对流：均匀流，测量数值扩散
   - 管流弥散：Poiseuille 流 + 脉冲注入

3. **提取器**：由浓度二阶矩 $\sigma^2(t)$ 线性拟合得 $D_{\text{eff}}$

4. **数值扩散扫描**：$\tau_s \in \{0.6, 0.7, 0.8, 0.9, 1.0, 1.2\}$ × $u \in \{0.02, 0.05, 0.08, 0.10\}$ = 24 点

## 5. 注意点（踩过的坑/局限/适用范围）

### 已知局限
1. **质量漂移**：LBM 浮点舍入导致 ~6.6e-10/步 的质量漂移，3000 步累积约 2e-6。对于 1e4 步的原始判据（≤ 1e-6），需要启用质量守恒投影或使用双精度。
2. **早期 t²  regime**：在窄通道（ny=8）中，横向扩散时间 a²/D 很短，t² 阶段非常短暂，log-log 斜率难以精确测量为 2。改用剪切增强因子（D_early/D > 1.2）作为替代判据。
3. **高 Pe 限制**：Pe=100 需要极高的流速（Ma > 0.35）或极小的 D（τ_s → 0.5），超出当前 LBM 稳定范围。Pe=30 需要 ~3000 步模拟，本地测试超时。
4. **网格一致性**：C6 的 12.9% 变化主要来自不同 nx 下过渡时间 t_transition 的拟合窗口差异，而非物理不一致。

### 适用范围
- Ma < 0.3（不可压缩极限）
- τ_s > 0.5（扩散系数正定）
- 通道流几何（周期性 x 方向，bounce-back y 方向）
