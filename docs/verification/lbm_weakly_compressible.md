# 弱可压缩 LBM 验证面：Ma→0 渐近一致性、绕圆柱 Strouhal 与声学滤波（P102W3-N05）

> 本页由 `scripts/plot_lbm_weakly_compressible.py` 从 `benchmarks/verified/lbm_weakly_compressible/{result,gates}.json` 自动生成，文中所有数字均为程序化注入（零手抄）。

## 1. 案例介绍（物理背景 / 几何 / 参数）

LBM 用 `p = c_s^2 rho`（`c_s^2 = 1/3`）代替不可压压力泊松方程，因此它求解的是**弱可压缩** Navier–Stokes 极限：所有结果相对不可压解都存在 `O(Ma^2)` 误差，`Ma = u_ref/c_s -> 0` 时才收敛到不可压解。本节点把「误差律本身」做成机器可裁的验证面，而不是再测一个单马赫数算例。

| 算例 | 几何 | 参数 | 用途 |
|---|---|---|---|
| 压力驱动槽道 | ny=33, nx=96，半程反弹壁，发展型速度入口 + 压力出口 | nu = 0.05 固定，tau = 0.65，Ma ∈ [0.01, 0.05, 0.1, 0.2, 0.3] | C1/C3/C6 |
| 体力驱动槽道（周期） | ny=33, nx=32，流向周期，Guo 体力 | 同一 nu，Ma 同上 | C1 阴性对照 |
| Re=100 圆柱 | D=8, 168×65，阻塞比 0.125，闭合 extrap + reg | Ma ∈ [0.01, 0.1, 0.2, 0.3]，nu 随 Ma 变化 | C2/C5/C7 |

> 圆柱 Ma = [0.05] 未产出记录（低 Ma 角落 tau→1/2 导致发散，见 §5），按 honest 原则不补造、不替代。
| 声学激励槽道 | ny=33, nx=96 | Ma = 0.01，密度脉冲幅值 0.001 | C4/C8 |

## 2. 方法（怎么做的）

* 求解器：`src/tensorlbm/weak_compressibility.py` 的 float64 NumPy D2Q9（BGK/TRT、Guo 体力、半程反弹、Zou–He 入口/出口与零梯度外推闭合）。
* 扫描与后处理：`src/tensorlbm/verification/weakly_compressible.py`（压力泊松参考解、差分 Ma 标度诊断、水动力系数 Mach 无关性、Ma_max 适用域门、产物写出）。
* **关键实验设计**：固定 `nu`（因此 `tau` 与离散误差底噪固定）后改变 `Ma`，用「相对最低 Ma 的差分剖面误差」`||u(Ma)-u(Ma_ref)||_inf/u_max` 作为 C1 判据量 —— 绝对误差在 H=32 下被约 7% 的壁面滑移/离散底噪支配（实测 Ma=0.01 绝对误差 0.0709），差分把它精确消去。
* 阴性对照：体力驱动周期槽道稳态密度严格均匀，三阶平衡态项恒为零，按构造**不可能**出现 `O(Ma^2)` 剖面信号；它用来证明 C1 诊断测的是可压缩性而不是任意数值伪迹。
* 压力场判据（C6）：在与 LBM 相同的网格上解不可压压力泊松问题`lap(p)=0`、入口/出口 Dirichlet、壁面 `dp/dy=0`（SOR，收敛残差 < 1e-10），入口压力由**动量平衡** `p_in = p_out + rho_0 a L` 给出（不是用测得的入口压力，否则 R² 恒为 1）。

## 6. 注意点 / 局限

* **低 Ma 角落的刚度（本节点最硬的限制）**：固定 Re 与直径时 `nu = Ma c_s D / Re`，故 `tau = 0.5 + 3 Ma c_s D / Re`；本算例 `Ma=0.01` 给出 `tau = 0.5014`。实测三种组合：Zou–He + BGK 与 Zou–He + 正则化 都在 ~800–1500 步内发散；零梯度外推 + 正则化 能活下来（本次 11085 步无发散），但 8 个对流时间内**涡脱落完全没发展起来**（C_L 幅值 0.014 vs 饱和值 ~0.3），由噪声过零估出的 St 是 9.86 这种无意义值。要在这个 Ma 拿到 `tau >= 0.55`，直径需 `D ~ nu Re/(Ma c_s) ~ 290` 直径（≈ 10^5 格），远超本单算力。因此 C2 的字面测点（Ma=0.01）标 `NOT_MEASURABLE`，不用任何代理替代。
* **圆柱仪器未通过验证（C0）**：同一驱动给出 `C_D = 2.12–5.24`，比 Braza 1986 的 1.35 高 57%–78%；`C_L` 幅值只有 0.014–0.103（Re=100 应 >=0.3，说明升力远未饱和），`Ma=0.1` 还给出 St=0.45 的离群值。**根因未查明**（候选：零梯度外推入口的有效动压偏低、动量交换力归一化口径、D=8 分辨率不足以解析边界层）。结论：该配置不能用于「水动力系数随 Ma 变化」级别的判据，C2/C5/C7 因此标 `NOT_SUPPORTED`，而不是给一个好看的相对差。正确路线是复用本仓已验证的 `benchmarks/verified/cylinder/re100` 引擎（far-field BC + 下游 sponge + MRT，Cd=1.329 / St=0.166），它在本机（无 GPU、128 核满载）跑 6 万步需数小时，超出本单预算。
* **绝对剖面误差不可用于 C1**：H=32 下离散底噪 ~7%，比 `O(Ma^2)` 项大 1–2 个量级；必须用固定 nu 的差分诊断（阴性对照相差 10^5 倍，证明差分诊断测的确实是压力梯度带来的可压缩性效应）。
* **实测标度不是纯二次**：差分误差的局部斜率随 Ma 单调上升 ([1.3, 1.54, 2.15])，全域拟合 1.56，只有最高一对 Ma（0.2 -> 0.3）达到 2.15。也就是说 `O(Ma^2)` 渐近区在 0.01–0.3 区间内**没有**被观测到，低 Ma 端存在低一阶的混入项 —— 这是本单的负面物理结论（来源未查明，候选：固定 nu 下压力水平 ∝ Ma，可压缩性修正与压力水平耦合）。
* **C4 字面判据不可达**：压力驱动槽道里存在 `O(Ma)` 的稳态水动力压力场（物理量，幅值远大于 1e-5），任何只压声学带的滤波都不能把它压到 1e-5；因此 C4 的低马赫预处理读法标 `NOT_SUPPORTED`（C8 诚实门），并单独报告后处理滤波的实测抑制倍数（滤波引起的剖面改变量 3.05e-05，不污染物理场）。
* **C6 的泊松解在充分发展槽道里是线性的**：该算例检验的是「LBM 压力场是否满足不可压动量平衡」，不是二维复杂压力场重构（后者需要投影法求解器，本仓不存在）；R² 只在 Ma <= 0.1 成立（[0.99853, 0.99777, 0.99575]），Ma >= 0.2 掉到 [0.98547, 0.96057]。

## 7. 误差判定（vs 基准）

| 关键量 | 基准 | 误差 | 是否 < 3% |
|---|---|---|---|
| C1 标度指数 | 理论 2.0（`O(Ma^2)`） | 实测 1.56（偏差 22%） | 否 |
| St（Re=100） | Braza 1986: 0.164–0.165 | 实测 0.18–9.86（最差 5891%） | 否 |
| C_D（Re=100） | Braza 1986: 1.35±0.05 | 实测 2.12–5.24（最差 288%） | 否 |
| 压力场（C6） | 不可压压力泊松解 | R² 最低 0.96057；偏差阶 1.45（目标 2） | 否 |
| 声学滤波（C4） | δρ/ρ₀ <= 1e-5 | 滤波后 1.28e-06（抑制 32.9 倍） | 是 |

> 结论：C1/C3/C6 的**假设（纯 `O(Ma^2)`）在本区间内被证伪**；C2/C5/C7 因仪器未验证而不可判定；C4 只在后处理读法下成立。所有结论都是 honest —— 没有一个 FAIL 被改写为 PASS。
