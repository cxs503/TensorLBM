## 1. 案例介绍（物理/几何/参数）

两相不可压 Newtonian 分层 Poiseuille 流：2D 通道（x 周期，nx=4），下相（重，ν₁=1/6）
上相（轻，ν₂=1/12），单位质量体力 G_x=5e-5 驱动，壁 no-slip（bounce-back），
界面速度+剪应力连续。解析解=每相抛物线（u_i''=-G/ν_i），界面位置由体积守恒定（h=φ₁H）。

| 参数 | 值 |
|---|---|
| τ₁, τ₂ | 1.0, 0.75（ν₁=1/6, ν₂=1/12, M=2） |
| G₁₂ | -1.0（mixture 平衡态稳定工作点） |
| G_x | 5e-5 |
| 分辨率 | Ny25（ny=25, half=12, 15000 步）/ Ny33（ny=33, half=16, 20000 步） |
| 初始化 | tanh-3 界面 @ half，ρ_heavy=0.7/ρ_light=0.3 全交换 |

## 2. 怎么做的（方法/流程/工具链）

1. **先独立推导**解析解（`artifacts/qr_pilot_a/derivation.md`）：2×2 界面条件系统，
   单相/等黏度极限自检通过（`qr_analytical.py` selftest OK）。
2. **独立重跑** A 臂同参数同调用序（`qr_recompute.py`，本席重写时间循环），
   另跑 A 臂原函数交叉验证（剖面 maxdiff 见 recompute_results.json）。
3. **壁面偏移收敛研究**（`wall_check.py`）：单相 Poiseuille 同壁面方案，
   ny=25/33/49，40000 步，比较 u_max 与 H=ny-1 / H=ny-2 解析值。
4. **稳态核查**（`qr_steady.py`）：Ny25 长跑 40000 步，跟踪 u_max/spurious/界面位置。
5. **判据复算**（`qr_conventions.py`/`qr_final.py`）：全部从 2D 场自算，零手抄。

误搬到 SC-MCMP（force-shift）路径。

## 5. 注意点（坑/局限/适用范围）

1. **壁面约定依赖力格式**：force-shift（SC-MCMP）→ H=ny-1；Guo 力（CG 基准）→ H=ny-2。
   跨模型搬约定=系统性偏差。本结论仅对 SC-MCMP force-shift 路径成立。
2. **两分辨率非同物理问题**：H=24 vs 32，④ 的"收敛趋势"被通道高度混淆，
   不是干净的收敛检验。
3. **nx=4 过窄**：x 向仅 4 格，spurious current 的 x 向统计意义弱。
4. **diffuse 界面**（~3-5 格）：界面区误差大，bulk 区才可比。
5. 本席未做：Ny33 长跑稳态核查（仅 Ny25）、u_eq="self" 对照臂。

## 7. 裁决

- **① PASS**（4.06%/3.96%，开发方目标正确，稳态值经长跑确认）。
- **② FAIL**（正确参考下 20.2%/16.8%）——开发方 PASS 是**错误壁面约定**的产物，
  非 honest-FAIL，属**方法性错误**（把 CG 基准的 H=ny-2 约定误用于 SC-MCMP 路径）。
- **③ FAIL**（0.324/0.172）——开发方 honest-FAIL，根因分析（SC 力非精确离散梯度
  → 界面 spurious 动量）**扎实**，与文献一致。
- **④ 不构成有效收敛证明**（两档物理通道高度不同）。

**对开发方"与历史记录对比"段的核查**：开发方称 W4-B 用"未修正"H=ny-1 引入
~15% 系统误差——**不成立**：(a) H=ny-1 恰是本路径正确约定；(b) W4-B 的 26.82%/33.17%
是 u_eq="self"+G₁₂=-2.5 的**真实模型误差**（W5-A T4 已证 self 保留 O(u_max) 组分滑移），
非参考解错误。

**总判定：A 臂 1/3 主判据 PASS（①），②③ FAIL。② 的 FAIL 由 QR 独立发现，
开发方未识别（其 PASS 基于错误参考解）。honest-FAIL 纪律：③ 的 honest-FAIL 保留；
② 由 QR 改判 FAIL（证据：wall_convergence.json + final_reference.json）。**
