# P248-N02 体素化 LBM 浸没表面亚体素测度：湿面积/排水体积的二阶收敛

**仓**: TensorLBM · **节点**: P248-N02 · **模块**: `src/tensorlbm/subvoxel_measure.py` · **战役脚本**: `scripts/subvoxel_measure_campaign.py`

**运行时间**: 527.3 s（单机 CPU，numpy float64，quick=False）

## 1. 案例介绍（物理背景 / 几何 / 参数表）

体素化 LBM 把船体 CAD 变成 `(nz, ny, nx)` 的布尔掩码/符号距离场。历史上平台用 `tensorlbm.hydrodynamics.voxel_wetted_area` 统计固/流**面片计数**乘以 `dx²` 作为湿面积。该估计的收敛阶是 `O(h)`，且对与网格对齐的表面最差：数字化圆截面的曼哈顿周长为 `8R`，而真周长 `2πR`，即恒定 **+27%** 系统性偏差。湿面积进入摩擦阻力 `C_F`、形状因子与自航预报，任何湍流模型都无法修正 5–30% 的几何误差。

本节点把面片计数换为**亚体素测度**：每个被切割的体素内，界面用（未截断的）符号距离场重建为一张平面，平面与立方体的交面积与固体体积分数**精确**计算（多边形裁剪，非采样）。对平面界面精确，对光滑曲面即为二阶 `O(h²)`。

## 2. 怎么做的（方法 / 流程 / 关键设置）

**(1) 精确平面-立方体测度**（`plane_cube_measure`）：把界面平面与单位立方体求交——12 条棱的穿越点按平面内极角排序得到切割多边形（面积/形心），6 个立方体面用 Sutherland–Hodgman 半空间裁剪后再用散度定理 `V = ⅓ Σ_f A_f (c_f·n_f)` 求固体体积分数。两者都是精确的（无采样、无迭代），因此单位球面/立方体面的退化情形也逐位精确。

**(2) 各向异性单元**（`plane_box_measure`）：把 `(hx,hy,hz)` 长方体仿射映回单位立方体，法向变为 `h⊙n/|h⊙n|`，面积按 `|J|·A_ref/|Jᵀn| = hx·hy·hz·A_ref/|h⊙n|` 缩放。这一条正是「切线垂直区」的解析依据：`|n_z| → 0` 时面积对 `h_z` 的敏感度为零，故 z 向不必加密（第 5 节给实测）。

**(3) 单元选面用 8 个角点**（`band_measure_nodal`）：单元含界面 ⇔ 8 个角点值不全同号；对这些单元用 8 角点最小二乘拟合平面（立方体设计矩阵正交，闭式：`b_i = Σsign·v /(4h_i)`，`d = mean(v)/|b|`）。**这是本节点第二个关键修正**：原先用 `φ/|∇φ|` 估计中心到界面的距离（`band_measure`），当 `|∇φ|` 在一个单元内变化一个量级时（KCS 龙骨层 `|∇φ|` 从 1 跳到 ~60）该估计把距离高报约 2 倍，导致近水平「平板龙骨」层的一半单元被漏掉，面积少算 15%。角点拟合见到真实变化，不受影响。

**(4) 二阶曲率修正项**（`curvature_correction`）：`A_patch *= 1 + h²/24·(κ₁²+κ₂²)`，其中 `κ₁²+κ₂² = ‖Hess φ‖²_F − (n·Hess φ·n)²` 是切向 Hessian 的平方 Frobenius 范数（Monge 面片 `z = κ₁x²/2 + κ₂y²/2` 的面积元在单元上平均即得）。

**(5) 收敛研究协议**：格心相对几何做确定性亚格偏移 `jitter = [0.3141, 0.0713, 0.1937]`，避免用格点对称巧合冒充收敛；对开边界几何（圆柱侧面、船体水线、艇体首尾）该方向 jitter 取 0 并令 `L/h` 为整数，使切割面片**恰好铺满**被测量的曲面（否则端面/水线会有 O(h) 的额外/缺失条带）。log-log 最小二乘拟合 `log e = log C + p log h`。

**(6) 工具链**：numpy float64 + matplotlib；参考值全部由本脚本内的独立求积生成（闭式解 / 参数化三角求积 / 圆台求和），不含任何手抄数字；`pytest tests/test_subvoxel_measure.py` 用Gauss–Legendre 分段精确积分做核函数的独立对照。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **等级集必须是（近）距离函数**：`band_measure`（`φ/|∇φ|` 路线）在 `|∇φ|` 单元内变化一个量级时高报距离 2 倍，KCS 龙骨层因此少算 15% 面积；解法是改用 8 角点拟合（`band_measure_nodal`），或先把等级集归一化。两者都已入库，报告的数据一律用角点路线。

2. **开边界几何必须让面片恰好铺满曲面**：圆柱侧面/船体水线/艇体端面所在方向不能留 pad 也不能有 jitter，且 `长度/h` 取整；否则端部会多算/少算一条 O(h) 的带（首次实现里 KCS 因此差 110 倍）。

3. **掩码路线≠SDF 路线**：`mask_to_levelset` 从布尔掩码反建 SDF（EDT 半格修正 + ~1 格高斯平滑），球面 R/h=32 处面积误差约 1.7%，而采样 SDF 路线 1e-4。结论：亚体素湿面积要求几何管线**把 SDF 传下来**，掩码只能做遗留兼容。

4. **台阶法对「箱形」船体并不差**：KCS 参数船的壁面近乎垂直+平板底，曼哈顿面积≈真面积，所以台阶法只有 2–7% 偏差；负控必须用曲率/斜置表面（球 50%、直纹圆柱 27%）才有判别力。这一点写进判据解读，避免误用。

5. **适用范围**：二阶收敛要求界面在单元内光滑可分辨（曲率半径 ≳ 2–3 h）。ζ^0.24 这类“平板龙骨”在 h≳κ⁻¹ 时降阶（实测 L/h=320 仍 0.29%，对 1% 判据足够，但不是二阶）；真实船体 CAD 有有限舭半径，不受此限。

6. **m6242 CAD 真值缺失**：本工作树内检索不到 m6242 的 CAD 固体/湿面积契约文件，故 KCS/SUBOFF 判据对照的是**解析/参数化真值**（KCS 半宽参数面三角求积、SUBOFF 圆台求和，两者与 `suboff_cad.suboff_analytic_wetted_area` 交叉核对一致）。契约重跑需在有 CAD 固体的环境里再做一次。
