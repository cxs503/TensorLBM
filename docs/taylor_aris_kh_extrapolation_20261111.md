## 1 案例介绍（物理背景 / 几何 / 参数）

**物理**：被动标量在横向剪切 `u_x(y)=U sin(2πy/H)` 中的长期输运由 Aris 型闭式给出

```
D_eff/D = 1 + Pe² / (8π²),     Pe = U H / D
```

推导：亏损流 `u'=U sin(my)`，`m=2π/H` ⇒ `ψ = -U/(D m²) sin(my)`，
`⟨ψ²⟩/D = U²/(2D m²) = U²H²/(8π²D)` ⇒ `D_eff = D + U²H²/(8π²D)`。
（`src/tensorlbm/taylor_dispersion.py:periodic_shear_taylor_diffusivity`，m7568）

**计量台**：单一轴向 Fourier 模态 `φ = 1 + ε cos(kx)`（`k=2π/L`），横截面平均幅值按
`exp(-k² D_eff t)` 衰减 ⇒ 拟合斜率反演 `D_eff = rate/k²`。
**关键口径事实**：该读数只有在 `kH → 0` 时才等于上式中的 `D_eff`；
而 m7568 与本单审计对象 `benchmarks/verified/taylor_aris_dispersion`（周期剪切臂）
全部算例都固定 `L/H = 8`，即 `kH = 0.785` —— 不是小量。

| 参数 | 取值 |
|---|---|
| 格子 | D2Q5（库内 `passive_scalar.equilibrium/collide/stream`，完全周期，无边界条件） |
| 分子扩散 | `D = 0.1`（`τ_D = 0.8`）—— 除 Ma 分离臂外恒定 |
| 轴向长宽比扫描 | `L/H ∈ {8, 16, 32, 64}` ⇒ `kH ∈ {0.785, 0.393, 0.196, 0.098}` |
| 横向分辨率扫描 | `H ∈ {16, 20, 26, 32}`（`Pe=8`、`L/H=32` 固定） |
| Péclet | `Pe ∈ {2, 5, 8, 12}`（`U = Pe·D/H`） |
| Ma 分离臂 | `Pe=8, H=16, L/H=32` 固定，`D` 与 `U` 同比例缩放 `s ∈ {0.5, 1, 2}`（Pe 不变，Ma 变） |
| 步数 | `n_steps = clamp(2/rate_theory, 6000, 12000)`；拟合窗口=记录后 50% |
| dtype / 线程 | float64 / 2–3 线程 CPU（本机 load15 ≈ 90，全部算例合计 21 个、约 6 min） |

## 2 怎么做的（方法 / 流程 / 工具链）

1. **驱动**：`benchmarks/pending/taylor_aris_kh_extrapolation/run_kh.py`
   —— 只调用库函数 `taylor_dispersion.run_periodic_shear_dispersion`
   （内部即 `passive_scalar` 的 D2Q5 三件套），**零手写物理核**；逐算例缓存 `case_NNN.json`。
2. **kH 外推**：对每个 `Pe` 把 `D_eff^LBM / D_eff^closed` 对 `(kH)²` 做二次最小二乘，
   取 `kH=0` 截距（4 档点，`R² = 1.00000`）。横向分辨率 `H=16` 全程固定 ⇒ 横向离散误差是常数，
   外推**只**剥掉有限波数偏置。
3. **偏置分离**：固定 `(Pe, kH)` 加密 `H` ⇒ 残差对 `1/H²` 线性拟合（`R²=0.999997`），
   得到"横向离散偏置"的阶与外推值。
4. **Ma 分离**：`Pe = UH/D` 固定时 `H` 与 `U` 是耦合的（`U=Pe·D/H`），因此 `Pe` 扫描
   **不能**被读成 Mach 律。改用 `D` 与 `U` 同比例缩放（`Pe` 不变、`Ma` 变）单独测 `Ma` 依赖。
5. **图表**：`run_kh.py --figs`（matplotlib）+ `--capture`（同一库算子路径捕获一张浓度场）。

## 3 计算结果（全部数字由 `artifacts/results.json` 程序化读出，零手抄）

### 3.1 kH→0 外推（`H=16` 固定，`D=0.1`）

| Pe | 出厂口径 `L/H=8`（`kH=0.785`） | `L/H=32`（`kH=0.196`） | `L/H=64`（`kH=0.098`） | **kH→0 外推** | 抵消量（pp） | 二次拟合 `R²` |
|---|---|---|---|---|---|---|
| 2 | −0.040 % | −0.056 % | −0.056 % | **−0.057 %** | 0.016 | 1.00000 |
| 5 | −0.166 % | −0.275 % | −0.280 % | **−0.282 %** | 0.116 | 1.00000 |
| 8 | −0.013 % | −0.494 % | −0.517 % | **−0.525 %** | 0.512 | 1.00000 |
| 12 | **+0.928 %** | −0.657 % | −0.732 % | **−0.757 %** | **1.685** | 1.00000 |

（"抵消量" = |出厂单点误差 − kH→0 误差|；`R²` 是对 `(kH)²` 的二次拟合优度。）

**读法**：出厂口径的"≤0.93 %"不是核的误差，而是**两个反号偏置的偶然抵消**：
有限波数偏置（正，∝Pe²）与横向离散偏置（负，∝1/H²）在 `L/H=8, H=16` 上几乎相消。
Pe 越高抵消越彻底（Pe=12 差 1.685 pp，且**符号翻转**）。

### 3.2 横向离散偏置（`Pe=8`、`kH=0.196` 固定）

| H | 16 | 20 | 26 | 32 | 拟合 `ratio = 1 + a/H² + b` |
|---|---|---|---|---|---|
| 误差 | −0.494 % | −0.306 % | −0.169 % | −0.101 % | `a = −1.340`，`b = +0.0297 %`，`R² = 0.9999969` |

⇒ `kH→0` 残差是**纯横向离散**、严格 `O(1/H²)`；`H→∞` 外推 **+0.030 %**。
即：**核的本征精度是 0.03 %（kH→0、H→∞）**，`verified` 判定的物理结论成立，
但"0.01–0.93 %"这组数字的**归因**必须改写为"离散偏置 + 抵消"。

### 3.3 Ma 依赖（`Pe=8`、`H=16`、`kH=0.196` 固定，`D`、`U` 同比例缩放）

| `D`（`τ_D`） | 0.05（0.65） | 0.1（0.8） | 0.2（1.1） |
|---|---|---|---|
| `Ma²` | 1.875e−3 | 7.50e−3 | 3.00e−2 |
| 误差 | −0.960 % | −0.494 % | **+1.371 %** |

线性拟合 `err[%] = −1.115 + 82.86·Ma²`，`R² = 0.9999999999`。
⇒ 固定几何下晶格 Mach 误差**为正且陡**：`|err| < 3 %` 要求 `Ma² < 0.0227`，即 **`Ma < 0.151`（`U < 0.087`）**。
**反例警告**：同一点在 `Pe` 扫描（`H` 固定）里误差随 Pe **变负**（−0.056 % → −0.657 %），
与上面的正向 Mach 律方向相反 ⇒ **`Pe` 扫描不能被解释为 Mach 律**（`Pe↔Ma↔U` 共线）。
本单第一版拟合就犯了这个错（斜率 −0.34、`R²=0.88`，方向错），由 §3.3 的分离实验推翻。

## 5 注意点 / 局限

1. **不改历史判定**：`verified/taylor_aris_dispersion` 的 ±3 % 门结论**维持 PASS**（所有算术口径均 <3 %）。
   本单只改**归因**：出厂数字是抵消产物，不是核精度。
2. **未做 kH→0 的两档交叉**：外推只在 `H=16` 上做（横向误差被固定住）；未在 `H=32` 上重做 4 点 kH 扫描
   （预算/机时限制，`H=32, L/H=64` 单算例 ~58 s）。若要同时外推两维，需 `4×4` 矩阵。
3. **Ma 分离臂的截距不可解释**：`s=0.5` 档 `τ_D=0.65` 已贴近 0.5 稳定性边界，截距（−1.11 %）混入了
   `τ_D` 效应，只有**斜率**（82.86/Ma²）可解释；斜率本身也可能含 `τ_D` 污染（三档 `τ_D` 同时变）。
4. **流场是外加的解析剪切**（标量被动 ⇒ 不跑动量求解器）：本单不检验水力-标量耦合，
   也不检验 `u'` 的横向采样与 D2Q9 力矩场的差异。
5. **`Pe` 上限**：`H=16` 时 `Pe=12` 已到 `U=0.075`（`3U²=1.7 %`）；更高 Pe 必须加 H，否则 Ma 误差进入正区间（§3.3）。
6. 机时披露：全部 21 算例 = 6 min 单机 CPU（load15≈90 的共享环境下）；`figures/` 与 `artifacts/` 可一键复算。

## 6 误差判定（关键量 vs 基准，逐项回答"是否 <3%"）

| 关键量 | 数值 | 基准 | 误差 | <3 % ? |
|---|---|---|---|---|
| `D_eff`（`Pe=2`，kH→0，H→∞） | 见 §3.1/§3.2 | 闭式 `1+Pe²/8π²` | −0.057 %（kH0）/ +0.030 %（H∞，Pe=8） | **是** |
| `D_eff`（`Pe=5`，kH→0） | −0.282 % | 同上 | **是** |
| `D_eff`（`Pe=8`，kH→0） | −0.525 % | 同上 | **是** |
| `D_eff`（`Pe=12`，kH→0） | −0.757 % | 同上 | **是** |
| 出厂口径（`L/H=8`）四档 | −0.040 / −0.166 / −0.013 / **+0.928 %** | 同上 | **是（但归因错误：抵消）** |
| 横向离散阶 | `a = −1.340`（`1/H²`），`R²=0.999997` | `O(h²)` 预期 | **是（阶成立）** |
| Ma 律斜率 | 82.86 %/Ma²（`R²=1.0000`） | 无文献基准（晶格效应量级） | 无基准 ⇒ 仅报量级与可用上限 `Ma<0.151` |

**结论**：`kH` 欠账清偿；判据（≤3 %）全部满足；唯一需要改的是**归因文本**——
`docs/taylor_aris_dispersion_20261109.md` / `benchmarks/verified/taylor_aris_dispersion`
的"≤0.93 %"应加注"含 ≤1.69 pp 的 kH 抵消，核本征精度 0.03 %（kH→0, H→∞）"。
