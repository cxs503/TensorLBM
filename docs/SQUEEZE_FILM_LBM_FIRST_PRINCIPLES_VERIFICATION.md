# 挤膜 LBM 的第一性原理复核：12–37 % 是"对标口径"，不是求解器误差（m22438）

**锚点**：KPI-LBM-VERIFIED-CAPS（周新增通过独立物理验证的能力数）
**仓**：TensorLBM　**分支**：agent/m22438
**工件**：`benchmarks/verified/squeeze_film_ns/`（`reference_ns.py` / `run_compare.py` / `summarize.py` / `results.json` / `figures/`）+ `tests/test_squeeze_film_ns_reference.py`

## 0. 一句话结论

`tensorlbm.squeeze_film_lbm` 被 2026-11-08 的验证报告判为"绝对载荷系统性高于闭式解 **12.2 %–37.2 %**、定量不可用，只能做标度锚"。本单用一条**与 LBM 和 Reynolds 渐近都无关**的第二路径（二维不可压 N-S，交错 MAC + 人工压缩性，Chorin 1967）重解同一物理问题，结论被**推翻**：

* 相对第一性原理 N-S 参考解，LBM 动量交换载荷误差为 **+1.58 % / +0.29 % / −0.51 %**（a=16，h=6/8/12，即 h/a=0.375/0.5/0.75）——**在 3 % 验收带内**，且 h=12 处甚至落在渐近解的另一侧；
* 那条 12–37 % 的"N-S 参考解 vs Reynolds 渐近"列（+12.38 %/+19.56 %/+37.93 %）与历史误差列逐行复现 ⇒ **历史误差列量的是对标口径（一阶润滑渐近的 O((h/a)^1.56) 截断），不是求解器**；
* 真实求解器误差只出现在**最薄膜**：h=3 → +11.55 %、h=4 → +5.21 %，随膜厚单调衰减，是"膜内只有 3–4 个格点"的离散误差，与物理无关。

**判定：能力锚从 WITHHELD/FAIL 升为 L3（h ≥ 6 的定量载荷通过独立物理验证）。**

## 1. 案例介绍（物理背景 / 几何 / 参数）

两块刚性平行平板以相对速度 V 逼近，板间距 h、半宽 a、二维平面应变（两端通大气）。在**板固定系**中，逼近板以速度 V 均匀吹入流体（切向速度为零），对立板不可渗透，两端 p=0 排放——这正是 `simulate_squeeze` 的降阶问题（顶行均匀零动量质量源 + 半步反弹壁 + `x=0, nx-1` 定点密度压力面，板跨 `nx-1=2a`）。

| 参数 | 值 | 出处 |
|---|---|---|
| 运动黏度 ν | 0.1（τ=0.8） | `simulate_squeeze(nu=…)` |
| 逼近速度 V | 0.005（Ma≈0.0087） | 同上 |
| 板半宽 a | 16（LBM nx=33；参考解 Lx=32） | `half_width=16` |
| 膜厚 h | 3 / 4 / 6 / 8 / 12（h/a = 0.188 … 0.75） | 与 2026-11-08 扫描同档 |
| 闭式解对标 | `F=8ρνVa³/h³`（Reynolds 1886；Stefan 1874） | `lattice_reynolds_force` |
| 独立参考 | 二维不可压 N-S（交错 MAC + 人工压缩性） | `benchmarks/verified/squeeze_film_ns/reference_ns.py` |

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

1. **先立参考解，再对 LBM**。`reference_ns.solve` 在**同一几何**上解原始变量 N-S：交错网格（u 在竖直面、v 在水平面、p 在格心，dx=dy），显式伪时间推进 + 人工压缩性把连续性变成 `p_t + c²∇·u = 0`；τ→稳态时 `∇·u→0` 精确成立。板边界：`u=0`（半步反弹对应位置用 (4/3)(u₁−3u₀) 抛物线拟合，对润滑抛物线**精确**），`v=0 / v=−V`；两端：p=0 + 开边界。
2. **参考解自身的可判据自检**（§3 上表）：细膜极限 h/a=0.094 下必须复现润滑渐近（实测 **+2.49 %**，与"有限 h/a 正修正"同族）；质量守恒 `|注入−两侧排出|/注入 = 1.97e-9`；`max|∇·u|/(V/h) = 3.1e-9`；网格 ny=16→24 载荷仅差 **+0.38 %**；对称性破缺种子 1e-3 vs 3e-3 不影响收敛解（测试 `test_reference_is_seed_independent`）。
3. **载荷口径对齐**：半步反弹的动量交换载荷是**总法向应力**积分 `∫(p−2μ∂v/∂y)dx`，而 `8μVa³/h³` 只是**压力**积分。参考解同时输出两种，LBM 侧同时取 `force_gauge_top`（ME）与 `force_pressure_integral`（无源壁行静压），四路互校。
4. **同档扫描**：a=16，h∈{3,4,6,8,12}，LBM 用 `simulate_squeeze(tol=1e-11, max_steps=2e5)`，参考解 ny=16（dx=dy）。
5. **工具链**：numpy 纯 CPU，单进程；`run_compare.py` → `sweep_*.json` → `summarize.py` → `results.json` + 两张图。报告数字全部由 `summarize.py` 程序化注入，零手抄。

## 4. 注意点（坑 / 局限 / 适用范围）

* **对称态是迭代的不动点**：u 只由 ∂p/∂x 驱动，而纯 y 向的散度永不产生 x 向结构 ⇒ 严格对称初值会把人工压缩性迭代锁死在"u≡0、v 线性、压力无界漂移"的伪不动点上（本单首次跑就踩到：u 恒为 0、载荷虚高 124 倍）。必须给一个 1e-3 倍黏性压力尺度的对称性破缺种子，并验证收敛解与种子无关。
* **压力规范必须被钉住**：人工压缩性的压力有自由常数，若用它去算端部梯度，会把**无物理意义的压力水平**读成驱动力（首次实现里正是"p 均匀 0.586、端部梯度巨大、u 被 Neumann 覆盖抹掉"）。参考解用 `p=0 于端面 + 镜像 ghost` 钉规范。
* **h=3 的 11.55 % 是离散误差**：膜内只有 3 个格点，LBM 的有效壁位置与抛物线分辨率都不足；它随 h 单调衰减（11.55 → 5.21 → 1.58 → 0.29 → −0.51），不是模型误差。**不要**把 h≥6 的结论外推到 h=3。
* **参考解局限**：只解二维平面应变（不含圆盘轴对称 Stefan 情形，也含 h/a 修正）；参考解自身离散不确定度 ≈0.3 %（ny 16→24 的 +0.38 %），故 ≤1 % 的 LBM 偏差不应被解读为 1 % 精度。
* **宽膜不稳定（a≥24）不在本单范围**：`simulate_squeeze` 在 a≥24,h=4 的伪解/发散仍未修；本单没有让它变好也没有让它变坏，历史登记保留。
