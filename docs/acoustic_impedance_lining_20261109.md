## 1 案例介绍（物理背景/几何/参数）

舱室/机舱围壁贴多孔吸声衬里，要回答：目标频带插入损失 IL 多少、能量去哪、
船用重量约束下最优 (厚度, 流阻) 是多少。物理口径：平面波正入射、局部反应
（locally reacting）壁面、刚性背衬（钢板），环境 20 ℃ 空气 ρ₀ = 1.204 kg/m³、
c₀ = 343 m/s、Z₀ = ρ₀c₀ = 412.97 Pa·s/m。

## 2 怎么做的（方法/流程/关键设置/工具链）

1. **等效流体关联式**：`delany_bazley(f, σ)` 返回
   `Z_c = ρ₀c₀(1 + 0.0571X^-0.754 + i·0.0870X^-0.732)`、
   `k_c = (2πf/c₀)(1 + 0.0978X^-0.700 + i·0.189X^-0.595)`。
   时间约定 `exp(-iωt)`（模块 docstring 写死）：`Im k_c > 0` 表示 +x 衰减、
   `Im Z_c > 0` 表示惯性（质量型）抗。常见文献的 `-j` 表法是相反约定，`α` 与
   `|R|` 对该共轭不变（有对应用例，含矩阵 `i` 号翻转）。
2. **分层 TMM**：每层 `[[cos k_c d, -i Z_c sin k_c d], [-i sin k_c d/Z_c, cos k_c d]]`，
   按 `T_total = T₁T₂…` 串联；刚性背衬 `Z_s = T₀₀/T₁₀`，消声背衬
   `Z_s = (T₀₀Z₀+T₀₁)/(T₁₀Z₀+T₁₁)`，也支持任意复背衬。
   `R=(Z_s-Z₀)/(Z_s+Z₀)`、`α=1-|R|²`、`IL=10log₁₀(1/(1-α))`。
3. **局部反应阻抗边界**（LBM 侧）：一维 D1Q2（两个群、c_s = 1，`p' = ρ-1`、
   `Z₀ = 1`）把两个特征量直接映射到两个群上，边界条件是**一行关系**：
   入射 `a = f₊-1/2`、反射 `c = f₋-1/2`，`c = R a`。单频复 `R` 用
   「幅值增益 `|R|` + 时延 `τ = (arg R + 2π)/ω`」实现（`exp(-iωt)` 下时延给
   相位 `+ωτ`；整周期平移在稳态不可见，且保证 `τ ≥ T/2`、更新显式）；
   分数延迟用三阶 Lagrange 插值。**不使用有理（IIR）拟合的宽带实现**——原因见 §5。
4. **测量链**（与 TMM 只共享目标反射系数，不共享任何离散化）：
   ①标定跑（消声端）得自由场入射与格点复波数 `k = -i ln(p₀/p₁)/(x₀-x₁)`；
   ②带衬里跑得总场；③叠加原理给出反射场 = 两次跑之差（同源同入口同格点，
   逐样本时间对齐），④相位去旋转到壁面得 `R`，幅值不受 `k` 影响；
   ⑤独立地用壁面节点的 `p'u'` 时均算吸收声强，做能量账。
5. **工具链**：numpy + scipy.signal（find_peaks）+ matplotlib；pytest 34 项；
   一键复现 `python scripts/run_acoustic_lining_m8462.py`（105 s，输出
   `artifacts/acoustic_lining_m8462/report.json` + 5 张图）。

## 5 注意点（踩过的坑 / 局限 / 适用范围）

1. **抗有理拟合：DB 面阻抗做不了好的因果宽带实现。** 先按「有理函数 +
   bilinear → IIR」路线实现，SK/向量拟合在 [100,6000] Hz 上最好也只有
   20–40 % 的 |R| 残差（`s` 域条件数 1e17 量级）。根因是分式幂律
   `f^-0.75` 只沿负实轴有支割线、不是有限阶有理函数，且 DB 的 `Z_c`/`k_c` 对
   并非热力学配对（见第 6 条的 1.1 % 非无源证据），其桌面数据不满足
   Kramers–Kronig。**本单因此改用单频复反射系数（稳态谐波扫频）实现**：
   同一频点上精确、无拟合残差，代价是**不是宽带时域吸收体**（列为未完成项）。
2. **D1Q3 会漏能。** 三速模型多一个静止群（熵模），把阻抗条件写在
   `p'/u'` 上会让能量漏进静止群并发散（实测 3 周期后 overflow）。改用 D1Q2
   （两个特征量就是两个群）后完全稳定——这条教训已写进模块 docstring。
3. **两次跑必须逐样本时间对齐。** 标定跑与衬里跑若预热长度不同（例如用边界
   自己的时延当余量），稳态相量会整整差一个周期，反射场相消得乱七八糟
   （实测退化成 `|R|~1e4`）。改成固定 2 周期余量后误差降到 4e-4。
4. **双探针法在低频病态。** 100 Hz 时 λ/dx≈1600 节点，8 节点间距只有 λ/200，
   2×2 求解发散。改用「叠加相减」取反射场，幅值不依赖 `k`，只在相位去旋转
   时用到 `k`（`k` 的符号错了会整体共轭，本单踩过一次）。
5. **argmax 找峰在近平坦区是病态的。** α 平台在 ±16 % 频率内只变 0.005，
   argmax 的 3 % 判据实际上是在比网格。故同时报「频带质心」（同网格比对，
   0.00 %），并显式给出平台宽度。
6. **DB 关联式不是严格无源的。** 硬背衬单层在 35 Hz（X=0.002，拟合窗之外）
   出现 `|R| = 1.0055`，即 1.1 % 的能量创生；拟合窗内也会有 0.14 %
   （σ=5000、厚层）。这是 DB 的已知缺陷，`absorption_coefficient` 对负 α
   做 0 截断，报告里保留原始 `max|R|` 作为审计数字。
7. **适用范围**：正入射、局部反应、刚性背衬、无流、线性声学、常温常压；
   三维房间声场、结构传声、气流偏置（高声强下的非线性流阻）均不在本单内。
8. **Miki(1990) 交叉模型未入库。** 记忆的 Miki 系数集重建后给出 ᾱ≈0.06
   的「几乎全反射」结果，与 DB 差 30 倍，明显不可信且无法离线核对原文，
   按诚实纪律**不予采纳**（宁缺勿错）。
