## 2 怎么做的（方法 / 流程 / 工具链）

整条链条为：**叶剖面升阻特性 → 叶元–动量（BEM）→ 径向载荷 → 体积力等效盘（Guo 源项）
→ LBM 动量理论核验 → 伴流分数 / 推力减额 → 自航点求解 T(n)(1−t) = R_T → P_E→P_T→P_D 功率链**。

### 2.1 叶元–动量（BEM）开水求解（`blade_element_momentum`）

对每个径向剖面 r/R，用二分/网格搜索求解平衡流角 φ：

```
r(φ) = φ − atan[ V_A(1+a) / (Ω r (1−a')) ]      （残差，逐剖面求零点）
a  = σ C_n / (4 F sin²φ − σ C_n)                （Prandtl 修正 F = F_tip·F_root）
a' = σ C_t / (4 F sinφ cosφ + σ C_t)
C_n = C_L cosφ − C_D sinφ,  C_t = C_L sinφ + C_D cosφ
dT/dr = ½ ρ W² Z c C_n,      dQ/dr = ½ ρ W² Z c C_t r,     W = V_A(1+a)/sinφ
```

- **输入是叶剖面升阻特性**（本节点要求第 1 项）：NACA 66 (mod) a = 0.8 剖面族，
  `C_L = 5.7/rad·(α − α₀)`（含软失速平台），`C_D = 0.0085 + 0.011 C_L²`。
  零升角 **α₀ = −3.5°** 由**单一运动学约束**确定：KP505 公开的零推力进速比 J₀ ≈ 1.13
  （α₀ = β(0.7R) − atan(J₀D/2πr)），**不用于拟合 KT/KQ 曲线**。
- 采用**网格搜索 + 线性插值**求 φ 零点，而非松弛不动点迭代：高盘面比桨
  （σ(0.7R) ≈ 0.82）在低 J 时环形动量关系无解（σC_n > 4F sin²φ），不动点迭代会发散
  并给出伪负推力——这是本节点踩到的第一个实质坑（§5.1）。
- 输出 `dT/dr(r)`、`dQ/dr(r)` 即为等效盘的面载荷，同时也给出 KT(J)、KQ(J)、η₀(J)。

### 2.2 体积力等效盘（`build_actuator_disk_field` + `apply_body_force_guo`）

- 把 BEM 的面载荷投影到 3 个格厚的圆盘上（含毂径），按径向插值分配，**归一化保证**
  `Σ f_x = T*`、`Σ r f_θ = Q*`（力矩与推力总量精确，机器可验证）。
- 注入格式为 Guo 型源项 `f_i += 3 w_i (c_i·F)`，因 `Σ_i 3 w_i c_ix² = 1`，注入动量为
  `F` **逐格精确**（测试实测相对误差 ~10⁻⁷）。
- 符号约定：x 由艏（入口）指向艉，水流沿 +x，桨把水向 +x 加速，故器件受力 +x，
  船体反作用推力 −x。
- **压力跳变与周向速度不施加**，而是作为动量源的**结果**由 LBM 场后验测量
  （`disk_pressure_jump`、`disk_swirl`）——这样等效盘实现是被验证的，而不是被规定的。

### 2.3 LBM 直通道核验（`run_actuator_disk_momentum_case`）

- D3Q19 + Smagorinsky MRT + Guo 源项，等速入口/零梯度出口，横向周期边界，
  容栅比 D/H = 0.4；时间平均取 `warmup + sample` 段。
- 核验项：①推力记账（Σf_x vs T*）；②压力跳变 Δp vs T/A；③动量理论
  Δp = u_a(U+u_a)（用实测盘面诱导速度 u_a）；④角动量通量 vs 施加力矩；
  ⑤远场尾流比 (u_wake−U)/(u_disk−U)（受直通道质量守恒限制，见 §5.4）。

算例：`nz×ny×nx = 18×24×64`，盘半径 R = 6 格，U = 0.05，τ = 0.5055，C_s = 0.1，3000 步（后 600 步时间平均），墙钟 264 s。

| 核验项 | 实测 / 偏差 | 判读 |
|---|---|---|
| 推力记账 Σf_x vs T* | 1.49e-08 | 注入动量逐格精确 |
| 盘面诱导速度 u_a/U | 0.1159 | 体积力产生射流加速 |
| Δp 实测 | 3.334e-04 | 压力跳变为动量源的结果（未施加） |
| Δp vs u_a(U+u_a) | 3.1% | 局部动量理论核验（有效） |
| Δp vs T/A_geo | 62.3% | 受通道阻塞：A_eff/A_geo ≈ 2.65，只作量级判读 |
| 远场尾流比 (u_w−U)/(u_d−U) | 1.541（理论 2） | 定速直通道质量守恒使其必然 <2，仅趋势判读 |
| 角动量通量 vs 力矩（全断面） | 73.5% | **未闭合**：短域内旋流剖面未发展，仅证明周向速度的符号与存在性（见 §5.7） |

### 2.4 阻力（模型尺度）

`ittc78_resistance`：ITTC-57 摩擦线 + 形状因子 (1+k) = 1.069 + 剩余阻力系数
C_R = 0.58×10⁻³（KCS 模型尺度 Fr = 0.26 的公开量级，作为**输入而非预测**）。

### 2.5 伴流分数与推力减额

- 有效伴流分数采用单桨船设计回归（Taylor / Harvald）：`w = 0.5 Cb − 0.05`。
- 推力减额采用 Heckscher 回归：`t = 0.25 w + 0.14`。
- **两者均与 LBM 提供的力学机制做了接口核验，但没有用 LBM 直接预测模型尺度 w、t**，
  原因与证据等级见 §5.3（低 Re LBM 无法给出 10⁷ 量级边界的伴流，属诚实局限）。

### 2.6 自航点求解（`solve_self_propulsion` / `solve_self_propulsion_curve`）

对转速 n 二分求解 `T(n)(1−t) = R_T`，其中 `J = V(1−w)/(nD)`。
两条互校路径：

| 路径 | KT, KQ 来源 | 证据等级 |
|---|---|---|
| A：BEM | 本节点 BEM 无标定预测 | REAL（未标定预测，含 ~10% 系统偏差） |
| B：开水曲线 | KP505 实测开水表插值 | 船 CFD 中体积力法的标准做法（推荐值） |

对**交付功率**采用路径 B；路径 A 作为"无标定预测"留档，差值即 BEM 建模误差的功率影响。

### 2.7 效率分解与功率链（`power_chain`）

```
P_E = R_T V,  P_T = T V_A = T V(1−w),  P_D = 2π n Q
η_H = (1−t)/(1−w),  η_R,  η_0 = J KT/(2π KQ),  η_D = P_E/P_D = η_H η_R η_0
```

- **η_R（相对旋转效率）**：实现并单测了 `relative_rotative_efficiency`——把**实测**盘面
  伴流场按 12 个周向扇区 × 8 个径向带做扇区 BEM，等推力下比较 `KQ_open/KQ_behind`。
  本案例没有模型尺度实测伴流场（§5.3），故数值上采用 Holtrop(1982) 回归
  `η_R = 0.9737 + 0.111(Cp − 0.0225 lcb) − 0.06325 P/D`（Cp = Cb/Cm = 0.6605，lcb = −1.5%L）。

## 5 注意点（踩过的坑 / 局限 / 适用范围）

### 5.1 高盘面比桨的环形动量关系会"无解"，松弛迭代会给出伪负推力
首版 BEM 用松弛不动点迭代，在 J ≤ 0.4 处 `σC_n > 4F sin²φ`，迭代发散，KT 出现 −30 甚至
−10⁴ 的荒谬值。改为**残差网格搜索 + 零点插值**，并对 a 施加 0.9 限幅后稳定。
残余影响：J ≤ 0.4 的重载区 KT 仍偏大 30–60%，仅在设计区（0.5 ≤ J ≤ 0.9）可用。

### 5.2 几何必须先验证：盘面比归一化
公开抄录的弦长分布按 r/R 积分只给出 A_E/A_0 = 0.7107，与 KP505 公布的 0.80 差 11%。
本模块保留弦长分布**形状**，按公布的盘面比归一化（`ear_scale = 1.126`，原始积分值
`raw_area_ratio()` 一并入库供审计）。这是几何一致性要求（等价于船体的 Cb/L/B 校验），
不是对性能曲线的标定。

### 5.3 未做模型尺度粘性伴流 LBM（诚实局限，最重要的限制）
要在 Re = 1.4×10⁷ 直接算 KCS 伴流，需要壁面模化的 LES（或 RANS）与足够壁面分辨率；
本仓库 LBM（BGK/MRT + Smagorinsky + bounce-back）在可行网格（L ≈ 130–180 格）上：
- 掩膜 Cb 离散误差已达 **19%**（L = 132、吃水仅 6 格），违反"几何先验证"纪律；
- 试算给出的盘面伴流分数 w = 0.85（低 Re 层流边界层 + 数值耗散主导），**物理上不可用**；
- LBM 稳定条件（τ−0.5 ∝ ν）把格点 Re 限制在 10³–10⁴ 量级。

因此：**w、t 的模型尺度数值来自设计回归（MODEL 级证据），不是 LBM 预测**；LBM 在本节点
承担的是"体积力等效盘实现 + 动量理论核验"（REAL）。这一取舍在 §1.3 判据达成中未做粉饰：
判据通过，但证据等级是"设计方法 + LBM 核验"，不是"高 Re 粘性 CFD 直接预测"。

### 5.4 直通道里无法核验远场 2× 尾流关系
定常直通道入口定速、断面固定，质量守恒禁止尾流整体加速，故
`(u_wake−U)/(u_disk−U)` 必然 < 2（本次实测见 §2.3 表）。该项只能作**趋势**核验；
严格的 2× 关系需自由来流/大域外边界。替代核验采用局部动量理论 Δp = u_a(U+u_a)，
不受通道限制。

### 5.5 η_R 目前是回归值，扇区 BEM 通路已实现但缺输入
`relative_rotative_efficiency` 已实现并单测（均匀伴流 → η_R ≈ 1），但要用于 KCS 需要
模型尺度盘面 r–θ 伴流场（§5.3 未获得）。故本案例 η_R = 0.9877（Holtrop 回归，MODEL）。

### 5.7 旋流角动量守恒未闭合（73.5%），已如实记录
全断面角动量通量（3.18×10⁻³）显著小于施加力矩（1.2×10⁻²）。原因：直通道算例的旋流剖面
在采样面尚未发展完全，且体积力施加的环向动量在短域内仍以压力/横向再分配形式存在；
要闭合该守恒需长通道 + 发展段。本节点只据此确认**周向速度的符号与量级**（u_θ > 0，
与 +θ 力矩一致），不宣称旋流守恒已核验。

### 5.6 数值细节
- Guo 源项动量为 float32 累加，机器精度检查按相对 10⁻³ 判据（实测 ~10⁻⁷~10⁻⁴）。
- `collide_smagorinsky_mrt3d` 在 CPU 上对 1.6×10⁶ 格点单步 ~1.3 s，直通道核验规模
  （1.2×10⁵ 格点）单步 ~0.2 s，故核验算例控制在 6000 步内。
