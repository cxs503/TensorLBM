## 0. 为什么做这一单

`src/tensorlbm/rao_analysis.py`（434 行）承担耐波性方向的全部频域工作：由水动力系数
组装 RAO、时域互谱 RAO、谱响应分析（SRA）与统计量、固有频率、实验比对。此前它
**没有任何解析基准测试**（全仓仅 `tests/test_irregular_wave_6dof.py` 断言"结果有限且为正"），
属于典型"验证欠账"。本轮按解析解逐项复核，并修掉复核中暴露的 4 处实缺陷。

## 1. 物理背景与算例

单体单自由度垂荡（heave）振子，运动方程

    (m + A) ẍ + B ẋ + C x = F cos(ωt)

解析幅频响应（Faltinsen 1990, ch. 3）：

    |H(ω)| = |F| / √[ (C − (m+A)ω²)² + (Bω)² ]

参数表（人为取轻质量体，使 m+A 与 C 在同量级，放大消去误差）：

| 量 | 符号 | 取值 | 单位 |
|---|---|---|---|
| 船体质量 | m | 1000 | kg |
| 附加质量 | A | 500 | kg |
| 辐射阻尼 | B | 2000 | kg/s |
| 静水恢复力 | C | 100000 | N/m |
| 激励幅值 | F | 1 | N |
| 固有频率 | ω_n=√(C/(m+A)) | 8.164966 | rad/s |

参考解来源：
- 幅频：单自由度阻尼振子闭式解（与模块的复数 6×6 求解路径**不共享代码**）；
- 固有频率：解耦情形 ω_n=√(C_ii/(M_ii+A_ii))；耦合情形另用 2×2 广义特征多项式闭式根与 det(C−ω²M) 残差双检；
- 波浪谱：Bretschneider/ISSC 谱 S(ω)=(A/ω⁵)exp(−B/ω⁴) 的矩闭式 m_n=(A/4)B^{(n−4)/4}Γ(1−n/4)（n<4）；
- 极值统计：Rayleigh 分布 N 循环期望极值 E[max]/(2√m0)=√(2 ln N)/2（Longuet-Higgins 1952）。

## 2. 做了什么（方法/流程）

1. 只读审计：读 `rao_analysis.py` 全文 → 定位 5 个公开函数 → 逐一对表解析解，构造 601 点频率扫描（0.2ω_n…5ω_n，跨共振峰与峰后消去谷）。
2. 独立复算：闭式解、Γ 函数矩、Rayleigh 因子、2×2 广义特征根全部在测试文件内独立实现。
3. 修复暴露的缺陷（4 处，均最小改动）：
   - **未建模自由度的奇异矩阵崩溃**：`compute_rao_from_hydrodynamics` 对只填了垂荡的 6×6 矩阵（工程上最常见的单自由度/条带理论模型）直接 `torch.linalg.inv` 全矩阵，`Z` 有零行零列 → `_LinAlgError`。改为按行量级识别未建模自由度（返回 `RAOData.inactive_dofs`），只解活动子块。
   - **精度**：整条求解链由 `complex64` 提升 `float64`（`rao_complex` 现为 `complex128`），峰后消去区相对误差从 1.5e-07 降到机器精度。
   - **`compute_natural_frequencies` 同类奇异**：质量阵含零行（未建模自由度）时同样崩溃；改为只解活动子块、未建模自由度返回 `NaN`（不伪造数值），解耦情形保持 ω_n[i] 对 DOF i 的对应关系。
   - **`spectral_response_analysis` 频率轴未排序**：降序 ω 会得到 m0<0 → 显著幅值 `NaN`、平均周期 `inf`（静默错值）；现入口统一按升序积分。
   - **`compute_rao_from_timeseries` 零能量频点噪声爆炸**：互谱比在激励能量为零的频点只剩舍入噪声（原本只 clamp 到 1e-30），实测可给出 O(1e2) 的伪 RAO 并抢占 argmax；现按 1e-8·max(S_ηη) 阈值判为无能量并置零。
   顺手清掉两行无效表达式（`omega[1]-omega[0] …`、`1.0/dt`）并把 `torch.trapz` 切到 `torch.trapezoid`（旧 API 已弃用）。

## 5. 注意点 / 局限

1. `compute_rao_from_hydrodynamics` 现按"行量级"判别未建模自由度；若调用方故意用极小但非零的质量/刚度填充未建模自由度，会被当作活动 DOF 参与求解（此时结果在数学上有定义，不再是"未建模"）。
2. 未建模自由度返回 **零响应**，固有频率返回 **NaN**——两者都是"该方向未定义"的显式约定，不伪造数值。
3. 时域互谱法在非整数 bin 频率下受 Hann 窗泄漏影响，峰外若干 bin 的比值不再严格等于传递函数，argmax 可能偏移 1–3 个 bin；需要高精度时请用整周期采样或 Welch 分段平均。这是估计器固有的性质，与本次修复无关。
4. m4 被无限带宽响应量的高频截断影响，本单只对 m0/m2 做解析对表（m4 无有限解析矩，n≥4 时 Γ 积分发散）。
5. 本轮只做频域工具箱复核，未与实验/CFD 的船体 RAO 数据比对（`wave_body_rao.py` 另有专项套件 `tests/test_wave_body_rao_validation.py`）。
