# IN65-N04 — DG 对流–扩散验证面：旋转锥 / 制造解 / 间断传播（从零到机器可证伪）

**节点** IN65-N04 · 战役 *DG from zero to machine-falsifiable* · **仓** TensorLBM · **模块** `src/tensorlbm/dg_verification/{hllc.py,frontier.py}` · **机器门** `tests/test_dg_frontier_in65.py`（19 项）· **工件** `artifacts/IN65_N04/*.json` + `VERDICT.json` + `figures/`

## 1. 案例介绍（物理背景 / 几何 / 参数表）

DG（间断 Galerkin）是 TensorLBM 里唯一能同时给出高阶精度与严格守恒的离散族：它既被用于混合 DG-LBM 的贴体带（`dg_lbm.py`），也是可压缩冲击族（`compressible_shock_family`）的候选主干。但库里的 DG 长期**没有独立验证面**——它只作为耦合求解器的一部分出现，误差与 LBM 碰撞、耦合带、几何纠缠在一起，无法判级。IN70-N01 建起了第一层阶梯（旋转锥 / 制造解 / Sod / 方波 / 质量账本），并留下四个未解问题：
① 变系数旋转对流中 P2 误差地板 ≈2e-3；② 旋转锥收敛阶未达战役门（1.8 / 2.7）；③ 理想气体 Sod 激波位置误差 25%（honest FAIL）；④ 等温 P2 在 t=400 长期退化。

本节点（IN65-N04）不是重跑那五个案例，而是**把四个未解问题逐条打开并定性定位**，并补上它们缺的工具：HLLC 接触间断通量、Zhang–Shu 正性保持限制器、纯算子（RHS 内不带限制）的 Euler DG、kink 正则性收敛上界理论、以及耗散/色散的标量量化（TV 账本、单模态幅值/相位）。


**模型问题与判据**（全部周期/笛卡尔网格、float64、Gauss–Lobatto 节点、p+3 Gauss 求积、SSP-RK3）：

## 2. 怎么做的（方法 / 流程 / 关键设置 / 工具链）

**离散**：节点型 DG，Gauss–Lobatto 节点（面值即自由度，无需 L2 投影），弱形式 $M\dot u=\int F\varphi'-\sum_{\text{faces}}F^*\varphi$，体项用 $p+3$ 点 Gauss 求积（对 $a(x)u$ 这类 $p+1$ 次被积函数精确），时间推进 SSP-RK3（Shu–Osher），CFL 0.2–0.3，面通量可选。

**新增工具（本节点）**：
* `hllc.py`：Toro HLLC 通量（三相波 $S_L<S_M<S_R$，恢复**接触间断**；波速估计用 PVRS 与双稀疏波估计取小者，Sod 跳跃上 $p^*=0.307$ 对精确 0.3031）；等温闭合 $p=c_s^2\rho$ 同实现（与 D2Q9 晶格一致）；`zhang_shu_limit`：Zhang–Shu 正性保持缩放限制器（$U\leftarrow\bar U+\theta(U-\bar U)$，$p(\theta)$ 对 $\theta$ 是凹二次型 ⇒ 二分法找最大可行 $\theta$；单元均值精确不变 ⇒ 严格守恒）。
* `frontier.py`：`EulerDG1D_HLLC`（**纯空间算子**，限制器只在阶段末施加；通量 hllc/rusanov 可切；边界 periodic/outflow）、`ScalarDG1D`、七个基准与量化指标。

**流程**：① 参数化基准 → ② `scripts/run_dg_frontier_in65.py --case all` 产出 JSON（集群 n315/n330 loong64 9 分片，日志与 JSON 均落工件） → ③ `scripts/plot_dg_frontier_in65.py` 出图（场量重算，不抄数） → ④ `scripts/verdict_dg_frontier_in65.py` 依判据自动裁 PASS/FAIL → ⑤ `scripts/report_dg_frontier_in65.py` 程序化注入本报告。

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **周期边界的激波管是错的（本轮最大发现）**：IN70-N01 的理想气体 Sod 用长度 1 的周期管，$t=0.2$ 时 $x=0$ 处的第二个 Riemann 问题（周期回绕）其右行波已推进 0.35，与 $x=0.5$ 的波系重叠，平台区被彻底破坏（实测 $x=0.78$ 处 $p\approx0.78$，精确 0.303）。`tests/test_dg_frontier_in65.py::test_periodic_tube_is_contaminated_reproduction` 把这个坑钉成回归测试；正式基准改用**出流端**（ghost=内部迹，通量退化为物理通量）。
2. **定位器陷阱**：Sod 的接触面是**最大的密度跳跃**，用 $\max|\partial_x\rho|$ 定位激波会把接触面当激波（上一节点 25% 的“FAIL”正是此伪影叠加上述周期污染）。压力在接触面上连续，故激波必须用 $\max|\partial_x p|$ 定位。
3. **一阶限制器会把接触抹到 10+ 格**：TVB 阈值 $M=0$ 等价于全场 minmod，激波管剖面变成准一阶（接触宽度 12–40 格）。$M=50$ 只限制真间断，接触宽度与 L1 明显改善（见 3.4 对照表）；但 $M$ 的量纲是 $dx^2$，网格加密后必须重标定。
4. **限制器不能放在 RHS 里**：SSP-RK3 的每个阶段都重新限制会破坏时间积分阶数与守恒结构；本轮把 RHS 做成纯算子，限制只作用于阶段末状态。
5. **周期性出流不可复用同一面通量**：周期数组上“绕回面”同时扮演左右两个边界，必须分别覆写两侧边界通量（否则边界处立刻产生伪压力波——本轮第一次实现即踩此坑，表现为 7224 步小步长 + 负压）。
6. **旋转测试的速度场在环面上不光滑（本轮第二个发现）**：$\mathbf a=(0.5-y,\,x-0.5)$ 是绕箱心的刚体旋转，跨 $y=0/1$ 时 $a_x$ 从 0.5 跳到 −0.5（$a_y$ 跨 $x=0/1$ 同理）。因此“$t=2\pi$ 的精确解 = 初场”只在**数据始终留在半径 0.5 的内切圆内**时成立。IN70 的高斯伴随用 $\sigma=0.1$、中心 (0.5,0.75)，支撑到 $r=0.55>0.5$，其 $L2$ 误差因此出现与阶数/网格无关的平台（实测 P2 阶 0.16、P1 阶 1.69，P2 在 N=16/32/64 上 L2 恒为 1.8e-3…2.3e-3）——这正是上一节点记为“P2 地板”的开放问题。本轮改用 $\sigma=0.05$（支撑 $r\le0.40$）后同一算子给出 P1 阶 1.97、P2 阶 3.79，说明地板是**基准构造**问题，不是离散缺陷。
7. **适用范围**：结论限于周期/出流边界的一维 Euler 与二维标量对流–扩散；不含壁面、三维、以及耦合 DG-LBM 带（`dg_lbm.py`）。旋转锥的 kink 上界是*L2 范数*结论，L1/L∞ 更慢；等温 LBM 互裁的分辨率 2000 格、$0\le t\le400$（≈100 次激波穿越）。
8. **等温体系没有接触间断**：$p=c_s^2\rho$ 闭合下特征线只有 3 条，“密度跳跃 + 同速”是声学 Riemann 问题而非接触，写成接触会得到错误的精确解。
