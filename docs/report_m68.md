# Mission 68 补报：SDAA Sweep — thermal_cavity (de Vahl Davis 自然对流方腔)

## 1. 案例介绍

### 物理背景
de Vahl Davis (1983) 自然对流方腔是计算流体力学最经典的验证基准之一。方形腔体内充满 Pr=0.71 的空气，左壁维持高温 T_hot=1.0，右壁维持低温 T_cold=0.0，上下壁绝热，四壁无滑移。浮力驱动自然对流，Rayleigh 数控制对流强度。

### 几何与参数

| 参数 | 值 |
|------|-----|
| 几何 | 1×1 方腔 |
| 格子模型 | D2Q9 (速度) + D2Q5 (温度)，BGK 碰撞 |
| 浮力格式 | Guo 格式 |
| Pr | 0.71 |
| Ra | {1e3, 1e4} |
| 网格 N | {64, 128, 256} |
| 总案例数 | 6 |
| 壁面 BC | 等温 (anti-bounce-back) + 绝热 (解缠反射) |

### 参考值 (de Vahl Davis 1983, 预注册)

| 物理量 | Ra=1e3 | Ra=1e4 |
|--------|--------|--------|
| Nū (平均 Nusselt) | 1.118 | 2.243 |
| u_max (扩散尺度) | 3.649 | 16.178 |
| v_max (扩散尺度) | 3.697 | 19.617 |

## 2. 方法

### 工具链
- **代码仓库**: TensorLBM (`benchmarks/verified/thermal_cavity/`)
- **Sweep 脚本**: `scripts/sdaa_sweep_thermal_cavity.py`（独立脚本，不改业务代码）
- **设备**: SDAA (`/dev/tcaicard1`)，PyTorch 2.7.1，float32
- **Triton 依赖**: 无（无需 `TRITON_INTERPRET=1` 绕行）

### 流程
1. 读取案例目录 `benchmarks/verified/thermal_cavity/` 的 driver.py 入口
2. 将张量放置到 `sdaa` 设备
3. 对 6 个 (Ra, N) 组合分别运行缩减步数（800–1000 步）
4. 提取稳态前的 Nu、u_max、v_max，与 DVD 1983 参考值比较
5. 按原口径判据（|err| ≤ 3%）逐条过门

### 步数缩减说明
完整收敛需 37k–563k 步（数小时），SDAA sweep 使用缩减步数以在 ~2 分钟内完成全部 6 案。这意味着结果处于**早期发展阶段**，尚未达到稳态。

## 4. 结果图

本次 sweep 为纯数值提取（无场量 npz/png 输出），未生成云图或比较曲线。理由：
- SDAA sweep 脚本设计为轻量级判据验证（800–1000 步），不输出完整场量数据
- 所有案例均处于早期发展阶段（远未稳态），场量云图物理意义有限
- 原始 NVIDIA 侧验证已包含完整稳态场量可视化（见 `benchmarks/verified/thermal_cavity/`）

**关键观察**：Ra=1e4, N=64 案例的 u_max 已达参考值的 90%（14.575 vs 16.178），表明 SDAA 设备上的物理演化方向正确，仅因步数不足未达稳态。

## 5. 注意点

### 踩过的坑
1. **步数不足是主要失败原因**：所有 6 案均因未达稳态而 FAIL，非算法/设备问题
2. **Nu 接近 1.0**：Ra=1e3 所有网格的 Nu≈1.0（纯导热值），说明对流尚未充分发展
3. **高 Ra 大网格发展更慢**：Ra=1e4, N=256 的 u_max 仅达参考值 6.6%，因大网格扩散时间尺度更长

### 原始判据口径
- 原始 NVIDIA 侧验证结论为 **PARTIAL**：N≥128 通过、N=64 因粗网格离散化失败
- 原始验证需要 37k–563k 步达到稳态
- 本次 SDAA sweep 使用缩减步数，**不应与原始验证结论直接比较**

### 设备兼容性
- SDAA 设备上代码无需 triton 绕行，直接运行
- 单步性能稳定（13–18 ms/step），无明显异常

### 适用范围
- 本 sweep 仅验证 SDAA 设备上代码可运行、物理演化方向正确
- 完整精度验证需运行至稳态（需数小时/案例）
