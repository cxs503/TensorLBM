## 1. 案例介绍

### 物理背景
DTMB Series 60 是 ITTC 推荐的标准化船型系列，Cb=0.60 成员是货船/油船的典型代表。Todd (1963) 发布了完整的模型试验阻力数据表，是船舶阻力预报的经典基准。本任务的目标是将船舶总体性能平台中 Series 60 阻力数据从硬编码/随机（MOCK）升级为基于物理算法的真实计算（REAL），并严格审计精度。

## 2. 方法

### 算法链路（三级证据分解）

原单实现了 `C_T = (1+k)·C_F + C_W` 的三级可审计分解：

1. **GEOMETRY 级**：参数化半宽图 `b(x,z) = (B/2)·(1-ξ²)^p · ζ^q`，满度指数 p 由二分法锁定到目标 Cb（|ΔCb| < 10⁻⁷），湿面积在 801×641 细网格上数值积分并固化，避免分辨率漂移。

2. **CORRELATION 级**：
   - 摩擦阻力：ITTC-1957 摩擦线 `C_F = 0.075/(log₁₀Re - 2)²`
   - 形状因子：Holtrop-Mennen (1984) 经验公式 `(1+k)`，含 LCB/Cstern 显式假设与敏感性区间

3. **THEORY 级**：Michell 薄船理论（Havelock 形式），对任意半宽图做三重积分，含：
   - 4×/2×/1× 加密 + Roache GCI 收敛估计
   - 轴向相位分辨率诊断（`k₀·sec(θ)·dx > π/8` 时拒绝出数）
   - 薄船适用性门限（L/B、Cb、B/L、T/L）

### 参考值锁定策略
参考值在运行前锁定（`refs_lock.json`，sha256 写入结果），防止事后挑选。Todd (1963) 数据标注为"二手转录"，明确不可作为一级基准。

## 5. 注意点

### 踩过的坑
1. **参数化几何的 Cwp 偏差**：Series 60 参数化模型的 Cwp=0.615，与某些文献值有差异，但不影响 Cb 锁定精度。
2. **薄船理论适用性**：Michell 理论要求 L/B > 6，Series 60 (L/B=6.5) 刚好过线，波阻精度受限。
3. **参考值来源**：Todd (1963) 数据为二手转录，不可作为一级基准；仓库内无一手模型试验数据。

### 局限性
1. **物理层精度不达标**：与 Todd 二手参考值偏差 -13.4%（Fn=0.3），远超 3% 目标，也不达 10% 带。
2. **LBM 腿缺失**：当前仓库无自由面+壁函数的模型 Re 求解能力，LBM 摩擦腿交付的 C_T_fric/ITTC ≈ 2.5（不可用）。
3. **单调性失败**：C_T(Fn) 在 Fn=0.2→0.3 区间未严格递增，可能是 Michell 理论在低 Fn 区的数值噪声。
4. **单相流口径**：本计算为单相流（无自由面），"波阻"实为 Michell 理论的数学波阻，非物理兴波。

### 适用范围
- ✓ 几何审计（Cb、S_wet）：< 3%（实际 < 10⁻⁵ %）
- ✓ 数值收敛（GCI）：< 3%（实际 1.45%）
- ✓ 分解自洽性：残差 = 0
- ✗ 物理对标（C_T vs 实验）：不达标
