## 1. 为什么单尺度 s^Q 失败（既有结论，复核确认）

数字楼梯椭圆壁**各向异性**：长轴端外凸 ~+1.1 格、短轴端内缩 ~−0.15 格
（双参数剖面拟合 (a_fit−a, b_fit−b) = (+1.176, −0.147)/(+1.057, −0.148)），
单一面积等效尺度 s^Q 无法同时表达两个方向的壁面偏移 → 最外中心 bin 超线。
求解器/BC 本身正确（剖面是精确椭圆抛物面，拟合残差 <0.2%）。

## 2. 两观测量水力反演（本单方法）

连续椭圆 (a_e,b_e) 充分发展流的三个解析关系：

```
u(y,z) = U_c (1 − (y/a_e)² − (z/b_e)²)
Q      = π a_e b_e U_c / 2
G      = 2ν U_c (a_e² + b_e²) / (a_e² b_e²)        [G = Δp/L]
```

取 **U_c = 2u_in**（均匀速度入口施加，质量守恒值），两个独立积分观测量定两个参数：

```
P = (a_e b_e)² = (2Q/(π U_c))²          ← Q（测量平面流量）
S = a_e² + b_e² = G·P/(2ν U_c)          ← G（充分发展段压差梯度）
a_e = √((S+√(S²−4P))/2),  b_e = √((S−√(S²−4P))/2)
```

**G 必须取充分发展段**（x_meas=nx/2 与 x_dev=nx−8 两平面密度差）：
入口段（x_e ≈ 0.05·Re·D_h）局部梯度高于充分发展值，用 x=0 全管长会把 G 高估
（a=20 实测 G_full 比 G_fd 高 ~11%），把 b_e 拉偏 ~0.5 格。

**质量守恒重归一（纯几何，不碰剖面）**：
`M_d(a_e,b_e) = Σ_{数字流体格} (1−(y/a_e)²−(z/b_e)²)`，`U_c' = Q/M_d`。
若剖面确为抛物面则 U_c' 即真实峰速；数字截面与连续椭圆的 O(1/a) 差异被吸收。

**主指标**（与 s^Q 主指标同哲学）：按 λ_e=(y/a_e)²+(z/b_e)² 分环、
中心区（u_ana>0.2U_c'）逐 bin 最大相对误差；解析值逐格求值再 bin 平均。
(a_e,b_e,U_c') 全部来自 Q、G 与几何计数，**零剖面拟合**——剖面只作为被检验量。
