## ① 案例介绍

**物理问题**：二维顶盖驱动方腔流（Lid-Driven Cavity），边长 L=1，顶盖以速度 U_lid 拖动，  
Re = U·L/ν = 5000，流动发展至定常。

**参考基准**：U. Ghia, K.N. Ghia, C.T. Shin, *"High-Re solutions for incompressible flow using  
the Navier-Stokes equations and a multigrid method"*, **J. Comput. Phys. 48(3)** (1982) 387–411.  
- Table III: u/U 沿竖直中线 x/L = 0.5（Re=5000 列）  
- Table IV: v/U 沿水平中线 y/L = 0.5（Re=5000 列）  
- 容差判据：逐点 |ref − got| ≤ 8% U_lid

**难点**：Re=5000 时 τ = 3·U_lid·L/Re + 0.5 ≈ 0.502（n=33）、0.508（n=129）、0.515（n=257），  
极度接近 LBM BGK 稳定性极限（τ > 0.5）。纯 BGK 碰撞在此参数下极易发散，需要 TRT/RLBM/MRT  
碰撞模型和/或更细网格。

## ⑤ 注意点（踩坑与局限）

1. **τ 接近 0.5 是硬约束**：Re=5000 在 D2Q9 LBM 中要求 τ 非常接近 0.5，导致数值不稳定。  
   - n=65: τ=0.5038 → 3000 步发散  
   - n=129: τ=0.5077 → ~10000 步发散  
   - n=257: τ=0.5154 → 预期可收敛（待验证）  
   - n=513: τ=0.5307 → 更好稳定性，但计算成本更高

2. **TRT 是最稳定的可用碰撞模型**：  
   - BGK：n=129 第 500 步发散  
   - RLBM：n=129 第 5000 步发散  
   - TRT：n=129 第 10000 步发散（最佳）

3. **速度爬升必要但不充分**：  
   - 无爬升（脉冲启动）：ρ 在 ~1000 步内打到 [0.6, 1.4]  
   - 爬升 2000 步：5000 步内稳定，但 10000 步附近仍失稳  
   - 爬升 5000 步：预期更好（待验证）

4. **参考数据准确性**：  
   - 本单添加的 Re=5000 参考数据来自 Ghia 1982 论文手动转录  
   - 已与多篇 CFD 基准研究交叉验证  
   - 但仍建议与实验数据或其他高精度数值解进一步对比

5. **MRT/entropic LBM 缺失**：  
   - D2Q9 MRT 碰撞模型未实现（仅有 D3Q19 MRT）  
   - Entropic LBM 未实现  
   - 这些更高级的碰撞模型可能提供更好的稳定性
