# FORCE2-MOMENTUM_VOL: 动量交换体积法力评估

## 物理出处
Chen(1998) LBM理论，基于动量守恒推导。通过控制体动量通量积分计算力：
$F_α = -∮_{∂V} Π_{αβ} n_β dS$，其中 $Π_{αβ} = Σ_i f_i c_{iα} c_{iβ}$。

## 改动摘要
- 新增 `TensorLBM/src/tensorlbm/force_volume.py`：实现体积法力计算。
- 将点采样（边界节点动量交换）替换为包围体积分（控制体表面动量通量）。
- 最小改动：仅修改力采样内核，不改变求解器其他部分。
