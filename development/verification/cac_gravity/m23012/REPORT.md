# cAC Gravity + Hydrostatic Pressure + Mass Conservation Verification (m23012)

## 0. 结论（一句话）

D3Q19 cAC+HCH 双分布实现已搭建（`src/tensorlbm/cac_lbm3d.py`），但**数值稳定性未通过**：
初始化后第 3 步即发散（phi 越界 → u 爆炸 → NaN），根因定位为**源项 S_i 的离散格式与宏观量恢复链不匹配**。
D2Q9 参考实现（commit 17e0f35ac）结构相同但需进一步对齐源项公式。本单交付：
- ✅ 预注册文件 `docs/m23012/PREREG.json`

- ✅ 验证脚本 `scripts/verify_cac_hydrostatic_mass.py`
- ❌ 物理验证未通过（发散），根因分析见下

## 1. 案例介绍（物理背景 / 几何 / 参数）

**物理问题**：保守 Allen-Cahn 相场耦合 HCH 不可压流体，在重力作用下验证：
1. 静水压分布 p(z) = p₀ + ρg(z_ref - z)，误差 < 1%
2. 有壁+重力 6000 步质量漂移 < 0.01%
3. 相场积分漂移 < 1e-10

**外部锚点**：Liang et al., Phys. Rev. E 97, 033309 (2018)

## 2. 怎么做的（方法 / 流程 / 工具链）

1. **D3Q19 cAC+HCH 实现**：基于 D2Q9 参考（commit 17e0f35ac）扩展到 3D
   - 双分布：f（相场，Σf_i = φ）+ g（流体，HCH 不可压）
   - 化学势：μ = 4βφ(φ-1)(φ-0.5) - κ∇²φ
   - 界面力：F = μ∇φ + ρg
   - 调和黏度混合
   - Neumann 壁面（零法向梯度）

2. **验证脚本**：`scripts/verify_cac_hydrostatic_mass.py`
   - 初始化液 slab（z=20..nz-20）
   - 运行 6000 步，每 100 步采样
   - 计算静水压误差、质量漂移、相场积分漂移

## 4. 根因分析

**发散机制**：
1. **第 1 步**：φ 越界（-0.013, 1.013），说明源项 S_i 的离散格式导致相场通量过大
2. **第 2-3 步**：φ 越界扩大 → 化学势 μ 计算异常 → 界面力 F 异常 → 速度 u 爆炸
3. **第 4 步+**：数值溢出 → NaN

**可能根因**：
1. **源项 S_i 公式不完整**：当前实现 `S_i = w_i * 3 * c_i · (φu_dt + λn̂/τ_f)` 是简化形式，
   Liang et al. 原文的源项包含速度依赖项 `(c_i - u)`，缺失此项可能导致动量不守恒
2. **宏观量恢复链**：`macroscopic_g` 中的压力恢复公式 `p = c_s²/(1-w₀) * (Σ_{i>0} g_i + ...)` 
   可能在 φ 越界时产生非物理压力
3. **平衡分布**：`g_equilibrium` 中的 HCH 不可压平衡分布可能需要修正项

**与 D2Q9 参考的差异**：
- D2Q9 参考（commit 17e0f35ac）使用相同的源项结构，但需验证其在 2D 下的稳定性
- D3Q19 的 stencil 权重不同（w₀=1/3 vs D2Q9 的 w₀=4/9），可能影响稳定性

## 5. 注意点（踩过的坑 / 局限 / 适用范围）

1. **源项公式需对齐原文**：Liang et al. (2018) Eq. (15)-(16) 的源项包含速度依赖项，
   当前简化形式可能不适用于大密度比情况
2. **FP64 是必要的**：FP32 下发散更快（实测第 2 步即 NaN）
3. **壁面策略**：Neumann 策略在 φ 越界时可能引入额外误差
4. **适用范围**：当前实现仅适用于小密度比（ρ_l/ρ_g < 2）且无外力的情况；
   重力 + 有壁情况需修复源项后才能验证
