# Historical Peskin tensor-product stencil and MDF comparison

This directory preserves the 2-D round-1 operator/cylinder study (m18131)
and the round-2 solid-interior screen (m20490). Read the original
[round 1 report](REPORT.md), [protocol](predeclared.json),
[original results](artifacts/xval_peskin_tp_mdf.json),
[round 2 report](r2_interior/REPORT_R2.md), and
[round 2 screen](r2_interior/artifacts/screen.json).

The original independently sourced vendor provenance is
[oss_ref/PROVENANCE.json](oss_ref/PROVENANCE.json). Its existing NumPy
implementation of the JAX-facing operations is preserved, not a new
stub or mock, and is not native JAX execution. Historical operator
agreement is not end-to-end scientific acceptance. Round 1 physical drag
was not validated; round 2 did not complete the decisive matrix.
The published claims in the original reports remain unchanged.

[Registered evidence entry](../../../benchmarks/cross_validation/peskin_tensor_product_stencil_mdf/README.md).
The separate 3-D sphere studies remain at
`benchmarks/xval_ib3d_diffuse_interface_mdf/` and
`benchmarks/xval_peskin_stencil_mdf_r2/`; those are different campaigns.

For path/CLI compatibility only, from the checkout root:

```sh
PYTHONPATH=src python development/verification/peskin_tensor_product_stencil_mdf/run_xval.py --help
PYTHONPATH=src python development/verification/peskin_tensor_product_stencil_mdf/r2_interior/run_l4_interior.py --help
```

Run the historical drivers only in an isolated copy with the required dependencies,
not over committed evidence. The original report/publishing tools retain historic
commands. Missing original figures, full ladder and publishing artifacts were not
reconstructed or generated by this migration.
