## ① 案例介绍（物理背景 / 几何 / 参数）

静态二维液滴在周期盒中松弛到 Laplace 平衡：分相靠 Shan-Chen 伪势自相互作用，界面张力由
Young-Laplace 定律 `Δp = σ/R_eq` 体现。判别目标是**同一个 SCMP 模型下三种力项注入方式**
（velocity-shift / EDM（Kupershtokh 精确差分，即 TCLB `shan-chen-edm` 所用）/ Guo 2002）
给出的界面张力与共存密度是否一致、是否随松弛时间 τ 漂移。上游第 1 轮用同一问题的自研复刻做过，
本轮改到**随仓发布的库路径**上并补齐非退化设计。

| 项 | 值 |
|---|---|
| 模型 | SCMP 单组分 Shan-Chen（Shan & Chen 1993/94），D2Q9，BGK |
| 伪势 | `ψ(ρ)=1−exp(−ρ)`（`tensorlbm.multiphase.psi_exp`, ρ₀=1） |
| 耦合 | 库约定 `G=+5`（后向 gather，>0 为吸引；等价教科书 `G_eff=−5`） |
| 体相压力 | `p_mech = c_s²ρ − (G/2)c_s²ψ²`（**库约定**；见③的约定核对） |
| 网格 | L = 4R，R ∈ {10,12,14} → L ∈ {40,48,56} |
| 初值 | tanh 界面，宽 4，ρ_l=1.957 / ρ_v=0.1596 |
| τ | 0.8 / 1.0 / 1.2（ν=(τ−1/3)/3 = 0.156 / 0.222 / 0.289） |
| 力项 | `velocity_shift`（历史默认）/ `edm`（精确差分）/ `guo`（Guo 2002 源项） |
| 收敛 | Δp 相对变化 <2e-3 每 250 步，上限 3000–4000 步（实测 1000–3000 步收敛） |
| 测量带 | 内 r ≤ 0.5R_eq，外 r ≥ 1.5R_eq；R_eq 由液区面积自洽迭代 |

## ② 怎么做的（方法 / 关键设置 / 工具链）

1. **对象校正**：不再自写求解器，全部走 `tensorlbm.multiphase.collide_sc_single_component`
   + `tensorlbm.solver.stream`（上游第 1 轮从未 import `tensorlbm`，见 `REVIEW_R1.md` S1）。
2. **压力约定校正**：`p_mech` 采用库的后向 gather 约定（减号）。用上游自己报告的密度复算，
   其"σ≈16"来自加号约定，真实值 0.055——相差 271 倍（`REVIEW_R1.md` S2）。
3. **非退化设计**：先证明并数值验证 **τ=1 时 EDM ≡ velocity-shift**（二者都松弛到
   `feq(u+F/ρ)`），因此判别必须在 τ≠1 下做。上游 9 个臂全在 τ=1，A/B 两臂按构造不可分。
4. **解析参照（不用求解器）**：在该 τ 无关的 SC 状态方程上做 Maxwell 等面积构造
   （等化学势 `∫(p−p_sat)/ρ²dρ=0`，对 p_sat 二分），得共存密度 `ρ_l, ρ_v` 与 `p_sat`；
   另以库内标定值 σ=0.0561 作为 σ 的独立交叉核对。
5. **工具链**：PyTorch 2.7.1（float32 求解 / float64 恒等式腿）、NumPy、SciPy(brentq)、
   Matplotlib；全量 45 例经 compute 门递交（`cj3388`，9 分片），紧凑 23 例在本机单线程完成
   （每次 <120 s，符合本机短测试额度）。
6. **不变式落库**：`tests/test_xval_sc_edm_laplace_r2.py`（5 项，20 s）——τ=1 恒等、三力项
   质量守恒/有界、σ 必须落在物理带宽（防回退到 271 倍错号）、Δp∝1/R 排序、Maxwell 解析自洽。

## ④ 注意点（踩坑 / 局限 / 适用范围）

1. **τ=1 是退化点**：任何"力项对比"若只在 τ=1 做，EDM 与 velocity-shift 必然逐位相同——这不是
   "力幅小掩盖了差异"，而是恒等式（2.78e-17）。
2. **压力符号必须跟库约定**：用加号约定会把 σ 放大到 ~16（271 倍），且因两臂共模抵消而"看起来一致"。
3. **Guo 分支 σ 偏低 39%**（0.0337 vs 0.0561）且与 τ 无关：该分支的 `S ∝ (1−1/2τ)` 与半力速度
   修正组合在本模型下系统性低估值，**建议单独立项核查**（本轮未定位到具体项，不下结论）。
4. **R=10 的 Δp 系统性偏高**（σ 高 1–2%），是测量带（0.5R_eq）与有限液滴曲率离散误差，属方法局限。
5. **寄生流偏大**（u_max≈0.13）：G=5、界面宽 4、τ≈1 的粗界面 SC 的已知伪影；本轮只做**相对**比较
   （三力项间），不作为绝对精度判据；要提高物理保真需更宽界面/更高阶各向同性力 stencil。
6. **与 TCLB 的对标是配方级、非代码级**：仓内无 TCLB 运行时，未执行 TCLB 本体（`REVIEW_R1.md` 未执行项）。
7. 全量 45 例（`cj3388`）递交时排队 16 位、8 min 后仍在 queue，本报告结论基于紧凑 23 例
   （3 半径 / τ∈{0.8,1.0,1.2}），半径点数少于全量计划的 5 个。

## ⑤ 误差判定（逐项对基准，显式回答「是否 <3%」）

| 关键量 | 基准 | 实测（最佳臂） | 误差 | <3%? | <15%? |
|---|---|---|---|---|---|
| σ（EDM，R=12，τ=0.8/1.0/1.2） | 库标定 0.0561 | 0.05496 / 0.05519 / 0.05508 | 2.0% / 1.6% / 1.8% | **是** | 是 |
| σ_fit（EDM，3 半径过原点拟合） | 0.0561 | 0.05416–0.05417 | 3.4% | **否（3.4%，略超）** | 是 |
| σ（velocity_shift，τ=0.8） | 0.0561 | 0.04230（σ_fit 0.04205） | 24.6%（25.0%） | 否 | **否（>15%）** |
| σ（velocity_shift，τ=1.2） | 0.0561 | 0.07277 | 29.7% | 否 | **否** |
| σ（Guo，任意 τ） | 0.0561 | 0.03368–0.03417 | 39.1–39.9% | 否 | **否** |
| ρ_l（三力项全体） | Maxwell 1.92887 | 1.914–2.009 | 0.3–4.1% | 部分（EDM 2.2% ✔ / guo 0.3–0.8% ✔ / vs@1.2 4.1% ✘） | 是 |
| ρ_v（EDM 全 τ） | Maxwell 0.15289 | 0.161–0.163 | 5.3–6.3% | 否 | 是 |
| ρ_v（velocity_shift τ=1.2） | 0.15289 | 0.1935 | 26.6% | 否 | **否** |
| ρ_v（Guo 全 τ） | 0.15289 | 0.1256–0.1280 | 16.3–18.5% | 否 | **否** |
| Laplace 线性性 | R² = 1 | 0.958–0.997 | — | 否（离散 <5%） | 是 |

**判定**：本锚点问的是"库是否达到 TCLB shan-chen-**edm** 一族的行为"。
**EDM 路径 PASS**：σ 对库标定值 1.6–2.0%（<3%），且 **σ 对 τ 的离散度 0.4%**（vs 25.6%），
共存密度 ρ_l/ρ_v 对 Maxwell 解析 2.2%/5.3–6.3%（<15%）——即 EDM 消除了 velocity-shift 的 τ 依赖伪力。
**同期发现两处 honest FAIL，不粉饰**：① velocity-shift 在 τ≠1 下 σ 误差 24.6–29.7%、ρ_v 误差 26.6%；
② Guo 分支 σ 偏低 39%、ρ_v 偏低 16–19%。二者均**不是** EDM 路径的缺陷，但说明"三种力项等价"的说法不成立，
上游第 1 轮"TL_vs == TL_edm ⇒ 力项影响被掩盖"的物理解释应更正为 τ=1 恒等式。
